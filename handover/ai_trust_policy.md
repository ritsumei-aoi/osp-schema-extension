# AI Trust Policy

## Forbidden Actions
- Do NOT use `git reset --hard` or `git push --force`.
- Do NOT modify or delete `.env`, `.git`, or system configuration files.
- Do NOT attempt to access external network resources unless explicitly instructed.

## Boundary
- If a task requires a decision not covered by `issue_open.md`, or if you encounter a mathematical ambiguity, halt and ask for clarification via `docs/issues/issue_needs_clarification.md`.
