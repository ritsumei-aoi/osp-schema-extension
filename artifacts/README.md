# Verification artifacts for the triviality of the gb-deformation of C(n+1)

Generated by `python3 scripts/verify_triviality.py 1 2 3` (exact rational arithmetic).
Re-verify from the JSON alone with `python3 scripts/check_artifacts.py 1 2 3`.
Human-readable formulas: `python3 scripts/print_formulas.py <n>`.

Files
- `Cn1_triviality_n1.json`, `Cn1_triviality_n2.json`, `Cn1_triviality_n3.json`
- `summary.json` — one-line conclusion and per-$n$ headline numbers.

Top-level keys of `Cn1_triviality_n{n}.json`
| key | content |
|---|---|
| `conventions` | the exact formulas used for the bracket decomposition, $\delta f$, $d\gamma$, ordering and normalisation |
| `basis` | `index`, `label` (root label), `parity`, `weight` $=(\varepsilon,\delta_1,\dots,\delta_n)$, `oscillator_expression` |
| `gb_parameters` | `index` $\alpha$, $(\sigma, j, s)$, and the relation $[b_j^s,a_1^\sigma]=-\mathrm{gb}[\alpha]\kappa$ |
| `structure_constants` | rows $[i,j,k,c]$: $[Z_i,Z_j]=\sum_k c\,Z_k$ (undeformed, $gb$-independent) |
| `gamma_g_part` | rows $[i,j,m,\alpha,v]$: $\gamma_{gb}(Z_i,Z_j)^m=\sum_\alpha v\,\mathrm{gb}[\alpha]$ |
| `gamma_scalar_part` | rows $[i,j,\alpha,v]$: scalar ($\kappa\mathbb C$) part of $[Z_i,Z_j]$ |
| `f_explicit` | primitive from the oscillator change of variables: rows $[m,i,\alpha,v]$ meaning $\phi_{mi}=\sum_\alpha v\,\mathrm{gb}[\alpha]$, plus `scalar_part` $f''$ |
| `f_homotopy` | primitive $f_N(Y)=\gamma(N,Y)/w$, same format |
| `linear_solve` | unknowns / rank / nullity of $\delta\phi=\gamma_{gb}$, solvability per direction, particular solutions |
| `verification` | booleans for every check performed |
| `cohomology` | $\dim C^1,Z^1,C^2,Z^2,B^2,H^2$ for odd cochains, and the same per Cartan-weight block |

All rational numbers are stored as strings (`"-1/2"`). Indices are 0-based and refer to `basis` / `gb_parameters`.
