Generated by `scripts/cn1_deformation.py`; independently re-checkable with
`scripts/verify_artifacts.py` (pure Python, exact rationals, no sympy).

```bash
python3 scripts/cn1_deformation.py --n 1 2 3 --out artifacts --full-complex
python3 scripts/verify_artifacts.py artifacts/cn1_n1.json artifacts/cn1_n2.json artifacts/cn1_n3.json
```

## Files

| file | content |
|---|---|
| `cn1_n1.json`, `cn1_n2.json`, `cn1_n3.json` | full structured data for n = 1, 2, 3 (schema below) |

## Schema of `cn1_n{n}.json`

All numbers are exact rationals stored as strings (`"1"`, `"-1/2"`).
A *linear form in gb* is a dict `{"gb[a+,b1-]": "-2", ...}` meaning
`-2 * gb_{+,1,-} + ...`; the key `"1"` (never present in practice) would be a constant term.

| key | meaning |
|---|---|
| `algebra`, `n`, `dim` | `C(n+1) = osp(2|2n)`, n, `{even, odd, total}` dimensions |
| `conventions` | oscillator names/parities, the deformed relations, basis convention, weight coordinates, the deformed-bracket decomposition, the coboundary formula, list of the 4n `gb` labels `gb[a sigma,b j s]` (= gb_{sigma,j,s}) |
| `basis[i]` | `{index, name, parity, weight, oscillator_expression}` for Z_i. Names: `N_a`, `N_k`, `E[root]` with roots written like `e+d1`, `-e-d2`, `2d1`, `d1-d2`. Weights are `(epsilon, delta_1, ..., delta_n)` coordinates |
| `structure_constants` | sparse list `{i, j, k, value}`: `[Z_i, Z_j]_0 = sum_k value Z_k` (undeformed, super-commutator) |
| `gamma_gb` | sparse list `{i, j, k, value: <linear form in gb>}`: the g-component of the kappa-part of `[Z_i, Z_j]_gb` (kappa on the left) |
| `scalar_part_s1` | sparse list `{i, j, value: <linear form>}`: the scalar (identity) component of the kappa-part — the part discarded "up to scalar" |
| `f_gb` | sparse list `{m, j, phi_mj: <linear form>}`: the explicit odd map `f_gb(Z_j) = sum_m phi_mj Z_m` with `gamma_gb = delta f_gb` |
| `lambda_gb` | sparse list `{j, value}`: scalar 1-cochain with `s1(Z_i, Z_j) = lambda([Z_i, Z_j]_0)` |
| `d_sigma` | the shift elements `d_+`, `d_-` (a^sigma -> a^sigma + kappa d_sigma) |
| `verification` | all boolean checks and numerical ranks (see below) |
| `conclusion` | one-sentence statement of the result |

### `verification` block

| key | meaning |
|---|---|
| `algebra.*` | closure without scalars, gb-free structure constants, super skew-symmetry, super Jacobi, weight consistency, `parity_equals_epsilon_weight_mod_2`, trivial centre |
| `gamma_is_cocycle` | first-order super-Jacobi identity of the deformed bracket, gb symbolic |
| `primed_oscillators_undeformed` | Lemma 3.1 of the report (shifted oscillators obey the undeformed relations) |
| `phi_is_homomorphism_on_g` | `[phi(Z_i), phi(Z_j)]_gb = sum_k c_ij^k phi(Z_k)` exactly in W_gb |
| `gamma_equals_delta_f_in_g` | `gamma_gb == delta f_gb` symbolically |
| `scalar_parts_equal_delta_minusF_scalars` | `s1 == lambda([.,.]_0)` symbolically |
| `rank_gb_to_gamma`, `gb_to_gamma_injective` | rank of the linear map gb -> gamma_gb (expected 4n) |
| `linear_solve` | independent exact solve of `delta phi = gamma_e` for each gb direction e (no use of the theorem's f): rank of delta^1, kernel dimension, solvability, re-substitution check, and a particular solution per direction |
| `cohomology_weight_zero` | dimensions of the weight-zero odd sub-complex (all zero: Theorem 4.2) |
| `cohomology_full_complex` | dimensions on the full odd complex: C^1, C^2, rank d^2, Z^2, B^2, H^2, Z^1, H^1, and `d2_after_delta_is_zero` |

## Conventions (same as in the report)

* `{a-, a+} = 1`, `(a±)^2 = 0`, `[b_k-, b_l+] = delta_kl`; `[b_j^s, a^sigma] = -gb_{sigma,j,s} kappa`; kappa odd, central, `kappa^2 = 0`, always written on the left.
* `[Z_i, Z_j]_gb = sum_k c_ij^k Z_k + kappa ( sum_k gamma_ij^k Z_k + s1_ij * 1 )`.
* `(delta f)(X,Y) = (-1)^{p(X)} [X, f(Y)] - (-1)^{(p(X)+1) p(Y)} [Y, f(X)] - f([X,Y])`.
