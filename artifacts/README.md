Generated by

```

python3 scripts/cn1_cohomology.py 1 2 3 --full    # independent rank computations over GF(2^31-1), ~12 s
```

## `Cn1_n{n}_verification.json`

| key | content |
|---|---|
| `basis[i]` | name, parity, weight `(eps, delta_1..delta_n)` and oscillator word of the basis vector `Z_i` (normal-ordered words; `H_{n+1}` contains the constant `-1/2`) |
| `structure_constants_C[i][j][k]` | `[Z_i, Z_j]_0 = sum_k C[i][j][k] Z_k` (nested dicts keyed by names, exact rationals as strings) |
| `gamma_ad_per_gb[gb][i][j][k]` | adjoint part of the deformation cochain for the **unit** parameter `gb`: `[Z_i,Z_j]_{U(A')} = [Z_i,Z_j]_0 + kappa * ( sum_k gamma_ad[i][j][k] Z_k + gamma_scalar[i][j] * 1 )`; the general cochain is the gb-linear combination |
| `gamma_scalar_per_gb[gb][i][j]` | scalar (central) part, normal-ordered section |
| `untwisting_map.f_phi_per_gb[gb][Z_j][Z_i]` | the explicit odd map `f(Z_j) = sum_i phi_ij Z_i` with `gamma_ad = delta f` (document formula for `delta`) |
| `untwisting_map.f_scalar_per_gb[gb][Z_j]` | scalar part `c` with `gamma_scalar = delta c`, `(delta c)(X,Y) = -c([X,Y])` |
| `checks` | booleans for every exact assertion performed (closure, super-skew-symmetry, kappa sign rules, untwisting isomorphism, homomorphism property, `gamma = delta f`, injectivity of `gb -> gamma_scalar`, symmetrised-section cross-check) |
| `cartan_matrix_*` | `[H_i, E_{alpha_j}] = a_ij E_{alpha_j}` for the simple roots listed in `simple_roots` |

Conventions: `kappa` odd central (`kappa^2 = 0`), written on the left; `{a-,a+} = 1`, `[b_j-, b_k+] = delta_jk`,
`[b_j^s, a^sigma] = -gb[a^sigma,b_j^s] kappa`; `(delta f)(X,Y) = (-1)^{p(X)}[X,f(Y)] - (-1)^{(p(X)+1)p(Y)}[Y,f(X)] - f([X,Y])`.

## `Cn1_n{n}_cohomology.json`

Produced without using the explicit `f`:

* `adjoint_equation_gamma_ad=delta_phi` – solvability (rank test) for each unit gb and a random gb; dimension of the affine solution space (= `dim Z^1_odd`).
* `literal_equation_gamma=delta_phi_with_scalars` – the same equation with the scalar part included: unsolvable for `phi: g -> g`, solvable for `phi: g -> g + C1` (normal-ordered section).
* `H1_odd(g,g)`, `cohomology.weight_zero`, `cohomology.full` – `dim Z^2_odd`, `dim B^2_odd`, `H^2_odd` from the order-kappa super-Jacobi identity on `L = g + kappa g`; `gamma_ad_is_cocycle_per_gb`, `random_coboundary_is_cocycle` are sanity checks of the equations.

All ranks are over GF(p), p = 2^31 - 1 (`prime`).
