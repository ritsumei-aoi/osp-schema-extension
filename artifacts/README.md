# Verification artifacts

Generated by `scripts/osp_deform.py` (exact rational arithmetic, standard library only) and
`scripts/summarize.py`. See `docs/issues/mathematical_proof.md` for the mathematics.

| file | content |
|---|---|
| `C{n+1}_deformation_n{n}.json` (n=1,2,3) | basis of C(n+1) (oscillator expressions, parity, weight), structure constants `[Z_i,Z_j,Z_k,c]`, cocycle `gamma[alpha]` and scalar terms per gb parameter, explicit odd maps `f_isometry` and `f_cartan` with their scalar parts, all check flags |
| `verification_summary.json` | theorem statement, explicit formulas, per-n/per-parameter pass flags |

Regenerate:
```bash
python3 scripts/osp_deform.py --n 1 --cohomology
python3 scripts/osp_deform.py --n 2 --cohomology
python3 scripts/osp_deform.py --n 3 --cohomology
python3 scripts/summarize.py
```
Exit code 0 means every check passed. Rational numbers are stored as strings (e.g. `"-1/2"`).
Weights are vectors in the coordinates `(epsilon, delta_1, ..., delta_n)`.
