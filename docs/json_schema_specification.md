# C(n+1) v5.0 JSON Schema Specification

This document specifies the v5.0 JSON schema for $C(n+1) = \mathfrak{osp}(2|2n)$ structure constants, extending the $B(0,n)$ v5.0 schema.

## 1. Overview: Schema Architecture

The JSON dataset for $C(n+1)$ is organized into 4 layers:
- Layer 1 (`C_{n}_structure.json`): Algebra structure (basis, parity, oscillator realizations, structure constants).
- Layer 2 (`C_{n}_gamma.json`): Inhomogeneous deformation ($\gamma$-structure).
- Layer 3 (`C_{n}_evaluated.json`): Numerically evaluated structure constants for specific $gb$ parameters.
- Layer 4 (`C_{n}_coboundary.json`): Coboundary data for triviality verification.

`n` denotes the bosonic rank ($n=1$ for $C(2)$, $n=2$ for $C(3)$, $n=3$ for $C(4)$).

## 2. Layer 1 (Schema 1): Algebra Structure Definition

### Top-Level Keys

```json
{
  "schema_version": "5.0",
  "algebra": { ... },
  "oscillator_generators": { ... },
  "oscillator_relations": { ... },
  "central_elements": { ... },
  "basis": { ... },
  "parity": { ... },
  "generator_realization": { ... },
  "structure_constants": [ ... ],
  "metadata": { ... }
}
```

### Key Specifications

#### 2.1 `algebra`
```json
{
  "family": "C",
  "m": 1,
  "n": 1,
  "cartan_type": "C(2)",
  "alternative_notation": {
    "osp": "osp(2|2)",
    "dimension_formula": "osp(2m|2n) with m=1"
  },
  "dimension": {
    "total": 8,
    "even": 4,
    "odd": 4
  }
}
```
*Dimension formulas*: even = $2n^2 + n + 1$, odd = $4n$, total = $2n^2 + 5n + 1$.

#### 2.2 `oscillator_generators`
```json
{
  "fermions": {
    "count": 2,
    "m": 1,
    "labels": ["a_1_p", "a_1_m"],
    "description": "Standard CAR fermionic pair a_1^±"
  },
  "bosons": {
    "count": 2,
    "n": 1,
    "labels": ["b_1_p", "b_1_m"],
    "description": "Bosonic oscillators b_i^± with i=1,...,n"
  }
}
```

#### 2.3 `oscillator_relations`
```json
{
  "standard_fermion_anticommutators": {
    "description": "{a_1^-, a_1^+} = 1",
    "relation": "a_1_m * a_1_p + a_1_p * a_1_m = 1"
  },
  "bosonic_commutators": {
    "description": "Canonical commutation relations for bosonic oscillators",
    "relations": {
      "same_type": "[b_i^±, b_j^±] = 0 for all i, j",
      "conjugate_pair": "[b_i^-, b_j^+] = δ_{ij}"
    }
  },
  "mixed_commutators": {
    "boson_fermion": "[b_i^±, a_1^±] = 0"
  }
}
```

#### 2.4 `central_elements` (Top-Level Key)
```json
{
  "kappa": {
    "parity": 1,
    "relation": "kappa^2 = 0",
    "description": "Odd nilpotent central extension element"
  },
  "K": {
    "parity": 0,
    "relation": "central scalar unit",
    "description": "Even central unit element"
  }
}
```

#### 2.5 `basis`
PBW ordering: `kappa < [odd] < [even]`
```json
{
  "even": [
    "H_1", "H_2",
    "E_2del1_p", "E_2del1_m"
  ],
  "odd": [
    "E_eps1_del1_pp", "E_eps1_del1_pm",
    "E_eps1_del1_mp", "E_eps1_del1_mm"
  ],
  "ordering_convention": "PBW: kappa < [odd] < [even]"
}
```

#### 2.6 `parity`
Mapping of each generator label to its parity $0$ (even) or $1$ (odd).

#### 2.7 `generator_realization`
Standard form expressions in terms of normal-ordered oscillator words:
- $H_1 = a_1^+ a_1^- + b_1^+ b_1^-$
- $H_k = b_{k-1}^+ b_{k-1}^- - b_k^+ b_k^-$ ($2 \le k \le n$)
- $H_{n+1} = -b_n^+ b_n^- - 1/2$
- $E_{2\delta_k} = (b_k^+)^2$, $E_{-2\delta_k} = (b_k^-)^2$
- $E_{\delta_i \pm \delta_j} = b_i^+ b_j^\pm$
- $E_{\pm\varepsilon \pm \delta_k} = a_1^\pm b_k^\pm$

#### 2.8 `structure_constants`
List of non-zero graded brackets $[X, Y\} = \sum_Z c_{XY}^Z Z$:
```json
[
  {
    "X": "H_1",
    "Y": "E_eps1_del1_pp",
    "Z": "E_eps1_del1_pp",
    "coeff": "2",
    "sign_rule": "graded"
  }
]
```

## 3. Schema 2 (Deformation), Schema 3 (Evaluated), Schema 4 (Coboundary) Specifications

- **Schema 2 (`C_{n}_gamma.json`)**: Contains the `gb_matrix` ($2 \times 2n$ parameters $\{ \mathrm{gb}_{a_1^\sigma, b_j^s} \}$) and symbolic gamma coefficients $\gamma_{abc}$ for $[X_a, X_b]_\gamma = [X_a, X_b]_0 + \kappa \sum_c \gamma_{abc} X_c$.
- **Schema 3 (`C_{n}_evaluated.json`)**: Evaluated brackets under specific numeric assignments of $gb$ parameters (e.g. all $gb = +1$).
- **Schema 4 (`C_{n}_coboundary.json`)**: Coboundary coefficients $(\delta f)_{abc}$ generated by an odd linear map $f: \mathfrak{g} \to \mathfrak{g}$.

---

## 4. Backward Compatibility with B(m,n) Schema

- Both schemas share the 4-layer architecture, PBW ordering concept, and top-level structural layout.
- $C(n+1)$ replaces `supplementary_fermion` with `fermions` (m=1), adds `central_elements` as a top-level key, and updates odd basis and generator realizations for $a_1^\pm$.
