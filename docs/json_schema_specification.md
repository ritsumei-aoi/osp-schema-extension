# JSON Schema Specification for C(n+1) = osp(2|2n) (Version 5.0)

This document specifies the v5.0 JSON schema for $C(n+1) = \mathfrak{osp}(2|2n)$ structure constants and deformations. It extends the $B(0,n)$ v5.0 schema (`docs/math/B0n_schema_v5.md`) to the $C(n+1)$ family while maintaining schema architecture consistency.

---

## 1. Overview and 4-Layer Architecture

The schema maintains a 4-layer architecture across files in `data/`:

| Layer | File Pattern | Purpose |
|---|---|---|
| Schema 1 | `C_{n}_structure.json` | Core algebra: basis, parity, oscillator realization, structure constants |
| Schema 2 | `C_{n}_gamma.json` | Inhomogeneous deformation parameters and $\gamma$-cocycle structure |
| Schema 3 | `C_{n}_evaluated.json` | Evaluated structure constants under concrete $gb$ sign assignments |
| Schema 4 | `C_{n}_coboundary.json` | Coboundary reference data generated by odd linear map $f$ |

Here $n$ denotes the **bosonic rank**:
- $n = 1$: $C(2) = \mathfrak{osp}(2|2)$
- $n = 2$: $C(3) = \mathfrak{osp}(2|4)$
- $n = 3$: $C(4) = \mathfrak{osp}(2|6)$

---

## 2. Schema 1 Top-Level Specification

A valid Schema 1 JSON file contains the following top-level keys:

```json
{
  "schema_version": "5.0",
  "algebra": { ... },
  "oscillator_generators": { ... },
  "central_elements": { ... },
  "oscillator_relations": { ... },
  "basis": { ... },
  "parity": { ... },
  "generator_realization": { ... },
  "structure_constants": [ ... ],
  "metadata": { ... }
}
```

---

## 3. Detailed Key Definitions

### 3.1 `schema_version`
String identifying the schema specification version: `"5.0"`.

### 3.2 `algebra`
Identifies the Lie superalgebra, Cartan type, and dimensions.
Mandatory fields:
- `"family"`: `"C"`
- `"m"`: `1` (fermionic rank)
- `"n"`: integer (bosonic rank, $n \ge 1$)
- `"cartan_type"`: `"C(n+1)"` (e.g. `"C(2)"`, `"C(3)"`, `"C(4)"`)
- `"alternative_notation"`:
  - `"osp"`: `"osp(2|2n)"` (e.g. `"osp(2|2)"`, `"osp(2|4)"`, `"osp(2|6)"`)
  - `"dimension_formula"`: `"osp(2m|2n) with m=1"`
- `"dimension"`:
  - `"total"`: $2n^2 + 5n + 1$
  - `"even"`: $2n^2 + n + 1$
  - `"odd"`: $4n$
  - `"formulas"`: `{"even": "2n^2 + n + 1", "odd": "4n", "total": "2n^2 + 5n + 1"}`

Example for $n = 1$:
```json
{
  "family": "C",
  "m": 1,
  "n": 1,
  "cartan_type": "C(2)",
  "alternative_notation": {
    "osp": "osp(2|2)",
    "dimension_formula": "osp(2m|2n) with m=1"
  },
  "dimension": {
    "total": 8,
    "even": 4,
    "odd": 4,
    "formulas": {
      "even": "2n^2 + n + 1",
      "odd": "4n",
      "total": "2n^2 + 5n + 1"
    }
  }
}
```

### 3.3 `oscillator_generators`
Defines the microscopic oscillators realizing the algebra.
Contains two primary keys:
- `"fermions"`:
  - `"count"`: 2
  - `"m"`: 1
  - `"labels"`: `["a_1_p", "a_1_m"]`
  - `"description"`: `"Standard fermionic CAR pair"`
- `"bosons"`:
  - `"count"`: $2n$
  - `"n"`: $n$
  - `"labels"`: `["b_1_p", "b_1_m", ...]`
  - `"description"`: `"Bosonic CCR oscillators b_i^± with i=1,...,n"`

### 3.4 `central_elements`
Top-level key specifying central elements:
- `"kappa"`:
  - `"parity"`: 1
  - `"nilpotent_order"`: 2
  - `"relation"`: `"kappa^2 = 0"`
  - `"description"`: `"Odd central parameter for inhomogeneous deformation"`
- `"K"`:
  - `"parity"`: 0
  - `"relation"`: `"K = 1"`
  - `"description"`: `"Even central identity element"`

### 3.5 `oscillator_relations`
Defines algebraic commutators and anticommutators:
- `"standard_fermion_anticommutators"`:
  - `"relations"`:
    - `"anticommutator"`: `"{a_1^-, a_1^+} = 1"`
    - `"nilpotency"`: `"(a_1^+)^2 = 0, (a_1^-)^2 = 0"`
- `"bosonic_commutators"`:
  - `"relations"`:
    - `"same_type"`: `"[b_i^±, b_j^±] = 0 for all i, j"`
    - `"conjugate_pair"`: `"[b_i^-, b_j^+] = δ_{ij}"`
- `"mixed_commutators"`:
  - `"relations"`:
    - `"boson_fermion"`: `"[b_i^±, a_1^±] = 0 (undeformed)"`

### 3.6 `basis`
Strictly PBW ordered lists of even and odd generators:
- `"even"`: Array of $2n^2 + n + 1$ string labels.
- `"odd"`: Array of $4n$ string labels.
- `"ordering_convention"`: `"PBW: κ < [odd] < [even]"`

### 3.7 `parity`
Mapping of each generator label to an integer in `{0, 1}`:
- `0`: Even generators ($H_i$, $E_{\pm 2\delta_k}$, $E_{\pm \delta_i \pm \delta_j}$).
- `1`: Odd generators ($E_{\pm \varepsilon \pm \delta_k}$).

### 3.8 `generator_realization`
Details the normal-ordered oscillator representation of each generator:
- `"description"`: `"Standard form with PBW ordering"`
- `"ordering"`: `"a_1_p, a_1_m, b_1_p, b_1_m, ..."`
- `"realizations"`: Object mapping generator name to:
  - `"standard_form"`: Array of `{"words": [...], "coeff": "..."}` objects with rational string coefficients.
  - `"frappat_form"`: LaTeX-like string representation.
  - `"parity"`: `0` or `1`.

### 3.9 `structure_constants`
List of non-zero graded Lie brackets:
$$[X, Y] = (-1)^{p(X)p(Y)} [Y, X] = \sum_Z c_{XY}^Z Z.$$
Stored canonically for $X \le Y$ in PBW order:
```json
{
  "X": "H_1",
  "Y": "E_eps1_del1_pp",
  "Z": "E_eps1_del1_pp",
  "coeff": "1",
  "sign_rule": "graded"
}
```

### 3.10 `metadata`
Metadata block capturing provenance:
```json
{
  "generated_by": "src/C_generators.py",
  "generation_date": "YYYY-MM-DD",
  "references": [
    "Frappat et al. (2000), Dictionary on Lie Algebras and Superalgebras",
    "handover/notation.md"
  ]
}
```

## 4. Comparison and Compatibility with B(0,n) Schema

| Field / Key | B(0,n) v5.0 | C(n+1) v5.0 | Compatibility Notes |
|---|---|---|---|
| `algebra.family` | `"B"` | `"C"` | Distinct family identifier |
| `algebra.m` | `0` | `1` | Reflects fermionic rank |
| `algebra.cartan_type` | `"B(0,n)"` | `"C(n+1)"` | Follows Frappat convention |
| Fermionic oscillators | `supplementary_fermion` (`a_0`, $a_0^2 = 1/2$) | `fermions` (`a_1_p`, `a_1_m`, $\{a_1^-, a_1^+\} = 1$) | CAR pair replaces single auxiliary fermion |
| `central_elements` | Embedded or implicit | **Top-level key** (`kappa`: odd, `K`: even) | Unified across all runs |
| Odd generators | $2n$ (`E_del{k}_p/m`) | $4n$ (`E_eps1_del{k}_pp/pm/mp/mm`) | Quadrupled odd sector reflecting $\pm\varepsilon\pm\delta_k$ |
| Even dimension | $2n^2 + n$ | $2n^2 + n + 1$ | Extra Cartan generator for $\mathfrak{so}(2)$ factor |
| PBW convention | $\kappa < [\text{odd}] < [\text{even}]$ | $\kappa < [\text{odd}] < [\text{even}]$ | Fully preserved |
| File naming | `B_{n}_structure.json` | `C_{n}_structure.json` | Fully parallel convention |
