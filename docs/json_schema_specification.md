# JSON Schema Specification for $C(n+1) = \mathfrak{osp}(2|2n)$

This document provides the complete, standalone v5.0 JSON schema specification for $C(n+1) = \mathfrak{osp}(2|2n)$ (Schema 1: Algebra Structure) and defines the conventions for all four schema layers.

---

## 1. Overview of the 4-Layer Schema Architecture

The data representation for $C(n+1) = \mathfrak{osp}(2|2n)$ is organized into 4 layers:

| Layer | File Pattern | Purpose |
|---|---|---|
| Schema 1 | `C_{n}_structure.json` | Underlying Lie superalgebra structure: basis, parities, oscillator realizations, structure constants |
| Schema 2 | `C_{n}_gamma.json` | Symbolic inhomogeneous deformation ($\gamma$-structure parametrized by the $gb$ matrix) |
| Schema 3 | `C_{n}_evaluated.json` | Evaluated structure constants under concrete $gb$ parameter assignments |
| Schema 4 | `C_{n}_coboundary.json` | Coboundary reference structure $\delta f$ generated by odd linear maps $f: \mathfrak{g} \to \mathfrak{g}$ |

Here, $n$ refers to the **bosonic rank** ($n=1$ for $C(2)=\mathfrak{osp}(2|2)$, $n=2$ for $C(3)=\mathfrak{osp}(2|4)$, $n=3$ for $C(4)=\mathfrak{osp}(2|6)$).

---

## 2. Schema 1: Top-Level Structure

A valid Schema 1 JSON file contains the following top-level keys:

```json
{
  "schema_version": "5.0",
  "algebra": { ... },
  "central_elements": { ... },
  "oscillator_generators": { ... },
  "oscillator_relations": { ... },
  "basis": { ... },
  "parity": { ... },
  "generator_realization": { ... },
  "structure_constants": [ ... ],
  "metadata": { ... }
}
```

## 3. Detailed Field Specifications

### 3.1 `schema_version`
String indicating schema version: `"5.0"`.

### 3.2 `algebra`
Specifies algebraic classification, ranks, and dimension formulas:
```json
{
  "family": "C",
  "m": 1,
  "n": 1,
  "cartan_type": "C(2)",
  "alternative_notation": {
    "osp": "osp(2|2)",
    "dimension_formula": "osp(2m|2n) with m=1, even = 2n^2 + n + 1, odd = 4n, total = 2n^2 + 5n + 1"
  },
  "dimension": {
    "total": 8,
    "even": 4,
    "odd": 4
  }
}
```

### 3.3 `central_elements` (Mandatory Top-Level Key)
Defines central elements governing the algebraic setting and deformations:
```json
{
  "kappa": {
    "label": "kappa",
    "parity": 1,
    "nilpotent_order": 2,
    "description": "Odd central element parametrizing inhomogeneous deformations (kappa^2 = 0)"
  },
  "K": {
    "label": "K",
    "parity": 0,
    "value": 1,
    "description": "Even central identity element from oscillator canonical relations"
  }
}
```

### 3.4 `oscillator_generators`
Divided into `"fermions"` (standard CAR pair, $m=1$) and `"bosons"` ($n$ pairs):
```json
{
  "fermions": {
    "m": 1,
    "labels": ["a_1_p", "a_1_m"],
    "parity": 1,
    "description": "Standard fermionic oscillator pair a_1^± satisfying CAR"
  },
  "bosons": {
    "count": 2,
    "n": 1,
    "labels": ["b_1_p", "b_1_m"],
    "parity": 0,
    "description": "Bosonic oscillators b_k^± with k=1,...,n"
  }
}
```

### 3.5 `oscillator_relations`
Defines algebraic relations satisfied by the oscillators:
```json
{
  "standard_fermion_anticommutators": {
    "description": "Canonical anticommutation relations (CAR) for fermions",
    "relations": {
      "conjugate_pair": "{a_1^-, a_1^+} = a_1^- a_1^+ + a_1^+ a_1^- = 1",
      "nilpotency": "(a_1^+)^2 = 0, (a_1^-)^2 = 0"
    }
  },
  "bosonic_commutators": {
    "description": "Canonical commutation relations (CCR) for bosons",
    "relations": {
      "same_type": "[b_j^±, b_k^±] = 0",
      "conjugate_pair": "[b_j^-, b_k^+] = δ_{jk}"
    }
  },
  "mixed_commutators": {
    "boson_fermion": "[b_j^±, a_1^±] = 0 (undeformed)"
  }
}
```

### 3.6 `basis`
Contains ordered lists of basis generators and ordering documentation:
```json
{
  "even": [
    "H_1", "H_2",
    "E_2del1_p", "E_2del1_m"
  ],
  "odd": [
    "E_eps1_del1_pp", "E_eps1_del1_pm", "E_eps1_del1_mp", "E_eps1_del1_mm"
  ],
  "ordering_convention": "PBW: kappa < [odd: E_eps1_del{k}_pp/pm/mp/mm] < [even: H_k, E_2del{k}_p/m, E_del{i}_del{j}_pp/mm/pm/mp]"
}
```

### 3.7 `parity`
Mapping from generator name to its $\mathbb{Z}_2$-parity ($0$ for even, $1$ for odd):
```json
{
  "H_1": 0, "H_2": 0,
  "E_2del1_p": 0, "E_2del1_m": 0,
  "E_eps1_del1_pp": 1, "E_eps1_del1_pm": 1,
  "E_eps1_del1_mp": 1, "E_eps1_del1_mm": 1
}
```

### 3.8 `generator_realization`
Defines each generator as a sum of normal-ordered oscillator words with exact rational coefficients:
```json
{
  "description": "Normal ordered form: fermions then bosons",
  "ordering": "a_1_p, a_1_m, b_1_p, b_1_m, ...",
  "realizations": {
    "H_1": {
      "standard_form": [
        {"words": ["a_1_p", "a_1_m"], "coeff": "1"},
        {"words": ["b_1_p", "b_1_m"], "coeff": "1"}
      ],
      "frappat_form": "a_1^+ a_1^- + b_1^+ b_1^-",
      "parity": 0
    },
    "H_2": {
      "standard_form": [
        {"words": ["b_1_p", "b_1_m"], "coeff": "-1"},
        {"words": [], "coeff": "-1/2"}
      ],
      "frappat_form": "-b_1^+ b_1^- - 1/2",
      "parity": 0
    },
    "E_eps1_del1_pp": {
      "standard_form": [
        {"words": ["a_1_p", "b_1_p"], "coeff": "1"}
      ],
      "frappat_form": "a_1^+ b_1^+",
      "parity": 1
    }
  }
}
```

### 3.9 `structure_constants`
List of all non-zero graded Lie superalgebra brackets $[X, Y\}$:
```json
[
  {
    "X": "H_1",
    "Y": "E_eps1_del1_pp",
    "Z": "E_eps1_del1_pp",
    "coeff": "2",
    "sign_rule": "graded"
  }
]
```

### 3.10 `metadata`
Metadata regarding generation provenance:
```json
{
  "generated_by": "src/C_generators.py",
  "generation_date": "YYYY-MM-DD",
  "references": [
    "Frappat et al. (2000), Dictionary on Lie Algebras and Superalgebras",
    "Bakalov and Sullivan (2017)"
  ]
}
```

## 4. Compatibility with $B(0,n)$ Specification

| Aspect | $B(0,n)$ Convention | $C(n+1)$ Convention | Rationale |
|---|---|---|---|
| Fermionic Oscillator | `supplementary_fermion` ($a_0, a_0^2=1/2$) | `fermions` ($a_1^\pm$, $\{a_1^-, a_1^+\}=1$) | $C(n+1)$ possesses true fermionic rank $m=1$ with CAR pair |
| Central Elements | Embedded note / implicit | Explicit top-level key `central_elements` | Standardizes representation of $\kappa$ and $K$ |
| Odd Root Labels | `E_del{k}_p/m` | `E_eps1_del{k}_pp/pm/mp/mm` | Reflects $\pm\varepsilon \pm \delta_k$ root vectors |
| Even Dimension | $2n^2 + n$ | $2n^2 + n + 1$ | Extra $\mathfrak{so}(2)$ Cartan element from fermionic sector |
| File Naming | `B_{n}_structure.json` | `C_{n}_structure.json` | $n$ uniformly indexes bosonic rank |
