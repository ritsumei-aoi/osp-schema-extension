# C(n+1) v5.0 JSON Schema Specification

This document specifies the v5.0 JSON schema for $C(n+1) = \mathfrak{osp}(2|2n)$ Lie superalgebra structure constants, extending the $B(0,n) = \mathfrak{osp}(1|2n)$ base schema.

---

## 1. Overview and Architecture

The schema maintains the 4-layer architecture of the reference system:
- **Layer 1 (Schema 1)**: `C_{n}_structure.json` — Undeformed algebra structure, oscillator realizations, basis, parity, and structure constants.
- **Layer 2 (Schema 2)**: `C_{n}_gamma.json` — Inhomogeneous deformation ($\gamma$-structure and symbolic gb parameters).
- **Layer 3 (Schema 3)**: `C_{n}_evaluated_<profile>.json` — Evaluated deformation constants with numerical parameter assignments.
- **Layer 4 (Schema 4)**: `C_{n}_coboundary.json` — Coboundary operator $\delta f$ generated by an odd linear map $f: \mathfrak{g} \to \mathfrak{g}$.

### File Naming Convention
Files are indexed by the bosonic rank $n$:
- $n = 1$: $C(2) = \mathfrak{osp}(2|2) \longrightarrow$ `C_1_structure.json`
- $n = 2$: $C(3) = \mathfrak{osp}(2|4) \longrightarrow$ `C_2_structure.json`
- $n = 3$: $C(4) = \mathfrak{osp}(2|6) \longrightarrow$ `C_3_structure.json`

## 2. Schema 1 (Algebra Structure) Specification

### Top-Level Keys
```json
{
  "schema_version": "5.0",
  "algebra": { ... },
  "central_elements": { ... },
  "oscillator_generators": { ... },
  "oscillator_relations": { ... },
  "basis": { ... },
  "parity": { ... },
  "generator_realization": { ... },
  "structure_constants": [ ... ],
  "metadata": { ... }
}
```

### Detailed Field Definitions

#### `schema_version`
- Type: `string`
- Value: `"5.0"`

#### `algebra`
- `family`: `"C"`
- `m`: `1` (fermionic pair rank)
- `n`: `<integer>` (bosonic rank, $n \ge 1$)
- `cartan_type`: `"C({n+1})"`
- `alternative_notation`:
  - `osp`: `"osp(2|2n)"`
  - `dimension_formula`: `"osp(2m|2n) with m=1, even = 2n^2 + n + 1, odd = 4n"`
- `dimension`:
  - `total`: $2n^2 + 5n + 1$
  - `even`: $2n^2 + n + 1$
  - `odd`: $4n$

#### `central_elements` (Top-level key)
Defines central elements governing the algebra and its deformations:
- `kappa`:
  - `label`: `"kappa"`
  - `parity`: `1`
  - `nilpotency`: `"kappa^2 = 0"`
  - `description`: `"Formal odd central element parametrizing inhomogeneous deformation"`
- `K`:
  - `label`: `"K"`
  - `parity`: `0`
  - `value`: `1`
  - `description`: `"Even central identity element (identified with scalar 1)"`

#### `oscillator_generators`
Separated into standard CAR fermions and CCR bosons:
- `fermions`:
  - `count`: `2`
  - `m`: `1`
  - `labels`: `["a_1_p", "a_1_m"]`
  - `description`: `"Standard fermionic pair satisfying CAR: {a_1^-, a_1^+} = 1, (a_1^+)^2 = (a_1^-)^2 = 0"`
- `bosons`:
  - `count`: $2n$
  - `n`: $n$
  - `labels`: `["b_1_p", "b_1_m", ..., "b_n_p", "b_n_m"]`
  - `description`: `"Bosonic oscillators b_k^± with k=1,...,n satisfying CCR: [b_i^-, b_j^+] = δ_{ij}"`

#### `oscillator_relations`
- `standard_fermion_anticommutators`:
  - `description`: `"Canonical anticommutation relations (CAR) for standard fermionic pair"`
  - `relations`:
    - `conjugate_pair`: `"{a_1^-, a_1^+} = 1"`
    - `nilpotency`: `"(a_1^+)^2 = 0, (a_1^-)^2 = 0"`
- `bosonic_commutators`:
  - `description`: `"Canonical commutation relations (CCR) for bosonic oscillators"`
  - `relations`:
    - `same_type`: `"[b_i^±, b_j^±] = 0 for all i, j"`
    - `conjugate_pair`: `"[b_i^-, b_j^+] = δ_{ij}"`
- `mixed_commutators`:
  - `boson_fermion`: `"[b_i^±, a_1^±] = 0 (undeformed; deformed by -gb * kappa in Schema 2)"`

#### `basis`
- `even`: List of even generator names (dimension $2n^2 + n + 1$).
  1. Cartan: `H_1, ..., H_{n+1}`
  2. Positive long roots: `E_2del1_p, ..., E_2del{n}_p`
  3. Positive short roots: `E_del{i}_del{j}_pp` ($1 \le i < j \le n$)
  4. Negative long roots: `E_2del1_m, ..., E_2del{n}_m`
  5. Negative short roots: `E_del{i}_del{j}_mm` ($1 \le i < j \le n$)
  6. Mixed short roots: `E_del{i}_del{j}_pm, E_del{i}_del{j}_mp` ($1 \le i < j \le n$)
- `odd`: List of odd generator names (dimension $4n$).
  - For $k = 1, \dots, n$: `E_eps1_del{k}_pp`, `E_eps1_del{k}_pm`, `E_eps1_del{k}_mp`, `E_eps1_del{k}_mm`
- `ordering_convention`: `"PBW: kappa < [odd: E_eps1_del{k}_pp/pm/mp/mm] < [even: H_k, E_2del{k}_p/m, E_del{i}_del{j}_pp/mm/pm/mp] (K = 1 is excluded)"`

#### `parity`
Dictionary mapping generator names to `0` (even) or `1` (odd).

#### `generator_realization`
- `description`: `"Standard form with PBW ordering"`
- `ordering`: `"a_1_p, a_1_m, b_1_p, b_1_m, ..."`
- `realizations`: Dictionary mapping generator name to:
  - `standard_form`: list of terms `{"words": [...], "coeff": "..."}`
  - `frappat_form`: LaTeX / ASCII string representation
  - `parity`: `0` or `1`
  - (optional) `note`: explanatory string

#### `structure_constants`
List of non-zero graded Lie brackets $[X, Y\}$:
```json
{
  "X": "H_1",
  "Y": "E_eps1_del1_pp",
  "Z": "E_eps1_del1_pp",
  "coeff": "1",
  "sign_rule": "graded"
}
```
Where $[X, Y\} = \sum_Z c_{XY}^Z Z$.
Sign rule follows graded skew-symmetry:
$$[Y, X\} = -(-1)^{p(X)p(Y)} [X, Y\}.$$

#### `metadata`
- `generated_by`: `"src/C_generators.py"`
- `generation_date`: `"2026-10-04"`
- `references`: List of literature and document references.

## 3. Backward Compatibility and Comparison with B(0,n) Schema

| Field / Feature | $B(0,n) = \mathfrak{osp}(1|2n)$ (v5.0) | $C(n+1) = \mathfrak{osp}(2|2n)$ (v5.0 Extension) | Compatibility Strategy |
|---|---|---|---|
| `algebra.family` | `"B"` | `"C"` | Distinguishes family |
| `algebra.m` | `0` | `1` | Parameterizes fermionic rank |
| `algebra.dimension` | even: $2n^2+n$, odd: $2n$ | even: $2n^2+n+1$, odd: $4n$ | Same schema structure |
| `central_elements` | Inside text / implicit | Explicit top-level key (`kappa`, `K`) | Harmonizes with deformation specs |
| `oscillator_generators` | `supplementary_fermion` ($a_0$) | `fermions` ($a_1^+, a_1^-$) | Clean separation of CAR pair |
| `oscillator_relations` | $a_0^2 = 1/2$ | $\{a_1^-, a_1^+\} = 1$, $(a_1^\pm)^2 = 0$ | Standard CAR |
| `basis.odd` | `E_del{k}_{p,m}` ($2n$) | `E_eps1_del{k}_{pp,pm,mp,mm}` ($4n$) | Extends index with $\varepsilon$ sign |
| `basis.even` | $n$ Cartan elements $H_1, \dots, H_n$ | $n+1$ Cartan elements $H_1, \dots, H_{n+1}$ | Incorporates $\mathfrak{so}(2)$ sector |
