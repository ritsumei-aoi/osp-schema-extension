# C(n+1) v5.0 JSON Schema Specification

This document specifies the complete JSON schema structure for $C(n+1) = \mathfrak{osp}(2|2n)$ across all four computational layers, providing a fully compatible extension of the $B(0,n)$ v5.0 schema.

---

## 1. 4-Layer Architecture and File Naming

The data for $C(n+1)$ is organized into 4 layers of computational depth:

| Layer | File Pattern | Description |
|---|---|---|
| **Layer 1: Algebra Structure** | `data/C_{n}_structure.json` | Basis, parity, oscillator realization, structure constants $[X, Y\}$ |
| **Layer 2: Gamma Structure** | `data/C_{n}_gamma.json` | Symbolic inhomogeneous deformation 2-cocycle $\gamma(X, Y)$ parameterized by $gb$ matrix |
| **Layer 3: Evaluated Structure** | `data/C_{n}_evaluated.json` | Structure constants evaluated under concrete numerical/sign assignments of $gb$ |
| **Layer 4: Coboundary Structure** | `data/C_{n}_coboundary.json` | Coboundary reference data $(\delta f)(X, Y)$ generated by odd linear maps $f: \mathfrak{g} \to \mathfrak{g}$ |

*Note*: The parameter $n$ indexing the filenames is the **bosonic rank** ($n \ge 1$):
- $n = 1 \implies C(2) = \mathfrak{osp}(2|2)$ (total dim 8)
- $n = 2 \implies C(3) = \mathfrak{osp}(2|4)$ (total dim 19)
- $n = 3 \implies C(4) = \mathfrak{osp}(2|6)$ (total dim 34)

## 2. Layer 1: Algebra Structure Schema (`C_{n}_structure.json`)

### Top-Level JSON Keys
1. `schema_version`: String (`"5.0"`)
2. `algebra`: Algebra metadata, Cartan type, family, and dimensions
3. `oscillator_generators`: Fermionic and bosonic oscillator labels and counts
4. `oscillator_relations`: Anticommutators (CAR), commutators (CCR), and mixed commutators
5. `central_elements`: Top-level specification of $\kappa$ and $K$
6. `basis`: Even and odd ordered basis lists
7. `parity`: Map from generator labels to $\{0, 1\}$
8. `generator_realization`: Oscillator word expansion and Frappat form for each generator
9. `structure_constants`: Non-zero graded Lie superalgebra brackets
10. `metadata`: Generator script info, timestamps, and mathematical literature references

## 3. Comparison and Compatibility with $B(m,n)$ / $B(0,n)$

| Field / Feature | $B(0,n)$ Specification | $C(n+1)$ Specification | Compatibility Strategy |
|---|---|---|---|
| **Algebra Family** | `"B"` ($m=0$) | `"C"` ($m=1$) | Unified `family` and `m`, `n` integer parameters |
| **Even Subalgebra** | $\mathfrak{sp}(2n)$ | $\mathfrak{so}(2) \times \mathfrak{sp}(2n)$ | Extra Cartan element $H_1$, even dim increased by 1 |
| **Fermion Key** | `supplementary_fermion` (`a_0`, $a_0^2 = 1/2$) | `fermions` (`a_1_p`, `a_1_m`, CAR) | Distinguishes supplementary vs CAR fermions |
| **Odd Generators** | $E_{\pm\delta_k}$ ($2n$ generators) | $E_{\pm\varepsilon \pm \delta_k}$ ($4n$ generators) | Explicit root notation `E_eps1_del{k}_{pp/pm/mp/mm}` |
| **Deformation parameters** | $2n$ parameters $\mathrm{gb}_{a_0, b_j^\pm}$ | $4n$ parameters $\mathrm{gb}_{\sigma, j, s}$ | Generalized $gb$ matrix representation |
| **Central Elements** | `central_elements` key | `central_elements` top-level key | Top-level object with $\kappa$ (odd) and $K$ (even) |
