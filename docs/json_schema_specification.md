# v5.0 JSON Schema Specification for C(n+1) = osp(2|2n)

This document specifies the v5.0 JSON schema extension for $C(n+1) = \mathfrak{osp}(2|2n)$ structure constants, inhomogeneous deformations (Layer 2), evaluated structures (Layer 3), and coboundary operators (Layer 4).

## 1. Overview & File Naming Conventions

The JSON data architecture consists of 4 computational layers:

| Layer | File Pattern | Description |
|---|---|---|
| Layer 1 | `C_{n}_structure.json` | Core algebra structure constants, basis, oscillator realizations |
| Layer 2 | `C_{n}_gamma.json` | Inhomogeneous deformation coefficients $\gamma_{abc}$ |
| Layer 3 | `C_{n}_evaluated.json` | Evaluated structure constants under concrete $gb$ parameter assignments |
| Layer 4 | `C_{n}_coboundary.json` | Coboundary coefficients $(\delta f)_{abc}$ generated by an odd linear map $f$ |

Here $n$ denotes the **bosonic rank** ($n=1, 2, 3$ corresponds to $C(2), C(3), C(4)$).

## 3. Schema Compatibility: B(0,n) vs C(n+1)

| Field / Feature | B(0,n) Schema v5.0 | C(n+1) Schema v5.0 |
|---|---|---|
| `algebra.family` | `"B"` | `"C"` |
| `algebra.m` | `0` | `1` |
| `algebra.dimension` | even: $2n^2+n$, odd: $2n$ | even: $2n^2+n+1$, odd: $4n$ |
| Fermionic Sector | `supplementary_fermion` ($a_0^2 = 1/2$) | `fermions` ($a_1^+, a_1^-$ with $\{a_1^-, a_1^+\}=1$) |
| Central Elements | `central_elements` top-level key ($\kappa, K$) | `central_elements` top-level key ($\kappa, K$) |
| File Naming | `B_{n}_structure.json` | `C_{n}_structure.json` |
