# JSON Schema Specification for Lie Superalgebras (v5.0 Extension for C(n+1))

This document defines the official v5.0 JSON schema specification for $C(n+1) = \mathfrak{osp}(2|2n)$, extended from the $B(0,n) = \mathfrak{osp}(1|2n)$ base specification.

---

## 1. Overview & Architecture

The schema maintains a 4-layer architecture representing increasing computational depth:

| Layer | File Naming Pattern | Description |
|---|---|---|
| Layer 1: Algebra Structure | `C_{n}_structure.json` | Superalgebra basis, parity grading, oscillator realizations, and structure constants. |
| Layer 2: Gamma Structure | `C_{n}_gamma.json` | Symbolic inhomogeneous deformation ($\gamma$-structure) and $gb$-matrix parameterization. |
| Layer 3: Evaluated Structure | `C_{n}_evaluated.json` | Structure constants evaluated under specific assignments of deformation parameters $gb$. |
| Layer 4: Coboundary Structure | `C_{n}_coboundary.json` | Coboundary operator $\delta f$ generated by odd linear maps for triviality verification. |

Here, $n$ denotes the **bosonic rank** ($n=1$ for $C(2)$, $n=2$ for $C(3)$, $n=3$ for $C(4)$).

---

## 2. Schema 1 Specification: Algebra Structure (`C_{n}_structure.json`)

### 2.1 Top-Level Keys

```json
{
  "schema_version": "5.0",
  "algebra": { ... },
  "central_elements": { ... },
  "oscillator_generators": { ... },
  "oscillator_relations": { ... },
  "basis": { ... },
  "parity": { ... },
  "generator_realization": { ... },
  "structure_constants": [ ... ],
  "metadata": { ... }
}
```

### 2.2 `algebra` Object
Specifies the classification, rank parameters, and superdimension of the Lie superalgebra.

```json
{
  "family": "C",
  "m": 1,
  "n": 1,
  "cartan_type": "C(2)",
  "alternative_notation": {
    "osp": "osp(2|2)",
    "dimension_formula": "osp(2m|2n) with m=1: even = 2n^2 + n + 1, odd = 4n, total = 2n^2 + 5n + 1"
  },
  "dimension": {
    "total": 8,
    "even": 4,
    "odd": 4
  }
}
```

- `family`: `"C"`
- `m`: `1` (fermionic rank)
- `n`: bosonic rank ($1, 2, 3, \ldots$)
- `cartan_type`: `"C({n+1})"`
- `dimension`: Formulas: even $= 2n^2 + n + 1$, odd $= 4n$, total $= 2n^2 + 5n + 1$.

### 2.3 `central_elements` Object (Top-Level Key)
Defines central elements involved in the algebraic construction and deformation.

```json
{
  "kappa": {
    "label": "kappa",
    "parity": 1,
    "relation": "kappa^2 = 0",
    "description": "Nilpotent odd central element parameterizing the inhomogeneous deformation"
  },
  "K": {
    "label": "K",
    "parity": 0,
    "relation": "K = 1",
    "description": "Even central identity element from pre-oscillator bilinear form"
  }
}
```

### 2.4 `oscillator_generators` Object
Defines the fermionic and bosonic oscillator generators. Replaces $B(0,n)$'s `supplementary_fermion` with standard fermionic CAR pairs.

```json
{
  "fermions": {
    "count": 2,
    "m": 1,
    "labels": ["a_1_p", "a_1_m"],
    "description": "Standard fermionic CAR pair a_1^± with parity 1"
  },
  "bosons": {
    "count": 2,
    "n": 1,
    "labels": ["b_1_p", "b_1_m"],
    "description": "Bosonic CCR oscillators b_k^± with k=1,...,n"
  }
}
```

### 2.5 `oscillator_relations` Object
Defines the algebraic relations obeyed by the oscillators.

```json
{
  "standard_fermion_anticommutators": {
    "description": "Canonical anticommutation relations (CAR) for standard fermionic pair",
    "relations": {
      "same_type": "{a_1^±, a_1^±} = 0",
      "conjugate_pair": "{a_1^-, a_1^+} = 1"
    }
  },
  "bosonic_commutators": {
    "description": "Canonical commutation relations (CCR) for bosonic oscillators",
    "relations": {
      "same_type": "[b_i^±, b_j^±] = 0 for all i, j",
      "conjugate_pair": "[b_i^-, b_j^+] = δ_{ij}"
    }
  },
  "mixed_commutators": {
    "description": "Undeformed mixed commutators between bosons and fermions",
    "boson_fermion": "[b_i^±, a_1^±] = 0"
  }
}
```

### 2.6 `basis` and `parity` Objects
Specifies basis generator labels and their $\mathbb{Z}_2$ grading (0 = even, 1 = odd).

```json
{
  "basis": {
    "even": ["H_1", "H_2", "E_2del1_p", "E_2del1_m"],
    "odd": ["E_eps1_del1_pp", "E_eps1_del1_pm", "E_eps1_del1_mp", "E_eps1_del1_mm"],
    "ordering_convention": "PBW: κ < [odd] < [even]"
  },
  "parity": {
    "H_1": 0, "H_2": 0, "E_2del1_p": 0, "E_2del1_m": 0,
    "E_eps1_del1_pp": 1, "E_eps1_del1_pm": 1, "E_eps1_del1_mp": 1, "E_eps1_del1_mm": 1
  }
}
```

### 2.7 `generator_realization` Object
Maps each Lie superalgebra generator to normal-ordered oscillator words with rational coefficients.

```json
{
  "description": "Standard form with PBW ordering",
  "ordering": "a_1_p, a_1_m, b_1_p, b_1_m",
  "realizations": {
    "H_1": {
      "standard_form": [
        {"words": ["a_1_p", "a_1_m"], "coeff": "1"},
        {"words": ["b_1_p", "b_1_m"], "coeff": "1"}
      ],
      "frappat_form": "a_1^+ a_1^- + b_1^+ b_1^-",
      "parity": 0
    },
    "H_2": {
      "standard_form": [
        {"words": ["b_1_p", "b_1_m"], "coeff": "-1"},
        {"words": [], "coeff": "-1/2"}
      ],
      "frappat_form": "-b_1^+ b_1^- - 1/2",
      "parity": 0
    },
    "E_eps1_del1_pp": {
      "standard_form": [
        {"words": ["a_1_p", "b_1_p"], "coeff": "1"}
      ],
      "frappat_form": "a_1^+ b_1^+",
      "parity": 1
    }
  }
}
```

### 2.8 `structure_constants` Array
List of non-zero Lie superalgebra brackets $[X, Y\} = \sum_Z C_{XY}^Z Z$:

```json
[
  {
    "X": "H_1",
    "Y": "E_eps1_del1_pp",
    "Z": "E_eps1_del1_pp",
    "coeff": "2",
    "sign_rule": "graded"
  }
]
```

## 3. Backward Compatibility & Differences from $B(0,n)$

| Key | $B(0,n)$ Schema | $C(n+1)$ Schema |
|---|---|---|
| `algebra.family` | `"B"` | `"C"` |
| `algebra.m` | `0` | `1` |
| `algebra.dimension` | even $= 2n^2+n$, odd $= 2n$ | even $= 2n^2+n+1$, odd $= 4n$ |
| Fermionic oscillators | `supplementary_fermion` (`a_0`, $a_0^2 = 1/2$) | `fermions` (`a_1_p, a_1_m`, $\{a_1^-, a_1^+\}=1$) |
| `central_elements` | Embedded or implicit | Top-level explicit key (`kappa`, `K`) |
| Odd generators | `E_del{k}_p`, `E_del{k}_m` ($2n$) | `E_eps1_del{k}_pp`, `pm`, `mp`, `mm` ($4n$) |
| Cartan generators | $H_1, \ldots, H_n$ ($n$) | $H_1, \ldots, H_{n+1}$ ($n+1$) |
