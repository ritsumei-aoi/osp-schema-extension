**Design**
- `gb_matrix`: 2 × 2n, rows `a_1_p, a_1_m`, columns `b_j_p, b_j_m`; 4n parameters `gb_a_1_{σ}_b_{j}_{s}`, defined by `[b_j^s, a_1^σ] = b a − a b = −gb κ` (implemented in `src/oscalg.py`; κ odd central, so κa = −aκ, κb = bκ, κ² = 0).
- γ is computed *from the oscillator algebra* (`src/gamma.py`): the graded commutator of the realizations in the deformed algebra is normal-ordered and decomposed in the basis of L = g ⊕ κg: `[X,Y} = [X,Y]_0 + κ γ(X,Y)`. γ is linear in gb (κ² = 0), so it is computed per unit parameter and stored as linear forms in gb.
- Files: `data/C_{1,2,3}_gamma.json` (92 / 568 / 1660 non-zero (X,Y,Z) entries, each carrying a linear form in gb; spec appended to `docs/json_schema_specification.md`).

**Decision (ambiguity) — realization of odd generators in the deformed algebra**
`a_σ b_τ` and `b_τ a_σ` differ by κ once gb ≠ 0. Options:
1. keep the normal-ordered product `a b` as the generator;
2. use the Weyl-symmetrised `(ab + ba)/2 = ab − ½ gb κ`.
Experiment with option 1 (n=1, all four unit gb): the κ-part of many brackets has a component along the constant (κ·K), e.g. for gb_{a⁺,b⁺}=1, `[E_{ε+δ}, H_2]` has κ-part `2H_2 + b⁺b⁻`, and `b⁺b⁻` alone is not in the span of g (the Cartan span only contains b⁺b⁻ + ½), i.e. γ ∉ g. This contradicts `C_inhomogeneous_definition.md` (γ: g⊗g → g). Option 2 gives γ ∈ g for all pairs (no residual in the exact decomposition) and is the canonical choice (symmetrised quadratics form the Lie algebra on a skew-supersymmetric form). **Chose option 2.** Effect: for gb = 0 nothing changes (Schema 1 unaffected).
