**Design / decisions**
- `src/oscalg.py`: exact (Fraction) normal-ordering engine for the Weyl–Clifford algebra with letters κ < a_1_p < a_1_m < b_1_p < b_1_m < ... (PBW word order of `notation.md`). Rewriting rules: a⁻a⁺ = 1 − a⁺a⁻, b⁻b⁺ = b⁺b⁻ + 1, odd–odd swaps carry −1, a² = κ² = 0. It also supports the deformed relation `[b,a] = −gb·κ` (used from I05).
  Option considered: matrix representation of the oscillators (infinite-dimensional boson, truncation errors) — rejected; symbolic rewriting is exact.
- `src/C_generators.py`: basis lists, realizations (Weyl-ordered quadratics), bracket by graded commutator `XY − (−1)^{pXpY}YX`, decomposition into the basis by exact elimination (`make_decomposer`). The bracket is *derived*, not hand-typed; closure on the basis with zero residual (no leftover constant) is asserted for every pair — this confirms the symmetric-ordering constants in H_1, H_k, H_{n+1}.
- Structure constants are written for all ordered pairs (see I02).
- Hand checks (n=1): {a⁺b⁺, a⁻b⁻} = N_b + 1 − N_a = −H_1 − 2H_2; [E_{2δ}, E_{−2δ}] = 4H_2 (= −4(N+½)); [H_1, E_ε+δ] = 2E; [H_2, E_{2δ}] = −2E_{2δ}. All match the program.
