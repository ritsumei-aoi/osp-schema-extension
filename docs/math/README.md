# Mathematical Reference for the Triviality Challenge

This directory contains the essential mathematical definitions required to analyze the triviality of inhomogeneous deformations for C(n+1).

## Files
- `Cn1_definition.md`: Definition of the C(n+1) root system and algebra structure.
- `C_inhomogeneous_definition.md`: Definition of the inhomogeneous (gb) deformation.
- `C_coboundary_definition.md`: Definition of the coboundary operator and triviality condition.

## Goal
Use these documents to rigorously determine whether the deformation is trivial for any non-zero gb parameters.
