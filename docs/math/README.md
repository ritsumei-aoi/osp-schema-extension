# Mathematical Reference for the Prospective Case Study

This directory contains self-contained mathematical reference documents for the prospective case study on C(n+1) = osp(2|2n) schema extension.

## Files

| File | Contents |
|---|---|
| `B0n_definition.md` | Algebraic structure and deformation parameters for B(0,n) = osp(1\|2n) |
| `B0n_schema_v5.md` | The v5.0 JSON schema specification for B(0,n) (base schema) |
| `Cn1_definition.md` | Root system and oscillator realization for C(n+1) = osp(2\|2n) |
| `C_inhomogeneous_definition.md` | Mathematical definition of the inhomogeneous deformation for C(n+1) |
| `C_coboundary_definition.md` | **NEW**: Mathematical definition of the coboundary structure and linear map f |

## How to Use

1. Read `B0n_definition.md` and `Cn1_definition.md` to understand the transition from B to C.
2. Read `C_inhomogeneous_definition.md` for Layer 2/3 parameters.
3. Read `C_coboundary_definition.md` to understand how to construct the reference Layer 4 for triviality checks.
