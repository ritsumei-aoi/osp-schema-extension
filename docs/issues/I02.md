## Context & Background
The existing Schema 1 (algebra structure) was designed for B(m,n). Extending to
C(n+1) requires modifications to several fields while maintaining backward
compatibility. Issue I01 has finalized the basis and PBW ordering.

## Requirements
1. Design `algebra` field for C(n+1) (family="C").
2. Design `oscillator_generators` without supplementary fermion.
3. Design `oscillator_relations` for standard fermionic pair (CAR).
4. Determine `central_elements` (kappa, K) for C(n+1).
5. Define file naming conventions (e.g., `C_1_structure.json`, `C_2_structure.json`, `C_3_structure.json`).

### Mandatory unified rules (fixed for all runs)
- **Algebra Field**: explicitly include `"m": 1` and the dimension formulas `even`: `2n^2 + n + 1`, `odd`: `4n`.
- **Oscillator Generators**: two keys, `"fermions"` (with `m=1`, labels `a_1_p, a_1_m`) and `"bosons"` (with rank `n`).
- **Central Elements**: `central_elements` is a **top-level key**, containing `kappa` (parity 1) and `K` (parity 0).
- **File Naming**: `C_{n}_structure.json`, where `n` is the bosonic rank (e.g., C(2) uses `n=1`).

#### Decisions Made

**1. `algebra` field**: family="C", m=1, n=bosonic rank. Dimension formulas: even=2n²+n+1, odd=4n. Applied for C(2)/C(3)/C(4).

**2. `oscillator_generators`**: Replaced `supplementary_fermion` with `fermions` key containing labels `a_1_p`, `a_1_m` (m=1). Bosons unchanged.

**3. `oscillator_relations`**: Added `standard_fermion_anticommutators` with {a_1^-, a_1^+}=1. Mixed commutator is zero in the undeformed algebra (becomes -gb·κ in Schema 2).

**4. `central_elements`**: Top-level key with kappa (parity 1, nilpotent) and K (parity 0, identified with scalar 1, excluded from basis).

**5. File naming**: `C_{n}_structure.json` where n = bosonic rank (C(2) → n=1, C(3) → n=2, C(4) → n=3).

**6. Schema document created**: `docs/json_schema_specification.md` with complete field definitions and compatibility table.

#### Compatibility Notes
- PBW ordering unchanged (κ < [odd] < [even]).
- B(0,n) `supplementary_fermion` → C(n+1) `fermions` (key name change).
- Odd generator labels change from `E_del{k}_p/m` to `E_eps1_del{k}_pp/pm/mp/mm`.
- Structure constants and generator realizations updated to use `a_1_p`/`a_1_m`.
