## Context & Background
The existing Schema 1 (algebra structure) was designed for B(m,n). Extending to
C(n+1) requires modifications to several fields while maintaining backward
compatibility. Issue I01 has finalized the basis and PBW ordering.

## Requirements
1. Design `algebra` field for C(n+1) (family="C").
2. Design `oscillator_generators` without supplementary fermion.
3. Design `oscillator_relations` for standard fermionic pair (CAR).
4. Determine `central_elements` (kappa, K) for C(n+1).
5. Define file naming conventions (e.g., `C_1_structure.json`, `C_2_structure.json`, `C_3_structure.json`).

### Mandatory unified rules (fixed for all runs)
- **Algebra Field**: explicitly include `"m": 1` and the dimension formulas `even`: `2n^2 + n + 1`, `odd`: `4n`.
- **Oscillator Generators**: two keys, `"fermions"` (with `m=1`, labels `a_1_p, a_1_m`) and `"bosons"` (with rank `n`).
- **Central Elements**: `central_elements` is a **top-level key**, containing `kappa` (parity 1) and `K` (parity 0).
- **File Naming**: `C_{n}_structure.json`, where `n` is the bosonic rank (e.g., C(2) uses `n=1`).

### Response

**Deliverable**: `docs/json_schema_specification.md` (Schema 1 complete; Schemas 2–4 to be appended in I05–I07).

**Decisions** (all mandatory unified rules followed)
- `algebra`: `family:"C"`, `m:1`, `dimension_formula` object (even `2n^2+n+1`, odd `4n`, total `2n^2+5n+1`), `dimension` totals 8/19/34.
- `oscillator_generators`: keys `fermions` (m=1, labels `a_1_p,a_1_m`) and `bosons` (count 2n, rank n).
- `oscillator_relations`: `standard_fermion_anticommutators` (CAR), `bosonic_commutators`, `mixed_commutators` (undeformed, `[b,a]=0`).
- `central_elements`: top-level key with `kappa` (parity 1, κ²=0) and `K` (parity 0, value 1, excluded from basis). K is identified with the scalar 1 (as in B(0,n)).
- File naming `C_{n}_structure.json`, n = bosonic rank (C(2) -> `C_1_structure.json`).
- Structure constants are stored for all ordered pairs so anti-symmetry is independently checkable in I04.

**Options considered**
- Store only X<Y pairs (smaller files) vs all ordered pairs. Chose all ordered pairs for independent verification of anti-symmetry.
- Keep `schema_version` "5.0" vs bump. Chose "5.0" for backward compatibility with B(0,n) readers; key changes are listed in the compatibility table.

**Ambiguity recorded**: `B0n_definition.md` says κ is listed with parity 0 in the JSON, while the unified rule and `C_inhomogeneous_definition.md` say p(κ)=1. Adopted p(κ)=1 (explicit mandatory rule).

**Verification**: completion criteria checked against the document sections (all Schema 1 fields, compatibility table, naming convention). The files generated in I03 are validated against this spec by unit tests.
