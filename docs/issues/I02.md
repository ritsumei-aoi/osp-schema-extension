## Context & Background
The existing Schema 1 (algebra structure) was designed for B(m,n). Extending to
C(n+1) requires modifications to several fields while maintaining backward
compatibility. Issue I01 has finalized the basis and PBW ordering.

## Requirements
1. Design `algebra` field for C(n+1) (family="C").
2. Design `oscillator_generators` without supplementary fermion.
3. Design `oscillator_relations` for standard fermionic pair (CAR).
4. Determine `central_elements` (kappa, K) for C(n+1).
5. Define file naming conventions (e.g., `C_1_structure.json`, `C_2_structure.json`, `C_3_structure.json`).

### Mandatory unified rules (fixed for all runs)
- **Algebra Field**: explicitly include `"m": 1` and the dimension formulas `even`: `2n^2 + n + 1`, `odd`: `4n`.
- **Oscillator Generators**: two keys, `"fermions"` (with `m=1`, labels `a_1_p, a_1_m`) and `"bosons"` (with rank `n`).
- **Central Elements**: `central_elements` is a **top-level key**, containing `kappa` (parity 1) and `K` (parity 0).
- **File Naming**: `C_{n}_structure.json`, where `n` is the bosonic rank (e.g., C(2) uses `n=1`).

### Response

#### 1. Schema 1 Field Design for C(n+1)
We have formalized the complete standalone Schema 1 v5.0 specification for $C(n+1) = \mathfrak{osp}(2|2n)$, adhering strictly to the mandatory unified rules:
1. **`algebra` Field**: Explicitly specifies `"family": "C"`, `"m": 1`, `"n": n`, with dimension formulas `even: 2n^2 + n + 1`, `odd: 4n`, `total: 2n^2 + 5n + 1`.
2. **`oscillator_generators` Field**: Removed the auxiliary `supplementary_fermion` key and introduced `"fermions"` (with `m=1`, labels `["a_1_p", "a_1_m"]`) alongside `"bosons"` (with rank `n` and count `2n`).
3. **`oscillator_relations` Field**: Replaced supplementary fermion relation with Canonical Anticommutation Relations (CAR) `standard_fermion_anticommutators` (`{a_1^-, a_1^+} = 1`, `(a_1^\pm)^2 = 0`), CCR for bosons, and commutation between bosons and fermions.
4. **`central_elements` Field**: Defined as a mandatory top-level key containing `kappa` (parity 1, nilpotent order 2) and `K` (parity 0, scalar identity 1).
5. **`basis` & `parity`**: Incorporates the $4n$ odd generators `E_eps1_del{k}_pp/pm/mp/mm` and $2n^2+n+1$ even generators (`H_1..H_{n+1}`, `E_2del{k}_p/m`, `E_del{i}_del{j}_...`).
6. **`generator_realization` & `structure_constants`**: Full normal-ordered polynomial expressions in $(a_1^\pm, b_k^\pm)$ and graded brackets.

#### 2. File Naming Conventions
Confirmed unified file naming across all four layers:
- Layer 1: `C_{n}_structure.json`
- Layer 2: `C_{n}_gamma.json`
- Layer 3: `C_{n}_evaluated.json`
- Layer 4: `C_{n}_coboundary.json`
where $n \in \{1, 2, 3\}$ indexes the bosonic rank.
