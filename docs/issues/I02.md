## Context & Background
The existing Schema 1 (algebra structure) was designed for B(m,n). Extending to
C(n+1) requires modifications to several fields while maintaining backward
compatibility. Issue I01 has finalized the basis and PBW ordering.

## Requirements
1. Design `algebra` field for C(n+1) (family="C").
2. Design `oscillator_generators` without supplementary fermion.
3. Design `oscillator_relations` for standard fermionic pair (CAR).
4. Determine `central_elements` (kappa, K) for C(n+1).
5. Define file naming conventions (e.g., `C_1_structure.json`, `C_2_structure.json`, `C_3_structure.json`).

### Mandatory unified rules (fixed for all runs)
- **Algebra Field**: explicitly include `"m": 1` and the dimension formulas `even`: `2n^2 + n + 1`, `odd`: `4n`.
- **Oscillator Generators**: two keys, `"fermions"` (with `m=1`, labels `a_1_p, a_1_m`) and `"bosons"` (with rank `n`).
- **Central Elements**: `central_elements` is a **top-level key**, containing `kappa` (parity 1) and `K` (parity 0).
- **File Naming**: `C_{n}_structure.json`, where `n` is the bosonic rank (e.g., C(2) uses `n=1`).

### Response

#### 1. Schema 1 Field Design Decisions
In accordance with the mandatory unified rules and $C(n+1)$ mathematical structure:
1. **`algebra` Field**:
   - `family`: `"C"`
   - `m`: `1`
   - `n`: `n` (e.g., 1, 2, 3)
   - `cartan_type`: `"C(n+1)"` (e.g., `"C(2)"`, `"C(3)"`, `"C(4)"`)
   - `dimension_formulas`: `even`: `"2n^2 + n + 1"`, `odd`: `"4n"`, `total`: `"2n^2 + 5n + 1"`
   - `dimension`: `{ "total": 2*n^2 + 5*n + 1, "even": 2*n^2 + n + 1, "odd": 4*n }`
2. **`oscillator_generators` Field**:
   - `fermions`: `{ "count": 2, "m": 1, "labels": ["a_1_p", "a_1_m"], "description": "Standard CAR fermionic oscillator pair a_1^±" }`
   - `bosons`: `{ "count": 2*n, "n": n, "labels": [...], "description": "Bosonic oscillators b_j^± with j=1,...,n" }`
3. **`oscillator_relations` Field**:
   - `standard_fermion_anticommutators`: CAR `{a_1^-, a_1^+} = 1`, `{a_1^±, a_1^±} = 0`.
   - `bosonic_commutators`: CCR `[b_i^-, b_j^+] = \delta_{ij}`, `[b_i^±, b_j^±] = 0`.
   - `mixed_commutators`: `[b_i^±, a_1^±] = 0`.
4. **`central_elements` Field**:
   - Top-level key containing:
     - `kappa`: `{ "parity": 1, "nilpotent_order": 2, "description": "Odd central element generating the nilpotent extension (kappa^2 = 0)" }`
     - `K`: `{ "parity": 0, "description": "Even central identity element (K = 1 in standard realization)" }`
5. **File Naming Convention**:
   - Layer 1: `C_{n}_structure.json`
   - Layer 2: `C_{n}_gamma.json`
   - Layer 3: `C_{n}_evaluated.json`
   - Layer 4: `C_{n}_coboundary.json`
   where `n` is the bosonic rank ($n=1, 2, 3$).

#### 2. Compatibility Analysis with $B(m,n)$
- Replaces the ad-hoc `supplementary_fermion` (`a_0^2 = 1/2`) with standard CAR fermionic pair `fermions` (`a_1_p`, `a_1_m`).
- Generalizes root naming to `E_eps1_del{k}_{pp/pm/mp/mm}` for odd roots and preserves `E_2del{k}_{p/m}`, `E_del{i}_del{j}_{pp/pm/mp/mm}` for even roots.
- Elevated `central_elements` to a top-level key.
