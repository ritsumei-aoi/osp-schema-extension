## Context & Background
The existing Schema 1 (algebra structure) was designed for B(m,n). Extending to
C(n+1) requires modifications to several fields while maintaining backward
compatibility. Issue I01 has finalized the basis and PBW ordering.

## Requirements
1. Design `algebra` field for C(n+1) (family="C").
2. Design `oscillator_generators` without supplementary fermion.
3. Design `oscillator_relations` for standard fermionic pair (CAR).
4. Determine `central_elements` (kappa, K) for C(n+1).
5. Define file naming conventions (e.g., `C_1_structure.json`, `C_2_structure.json`, `C_3_structure.json`).

### Mandatory unified rules (fixed for all runs)
- **Algebra Field**: explicitly include `"m": 1` and the dimension formulas `even`: `2n^2 + n + 1`, `odd`: `4n`.
- **Oscillator Generators**: two keys, `"fermions"` (with `m=1`, labels `a_1_p, a_1_m`) and `"bosons"` (with rank `n`).
- **Central Elements**: `central_elements` is a **top-level key**, containing `kappa` (parity 1) and `K` (parity 0).
- **File Naming**: `C_{n}_structure.json`, where `n` is the bosonic rank (e.g., C(2) uses `n=1`).

#### Schema 1 Field Definitions for C(n+1)

**1. Algebra Field Design**

```json
{
  "family": "C",
  "m": 1,
  "n": 2,
  "cartan_type": "C(3)",
  "alternative_notation": {
    "osp": "osp(2|4)",
    "dimension_formula": "osp(2m|2n) with m=1"
  },
  "dimension": {
    "total": 19,
    "even": 11,
    "odd": 8
  }
}
```

Dimension formulas: even = $2n^2 + n + 1$, odd = $4n$, total = $2n^2 + 5n + 1$.

**2. Oscillator Generators (no supplementary fermion)**

```json
{
  "fermions": {
    "m": 1,
    "count": 2,
    "labels": ["a_1_p", "a_1_m"],
    "description": "Standard fermionic pair a_1^± with m=1"
  },
  "bosons": {
    "count": 2n,
    "n": n,
    "labels": ["b_1_p", "b_1_m", ..., "b_n_p", "b_n_m"],
    "description": "Bosonic oscillators b_k^± with k=1,...,n"
  }
}
```

**3. Oscillator Relations (CAR for standard pair)**

```json
{
  "fermionic_anticommutators": {
    "description": "Standard CAR for the fermionic pair",
    "relations": {
      "anticommutator": "{a_1^-, a_1^+} = 1",
      "self_relations": "a_1^+ a_1^+ = 0, a_1^- a_1^- = 0"
    }
  },
  "bosonic_commutators": { ... },
  "mixed_anticommutators": { ... },
  "deformation_parameter_relations": {
    "description": "Nilpotent deformation via κ",
    "relation": "κ^2 = 0"
  }
}
```

**4. Central Elements (κ, K)**

```json
{
  "kappa": {
    "label": "κ",
    "parity": 1,
    "relation": "κ^2 = 0",
    "description": "Odd central element; generates cohomology deformation"
  },
  "K": {
    "label": "K",
    "parity": 0,
    "relation": "scalar 1 in applications",
    "description": "Even central element; identified with scalar 1"
  }
}
```

**Important**: κ and K are NOT included in basis lists. They represent the algebraic structure but are excluded from PBW-ordered basis elements.

**5. File Naming Convention**

Pattern: `C_{n}_*.json` where `n` is the bosonic rank.

| Algebra | Files |
|---|---|
| C(2) = osp(2\|2), n=1 | C_1_structure.json, C_1_gamma.json, C_1_evaluated_<gb>.json, C_1_coboundary_<gb>.json |
| C(3) = osp(2\|4), n=2 | C_2_structure.json, C_2_gamma.json, C_2_evaluated_<gb>.json, C_2_coboundary_<gb>.json |
| C(4) = osp(2\|6), n=3 | C_3_structure.json, C_3_gamma.json, C_3_evaluated_<gb>.json, C_3_coboundary_<gb>.json |

#### Compatibility with B(m,n) Schema

Key differences and compatibility notes:

| Key | B(m,n) | C(n+1) | Compatibility |
|---|---|---|---|
| Fermionic generators | `a_0` (supplementary) | `a_1_p`, `a_1_m` (standard pair) | Incompatible; distinct relational structure |
| Central elements | Implicit | Explicit top-level key | Additive; new key required |
| Basis.odd | `E_del{k}_p/m` (2n elements) | `E_eps_del{k}_{pp/pm/mp/mm}` (4n elements) | Label convention extended |
| Parity encoding | Same 0/1 convention | Same 0/1 convention | Compatible |
| Oscillator realization format | Same JSON structure | Same JSON structure | Compatible |
| File naming | `B_m_n_*.json` | `C_n_*.json` | Different but consistent |

The schema is extensible: future algebras can follow the same 4-layer pattern with
modifications to fermionic/central-element structures as needed.
