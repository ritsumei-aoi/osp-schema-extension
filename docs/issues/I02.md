## Context & Background
The existing Schema 1 (algebra structure) was designed for B(m,n). Extending to
C(n+1) requires modifications to several fields while maintaining backward
compatibility. Issue I01 has finalized the basis and PBW ordering.

## Requirements
1. Design `algebra` field for C(n+1) (family="C").
2. Design `oscillator_generators` without supplementary fermion.
3. Design `oscillator_relations` for standard fermionic pair (CAR).
4. Determine `central_elements` (kappa, K) for C(n+1).
5. Define file naming conventions (e.g., `C_1_structure.json`, `C_2_structure.json`, `C_3_structure.json`).

### Mandatory unified rules (fixed for all runs)
- **Algebra Field**: explicitly include `"m": 1` and the dimension formulas `even`: `2n^2 + n + 1`, `odd`: `4n`.
- **Oscillator Generators**: two keys, `"fermions"` (with `m=1`, labels `a_1_p, a_1_m`) and `"bosons"` (with rank `n`).
- **Central Elements**: `central_elements` is a **top-level key**, containing `kappa` (parity 1) and `K` (parity 0).
- **File Naming**: `C_{n}_structure.json`, where `n` is the bosonic rank (e.g., C(2) uses `n=1`).

#### Field Designs (Unified Rules)

**1. Algebra Field**
```json
{
  "family": "C",
  "m": 1,
  "n": <bosonic_rank>,
  "cartan_type": "C(n+1)",
  "dimension": {
    "even": "2n² + n + 1",
    "odd": "4n",
    "total": "2n² + 5n + 1"
  }
}
```
- Always includes `m=1` for single fermionic pair
- Dimension formulas implemented for n=1,2,3

**2. Oscillator Generators**
```json
{
  "fermions": {
    "m": 1,
    "labels": ["a_1_p", "a_1_m"],
    "car_relation": "{a_1^-, a_1^+} = 1"
  },
  "bosons": {
    "n": <bosonic_rank>,
    "labels": ["b_k_p", "b_k_m"]
  }
}
```
- Two top-level keys: `fermions` and `bosons`
- No supplementary fermion; uses standard fermionic pair with CAR

**3. Oscillator Relations**
```json
{
  "standard_fermion_anticommutators": {
    "relation": "{a_1_m, a_1_p} = 1"
  },
  "bosonic_commutators": {
    "conjugate_pair": "[b_i^-, b_j^+] = δ_{ij}"
  },
  "mixed_commutators": {
    "fermion_boson": "[b_i^±, a_1^±] = 0"
  }
}
```

**4. Central Elements (Top-Level Key)**
```json
{
  "central_elements": {
    "kappa": {
      "label": "κ",
      "parity": 1,
      "property": "κ² = 0",
      "role": "Deformation parametrization"
    },
    "K": {
      "label": "K",
      "parity": 0,
      "property": "identified with scalar 1",
      "role": "Even central element"
    }
  }
}
```

**5. File Naming Convention**
- Pattern: `C_{n}_structure.json` where n is bosonic rank
- Examples:
  - C(2) = osp(2|2): `C_1_structure.json`
  - C(3) = osp(2|4): `C_2_structure.json`
  - C(4) = osp(2|6): `C_3_structure.json`

**6. Four-Layer File Structure**
| Layer | Filename | Purpose |
|---|---|---|
| 1 | `C_n_structure.json` | Algebra structure and basis |
| 2 | `C_n_gamma.json` | Deformation parameters and gamma structure |
| 3 | `C_n_evaluated_<gb>.json` | Evaluated (numerical) structure constants |
| 4 | `C_n_coboundary_<gb>.json` | Coboundary data for triviality |
