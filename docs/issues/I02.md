## Context & Background
The existing Schema 1 (algebra structure) was designed for B(m,n). Extending to
C(n+1) requires modifications to several fields while maintaining backward
compatibility. Issue I01 has finalized the basis and PBW ordering.

## Requirements
1. Design `algebra` field for C(n+1) (family="C").
2. Design `oscillator_generators` without supplementary fermion.
3. Design `oscillator_relations` for standard fermionic pair (CAR).
4. Determine `central_elements` (kappa, K) for C(n+1).
5. Define file naming conventions (e.g., `C_1_structure.json`, `C_2_structure.json`, `C_3_structure.json`).

### Mandatory unified rules (fixed for all runs)
- **Algebra Field**: explicitly include `"m": 1` and the dimension formulas `even`: `2n^2 + n + 1`, `odd`: `4n`.
- **Oscillator Generators**: two keys, `"fermions"` (with `m=1`, labels `a_1_p, a_1_m`) and `"bosons"` (with rank `n`).
- **Central Elements**: `central_elements` is a **top-level key**, containing `kappa` (parity 1) and `K` (parity 0).
- **File Naming**: `C_{n}_structure.json`, where `n` is the bosonic rank (e.g., C(2) uses `n=1`).

### Response

#### 1. Design of `algebra` Field for C(n+1)

**Structure**:
```json
{
  "family": "C",
  "m": 1,
  "n": <n>,
  "cartan_type": "C(n+1)",
  "alternative_notation": {
    "osp": "osp(2|2n)",
    "dimension_formula": "osp(2m|2n) with m=1"
  },
  "dimension": {
    "total": 2*n^2 + 5*n + 1,
    "even": 2*n^2 + n + 1,
    "odd": 4*n
  }
}
```

**Dimension Examples**:
- C(2) (n=1): even=4, odd=4, total=8
- C(3) (n=2): even=11, odd=8, total=19
- C(4) (n=3): even=22, odd=12, total=34

#### 2. Design of `oscillator_generators` (No Supplementary Fermion)

**Structure**:
```json
{
  "fermions": {
    "count": 2,
    "m": 1,
    "labels": ["a_1_p", "a_1_m"],
    "relation": "{a_1^-, a_1^+} = 1",
    "description": "Standard fermionic pair; Clifford algebra generators"
  },
  "bosons": {
    "count": 2*n,
    "n": n,
    "labels": ["b_1_p", "b_1_m", "b_2_p", "b_2_m", ..., "b_n_p", "b_n_m"],
    "description": "Bosonic oscillators b_i^± with i=1,...,n"
  }
}
```

**Key difference from B(0,n)**: No `supplementary_fermion` key; the fermionic content is captured by the standard CAR pair `a_1_p, a_1_m`.

#### 3. Design of `oscillator_relations` (CAR for Standard Pair)

**Structure**:
```json
{
  "standard_fermion_anticommutators": {
    "description": "Canonical anticommutation relations for fermionic pair",
    "relations": {
      "standard_car": "{a_1^-, a_1^+} = 1",
      "self_anticommutators": "{a_1^+, a_1^+} = {a_1^-, a_1^-} = 0"
    }
  },
  "bosonic_commutators": {
    "description": "Canonical commutation relations for bosonic oscillators",
    "relations": {
      "same_type": "[b_i^±, b_j^±] = 0 for all i, j",
      "conjugate_pair": "[b_i^-, b_j^+] = δ_{ij}"
    }
  },
  "mixed_commutators": {
    "boson_fermion": "[b_i^±, a_1^±] = 0"
  }
}
```

**Key difference from B(0,n)**: `supplementary_fermion_relation` is replaced with `standard_fermion_anticommutators` containing the full CAR relation.

#### 4. Design of `central_elements` (New Top-Level Key)

**Structure** (added to top level):
```json
{
  "central_elements": {
    "kappa": {
      "symbol": "κ",
      "parity": 1,
      "nilpotency": "κ² = 0",
      "description": "Odd central element; parameter for inhomogeneous deformation"
    },
    "K": {
      "symbol": "K",
      "parity": 0,
      "description": "Even central identity element (typically identified with scalar 1)"
    }
  }
}
```

**Role**: Enables formal central extension for deformation parameters in Schema 2.

#### 5. File Naming Convention

**Pattern**: `C_{n}_structure.json`

where `n` is the **bosonic rank** (number of pairs of bosonic oscillators).

**Mapping**:
- C(2) = osp(2|2) → `C_1_structure.json` (n=1)
- C(3) = osp(2|4) → `C_2_structure.json` (n=2)
- C(4) = osp(2|6) → `C_3_structure.json` (n=3)

This mirrors the B(0,n) naming convention where B(0,n) → `B_n_structure.json`.

#### 6. Schema Evolution: B(m,n) → C(n+1)

| Aspect | B(0,n) | C(n+1) |
|---|---|---|
| Family | "B" | "C" |
| m value | 0 | 1 |
| Fermionic oscillators | Supplementary $a_0$ (with $a_0^2 = 1/2$) | Standard pair $a_1^\pm$ (with $\{a_1^-, a_1^+\} = 1$) |
| Odd roots | $\pm\delta_k$ (2n total) | $\pm\varepsilon \pm \delta_k$ (4n total) |
| Generator labels | `E_del{k}_p/m` | `E_eps_del{k}_{pp/pm/mp/mm}` |
| Central elements | Not explicitly listed | Explicit `central_elements` key |
| Dimension (even) | $2n^2 + n$ | $2n^2 + n + 1$ |
