## Context & Background
The existing Schema 1 (algebra structure) was designed for B(m,n). Extending to
C(n+1) requires modifications to several fields while maintaining backward
compatibility. Issue I01 has finalized the basis and PBW ordering.

## Requirements
1. Design `algebra` field for C(n+1) (family="C").
2. Design `oscillator_generators` without supplementary fermion.
3. Design `oscillator_relations` for standard fermionic pair (CAR).
4. Determine `central_elements` (kappa, K) for C(n+1).
5. Define file naming conventions (e.g., `C_1_structure.json`, `C_2_structure.json`, `C_3_structure.json`).

### Mandatory unified rules (fixed for all runs)
- **Algebra Field**: explicitly include `"m": 1` and the dimension formulas `even`: `2n^2 + n + 1`, `odd`: `4n`.
- **Oscillator Generators**: two keys, `"fermions"` (with `m=1`, labels `a_1_p, a_1_m`) and `"bosons"` (with rank `n`).
- **Central Elements**: `central_elements` is a **top-level key**, containing `kappa` (parity 1) and `K` (parity 0).
- **File Naming**: `C_{n}_structure.json`, where `n` is the bosonic rank (e.g., C(2) uses `n=1`).

### Response

**Decision log (No-Gate condition)**

Created `docs/json_schema_specification.md` with a complete 4-layer schema definition.

Key design decisions:

1. **Algebra field**: `family="C"`, `m=1`, dimensions use formulas even=$2n^2+n+1$, odd=$4n$.

2. **Oscillator generators**: `supplementary_fermion` key removed; replaced by `fermions` key with `m=1`, labels `a1p`/`a1m`, CAR `{a1m, a1p}=1`.

3. **Central elements**: new top-level key `central_elements` with `K` (parity 0) and `kappa` (parity 1). Both have `in_basis: false` but K may appear as Z in structure_constants (for brackets that produce a K coefficient, e.g., `{E_eps1_del{k}_pp, E_eps1_del{k}_mm} = N_{bk} = Σ H_j - H_{n+1} - (1/2)K`).

4. **structure_constants format**: extended to list-of-terms format `"result": [{Z, coeff}, ...]` to allow multi-generator results (e.g., Cartan + K). This is a backward-compatible extension of the B(0,n) format.

5. **File naming**: `C_{n}_structure.json`, `C_{n}_gamma.json`, `C_{n}_evaluated.json`, `C_{n}_coboundary.json` where n is the bosonic rank.

6. **Compatibility table**: documented in the spec — all field changes relative to B(0,n) are listed.
