## Context & Background
The existing Schema 1 (algebra structure) was designed for B(m,n). Extending to
C(n+1) requires modifications to several fields while maintaining backward
compatibility. Issue I01 has finalized the basis and PBW ordering.

## Requirements
1. Design `algebra` field for C(n+1) (family="C").
2. Design `oscillator_generators` without supplementary fermion.
3. Design `oscillator_relations` for standard fermionic pair (CAR).
4. Determine `central_elements` (kappa, K) for C(n+1).
5. Define file naming conventions (e.g., `C_1_structure.json`, `C_2_structure.json`, `C_3_structure.json`).

### Mandatory unified rules (fixed for all runs)
- **Algebra Field**: explicitly include `"m": 1` and the dimension formulas `even`: `2n^2 + n + 1`, `odd`: `4n`.
- **Oscillator Generators**: two keys, `"fermions"` (with `m=1`, labels `a_1_p, a_1_m`) and `"bosons"` (with rank `n`).
- **Central Elements**: `central_elements` is a **top-level key**, containing `kappa` (parity 1) and `K` (parity 0).
- **File Naming**: `C_{n}_structure.json`, where `n` is the bosonic rank (e.g., C(2) uses `n=1`).

### Response

### 1. Decisions & Schema Design
- **Algebra Field**:
  - `family`: `"C"`
  - `m`: `1`
  - `n`: `n` (bosonic rank)
  - Dimension formulas: `even = 2*n^2 + n + 1`, `odd = 4*n`, `total = 2*n^2 + 5*n + 1`.
- **Oscillator Generators & Relations**:
  - `fermions`: CAR pair with labels `["a_1_p", "a_1_m"]` ($m=1$).
  - `bosons`: CCR pairs with labels `["b_1_p", "b_1_m", ...]`.
  - Relations include standard CAR anticommutation `{a_1_m, a_1_p} = 1`, $(a_1^\pm)^2 = 0$, and CCR $[b_j^-, b_k^+] = \delta_{jk}$.
- **Central Elements**:
  - Dedicated top-level key `central_elements` specifying `kappa` ($p(\kappa)=1, \kappa^2=0$) and `K` ($p(K)=0, K=1$).
- **File Naming Convention**:
  - Layer 1: `data/C_{n}_structure.json`
  - Layer 2: `data/C_{n}_gamma.json`
  - Layer 3: `data/C_{n}_evaluated.json`
  - Layer 4: `data/C_{n}_coboundary.json`
  - Note: $n$ represents the bosonic rank ($n=1$ for $C(2)$, $n=2$ for $C(3)$, $n=3$ for $C(4)$).

### 2. Backward Compatibility
- Schema 1 structure matches the 4-layer hierarchy of $B(0,n)$ v5.0.
- `basis`, `parity`, `structure_constants`, and `metadata` follow the identical JSON schema keys and PBW ordering conventions.
