## Context & Background
The existing Schema 1 (algebra structure) was designed for B(m,n). Extending to
C(n+1) requires modifications to several fields while maintaining backward
compatibility. Issue I01 has finalized the basis and PBW ordering.

## Requirements
1. Design `algebra` field for C(n+1) (family="C").
2. Design `oscillator_generators` without supplementary fermion.
3. Design `oscillator_relations` for standard fermionic pair (CAR).
4. Determine `central_elements` (kappa, K) for C(n+1).
5. Define file naming conventions (e.g., `C_1_structure.json`, `C_2_structure.json`, `C_3_structure.json`).

### Mandatory unified rules (fixed for all runs)
- **Algebra Field**: explicitly include `"m": 1` and the dimension formulas `even`: `2n^2 + n + 1`, `odd`: `4n`.
- **Oscillator Generators**: two keys, `"fermions"` (with `m=1`, labels `a_1_p, a_1_m`) and `"bosons"` (with rank `n`).
- **Central Elements**: `central_elements` is a **top-level key**, containing `kappa` (parity 1) and `K` (parity 0).
- **File Naming**: `C_{n}_structure.json`, where `n` is the bosonic rank (e.g., C(2) uses `n=1`).

### Response

**Decisions**:
- `algebra`: `family: "C"`, `m: 1`, `dimension` even $2n^2+n+1$, odd $4n$, total $2n^2+5n+1$, as mandated.
- `oscillator_generators`: two keys, `fermions` (labels `a_1_p`, `a_1_m`, $m=1$) and `bosons` (rank $n$), as mandated. `supplementary_fermion` is removed.
- `central_elements`: a **top-level** key holding `kappa` (parity 1, $\kappa^2=0$) and `K` (parity 0, identified with $1$), as mandated.
- `schema_version` kept at `"5.0"` for compatibility with B(0,n).
- File naming: `C_{n}_structure.json` with $n$ the bosonic rank ($n=1$ gives $C(2)$), as mandated.
- Options considered for the basis labels: Frappat labels (`E_eps1_del{k}_pp`, etc.) or the Weyl-quadratic labels `W(x,y)`. Chosen: `W(x,y)`, since it matches the basis decided in I01 and avoids a labelling map.

**Compatibility with B(m,n)**: documented field by field in `docs/json_schema_specification.md`. Shared keys keep their structure, so a reader can be reused with the fermion-key change.

**Result**: `docs/json_schema_specification.md` created.
