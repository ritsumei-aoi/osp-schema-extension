C(n+1) requires modifications to several fields while maintaining backward
compatibility. Issue I01 has finalized the basis and PBW ordering.

## Requirements
1. Design `algebra` field for C(n+1) (family="C").
2. Design `oscillator_generators` without supplementary fermion.

### Mandatory unified rules (fixed for all runs)

- **Central Elements**: `central_elements` is a **top-level key**, containing `kappa` (parity 1) and `K` (parity 0).
- **File Naming**: `C_{n}_structure.json`, where `n` is the bosonic rank (e.g., C(2) uses `n=1`).

### Response

#### 1. Specification Overview
The v5.0 JSON schema extension for $C(n+1) = \mathfrak{osp}(2|2n)$ was designed and documented in `docs/json_schema_specification.md`. It strictly adheres to all mandatory unified rules:
- **`algebra` Field**: Contains `"family": "C"`, `"m": 1`, bosonic rank `n`, `"cartan_type": "C(n+1)"`, and dimension formulas `even = 2n^2 + n + 1`, `odd = 4n`, `total = 2n^2 + 5n + 1`.
- **`oscillator_generators`**: Structured with `"fermions"` (`m=1`, labels `["a_1_p", "a_1_m"]`) and `"bosons"` (labels `["b_k_p", "b_k_m"]` for $k=1,\ldots,n$). The obsolete `supplementary_fermion` key is removed.
- **`central_elements`**: Defined as a top-level key containing `kappa` ($p=1$, nilpotent order 2) and `K` ($p=0$, identity scaling).
- **`oscillator_relations`**: Specified with CAR for standard fermions ($\{a_1^-, a_1^+\} = 1$, $(a_1^\pm)^2 = 0$) and CCR for bosons ($[b_j^-, b_k^+] = \delta_{jk}$).
- **File Naming Convention**: Confirmed across all 4 schema layers as `C_{n}_structure.json`, `C_{n}_gamma.json`, `C_{n}_evaluated.json`, and `C_{n}_coboundary.json`, where $n \in \{1, 2, 3\}$ is the bosonic rank.

#### 2. Compatibility Analysis with $B(0,n)$
The 4-layer architecture of the $B(0,n)$ schema is preserved:
- Ordering convention `PBW: κ < [odd] < [even]` is maintained.
- Representation format for oscillator words `{"words": [...], "coeff": "..."}` and graded brackets `{"X": ..., "Y": ..., "Z": ..., "coeff": ..., "sign_rule": "graded"}` remain identical to allow existing schema parsers and analysis tools to operate without breaking changes.
- Comparison matrix between $B(0,n)$ and $C(n+1)$ was established in Section 4 of `docs/json_schema_specification.md`.
