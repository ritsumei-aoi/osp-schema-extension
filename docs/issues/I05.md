#### 1. gb matrix (Requirement 1)

$2 \times 2n$ matrix, rows `a_1_p` ($\sigma=+$), `a_1_m` ($\sigma=-$), columns `b_1_p, b_1_m, …, b_n_p, b_n_m`;
labels `gb_a1{σ}_b{k}{s}` $= \mathrm{gb}_{\sigma,k,s}$ (4n symbols). Stored under `gb_matrix` in Schema 2.

#### 2. Computation of $\gamma$ (Requirement 2)

`src/C_gamma.py` re-uses the normal-ordering engine with the deformed rule
$b_k^s a_1^\sigma = a_1^\sigma b_k^s - \mathrm{gb}_{\sigma,k,s}\kappa$ (from $[b_k^s, a_1^\sigma] = -\mathrm{gb}\,\kappa$),
$\kappa$ odd central ($\kappa a = -a\kappa$, $\kappa b = b\kappa$, $\kappa^2=0$). For every ordered pair the deformed
bracket is normal-ordered and split as $[X,Y\}_0 + \kappa\,\gamma(X,Y)$; $\gamma(X,Y)$ is decomposed exactly in
basis ∪ {K}. The gb symbols are sympy symbols, so all coefficients are exact linear forms in gb.

**Finding (important for I07/I08): $\gamma$ is not $\mathfrak g$-valued; it has a $K$-component.**
Example (n=1, hand-checked):
$[H_2, E_{\varepsilon+\delta_1}]_\gamma$ with $H_2 = -b_1^+b_1^- - \tfrac12$, $E_{\varepsilon+\delta_1} = a_1^+b_1^+$:
$$\gamma(H_2, E_{\varepsilon+\delta_1}) = \mathrm{gb}_{++}(N_1+1) + \mathrm{gb}_{+-}(b_1^+)^2
= -\mathrm{gb}_{++} H_2 + \tfrac12\mathrm{gb}_{++} K + \mathrm{gb}_{+-} E_{2\delta_1}.$$
The constant arises because the deformed relation removes one $b$ and one $a$ from the 4-letter word and
the remaining two bosons may sit in anti-normal order ($b^-b^+ = b^+b^- + 1$). The element $N_1 + 1$ is not in
$\mathfrak g$ (whose Cartan is spanned by $N_1 + \tfrac12$ and $N_a - \tfrac12$), so a $K$-term is unavoidable.
This is consistent with the setting of `C_inhomogeneous_definition.md`, where the extension
$A = V \oplus \mathbb{C}K \oplus \mathbb{C}\kappa$ explicitly contains $K$. Hence
**$\gamma: \mathfrak g\otimes\mathfrak g \to \mathfrak g \oplus \mathbb{C}K$** is the target recorded in the schema.
Counts of $K$-terms: 20 (n=1), 84 (n=2), 180 (n=3).

**Ambiguities recorded (ai_trust_policy):**
* *gb parity.* The definition says gb has parity 1, but with $[b,a]$ odd and $\kappa$ odd, an odd gb would make
  $\mathrm{gb}\,\kappa$ even and break the parity of the bracket; in the pre-oscillator-form picture of the same
  document, $(b|a) = -\mathrm{gb}$ is a scalar. I treat gb as **formal commuting scalars** in all computations
  (the only thing that matters is that $\mathrm{gb}\,\kappa$ is central and that $\kappa$ is written leftmost),
  record `gb_parity: 1` in the schema as the documented convention, and document this in `deformation.gb_treatment`.
  The B(0,n) convention ("gb parity 1") came from $a_0^2 \mapsto \tfrac12 + \kappa\sum \mathrm{gb}\,b$ where it is needed;
  for C(n+1) it is not.
* *Target of $\gamma$.* `C_inhomogeneous_definition.md` writes $\gamma: \mathfrak g\otimes\mathfrak g\to\mathfrak g$;
  the computation forces $\mathfrak g\oplus\mathbb{C}K$. I keep the extra component rather than discarding it
  (discarding would silently change the deformation) and analyse its consequences in I08.
* *Deformation of the Cartan.* $\gamma(H_1,H_2) \neq 0$ (e.g. $\mathrm{gb}_{--}E_{\varepsilon+\delta_1} + \ldots$):
  the deformed Cartan subalgebra is no longer abelian at order $\kappa$. This is a genuine feature of the deformation
  ($[a^+a^-, b^+b^-] \ne 0$ once $[b,a]\ne0$), not an error.

#### 3. `inhomogeneous_deformation` field design (Requirement 3)

Entries `{X, Y, Z, coeff, linear_form}` for all ordered pairs with nonzero $\gamma$; `coeff` is a sympy string,
`linear_form` maps gb labels to rational strings. Additional keys: `deformation` (definition, κ data, gb treatment,
target, parity rule), `gb_matrix`, `consistency`, `schema1_file`. Full definition added to
`docs/json_schema_specification.md` (Schema 2 section).

Alternatives considered: (a) store $\gamma$ as a dense $4n$-indexed tensor $\gamma_{abc}^{(\mathrm{gb})}$ —
rejected, >99% zeros; (b) store only $X<Y$ — rejected, keeping both orders lets readers check antisymmetry as in Schema 1.
