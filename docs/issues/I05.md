### Response

**Design / decisions**

1. **gb_matrix**: 2 × 2n, rows `a_1_p, a_1_m`, columns `b_1_p, b_1_m, …, b_n_p, b_n_m`; entry `gb_a_1_{σ}_b_{j}_{s}` ↔ relation `[b_j^s, a_1^σ] = -gb κ`. 4n parameters.
2. **How γ is computed** (options: (a) hand derivation of every bracket; (b) symbolic sympy; (c) reuse the exact oscillator engine of I03 with the deformed relation). Chose (c): `OscAlgebra(n, gb)` rewrites `b a → a b − gb κ`. Because κ² = 0, γ is *linear* in gb, so γ is obtained from 4n runs with unit gb vectors; linearity is then independently tested against a direct run at random rational gb.
3. **Ambiguity – parity of gb.** The doc says gb "must have parity 1", but `[b, a]` is odd, equal to `-gb κ` with κ odd, so gb·κ is odd only if gb is an ordinary (even) number. Assumption: gb are numeric scalars, the "parity 1" is carried by κ. Recorded in the JSON (`parameters.note`).
4. **Ambiguity – κ and a_1^± .** κ is "central" in the super sense: it anticommutes with the odd a_1^±, commutes with b. Result κ·(…) is always written with κ on the left (sign from moving κ past a's is taken into account by the engine).
5. **Finding – central component of γ.** γ(X,Y) is not always in g: for odd–even pairs (and the like) the Weyl-symmetrised expansion leaves a residual constant, i.e. a term κ·1 (K=1, central). E.g. n=1: `[E_eps1_del1_pp, H_1]` has γ ∝ κ·1 in addition to g-valued terms. Options: (i) drop it (γ: g⊗g→g as in the doc), (ii) keep it as `Z = "K"`. Chose (ii): dropping it would break the cocycle condition / the Jacobi identity of the deformed algebra, and is needed for the I08 triviality statement (f then takes values in g ⊕ CK, see notation.md). Counts of pairs with a K-component: n=1: 20, n=2: 84, n=3: 180.
6. **Schema 2 format**: `inhomogeneous_deformation.gamma` = list of `{X, Y, Z, coeff: {param: rational}}`; specification appended to `docs/json_schema_specification.md`.

**Results**: `python3 src/C_gamma.py` writes `data/C_{1,2,3}_gamma.json`:
```
n=1: nonzero gamma pairs=54, with K-component=20, cocycle failures (gb=all 1)=0
n=2: nonzero gamma pairs=260, with K-component=84, cocycle failures (gb=all 1)=0
n=3: nonzero gamma pairs=714, with K-component=180, cocycle failures (gb=all 1)=0
```

**Consistency check with Schema 1** (`tests/test_C_gamma.py`, 39 tests pass in total with `python3 -m pytest -q`): same basis/parity as Schema 1; labels valid; parity rule p(Z)=p(X)+p(Y)+1; the κ-free part of the deformed bracket equals Schema 1 for random gb; JSON γ evaluated at random rational gb equals the directly computed deformed γ (linearity); γ(gb=0)=0; first-order super Jacobi (2-cocycle) condition holds for random gb (and a perturbation test shows the checker detects violations) – this independently validates the sign conventions.
