**2. gb_matrix Structure**

For C(n+1), the deformation parameters are indexed by:
- **Fermionic oscillator**: a_1^+ (p) or a_1^- (m)
- **Bosonic oscillator index**: j = 1, ..., n
- **Bosonic sign**: + (p) or - (m)

**Total**: 2 × 2n = **4n parameters** (all parity 1)

The exchange relations are:
$$[b_j^s, a_1^\sigma] = -\mathrm{gb}_{\sigma,j,s} \cdot \kappa$$

**Parameter Labels**:
```
gb_a1p_b{j}p, gb_a1p_b{j}m  (fermionic creation)
gb_a1m_b{j}p, gb_a1m_b{j}m  (fermionic annihilation)
```

**4. Gamma Coefficients Structure**

The 2-cocycle γ(X, Y) encodes the deformation bracket:
$$[X, Y]_\gamma = [X, Y]_0 + \kappa \cdot \gamma(X, Y)$$

**Computed terms**:

Type 1: Cartan-ε root brackets
- [H_1, E_eps_del{k}_{...}]: 4n terms (one per ε-root)
- Each involves corresponding gb parameter

Type 2: Odd-odd brackets
- [E_eps_del{i}_{...}, E_eps_del{j}_{...}]: ~4n²/2 sample terms
- Fermionic anticommutator interactions
- Involve products of gb parameters

**Example gamma term**:
```json
{
  "X": "H_1",
  "Y": "E_eps_del1_pp",
  "gamma_symbolic": "gb_a1p_b1p",
  "gamma_description": "Deformation from [a_1 interaction with b_1]",
  "involves_kappa": true
}
```

#### Mathematical Foundation

**Inhomogeneous Deformation (from `C_inhomogeneous_definition.md`)**:

The deformation is defined by modifying oscillator exchange relations:
$$[b_j^s, a_1^\sigma] = -\mathrm{gb}_{\sigma,j,s} \cdot \kappa$$

This induces a deformed bracket:
$$[X, Y]_\gamma = [X, Y]_0 + \kappa \cdot \gamma(X, Y)$$

where γ is a 2-cocycle satisfying:
$$\delta \gamma(X, Y, Z) = 0 \text{ (cocycle condition)}$$

**Triviality Analysis (prepared for I08)**:
A deformation is **trivial** if ∃ odd linear map f: g → g such that:
$$\gamma(X, Y) = (\delta f)(X, Y)$$
