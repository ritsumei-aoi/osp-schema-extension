### Response

**Implementation**: `src/C_gamma.py`

**gb_matrix**: For C(n+1), the deformation parameters are 4n in total:
  gb_{sigma,j,s} for sigma ∈ {+,-}, j=1..n, s ∈ {+,-}.
  Relation: [b_j^s, a_1^sigma] = -gb_{sigma,j,s} * kappa.

**Gamma computation**: Derived from the Wick contraction formula. For each basis pair (X=o1*o2, Y=o3*o4), the mixed boson-fermion contractions in Terms 1-4 are replaced by their deformed values (gb * kappa) instead of 0. The remaining oscillator pair gives the Z component. Contributions with the same (X,Y,Z,gb_param) are aggregated.

**Results**:
- C(2) (n=1): 16 gamma coefficient terms (4 gb parameters, each appearing in multiple brackets).
- C(3) (n=2): 128 gamma coefficient terms.
- C(4) (n=3): 432 gamma coefficient terms.

**Sample for C(2)**:
  gamma(E_2del1_p, E_eps1_del1_pp)^{E_2del1_p} = -2 * gb_a1p_b1p
  gamma(E_eps1_del1_pp, E_eps1_del1_pm)^{E_eps1_del1_pm} = -gb_a1p_b1p

**Consistency with Schema 1**: The gb_matrix has the correct size 4n, and the gamma coefficients only reference generators present in the Schema 1 basis.
