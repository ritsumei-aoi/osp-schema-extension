### Response

**Status**: done. Two engine bugs were found and fixed in this issue (items 1–2 below). Both affect the I03 outputs, which are regenerated here.

**Method.** $\gamma$ is the $\kappa$-linear part of $[X_a,X_b]$ in the associative algebra with the deformed relation $[b_j^s,a^\sigma]=-\mathrm{gb}_{\sigma,j,s}\kappa$. It is linear in the 4n parameters, since $\kappa^2=0$ and each contraction carries one gb. Code: `src/C_gamma.py` (driver) and `src/c_algebra.py` (engine). Output: `data/C_{n}_gamma.json` (Schema 2).

**Bugs found and fixed.**
1. **Non-associative engine.** Treating $\kappa$ as commuting with $a^\pm$ gave 104 failures of associativity among 512 triple products ($n=1$). The reason: $\kappa$ is odd, so it must anticommute with $a^\pm$ (super-central). The Leibniz rule on $\{a^-,a^+\}=1$ requires this. After the fix, associativity has 0 failures for $n=1,2$ (512 and 6859 triples).
2. **Left/right convention for $\kappa$.** The engine writes $\kappa$ on the right. The doc writes $\kappa\gamma$. The two differ by $(-1)^{p(X)+p(Y)+1}$. The doc's convention gives 0 cocycle failures; the other gives 462 for $n=1$. The exported $\gamma$ uses the doc's convention (decision A7).

**Checks** (all in `gamma_checks`, run for every $n$):

| check | $n=1$ | $n=2$ | $n=3$ |
|---|---|---|---|
| parity of $\gamma(X,Y)$ is $p(X)+p(Y)+1$ | 0 failures | 0 | 0 |
| graded anti-symmetry | 0 | 0 | 0 |
| cocycle condition, for every gb tag ($\sum$ over triples $\times$ tags) | 0 of 2048 | 0 of 54872 | 0 of 471648 |
| super-Jacobi defect in the algebra (independent of the $\gamma$ table) | 0 of 512 | 0 of 6859 | 0 of 39304 |
| $\kappa$-free part agrees with Schema 1 JSON | 40 entries, 0 mismatches | 198, 0 | 528, 0 |

Counts: g-valued entries 92 / 568 / 1660; $K$-components 20 / 84 / 180.

**Sample** ($n=1$, doc convention): $[E_{\varepsilon+\delta_1}, E_{\varepsilon+\delta_1}]$ has $\gamma$-coefficient $-2\,\mathrm{gb}_{a_1^+,b_1^+}$ on $E_{\varepsilon+\delta_1}$; $[E_{\varepsilon+\delta_1}, H_1]$ has $+\mathrm{gb}_{a_1^+,b_1^+}$ on $H_1$ and $2\,\mathrm{gb}_{a_1^+,b_1^-}$ on $E_{2\delta_1}$. Non-zero $\gamma$ appears only for the four gb tags of $n=1$.

**Consistency with Schema 1.** The $\kappa$-free part is unchanged and agrees with `C_{n}_structure.json` for every entry. The Schema 1 file was regenerated only because its `central_elements` text changed to "super-central". Its structure constants did not change.

**Decisions** (see notation.md §8): gb are commuting scalars (A1); $\kappa$ is super-central (A5); $\gamma$ is in the doc's left convention (A7); $K$-components are recorded separately (A4).
