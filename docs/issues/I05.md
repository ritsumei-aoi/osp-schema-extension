### Response

#### Implementation
- `src/C_gamma.py`: builds the deformed oscillator algebra (`OscillatorAlgebra(n, deformed=True)`,
  rule `b_j^s a_1^σ = a_1^σ b_j^s - gb_{σ,j,s} kappa`), computes `[X,Y}` for every ordered pair
  of basis elements, splits the result as `[X,Y]_0 + kappa·Σ_p p·X_p` and decomposes each `X_p`
  in the basis ∪ {K}. Output `data/C_{n}_gamma.json` (Schema 2 as specified in
  `docs/json_schema_specification.md` §2). `gb_matrix` is 2×2n (rows `a_1_p, a_1_m`, columns
  `b_1_p, …, b_n_m`), parameters `gb_a1{σ}_b{j}{s}`.
- `tests/test_C_gamma.py`: 5 tests × n (linearity/homogeneity in gb, sector support,
  antisymmetry, Jacobi on L, file equals fresh generation, hand values for n=1).

#### Mathematical decisions / recorded ambiguities
1. **Parity of gb.** `C_inhomogeneous_definition.md` says gb "must have parity 1", but with
   `[b_j^s, a_1^σ]` odd and `kappa` odd, a parity-1 gb would make the right-hand side even.
   The pre-oscillator-form definition in the same document, `[a,b] = (a|b)κ` for `p(a)≠p(b)`
   with `(·|·): V×V → C`, makes gb = -(b|a) a **scalar**. Adopted: gb are c-numbers; the odd
   parity of the deformation term `gb·kappa` is carried by `kappa`. The schema keeps
   `"parity": 1` on the gb block (B(0,n) convention) with an explanatory `parity_note`.
2. **Target of γ is g ⊕ C K, not g.** The deformed bracket of two symmetrized quadratics is
   `[X,Y]_0 + kappa·(γ_g(X,Y) + γ_K(X,Y)·K)`, and `γ_K ≠ 0` in general. Example (n=1, by hand
   and by the script): `[a_1^+b_1^-, b_1^+b_1^-] = a_1^+b_1^- + kappa(gb_{+1+} b_1^-b_1^- + gb_{+1-} b_1^+b_1^-)`
   and `b_1^+b_1^- = N_1^s - ½`, so with `H_2 = -N_1^s` the pair `(E_eps1_del1_pm, H_2)` has
   `γ_K = +½ gb_a1p_b1m`. The constants cannot be removed by changing the embedding of g
   (g is simple, so the symmetrized embedding is the only Lie-subalgebra complement). Options
   considered: (a) drop K-components (loses information, breaks Jacobi on L), (b) record them
   with `Z = "K"` (adopted; K is the even central element already declared in
   `central_elements`). Counts of K-entries: n=1: 20, n=2: 84, n=3: 180.
3. The definition "γ: g⊗g → g" in the handover document is therefore read as
   "γ: g⊗g → g ⊕ C K", with L = g ⊕ kappa·(g ⊕ C K) as the abelian extension.

The Jacobi check on L uses the bracket `[X, kappa W] = (-1)^{p(X)} kappa [X,W]_0`,
`[kappa W, X] = kappa [W,X]_0`, `[kappa W, kappa W'] = 0` (derived from `kappa` odd central);
it is a genuine 2-cocycle test of γ with exact linear forms in gb.

#### Sample of γ for n=1 (full list in `data/C_1_gamma.json`)
```
γ(E_eps1_del1_pp, E_eps1_del1_pp) = 2 gb_a1p_b1p · E_eps1_del1_pp
γ(E_eps1_del1_pp, H_1)            = gb_a1p_b1p·H_1 + gb_a1p_b1m·E_2del1_p + gb_a1p_b1p·K
γ(E_eps1_del1_pm, H_2)            = gb_a1p_b1m·H_2 - gb_a1p_b1p·E_2del1_m + ½ gb_a1p_b1m·K
γ(H_1, H_2)                       = gb_a1m_b1m·E_eps1_del1_pp + gb_a1m_b1p·E_eps1_del1_pm - gb_a1p_b1m·E_eps1_del1_mp - gb_a1p_b1p·E_eps1_del1_mm
γ(H_1, E_2del1_p)                 = -2 gb_a1m_b1p·E_eps1_del1_pp + 2 gb_a1p_b1p·E_eps1_del1_mp
```
Structural observation: γ(X,Y) ≠ 0 only if X or Y contains a fermionic factor (odd generators
or `H_1`); the sp(2n) part is undeformed, as expected since only `[b, a_1]` is deformed.
