### Response

Implemented `src/C_gamma.py` with symbolic `GbExpr` class for linear expressions in gb parameters.

**gb_matrix**: 4n parameters: gb_a1{sigma}_b{j}{s} for sigma in {p,m}, j=1..n, s in {p,m}.

**Gamma computation approach**: For each basis pair (X,Y), compute the kappa-coefficient of [X,Y]_gamma by tracking where the deformed relation [b_j^s, a_1^sigma] = -gb_{sigma,j,s}*kappa enters. Key contributions:
- eps_del/eps_del: each generator swaps b_k with the other a_1, creating two gb terms per pair.
- eps_del/2del: the [a_1, (b^{ls})^2] deformation contributes 2*gb term.
- eps_del/del_del: [a_1, b_i*b_j] deformation contributes gb terms for each boson factor.

**Output**:
- C_1_gamma.json: 44 gamma entries (n=1)
- C_2_gamma.json: 336 gamma entries (n=2)
- C_3_gamma.json: 1116 gamma entries (n=3)

Consistency check: all Z labels in gamma_coefficients are valid basis elements (no warnings). Gamma entries involve only odd generators (eps_del), 2del, and del_del — consistent with the Z labels being in the algebra basis.
