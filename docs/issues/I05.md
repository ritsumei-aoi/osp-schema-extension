#### 2. The gb matrix

`gb_matrix` is $2 \times 2n$: rows indexed by the fermionic label
(`a_1_p`, `a_1_m`), columns by the bosonic label (`b_1_p, b_1_m, …, b_n_p, b_n_m`),
giving $4n$ parameters `gb_a1{P|M}_b{k}{P|M}`, defined by

$$[\,b_k^s,\ a_1^\sigma\,] = -\,\mathrm{gb}_{\sigma,k,s}\,\kappa .$$

| n | parameters |
|---|---|
| 1 | 4 |
| 2 | 8 |
| 3 | 12 |

#### 3. Method — γ as a by-product of the same engine

Rather than deriving $\gamma_{abc}$ by hand, the **single** oscillator
contraction above was injected into the normal-ordering engine of I03 and all
brackets recomputed. Then

$$[X,Y]_\gamma = \underbrace{[X,Y]_0}_{\kappa\text{-free}} + \kappa\,\gamma(X,Y),$$

and $\gamma(X,Y)$ is obtained by stripping the leading $\kappa$ and decomposing
in the basis. This was the explicit reason for choosing the oscillator-calculus
design in I03, and it paid off: Schema 2 required no new bracket logic at all.

**γ is linear in gb** — proved and checked: a second contraction would require a
second $\kappa$ factor, and $\kappa^2 = 0$. A corollary is that the $\kappa$-free
part of the deformed bracket is *identical* to Schema 1; this is asserted
entry-by-entry (`consistency.undeformed_part_matches_schema1`).

#### 4. Ambiguity resolved: the parity of gb

`docs/math/C_inhomogeneous_definition.md` carries an internal inconsistency.
Its §1 defines $[b_k^s, a_1^\sigma] = -\mathrm{gb}_{\sigma,k,s}\kappa$; the LHS
has parity $p(b)+p(a) = 0+1 = 1$. Its **Parity Note** then asserts
"the deformation parameters gb must have parity 1", which would make the RHS
$\mathrm{gb}\cdot\kappa$ have parity $1+1 = 0$. The two statements cannot both hold.

Options considered:

- **(a)** Keep gb odd and reinterpret the defining relation (e.g. as an
  anticommutator). Rejected: $b$ is even, so the bracket $[b,a\}$ *is* the
  commutator; there is no reinterpretation available.
- **(b)** Keep gb odd and declare κ even. Rejected: contradicts
  `B0n_definition.md` §3 ($p(\kappa)=1$, $\kappa^2=0$) and the I02 mandatory rule.
- **(c) Chosen** — treat gb as **even (commuting) formal scalars**, keeping
  $p(\kappa) = 1$ and the defining relation as written.

**Reason.** Under (c) every parity ledger closes: $p(\gamma(X,Y)) = p(X)+p(Y)+1$
holds for all 744 computed entries at $n=3$ (test
`test_gamma_parity`), which is exactly the condition for
$\kappa\,\gamma(X,Y)$ to have parity $p(X)+p(Y)$. Under (a)/(b) it would not.

**Why the source document says otherwise.** The Parity Note is inherited from
B(0,n), where the structure is genuinely different: there the deformation is
$a_0^2 \mapsto \tfrac12 + \kappa\sum \mathrm{gb}\,b_j^s$
(`B0n_definition.md` §3). There the gb multiplies a *degree-one* element $b_j^s$
inside an even expression, so $p(\mathrm{gb})=1$ is forced. In C(n+1) the gb
multiplies $\kappa$ alone, and the forced parity flips. The note was carried
over without re-deriving. Recorded here; no change requested to the source
document.

This assumption is **isolated and auditable**: it only fixes whether gb symbols
pick up signs when commuted past odd elements. Since every gb in the computation
appears attached to $\kappa$ and $\kappa^2=0$, no gb is ever commuted past
another gb, so the choice affects only overall signs, not the structure of the
answer — and the cocycle check of §6 would fail if the signs were wrong.

#### 6. Consistency checks

1. **Schema 1 agreement** — the $\kappa$-free part of every deformed bracket
   equals the Schema 1 constant, for all ordered pairs, all $n$. PASS.
2. **2-cocycle condition.** In $L = \mathfrak g \oplus \kappa\mathfrak g$ one has
   $[\kappa u, Z\} = \kappa[u,Z\}_0$, so the $\kappa$-component of
   $[[X,Y]_\gamma, Z]_\gamma$ is
   $\Phi(X,Y,Z) = \gamma([X,Y]_0, Z) + [\gamma(X,Y), Z]_0$, and super Jacobi
   requires the signed cyclic sum of $\Phi$ to vanish. Checked **symbolically in
   the gb parameters** on all $N^3$ triples: 512 / 6859 / 39304. PASS. This is
   the strongest available check that the γ table is correct, and it is where a
   wrong gb-parity convention (§4) would have shown up.
3. **Parity** $p(\gamma(X,Y)) = p(X)+p(Y)+1$ on every entry. PASS.
4. **Linearity in gb** — every coefficient is homogeneous of degree 1. PASS.
5. **Round trip** — JSON equals a fresh live computation. PASS.

#### 7. Finding recorded for I07: γ takes values in $\mathfrak g \oplus \mathbb C K$

γ has a **non-zero $K$-component** on exactly the (odd, even) pairs — 12 / 40 / 84
pairs for $n = 1,2,3$. This is genuine, not an artefact: e.g.
$\gamma(a_1^+b_1^+, H_{\delta_1})$ contains $b_1^-b_1^+ = b_1^+b_1^- + 1$, whose
constant term survives under *any* Cartan normalization. So
$\gamma : \mathfrak g \otimes \mathfrak g \to \tilde{\mathfrak g} = \mathfrak g \oplus \mathbb C K$,
consistent with `C_inhomogeneous_definition.md`, which builds the whole setting
inside $A = V \oplus \mathbb C K \oplus \mathbb C\kappa$.

**Consequence flagged for I07/I08.** Structure constants of $\mathfrak g$ never
produce $K$ (verified in I04), so $[X, f(Y)]$ never does either. Hence a map
$f: \mathfrak g \to \mathfrak g$ gives a $\delta f$ with **zero** $K$-component
and could never reproduce γ. The target of $f$ must therefore be
$\tilde{\mathfrak g} = \mathfrak g \oplus \mathbb C K$; then
$(\delta f)|_K(X,Y) = -f([X,Y])|_K$, which is supported exactly on pairs whose
bracket has an odd component — i.e. the (odd, even) pairs. The supports match.
This is taken up as an explicit design decision in I07.
