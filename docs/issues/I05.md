#### 1. `gb_matrix` (Requirement 1)
$2\times 2n$ matrix, rows `a_1_p, a_1_m`, columns `b_1_p, b_1_m, …, b_n_p, b_n_m`, entry
labels `gb_a1{σ}_b{k}{s}` $= \mathrm{gb}_{a_1^σ, b_k^s}$; $4n$ parameters, stored in
`inhomogeneous_deformation.gb_matrix` together with the defining relation
$[b_k^s, a_1^σ] = -\mathrm{gb}_{a_1^σ,b_k^s}\,\kappa$.

**Ambiguity recorded (ai_trust_policy boundary).** `C_inhomogeneous_definition.md` ends with
"the deformation parameters gb must have parity 1". Taken literally (Grassmann-odd gb),
the right-hand side $\mathrm{gb}\cdot\kappa$ would be *even* while the left-hand side
$[b_k^s, a_1^σ]$ is odd, so the defining relation itself would violate parity; moreover the
same document defines the extension through a scalar-valued pre-oscillator form
$(\cdot|\cdot): V\times V\to\mathbf C$ with $[a,b] = (a|b)\kappa$, and I06 asks to substitute
numeric signs into gb. **Assumption adopted:** the gb entries are commuting scalars and the
odd parity is carried by κ alone; the parity statement is read as the (correct) statement
that $\gamma$ is an odd 2-cochain, $p(\gamma(X,Y)) = p(X)+p(Y)+1$. This is enforced as
check 3 below and recorded in `notation.md` §4 and in the JSON (`parameter_type`).

#### 2. γ coefficients (Requirement 2)
For each ordered pair $(X,Y)$ of basis generators the engine of I03 evaluates
$XY - (-1)^{p(X)p(Y)}YX$ in $\mathcal U(A)$ with the deformed relation switched on, moves
κ to the far left ($x\kappa = (-1)^{p(x)}\kappa x$, $\kappa^2 = 0$), splits
$[X,Y]_\gamma = [X,Y]_0 + \kappa\,\gamma(X,Y)$, and decomposes $\gamma(X,Y)$ in the basis of
$\mathfrak g$ **plus the even central element K**. Each coefficient is a linear form in the gb
symbols (linearity is automatic from κ² = 0).

**Mathematical finding: γ takes values in $\mathfrak g\oplus\mathbf C K$, not in $\mathfrak g$.**
Example (n = 1, verified by hand):
$[H_1, E_{\varepsilon+\delta_1}]_\gamma = 2E_{\varepsilon+\delta_1} + \kappa\big(-\mathrm{gb}_{a^+b^+}H_1 - \mathrm{gb}_{a^+b^-}E_{2\delta_1} - \mathrm{gb}_{a^+b^+}K\big)$.
The constant arises because $[b_1^+b_1^-, a_1^+b_1^+]$ produces $-\mathrm{gb}_{a^+b^+}\kappa\, b_1^-b_1^+ = -\mathrm{gb}_{a^+b^+}\kappa(b_1^+b_1^- + 1)$,
and $b_1^+b_1^-$ is not a symmetrised quadratic. Pairs with a K-component: 20 / 84 / 180
for n = 1, 2, 3. This is why Schema 2–4 admit `"K"` as a target label (I02 §2); it becomes
important for the triviality question in I07/I08.
Other hand-checked entries: $\gamma(E_{\varepsilon-\delta_1},E_{\delta_1-\varepsilon}) = \mathrm{gb}_{a^-b^-}E_{\varepsilon+\delta_1} + \mathrm{gb}_{a^+b^+}E_{-\varepsilon-\delta_1}$;
$\gamma(E_{\varepsilon+\delta_1},E_{\varepsilon+\delta_1}) = 2\mathrm{gb}_{a^+b^+}E_{\varepsilon+\delta_1}$ (odd generators no longer square to zero);
$\gamma(H_1,H_2) \ne 0$ (the so(2) part of $H_1$ feels the deformation) while the pure
$\mathfrak{sp}(2n)$ sector ($H_2,\dots,H_{n+1}$, all $E_{\pm2\delta}, E_{\pm\delta\pm\delta}$) is undeformed.

#### 3. `inhomogeneous_deformation` field (Requirement 3)
