### Response

#### Decisions and Results

**1. gb_matrix definition**: For C(n+1), the deformation is parameterized by 4n parameters:
- gb_{σ,j,s} for σ ∈ {+,-} (fermionic label), j = 1,...,n (bosonic index), s ∈ {+,-} (bosonic sign)
- These arise from the deformed mixed commutator: [b_j^s, a_1^σ] = -gb_{σ,j,s} · κ

Parameter counts: C(2): 4, C(3): 8, C(4): 12.

**2. Gamma computation**: Implemented in `src/C_gamma.py` using first-order perturbation theory:
- Modified the normal ordering algorithm to track gb-proportional correction terms
- Since κ² = 0, only first-order terms in gb contribute
- Each gamma coefficient γ(X,Y)^Z is a linear expression in gb parameters
- The correction may produce K (identity) components, handled by extended Cartan decomposition

**3. Schema 2 JSON output**:
- `C_1_gamma.json`: 56 gamma entries, 4 gb params
- `C_2_gamma.json`: 326 gamma entries, 8 gb params
- `C_3_gamma.json`: 920 gamma entries, 12 gb params

**4. Consistency verification**: All X, Y, Z labels in gamma entries correspond to valid generators from Schema 1 (plus K). All gb_param labels are valid. Algebra metadata matches between Schema 1 and Schema 2.
