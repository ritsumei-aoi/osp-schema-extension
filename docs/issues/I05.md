### Response

Implemented `src/C_gamma.py`.

**Approach.** The deformed oscillator relations are
`a_1^σ · b_j^s - b_j^s · a_1^σ = gb_{σ,j,s} · κ`, with κ odd central and
κ² = 0. Since κ² = 0, only first-order gb terms survive. The implementation
mirrors the undeformed normalizer but, when a `(boson, fermion)` pair is
swapped during normalization, additionally emits a branch
`-gb_{σ,j,s} · κ · (word with the swapped pair deleted)`. That shorter
word is normalized under the undeformed rules (further swaps on a κ-branch
would be O(κ²) and are discarded).

**gb parameters** indexed by (σ ∈ {+,−}, j ∈ 1..n, s ∈ {+,−}) — 4n total,
parity 1. Schema labels: `gb_a1{σ}_b{j}{s}`.

**Projection.** The κ-coefficient `γ(X,Y)` is an oscillator polynomial with
sympy coefficients linear in gb. A sympy-coefficient version of the
I03 projector decomposes γ onto the Cartan–root basis.

**Consistency.** The body component of the deformed bracket matches the
undeformed body (verified by sharing `normalize_word` for the body half).
Spot-check for n=1:
`γ(H_1, E_2del1_p) → +2·gb_{a_1^-, b_1^+}·E_eps1_del1_pp + 2·gb_{a_1^+, b_1^+}·E_eps1_del1_mp`,
reflecting that δ-raising moves cost one b-a swap.
