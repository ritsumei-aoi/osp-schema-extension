#### Implementation
- `src/oscillator.py` (deformed mode): `[b_j^s, a_1^σ] = −gb_{σ,j,s} κ` (equivalently `b a = a b − gb κ`),
  κ odd central, κ² = 0, κ moved to the left with sign `(−1)^{parity of prefix}`.
- `src/C_gamma.py`: evaluates every ordered bracket of the Schema 1 realizations in the deformed
  oscillator algebra, splits the result into the κ⁰ part and the κ¹ part, and decomposes the κ¹ part
  (per gb parameter) into the basis **plus K**. Output `data/C_{n}_gamma.json`
  (format appended to `docs/json_schema_specification.md`, "Schema 2").
- `gb_matrix`: 2 × 2n, rows `(a_1_p, a_1_m)`, cols `(b_1_p, b_1_m, …, b_n_m)`, labels `gb_{σ}_{j}_{s}`; 4n parameters.

#### Consistency with Schema 1 (all read back from JSON)
1. Parity: γ is **odd** (p(Z) = p(X)+p(Y)+1), all labels in the Schema 1 basis — 0 failures.
2. The κ⁰ part of the deformed bracket reproduces Schema 1 exactly — 0 mismatches.
3. 2-cocycle condition (order-κ Jacobi of [ , ]_γ, using Schema 1 constants), for each gb separately, all triples — 0 failures. A negative control (one corrupted γ coefficient) is detected by the test suite.

#### Ambiguities and decisions
1. **Parity of gb.** The doc says gb "must have parity 1". But [b, a] is odd and κ is odd, so in
   `[b,a] = −gb κ` the coefficient gb must be an even (commuting) scalar; Grassmann-odd gb would make
   the right side even. *Decision*: keep the label `parameter_parity: 1` in the JSON (spec compliance;
   the parameters only ever appear multiplied by κ), but compute with gb as commuting scalars. Recorded in `gb_matrix.parity_note`.
2. **Central terms.** The κ-part of brackets is quadratic in oscillators and contains constants
   (e.g. b⁺b⁻ = (b⁺b⁻ + ½) − ½). So γ takes values in g ⊕ ℂK, not g. *Options*: (a) drop K terms;
   (b) store them separately. *Decision*: (b) — `central_component` list (20/84/180 entries for n=1/2/3), so that
   I07/I08 can treat the "up to scalar" clause of `C_coboundary_definition.md` explicitly instead of silently.
3. Order of κ: always on the left, `[X,Y]_γ = [X,Y]_0 + κ γ(X,Y)` (matches the δf sign convention, see I07).
