### Response

**Decisions**
- **gb matrix** (2 × 2n): rows are fermions $a_1^\sigma$ ($\sigma=\pm$), columns are bosons $b_j^s$ (ordered $j$, then $s$). Entries are the $4n$ symbols `gb_a_1_{p,m}__b_{j}_{p,m}`. Parity 1, as the math document requires.
- **Deformed relation**: $[b_j^s, a_1^\sigma] = -\mathrm{gb}_{\sigma,j,s}\,\kappa$, exactly as in `docs/math/C_inhomogeneous_definition.md`. All other relations are undeformed (the CAR $\{a_1^-,a_1^+\}=1$ and the CCR).
- **κ convention**: κ is treated as central (commutes with all oscillators), following the schema statement. Alternative considered: κ anticommuting with the odd $a_1^\pm$. Rejected, since it would add a sign convention the math document does not state, and κ enters only linearly here.
- **Computation**: κ is a formal symbol with $\kappa^2=0$. The κ⁰ part of every bracket is the undeformed Schema 1 bracket, and the κ¹ part is $\gamma$. Both come from one computation, so the consistency check compares the same arithmetic.
- **Storage**: γ is stored once per unordered pair in PBW order (`sign_rule: graded`), like Schema 1. Coefficients are linear forms in gb written as sympy strings (e.g. `-2*gb_a_1_p__b_1_p`).

**Results**
- Consistency with Schema 1: the κ⁰ part equals `data/C_{n}_structure.json` on all pairs for n=1,2,3 (0 mismatches). The check is `check_against_schema1` in `src/C_gamma.py`.
- Graded antisymmetry of γ on all ordered pairs holds for n=1,2,3.
- Every coefficient of γ is linear in gb (checked in tests).
- Nonzero γ entries in the JSON: 56, 272, 744 (for n=1,2,3).

**Finding: κ·K components.** The first run failed an assertion that γ has no K component. Cause: a single fermion–boson contraction followed by the undeformed boson commutator $[b_p,b_m]=1$ leaves $\kappa\cdot 1$. In the schema, K is the central identity (K=1), so $\kappa\cdot K$ is a legitimate term of the deformed bracket. Example: $\gamma(E_{\varepsilon+\delta_1}^{pp}, E_{2\delta_1}^-) = \mathrm{gb}_{a_1^+,b_1^-}\,(H_1 + \tfrac12 K)$. I kept these components and recorded their count (24, 80, 168 pairs for n=1,2,3). This matters for I08: a comparison that ignores K would miss part of the structure.

**Tests**: `tests/test_C_gamma.py` (5 test kinds, parametrized over n). `python3 -m pytest -q` gives **34 passed** (16 generator, 5 verifier, 13 gamma).

**Completion Criteria**: all three marked [x] above.
