#### Implementation

**Script**: `src/C_gamma.py`

The gamma 2-cocycle is computed by tracking the kappa contributions that arise when computing the graded commutator [X,Y}_deformed in the oscillator algebra with modified relations:
  [b_j^s, a_1^sigma] = -gb_{sigma,j,s} * kappa

The algorithm:
1. `normal_order_deformed(word)`: normal-orders an oscillator word in the deformed algebra, tracking both the standard (undeformed) terms and the kappa-proportional terms separately.
2. `graded_commutator_deformed(m1, m2)`: computes [m1, m2} in the deformed algebra, separating undeformed and kappa parts.
3. `compute_gamma(n, ...)`: sums all monomial-pair contributions, then expresses the kappa part in terms of basis generators using mono_map.

**gb matrix**:
- Size: 4n parameters (sigma ∈ {p,m}, j=1..n, s ∈ {p,m})
- Labels: `gb_p_1_p, gb_p_1_m, gb_m_1_p, gb_m_1_m` (for n=1), etc.
- Parity: 1 (odd parameters, consistent with kappa being odd)

#### Generated Files

- `data/C_1_gamma.json`: 96 non-zero gamma entries (n=1, 4 gb parameters)
- `data/C_2_gamma.json`: 576 non-zero gamma entries (n=2, 8 gb parameters)
- `data/C_3_gamma.json`: 1672 non-zero gamma entries (n=3, 12 gb parameters)

#### Consistency Checks

1. **Parity check**: All gamma(X,Y)[Z] entries have parity p(X)+p(Y)+1 (mod 2) ← OK for all n.
2. **Antisymmetry check**: gamma(X,Y) = -(-1)^{p(X)p(Y)} gamma(Y,X) ← OK for n=1,2,3.
3. **Schema 1 consistency**: gamma coefficients reference only generators in C_{n}_structure.json basis.
