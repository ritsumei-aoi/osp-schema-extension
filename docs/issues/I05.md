#### Implementation
Created `src/C_gamma.py` implementing:
- `build_gb_parameters(n)`: generates 4n deformation parameters {gb_{a1σ,bjs}}
- `deformed_normal_order()`: normal ordering with deformed mixed commutators [b_j^s, a_1^σ] = -gb_{σ,j,s}·κ
- `compute_gamma_coefficients(n)`: computes all γ_{X,Y,Z} first-order deformation coefficients
- `build_schema2_json(n)`: assembles Schema 2 JSON

The deformation is parameterized by the gb matrix (size 2×2n = 4n parameters):
- For each fermionic oscillator (a_1^+, a_1^-) and bosonic oscillator (b_j^+, b_j^-), one parameter
