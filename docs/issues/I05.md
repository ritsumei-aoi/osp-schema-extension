**Executed by**: Claude Sonnet 4.6 (No-Gate condition)

#### Implementation

**Script**: `src/C_gamma.py` — `CnPlusOneGamma` extends `CnPlusOne` with:

- `_no_recurse_deformed()`: modified normal ordering that tracks b-a swap deformation terms. For each swap of $b_j^s$ (even oscillator, index≥2) past $a_1^\sigma$ (odd, index 0 or 1), adds $-\text{gb}_{\sigma,j,s}$ times the remaining monomial to the kappa-coefficient accumulator.
- `multiply_deformed()`: multiplies elements tracking both main (kappa^0) and kappa-part.
- `bracket_deformed()`: returns `(main_gens, gamma_gens)` — main part matches undeformed bracket; gamma_gens is the 2-cocycle expressed as `{gen_Z: {gb_var: coeff}}`.
- `compute_gamma()`: iterates all pairs, outputs list of gamma entries.
- `build_schema2()`: assembles Schema 2 JSON.

**gb matrix design** (4n parameters, parity 1):
- Labels: `gb_a1p_b{k}p`, `gb_a1p_b{k}m`, `gb_a1m_b{k}p`, `gb_a1m_b{k}m` for k=1..n.
- Defining relation: $[b_j^s, a_1^\sigma] = -\text{gb}_{\sigma,j,s} \cdot \kappa$.

**Consistency verification**: For n=1, all 64 bracket pairs verified: the main (kappa^0) part of `bracket_deformed()` matches the undeformed `bracket()` exactly. ✓

- `data/C_2_gamma.json`: 292 non-zero gamma entries (8 gb parameters)
