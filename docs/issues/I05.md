### Response

### 1. Implementation Details
- Implemented `src/C_gamma_generators.py` to evaluate the inhomogeneous deformation:
  $$[b_j^s, a_1^\sigma] = - \mathrm{gb}_{\sigma, j, s} \cdot \kappa, \quad \sigma \in \{+, -\}, s \in \{+, -\}, j \in \{1, \ldots, n\}$$
  - The parameter collection $gb$ contains $4n$ parity-1 parameters with shape $(2, 2n)$.
  - Exact derivation of $\kappa$-linear contributions to $[X, Y]_\gamma = [X, Y]_0 + \kappa \cdot \gamma(X, Y)$ and decomposition modulo central scalar $K$ using `solve_in_basis_mod_K`.
- Output Schema 2 JSON files to `data/`:
  - `data/C_1_gamma.json` ($n=1, C(2)$): 4 $gb$ parameters, 96 non-zero $\gamma$-terms.
  - `data/C_2_gamma.json` ($n=2, C(3)$): 8 $gb$ parameters, 576 non-zero $\gamma$-terms.
  - `data/C_3_gamma.json` ($n=3, C(4)$): 12 $gb$ parameters, 1,672 non-zero $\gamma$-terms.

  - Graded anti-symmetry of $\gamma(X, Y)$ for all parameters and generator pairs.
  - Full consistency of metadata and algebra definitions between Schema 1 and Schema 2.
