### Analysis & Decisions
1. **Implementation**: Implemented `src/C_gamma.py` to evaluate the inhomogeneous deformation. The algorithm works by assigning $\omega \mapsto \omega + \kappa \eta$ where $\eta(a_1^\sigma, b_k^s) = \mathrm{gb}_{\sigma, k, s}$. The purely linear term in $\kappa$ corresponds exactly to the 2-cocycle $\gamma(X, Y)$.
2. **Schema 2 Design**: Defined `inhomogeneous_deformation` with the $2 \times 2n$ gb matrix. The output records $\{X, Y, Z, \mathrm{gb}, \text{coeff}\}$ representing the component of $\gamma(X, Y)$ in the direction of generator $Z$ proportional to the parameter $\mathrm{gb}$.
3. **Execution**: Evaluated successfully for $n=1, 2, 3$ generating `C_1_gamma.json`, `C_2_gamma.json`, and `C_3_gamma.json`.
4. **Consistency**: The algorithm dynamically uses the exact generators and ordering from Schema 1, guaranteeing perfect compatibility.
