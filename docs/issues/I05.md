#### Decisions and Results

1. **gb_matrix**: Defined with 4n parameters indexed by $(\sigma, j, s)$ where $\sigma \in \{+,-\}$ (fermion sign), $j \in \{1,\ldots,n\}$ (boson index), $s \in \{+,-\}$ (boson sign). The deformation rule is $[b_j^s, a_1^\sigma] = -\text{gb}_{\sigma,j,s} \cdot \kappa$.

2. **Gamma computation**: Uses the same graded Leibniz expansion as structure constants, but replaces each fundamental bracket $[b_j^s, a_1^\sigma]$ with its deformed value $-\text{gb} \cdot \kappa$. Since $\kappa^2 = 0$, only first-order corrections survive. Each $\gamma_{X,Y,Z}$ coefficient is linear in a single gb parameter.

3. **Results**:

   - C(3) n=2: 284 gamma entries, 8 gb parameters
   - C(4) n=3: 830 gamma entries, 12 gb parameters
