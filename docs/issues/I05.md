### Response

**Implementation**: `src/C_gamma.py`

**gb_matrix**: For C(n+1), 4n parameters gb_{σ,k,s} where σ∈{p,m}, k=1..n, s∈{p,m}.
The deformed relation is [bks, a1σ] = -gb_{σ,k,s}·κ (was 0 in the standard algebra).

**Algorithm**: `deformed_normal_form(init_dict)` tracks boson-fermion swap contributions.
Every time a boson bks passes a fermion a1σ during standard normal ordering, a "raw" gamma contribution is recorded: reduced tuple (remaining monomials) with coefficient -gb_{σ,k,s}. After the main stack completes, all raw gamma tuples are brought to standard normal form via `normal_form_poly`, then expressed in the basis using `express_in_basis_v2` and the Cartan solver.

**Key finding**: For degree-2 generators, gamma coefficients are LINEAR in gb parameters. No gb^2 terms arise because the raw gamma tuples (degree ≤ 2) are purely bosonic or fermionic — no further boson-fermion swaps occur during their normalization.

**Results**:
```
n=1 (C(2)): 4 gb params, 56 gamma entries
n=2 (C(3)): 8 gb params, 322 gamma entries
n=3 (C(4)): 12 gb params, 912 gamma entries
All Z generators valid (no references outside basis).
```

Sample (n=1):
```
gamma(H_1, E_2del1_p) -> E_eps1_del1_mp: 2*gb_p1p
gamma(H_1, E_2del1_p) -> E_eps1_del1_pp: 2*gb_m1p
gamma(E_eps1_del1_pp, E_eps1_del1_mm) -> E_eps1_del1_pm: -gb_m1p
gamma(E_eps1_del1_pp, E_eps1_del1_mm) -> E_eps1_del1_mp: -gb_p1m
```

Manual verification of gamma(E_pp, E_mm):
- In (E_pp)(E_mm) = (a1p b1p)(a1m b1m): b1p passes a1m → -gb_m1p · (a1p b1m) = -gb_m1p · E_pm. ✓
- In (E_mm)(E_pp) = (a1m b1m)(a1p b1p): b1m passes a1p → -gb_p1m · (a1m b1p) = -gb_p1m · E_mp. ✓
