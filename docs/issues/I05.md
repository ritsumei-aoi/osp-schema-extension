### Response

#### 1. `gb_matrix` (Requirement 1)
$2\times 2n$ matrix, rows = $a_1^+, a_1^-$, columns = $b_1^+, b_1^-, \dots, b_n^+, b_n^-$; entry labels `gb_a1{σ}_b{k}{s}` (row-major list in the JSON with `row`/`col` indices). The deformation enters only through $[b_k^s, a_1^\sigma] = -\mathrm{gb}_{a_1^\sigma,b_k^s}\,\kappa$ (`C_inhomogeneous_definition.md` §1); CAR, CCR and the centrality/nilpotency of $\kappa$ are unchanged.

#### 2. Computation of $\gamma_{abc}$ (Requirement 2) — `src/C_gamma.py`
$[X,Y\}_\gamma$ is computed in the deformed oscillator algebra (`OscillatorAlgebra(n, gb)` from I03, with $\kappa$ as an odd, super-central, nilpotent symbol placed first in the normal order). The result splits uniquely as $A_0 + \kappa A_1$; $A_0$ is asserted equal to the Schema 1 bracket and $A_1 = \gamma(X,Y)$ is decomposed exactly in $\mathfrak g\oplus\mathbb C K$. Since $\kappa^2=0$, $\gamma$ is linear in gb, so it is computed once per parameter (gb$_p=1$, others 0) and stored as a linear form `coeff: {gb_label: rational}` plus a readable `linear_form`.

**Mathematical point recorded (ambiguity)**: $\gamma(X,Y)$ is *not* always in $\mathfrak g$: for opposite-parity pairs a scalar component appears, e.g. $\gamma(E_{\varepsilon+\delta_1}, H_1) = \mathrm{gb}_{a_1^+b_1^+}(H_1 + K) + \mathrm{gb}_{a_1^+b_1^-}E_{2\delta_1}$, because the κ-part contains $b_k^+b_k^- = \tilde N_k - \tfrac12$ and $a_1^+a_1^- = J + \tfrac12$. The definition document writes $\gamma:\mathfrak g\otimes\mathfrak g\to\mathfrak g$ but also embeds everything in $\mathcal U(A)$ with $A = V\oplus\mathbb CK\oplus\mathbb C\kappa$ and speaks of the adjoint representation, in which $K$ acts trivially. Decision: store the $K$-component explicitly (`"Z": "K"`) so nothing is lost, and let I08 treat the $K$-part separately (comparison "up to scalar"). Counts of entries with `Z = K`: 20 (n=1), 84 (n=2), 180 (n=3).

**Parity bookkeeping (ambiguity)**: the definition says both gb and κ have parity 1, which would make $\mathrm{gb}\,\kappa$ even and break $p([b,a])=1$. What matters is that the product $\mathrm{gb}\cdot\kappa$ is odd and super-central; I verified by hand that attributing the odd grading to κ (I02 rule) or to gb (B(0,n) JSON convention) yields identical $\gamma$. `gb_matrix.parity: 1` is kept as the label with a `parity_note`.

#### 5. Consistency with Schema 1 (Requirement 5) — `check_gamma_consistency`
Performed inside the generator (raises on failure) and re-run from the JSON files alone in `tests/test_C_gamma.py`:
* κ-free part of every deformed bracket equals the Schema 1 structure constant (asserted for every pair and every parameter);
* parity rule $p(\gamma(X,Y)) = p(X)+p(Y)+1$ for every stored component;
* graded antisymmetry $\gamma(Y,X) = -(-1)^{p(X)p(Y)}\gamma(X,Y)$;
* **cocycle condition**: the super Jacobi identity of the deformed bracket on $L = \mathfrak g\oplus\kappa(\mathfrak g\oplus\mathbb CK)$, with $[X,\kappa Z\} = (-1)^{p(X)}\kappa[X,Z\}$, $[\kappa Z,W\} = \kappa[Z,W\}$, $[\kappa Z,\kappa W\}=0$, holds for all triples and every gb parameter (n=1: 512×4, n=2: 6 859×8, n=3: 39 304×12 triple checks). This is exactly the statement that $\gamma$ is a 2-cocycle with values in the (parity-shifted) adjoint module.

Hand-checked entries (n=1): $\gamma(E_{\varepsilon+\delta_1},E_{\varepsilon+\delta_1}) = 2\,\mathrm{gb}_{a_1^+b_1^+}E_{\varepsilon+\delta_1}$ (from $b^+a^+ = a^+b^+ - \mathrm{gb}\,\kappa$ and $a^+\kappa=-\kappa a^+$), and $\gamma(E_{\varepsilon+\delta_1},H_1)$ as above — both match the JSON (encoded in `test_hand_checked_gamma_n1`).
