**Implementation**: `src/C_gamma.py`.
- Because $\kappa^2=0$, $\gamma$ is linear in gb. It is computed exactly by building the algebra for each of the $4n$ unit vectors and reading the $\kappa$-coefficients.
- `gb_matrix`: $2\times 2n$, rows $a_1^+,a_1^-$, columns $b_j^\pm$, entries `gb_a1{sigma}_b{j}{s}`.
- `inhomogeneous_deformation.gamma`: for each nonzero $(X,Y,Z)$, the linear form in gb (`terms`).
- Output: `data/C_{1,2,3}_gamma.json`, with 108, 536 and 1476 nonzero entries.

**Decisions** (recorded in `handover/notation.md`, "Deformation conventions"):
- Basis symbols are gb-free; only products use the deformed relations. Options: deform the basis symbols too (rejected: it puts $\kappa$-constants into the basis), or gb-free symbols with deformed products (chosen).
- $\kappa$ is odd and graded-central. A contraction moved past an odd prefix takes the sign $(-1)^{\#\text{odd prefix}}$.

**Bug found and fixed (root cause)**: the first run failed the $\kappa$-linear Jacobi check (21 nonzero entries for one gb unit). $\kappa$ was kept as a commuting coefficient, so a contraction next to an odd prefix lacked the sign $(-1)^{\#\text{odd prefix}}$. Fixed in `OscAlgebra.normal`. After the fix, Schema 1 regenerates byte-identically, and the 12 unit tests and `verify_C_structure.py` still pass.
