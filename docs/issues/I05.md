#### Mathematical set-up and interpretation
Pre-oscillator algebra A = V ⊕ ℂK ⊕ ℂκ, $C(n+1)$ realized inside U(A) (K = 1). The deformation
changes only the mixed form: $[b_j^s, a_1^\sigma] = -\mathrm{gb}_{\sigma,j,s}\,\kappa$
(equivalently $[a_1^\sigma, b_j^s] = +\mathrm{gb}_{\sigma,j,s}\kappa$). For generators X, Y
(fixed oscillator words from Schema 1) the graded commutator in U(A), normal ordered with κ moved
to the left (κ supercentral, κ²=0), splits uniquely as $[X,Y] = [X,Y]_0 + \kappa\,\gamma(X,Y)$.

Ambiguities and decisions:
1. **Parity of gb.** The doc says gb "must have parity 1". If gb were Grassmann-odd, $-\mathrm{gb}\,\kappa$
   would be even while $[b,a]$ is odd, violating parity. Decision: gb are **commuting scalars**;
   "parity 1" is kept as a formal label (`parameter_parity: 1`) meaning that gb multiplies the
   odd central κ in a mixed-parity bracket. Recorded in `gb_matrix.parity_note`.
2. **Target space of γ.** The doc says γ: g⊗g→g, but computation shows γ(X,Y) ∈ g ⊕ ℂK: normal
   ordering e.g. $\kappa\,b^-b^+ = \kappa(b^+b^- + 1)$ or $\kappa\,a^-a^+$ produces constants.
   Decision: store the central part explicitly as `Z = "K"` (20 / 84 / 180 entries for n=1/2/3),
   so nothing is lost; the triviality test (I07/I08) treats it "up to scalar" as the coboundary
   doc allows, and also separately.
3. γ is exactly **linear** in gb (κ²=0), so it is computed exactly for each of the 4n unit gb
   vectors and stored as linear forms.
