#### Implementation

Implemented `src/C_gamma.py` with:
- `_normalize_deformed(word, n)`: extends the oscillator normal-ordering to track kappa contributions from the deformed commutator `[b_j^s, a_1^sigma] = -gb_{sigma,j,s} * kappa`. Since `kappa^2 = 0`, at most one kappa insertion per product is non-zero.
- `compute_gamma(n)`: for each generator pair (X,Y), computes the kappa coefficient by expanding `[X,Y}_deformed = [X,Y}_0 + kappa * gamma(X,Y)`, then expresses `gamma(X,Y)` in the generator basis.
- `build_schema2(n)`: assembles the Schema 2 JSON.

#### gb Matrix

For C(n+1): 4n parameters `gb_a1{sigma}_b{k}{s}` for sigma, s ∈ {p, m}, k=1,...,n.

**Sample verification**: `gamma(E_eps_del1_pp, E_eps_del1_pp) = -2 · gb_a1p_b1p · E_eps_del1_pp`.

This is correct: `[a_1^+ b_1^+, a_1^+ b_1^+]_deformed` produces a kappa term when `b_1^+` passes `a_1^+`, giving `-2 · gb_a1p_b1p · kappa · a_1^+ b_1^+`.
