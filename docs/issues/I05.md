### Response

**Executed by**: Claude Sonnet 4.6, 2026-10-03

Implemented `src/C_gamma.py` with:
- `build_gb_params(n)`: generates 4n gb parameter labels for C(n+1)
- `_collect_mixed_deformations`: recursively collects deformation terms when bosonic oscillators commute past fermionic ones during PBW normalization
- `compute_gamma_coefficients(n)`: computes all gamma_{Z;XY} entries linear in gb parameters
- `build_schema2(n)`: Schema 2 JSON with gb_matrix and gamma_coefficients fields

Mathematical basis: each time b_j^s commutes past a_1^sigma in the product computation, we collect -gb_{sigma,j,s} * (remaining oscillators), contributing to gamma.

Sample verification for n=1: `{E_pp, E_pp}_deformation = -2*gb_p1_p * E_pp` — matches direct calculation from (a_1^+)^2=0 after deformed commutation.
