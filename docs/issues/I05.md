#### Schema 2 Structure: Inhomogeneous Deformation

**gb-Matrix Definition**:
- Shape: 2 × 2n (fermionic signs × bosonic oscillators)
- Total parameters: 4n (odd parity each)
- Indexing: gb_{σ,k,s} where σ ∈ {+,-}, k ∈ {1,...,n}, s ∈ {+,-}

**Exchange Relation** (fundamental deformation rule):
$$[b_j^s, a_1^σ] = -\mathrm{gb}_{σ,j,s} \cdot κ$$

This induces the deformed bracket:
$$[X, Y]_γ = [X, Y]_0 + κ \cdot γ(X, Y)$$

where γ(X, Y) is a 2-cocycle derived from oscillator bracket evaluation.

**gb_Parameters** (for each n):

| Algebra | Parameters | Example labels |
|---------|-----------|---|
| C(2) | 4 | gb_+_1_p, gb_+_1_m, gb_-_1_p, gb_-_1_m |
| C(3) | 8 | gb_+_1_p, gb_+_1_m, gb_+_2_p, gb_+_2_m, gb_-_1_p, gb_-_1_m, gb_-_2_p, gb_-_2_m |
| C(4) | 12 | gb_±_{1,2,3}_{p,m} (all combinations) |

#### Design Notes

1. **Gamma Coefficients**: The γ-cocycle coefficients are marked "to be computed". This is correct because:
   - Their values depend on the specific gb parameters
   - Full computation requires evaluating $\dim(\mathfrak{g})^2$ brackets
   - This is typically done numerically in Schema 3 layer

2. **Coboundary Framework**: Schema 2 establishes the framework for triviality analysis:
   - Defines the odd linear map f: g → g
   - States the coboundary operator formula
   - Lists the triviality condition γ = δf
   - Actual triviality verification is Schema 4 work

3. **Parity Consistency**: All gb_parameters have parity 1 (odd), which is required because:
   - κ is odd (parity 1)
   - The bracket [b_j^s, a_1^σ] must preserve total parity
   - gb_σ,j,s · κ has parity = 1 · 1 = 0 (even), as expected for the right-hand side
