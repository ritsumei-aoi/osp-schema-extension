### Response

#### Implementation Summary

**1. GB Matrix Design for C(n+1)**

The deformation parameters form a 4n × 1 matrix indexed by:
- Fermionic oscillator sign: σ ∈ {+, -}
- Bosonic oscillator index: j ∈ {1, ..., n}
- Bosonic oscillator sign: s ∈ {+, -}

**Total parameters**: 4n (each with parity 1, odd)

**Labeling**: `gb_a1_σ_bj_s` where σ,s ∈ {p,m}

**Example for C(2) (n=1)**:
```
gb_a1_p_b1_p   (parameter for [b_1^+, a_1^+])
gb_a1_p_b1_m   (parameter for [b_1^-, a_1^+])
gb_a1_m_b1_p   (parameter for [b_1^+, a_1^-])
gb_a1_m_b1_m   (parameter for [b_1^-, a_1^-])
```

**2. Gamma Coefficient Computation**

The inhomogeneous deformation is defined by:
$$[X, Y]_\gamma = [X, Y]_0 + \kappa \cdot \gamma(X, Y)$$

where γ(X, Y) encodes the deformation via the exchange relations:
$$[b_j^s, a_1^\sigma] = -gb_{\sigma,j,s} \cdot \kappa$$

**Gamma structure computed**:
- For each generator pair (X, Y), compute how the boson-fermion interaction deforms the bracket
- Gamma terms indexed by (X, Y, Z) with symbolic coefficients depending on gb parameters
- Results stored in `inhomogeneous_deformation.gamma_terms` list
