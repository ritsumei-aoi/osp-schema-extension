### Response

**Implementation:** `src/C_gamma.py`

**Algorithm:** Two-track normal ordering in the deformed oscillator algebra.

- Deformed commutation rule: b_j^s · a_1^σ = a_1^σ · b_j^s − gb_{σ,j,s} · κ
- Normal ordering tracks two streams simultaneously: main terms (κ-free) and κ-proportional terms.
- κ² = 0 ensures no higher-order corrections; deformed swaps within κ-terms produce zero delta.
- Gamma entries are extracted by decomposing the κ-proportional part of [X, Y]_gamma back into basis generators using Cartan inversion formulas.

**gb_matrix design:**
- Size: 2 × 2n (rows: σ ∈ {+,−}; columns: (j,s) ∈ {1,...,n}×{+,−})
- Parameter labels: gb_{σ}_{j}_{s}, total count = 4n
- Graded: all gb parameters are even scalars (γ itself is a 2-cochain of odd degree)

**Consistency check:**
- Schema 2 gamma pairs ⊃ Schema 1 SC pairs (deformation opens new brackets)
- Gamma-only pairs (zero in SC, non-zero in γ): 9, 62, 215 for n=1,2,3

**Results:**
```
C(2) = osp(2|2), n=1: 46 gamma entries, 4 gb parameters
C(3) = osp(2|4), n=2: 284 gamma entries, 8 gb parameters
C(4) = osp(2|6), n=3: 830 gamma entries, 12 gb parameters
```

**Sample entries (n=1):**
- γ(H₁, H₂) = −gb_m_1_m·E_ε₁δ₁_pp − gb_m_1_p·E_ε₁δ₁_pm − gb_p_1_m·E_ε₁δ₁_mp − gb_p_1_p·E_ε₁δ₁_mm
- γ(H₁, E_ε₁δ₁_pp) = gb_p_1_p·H₁ + 2·gb_p_1_p·H₂ − gb_p_1_m·E_2δ₁_p
