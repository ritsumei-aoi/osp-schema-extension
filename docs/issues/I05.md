### Response

**Implementation (2026-10-08, no-gate)**

Files: `src/C_gamma.py` (computation, Schema 2 writer, evaluation helpers `gamma_table`,
`extended_algebra`), `data/C_{1,2,3}_gamma.json`, `tests/test_C_gamma.py`,
`docs/json_schema_specification.md` §6.

**1. gb matrix.** 2 × 2n matrix, rows `a_1_p, a_1_m`, columns `b_1_p, b_1_m, …, b_n_p, b_n_m`, labels
`gb_a1{σ}_b{j}{s}`; 4n parameters. Deformed relation exactly as in `C_inhomogeneous_definition.md`:
`[b_j^s, a_1^σ] = -gb_{σ,j,s} kappa`.

**2. Mathematical ambiguities resolved (recorded per ai_trust_policy).**
- *Parity of gb.* The definition says gb has parity 1, but with kappa odd the relation
  `[b, a] = -gb kappa` has an odd left-hand side, so gb must be a commuting scalar for the relation to be
  homogeneous (odd · odd would be even). Options: (a) Grassmann-odd gb, (b) scalar gb. Chose (b): it is the only
  parity-consistent reading, it matches I06 ("substituting concrete signs into gb"), and the resulting γ is
  linear in gb either way. The "parity 1" of the definition is recorded as formal bookkeeping in `gb_matrix.parity_note`.
- *Target of γ.* γ(X,Y) is obtained by normal-ordering in the enveloping algebra; the κ-terms are quadratic
  words, which lie in the span of the basis **plus the scalar 1 = K** (the Cartan span of C(n+1) does not contain 1,
  see I01). Example: γ(H_1, E_eps1_del1_pp) = -gb_a1p_b1p (H_1 + K) - gb_a1p_b1m E_2del1_p.
  Options: (a) discard the K-components, (b) keep them as entries with Z = "K". Chose (b): dropping them would
  change the bracket; K is already a declared central element of the schema (I02), and the K-part is itself
  a scalar 2-cocycle, which matters for the triviality analysis in I08.

**3. Computation.** `OscillatorAlgebra(n, deformed=True)` with sympy symbols for gb; for every ordered pair
(X, Y) the graded commutator is normal-ordered, split into κ⁰ and κ¹ parts, and both parts are decomposed
with the exact `Decomposer` of I03. The κ⁰ part is asserted to equal Schema 1 (consistency with Layer 1).
κ² = 0 makes γ exactly linear in gb; `linear_form` stores it as `{gb_label: rational}`.

**4. Results.**

Hand-checked samples (n = 1), both reproduced by the data:
```
gamma(E_eps1_del1_pm, E_eps1_del1_mp) = gb_a1m_b1m E_eps1_del1_pp + gb_a1p_b1p E_eps1_del1_mm
gamma(H_1, E_eps1_del1_pp)            = -gb_a1p_b1p H_1 - gb_a1p_b1p K - gb_a1p_b1m E_2del1_p
```
Structural observations (verified on the data for n = 1, 2, 3): γ(X, Y) ≠ 0 only when at least one of
X, Y contains the fermions, i.e. is an odd generator or H_1; all pairs of pure `sp(2n)` elements
(E_2del, E_del_del, H_k with k ≥ 2) have γ = 0. Every γ coefficient is a linear form in gb with
coefficients in {±1, ±2, ±1/2}.

**5. Consistency checks (all pass; `python3 -m pytest -q tests/test_C_gamma.py` → 18 passed).**
- κ⁰ part == Schema 1 for n = 1, 2, 3 (also asserted in the generator).
- Parity rule p(Z) = p(X) + p(Y) + 1 for every entry; graded antisymmetry of γ.
- Cocycle condition: super Jacobi of L = g~ ⊕ κ g~ (dim 18 / 40 / 70) holds for all 4n unit gb vectors
  (n = 1, 2) and for random rational gb vectors (n = 1, 2, 3), using the I04 verifier. A control run with
  the odd–odd entries of γ sign-flipped produces 523 Jacobi failures (n = 2), so the check is sensitive.
