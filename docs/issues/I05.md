#### 2. Deformation Parameters (gb_matrix)

**Size**: 2 rows × 2n columns

**Parameters**: 4n total (for each fermionic-bosonic pair):
- gb_{a_1^+, b_j^+}, gb_{a_1^+, b_j^-}, gb_{a_1^-, b_j^+}, gb_{a_1^-, b_j^-}
- for j = 1, ..., n

**Indexing Convention**:
```
gb_a1_{σ}_b{j}_{s}
where σ ∈ {p, m} (+ or -)
      j ∈ {1, ..., n} (bosonic oscillator index)
      s ∈ {p, m} (+ or -) (bosonic sign)
```

**Example for C(2)** (n=1):
- gb_a1_p_b1_p, gb_a1_p_b1_m, gb_a1_m_b1_p, gb_a1_m_b1_m (4 parameters)

**Example for C(3)** (n=2):
- 8 parameters: gb_a1_{σ}_b{1,2}_{±}

#### 3. Gamma Structure Definition

**Field**: `gamma_structure` (new in Schema 2)

**Subfields**:
- `deformation_parameters`: List of gb parameter definitions with parity and descriptions
- `gb_matrix_size`: Dimensions (2 × 2n)
- `gamma_coefficients`: List of γ-terms in the deformed bracket [X, Y]_γ = [X, Y]_0 + κ · γ(X, Y)

**Role**: Parametrizes the inhomogeneous deformation via the 2-cocycle γ.
