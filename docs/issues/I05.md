#### Deformation Parameters (gb matrix)

For C(n+1), defined 4n parameters:
$$\{gb_{a_1^\sigma, b_j^s} : \sigma, s \in \{+,-\}, j=1,\ldots,n\}$$

Exchange relations:
$$[b_j^s, a_1^\sigma] = -gb_{\sigma,j,s} \cdot \kappa$$

**Parameter indexing**:
- gb_a1p_b1p, gb_a1p_b1m, gb_a1m_b1p, gb_a1m_b1m (for j=1)
- ... (continuing for j=2,...,n)
