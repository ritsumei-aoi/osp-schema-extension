# Triviality of the inhomogeneous (gb) deformation of C(n+1) = osp(2|2n)

## Theorem

Let g = osp(2|2n), n ≥ 1, and let γ_gb be the inhomogeneous deformation cochain defined by the parameters gb_{σ,j,s} (4n of them). Then γ_gb = δf for some odd linear f: g → g **if and only if gb = 0**. For n = 1, 2, 3 this is a computer-verified exact result (rational linear algebra). The map gb ↦ [γ_gb] ∈ H²(g; Πg) is injective, so the class space contains at least a 4n-dimensional subspace of non-trivial classes.

I did not prove the statement for general n. The pattern is uniform (see "Structure"), but I give no proof for n ≥ 4.

## Setting (from docs/math)

- U(A) is generated by a^±_1 (odd), b^±_k (even) and the odd central κ, with κ² = 0 because 2κ² = [κ,κ] = 0.
- The relations are [b⁻_k,b⁺_l] = δ_kl, {a⁻,a⁺} = 1, and [b^s_j, a^σ] = −gb_{σ,j,s} κ.
- g is the span of the 2n²+5n+1 supersymmetrised quadratics Z = ½(uv + (−1)^{p(u)p(v)} vu).
- For each basis pair, [Z_i,Z_j]_gb = Σ c_ij^k Z_k + κ·(Σ γ_ij^k Z_k + s_ij·1).
- c is the undeformed structure constant. γ is the κ-coefficient and is linear in gb, because κ² = 0.
- The scalar part s_ij is the coefficient of κ·1.

## Handling "adjoint representation / up to scalar"

1. **Adjoint module.** L = g ⊕ κg is the abelian extension of g by Πg, the adjoint module with flipped parity, on which κ acts trivially. γ is therefore a 2-cochain with values in Πg, and δ is the Chevalley–Eilenberg differential of the given formula.
2. **Which f.**
   - Take the new section X' = X + κf(X). A direct computation with κ odd and central gives [X',Y']' = ([X,Y])' + κ(γ + δf)(X,Y).
   - So γ is trivial, meaning the extension splits, iff γ = −δf for some f. Replacing f by −f gives γ = δf.
   - The convention in C_coboundary_definition.md is exactly the one that makes the odd inner maps f = ad Z with Z ∈ g₁ cocycles.
   - `check_conventions.py` confirms this: δ(ad Z) = 0 to machine precision for n = 1, 2, 3.
3. **"Up to scalar."** I considered three readings.
   - (a) γ = λ·δf with λ ≠ 0. This is the same as exact equality, because Im δ is a linear subspace, so f can be rescaled to f/λ. It adds no new solutions.
   - (b) Equality modulo constants, i.e. modulo κ·1 ∈ A. g has no centre and the unit is not in g, so the only possible scalar obstruction is the κ·1 component of γ.
     - I computed this component for every basis pair and every gb parameter. It is identically zero (`scalar_parts_nonzero` = 0 in the artifacts).
     - Hence the strict and the mod-scalar versions coincide.
   - (c) Equality up to a pair-dependent scalar λ(X,Y). This is not a linear condition and is not a meaningful notion of equivalence, so I did not use it.
   
   Conclusion: the answer is the same under every meaningful reading.
4. **Choice of section.** Z is a fixed lift of g into U(A). A different lift changes γ by δ(some f), so the class [γ] and the triviality question do not depend on the lift.

## Structure of γ and the computation

γ(X,Y) collects the terms of [XY] in which one oscillator from each of X and Y contracts through a gb-pairing, leaving a quadratic. The parity of γ is odd:

| X, Y | contraction | value of γ |
|---|---|---|
| g₀ × g₀ (a⁺a⁻ with bb) | a with b | g₁ |
| g₀ × g₁ | | g₀ |
| g₁ × g₁ | | g₁ |

Each of the 4n parameters gives a nonzero γ (21 nonzero entries for n = 1).

Unknowns and equations:
- The unknowns are the odd matrix f (φ_ml with p(m) ≠ p(l)) and t = gb. The count is 32, 176, 528 for f and 4, 8, 12 for t at n = 1, 2, 3.
- The equations are δf − Σ_m t_m γ^{(m)} = 0 on all triples (i,j,k).
- The null space is computed exactly over ℚ through the Gram matrix, and its projection onto t is taken.

| n | dim g (even\|odd) | rank δ | dim ker δ | rank [δ \| γ] | trivial gb subspace |
|---|---|---|---|---|---|
| 1 | 4\|4 | 28 | 4 | 32 | **0** |
| 2 | 11\|8 | 168 | 8 | 176 | **0** |
| 3 | 22\|12 | 516 | 12 | 528 | **0** |

- ker δ has dimension 4n = dim g₁. It is exactly the space of odd inner derivations ad(g₁), which the sanity check verifies.
- rank [δ | γ] = rank δ + 4n. The 4n columns γ^{(m)} are linearly independent modulo Im δ, so a combination Σ t_m γ^{(m)} lies in Im δ only if t = 0.

## Artifacts (for reproduction)

- `verify_triviality.py [n…]` regenerates everything and writes `artifacts/cn1_n{1,2,3}.json` and `artifacts/summary.json`.
- Each `cn1_n*.json` contains:
  - the basis;
  - the structure constants `c` ("i,j" → {k: value});
  - γ for each gb parameter and the scalar parts of γ;
  - the result block.
- `check_conventions.py` is the sign-convention sanity check.

## Caveats

- General n is not proved; the pattern (rank [δ | γ] = rank δ + 4n) held for n = 1, 2, 3.
- The conclusion rests on my reading that g is embedded via supersymmetrised quadratics. This choice does not affect triviality (see item 4 above).
- I used no external papers, so no Frappat references were needed or accessed.
