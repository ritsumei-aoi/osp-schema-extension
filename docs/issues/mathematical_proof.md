# Triviality of inhomogeneous gb-deformations of C(n+1) = osp(2|2n)

**Status**: concluded (computational verification for n = 1, 2, 3)
**Issue**: `docs/issues/issue_open.md`
**Artifacts**: `artifacts/c_triviality_n1.json`, `artifacts/c_triviality_n2.json`, `artifacts/c_triviality_n3.json`
**Script**: `scripts/verify_c_triviality.py` (run as `python3 -I scripts/verify_c_triviality.py 1 2 3`)

---

## 1. Conclusion

For n = 1, 2, 3, **every** gb-configuration is trivial. The set of trivial configurations is the whole parameter space C^{4n}, so the triviality conditions are vacuous: no nonzero gb is obstructed. Concretely:

| n | dim g (even\|odd) | odd 1-cochains f | rank δ | gb-params | trivial gb-subspace W |
|---|---|---|---|---|---|
| 1 | 8 (4\|4)   | 32  | 28  | 4  | 4  (= all) |
| 2 | 19 (11\|8) | 176 | 168 | 8  | 8  (= all) |
| 3 | 34 (22\|12)| 528 | 516 | 12 | 12 (= all) |

The kernel of δ on odd maps has dimension 4n in each case. It equals the space of odd inner derivations ad_Z (Z odd), which is a consistency check on the sign convention and on the algebra.

This is a definitive answer under the requirement stated in the issue (γ_gb = δf with f odd), and under the stronger inhomogeneous framework described in §3. The answer does not depend on the reading of "up to scalar" (§2).

The expected answer, that only gb = 0 is trivial, does **not** hold in this model.

## 2. Handling "adjoint representation / up to scalar"

**Adjoint part.** The deformation has two components:
- an adjoint-valued part γ_gb : g⊗g → g, the κ-coefficient of the bracket between basis elements of g;
- a trivial-module part c_gb : g⊗g → C, the coefficient of κ·1. This part comes from contractions that leave no oscillators, and it is what the document calls the inhomogeneous part.

The coboundary δf of an odd f : g → g is adjoint-valued, so it can only match γ_gb. The trivial-module part must be matched separately. Because the κ-linear Jacobiator and the coboundaries respect this splitting, the triviality condition is **block diagonal**:

  γ_gb + c_gb = δ(f, h) ⟺ γ_gb = δf and c_gb = δ_triv h,

where h : g → C is an odd functional and (δ_triv h)(X,Y) = −h([X,Y]). Cross terms vanish because κ·1 is central. So triviality holds iff both blocks are coboundaries.

**"Up to scalar".** The coboundary doc states the triviality equality holds "up to scalar". The set {λ·δf : λ ∈ C, f odd} equals im δ, since im δ is a vector subspace. The condition "γ = λδf for some λ" is therefore the same linear condition as "γ ∈ im δ". The scalar adds no freedom and no extra solutions.

A pointwise reading ("for each pair (X,Y), γ(X,Y) ∝ δf(X,Y) with a pair-dependent scalar") is nonlinear and is not a cohomological notion. It is still implied by our result, because exact equality γ = δf with λ = 1 satisfies it. So the positive answer holds under every reading of "up to scalar" considered here.

**Parity note on the document.** The document says gb has parity 1 because κ is odd. The parity-1 property belongs to the cochain γ (κγ has even bracket parity), not to the scalar gb. The scalar gb is consistent with [b,a] = −gb·κ as the parameter of an odd deformation, which is why f is taken odd. This is a wording issue in the document, not a change to the mathematics.

## 3. Model and conventions

**Oscillator realisation (as given in the document).** Generators: κ (odd, super-central, κ² = 0); a⁺, a⁻ (odd, {a⁻, a⁺} = 1); b_j⁺, b_j⁻ (even, [b_j⁻, b_j⁺] = 1). The deformed relation is [b_j^s, a^σ] = −gb_{σ,j,s}·κ, with 4n parameters gb_{σ,j,s}. All other brackets are undeformed.

**Algebra.** g is spanned by quadratic normal-ordered monomials x_p x_q modulo the central constant 1. This gives dim g = 2n²+5n+1 with dim g_0 = 2n²+n+1 and dim g_1 = 4n. The bracket is the super-commutator projected to the quadratic part.

**Deformed bracket.** Write μ = μ₀ + κγ + κ·c·1. Here γ_u is the κ-coefficient for gb_u = 1, and the constant c_u is taken in a splitting basis Q̃_a = Q_a + λ_a·1 in which the undeformed bracket has no constant term (λ is solved from the undeformed constants). Brackets of lifts are unchanged, but the constant term of the κ-quadratic part shifts: c'_u = c_u − γ_u·λ.

**Normal ordering.** The rewriting x_p x_q = (−1)^{|p||q|} x_q x_p + [x_p, x_q] is applied with κ placed leftmost. A κ generated by a contraction in the middle of a word is moved to the front with sign (−1)^{parity of the prefix}. An error in this sign was found during verification and fixed (§5).

## 4. Verification performed

For each n = 1, 2, 3 the script checks the following:

1. **Dimension and parity.** dim g and the even/odd split match 2n²+5n+1 and the document's table.
2. **Super-Jacobi, undeformed.** Maximum residual 0 (all n).
3. **Super-Jacobi, κ-linear.** The linearised Jacobiator of μ₀ + κγ_u vanishes for all units u (maximum residual 0 for all n). The κ-linear sign rules used are μ(X,κW) = (−1)^{|X|} κ μ₀(X,W) and μ(κW,X) = κ μ₀(W,X).
4. **Associativity of normal ordering** (n = 1, 2): 400 random triples each, 0 failures after the sign fix. Before the fix, 10 of 300 random triples failed.
5. **Sign-convention sanity.** δ(ad Z) = 0 for odd Z, so the document's δf formula is consistent with the algebra (maximum residual 0).
6. **Adjoint block.** Each γ_u ∈ im δ (residual ≤ 1e-14 in the projection). Explicit witnesses f_u with δf_u = γ_u are stored in the artifacts; the witness residual is ≤ 7e-14.
7. **Trivial-module block.** Each c'_u ∈ im δ_triv (residual ≤ 1e-15). Explicit witnesses h_u are stored; residual ≤ 5e-16.
8. **Controls.** Random cochains of the correct parity are *not* in im δ (adjoint residuals 15.6, 59.4, 136.3; trivial residuals 6.5, 11.6, 23.2 for n = 1, 2, 3). The membership test therefore discriminates.
9. **Joint W.** The combined linear system over the gb-space has rank 0 at every n, so W = C^{4n}.

**Example (n = 1, gb_{+,1,+} = 1).** The lift is λ = (−1/2 on a⁺a⁻, +1/2 on b₁⁺b₁⁻, 0 otherwise). Basis (n = 1): Z₀ = a⁺a⁻, Z₁ = a⁺b₁⁺, Z₂ = a⁺b₁⁻, Z₃ = a⁻b₁⁺, Z₄ = a⁻b₁⁻, Z₅ = (b₁⁺)², Z₆ = b₁⁺b₁⁻, Z₇ = (b₁⁻)². The adjoint witness f (odd, six nonzero entries, notation "Z_out ← Z_in") is

- Z₀ ← Z₁: 1/3
- Z₃ ← Z₅: −2/3
- Z₄ ← Z₀: 2/3
- Z₄ ← Z₆: −1/3
- Z₆ ← Z₁: 2/3
- Z₇ ← Z₂: 2/3

and δf reproduces γ_{+,1,+} to residual 3.5e-15. The trivial witness is h = ½ on Z₁ = a⁺b₁⁺ in the lifted basis, which reproduces the constant block to residual 3.5e-16. The exact values are stored in `artifacts/c_triviality_n1.json`.

## 5. Errors found during verification (corrected)

- **κ-sign in normal ordering.** The first implementation omitted the sign (−1)^{parity of prefix} when a κ from a contraction was moved to the front. This made normal ordering non-associative (10 failures in 300 triples) and gave κ-linear Jacobi residual 8. Both are fixed; the reported results use the corrected code only.
- **Constant term.** An early version dropped the κ·1 part without a lift correction, so the trivial-module block was never tested. The final run includes it, with the lift correction c' = c − γ·λ. The κ·1 block is also trivial, so the final answer is unchanged. The adjoint-only result (item 6 of §4) already gives the same conclusion.

## 6. Interpretation and limitations

- The result says that the inhomogeneous gb-deformations are pure gauge at the linear level: each one is an infinitesimal change of basis. This is consistent with the expectation that osp(2|2n) has no nontrivial inhomogeneous deformations of this kind, but I have **not** checked this against the literature. The literature was not consulted, because external web access and papers require human approval, which was not requested.
- The model includes only the deformed brackets [b, a] = −gb·κ, as the document specifies. If other gb-dependent relations were intended (for example in [a,a] or [b,b]), the analysis would have to be redone.
- Triviality here is at linear order in gb, which is exact since κ² = 0.
- Normalisations of gb (for example a rescaling of κ) rescale the γ_u and do not change triviality.
- The lift convention affects only the constant component c, not the adjoint component. The witnesses are given in the lifted basis; the constants are stored with the artifacts.
- I did not run the associativity test for n = 3 (the run is restricted to n = 1, 2). The Jacobi checks for n = 3 are complete.

## 7. Structured artifacts

Each `artifacts/c_triviality_n{n}.json` contains:
- `basis`: index, pair, label, parity of each basis element;
- `structure_constants_mu0_nonzero`: [i, j, k, value] for the undeformed bracket;
- `gamma_nonzero`: the adjoint 2-cochain for each gb parameter;
- `checks`: Jacobi residuals, δ(ad Z) residual, closure residual, parity violations, and the lift λ;
- `adjoint_block`: rank of δ, per-unit membership, and witnesses f;
- `trivial_module_block`: per-unit membership and witnesses h;
- `controls_random_cochains_residual`;
- `joint`: dim W, and the conclusion.

## 8. Final statement

Under the document's definitions, every inhomogeneous gb-deformation of C(n+1) = osp(2|2n) for n = 1, 2, 3 is trivial. The triviality conditions are therefore vacuous: the trivial locus is all of C^{4n}, with explicit odd witnesses f (adjoint block) and h (trivial block) recorded in the artifacts. The equality is exact, so the answer is the same under any reading of "up to scalar".
