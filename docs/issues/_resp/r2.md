**Decisions**
- Wrote `docs/json_schema_specification.md` (Schema 1 complete; Schemas 2-4 sections are added in I05-I07 as the issues request).
- Followed the mandatory unified rules: `algebra.m=1` with dimension formulas `2n^2+n+1` / `4n`; `oscillator_generators` has exactly `fermions` (m=1, `a_1_p`,`a_1_m`) and `bosons` (rank n); `central_elements` is top-level with `kappa` (parity 1) and `K` (parity 0); files `C_{n}_structure.json` with n = bosonic rank.

- Ambiguity: the doc says K is "identified with the scalar 1 and excluded from basis". I keep it only in `central_elements`; consequences for the deformation (a κ·K residue) are handled in I05 and I08.
- Compatibility table (section 1.9) documents key-by-key differences vs B(0,n)/B(m,n).
