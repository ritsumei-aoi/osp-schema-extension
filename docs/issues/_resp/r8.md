## Triviality Search Report

### 0. Method and the key interpretive decision

Tools: `src/triviality_search.py` (run: `python src/triviality_search.py`; tests in `tests/test_triviality_search.py`, `python -m pytest -q`: `100 passed`).
Data compared: Layer 3 (`C_{n}_evaluated*.json`) vs Layer 4 (`C_{n}_coboundary*.json`) for n=1,2,3 and the 5 profiles (plus/minus/alt/zero/single), then an independent search over **all** odd linear maps f (528 unknowns for n=3), not only the reference f of I07.

**The deformed bracket has two pieces** (see I05): `[X,Y]_γ = [X,Y]_0 + κ·γ(X,Y) + κK·γ_K(X,Y)`, where γ is g-valued and γ_K is a scalar (κ·1) outside g. The docs define γ: g⊗g→g and f: g→g, so the issue "is γ = δf?" is ambiguous about γ_K. I considered three readings and report all (decision: the analysis is run under each; my recommended reading is flagged in §3):

| reading | f maps to | γ compared | name |
|---|---|---|---|
| A | g | g-valued part only (γ_K ignored) | "g-part" |
| B | g ⊕ CK (K=1 central, even) | full κ-part | "extended" |
| C | g | full κ-part incl. γ_K | "strict" |

### 1. Case-specific evidence

For every one of the 15 (n, profile) pairs, `g-part mismatches Layer3 vs Layer4 = 0`: the g-valued γ equals δf **exactly** (entry by entry, exact rationals). Examples (γ_{XYZ} = (δf)_{XYZ}):
- n=1, plus (all gb=+1): γ(E_2del1_m, E_eps1_del1_mm → E_2del1_m) = −2 = δf; γ(E_2del1_m, E_eps1_del1_mp → H_2) = 2 = δf.
- n=1, single (only gb_{a_1^+,b_1^+}=1): γ(E_2del1_p, E_eps1_del1_pm → H_2) = 2 = δf; γ(E_2del1_p, E_eps1_del1_pp → E_2del1_p) = −2 = δf; γ(E_2del1_p, H_1 → E_eps1_del1_mp) = −2 = δf.
- n=2, alt: γ(E_2del1_m, E_eps1_del1_mp → H_3) = −2 = δf.
- zero profile: γ = 0, f = 0 (trivial control).

The scalar parts do **not** coincide for any non-zero profile: Layer 3 has κK-residues, Layer 4's δf (f g-valued) has none:

### 2. Rigorous analysis of the discrepancies

Pairs (X,Y) and coefficients, n=1, profile plus (γ_K = coefficient of κK): (H_1,E_eps1_del1_pp) −1; (H_1,E_eps1_del1_mm) +1; (H_2,E_eps1_del1_pp) +1/2; (H_2,E_eps1_del1_pm) −1/2; (H_2,E_eps1_del1_mp) +1/2; (H_2,E_eps1_del1_mm) −1/2; (E_2del1_p,E_eps1_del1_pm) +1; (E_2del1_p,E_eps1_del1_mm) +1; (E_2del1_m,E_eps1_del1_pp) −1; (E_2del1_m,E_eps1_del1_mp) −1; and the 10 transposed pairs (E_eps…, H/E_2del). Every such pair has [X,Y]_0 odd (one even, one odd generator), as required by parity (κ odd). δf has K-component 0 there because f was restricted to g.

Mathematical reason (verified numerically for all 15 cases, `k_identity_ok = True`, and in closed form below):
1. The reference f = −D comes from the shift b_j^s → b_j^s + κD(b_j^s). For an odd generator E_{σ,j,s} = a_σ b_j^s, D(E) = −a_σ D(b_j^s) contains a_σ a_{−σ}. In PBW form a_p a_m = h_a + ½ = (H_1 − H_2 − … − H_n + H_{n+1}) + ½·K and a_m a_p = 1 − a_p a_m has K-component ½ too. Hence f(E_{σ,j,s}) has the K-component **f_K(E_{σ,j,s}) = ½·gb_{σ,j,s}** (checked on all odd generators for n=1,2,3 with the alt profile, `test_fK_closed_form`).
2. For a K-valued part of f, K central gives (δf)_K(X,Y) = −f_K([X,Y]). The data satisfy exactly γ_K(X,Y) = −f_K([X,Y]) (all profiles). Example: [H_1,E_{ε+δ}] = 2E_{ε+δ} ⇒ γ_K = −2·½·gb_{p,1,p} = −gb_{p,1,p} (= −1 for plus, as in the table).
3. Since g = [g,g] (for the Lie superalgebras here; observed as: the K-residue map gb ↦ γ_K is injective, rank 4n for n=1,2,3), f_K is uniquely determined by γ_K. Thus no g-valued f can reproduce a non-zero γ_K, and the g-valued part cannot hide it either.
4. Why the residue exists at all: the quadratic Weyl-ordered elements close without a central term in the undeformed algebra, but the oscillator shift moves the odd generators by κ·a a'-type terms whose Weyl normal ordering contains the constant ½; this constant is κ·1 = κK.

### 3. Conjecture (necessary and sufficient conditions on gb)

Notation: gb ∈ C^{4n}, space of all deformations. Evidence = exact data for the 5 profiles and the full linear-algebra search (dimensions of the trivial subspace {gb : γ_gb ∈ Im δ}; "up to scalar" adds nothing because the condition is linear, so λγ = δf ⇔ γ = δ(f/λ)):

```
     trivial gb-subspace dim (of 4):  g-part=4  strict=0  extended=4   rank(gb→κK)=4
n=2: unknowns=176 rank(δ strict)=168 rank(δ ext)=176
     trivial gb-subspace dim (of 8):  g-part=8  strict=0  extended=8   rank(gb→κK)=8
n=3: unknowns=528 rank(δ strict)=516 rank(δ ext)=528
     trivial gb-subspace dim (of 12): g-part=12 strict=0  extended=12  rank(gb→κK)=12
```

**Conjecture (C(n+1), n ≥ 1; verified for n = 1,2,3; the mechanism in §2 is n-independent, so I expect it in general but have not written a proof for all n):**
- (A, B) The g-valued part of the deformation is trivial for **every** gb ∈ C^{4n}: no condition on gb (neither signs nor relations among the 4n parameters). Likewise the full deformation is trivial for every gb if f may take values in g ⊕ CK, with explicit f = −D (gb_{σ,j,s} ↔ c_{j,s,−σ} is a bijection between the 4n deformation parameters and the 4n shift parameters). The trivial subspace is the whole parameter space; the sign profiles plus/minus/alt/single are all trivial.
- (C) With f restricted to g and the κK residue included, the deformation is trivial **iff gb = 0** (all 4n parameters vanish): the residue map is injective and f_K = ½gb is forced.

Reading-dependence: which of A/B vs C is the "intended" notion is the main open question I could not settle from the documents (they say γ: g⊗g→g, and K "is excluded from the basis", which favours C, but they also say K=1 ∈ U(A), which makes the κ-central term a legitimate part of the bracket and favours B). I judge **B** the natural one: the κK term is removable by redefining odd generators X → X + ψ(X)κ, which keeps the grading and the Lie superalgebra structure (odd + odd κ). Recommended answer for downstream use: *trivial for every gb* (reading A/B); *under the strict reading, gb = 0 only*. A human decision is needed on the reading before this is cited.

### 4. Limitations / caveats
- gb treated as ordinary scalars (parity-1 ambiguity, I05). If gb were Grassmann-odd the bracket would be parity-inconsistent, so I did not pursue it.
- γ depends on the lift of generators into the oscillator algebra (fermion-first PBW words, I01); a different lift changes γ by a coboundary but can move the κK residue, so the strict-reading conclusion (C) is lift-dependent, whereas A/B are not.
- The numerical rank computations use floating-point `matrix_rank`/`lstsq` (entries are small rationals; ranks are far from tolerance boundaries). The exact statements (g-part equality of Layer 3 and 4, K-identity, f_K closed form) are in exact `Fraction` arithmetic.
- The extended-map kernel is trivial (rank 4n+… = all unknowns), i.e. f is unique in reading B; in reading A the g-valued f is unique only modulo odd inner derivations ad(odd), dimension 4n (kernel of δ: 32−28 = 4, 176−168 = 8, 528−516 = 12 = 4n).
