#### Representative gb assignments (options considered)
- *Option A*: only `all_plus` (minimal, as the issue's example).
- *Option B (chosen)*: a small family of sign profiles that probes different structures of the 2×2n gb matrix,
  so I08 has evidence across qualitatively different cases rather than one point:

| profile | definition of gb_{σ,j,s} | purpose |
|---|---|---|
| `zero` | 0 | undeformed control (must be trivial) |
| `all_plus` / `all_minus` | +1 / −1 | issue's example; linearity check (all_minus = −all_plus) |
| `row_sign` | +1 if σ=+ else −1 | distinguishes a_1^+ and a_1^- rows |
| `col_sign` | +1 if s=+ else −1 | distinguishes b^+ and b^- columns |
| `checkerboard` | +1 if σ=s else −1 | |
| `index_parity` | (−1)^{j+1} | varies with boson index (non-trivial only for n≥2) |
| `single_p_1_p` | only gb_p_1_p = 1, others 0 | isolates one parameter (sparse case) |
| `random_signs` | seeded random ±1 (seed 20261006+n) | generic case |

#### Implementation / output
`src/C_evaluate.py` reads `C_{n}_gamma.json`, substitutes each profile, and writes `data/C_{n}_evaluated.json`
(format appended to the spec as "Schema 3"). Each profile stores its gb values (dict and 2×2n matrix),
the evaluated γ entries (`gamma`) and the evaluated K components (`central_component`).
```
$ python3 src/C_evaluate.py
n=1: -> data/C_1_evaluated.json  mismatching profiles vs Schema 2: 0
   zero:0+0K, all_plus:92+20K, ..., single_p_1_p:23+6K, random_signs:92+20K
n=2: -> data/C_2_evaluated.json  mismatching profiles vs Schema 2: 0
   zero:0+0K, all_plus:568+84K, ..., single_p_1_p:67+10K, random_signs:568+84K
n=3: -> data/C_3_evaluated.json  mismatching profiles vs Schema 2: 0
   zero:0+0K, all_plus:1660+180K, ..., single_p_1_p:131+14K, random_signs:1660+180K
$ python3 -m pytest -q
31 passed
```
Observation: every symbolic γ coefficient involves exactly one gb parameter, so all full ±1 profiles have the same support (no cancellations).

#### Consistency with Schema 2
`check_against_schema2` re-reads the written JSON and recomputes Σ coeff·gb from `C_{n}_gamma.json` for every entry of every
profile: 0 mismatching profiles for n=1,2,3, no missing/extra entries. Tests also check zero-profile emptiness and exact linearity (all_minus = −all_plus).
