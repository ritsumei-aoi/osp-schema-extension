### Response

#### Representative gb assignments (decision)
Because γ is **linear** in the $4n$ parameters (I05), a single profile cannot exhibit the dependence on
the gb matrix, so seven deterministic profiles are generated; `all_plus` is the default
(`C_{n}_evaluated.json`, as required by the issue's file name) and the others are
`C_{n}_evaluated_{profile}.json` (following the `_<gb>` suffix of `B0n_schema_v5.md`):

| profile | gb values |
|---|---|
| `all_plus` (default) | all $+1$ |
| `all_minus` | all $-1$ |
| `row_sign` | $a_1^+$ row $+1$, $a_1^-$ row $-1$ |
| `column_alternating` | $b_k^+$ columns $+1$, $b_k^-$ columns $-1$ |
| `unit_a1p_b1p` | only $\mathrm{gb}_{+,1,+}=1$ |
| `unit_a1m_b1m` | only $\mathrm{gb}_{-,1,-}=1$ |
| `generic` | distinct primes $2,3,5,\dots$ (no accidental cancellations) |

Alternative considered: random rational values with a fixed seed — rejected in favour of
reproducible, human-readable values; `generic` already plays the "no coincidence" role.

#### Implementation
`src/C_evaluate.py` reads `C_{n}_gamma.json` (Schema 2), evaluates every linear form, and writes
Schema 3 with `gb_profile` (name, values, $2\times2n$ matrix), `evaluated_gamma` (non-zero numeric
γ coefficients) and `evaluated_structure_constants` (every triple with its undeformed `coeff` and its
`kappa_coeff`, i.e. the full deformed bracket $[X,Y\}_0+\kappa\gamma(X,Y)$ at that profile).
**Consistency with Schema 2** is checked by an independent route: γ is recomputed directly in the
oscillator engine with the numeric gb substituted (`evaluate_direct`) and compared coefficient-by-coefficient
with the Schema 2 evaluation (`matches_direct_recomputation` stored in the file).
`tests/test_C_evaluate.py`: 29 tests, all passing in 5.5 s (per n × profile consistency, record format, default-file identity,
hand values, on-disk = regenerated).

```
n=3 (same five profiles) : 1660 ; unit profiles : 131      — all schema2-consistent=True
ALL PASS        (21 files written, data/ is 4.2 MB in total)
```
Note: the ±1 profiles have exactly the same number of non-zero coefficients as `generic` — expected, since
every γ coefficient is a single monomial $c\cdot\mathrm{gb}_{\sigma,k,s}$ (no two gb's ever combine
in one coefficient — verified: 0 coefficients with more than one gb symbol in all three Schema 2 files),
so sign changes can never cancel a coefficient.
