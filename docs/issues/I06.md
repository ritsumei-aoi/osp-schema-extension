### Response

**Script:** `src/C_evaluate.py`. Substitutes concrete values for the 4n gb parameters into the
symbolic Schema-2 γ and emits the evaluated deformation.

**(1) Representative gb profiles** (the 4n parity-1 parameters given concrete signs):
- `all_plus` — every $\mathrm{gb}=+1$ (the representative profile).
- `fermion_sign` — $\mathrm{gb}_{\sigma,j,s}=+1$ if $\sigma=+$, else $-1$ (a sign profile used to
  exercise sign dependence for I08).

**(2) Evaluation + independent cross-check.** For each profile and each basis pair the script both
substitutes the symbolic γ *and* independently recomputes the deformed bracket with a **numeric** gb
hook, then compares. This is the Schema-2 consistency check.

**(3) Outputs.** `data/C_{1,2,3}_evaluated.json`, each with a `evaluations` block per profile
(`gb_values`, `evaluated_gamma`, `num_nonzero`, `consistency_with_schema2`). Under `all_plus`:
62 (n=1) / 337 (n=2) / 936 (n=3) nonzero evaluated γ records.

**Consistency with Schema 2:** `consistency_with_schema2 = True` for every profile and every n
(symbolic-substitution equals numeric recompute). Verified also in
`tests/test_C_layers34.py::test_evaluated_consistency` (6 passed).

All completion criteria met.
