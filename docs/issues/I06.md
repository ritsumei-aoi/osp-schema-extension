### Response

**Implementation:** `src/C_evaluate.py`

**Assignment chosen:** all gb = +1 (uniform sign profile). All 4n parameters set to 1.
Decision rationale: The uniform assignment is the simplest representative, avoids accidental cancellations, and produces the maximal-support gamma. An alternating sign profile (gb_{σ,j,s} = σ·s) is also defined in the script for future use.

**Consistency with Schema 2:**
- All 46 / 284 / 830 symbolic gamma entries remain non-zero under gb=1.
- Schema 3 entries are a direct linear evaluation of Schema 2 symbolic expressions.

**Results:**
```
C(2) = osp(2|2), n=1: 46 non-zero evaluated entries
C(3) = osp(2|4), n=2: 284 non-zero evaluated entries
C(4) = osp(2|6), n=3: 830 non-zero evaluated entries
```
