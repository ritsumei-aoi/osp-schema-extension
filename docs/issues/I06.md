### Response

**Decision and implementation:** Implemented `src/C_evaluate.py` and documented the Schema 3 shape in `docs/json_schema_specification.md`. Considered using multiple sign profiles versus a single uniform assignment; chose `all_plus` (`gb=+1` for every parameter) because it is simple, reproducible, and directly comparable across ranks. The evaluator retains Schema 1 structure constants and emits the exact substituted gamma correction separately, combining equal `(X,Y,Z)` terms and dropping zero sums.

The `gb` parameters are declared odd in Schema 2, so assigning ordinary numeric `+1` is only a formal specialization. Schema 3 preserves the `formal_only` parity status and warning rather than claiming the parity conflict is resolved.

**Verification:** Generated `data/C_1_evaluated.json`, `data/C_2_evaluated.json`, and `data/C_3_evaluated.json`. The all-plus assignment contains 4, 8, and 12 parameter values; evaluated corrections contain 60, 334, and 932 terms, respectively. Tests independently re-sum the Schema 2 terms, compare committed outputs with the evaluator, and confirm source algebra and structure constants are unchanged. `pytest -q` passed all 33 tests; `git diff --check` passed.
