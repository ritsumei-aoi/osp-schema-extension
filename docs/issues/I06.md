### Response

#### Implementation
- `src/C_evaluate.py`: substitutes gb values into the symbolic γ of Schema 2 and writes
  Schema 3 files (`docs/json_schema_specification.md` §3). The representative assignment is
  `all_plus` (all 4n parameters = +1) → `data/C_{n}_evaluated.json`. Five further profiles are
  written as `data/C_{n}_evaluated_<profile>.json`: `fermion_sign` (+1 on the `a_1^+` row,
  −1 on the `a_1^-` row), `boson_sign` (+1 on `b^+` columns, −1 on `b^-` columns),
  `single_a1p_b1m` (one parameter), `row_a1p_only`, `zero` (undeformed sanity profile).
  The profile set was chosen so that I08 can separate the dependence on the fermionic row,
  the bosonic column, and individual parameters.
- `tests/test_C_evaluate.py`: profiles have 4n parameters; each Schema 3 file equals Schema 2
  with substitution; antisymmetry and super-Jacobi on L hold for the numeric γ; explicit n=1 values.

#### Consistency with Schema 2
`check_consistency_with_schema2` verifies for every file: (i) the stored evaluated γ equals the
exact substitution into the Schema 2 linear forms, (ii) super-antisymmetry, (iii) super-Jacobi
of the numeric deformed bracket on L = g ⊕ κ(g ⊕ K).
