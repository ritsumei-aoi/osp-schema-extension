#### Decisions

- **Representative assignment**: all 4n parameters gb = +1
  (`gb_assignment_name: "all_plus_one"`). Rationale: it excites every gb
  channel simultaneously with unit weight, so any structural discrepancy
  between deformation and coboundary in I08 would be visible; sign-profile
  variations are explored programmatically in I08 via
  `evaluate_gamma(n, assignment)`, which accepts arbitrary rational
  assignments (the zero assignment is unit-tested to give γ ≡ 0).
- Schema 3 format follows `docs/json_schema_specification.md`: flat
  `evaluated_gamma` records `{X, Y, Z, coeff}` with exact-rational string
  coefficients, plus the `gb_assignment` used and refs to Schemas 1–2.
