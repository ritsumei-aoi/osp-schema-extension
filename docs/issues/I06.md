### Response

Implemented `src/C_evaluate.py`.

**Representative profile chosen**: `all_plus_one`, which sets every one of
the 4n gb parameters to +1. Rationale: this profile is the simplest
nontrivial substitution, and is sufficient to expose the triviality
structure (I08 will relate it to the coboundary target).

An alternative `fermion_parity_signs` profile (sign = +1 if σ matches s,
else −1) is also provided in the module for sensitivity analysis.

Consistency with Schema 2: `evaluate_profile` directly substitutes sympy
symbols; the entry list is the subset of Schema 2 entries whose coefficient
does not vanish after substitution. For `all_plus_one` on n=1,2,3 every
Schema 2 entry survived, giving the same counts (46 / 282 / 836).
