### Response

**Decisions**
- Canonical assignment: `all_plus` (every one of the 4n gb = +1) → `data/C_{n}_evaluated.json`, as the issue suggests.
- Because I08 needs trivial/non-trivial contrasts, six more profiles are written to `data/C_{n}_evaluated_<profile>.json`: `all_minus`, `zero`, `sigma_p_only`, `sigma_m_only`, `alternating`, `unit_first`. Option considered: one file with several profiles inside; rejected to keep one-assignment-per-file (Schema 3 as described in the spec).
- Schema 3 layout documented in `docs/json_schema_specification.md` (spec was silent on Schema 3 for C(n+1); designed as: gb_assignment + evaluated gamma list, targets include `K`).

**Implementation**: `src/C_evaluate.py` substitutes the gb values into the symbolic Schema 2 JSON and, in the same call, recomputes γ directly in the deformed oscillator algebra; `build_schema3` raises if the two differ.
