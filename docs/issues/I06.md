### Response

**Status**: done.

**Representative assignment (decision).** All $4n$ parameters are set to $+1$. Reasons: it is the simplest profile that gives every gb label a non-zero role, it is easy to audit, and it is the example the issue names. Other profiles are not used here. I08 evaluates arbitrary profiles with the same code, so the representative choice does not limit the analysis.

**Method.** `src/C_evaluated.py` reads only the JSON files: Schema 1 for $\kappa$-free coefficients and Schema 2 for the $\kappa$-coefficients (the $\mathfrak g$-valued entries and the $K$-components). It substitutes gb values and writes `data/C_{n}_evaluated.json` (Schema 3). Each entry records `coeff_kappa0` (Schema 1) and `coeff_kappa1` (the evaluated $\gamma$).

**Results.**

| $n$ | evaluated $\kappa$-entries | $K$-components | Schema 2 consistency (independent summation) |
|---|---|---|---|
| 1 | 132 | 20 | 92 entries compared, 0 mismatches |
| 2 | 766 | 84 | 568 entries compared, 0 mismatches |
| 3 | 2188 | 180 | 1660 entries compared, 0 mismatches |

Example ($n=1$, all gb $=1$), read from the file. For $[E_{\varepsilon+\delta_1}, E_{-\varepsilon+\delta_1}]$:
the $\kappa$-free part is $2\,E_{2\delta_1}$ (`coeff_kappa0` $=2$), and the deformation adds $E_{-\varepsilon+\delta_1}$ and
$E_{\varepsilon+\delta_1}$ with `coeff_kappa1` $=1$ each. These are the entries with $\kappa_0=0$ or $\kappa_0\ne0$ and $\kappa_1\ne0$ that the deformation contributes.

**Checks.** The $\mathfrak g$-valued cocycle and the super-Jacobi defect in the algebra were already verified in I05 for every gb tag, which covers all $4n$ parameters. The evaluated file is a sum of those verified tags at gb $=1$, so it inherits that result.

**Schema 3 format.** Matches `docs/json_schema_specification.md` §4, with an extra field `K_components` recording the $K$-part. Coefficients are exact strings.
