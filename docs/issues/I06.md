#### Implementation

**Script**: `src/C_evaluated.py`

**Representative assignment**: All gb parameters set to +1 ("all_ones" profile).
- gb_{sigma,j,s} = 1 for all sigma ∈ {p,m}, j=1..n, s ∈ {p,m}
- This gives a canonical, non-degenerate deformation for analysis.

The evaluated gamma entries are:
  coeff(X,Y,Z) = sum_lbl 1 * gamma_{XYZ,lbl}

The combined bracket stores both the undeformed structure constants (source="structure")
and the kappa*gamma terms (source="kappa_gamma").

#### Generated Files

- `data/C_1_evaluated.json`: 40 structure + 96 kappa_gamma = 136 total entries
- `data/C_2_evaluated.json`: 198 structure + 576 kappa_gamma = 774 total entries
- `data/C_3_evaluated.json`: 528 structure + 1672 kappa_gamma = 2200 total entries

#### Consistency Check

All 3 cases pass:
- All generator labels (X,Y,Z) are in the Schema 1 basis.
- Evaluated gamma entries have correct parity: p(gamma(X,Y)[Z]) = p(X)+p(Y)+1 (mod 2).
