### Response

#### Representative assignment and profiles
Options considered: (a) a single all-$+1$ assignment; (b) all $2^{4n}$ sign patterns (16 / 256 /
4096 files — rejected as noise: γ is linear in gb, so sign patterns are not independent evidence);
(c) **a small set of structurally distinct profiles (chosen)**: `all_plus` (representative, written to
`C_{n}_evaluated.json` as required), `all_minus`, `row_sign` (sign depends on $a_1^\pm$),
`column_sign` (sign depends on $b^\pm$), `single_a1p_b1p` (one parameter), `generic` (distinct
rationals of mixed sign, to expose any accidental cancellation) and `zero` (control). Each is written
to `C_{n}_evaluated_<profile>.json`. These give I08 both sign-type evidence and a generic point.

#### Implementation
`src/C_evaluate.py`: `profiles(n)`, `evaluate_gamma` (substitutes `coeff_terms` of Schema 2),
`recompute_gamma` (independent path: oscillator algebra run with numeric gb via the new
`gb_values` option of `OscillatorAlgebra`/`CBasis`), `build_schema3`, `write_schema3`,
`check_profile`. Schema 3 layout documented in `docs/json_schema_specification.md` §3:
`gb_profile` (values + 2×2n matrix), `evaluated_structure.deformed_structure_constants`
(`coeff_0` + `coeff_kappa`·κ per `Z`) and `evaluated_structure.gamma_evaluated` (κ-part only).

#### Consistency with Schema 2
For every n and profile the substituted γ equals the independently recomputed γ (exact rationals).
