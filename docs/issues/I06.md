#### Decisions and Results

**gb assignment**: Chose the "all_plus" profile (all gb parameters = +1) as the representative assignment. This is the simplest non-trivial case and allows clean comparison with the coboundary in I07/I08.

**Implementation**: Created `src/C_evaluated.py`:
- `build_gb_assignment(n, profile)`: Builds a concrete gb assignment dictionary.
- `evaluate_gamma(gamma_data, gb_assignment)`: Substitutes numerical values into symbolic gamma coefficients, aggregating multiple gb contributions per generator pair.
- `generate_schema3_json(n, profile)`: Produces Schema 3 JSON.
