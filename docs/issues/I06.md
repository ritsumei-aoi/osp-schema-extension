#### 1. Representative assignment (Requirement 1)

Representative profile **`all_plus`**: all $4n$ parameters $\mathrm{gb}_{\sigma,k,s} = +1$, written to
`C_{n}_evaluated.json`. Because the symbolic $\gamma$ is linear in gb and every entry of Schema 2 involves a
single gb symbol, `all_plus` exercises every term without cancellation (112 / 652 / 1840 terms, exactly the
symbolic counts). To support the triviality search in I08, four further profiles are generated as
`C_{n}_evaluated_<profile>.json`:

| profile | assignment | purpose |
|---|---|---|
| `zero` | all 0 | control (undeformed; trivially trivial) |
| `single` | only $\mathrm{gb}_{+,1,+}=1$ | isolates one parameter |
| `alternating` | $+1$ if $\sigma=s$, else $-1$ | mixed signs |
| `random` | deterministic values in $\{-2,-1,1,2\}$ | generic non-sign values |

Alternative considered: a one-hot profile for *each* of the 4n parameters (up to 12 files per n). Rejected as
redundant because Schema 2 already stores the exact linear dependence on every parameter; `single` plus the
symbolic data covers that.

#### 2. Substitution script (Requirement 2)

`src/C_evaluate.py`: reads `C_{n}_gamma.json` and `C_{n}_structure.json`, substitutes the profile values
into `linear_form` with exact `Fraction` arithmetic, merges equal $(X,Y,Z)$ keys, drops zeros, and also emits
the merged `deformed_structure_constants` ($[X,Y\}_\gamma = \sum_Z(\mathrm{coeff}_0 + \kappa\,\mathrm{coeff}_\kappa) Z$).

#### 3. Schema 3 format (Requirement 3)

Defined in `docs/json_schema_specification.md` (Schema 3 section): `layer`, `profile`, `gb_assignment`,
numeric `gb_matrix.values`, `evaluated_gamma.entries`, `deformed_structure_constants.entries`, `summary`.
