### Response

**Files**: `src/C_evaluate.py` (substitution and Schema 3 writer), output `data/C_1_evaluated.json` (58 nonzero entries), `data/C_2_evaluated.json` (330), `data/C_3_evaluated.json` (926). These are the same entry counts as Schema 2, so no entry cancelled at this profile.

**Representative gb assignment (decision)**

- Options considered: (a) all $\mathrm{gb}=+1$; (b) all $-1$; (c) mixed sign profiles, e.g. alternating in $k$ or in $\sigma$; (d) a single nonzero parameter (a "basis" profile).
- Chose (a) $\mathrm{gb}\equiv+1$ for the Layer 3 file. Reason: it is the simplest assignment that makes every gb-term contribute with the same sign, so no cancellation can hide a discrepancy. Profile (d) is useful for the I08 analysis, not as the representative. The profile is recorded inside the file (`profile.name = all_plus_one`, `profile.gb` with all four labels for each $n$), so the file can be reproduced.
- Caveat: a single point of the 4n-dimensional gb space is one sample. I08 studies the whole space.

**Schema 3 format**: `schema_version`, `layer`, `algebra`, `profile` (name and the full gb map), `evaluated_gamma` (list of `{X, Y, Z, coeff}` with $i\le j$ and nonzero coefficients, including `Z: "K"`), `metadata` (generator and source file).

**Consistency check (run output of `python3 src/C_evaluate.py`)**

```

n=2: wrote C_2_evaluated.json: 330 nonzero entries (42 with Z=K); Schema 2 vs engine agree: True
```

- *Schema 2 vs Layer 3*: each evaluated coefficient was computed from the Schema 2 JSON on disk (linear sum over gb terms). It was then compared, entry by entry, with an independent recomputation from the oscillator engine. The two agree exactly for $n=1,2,3$.
- *Format*: the same $\{X,Y,Z,\text{coeff}\}$ list as Schema 1 is used, with $Z\in\mathfrak g\cup\{K\}$.

**Note**: The K-entries are carried into Schema 3 unchanged. The I07 coboundary has no K-component (see I05), so at this profile $\gamma$ has K-components and cannot equal any $\delta f$ with $f:\mathfrak g\to\mathfrak g$. This is analysed in I08.
