### Response

#### 1. Representative gb assignments (Requirement 1)
Seven named profiles are implemented in `src/C_evaluate.py::profile_values` (values are exact rationals):

| profile | file | assignment |
|---|---|---|
| `ones` (**representative**) | `C_{n}_evaluated.json` | all $4n$ parameters $=+1$ |
| `alternating` | `C_{n}_evaluated_alternating.json` | $+1$ if the $a_1$-sign equals the $b_k$-sign, else $-1$ |
| `plus_only` | `…_plus_only.json` | $\mathrm{gb}_{a_1^+,\cdot}=1$, $\mathrm{gb}_{a_1^-,\cdot}=0$ |
| `minus_only` | `…_minus_only.json` | $\mathrm{gb}_{a_1^-,\cdot}=1$, $\mathrm{gb}_{a_1^+,\cdot}=0$ |
| `single` | `…_single.json` | only $\mathrm{gb}_{a_1^+,b_1^+}=1$ |
| `conjugate` | `…_conjugate.json` | $\mathrm{gb}_{a_1^+,b_k^\pm}=\pm k$, $\mathrm{gb}_{a_1^-,b_k^\pm}=\mp k$ |
| `mixed` | `…_mixed.json` | fixed pattern in $\{1,-1,\tfrac12,-2\}$ |

Options considered: a single all-ones file only (minimal, as suggested in the issue) vs. several sign profiles. Chosen: all-ones as the default file name plus profile variants, because I08 must contrast trivial/non-trivial cases and needs more than one data point; row-only and single-parameter profiles isolate the contribution of individual gb entries (γ is linear in gb).

#### 2. Script (Requirement 2)
`src/C_evaluate.py` loads `C_{n}_gamma.json`, evaluates every linear form at the assignment (dropping zeros), and writes Schema 3 per `docs/json_schema_specification.md` §3: `profile`, `gb_assignment`, `evaluated_gamma` (`{X,Y,Z,coeff}` with `Z` possibly `K`), and `deformed_structure_constants` (Schema 1 entries with `kappa_order: 0` followed by the evaluated γ with `kappa_order: 1`, i.e. the complete deformed bracket $[X,Y]_\gamma$ at the chosen gb).

```

C(2) profile single      :    29 non-zero gamma entries (6 with Z=K);  ... -> data/C_1_evaluated_single.json
C(3) profile ones        :   652 non-zero gamma entries (84 with Z=K); ... -> data/C_2_evaluated.json
```

#### 3. Schema 3 format (Requirement 3) and consistency with Schema 2
* **Independent recomputation**: for every file the script recomputes γ *directly* in the deformed oscillator algebra with the numeric gb values (`direct_gamma`, which never looks at the Schema 2 linear forms) and raises if the result differs. All 21 files match (`consistency.direct_recomputation_matches: true`).
* `tests/test_C_evaluate.py` (25 tests): for every (n, profile) the JSON `evaluated_gamma` equals the evaluation of the Schema 2 forms at the stored `gb_assignment`; `kappa_order: 0` entries equal Schema 1 exactly; the `single` profile equals the `gb_a1p_b1p` column of Schema 2; direct recomputation re-run for n=1,2.
