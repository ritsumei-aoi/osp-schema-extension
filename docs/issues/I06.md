#### Representative gb assignments (decision)
Options considered: (a) a single all-+1 profile; (b) all $2^{4n}$ sign profiles (up to $2^{12}=4096$ for n=3, too many to store usefully); (c) a small set of structured profiles that probe different symmetries. Chosen (c), 8 profiles
per rank, all values in {−1, 0, +1}:

| name | assignment | purpose |
|---|---|---|
| `zero` | all 0 | undeformed baseline (must give empty γ) |
| `all_plus` / `all_minus` | all ±1 | the example in the issue; their pair tests linearity |
| `single_p1p` | only $\mathrm{gb}_{+,1,+}=1$ | isolates one parameter (sparse γ) |
| `fermion_sign` | $+1$ for $a_1^+$ row, $-1$ for $a_1^-$ row | sign profile breaking fermion symmetry |
| `boson_sign` | $+1$ for $b_j^+$ columns, $-1$ for $b_j^-$ | sign profile breaking boson symmetry |
| `alternating_j` | $(-1)^{j+1}$ | mode-dependent signs (trivially uniform for n=1) |
| `random_signs` | seeded random ±1 (seed 20261006+n) | generic profile |

#### Implementation and output
`src/C_evaluate.py` reads `C_{n}_gamma.json`, substitutes each profile and writes `C_{n}_evaluated.json` with
`profiles: [{name, description, gb_values, gamma: [{X,Y,Z,coeff}]}]` (spec §3; rational `coeff`, `Z="K"` for the central part).
