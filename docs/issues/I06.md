### Response

**Implementation**: `src/C_evaluate.py`

**gb assignment**: All 4n parameters set to +1 (representative uniform assignment).

**Algorithm**: Parse the linear `coeff_expr` strings from Schema 2 gamma entries, substitute gb_label → 1, sum the rational coefficients using `fractions.Fraction`. Entries evaluating to 0 are dropped.

**Results**:
```
n=1: 56 evaluated_gamma entries (all non-zero after gb=1 substitution)
n=2: 322 evaluated_gamma entries
n=3: 912 evaluated_gamma entries
```

Sample (n=1, gb=+1 evaluation):
```
(H_1, E_2del1_p)       -> E_eps1_del1_mp: 2
(H_1, E_2del1_p)       -> E_eps1_del1_pp: 2
(H_1, E_eps1_del1_pp)  -> H_2: 2, H_1: 1, E_2del1_p: -1
(H_1, E_eps1_del1_pm)  -> H_2: 2, H_1: 1, K: 1, E_2del1_m: -1
```

K (even central element) appears in gamma when some brackets pick up a scalar. This is consistent with H_{n+1} containing the -1/2 constant.

**Consistency**: All evaluated Z generators are valid basis members; entry count equals Schema 2 count (no gb expression evaluates to exactly 0 at uniform gb=+1).
