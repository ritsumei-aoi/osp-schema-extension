### Response

**Decision:** Selected a uniform all-`+1` assignment for every gb parameter.
It is a simple, reproducible nonzero sign profile and covers the complete
2×2n matrix for each rank. Schema 3 keeps ordinary and deformation terms
separate using `kappa_order` 0 and 1, preserving the nilpotent extension
instead of numerically collapsing κ.

**Results:** Added `src/C_evaluate.py`, documented the Schema 3 format, and
generated `data/C_1_evaluated.json`, `data/C_2_evaluated.json`, and
`data/C_3_evaluated.json`. The evaluator checks the source algebra/rank,
Schema 1 filename, gb matrix dimensions, and every symbolic parameter
reference before emitting evaluated coefficients.

**Verification:** `python src/C_evaluate.py` generated all three outputs.
The assigned parameter counts are 4, 8, and 12; each output combines the
Schema 1 constants and substituted Schema 2 terms, with exact rational
coefficients and κ-order preserved.
