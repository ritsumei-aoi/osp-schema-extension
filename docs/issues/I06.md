### Response

#### 1. Parameter Assignment Design
- Selected canonical representative profile: **`all_plus_one`**, where all $4n$ deformation parameters are set to $+1$:
  $$\mathrm{gb}_{a_1^\sigma, b_j^s} = +1 \quad \forall \sigma \in \{p, m\},\ j \in \{1, \dots, n\},\ s \in \{p, m\}.$$
- The script `src/C_evaluated.py` also accepts arbitrary user-specified parameter maps.

#### 2. Implementation
- Implemented `src/C_evaluated.py`:
  - `evaluate_gamma(n, param_values)`: substitutes numeric values into $\gamma_{XY, Z, \text{param}}$ and computes the net evaluated cocycle $\gamma(X, Y) = \sum_Z c_{XY}^Z Z$.
  - `generate_evaluated_json(n, profile_name, param_values)`: formats output matching Schema 3 specifications (`schema_version`, `algebra`, `evaluation`, `basis`, `parity`, `evaluated_gamma`, `metadata`).
  - `save_evaluated_json(n, output_dir)`: saves `C_{n}_evaluated.json` in `data/`.

#### 3. Generated Schema 3 Files in `data/`
- `data/C_1_evaluated.json`: $C(2)$ ($4$ evaluated non-zero brackets under $\mathrm{gb}=+1$).
- `data/C_2_evaluated.json`: $C(3)$ ($8$ evaluated non-zero brackets under $\mathrm{gb}=+1$).
- `data/C_3_evaluated.json`: $C(4)$ ($12$ evaluated non-zero brackets under $\mathrm{gb}=+1$).

#### 4. Verification & Testing
Added test suite `tests/test_c_evaluated.py`:
- Verified exact sum equivalence against Schema 2 (`C_{n}_gamma.json`) for all non-zero terms.
- Verified graded anti-symmetry $\gamma(Y, X) = -(-1)^{p(X)p(Y)} \gamma(X, Y)$ on evaluated brackets.
- Verified parity grading rule $p(Z) \equiv (p(X) + p(Y) + 1) \pmod 2$.
