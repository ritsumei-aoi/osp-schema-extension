### Response

**Decisions**
- Representative gb assignments (4n parameters each), one file per n with several profiles:
  - `all_plus_one`: every gb = +1 (primary, the default profile, as suggested in the issue).
  - `all_zero`: every gb = 0 (undeformed; γ vanishes). Included as the trivial reference.
  - `sign_by_boson`: gb = +1 for s = p and −1 for s = m. This mixes signs, so it tests a profile that is not all-equal.
- Options considered: one profile only (rejected, since I08 needs both a clear reference and a second case to compare); a random profile (rejected, since it is not reproducible from the notes; the three profiles are fixed and documented in the file).
- Schema 3 keeps the Schema 1 basis (`basis_ref`) and the Schema 2 references. Each profile stores the gb values and the nonzero evaluated γ entries. Zero coefficients are dropped.

**Execution log**
