### Response

**Agent**: Claude Sonnet 4.6 | **Date**: 2026-10-09

**Design decision**: Uniform assignment gb_{σ,j,s} = 1 for all 4n parameters. This is the
simplest non-trivial evaluation ("all-ones" profile) that activates the full deformation.
The script allows arbitrary assignments for future experiments.

**Implementation**: `src/C_evaluated.py`
- `make_gb_assignment(n, value)`: generates the uniform assignment dict
- `evaluate_gamma(s1, s2, gb_assignment)`: substitutes values into Schema 2 gamma_coefficients
  by computing sum_{gb} gb_val * coeff for each (X,Y,Z) triple
- `build_schema3(n, gb_assignment)`: assembles Schema 3 JSON with `gb_assignment` field

**Output** (all gb = 1):

|---|---|
| 1 |  96 |
| 2 | 576 |

Note: With uniform all-1 assignment, the entry count equals Schema 2 (no cancellations
across different gb parameters for this particular assignment).

**Consistency with Schema 2**: verified by construction — Schema 3 is a linear combination
of Schema 2 rows with the assigned coefficients. All X, Y, Z labels are preserved from
Schema 2, ensuring basis membership and parity conservation carry over directly.
