### Response

**Implementation: `src/C_evaluate.py`**

**gb assignment (representative):** All 4n gb parameters set to +1.

The `evaluate_coeff_expr` function parses the symbolic coeff_expr strings from Schema 2 and evaluates them numerically (using Fraction arithmetic).

**Results:**

| n | gb params | gamma terms (symbolic) | gamma terms (evaluated at gb=1) |
|---|---|---|---|
| 1 | 4 | 54 | 54 |
| 2 | 8 | 344 | 344 |
| 3 | 12 | 1148 | 1148 |

All 54/344/1148 symbolic gamma terms remain non-zero after evaluation at gb=1, confirming the evaluation is consistent.

**Consistency with Schema 2:** The evaluated_gamma count matches the symbolic count because all symbolic terms involve exactly one gb parameter (linear) and gb=1 does not zero out any.

Sample (n=1, all gb=1):

- $\gamma(E_{\varepsilon+\delta_1}, H_1) \to H_2$: coeff = -2
- $\gamma(E_{\varepsilon+\delta_1}, H_1) \to E_{2\delta_1}$: coeff = +1
