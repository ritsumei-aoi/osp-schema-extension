### Response

**Script**: `src/C_evaluate.py`

**gb assignment**: All gb parameters set to +1 (label: `all_plus_1`). This is a representative sign profile — all 4n parameters equal to 1. This choice activates all possible deformation terms and provides a concrete non-trivial test case.

**Method**: For each gamma entry (X,Y,Z,gb_label,coeff), substitute gb_label=1 to get numerical coeff. Sum over gb_labels for same (X,Y,Z) triple. Combine with undeformed structure constants to produce deformed_structure_constants.

**Results**:
- C_1_evaluated.json: 50 gamma entries → 70 deformed SC
- C_2_evaluated.json: 292 gamma entries → 391 deformed SC
- C_3_evaluated.json: 842 gamma entries → 1106 deformed SC

**Consistency**: All evaluated gamma entries reference valid Schema 2 gb parameters. Deformed SC extends Schema 1 SC correctly.
