### Response

#### GB Parameter Assignment Strategy

**Representative Assignment**: All gb parameters set to +1

**Rationale**:
- Canonical choice: symmetric point in parameter space
- Simplest non-trivial evaluation
- Sufficient for prototype; allows for future alternative assignments
- Each gb_{a_1^σ, b_j^s} = +1 for all σ,s ∈ {+,-}, j ∈ {1,...,n}

**Alternative assignments** (for future work):
- gb = -1 (opposite sign)
- Mixed assignments (e.g., alternating signs)
- Parameter-dependent evaluations

#### Implementation: `src/C_evaluated_generator.py`

**CnEvaluatedGenerator class**:
- `_load_schema2()`: Load Schema 2 (gamma structure)
- `_default_gb_assignment()`: Create gb = +1 assignment for all 4n parameters
- `_substitute_gamma_terms()`: Replace symbolic gb references with numeric values
- `to_json()`: Generate complete Schema 3 JSON

**Process flow**:
1. Load Schema 2 symbolic gamma structure
2. For each gamma term, identify gb parameter reference
3. Substitute assigned value (+1 in this case)
4. Collect evaluated structure constants with numeric coefficients
5. Generate Schema 3 JSON with evaluation point documented
