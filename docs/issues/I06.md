### Response

#### gb Assignment

Representative assignment: all 4n gb parameters set to +1 (all-plus canonical profile).
This is the simplest non-degenerate choice; it makes all deformation terms active.

#### Schema 3 Format

Each file `C_{n}_evaluated.json` contains:
- `gb_assignment`: dict mapping each gb label to its value (all 1).
- `evaluated_gamma.entries`: list of {X, Y, Z, coeff} with numeric (Fraction) coefficients.
- `consistency`: record of entry counts for cross-verification.

The evaluation is purely linear: each gamma entry's symbolic coefficient `c * gb_param`
is substituted with `c * 1 = c`.
