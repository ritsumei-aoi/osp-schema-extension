#### 2. Decision: seven profiles, not one

The issue suggests "all set to +1 **or** representative sign profiles". Options:

- **(a)** The single profile gb ≡ +1.
- **(b) Chosen** — a small family spanning the qualitatively distinct regions of
  the $4n$-dimensional parameter space.

**(b)** was chosen because I08 asks for *conditions* on gb under which the
deformation is trivial. A single point cannot distinguish "trivial for this gb"
from "trivial for all gb"; a family that includes degenerate, sparse, sign-mixed
and generic points can. The extra cost is one script run.

| Profile | gb assignment | Purpose |
|---|---|---|
| `all_plus` **(primary)** | all $+1$ | maximally symmetric; the literal suggestion in the issue |
| `fermionic_sign` | $+1$ if $\sigma=+$, $-1$ if $\sigma=-$ | isolates dependence on the $\varepsilon$ sign |
| `bosonic_sign` | $+1$ if $s=+$, $-1$ if $s=-$ | isolates dependence on the $\delta$ sign |
| `creation_only` | $1$ if $s=+$, else $0$ | rank-deficient: half the parameters vanish |
| `single_mode` | only $\mathrm{gb}_{+,1,+}=1$ | sparsest non-zero deformation |
| `generic_rational` | pairwise distinct rationals | generic point, no accidental relations |
| `zero` | all $0$ | undeformed control; γ must vanish |

#### 3. Decision: file naming

`docs/json_schema_specification.md` §0 (from I02) specifies
`C_{n}_evaluated_{profile}.json`, while this issue's text asks for
`C_{n}_evaluated.json`. Options: rename the spec; drop the extra profiles; emit
both. **Chosen: emit both** — the per-profile files carry the data, and
`C_{n}_evaluated.json` is written as a byte-identical copy of the primary
(`all_plus`) profile so that the literal deliverable named in I06 exists. A test
(`test_primary_alias_file_matches`) asserts the two stay identical.

#### 4. Method and the two independent cross-checks

Since every γ coefficient is linear in gb (I05), evaluation is exact rational
substitution — no floating point anywhere. To make the consistency check with
Schema 2 **non-trivial**, the data is produced twice by different routes and
compared:

1. **Substitution** — take the Layer 2 symbolic coefficients and substitute.
2. **Direct recomputation** — rebuild the whole deformed oscillator algebra with
   *numeric* gb from the start and recompute every bracket.

These share no code path beyond the normal-ordering engine, so agreement rules
out both a substitution bug and a symbolic-simplification bug. Plus:

3. **Cocycle condition** re-verified at each numeric point on all $N^3$ triples.

Observations recorded for I08:

- Entry counts for `all_plus`, `fermionic_sign`, `bosonic_sign` and
  `generic_rational` are **identical** (56 / 272 / 744) and equal to the symbolic

  they are all generic in the relevant sense.
- `creation_only` halves the support (28 / 136 / 372); `single_mode` reduces it
  to $4n+10$ … (14 / 34 / 62); `zero` kills it entirely. So the profiles really
  do sample different strata.
- γ depends on gb **linearly and with no constant term**, so the
  parameter-to-γ map is linear; `zero` giving $\gamma \equiv 0$ confirms it.
