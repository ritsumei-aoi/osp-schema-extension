## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

## Requirements
1. Define even and odd basis lists for C(n+1) for n=1, 2, 3 (i.e., C(2), C(3), C(4)), following the Frappat notation.
2. Determine PBW ordering with ε-roots: list at least two concrete options, choose one, and justify the choice.
3. Design oscillator generator labels consistent with `handover/notation.md`.
4. Update `handover/notation.md` with the finalized conventions.

### Response

**Decisions**

Basis lists, generator labels, oscillator conventions and PBW ordering have
been formalized in `handover/notation.md`. Summary:

- Oscillators: standard fermionic pair `a_1_p`, `a_1_m` (CAR); n bosonic pairs
  `b_k_p`, `b_k_m` (CCR); κ odd central (κ² = 0); K = 1.
- Odd root labels use suffix `pp/pm/mp/mm` encoding (sign of ε, sign of δ_k).
- Even basis: `H_j` (j=1..n+1), `E_2del{k}_p/m`, `E_del{i}_del{j}_pp/mm/pm/mp`.
- Odd basis: `E_eps1_del{k}_{pp,pm,mp,mm}` (4n items).
- Dimensions reproduce 2n²+n+1 (even) and 4n (odd). Verified for n=1,2,3:
  4+4=8, 11+8=19, 22+12=34.

**PBW ordering options considered**
- A: κ < odd < even, with odd ordered by (k, sign-slot) and even by
  (H, raising, lowering, mixed). **Chosen** — minimises diff with B(0,n) v5.0,
  keeps parity blocks visible.
- B: strict height ordering with ε and δ interleaved. Rejected — breaks the
  parallel layout and complicates diff review.

**Verification**: counts match the dimension table in
`docs/math/Cn1_definition.md`. No ambiguity encountered.
