## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

## Requirements
1. Define even and odd basis lists for C(n+1) for n=1, 2, 3 (i.e., C(2), C(3), C(4)), following the Frappat notation.
2. Determine PBW ordering with ε-roots: list at least two concrete options, choose one, and justify the choice.
3. Design oscillator generator labels consistent with `handover/notation.md`.
4. Update `handover/notation.md` with the finalized conventions.

### Response

**Decisions and Results**:

1. **Even and odd basis lists** defined for C(2), C(3), C(4) in `handover/notation.md`:
   - C(2): 4 even + 4 odd = 8 total (matches $2n^2+5n+1$ with $n=1$)
   - C(3): 11 even + 8 odd = 19 total (matches $n=2$)
   - C(4): 22 even + 12 odd = 34 total (matches $n=3$)

2. **PBW ordering**: Two options considered:
   - Option A (ε-first): $\kappa < [\text{odd}] < [\text{even}]$ — consistent with B(0,n) convention
   - Option B (Cartan-first): $\kappa < [\text{odd}] < [H_k] < [\text{even roots}]$ — separates Cartan from root vectors
   - **Chosen**: Option A, for consistency with the existing B(0,n) schema convention where the parity split is the primary division.

3. **Generator labels**: Following B(0,n) conventions with modifications for ε-roots:
   - Odd generators use `E_eps_del{k}_XY` where X is the sign of ε and Y is the sign of δ_k
   - Even generators retain the same labels as B(0,n) (Cartan H_k, root vectors E_2del{k}_p/m, E_del{i}_del{j}_XY)
   - Cartan generators extended: H_1 includes fermionic number operator; H_{n+1} is the terminal Cartan

4. **Updated** `handover/notation.md` with all conventions.
