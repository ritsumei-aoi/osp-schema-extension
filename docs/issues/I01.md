## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

**Basis and Root System Design for C(n+1) = osp(2|2n)**

The root system uses orthogonal vectors ε (fermionic) and δ_1,...,δ_n (bosonic):
- Even roots: ±2δ_k, ±(δ_i ± δ_j) for i<j
- Odd roots: ±ε ± δ_k for k=1,...,n

**Basis Dimensions Verified**:
- n=1 (C(2)): even=4, odd=4, total=8 ✓ (formula: 2n²+n+1=4, 4n=4)
- n=2 (C(3)): even=11, odd=8, total=19 ✓ (formula: 11, 8)
- n=3 (C(4)): even=22, odd=12, total=34 ✓ (formula: 22, 12)

**PBW Ordering Decision**: Chose Option A (κ < odd < even), matching B(0,n) convention.
Option B (even < odd < κ) was considered but rejected for inconsistency with base case.
Odd generators grouped by sign pattern (pp, pm, mp, mm) then by k index.

**Generator Label Convention**: ε-roots labeled as `E_eps1_del{k}_{sign}` where
sign ∈ {pp, pm, mp, mm} encodes (ε-sign, δ-sign). Full tables in `handover/notation.md`.

All conventions written to `handover/notation.md`.
