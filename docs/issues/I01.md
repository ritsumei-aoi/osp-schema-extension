## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

**Decisions**
- Even basis: `H_eps` (so(2), realized as $a_1^+a_1^-$) + `H_1..H_n` + `E_2del{k}_{p,m}` + `E_del{i}_del{j}_{pp,pm,mp,mm}`. Count $2n^2+n+1$.
- Odd basis: `E_eps1_del{k}_{pp,pm,mp,mm}`, count $4n$.
- PBW: odd-first (`odd < even`), chosen over even-first and root-height ordering, for parallelism with the B(0,n) convention in `docs/math/B0n_schema_v5.md`. Details in `handover/notation.md`.
- Considered but rejected: even-first (breaks the B(0,n) parallel); root-height (depends on simple system, mixed heights across $n$).

**Results**
- Dimensions verified by script for n=1,2,3: even 4/11/22, odd 4/8/12, total 8/19/34 (matches formulas in `docs/math/Cn1_definition.md`).
- Full label lists for C(2), C(3), C(4) are in `handover/notation.md`.

**Ambiguities and assumptions**
- $\mathfrak{so}(2)$ normalization: $H_\varepsilon = a_1^+a_1^-$ (any constant rescaling gives an isomorphic algebra).
- Simple root $\alpha_1 = \varepsilon-\delta_1$ taken as leftmost, consistent with `Cn1_definition.md`.
- The reference B(0,n) repository URL in the issue is external; not accessed (no-external-access rule).
