## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

#### 1. PBW Ordering Options & Decision
- **Option A (Parity-Block PBW Ordering)**: `κ < [odd generators] < [even generators]`.
  - Odd generators ordered by bosonic index $k$, then sign signature `pp < pm < mp < mm`.
  - Even generators ordered by Cartan elements `H_1, ..., H_{n+1}`, positive roots, then negative roots.
- **Option B (Root-Height Canonical Ordering)**: Order strictly by root weight height relative to simple roots, interleaving even and odd elements.
- **Decision & Justification**: Option A was selected because it preserves direct architectural compatibility with the $B(0,n)$ v5.0 schema (`κ < [odd] < [even]`). This block structure allows downstream linear algebra solvers and coboundary matrix routines to reuse block-triangular reduction without modification.

#### 2. Generator Notation & Realization
- **Fermionic pair**: $a_1^+, a_1^-$ with CAR $\{a_1^-, a_1^+\} = 1$.
- **Bosonic oscillators**: $b_k^+, b_k^-$ ($1 \le k \le n$) with CCR $[b_k^-, b_l^+] = \delta_{kl}$.
- **Even basis generators**:
  - Cartans: `H_1`, ..., `H_{n+1}`
  - Roots $\pm 2\delta_k$: `E_2del{k}_p`, `E_2del{k}_m`
  - Roots $\pm \delta_i \pm \delta_j$: `E_del{i}_del{j}_pp`, `E_del{i}_del{j}_mm`, `E_del{i}_del{j}_pm`, `E_del{i}_del{j}_mp`
- **Odd basis generators**:
  - Roots $\pm \varepsilon \pm \delta_k$: `E_eps1_del{k}_pp`, `E_eps1_del{k}_pm`, `E_eps1_del{k}_mp`, `E_eps1_del{k}_mm`

#### 3. Concrete Basis Specifications for C(2), C(3), C(4)
- **C(2)** ($n=1$): Even (4) = `H_1`, `H_2`, `E_2del1_p`, `E_2del1_m`; Odd (4) = `E_eps1_del1_pp`, `E_eps1_del1_pm`, `E_eps1_del1_mp`, `E_eps1_del1_mm`. Total dim: 8.
- **C(3)** ($n=2$): Even (11) = `H_1`, `H_2`, `H_3`, `E_2del1_p`, `E_2del2_p`, `E_del1_del2_pp`, `E_2del1_m`, `E_2del2_m`, `E_del1_del2_mm`, `E_del1_del2_pm`, `E_del1_del2_mp`; Odd (8) = `E_eps1_del1_pp..mm`, `E_eps1_del2_pp..mm`. Total dim: 19.
- **C(4)** ($n=3$): Even (22), Odd (12). Total dim: 34.
