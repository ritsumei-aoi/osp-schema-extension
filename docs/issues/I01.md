## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

#### Sources used
Only repository documents: `docs/math/Cn1_definition.md`, `B0n_definition.md`, `B0n_schema_v5.md`.
The external GitHub/arXiv links in the Context were not accessed (no web access in this session).

#### 1. Basis lists
Finalized in `handover/notation.md` §3 for n=1,2,3. Counts: even $2n^2+n+1$ (4, 11, 22), odd $4n$
(4, 8, 12), total (8, 19, 34), matching the table in `Cn1_definition.md`.
Even part: $n+1$ Cartan generators `H_1..H_{n+1}` (the extra Cartan element relative to B(0,n)
carries the $\mathfrak{so}(2)$ direction) plus the $2n^2$ root vectors of $\mathfrak{sp}(2n)$.
Odd part: the $4n$ generators $E_{\pm\varepsilon\pm\delta_k}$.

#### 2. PBW ordering — options considered
* **Option A (chosen)**: $\kappa <$ [odd] $<$ [even], odd block ordered by $\varepsilon$-sign, then $k$,
  then $\delta$-sign; even block as in B(0,n) (Cartan, positive, negative, mixed).
  Reason: identical shape to the B(0,n) v5.0 convention (`B0n_schema_v5.md`), so the
  generator/verification code and any downstream consumer of B data can be reused with minimal
  change; the odd ordering also coincides with the oscillator normal order ($a_1^+$ words before $a_1^-$ words).
* **Option B**: $\kappa <$ [even] $<$ [odd] (Cartan and $\mathfrak{sp}(2n)$ first). Rejected: breaks
  compatibility with the B(0,n) convention for no computational gain.
* **Option C**: ordering by root height (negative roots, Cartan, positive roots, parity-mixed).
  Rejected: nicer for Chevalley-basis presentations, but it interleaves parities, which complicates
  parity-block checks and the odd linear map $f$ of Layer 4.

#### 3. Generator labels
`E_eps1_del{k}_{σ s}` for the odd generators (σ = sign of ε, s = sign of δ_k), B(0,n) labels for the
$\mathfrak{sp}(2n)$ part, `H_1..H_{n+1}` for the Cartan subalgebra; oscillator labels
`a_1_p, a_1_m, b_{k}_p, b_{k}_m`; central elements `K`, `kappa`; deformation parameters
`gb_a1{σ}_b{j}{s}`. See `handover/notation.md` §2, §5.

#### 4. Ambiguities recorded (ai_trust_policy boundary)
* `Cn1_definition.md` gives $E_{2\delta_n} = \tfrac12 (b_n^+)^2$ in the simple-generator list but
  $E_{\pm2\delta_k} = (b_k^\pm)^2$ in the all-generators list. Adopted $(b_k^\pm)^2$ (B(0,n)-compatible,
  and consistent with the all-generators list).
* Cartan basis: simple-root $H_k$ (as in the math note) vs. diagonal number operators $N_a, N_k$.
  Adopted the simple-root $H_k$ to follow the note and the B(0,n) schema; the invertible change of
  basis is documented in `notation.md` §2 so either form can be recovered.
* The constant terms produced by $a_1^+a_1^-$ and $b_k^+b_k^-$ are recorded as multiples of the even
  central element $K=1$ (never as independent basis elements).
