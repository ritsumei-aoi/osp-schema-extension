## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

## Requirements
1. Define even and odd basis lists for C(n+1) for n=1, 2, 3 (i.e., C(2), C(3), C(4)), following the Frappat notation.
2. Determine PBW ordering with ε-roots: list at least two concrete options, choose one, and justify the choice.
3. Design oscillator generator labels consistent with `handover/notation.md`.
4. Update `handover/notation.md` with the finalized conventions.

**1. Basis Lists**

*C(2) (n=1)*
- **Even (4):** `H_1, H_2, E_2del1_p, E_2del1_m`
- **Odd (4):** `E_eps1_del1_pp, E_eps1_del1_pm, E_eps1_del1_mp, E_eps1_del1_mm`

*C(3) (n=2)*
- **Even (11):** `H_1, H_2, H_3, E_2del1_p, E_2del1_m, E_2del2_p, E_2del2_m, E_del1_del2_pp, E_del1_del2_pm, E_del1_del2_mp, E_del1_del2_mm`
- **Odd (8):** `E_eps1_del1_pp, E_eps1_del1_pm, E_eps1_del1_mp, E_eps1_del1_mm, E_eps1_del2_pp, E_eps1_del2_pm, E_eps1_del2_mp, E_eps1_del2_mm`

*C(4) (n=3)*

- **Odd (12):** `E_eps1_del{k}_pp, E_eps1_del{k}_pm, E_eps1_del{k}_mp, E_eps1_del{k}_mm` for `k=1,2,3`.

**2. PBW Ordering**
- **Option A:** `[odd] < [even]`. This matches the convention of `B(0,n)` exactly, ensuring maximum code compatibility and ease of transitioning downstream tools.
- **Option B:** `[even] < [odd]`. 
- **Decision:** **Option A**. The continuity with the reference B(0,n) codebase strongly justifies choosing Option A.

**3. Generator Labels**
Defined in `handover/notation.md`. The odd root generators are assigned labels `E_eps1_del{k}_{signs}`, and even generators follow the established patterns.
