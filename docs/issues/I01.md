## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

**Decisions and Results (Claude Opus 4.6)**

#### 1. Even and Odd Basis Lists

Using the root system from `Cn1_definition.md`, the basis lists for C(n+1) = osp(2|2n) are:

**C(2), n=1**: even=4, odd=4, total=8
- Even: H_1, H_2, E_2del1_p, E_2del1_m
- Odd: E_eps1_del1_pp, E_eps1_del1_pm, E_eps1_del1_mp, E_eps1_del1_mm

**C(3), n=2**: even=11, odd=8, total=19
- Even: H_1, H_2, H_3, E_2del1_p, E_2del2_p, E_del1_del2_pp, E_2del1_m, E_2del2_m, E_del1_del2_mm, E_del1_del2_pm, E_del1_del2_mp
- Odd: E_eps1_del1_pp, E_eps1_del1_pm, E_eps1_del2_pp, E_eps1_del2_pm, E_eps1_del1_mp, E_eps1_del1_mm, E_eps1_del2_mp, E_eps1_del2_mm

**C(4), n=3**: even=22, odd=12, total=34
- Even: H_1, ..., H_4, E_2del{k}_p/m, E_del{i}_del{j}_pp/mm/pm/mp
- Odd: E_eps1_del{k}_pp/pm/mp/mm for k=1,2,3

Dimension verification: even = 2n²+n+1, odd = 4n, total = 2n²+5n+1. All match Frappat.

#### 2. PBW Ordering Decision

**Options considered:**
- **Option A**: κ < [odd] < [even] — consistent with B(0,n) convention
- **Option B**: κ < [even] < [odd] — reversed order

**Choice: Option A** (κ < odd < even), for backward compatibility with the existing B(0,n) schema.

Within odd: positive ε before negative ε, ascending k, +δ before −δ.
Within even: Cartan ascending, then positive roots, negative roots, mixed roots.

#### 3. Generator Label Conventions

Odd generators use the pattern `E_eps1_del{k}_{ss}` where:
- First sign indicates ε direction (+/−)
- Second sign indicates δ direction (+/−)
- Labels: `_pp`, `_pm`, `_mp`, `_mm`

This extends the B(0,n) two-index sign convention naturally to include the ε root.

All conventions documented in `handover/notation.md`.
