## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

3. Design oscillator generator labels consistent with `handover/notation.md`.

### Response

**Date**: 2026-10-06 — all conventions written to `handover/notation.md`.

#### 1. Even / odd basis
From `Cn1_definition.md`: even = Cartan ($n+1$: $H_1,\dots,H_{n+1}$) + $\pm2\delta_k$ ($2n$) +
$\pm\delta_i\pm\delta_j$ ($2n(n-1)$) $= 2n^2+n+1$; odd = $\pm\varepsilon\pm\delta_k$ ($4n$).
Counts: C(2) 4|4, C(3) 11|8, C(4) 22|12 (full lists in `notation.md` §5).

#### 2. PBW ordering — options considered
- **Option A (chosen)**: $\kappa <$ [odd] $<$ [even] (B(0,n) block structure kept);
  odd block sign-major/index-minor with the $\varepsilon$-sign first:
  `pp(1..n), pm(1..n), mp(1..n), mm(1..n)`.
- **Option B**: odd block ordered by root height / positive-before-negative roots
  ($\varepsilon+\delta_k, \varepsilon-\delta_k, -\varepsilon+\delta_k, -\varepsilon-\delta_k$ grouped per $k$:
  `pp_1, pm_1, mp_1, mm_1, pp_2, ...`).
- **Option C**: interleave odd and even by root height (mixes parity blocks).

Reasons for A: (i) keeps the exact B(0,n) block shape `κ < odd < even`, so v5.0 tooling and
comparison code carry over; (ii) the first letter of the suffix is the fermion label, so the
odd block is split into an $a_1^+$ half and an $a_1^-$ half, matching the row structure of the
$2\times2n$ gb matrix used in Layer 2; (iii) within each half, B(0,n)'s sign-major/index-minor
pattern (`E_del1_p, E_del2_p, E_del1_m, ...`) is reproduced. Option C was rejected because it breaks
the parity-block structure required by the v5.0 `ordering_convention`.

#### 3. Generator labels / realizations
`H_k`, `E_2del{k}_{p,m}`, `E_del{i}_del{j}_{pp,mm,pm,mp}` as in B(0,n); odd:
`E_eps1_del{k}_{σs}` $= a_1^\sigma b_k^s$. Oscillator labels `a_1_p, a_1_m, b_k_p, b_k_m`;
oscillator normal order `a_1_p < a_1_m < b_1_p < b_1_m < ...`.

#### 4. Ambiguities found in the documents and decisions taken
1. **Normalization of $E_{\pm2\delta_k}$**: `Cn1_definition.md` gives $\tfrac12(b_n^\pm)^2$ for the
   simple generators but $(b_k^\pm)^2$ in the "all root generators" list. *Decision*: use
   $\tfrac12(b_k^\pm)^2$ for every $k$ (needed so that the simple generator agrees with the
   list and so that $[E_{2\delta_n},E_{-2\delta_n}]=H_{n+1}$ exactly, a Chevalley-type
   normalization). The alternative only rescales basis vectors; no conclusion depends on it.
2. **Constants in Cartan elements**: $H_1=a_1^+a_1^-+b_1^+b_1^-$ and $H_{n+1}=-b_n^+b_n^--\tfrac12$
   are exactly the super-symmetrized quadratics. With these, the span is closed without
   central terms (verified in I03/I04), so $K$ never appears in Schema 1 brackets.
3. **$\kappa$ parity**: B(0,n) doc §3 says $p(\kappa)=1$ but mentions JSON parity 0. I follow the
   I02 mandatory rule ($\kappa$ parity 1, $K$ parity 0).
