## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Analysis & Decisions
1. **Basis Lists**: Based on `Cn1_definition.md`, the even roots are $\pm 2\delta_k$ and $\pm\delta_i \pm\delta_j$, and Cartans $H_1, \ldots, H_{n+1}$. The odd roots are $\pm\varepsilon \pm\delta_k$. I have generated lists for C(2), C(3), C(4) maintaining appropriate counts.
2. **PBW Ordering Options considered**:
   - Option A: `κ < [even] < [odd]` (standard graded lexicographic).
   - Option B: `κ < [odd] < [even]` (backward-compatible with B(0,n) schemas).
   - **Decision**: Option B is chosen to maintain compatibility with existing B(0,n) implementations.
3. **Notation**: Defined labels following the `E_eps1_del{k}_{signs}` pattern for odd roots and B(0,n) style for even roots.
4. **Execution**: Updated `handover/notation.md` with these conventions. All completion criteria met.
