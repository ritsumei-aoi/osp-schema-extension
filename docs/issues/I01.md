## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

**Decisions**

1. **Basis** (`handover/notation.md`): even = `H_1..H_{n+1}`, `E_2del{k}_{p,m}`, `E_del{i}_del{j}_{pp,pm,mp,mm}` (i<j); odd = `E_eps1_del{k}_{pp,pm,mp,mm}` (first sign = sign of ε, second = sign of δ_k). Counts: C(2) 4|4, C(3) 11|8, C(4) 22|12 (= 2n²+n+1 | 4n); checked by code (`even_basis`, `odd_basis` in `src/C_generators.py`).
2. **PBW ordering** – options considered: (A) odd block first, B(0,n)-v5.0 compatible; (B) triangular height order (negative < Cartan < positive); (C) ε-graded blocks (ε=-1 odd < even < ε=+1 odd). **Chosen (A)**: backward compatible with B(0,n) v5.0, keeps all ε-roots (all odd) contiguous, and is independent of a choice of positive system. Within odd block order is (type pp,pm,mp,mm; then k).
3. **Generator labels**: oscillators `a_1_p, a_1_m, b_{k}_{p,m}`, formal `kappa`; normal-ordering order `kappa < a_1_p < a_1_m < b_1_p < ...`.
4. **Ambiguities / assumptions recorded**
   - Doc §2 of `Cn1_definition.md` gives E_{2δ_n}=½(b⁺)² for simple generators but E_{±2δ_k}=(b_k^±)² for "all root generators". I use (b_k^±)² (no ½) for all k, consistent with the B(0,n) label table.
   - Cartan elements: the doc's H_k are exactly the Weyl-symmetrised combinations (h_a=a⁺a⁻−½, h_k=b⁺b⁻+½), so g closes with no central constant; this is why H_{n+1} carries "−½".
   - κ parity: B(0,n) doc says "parity 0 in the JSON", the I02 unified rule says parity 1. κ is odd (I follow the unified rule); in the oscillator algebra κ supercommutes with everything (anticommutes with a_1^±, commutes with b).
   - K is identified with the scalar 1 and is not a basis element.
5. Notation for gb, layers, the odd map f, and the central "K" direction of γ is also fixed in `notation.md` (the K-direction was found necessary in I05; see I05 response).

**Verification**: `python3 src/C_generators.py` builds all three bases and checks closure (no residual central constants in the undeformed algebra); dimensions 8, 19, 34 as required.
