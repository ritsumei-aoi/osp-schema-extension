## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

## Requirements

2. Determine PBW ordering with ε-roots: list at least two concrete options, choose one, and justify the choice.
3. Design oscillator generator labels consistent with `handover/notation.md`.
4. Update `handover/notation.md` with the finalized conventions.

### Response

**Decisions**
- Basis counts match `Cn1_definition.md`: C(2) 4|4, C(3) 11|8, C(4) 22|12 (even 2n²+n+1, odd 4n).
- PBW options considered: (1) parity-first κ<odd<even (B(0,n)-compatible), (2) Chevalley root-height order, (3) oscillator-word lexicographic. Chosen (1): backward compatible with the v5.0 B schema and consistent with fermion-left-of-boson normal ordering, which the deformation [b,a] = -gb κ needs.
- Odd labels `E_eps1_del{k}_{σ s}` = a_1^σ b_k^s; Cartans H_1..H_{n+1} follow `Cn1_definition.md`.
- Deviations (documented in notation.md): odd generators always fermion-first (E_{δ1-ε}=a_1^- b_1^+ rather than b_1^+ a_1^-); E_{±2δ}=(b^±)^2 uniformly (the doc has ½(b_n^±)² in one place and (b^±)² in another).
- Ambiguity noted: the doc's H_1 = a⁺a⁻ + b₁⁺b₁⁻ and H_{n+1} = -b_n⁺b_n⁻ - ½ look inconsistent in constants, but H_1 = h_a + h_1 and H_{n+1} = -h_n with Weyl-ordered h_a = a⁺a⁻-½, h_k = b⁺b⁻+½, so the algebra closes with no central term. Assumption adopted: the doc's H's as written (computer-verified in I03/I04).

**Result**: `handover/notation.md` rewritten with basis lists, PBW ordering, generator labels, file names. Criteria checked by inspection against the doc's dimension table (no code in this issue).
