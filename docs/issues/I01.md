## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

#### 1. Basis lists (Requirement 1)

Root system (Frappat): $\Delta_{\bar0} = \{\pm 2\delta_k, \pm\delta_i \pm \delta_j\}$,
$\Delta_{\bar1} = \{\pm\varepsilon \pm \delta_k\}$; even part $\mathfrak{so}(2)\oplus\mathfrak{sp}(2n)$.
Counts: even $= (n+1) + 2n + 4\binom{n}{2} = 2n^2+n+1$, odd $= 4n$.
The full lists for C(2), C(3), C(4) are written out in `handover/notation.md` §4
(4+4, 11+8, 22+12 generators). They are generated by `even_basis(n)` / `odd_basis(n)`
in I03 and tested against these literal lists.

Cartan subalgebra: I use the Frappat distinguished simple-root Cartans
exactly as given in `Cn1_definition.md` §2:
$H_1 = a_1^+a_1^- + b_1^+b_1^-$, $H_k = N_{k-1} - N_k$ ($2\le k\le n$), $H_{n+1} = -N_n - \tfrac12$.
Alternative considered: "diagonal" Cartans $a_1^+a_1^- - \tfrac12$, $N_k + \tfrac12$.
Both span the same subspace (the symmetrized number operators); the Frappat form was chosen
because the reference document specifies it and because it mirrors the B(0,n) schema
(`H_k = N_k - N_{k+1}`, `H_n = N_n + 1/2`). The constant $-\tfrac12$ in $H_{n+1}$ is not optional:
$[(b_n^+)^2, (b_n^-)^2] = -4N_n - 2 = 4H_{n+1}$, so without it the bracket does not close.

**Normalization ambiguity (recorded per ai_trust_policy):** `Cn1_definition.md` gives
$E_{\pm2\delta_n} = \tfrac12 (b_n^\pm)^2$ in the simple-generator table but $(b_k^\pm)^2$ in the
"all root generators" list. I adopt $(b_k^\pm)^2$ (no $\tfrac12$), matching the B(0,n) label table,
so that `E_2del{k}_p` has the same meaning in both families. The only consequence is
$[E_{2\delta_n}, E_{-2\delta_n}] = 4H_{n+1}$ instead of $H_{n+1}$.

#### 2. PBW ordering (Requirement 2)

Options considered:

| Option | Order | Pros | Cons |
|---|---|---|---|
| A (chosen) | `kappa < [odd: pp, pm, mp, mm blocks] < [even: H, E_2del_p, E_dd_pp, E_2del_m, E_dd_mm, E_dd_pm, E_dd_mp]` | identical shape to the B(0,n) v5.0 convention (`κ < odd < even`); odd block ordered by ε-sign first, consistent with the oscillator order `a_1_p < a_1_m`; B(0,n) tooling carries over | odd generators are not grouped by root height |
| B | `kappa < [even] < [odd]` | even monomials first is the classical PBW habit | breaks compatibility with the B(0,n) schema ordering and with its `κ < odd < even` description |
| C | $\varepsilon$-grading: `E_eps1_*_p?` (ε-weight +1) < even (weight 0) < `E_eps1_*_m?` (weight −1) | reflects the $\mathbb{Z}$-grading $\mathfrak g_{-1}\oplus\mathfrak g_0\oplus\mathfrak g_{1}$ of C(n+1) | the odd generators are split around the even block; the B(0,n) comparison and the `basis.odd` list order would differ from the PBW order |

Decision: **Option A**. Rationale: the task is a schema *extension* of B(0,n) v5.0, so keeping the
`κ < odd < even` shape minimizes the diff in every downstream layer; inside the odd block the
`pp, pm, mp, mm` order is the lexicographic order of the oscillator normal order
(`a_1_p` before `a_1_m`, `b_k_p` before `b_k_m`).

#### 3. Generator labels (Requirement 3)

Odd: `E_eps1_del{k}_{σs}` with σ = sign of ε, s = sign of δ_k; realization `a_1_σ b_k_s`.
Even: unchanged from B(0,n) (`H_k`, `E_2del{k}_p/m`, `E_del{i}_del{j}_pp/pm/mp/mm`), with
`H_{n+1}` added. Oscillators: `a_1_p, a_1_m, b_k_p, b_k_m`; central: `kappa` (parity 1), `K` (parity 0).
Oscillator normal order `kappa < a_1_p < a_1_m < b_1_p < b_1_m < ... < b_n_m`.
