## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

**Decision and options considered:** I used \(n+1\) Cartan generators, the
\(2n\) roots \(\pm2\delta_k\), and the \(4\binom n2\) roots
\(\pm\delta_i\pm\delta_j\) for the even sector; the odd sector consists of
the \(4n\) roots \(\pm\varepsilon\pm\delta_k\). For PBW order I considered
the B-compatible parity-block order and a root-triangular order. I selected
the parity-block order \(\kappa < [\text{odd}] < [\text{even}]\) so the new
schema stays comparable to the B(0,n) base. Generator labels and canonical
within-sector ordering are now specified in `handover/notation.md`.

**Results and verification:** The explicit lists give even/odd cardinalities
`(4, 4)` for C(2), `(11, 8)` for C(3), and `(22, 12)` for C(4), matching
\((2n^2+n+1,4n)\) at \(n=1,2,3\). The even labels cover Cartan, positive
and negative long roots, and all four \(\delta_i,\delta_j\) sign choices;
the odd labels cover all four \(\varepsilon,\delta_k\) sign choices.
