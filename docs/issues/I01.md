## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

## Requirements
1. Define even and odd basis lists for C(n+1) for n=1, 2, 3 (i.e., C(2), C(3), C(4)), following the Frappat notation.
2. Determine PBW ordering with ε-roots: list at least two concrete options, choose one, and justify the choice.
3. Design oscillator generator labels consistent with `handover/notation.md`.
4. Update `handover/notation.md` with the finalized conventions.

### Response

#### Decisions

1. **Basis lists** (Requirement 1). Even: `H_1..H_{n+1}` (Frappat distinguished Cartan basis
   of `Cn1_definition.md` §2), `E_2del{k}_p/m`, `E_del{i}_del{j}_pp/mm/pm/mp` (i<j);
   odd: `E_eps1_del{k}_pp/pm/mp/mm`. Counts: n=1 → 4|4, n=2 → 11|8, n=3 → 22|12,
   matching `2n^2+n+1 | 4n`. Explicit lists for C(2), C(3), C(4) are in
   `handover/notation.md` §4.
2. **PBW ordering** (Requirement 2). Three options were listed in `notation.md` §5:
   A `kappa < [odd] < [even]` (odd block grouped by ε-sign), B `kappa < [even] < [odd]`,
   C root-height ordering. **Option A adopted**: it reproduces the B(0,n) v5.0 convention
   verbatim (κ first, same even-block order), and the ε-sign grouping of the odd block reflects
   the so(2) charge and the fact that odd generators with equal ε-sign anticommute
   (`(a_1^±)^2 = 0`), so each ε-block is an abelian odd subalgebra.
3. **Generator labels** (Requirement 3). Grammar `E_<root>_<signs>`; the sp(2n) labels are
   identical to B(0,n) v5.0; odd labels `E_eps1_del{k}_<fermion sign><boson sign>`
   (first letter = sign of ε, second = sign of δ_k). Oscillator labels `a_1_p, a_1_m, b_k_p, b_k_m`;
   central elements `K` (parity 0, = 1) and `kappa` (parity 1, κ²=0).
4. **Recorded ambiguity**: `Cn1_definition.md` gives `E_{2δ_n} = ½(b_n^+)^2` in the simple-root
   list but `(b_k^±)^2` in the all-roots table. Adopted `(b_k^±)^2` (no ½), consistent with the
   B(0,n) labels. This only rescales two basis vectors per k and does not affect any
   structural conclusion.
5. **Cartan constants**: `H_{n+1} = -b_n^+b_n^- - 1/2` and `H_1 = a_1^+a_1^- + b_1^+b_1^-` are
   exactly the Frappat combinations of the symmetrized number operators
   `N_0^s = a_1^+a_1^- - 1/2`, `N_k^s = b_k^+b_k^- + 1/2` (notation.md §3.3), so the span of the
   basis is the Lie superalgebra of symmetrized quadratics and closes under brackets without
   extra constants. This was checked by hand for `[E_2del{k}_p, E_2del{k}_m] = -4 N_k^s`.
