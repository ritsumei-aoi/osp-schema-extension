## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

**Decision log (No-Gate condition)**

#### 1. Basis lists

From the root system $\Delta_{\bar{0}} = \{\pm 2\delta_k\} \cup \{\pm(\delta_i \pm \delta_j)\mid i<j\}$ and $\Delta_{\bar{1}} = \{\pm\varepsilon \pm \delta_k\}$, the basis lists are as documented in `handover/notation.md`.

Dimension check (formula: even $= 2n^2+n+1$, odd $= 4n$):
- $n=1$: even=4, odd=4, total=8. Generator count: H_1,H_2 (2 Cartans) + E_2del1_p, E_2del1_m (2 roots) = 4 even; 4 odd. ✓
- $n=2$: even=11, odd=8. 3 Cartans + 4 length-2δ + 4 length-δi±δj = 11 even; 8 odd. ✓
- $n=3$: even=22, odd=12. 4 Cartans + 6 + 12 = 22 even; 12 odd. ✓

#### 2. PBW ordering decision

**Options considered**:
- Option A (parity-first): $\kappa < [\text{odd}] < [\text{even}]$, matching B(0,n) convention.
- Option B (oscillator-first): order by oscillator content.

**Choice**: Option A. Rationale: backward compatibility with the B(0,n) schema; the structure-constant comparison across families is simpler when the same parity-first convention is used.

#### 3. Notation conventions

Generator label scheme finalized in `handover/notation.md`:
- Odd generators: `E_eps1_del{k}_{s1s2}` where s1∈{p,m} encodes the ε sign and s2∈{p,m} encodes the δ_k sign.
- Even root generators follow the B(0,n) convention for δ-roots, with `_pp`/`_pm`/`_mp`/`_mm` suffixes.
- Cartan generators: `H_{k}` for k=1,...,n+1.
