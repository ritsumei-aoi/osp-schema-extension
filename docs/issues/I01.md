## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

## Requirements
1. Define even and odd basis lists for C(n+1) for n=1, 2, 3 (i.e., C(2), C(3), C(4)), following the Frappat notation.
2. Determine PBW ordering with ε-roots: list at least two concrete options, choose one, and justify the choice.
3. Design oscillator generator labels consistent with `handover/notation.md`.
4. Update `handover/notation.md` with the finalized conventions.

### Response

**Decisions and Analysis**:
1. **Basis Lists**: The even and odd basis lists were constructed by counting the Cartans ($n+1$ for $C(n+1)$) and evaluating the respective root systems. C(2) has 4 even/4 odd; C(3) has 11 even/8 odd; C(4) has 22 even/12 odd.
2. **PBW Ordering**: I considered two options for the PBW ordering with $\varepsilon$-roots:
   - *Option 1*: Parity-first ordering `κ < [odd] < [even]`, where odd generators are sorted lexicographically by label, followed by Cartans, then even roots ordered lexicographically.
   - *Option 2*: Root-space structured ordering `κ < [Cartans] < [positive even] < [negative even] < [positive odd] < [negative odd]`.
   *Choice & Justification*: I chose **Option 1** because it aligns strictly with the existing v5.0 JSON schema for $B(0,n)$, ensuring maximum structural compatibility when generating the structure constants and coboundary data.
3. **Notation**: Generator labels were designed following the conventions set in $B(0,n)$ (e.g., `E_2del{k}_p`, `E_del{i}_del{j}_pp`) and extended for $\varepsilon$-roots (`E_eps_del{k}_...`).
