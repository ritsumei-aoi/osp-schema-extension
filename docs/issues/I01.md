## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

#### 1. Analysis and Basis Definition
Following Frappat et al. (arXiv:hep-th/9607161) and `docs/math/Cn1_definition.md`, the root system of $C(n+1) = \mathfrak{osp}(2|2n)$ consists of:
- Even roots: $\Delta_{\bar{0}} = \{\pm 2\delta_k \mid 1 \le k \le n\} \cup \{\pm(\delta_i \pm \delta_j) \mid 1 \le i < j \le n\}$.
- Odd roots: $\Delta_{\bar{1}} = \{\pm\varepsilon \pm \delta_k \mid 1 \le k \le n\}$.
- Cartan subalgebra: dimension $n+1$ spanned by $H_1, \dots, H_{n+1}$.

#### 2. PBW Ordering Options and Decision
We considered two concrete ordering schemes:
- **Option 1 (Parity-Separated Block Ordering)**:
  $$\kappa < [\text{odd basis}] < [\text{even basis}]$$
  Within odd basis: ordered by bosonic index $k=1,\dots,n$, then sign combination `pp`, `pm`, `mp`, `mm`.
  Within even basis: Cartan ($H_1, \dots, H_{n+1}$), positive long roots, positive short roots, negative long roots, negative short roots, mixed short roots.
- **Option 2 (Graded Root-Height / Triangular Ordering)**:
  $$\kappa < \text{Negative Odd} < \text{Negative Even} < \text{Cartan} < \text{Positive Even} < \text{Positive Odd}$$
  Triangular decomposition sorting generators strictly by root height.

**Decision**: Selected **Option 1**.
**Reason**: Option 1 directly extends the $B(0,n)$ schema architecture where `basis.odd` and `basis.even` are separate arrays and the global ordering is $\kappa < \text{odd} < \text{even}$. Grouping the odd generators by bosonic index $k$ aligns directly with the deformation parameter blocks $\mathrm{gb}_{\sigma, k, s}$, preserving clarity and backwards compatibility.
