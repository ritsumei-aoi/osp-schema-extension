## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

  and complete even/odd bases for $n=1,2,3$ in `handover/notation.md`.
- Considered ordering odd roots per bosonic index versus grouping by the sign

  odd generators adjacent and to extend the schema predictably with rank.
  This is an ordering convention; either would be a valid PBW ordering.

  schema's convention that these are bookkeeping/identity elements rather
  than independent generators.

Verification: checked the even/odd counts against
$\dim_{\bar 0}=2n^2+n+1$ and $\dim_{\bar 1}=4n$:
$n=1$: $4|4$; $n=2$: $11|8$; $n=3$: $22|12$. The listed root families
provide $n+1$ Cartan elements, $2n$ roots $\pm2\delta_k$, and
$4\binom{n}{2}$ pair roots in the even sector; the odd sector lists four
roots for each $k$.
