## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

**Result**: `handover/notation.md` finalized (sections 1-7). Basis and labels are fixed for general $n$, and the explicit lists are:

- $C(2)$ ($n=1$): even $H_1, H_2, E_{2\delta_1}, E_{-2\delta_1}$ (4); odd $E_{\varepsilon\pm\delta_1}, E_{-\varepsilon\pm\delta_1}$ (4).
- $C(3)$ ($n=2$): even 11 = $H_1,H_2,H_3$, $E_{\pm2\delta_{1,2}}$ (4), $E_{\pm\delta_1\pm\delta_2}$ (4); odd 8.
- $C(4)$ ($n=3$): even 22 = $H_{1..4}$ (4), $E_{\pm2\delta_{1,2,3}}$ (6), $E_{\pm\delta_i\pm\delta_j}$ for $i<j$ (12); odd 12.

**Decisions**

1. *PBW ordering.* Considered (A) odd-first $\kappa<[\text{odd}]<[\text{even}]$, (B) even-first, and (C) an $\varepsilon$-sign blocked ordering $[\varepsilon^+\text{odd}]<[\text{even}]<[\varepsilon^-\text{odd}]$. Chose (A). Reason: it matches the B(0,n) schema block structure, so the two schemas can be compared directly, and it places all deformation-carrying generators in one block. (C) would fit a triangular decomposition, but that is not needed here. Within the odd block, the order is (ε-sign, δ-sign, k).
2. *Root normalization.* The docs disagree: `Cn1_definition.md` ("Simple generators") writes $E_{2\delta_n}=\tfrac12(b_n^+)^2$, but the "All root generators" section writes $E_{\pm2\delta_k}=(b_k^\pm)^2$. Chose the second, for uniformity across all roots and to match the B(0,n) schema. A rescaling of a root vector does not change triviality.
3. *Cartan.* Used $H_1 = a_1^+a_1^-+b_1^+b_1^-$, $H_k=b_{k-1}^+b_{k-1}^- - b_k^+b_k^-$, $H_{n+1}=-b_n^+b_n^- - \tfrac12$ exactly as written. $H_1+H_2$ (for $n=1$) equals $a_1^+a_1^- - \tfrac12$, the traceless fermion number, which is a sanity check. The constant $-\tfrac12$ is the only constant term. Whether the Cartan closes with these constants is checked in I03, not assumed here.
4. *Constant term.* $K$ is identified with the scalar $1$ and excluded from the basis. If a bracket of basis elements produces a constant residual that no basis element absorbs, that is a failure to be reported, not silently dropped.
5. *Oscillator labels.* `a_1_p` = $a_1^+$, `a_1_m` = $a_1^-$, `b_k_p` = $b_k^+$, `b_k_m` = $b_k^-$.
6. *gb labels.* `gb_a1{σ}_b{k}{s}`, $4n$ parameters.

**Verification**: The counts above were checked by hand against $2n^2+n+1$ and $4n$ (even and odd dims for $n=1,2,3$ are 4/4, 11/8, 22/12). The closure of the bracket is not yet checked, and will be verified in I03.
