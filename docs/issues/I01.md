## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

#### Decisions Made

**1. Basis lists defined for C(2), C(3), C(4)**

The root system of C(n+1) = osp(2|2n) uses vectors ε (fermionic) and δ_k (bosonic, k=1..n).
- Even roots: ±2δ_k and ±(δ_i ± δ_j) for i<j → counts: 2n + 4·C(n,2) = 2n + 2n(n-1) = 2n²
- Plus n+1 Cartan generators → total even = 2n²+n+1
- Odd roots: ±ε ± δ_k → 4n generators

Verified counts:
- C(2) n=1: even=4, odd=4, total=8 ✓
- C(3) n=2: even=11, odd=8, total=19 ✓
- C(4) n=3: even=22, odd=12, total=34 ✓

**2. PBW ordering decided**

Chosen: `κ < [odd] < [even]` (Option A), consistent with B(0,n) v5.0 schema.
Rejected Option B (κ < [even Cartan] < [odd] < [even roots]) as it would break even/odd partition consistency.

Within odd: pp < pm < mp < mm subscript order, then ascending k.
Within even: Cartan (H_1..H_{n+1}), positive even, negative even, mixed.

**3. Generator label conventions finalized**

- Odd generators (ε-roots): `E_eps1_del{k}_pp/pm/mp/mm` for k=1..n
- Even Cartan: `H_1`..`H_{n+1}`
- Even root vectors: same as B(0,n) (`E_2del{k}_p/m`, `E_del{i}_del{j}_pp/mm/pm/mp`)
- Fermionic oscillators: `a_1_p`, `a_1_m` (replacing B(0,n)'s `a_0`)
- Deformation params: `gb_{sigma}_{j}_{s}` with σ,s ∈ {p,m}, j=1..n (4n params)
