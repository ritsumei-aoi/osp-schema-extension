## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

**1. Even and Odd Basis Lists**
Based on the $\mathfrak{osp}(2|2n)$ root system, the basis elements for $C(n+1)$ are:
*   **C(2) / n=1 (Total 8)**
    *   **Even (4):** $H_1, H_2, E_{2\delta_1}, E_{-2\delta_1}$
    *   **Odd (4):** $E_{\varepsilon+\delta_1}, E_{\varepsilon-\delta_1}, E_{-\varepsilon+\delta_1}, E_{-\varepsilon-\delta_1}$
*   **C(3) / n=2 (Total 19)**
    *   **Even (11):** $H_1, H_2, H_3, E_{2\delta_1}, E_{-2\delta_1}, E_{2\delta_2}, E_{-2\delta_2}, E_{\delta_1+\delta_2}, E_{\delta_1-\delta_2}, E_{-\delta_1+\delta_2}, E_{-\delta_1-\delta_2}$
    *   **Odd (8):** $E_{\varepsilon+\delta_1}, E_{\varepsilon-\delta_1}, E_{-\varepsilon+\delta_1}, E_{-\varepsilon-\delta_1}, E_{\varepsilon+\delta_2}, E_{\varepsilon-\delta_2}, E_{-\varepsilon+\delta_2}, E_{-\varepsilon-\delta_2}$
*   **C(4) / n=3 (Total 34)**
    *   **Even (22):** $H_1, H_2, H_3, H_4$, $E_{\pm 2\delta_k}$ ($k \in \{1,2,3\}$), $E_{\pm\delta_i\pm\delta_j}$ ($1 \le i < j \le 3$)
    *   **Odd (12):** $E_{\pm\varepsilon\pm\delta_k}$ ($k \in \{1,2,3\}$)

**2. PBW Ordering Options & Decision**
*   **Option A:** Standard Highest Weight ($\mathfrak{n}^- < \mathfrak{h} < \mathfrak{n}^+$). Ordering lexicographically with $\varepsilon > \delta_1 > \dots > \delta_n > 0$.
*   **Option B:** Parity-separated (Even $<$ Odd). Sub-ordered internally by highest weight.
*   **Decision & Justification:** I chose **Option A**. The triangular decomposition ($\mathfrak{n}^- \oplus \mathfrak{h} \oplus \mathfrak{n}^+$) is crucial for defining Verma modules and correctly separating creation/annihilation operators when applying the normal form to the coboundary operator. Option B disrupts the natural Lie algebraic structure.

**3. Notation Conventions**
Oscillator and root string labels have been finalized (e.g., `a1+`, `bk-`, `H_k`, `E_eps+d1`). `handover/notation.md` has been updated to reflect these decisions.
