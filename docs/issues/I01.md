## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

### 1. Decisions & Options Considered
- **Fermionic Oscillator Choice**: Adopted the standard CAR pair $a_1^+, a_1^-$ (`a_1_p`, `a_1_m`) with $\{a_1^-, a_1^+\} = 1$, replacing the supplementary fermion $a_0$ ($a_0^2 = 1/2$) of $B(0,n)$.
- **PBW Ordering Options**:
  - *Option A (Adopted)*: $\kappa < [\text{odd}] < [\text{even}]$. Odd generators grouped by bosonic index $k=1,\ldots,n$ and sign profiles (`pp, pm, mp, mm`), followed by Cartan generators $H_1, \ldots, H_{n+1}$, followed by even root generators.
  - *Option B (Rejected)*: $\kappa < [\text{Cartan}] < [\text{even roots}] < [\text{odd}]$.
  - *Rationale*: Option A preserves the structural convention of the $B(0,n)$ schema specification v5.0, maximizing code and test reusability and keeping odd/even partition consistent across the codebase.
- **Generator Labeling**:
  - Fermion-boson odd generators: `E_eps1_del{k}_{sign_eps}{sign_del}` where signs are `p` for $+$ and `m` for $-$.
  - Cartan generators: `H_1, ..., H_{n+1}` where $H_1 = a_1^+ a_1^- + b_1^+ b_1^-$, $H_k = b_{k-1}^+ b_{k-1}^- - b_k^+ b_k^-$ ($2 \le k \le n$), and $H_{n+1} = -b_n^+ b_n^- - 1/2$.
  - Even root generators: `E_2del{k}_p`, `E_2del{k}_m`, `E_del{i}_del{j}_pp`, `E_del{i}_del{j}_pm`, `E_del{i}_del{j}_mp`, `E_del{i}_del{j}_mm`.
