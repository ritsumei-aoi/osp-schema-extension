## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

**Decision log (No-Gate condition):**

**Basis design:**
The root system of C(n+1) = osp(2|2n) has:
- Even roots: ±2δ_k (2n roots) ∪ ±(δ_i ± δ_j) for i<j (2n(n-1) roots) + Cartan (n+1)
  Total even dim = (n+1) + 2n^2 = 2n^2 + n + 1 ✓
- Odd roots: ±ε ± δ_k for k=1,...,n (4n roots, generators E_eps1_del{k}_{ss})

Basis counts verified: C(2)=8, C(3)=19, C(4)=34. All match formula 2n^2+5n+1.

**PBW ordering — options considered:**

Option A (chosen): κ < [odd, by sign group then boson index] < [even, Cartan then non-Cartan]
- Within odd: pp-group (k=1..n), pm-group (k=1..n), mp-group (k=1..n), mm-group (k=1..n)
- Within even non-Cartan: positive first (pp, p), then negative (mm, m), then mixed (pm, mp)
- Rationale: Follows B(0,n) convention closely (odd before even), groups sign patterns for readability.

Option B: κ < [odd sorted by root magnitude then lexicographic]
- Would require defining a total order on ε, δ vectors, more complex to document.

**Chosen**: Option A, documented in handover/notation.md.

**Generator label design:**
- Odd generators: E_eps1_del{k}_{s1s2} where s1 is sign of ε-part and s2 is sign of δ_k-part.
  E.g., ε+δ_k → pp, ε-δ_k → pm, -ε+δ_k → mp, -ε-δ_k → mm.
- Consistent with B(0,n) conventions (pp/pm/mp/mm suffix for two-oscillator generators).
