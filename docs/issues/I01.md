## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

#### Summary
Conventions finalized in `handover/notation.md` (sections 1–5).

#### 1. Basis lists
Even basis (dim $2n^2+n+1$) = Cartan `H_1..H_{n+1}` + $\mathfrak{sp}(2n)$ root vectors; odd basis (dim $4n$) = `E_eps1_del{k}_{pp,pm,mp,mm}`.
Counts: C(2) 4|4 (total 8), C(3) 11|8 (19), C(4) 22|12 (34) — matches `Cn1_definition.md` table.
Explicit lists for n=1,2,3 are in `notation.md` §3 (and will be machine-checked in I03 tests).

#### 2. PBW ordering — options considered
| Option | Ordering | Pros | Cons |
|---|---|---|---|
| A (chosen) | κ < [odd: pp-block, pm-block, mp-block, mm-block; each by k] < [even as B(0,n)] | Same top-level structure as B(0,n) (`κ < [odd] < [even]`); positive odd roots ε±δ_k (distinguished system) precede negative ones, mirroring B(0,n) `E_del{k}_p` before `E_del{k}_m`; trivial to generate programmatically | Not ordered by root height |
| B | κ < [odd sorted by height w.r.t. distinguished simple roots] < [even] | Root-theoretic | Height order depends on the choice of simple system; differs from B(0,n) layout; harder to diff against B data |
| C | κ < [even] < [odd] | Even subalgebra first | Breaks compatibility with B(0,n) v5.0 convention |
| D | interleave by k (`del1_pp, del1_pm, del1_mp, del1_mm, del2_pp, …`) | groups by boson index | sign-blocks broken; B(0,n) groups by sign first |

**Decision**: Option A, because the issues require backward compatibility with B(0,n) v5.0 (I02) and A is the minimal change of the B(0,n) rule `E_del{k}_p (all k) < E_del{k}_m (all k)`.

#### 3. Generator labels
Oscillators `a_1_p, a_1_m, b_k_p, b_k_m, kappa, K`; root labels per the B(0,n) table with `E_eps1_del{k}_{σs}` for odd roots σε + sδ_k.

#### Ambiguities found and assumptions adopted (No-Gate: decided by agent)
1. **Normalization of $E_{\pm2\delta_n}$**: `Cn1_definition.md` gives $\tfrac12 (b_n^\pm)^2$ for the simple generator but $(b_k^\pm)^2$ in "all root generators". Options: (a) use $(b_k^\pm)^2$ uniformly, (b) use $\tfrac12(b_k^\pm)^2$ uniformly, (c) mixed. **Chosen (a)**: uniform, matches the B(0,n) label table; the normalization only rescales structure constants and has no effect on triviality (I08). The Chevalley element is $\tfrac12$ `E_2del{n}_p`.
2. **Cartan basis**: options (a) Chevalley coroots `H_1..H_{n+1}` of `Cn1_definition.md`, (b) orthogonal $h_\varepsilon, h_k$. **Chosen (a)** for consistency with the reference document; verified that $\{H_i\}$ is a basis of the Cartan subalgebra (triangular in $h_n, h_{n-1}, \dots, h_1, h_\varepsilon$).
3. **Constants in Cartan generators**: $H_{n+1} = -b_n^+b_n^- - \tfrac12$ and $H_1 = a_1^+a_1^- + b_1^+b_1^-$ are exactly the Weyl-symmetrized forms; I adopt Weyl ordering for all even generators so the generator span closes without $K$ (checked in I03).
4. **Sign of $H_{n+1}$** differs from B(0,n) ($H_n = +b_n^+b_n^- + \tfrac12$). Followed the C(n+1) document.
