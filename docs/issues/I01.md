## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

#### Basis Design

C(n+1) = osp(2|2n) has oscillators: standard fermionic pair a_1^±  (CAR: {a_1^-, a_1^+}=1) and bosonic oscillators b_k^± (k=1..n, CCR).

Even generators: n+1 Cartan elements H_1..H_{n+1}, roots ±2δ_k (2n generators), ±(δ_i±δ_j) for i<j (2n(n-1) generators). Total: 2n²+n+1 ✓

Odd generators: roots ±ε±δ_k for k=1..n (4n generators) ✓

#### PBW Ordering Decision

Two options considered:
- Option A: κ < fermionic oscillators < odd generators < even generators (mixes algebra/oscillator levels)
- Option B: κ < odd generators < even generators (parallel to B(0,n) convention)

**Adopted Option B** for consistency with B(0,n) schema convention. Within odd: ordered by sign pattern (pp, pm, mp, mm) and within each sign pattern by index k. Within even: Cartan first, then positive roots, then negative roots by type.

#### Generator Label Convention

Odd generators: `E_eps1_del{k}_{ss}` where ss ∈ {pp, pm, mp, mm} encoding (sign of ε, sign of δ_k).
Even generators: `E_2del{k}_{p/m}`, `E_del{i}_del{j}_{ss}` for i<j.
Central: `K` (parity 0, K=1), `kappa` (parity 1, nilpotent).

All conventions documented in `handover/notation.md`.
