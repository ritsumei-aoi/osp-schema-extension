## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

#### 1. Options Considered for PBW Ordering
We considered two primary PBW ordering designs:
- **Option 1: Graded Sector Ordering ($\kappa < \text{Odd} < \text{Even}$)**
  - Order: $\kappa < \text{Odd}(\pm\varepsilon \pm \delta_k) < \text{Cartan}(H_1, \dots, H_{n+1}) < \text{Even Roots}(\pm 2\delta_k, \pm\delta_i \pm \delta_j)$.
  - Rationale: Directly extends the $B(0,n)$ convention established in `docs/math/B0n_schema_v5.md`. Preserves the block-graded separation between fermionic (odd) and bosonic (even) sectors, simplifying linear algebra indexing for coboundary and deformation structures.
- **Option 2: Triangular Root Decomposition Ordering ($\mathfrak{g}^+ < \mathfrak{h} < \mathfrak{g}^-$)**
  - Order: Positive odd/even roots < Cartan generators < Negative odd/even roots.
  - Rationale: Natural in representation theory (Verma modules), but creates parity-interleaved basis lists that break compatibility with the 4-layer JSON schema structure.

**Decision**: Adopt **Option 1 (Graded Sector Ordering)** for complete backward compatibility and mathematical consistency across the schema layers.

#### 2. Generator Notation and Labeling Conventions
- **Bosonic Oscillators**: `b_j_p` ($b_j^+$), `b_j_m` ($b_j^-$) for $j=1, \dots, n$ (parity 0).
- **Fermionic Oscillators**: `a_1_p` ($a_1^+$), `a_1_m` ($a_1^-$) (parity 1, standard CAR pair $\{a_1^-, a_1^+\} = 1$).
- **Cartan Elements ($n+1$)**:
  - $H_1 = a_1^+ a_1^- + b_1^+ b_1^-$
  - $H_k = b_{k-1}^+ b_{k-1}^- - b_k^+ b_k^-$ ($2 \le k \le n$)
  - $H_{n+1} = b_n^+ b_n^- + \frac{1}{2}$
- **Even Root Generators ($2n^2$)**:
  - Long roots: `E_2del{k}_p` = $(b_k^+)^2$, `E_2del{k}_m` = $(b_k^-)^2$
  - Short roots ($1 \le i < j \le n$): `E_del{i}_del{j}_pp` ($b_i^+ b_j^+$), `E_del{i}_del{j}_pm` ($b_i^+ b_j^-$), `E_del{i}_del{j}_mp` ($b_i^- b_j^+$), `E_del{i}_del{j}_mm` ($b_i^- b_j^-$)
- **Odd Root Generators ($4n$)**:
  - `E_eps1_del{k}_pp` = $a_1^+ b_k^+$
  - `E_eps1_del{k}_pm` = $a_1^+ b_k^-$
  - `E_eps1_del{k}_mp` = $a_1^- b_k^+$
  - `E_eps1_del{k}_mm` = $a_1^- b_k^-$
