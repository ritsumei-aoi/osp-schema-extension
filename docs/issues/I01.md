## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

## Requirements

3. Design oscillator generator labels consistent with `handover/notation.md`.

### Response

**Decisions**
- Basis dimensions checked against `docs/math/Cn1_definition.md`: C(2) = 4+4 = 8, C(3) = 11+8 = 19, C(4) = 22+12 = 34. Even basis = Cartan (n+1) plus roots ±2δ_k and ±(δ_i±δ_j); odd basis = ±ε±δ_k (4n).
- Odd generators use four labels per k (`E_eps1_del{k}_{pp,pm,mp,mm}`), with the sign pattern giving the ε sign then the δ sign.
- PBW ordering: κ < [odd] < [even], K excluded. Options considered: (A) odd-first (chosen), (B) even-first, (C) height-interleaved. Reason for (A): it matches B(0,n) so only the odd block changes.
- Cartan: H_1 = a_1^+a_1^- + b_1^+b_1^-, H_k = b_{k-1}^+b_{k-1}^- - b_k^+b_k^- for 2≤k≤n, H_{n+1} = -b_n^+b_n^- - 1/2.

**Ambiguity recorded**: `docs/math/C_inhomogeneous_definition.md` uses the gb index order (σ, j, s), whereas the I05 `gb_matrix` shape is 2×2n. I adopt row = σ, column = (j, s) to match that shape.
