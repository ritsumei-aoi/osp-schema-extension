## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

  - Odd (4): `E_eps1_del1_pp`, `E_eps1_del1_pm`, `E_eps1_del1_mp`, `E_eps1_del1_mm`
- **C(3) / n=2:**

  - Odd (8): `E_eps1_del1_pp`, `E_eps1_del1_pm`, `E_eps1_del1_mp`, `E_eps1_del1_mm`, `E_eps1_del2_pp`, `E_eps1_del2_pm`, `E_eps1_del2_mp`, `E_eps1_del2_mm`
- **C(4) / n=3:**
  - Even (22): `H_1`..`H_4`, `E_2del1_p/m`, `E_2del2_p/m`, `E_2del3_p/m`, `E_del1_del2_pp/mm/pm/mp`, `E_del1_del3_pp/mm/pm/mp`, `E_del2_del3_pp/mm/pm/mp`
  - Odd (12): `E_eps1_del1_pp/pm/mp/mm`, `E_eps1_del2_pp/pm/mp/mm`, `E_eps1_del3_pp/pm/mp/mm`

**2. PBW Ordering Options Considered**
- **Option 1 (Parity-grouped, B(0,n) style):** `κ < [odd] < [even]`. This separates odd and even sectors entirely, matching the existing B(0,n) schema's structure.
- **Option 2 (Lexicographical Roots):** Pure lexicographical ordering of roots, intertwining odd and even generators.

*Decision:* I have chosen **Option 1** because maintaining consistency with the established B(0,n) schema reduces friction when extending the JSON schema for C(n+1).

**3. Generator Labels**
Finalized as `E_2del{k}_p/m`, `E_del{i}_del{j}_pp/mm/pm/mp`, and `E_eps1_del{k}_pp/pm/mp/mm`.

**4. Updates**
`handover/notation.md` has been updated with these conventions. All completion criteria met.
