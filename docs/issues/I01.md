## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

#### 1. Even and Odd Basis Lists for C(2), C(3), C(4)

**C(2)** (n=1): C(2) = osp(2|2) with 4 even + 4 odd = 8 generators

Even basis (4 generators):
- `H_1` = $a_1^+ a_1^- + b_1^+ b_1^-$ (Cartan)
- `H_2` = $-b_1^+ b_1^- - 1/2$ (Cartan)
- `E_{2\delta_1}_p` = $(1/2)(b_1^+)^2$ (even root)
- `E_{2\delta_1}_m` = $(1/2)(b_1^-)^2$ (even root)

Odd basis (4 generators):
- `E_{\varepsilon + \delta_1}_pp` = $a_1^+ b_1^+$ (odd root)
- `E_{\varepsilon - \delta_1}_pm` = $a_1^+ b_1^-$ (odd root)
- `E_{-\varepsilon + \delta_1}_mp` = $a_1^- b_1^+$ (odd root)
- `E_{-\varepsilon - \delta_1}_mm` = $a_1^- b_1^-$ (odd root)

**C(3)** (n=2): C(3) = osp(2|4) with 11 even + 8 odd = 19 generators

Even basis (11 generators):
- `H_1` = $a_1^+ a_1^- + b_1^+ b_1^-$ (Cartan)
- `H_2` = $b_1^+ b_1^- - b_2^+ b_2^-$ (Cartan)
- `H_3` = $-b_2^+ b_2^- - 1/2$ (Cartan)
- `E_{2\delta_1}_p`, `E_{2\delta_1}_m` = $(b_1^+)^2, (b_1^-)^2$
- `E_{2\delta_2}_p`, `E_{2\delta_2}_m` = $(1/2)(b_2^+)^2, (1/2)(b_2^-)^2$
- `E_{\delta_1 + \delta_2}_pp` = $b_1^+ b_2^+$
- `E_{\delta_1 - \delta_2}_pm` = $b_1^+ b_2^-$
- `E_{-\delta_1 + \delta_2}_mp` = $b_1^- b_2^+$
- `E_{-\delta_1 - \delta_2}_mm` = $b_1^- b_2^-$

Odd basis (8 generators):
- `E_{\varepsilon + \delta_1}_pp` = $a_1^+ b_1^+$
- `E_{\varepsilon - \delta_1}_pm` = $a_1^+ b_1^-$
- `E_{-\varepsilon + \delta_1}_mp` = $a_1^- b_1^+$
- `E_{-\varepsilon - \delta_1}_mm` = $a_1^- b_1^-$
- `E_{\varepsilon + \delta_2}_pp` = $a_1^+ b_2^+$
- `E_{\varepsilon - \delta_2}_pm` = $a_1^+ b_2^-$
- `E_{-\varepsilon + \delta_2}_mp` = $a_1^- b_2^+$
- `E_{-\varepsilon - \delta_2}_mm` = $a_1^- b_2^-$

**C(4)** (n=3): C(4) = osp(2|6) with 22 even + 12 odd = 34 generators

Even basis (22 generators):
- Cartan: `H_1`, `H_2`, `H_3`, `H_4` (4 generators)
- Even roots from $\pm 2\delta_k$: `E_{2\delta_k}_p`, `E_{2\delta_k}_m` for $k=1,2,3$ (6 generators)
- Even roots from $\pm(\delta_i \pm \delta_j)$ for $i < j$: 12 generators (3 pairs of indices, 4 combinations each)

Odd basis (12 generators):
- `E_{\pm\varepsilon \pm \delta_k}` for $k=1,2,3$: 4 roots × 3 indices = 12 generators

#### 2. PBW Ordering with ε-Roots

**Decision**: Use height-lexicographic ordering with fermionic-priority convention.

**Options considered**:
1. **Fermionic priority**: Order $\varepsilon < \delta_1 < \delta_2 < ... < \delta_n$. The height of a root is the sum of absolute coefficients. This ensures fermionic generators appear first.
2. **Standard δ priority**: Order $\delta_1 < \delta_2 < ... < \delta_n < \varepsilon$. Bosonic coordinates dominate.

**Choice**: Option 1 (fermionic priority)

**Justification**:
- In C(n+1), the fermionic pair $a_1^\pm$ is the "new" dimension compared to B(0,n), and it defines the extension from osp(1|2n) to osp(2|2n).
- Putting fermionic roots first reflects the algebraic structure: the fermionic coordinate $\varepsilon$ generates the family of odd roots.
- This mirrors the quantum field theory convention where fermionic fields are often listed first.
- Concrete ordering within each height level: lexicographic order on multi-indices.

**Explicit PBW ordering**:
- Height 1: $\varepsilon$
- Height 1: $\delta_1, \delta_2, ..., \delta_n$ (in index order)
- Height 2: $2\varepsilon, \varepsilon \pm \delta_1, ..., \varepsilon \pm \delta_n, \delta_1 \pm \delta_2, ..., 2\delta_n$
- Higher heights follow recursively.

#### 3. Oscillator Generator Labels

**Convention**: Extend B(0,n) label scheme to include $\varepsilon$.

| Root | Generator Label | Oscillator Realization |
|---|---|---|
| $H_k$ | `H{k}` | (See simple generators) |
| $2\delta_k$ | `E_2del{k}_p` | $(b_k^+)^2$ (or $(1/2)(b_k^+)^2$ for $k=n$) |
| $-2\delta_k$ | `E_2del{k}_m` | $(b_k^-)^2$ (or $(1/2)(b_k^-)^2$ for $k=n$) |
| $\delta_i + \delta_j$ ($i<j$) | `E_del{i}_del{j}_pp` | $b_i^+ b_j^+$ |
| $\delta_i - \delta_j$ ($i<j$) | `E_del{i}_del{j}_pm` | $b_i^+ b_j^-$ |
| $-\delta_i + \delta_j$ ($i<j$) | `E_del{i}_del{j}_mp` | $b_i^- b_j^+$ |
| $-\delta_i - \delta_j$ ($i<j$) | `E_del{i}_del{j}_mm` | $b_i^- b_j^-$ |
| $\varepsilon + \delta_k$ | `E_eps_del{k}_pp` | $a_1^+ b_k^+$ |
| $\varepsilon - \delta_k$ | `E_eps_del{k}_pm` | $a_1^+ b_k^-$ |
| $-\varepsilon + \delta_k$ | `E_eps_del{k}_mp` | $a_1^- b_k^+$ |
| $-\varepsilon - \delta_k$ | `E_eps_del{k}_mm` | $a_1^- b_k^-$ |
