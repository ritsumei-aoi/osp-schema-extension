## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

**Decisions and Results**

#### 1. Even and Odd Basis Lists

Using the root system from `Cn1_definition.md`:
- Even roots: $\pm 2\delta_k$, $\pm(\delta_i \pm \delta_j)$ for $i<j$
- Odd roots: $\pm\varepsilon \pm \delta_k$
- Even subalgebra: $\mathfrak{so}(2) \times \mathfrak{sp}(2n)$, adding one Cartan element $H_1 = a_1^+ a_1^- + b_1^+ b_1^-$ vs B(0,n).

Explicit basis lists for C(2) (n=1, 4+4=8), C(3) (n=2, 11+8=19), C(4) (n=3, 22+12=34) are documented in `handover/notation.md`.

#### 2. PBW Ordering Decision

**Options considered**:
- **Option A**: $\kappa < [\text{odd}] < [\text{even}]$ — consistent with B(0,n) convention in the v5.0 schema.
- **Option B**: $\kappa < [\text{even}] < [\text{odd}]$ — standard in some mathematical references.

**Choice**: Option A. Rationale: maintains compatibility with the B(0,n) schema convention already established in `B0n_schema_v5.md`, making cross-schema comparisons straightforward.

Within odd sector: grouped by sign pattern (pp, pm, mp, mm), then by bosonic index within each group.
Within even sector: Cartan first, then positive root generators, negative root generators, mixed sign generators.

#### 3. Generator Label Convention

Odd generator labels use `E_eps_del{k}_{ss}` where the first sign is the $\varepsilon$ coefficient and the second is the $\delta_k$ coefficient:
- `E_eps_del{k}_pp` = $a_1^+ b_k^+$ (root $\varepsilon + \delta_k$)
- `E_eps_del{k}_pm` = $a_1^+ b_k^-$ (root $\varepsilon - \delta_k$)
- `E_eps_del{k}_mp` = $a_1^- b_k^+$ (root $-\varepsilon + \delta_k$)
- `E_eps_del{k}_mm` = $a_1^- b_k^-$ (root $-\varepsilon - \delta_k$)

Even generator labels follow B(0,n) conventions unchanged. The additional Cartan element $H_1$ (from the $\mathfrak{so}(2)$ factor) is new; subsequent Cartan elements shift index by 1.

All conventions are recorded in `handover/notation.md`.
