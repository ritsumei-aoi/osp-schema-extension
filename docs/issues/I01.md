## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

#### Analysis and Decisions

**1. Even and Odd Basis Lists (C(2), C(3), C(4))**

Completed and documented in `handover/notation.md` (see "C(n+1) Basis Structure" section).

Key observations:
- Even basis: Includes $n+1$ Cartan elements ($H_1, \ldots, H_{n+1}$) and $n^2+n$ root generators
- Odd basis: Includes $4n$ root generators of the form $E_{\varepsilon \pm \delta_k}$ for $k=1,\ldots,n$
- Dimension verification:
  - C(2): even=4, odd=4, total=8 ✓
  - C(3): even=11, odd=8, total=19 ✓
  - C(4): even=22, odd=12, total=34 ✓

**2. PBW Ordering with ε-roots**

Two concrete options were considered:

**Option 1 (Selected)**: Fermionic roots before bosonic roots
```
κ < [odd: E_eps_del{k}_{pp,pm,mp,mm}] < [even: H_j, bosonic roots]
```
Justification: This follows standard superalgebra conventions (Frappat et al., Kac) where odd generators are treated as "higher weight" than even generators. The fermionic roots, being associated with the standard CAR pair $a_1^\pm$, naturally precede the purely bosonic root generators in the positive direction.

**Option 2** (rejected): Bosonic roots before fermionic roots
```
κ < [even: H_j, bosonic roots] < [odd: E_eps_del{k}_{...}]
```
This would prioritize the simpler bosonic structure, but violates standard superalgebra conventions for weight orderings.

**Chosen**: Option 1. The ordering respects the natural hierarchy of root systems in superalgebras, where odd roots are considered "higher" in the Hasse diagram of positive roots.

**3. Oscillator Generator Labels**

Designed a consistent suffix convention for odd roots:
```
E_eps_del{k}_{XY}  where X,Y ∈ {p,m}
- X: sign of fermionic factor (p=a_1^+, m=a_1^-)
- Y: sign of bosonic factor (p=b_k^+, m=b_k^-)
```

Examples:
- `E_eps_del1_pp` = $a_1^+ b_1^+$
- `E_eps_del1_pm` = $a_1^+ b_1^-$
- `E_eps_del1_mp` = $a_1^- b_1^+$
- `E_eps_del1_mm` = $a_1^- b_1^-$
