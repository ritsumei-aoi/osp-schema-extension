## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

**Result**: `handover/notation.md` rewritten with the full conventions (oscillator letters, generator labels, even/odd bases for C(2), C(3), C(4), PBW order, normalization). Dimensions confirmed by code (`src/C_generators.py`): C(2) 4|4, C(3) 11|8, C(4) 22|12 (matches `Cn1_definition.md`).

**PBW ordering options considered**
- (A) B(0,n)-style block order: κ < odd < even; even = Cartan, then 2δ_k and δ_i+δ_j (positive type), then negative type, then mixed pm/mp. Direct extension of the v5.0 convention.
- (B) Root-height order (negative roots < Cartan < positive roots), the textbook PBW ordering. It interleaves odd and even generators, so it breaks the "κ < odd < even" convention of the v5.0 spec.
- (C) Group odd generators by the ε-root first (+ε block, −ε block).
- **Chosen: (A) with the (C)-style grouping inside the odd block** (ε-sign outermost, then δ-sign, then k). Reason: backward compatibility with B(0,n) v5.0 (`basis.ordering_convention`), and the ε-sign grouping matches the oscillator letter order a_1_p < a_1_m.

**Ambiguities / assumptions (ai_trust_policy Boundary)**
- A1: `Cn1_definition.md` gives E_{±2δ_n} = ½(b_n^±)² in the simple-generator table but (b_k^±)² in the general formula. Adopted (b^±)² everywhere (matches the B(0,n) label table). Only an overall scale of those generators is affected; Jacobi is unaffected.
- A2: H_1 = a_1^+a_1^- + b_1^+b_1^- as given (includes the so(2) part), so H_1..H_{n+1} span an (n+1)-dim Cartan inside the (n+2)-dim space {N_a, N_1..N_n, 1}. The constant in H_{n+1} = −N_n − 1/2 is what makes brackets close with K = 1 (verified in I03: every bracket expands exactly in the basis).
- A3: Odd label `E_eps1_del{k}_{e}{d}`: first letter = sign of ε, second = sign of δ_k (per `B0n_schema_v5.md`).
