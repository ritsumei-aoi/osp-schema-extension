## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

#### 1. Basis Lists

Derived from `Cn1_definition.md`. The even subalgebra is so(2)×sp(2n), dim = 2n²+n+1; the odd sector has dimension 4n (roots ±ε±δ_k).

**C(2) = osp(2|2), n=1**, dim (4|4):
- Even (4): `H_1, H_2, E_2del1_p, E_2del1_m`
- Odd (4): `E_eps_del1_pp, E_eps_del1_pm, E_eps_del1_mp, E_eps_del1_mm`

**C(3) = osp(2|4), n=2**, dim (11|8):
- Even (11): `H_1, H_2, H_3, E_2del1_p, E_2del2_p, E_del1_del2_pp, E_2del1_m, E_2del2_m, E_del1_del2_mm, E_del1_del2_pm, E_del1_del2_mp`
- Odd (8): `E_eps_del1_pp, E_eps_del1_pm, E_eps_del1_mp, E_eps_del1_mm, E_eps_del2_pp, E_eps_del2_pm, E_eps_del2_mp, E_eps_del2_mm`

**C(4) = osp(2|6), n=3**, dim (22|12):
- Even (22): `H_1, H_2, H_3, H_4, E_2del1_p, E_2del2_p, E_2del3_p, E_del1_del2_pp, E_del1_del3_pp, E_del2_del3_pp, E_2del1_m, E_2del2_m, E_2del3_m, E_del1_del2_mm, E_del1_del3_mm, E_del2_del3_mm, E_del1_del2_pm, E_del1_del2_mp, E_del1_del3_pm, E_del1_del3_mp, E_del2_del3_pm, E_del2_del3_mp`
- Odd (12): `E_eps_del{k}_{pp/pm/mp/mm}` for k=1,2,3 (12 total)

Dimension check: even = 4+6+4+4+4 = 22 ✓, odd = 12 ✓

#### 2. PBW Ordering Decision

Two options considered:
- **Option A** (chosen): `κ < [odd: ε-roots] < [even: Cartan, positive, negative, mixed]` — consistent with B(0,n) convention.
- **Option B**: `κ < [positive bosonic] < [fermionic] < [negative bosonic]` — rejected because it mixes parity classes.

**Chosen ordering**: Option A. Rationale: preserves the standard superalgebra PBW convention, groups all odd (fermionic ε-type) generators before even generators, and aligns with the existing B(0,n) schema.

#### 3. Generator Labels

Established in `handover/notation.md`. Key label pattern:
- Odd: `E_eps_del{k}_{ss}` where ss ∈ {pp, pm, mp, mm} (signs of ε and δ_k)
- Even: same as B(0,n) convention for bosonic sector
