## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

#### 1. Basis Definitions for $C(n+1) = \mathfrak{osp}(2|2n)$ ($n=1, 2, 3$)
Following Frappat et al. (2000), the root system consists of:
- Bosonic roots $\Delta_{\bar{0}} = \{\pm 2\delta_k\} \cup \{\pm(\delta_i \pm \delta_j) \mid 1 \le i < j \le n\}$.
- Fermionic roots $\Delta_{\bar{1}} = \{\pm \varepsilon \pm \delta_k \mid 1 \le k \le n\}$.
- Cartan subalgebra of dimension $n+1$: $\{H_1, \ldots, H_{n+1}\}$.

The explicit dimensions are:
- $n=1$ ($C(2) = \mathfrak{osp}(2|2)$): Even = 4, Odd = 4, Total = 8.
- $n=2$ ($C(3) = \mathfrak{osp}(2|4)$): Even = 11, Odd = 8, Total = 19.
- $n=3$ ($C(4) = \mathfrak{osp}(2|6)$): Even = 22, Odd = 12, Total = 34.

The explicit basis lists:
- **$n=1$ ($C(2)$)**:
  - `even`: `["H_1", "H_2", "E_2del1_p", "E_2del1_m"]`
  - `odd`: `["E_eps1_del1_pp", "E_eps1_del1_pm", "E_eps1_del1_mp", "E_eps1_del1_mm"]`
- **$n=2$ ($C(3)$)**:
  - `even`: `["H_1", "H_2", "H_3", "E_2del1_p", "E_2del2_p", "E_del1_del2_pp", "E_2del1_m", "E_2del2_m", "E_del1_del2_mm", "E_del1_del2_pm", "E_del1_del2_mp"]`
  - `odd`: `["E_eps1_del1_pp", "E_eps1_del2_pp", "E_eps1_del1_pm", "E_eps1_del2_pm", "E_eps1_del1_mp", "E_eps1_del2_mp", "E_eps1_del1_mm", "E_eps1_del2_mm"]`
- **$n=3$ ($C(4)$)**:
  - `even`: `["H_1", "H_2", "H_3", "H_4", "E_2del1_p", "E_2del2_p", "E_2del3_p", "E_del1_del2_pp", "E_del1_del3_pp", "E_del2_del3_pp", "E_2del1_m", "E_2del2_m", "E_2del3_m", "E_del1_del2_mm", "E_del1_del3_mm", "E_del2_del3_mm", "E_del1_del2_pm", "E_del1_del3_pm", "E_del2_del3_pm", "E_del1_del2_mp", "E_del1_del3_mp", "E_del2_del3_mp"]`

#### 2. PBW Ordering Options and Decision
Two concrete ordering options were evaluated:
- **Option 1 (Root-Type Block Ordering)**:
  Order: $\kappa < [\text{odd}] < [\text{even}]$.
  - Odd block: all `pp` roots, followed by all `pm` roots, then all `mp` roots, then all `mm` roots (sub-sorted by bosonic index $k$).
  - Even block: Cartan block $H_1, \ldots, H_{n+1}$, positive long roots `2del_p`, positive cross roots `pp`, negative long roots `2del_m`, negative cross roots `mm`, and mixed cross roots `pm`, `mp`.
- **Option 2 (Mode-Clustered Ordering)**:
  Order: $\kappa < [\text{odd}] < [\text{even}]$.
  - Odd block: clustered per bosonic mode $k$: for $k=1,\ldots,n$, list (`E_eps1_del{k}_pp`, `pm`, `mp`, `mm`).
  - Even block: Cartan block, followed by mode-clustered root pairs.

**Decision & Justification**: Option 1 was selected. It directly mirrors the conventions in the existing $B(0,n)$ v5.0 schema where positive root blocks precede negative root blocks, conforming naturally to the triangular decomposition $\mathfrak{g} = \mathfrak{n}^- \oplus \mathfrak{h} \oplus \mathfrak{n}^+$.

#### 3. Generator Labels and Oscillator Realizations
- Fermionic oscillators: $a_1^+, a_1^-$ labelled as `"a_1_p"`, `"a_1_m"`.
- Bosonic oscillators: $b_k^+, b_k^-$ labelled as `"b_{k}_p"`, `"b_{k}_m"`.
- Cartans:
  - $H_1 = a_1^+ a_1^- + b_1^+ b_1^-$
  - $H_k = b_{k-1}^+ b_{k-1}^- - b_k^+ b_k^-$ ($2 \le k \le n$)
  - $H_{n+1} = -b_n^+ b_n^- - 1/2$
- Root generators:
  - `E_2del{k}_p` $= (b_k^+)^2$, `E_2del{k}_m` $= (b_k^-)^2$
  - `E_del{i}_del{j}_pp` $= b_i^+ b_j^+$, `E_del{i}_del{j}_mm` $= b_i^- b_j^-$
  - `E_del{i}_del{j}_pm` $= b_i^+ b_j^-$, `E_del{i}_del{j}_mp` $= b_i^- b_j^+$
  - `E_eps1_del{k}_pp` $= a_1^+ b_k^+$, `E_eps1_del{k}_pm` $= a_1^+ b_k^-$
  - `E_eps1_del{k}_mp` $= a_1^- b_k^+$, `E_eps1_del{k}_mm` $= a_1^- b_k^-$
- Central elements: `kappa` (parity 1) and `K` (parity 0).

`handover/notation.md` has been fully updated with these conventions.
