## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

#### 1. Analysis and Generator Labeling Convention
In $C(n+1) = \mathfrak{osp}(2|2n)$, the fermionic sector is realized by a standard CAR oscillator pair:
- `a_1_p` ($a_1^+$), `a_1_m` ($a_1^-$) with $\{a_1^-, a_1^+\} = 1$, parity $p = 1$.
The bosonic sector comprises $n$ CCR oscillator pairs:
- `b_k_p` ($b_k^+$), `b_k_m` ($b_k^-$) with $[b_j^-, b_k^+] = \delta_{jk}$, parity $p = 0$.

The root system decomposition leads to the following Lie superalgebra generators:
- **Even sector** ($\dim = 2n^2 + n + 1$, parity 0):
  - Cartan generators: $H_1, \ldots, H_{n+1}$ ($n+1$ total), where $H_1 = a_1^+ a_1^- + b_1^+ b_1^-$, $H_k = b_{k-1}^+ b_{k-1}^- - b_k^+ b_k^-$ ($2 \le k \le n$), and $H_{n+1} = -b_n^+ b_n^- - 1/2$.
  - Long roots $\pm 2\delta_k$: `E_2del{k}_p` = $(b_k^+)^2$, `E_2del{k}_m` = $(b_k^-)^2$.
  - Cross roots $\pm \delta_i \pm \delta_j$ ($1 \le i < j \le n$): `E_del{i}_del{j}_pp`, `E_del{i}_del{j}_mm`, `E_del{i}_del{j}_pm`, `E_del{i}_del{j}_mp`.
- **Odd sector** ($\dim = 4n$, parity 1):
  - Roots $\pm \varepsilon \pm \delta_k$:
    - `E_eps1_del{k}_pp` ($+\varepsilon + \delta_k$): $a_1^+ b_k^+$
    - `E_eps1_del{k}_pm` ($+\varepsilon - \delta_k$): $a_1^+ b_k^-$
    - `E_eps1_del{k}_mp` ($-\varepsilon + \delta_k$): $a_1^- b_k^+$
    - `E_eps1_del{k}_mm` ($-\varepsilon - \delta_k$): $a_1^- b_k^-$

#### 2. PBW Ordering Options and Decision
Two concrete PBW ordering schemes were analyzed:
- **Option 1 (Parity-Split PBW: Odd < Even)**:
  $$\kappa < [\mathfrak{g}_{\bar{1}}] < [\mathfrak{g}_{\bar{0}}]$$
  Odd generators ordered by $(k, \text{sign profile } \mathtt{pp < pm < mp < mm})$, followed by Cartan generators, then positive roots, negative roots, and mixed roots.
- **Option 2 (Triangular Root-Height PBW)**:
  $$E^- < H < E^+$$
  Generators ordered by root height regardless of parity.

**Decision & Justification**: Option 1 was selected.
- Compatibility: Matches the v5.0 JSON schema architectural structure from $B(0,n)$ where `basis.even` and `basis.odd` are separate ordered arrays.
- Nilpotency stratification: Placing odd (Grassmann) variables before even (polynomial) variables simplifies canonical reduction and representation theory in $\mathcal{U}(\mathfrak{g})$.
