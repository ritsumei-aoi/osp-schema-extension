## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

3. Design oscillator generator labels consistent with `handover/notation.md`.

### Response

#### Decisions and Results

**1. Even and odd basis lists**

Defined for all three ranks using the Frappat et al. convention:
- C(2) = osp(2|2), n=1: 4 even + 4 odd = 8 total ✓
- C(3) = osp(2|4), n=2: 11 even + 8 odd = 19 total ✓
- C(4) = osp(2|6), n=3: 22 even + 12 odd = 34 total ✓

Dimension formulas verified: even = 2n²+n+1, odd = 4n, total = 2n²+5n+1.

**2. PBW ordering decision**

Two options considered:

*Option A*: κ < [odd] < [even] — consistent with B(0,n) convention from the base schema.
*Option B*: κ < [even] < [odd] — alternative ordering.

**Chose Option A** because:
- Direct consistency with the B(0,n) v5.0 schema convention (the base case uses κ < [odd] < [even]).
- Preserves backward compatibility, making cross-algebra comparisons straightforward.
- The odd sector is "lower" in PBW ordering, which aligns with the convention that fermionic generators precede bosonic composites in the oscillator algebra.

Within the odd sector, generators are grouped by ε-sign (positive ε first, then negative ε), and within each group by δ-index. Within the even sector: Cartan first, then positive roots, negative roots, mixed roots.

**3. Generator labels**

Labels follow the pattern `E_{root_description}_{signs}`:
- Even roots: same as B(0,n) — `E_2del{k}_p/m`, `E_del{i}_del{j}_pp/pm/mp/mm`
- Odd roots: `E_eps1_del{k}_pp/pm/mp/mm` (ε sign first, then δ sign)
- Cartan: `H_1` through `H_{n+1}` (n+1 Cartan generators, one more than B(0,n))

All conventions documented in `handover/notation.md`.
