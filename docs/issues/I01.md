## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

**Decision and rationale.** The even basis has \(n+1\) Cartan generators,
\(2n\) long-root generators, and \(4\binom{n}{2}\) mixed-root generators;
the odd basis has four generators for each \(k\). This gives the required
dimensions \(2n^2+n+1\) and \(4n\). I compared a root-system order
(negative roots, Cartan, positive roots) with the established B-schema
parity-block order. I selected the latter for consistent schema serialization,
and specified a stable sign/index order within each block. The labels use
`H_eps`, `H_k`, `E_2del{k}_{p|m}`, `E_del{i}_del{j}_{pp|pm|mp|mm}`, and
`E_eps1_del{k}_{pp|pm|mp|mm}`; oscillator labels are `a_1_p/m` and
`b_k_p/m`.
