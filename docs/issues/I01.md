## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

#### Decisions and Analysis

**Even/Odd Basis Lists**: Derived from the root system of C(n+1) = osp(2|2n):
- Even roots: $\{\pm 2\delta_k\} \cup \{\pm(\delta_i \pm \delta_j) \mid i < j\}$, giving $2n^2$ root generators + $(n+1)$ Cartan = $2n^2+n+1$ total even generators.
- Odd roots: $\{\pm\varepsilon \pm \delta_k\}$, giving $4n$ odd generators.
- Verified against dimension formula: even $= 2n^2+n+1$, odd $= 4n$, total $= 2n^2+5n+1$. ✓
  - C(2): 4|4=8 ✓; C(3): 11|8=19 ✓; C(4): 22|12=34 ✓.

**PBW Ordering**: Two options considered:
- Option A (chosen): $\kappa < [\text{odd}] < [\text{even}]$, following B(0,n) schema convention for consistency. Within odd: ordered by ε-sign first (positive-ε before negative-ε), then bosonic mode index. Within even: Cartan H_k, then positive sp(2n), then negative, then mixed.
- Option B (not chosen): Oscillator-level PBW ($a_1^+ < a_1^- < b_1^+ < b_1^- < \cdots$). Cleaner for computation, but less aligned with existing schema structure.

**Rationale**: Option A maintains schema consistency with B(0,n) and makes parity grouping explicit.

**Generator Labels**: Designed to extend the B(0,n) convention:
- B(0,n) used `E_del{k}_p/m` for $a_0 b_k^\pm$. For C(n+1), the fermionic pair $a_1^\pm$ replaces $a_0$, giving `E_eps1_del{k}_pp/pm/mp/mm` (4 labels per bosonic mode k).
- Label suffix `pp/pm/mp/mm` = (sign of ε, sign of δ_k). Consistent with even generators `E_del{i}_del{j}_pp/mm/pm/mp`.

#### Verification

All dimensions confirmed:
- n=1: even 4 = 2(1)+1+1 ✓, odd 4 = 4(1) ✓
- n=2: even 11 = 2(4)+2+1 ✓, odd 8 = 4(2) ✓
- n=3: even 22 = 2(9)+3+1 ✓, odd 12 = 4(3) ✓
