## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

3. Design oscillator generator labels consistent with `handover/notation.md`.

#### 2. Basis design

Even part (dimension $2n^2+n+1$), split as $\mathfrak{so}(2)\oplus\mathfrak{sp}(2n)$:

| Block | Label | Realization | Count |
|---|---|---|---|
| so(2) Cartan | `H_eps1` | $a_1^+a_1^- - \tfrac12$ | 1 |
| sp(2n) Cartan | `H_del{k}` | $b_k^+b_k^- + \tfrac12$ | $n$ |
| long roots | `E_2del{k}_p/m` | $(b_k^\pm)^2$ | $2n$ |
| short roots | `E_del{i}_del{j}_pp/mm/pm/mp` ($i<j$) | $b_i^{\pm}b_j^{\pm}$ | $4\binom n2$ |

$1+n+2n+2n(n-1) = 2n^2+n+1$ &check;

Odd part (dimension $4n$): `E_eps1_del{k}_pp/pm/mp/mm` $= a_1^{\pm}b_k^{\pm}$,
realizing the four odd roots $\pm\varepsilon\pm\delta_k$. &check;

Verified totals: $n=1\to 4|4=8$, $n=2\to 11|8=19$, $n=3\to 22|12=34$, matching
the table in `docs/math/Cn1_definition.md` §1.

#### 3. Decision: symmetrized Cartan normalization (ambiguity resolved)

`docs/math/Cn1_definition.md` gives the simple generators in the *unsymmetrized*
form $H_1 = a_1^+a_1^- + b_1^+b_1^-$, $H_{n+1} = -b_n^+b_n^- - \tfrac12$ — note
the document itself already carries a $-\tfrac12$ on the terminal Cartan, so the
normalization is not uniform across the document. Options considered:

- **(a) Unsymmetrized**: `H_eps1` $=a_1^+a_1^-$, `H_del{k}` $=b_k^+b_k^-$.
- **(b) Symmetrized** (chosen): `H_eps1` $=a_1^+a_1^--\tfrac12$,
  `H_del{k}` $=b_k^+b_k^-+\tfrac12$.
- **(c) Simple-root basis**: use Frappat's $H_1,\dots,H_{n+1}$ verbatim.

**Chosen: (b).** Reason: under (a) the even span does not close on itself in
$\mathcal U(A)$ — e.g.
$\{a_1^+b_k^+,\,a_1^-b_k^-\} = b_k^+b_k^- + 1 - a_1^+a_1^-$ leaves a residual
$+1\cdot K$, forcing every structure-constant table to carry spurious central
terms. Under (b) the same bracket is exactly `H_del{k}` $-$ `H_eps1`, and
$[(b_k^+)^2,(b_k^-)^2] = -4\,$`H_del{k}` exactly. (c) was rejected because the
simple-root Cartan is not orthogonal in the $\varepsilon/\delta$ labelling, which
would make the root-to-generator map in the JSON non-diagonal. The $\pm\tfrac12$
shifts are central, so (a), (b), (c) span the same Cartan subalgebra of
$C(n+1)$ modulo $K$; only (b) makes $K$ drop out identically. This choice is
re-verified computationally in I03/I04 (every structure constant lands in the
basis with zero $K$-component).

#### 4. Decision: PBW ordering

Three options were written out (`notation.md` §4.1): **A** grade-first
(`κ < odd < even`, the B(0,n) v5.0 layout), **B** triangular
(`negative < Cartan < positive`), **C** sector-first (fermionic sector first).

**Chosen: A.** Justification recorded in `notation.md` §4.2 — (i) it is the
literal transcription of the B(0,n) v5.0 ordering, preserving tooling/diff
compatibility, which is the explicit goal of this extension study; (ii) keeping
the odd block contiguous makes the parity-reversing map $f$ of Layer 4 a clean
2×2 block matrix; (iii) B would require fixing an arbitrary Borel for the
$\pm\varepsilon\pm\delta_k$ roots; (iv) C splits `H_eps1` from the other Cartan
elements for no structural gain.

Normal ordering of oscillator *words* (distinct from the PBW order on *generators*)
is fixed by the index map `kappa=0, a_1_p=1, a_1_m=2, b_k_p=2k+1, b_k_m=2k+2`.

#### 5. Label grammar

Suffix letters `p`/`m` are read left-to-right in the same order as the oscillator
word, so `E_eps1_del2_pm` $=a_1^+b_2^-$ unambiguously. This matches the suffix
grammar already used by B(0,n) (`E_del{i}_del{j}_pm` $=b_i^+b_j^-$) and the
target labels mandated in `docs/math/B0n_schema_v5.md` ("Task" table:
`E_eps1_del{k}_pp/pm/mp/mm`).

#### 6. Verification

Counts checked by hand and (later) by `tests/test_C_basis.py` in I03:
even/odd/total $=(4,4,8)$, $(11,8,19)$, $(22,12,34)$ for $n=1,2,3$.
All three completion criteria are satisfied.
