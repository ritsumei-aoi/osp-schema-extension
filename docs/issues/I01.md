## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

#### Even and Odd Basis Lists

**n=1 (C(2)=osp(2|2))**: dim=(4|4)
- Even (4): `H_1`, `H_2`, `E_2del1_p`, `E_2del1_m`
- Odd (4): `E_eps1_del1_pp`, `E_eps1_del1_pm`, `E_eps1_del1_mp`, `E_eps1_del1_mm`

**n=2 (C(3)=osp(2|4))**: dim=(11|8)
- Even (11): `H_1`, `H_2`, `H_3`, `E_2del1_p`, `E_2del2_p`, `E_del1_del2_pp`, `E_2del1_m`, `E_2del2_m`, `E_del1_del2_mm`, `E_del1_del2_pm`, `E_del1_del2_mp`
- Odd (8): `E_eps1_del{k}_{pp,pm,mp,mm}` for k=1,2

**n=3 (C(4)=osp(2|6))**: dim=(22|12)
- Even (22): `H_1..H_4`, six raising/lowering pairs for ±2δ_k and ±(δ_i±δ_j), six mixed
- Odd (12): `E_eps1_del{k}_{pp,pm,mp,mm}` for k=1,2,3

Dimension check: even=2n²+n+1, odd=4n ✓ for all three.

#### PBW Ordering Decision

Two options considered:
- **Option A** (chosen): κ < [odd by k then pp/pm/mp/mm] < [even: Cartan, raising, lowering, mixed] — mirrors B(0,n) v5.0 structure, simplifies code indexing.
- **Option B**: Interleave by root height — more natural algebraically but complicates label arrays in code.

**Decision**: Option A, for consistency with the existing B(0,n) schema and simpler implementation.

#### Generator Label Conventions

Odd generators use the prefix `E_eps1_del{k}_{sign}` where sign encodes (ε_sign, δ_sign): pp=(+,+), pm=(+,−), mp=(−,+), mm=(−,−). Even generators follow the same convention as B(0,n). All documented in `handover/notation.md`.
