## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

#### 1. Analysis and Basis Definition
For $C(n+1) = \mathfrak{osp}(2|2n)$ ($m=1$, bosonic rank $n \ge 1$):
- Superdimension: $(2n^2 + n + 1) \mid 4n$, total dimension $2n^2 + 5n + 1$.
- Even subalgebra: $\mathfrak{so}(2) \times \mathfrak{sp}(2n)$ of dimension $2n^2 + n + 1$, spanned by $n+1$ Cartan generators $H_1, \dots, H_{n+1}$, $2n$ long roots $\pm 2\delta_k$, and $2n(n-1)$ roots $\pm \delta_i \pm \delta_j$ ($1 \le i < j \le n$).
- Odd subspace: dimension $4n$, spanned by $4n$ roots $\pm \varepsilon \pm \delta_k$ ($k=1, \dots, n$).

Concrete basis sets:
- **$C(2) = \mathfrak{osp}(2|2)$ ($n=1$, dim $4 \mid 4$, total 8)**:
  - Even (4): `["H_1", "H_2", "E_2del1_p", "E_2del1_m"]`
  - Odd (4): `["E_eps1_del1_pp", "E_eps1_del1_pm", "E_eps1_del1_mp", "E_eps1_del1_mm"]`
- **$C(3) = \mathfrak{osp}(2|4)$ ($n=2$, dim $11 \mid 8$, total 19)**:
  - Even (11): `["H_1", "H_2", "H_3", "E_2del1_p", "E_2del2_p", "E_2del1_m", "E_2del2_m", "E_del1_del2_pp", "E_del1_del2_mm", "E_del1_del2_pm", "E_del1_del2_mp"]`
  - Odd (8): `["E_eps1_del1_pp", "E_eps1_del1_pm", "E_eps1_del1_mp", "E_eps1_del1_mm", "E_eps1_del2_pp", "E_eps1_del2_pm", "E_eps1_del2_mp", "E_eps1_del2_mm"]`
- **$C(4) = \mathfrak{osp}(2|6)$ ($n=3$, dim $22 \mid 12$, total 34)**:
  - Even (22): Cartans (4) `H_1`..`H_4`; $2\delta$ roots (6) `E_2del1_p`, `E_2del2_p`, `E_2del3_p`, `E_2del1_m`, `E_2del2_m`, `E_2del3_m`; cross roots (12) `E_del{i}_del{j}_{pp,mm,pm,mp}` for $(i,j) \in \{(1,2), (1,3), (2,3)\}$.
  - Odd (12): `E_eps1_del{k}_{pp,pm,mp,mm}` for $k=1, 2, 3$.

#### 2. PBW Ordering Options Considered
- **Option A (Odd-First PBW: $\kappa < [\text{odd}] < [\text{even}]$)**:
  - Nilpotent element $\kappa$ first, followed by all $4n$ odd generators (ordered by $k$ then `pp < pm < mp < mm`), followed by even generators (Cartans $H_1, \dots, H_{n+1}$, then positive even roots, then negative even roots).
  - *Pros*: Directly mirrors the v5.0 schema convention for $B(0,n)$ (`κ < [odd] < [even]`). Clear parity-block structuring simplifies representation of the parity-reversing linear map $f: \mathfrak{g}_{\bar{0}} \to \mathfrak{g}_{\bar{1}}$ and $f: \mathfrak{g}_{\bar{1}} \to \mathfrak{g}_{\bar{0}}$.
- **Option B (Root Height / Graded Cartan PBW)**:
  - $[\text{Cartan}] < [\text{Positive Even}] < [\text{Positive Odd}] < \kappa < [\text{Negative Odd}] < [\text{Negative Even}]$.
  - *Pros*: Follows standard Lie algebra triangular decomposition ($N^- \oplus H \oplus N^+$).
  - *Cons*: Intermingles parities, making block-matrix formulations of coboundary systems more complex and departing from the $B(0,n)$ schema architecture.

**Decision**: Selected **Option A**. It provides maximum continuity with the established $B(0,n)$ schema architecture, minimizes migration friction across JSON generators, and maintains clean parity-decoupled indexing.

#### 3. Generator Naming Conventions
- Fermionic oscillators: `a_1_p` ($a_1^+$), `a_1_m` ($a_1^-$).
- Bosonic oscillators: `b_k_p` ($b_k^+$), `b_k_m` ($b_k^-$) for $k \in \{1, \dots, n\}$.
- Odd generators: `E_eps1_del{k}_pp` ($a_1^+ b_k^+$), `E_eps1_del{k}_pm` ($a_1^+ b_k^-$), `E_eps1_del{k}_mp` ($a_1^- b_k^+$), `E_eps1_del{k}_mm` ($a_1^- b_k^-$).
- Even generators: Cartans `H_1`..`H_{n+1}`, long roots `E_2del{k}_p/m`, and mixed roots `E_del{i}_del{j}_pp/mm/pm/mp`.
