## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

#### Analysis & Design Decisions

**1. Even and Odd Basis Structure for C(n+1)**

C(n+1) = osp(2|2n) has superdimension (2n² + n + 1 | 4n).
Key structural difference from B(0,n): 
- Replaces supplementary fermion a₀ with standard fermionic pair a₁± (CAR: {a₁⁻, a₁⁺} = 1)
- Adds extra fermionic root dimension ε, giving 4n odd generators instead of 2n
- Adds one even generator to even subalgebra (so(2) × sp(2n) instead of sp(2n) alone)

**Basis for C(2) (n=1): Total 8 = 4 even + 4 odd**
- Even (4): H₁, H₂, E₂δ₁ₚ, E₂δ₁ₘ
- Odd (4): E_ε₁δ₁ₚₚ, E_ε₁δ₁ₚₘ, E_ε₁δ₁ₘₚ, E_ε₁δ₁ₘₘ

**Basis for C(3) (n=2): Total 19 = 11 even + 8 odd**
- Even (11): H₁, H₂, H₃, 
  - E₂δ₁ₚ, E₂δ₁ₘ, E₂δ₂ₚ, E₂δ₂ₘ
  - E_δ₁δ₂ₚₚ, E_δ₁δ₂ₚₘ, E_δ₁δ₂ₘₚ, E_δ₁δ₂ₘₘ
- Odd (8): E_ε₁δₖ_ss for k ∈ {1,2}, s ∈ {p,m}²

**Basis for C(4) (n=3): Total 34 = 22 even + 12 odd**
- Even (22): H₁, H₂, H₃, H₄,
  - E₂δₖ_s for k ∈ {1,2,3}, s ∈ {p,m}
  - E_δᵢδⱼ_ss for all i<j, all sign patterns ss
- Odd (12): E_ε₁δₖ_ss for k ∈ {1,2,3}, all sign patterns ss

**2. PBW Ordering: Two Candidate Options**

**Option A (Conservative): Odd generators before even, by index**
```
κ < [odd: E_ε₁δ₁ₚₚ, E_ε₁δ₁ₚₘ, E_ε₁δ₁ₘₚ, E_ε₁δ₁ₘₘ, E_ε₁δ₂ₚₚ, ...] 
   < [even: Cartan H₁...Hₙ₊₁, then roots by 2δₖ, then δᵢδⱼ]
```
**Rationale**: Matches B(0,n) pattern. Separates odd and even sectors cleanly. Follows creation-annihilation hierarchy within each index.

**Option B (Interleaved): Group by oscillator index across parities**
```
κ < [mixed: per-k generators for k=1,n ordered by: odd E_ε₁δₖ_ss, then even roots involving δₖ]
   < [remaining even: Cartan, higher-order roots]
```
**Rationale**: Clusters related generators. More compact representation.

**CHOICE: Option A (Conservative)**
Justification: 
- Maintains consistency with established B(0,n) schema conventions (seen in B0n_schema_v5.md)
- Cleaner separation of parities simplifies bracket computation
- Easier to verify triviality conditions per parity sector
- More natural for oscillator realization: fermionic term a₁±, bosonic terms b_k±

**3. Generator Labeling Convention**

**Oscillator labels** (extending B(0,n) convention):
- a_1_p := a₁⁺ (fermionic creation)
- a_1_m := a₁⁻ (fermionic annihilation)
- b_k_p := bₖ⁺ (bosonic creation, k=1...n)
- b_k_m := bₖ⁻ (bosonic annihilation, k=1...n)
- κ := central odd element

**Root generator labels** (systematic extension of B(0,n) convention):
| Root | Generator | Realization | Notes |
|---|---|---|---|
| ε + δₖ | E_eps1_del{k}_pp | a₁⁺ bₖ⁺ | fermionic +, bosonic + |
| ε - δₖ | E_eps1_del{k}_pm | a₁⁺ bₖ⁻ | fermionic +, bosonic - |
| -ε + δₖ | E_eps1_del{k}_mp | a₁⁻ bₖ⁺ | fermionic -, bosonic + |
| -ε - δₖ | E_eps1_del{k}_mm | a₁⁻ bₖ⁻ | fermionic -, bosonic - |
| 2δₖ | E_2del{k}_p | (bₖ⁺)² | root 2δₖ |
| -2δₖ | E_2del{k}_m | (bₖ⁻)² | root -2δₖ |
| δᵢ + δⱼ | E_del{i}_del{j}_pp | bᵢ⁺ bⱼ⁺ | both + |
| δᵢ - δⱼ | E_del{i}_del{j}_pm | bᵢ⁺ bⱼ⁻ | i +, j - |
| -δᵢ + δⱼ | E_del{i}_del{j}_mp | bᵢ⁻ bⱼ⁺ | i -, j + |
| -(δᵢ + δⱼ) | E_del{i}_del{j}_mm | bᵢ⁻ bⱼ⁻ | both - |

**Cartan generators**:
- Hₖ for k=1 to n+1 (n+1 generators)

**Deformation parameters** (for later use in inhomogeneous schema):
- gb_{a_1_p, b_j_p}, gb_{a_1_p, b_j_m}, gb_{a_1_m, b_j_p}, gb_{a_1_m, b_j_m} (4n parameters, parity 1)
