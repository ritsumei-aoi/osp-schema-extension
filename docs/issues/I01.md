## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

#### 1. Basis lists
Derived from `Cn1_definition.md` §1–2. Even part $\mathfrak{so}(2)\oplus\mathfrak{sp}(2n)$:
$n+1$ Cartan elements, $2n$ long roots $\pm2\delta_k$, $2n(n-1)$ short roots $\pm\delta_i\pm\delta_j$;
total $2n^2+n+1$. Odd part: $\pm\varepsilon\pm\delta_k$, $4n$ generators. Explicit lists for
$n=1,2,3$ are in `handover/notation.md` §3 (sizes 4|4, 11|8, 22|12 — matching the table in
`Cn1_definition.md`).

Cartan generators: I kept the Frappat simple-root Cartan $H_1,\dots,H_{n+1}$ exactly as given in
`Cn1_definition.md` (including the constant $-\tfrac12$ in $H_{n+1}$). Check performed by hand:
$\mathrm{span}\{H_i\} = \mathrm{span}\{a_1^+a_1^- - \tfrac12,\ b_k^+b_k^-+\tfrac12\}$
(e.g. $H_1 = (a_1^+a_1^- - \tfrac12) + (b_1^+b_1^-+\tfrac12)$), i.e. exactly the super-symmetrised
quadratics, so brackets such as $\{a_1^+b_1^+, a_1^-b_1^-\} = b_1^+b_1^- - a_1^+a_1^- + 1 = -H_1 - 2H_2$
(for $n=1$) close in the span **without** leftover constants. This will be verified mechanically in I03.

#### 2. PBW ordering — options considered
| Option | Odd block order | Pros | Cons |
|---|---|---|---|
| **(A) sign-major** (chosen) | by $\varepsilon$-sign, then $\delta$-sign, then $k$: `pp(k=1..n), pm(..), mp(..), mm(..)` | mirrors B(0,n) (`E_del{k}_p` for all $k$ before `E_del{k}_m`); the $a_1^+$ block and the $a_1^-$ block are contiguous, which aligns with the two rows of the gb matrix in I05 | roots of the same $k$ are not adjacent |
| (B) index-major | by $k$, then `pp, pm, mp, mm` | all four roots $\pm\varepsilon\pm\delta_k$ adjacent | breaks the B(0,n) pattern; gb rows interleaved |
| (C) root-height (positive roots first, then negative, within parity) | $\varepsilon\pm\delta_k$ then $-\varepsilon\pm\delta_k$ | standard in Lie theory | equivalent to (A) up to a permutation of the middle blocks; (A) is easier to generate programmatically |

Decision: **(A)**, with the global PBW order `kappa < [odd] < [even]` inherited from B(0,n) v5.0 and
$K=1$ excluded (as in B(0,n)). Even block order copies B(0,n): Cartan, `E_2del_p`, `E_del_del_pp`,
`E_2del_m`, `E_del_del_mm`, `E_del_del_pm`, `E_del_del_mp`.

#### 3. Generator labels
`E_eps1_del{k}_{σ}{s}` with σ = sign of ε (fermion $a_1^\sigma$), s = sign of $\delta_k$ (boson $b_k^s$),
as suggested in `B0n_schema_v5.md` ("E_eps1_del{k}_pp/pm/mp/mm"). Even labels unchanged from B(0,n).
Oscillator labels `a_1_p, a_1_m, b_k_p, b_k_m`; central `K`, `kappa`; deformation parameters
`gb_a_1_{σ}_b_{j}_{s}`. Oscillator normal-ordering `a_1_p < a_1_m < b_1_p < b_1_m < ...` (fermions first,
creation before annihilation, as in the B(0,n) `ordering` string `a_0, b_1_p, b_1_m, ...`).

#### 4. Conventions fixed now for later issues (recorded here so I02–I08 are consistent)
* Bracket $[X,Y\} = XY - (-1)^{p(X)p(Y)}YX$; structure constants stored for all ordered pairs.
* $\kappa$ is odd, $\kappa^2 = 0$, supercentral ($\kappa x = (-1)^{p(x)}x\kappa$) and is written on
  the left: $[X,Y\}_\gamma = [X,Y\}_0 + \kappa\gamma(X,Y)$. Reason: with this rule
  $[X,\kappa Y\} = (-1)^{p(X)}\kappa[X,Y\}$, which is exactly the sign pattern of the coboundary
  formula in `C_coboundary_definition.md`; a commuting $\kappa$ would be inconsistent with that formula.
* gb parameters are ordinary scalars (see I05 for the parity discussion).
