## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

#### 1. Basis lists (Requirement 1)
Derived from the root system in `Cn1_definition.md`:
$\Delta_{\bar 0} = \{\pm 2\delta_k, \pm(\delta_i\pm\delta_j)\}$ plus a rank-$(n+1)$ Cartan,
$\Delta_{\bar 1} = \{\pm\varepsilon\pm\delta_k\}$.
Counts: even $(n+1) + 2n + 4\binom n2 = 2n^2+n+1$, odd $4n$ — these reproduce the table
(4|4, 11|8, 22|12) for $n = 1,2,3$. Explicit lists for C(2), C(3), C(4) are written in
`handover/notation.md` §2.

Decision on the Cartan basis: I use the Chevalley-type generators `H_1..H_{n+1}` exactly as
defined in `Cn1_definition.md` ($H_1 = a_1^+a_1^- + b_1^+b_1^-$,
$H_k = b_{k-1}^+b_{k-1}^- - b_k^+b_k^-$, $H_{n+1} = -b_n^+b_n^- - \tfrac12$).
Alternative considered: the "number-operator" Cartan
$\{a_1^+a_1^- - \tfrac12,\ b_k^+b_k^- + \tfrac12\}$, which diagonalises the roots more
transparently. Rejected because Requirement 1 asks for the Frappat notation and because
the B(0,n) v5.0 schema also uses Chevalley-type `H_k`. The two choices are related by an
invertible integer change of basis:
$b_k^+b_k^- + \tfrac12 = H_{k+1}+\dots+H_n - H_{n+1}$,
$a_1^+a_1^- - \tfrac12 = H_1 - H_2 - \dots - H_n + H_{n+1}$.
Hand check: $\{a_1^+b_1^-, b_1^+a_1^-\} = a_1^+a_1^-(b_1^+b_1^-+1) + b_1^+b_1^-(1-a_1^+a_1^-) = H_1$ ✓;
$[\tfrac12(b_n^+)^2, \tfrac12(b_n^-)^2] = -b_n^+b_n^- - \tfrac12 = H_{n+1}$ ✓.

All basis realizations are symmetrised quadratics ($H_1 = (a_1^+a_1^- - \tfrac12) + (b_1^+b_1^- + \tfrac12)$,
etc.), so $\mathfrak g$ closes under the bracket without constant terms. This will be
asserted mechanically in I03.

#### 2. PBW ordering (Requirement 2)
Options considered:
* **Option A (parity-first, B(0,n)-compatible)**: `kappa < [odd] < [even]`, odd block ordered
  by fermionic sign, then boson index, then bosonic sign; even block ordered as in B(0,n) v5.0
  (Cartan, raising, lowering, mixed).
* **Option B (triangular / root-height)**: negative roots < Cartan < positive roots, odd and
  even generators interleaved by root height. Natural for highest-weight computations.
* **Option C (oscillator-degree)**: order generators by their leading oscillator word in the
  word order `a_1_p < a_1_m < b_1_p < …`. Odd generators would then all precede even ones,
  but the even block order would differ from B(0,n).

**Chosen: Option A.** Reasons: (i) it is a strict extension of the B(0,n) v5.0 convention
`κ < [odd] < [even]`, so Schema 1 stays backward compatible and the B(0,n) tooling pattern
carries over; (ii) parity-first ordering is what the odd central element κ and the odd map
$f$ (I07) need, since every object in Schemas 2–4 is graded by parity first; (iii) Option B
would require fixing a positive system for the odd roots ($\pm\varepsilon\pm\delta_k$), which
differs between Frappat's distinguished and non-distinguished Dynkin diagrams, an avoidable
source of ambiguity. The two orderings (oscillator symbols vs. basis generators) are both
written down in `notation.md` §3.

#### 3. Generator labels (Requirement 3)
Kept every B(0,n) label unchanged for the even part; odd generators follow the pattern
prescribed by `B0n_schema_v5.md`: `E_eps1_del{k}_{σ}{s}` with σ = sign of ε, s = sign of
$\delta_k$ (realization $a_1^{σ} b_k^{s}$). Oscillator labels `a_1_p, a_1_m, b_k_p, b_k_m`;
central elements `kappa` (odd) and `K` (even, = 1). Deformation parameters `gb_a1{σ}_b{k}{s}`
and coboundary unknowns `phi_<i>_<j>` are also fixed now so that I05–I08 use one convention.
