## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

#### 1. Mathematical Analysis and Design Decisions
For the Lie superalgebra $C(n+1) = \mathfrak{osp}(2|2n)$ with fermionic rank $m=1$ and bosonic rank $n$, we have established the exact basis, generator realization, and notation conventions consistent with Frappat et al. (2000) and the $B(0,n)$ base schema.

- **Dimension Formulas**:
  - Even dimension: $\dim(\mathfrak{g}_{\bar{0}}) = 2n^2 + n + 1$ (consisting of $\mathfrak{so}(2) \oplus \mathfrak{sp}(2n)$)
  - Odd dimension: $\dim(\mathfrak{g}_{\bar{1}}) = 4n$
  - Total dimension: $\dim(\mathfrak{g}) = 2n^2 + 5n + 1$
  - Specifically:
    - $n=1$ ($C(2) = \mathfrak{osp}(2|2)$): 4 even, 4 odd, 8 total
    - $n=2$ ($C(3) = \mathfrak{osp}(2|4)$): 11 even, 8 odd, 19 total
    - $n=3$ ($C(4) = \mathfrak{osp}(2|6)$): 22 even, 12 odd, 34 total

#### 2. Considered PBW Ordering Options
We evaluated two primary candidate PBW ordering strategies:
- **Option 1: Graded PBW Ordering ($\kappa < \text{Odd} < \text{Even}$)**
  - Order: $\kappa < [E_{\varepsilon \pm \delta_k}, \ldots] < [H_k, E_{\pm 2\delta_k}, E_{\pm \delta_i \pm \delta_j}]$.
  - Rationale: Fully compatible with the existing $B(0,n)$ schema architecture. It cleanly separates the odd subspace from the even subalgebra, which provides substantial computational advantages when structuring the parity-reversing coboundary linear map $f: \mathfrak{g} \to \mathfrak{g}$ as off-diagonal blocks.
- **Option 2: Root Height / Triangular Ordering ($\mathfrak{n}^- < \mathfrak{h} < \mathfrak{n}^+$)**
  - Order: Group negative root generators, Cartan generators, then positive root generators.
  - Evaluation: While standard in Verma module representations, it mixes even and odd parities across root spaces, introducing unnecessary indexing complexity into the 4-layer JSON schema and matrix representations of $f$.

**Decision**: Option 1 was selected and adopted.

#### 3. Finalized Basis Lists
- **Even Basis**:
  - Cartan generators: $H_1, \ldots, H_{n+1}$ ($n+1$ generators)
  - Long roots: $E_{2\delta_k}^+$ (`E_2del{k}_p`), $E_{2\delta_k}^-$ (`E_2del{k}_m`) for $k=1,\ldots,n$ ($2n$ generators)
  - Mixed roots (for $n \ge 2$, $1 \le i < j \le n$): `E_del{i}_del{j}_pp`, `E_del{i}_del{j}_mm`, `E_del{i}_del{j}_pm`, `E_del{i}_del{j}_mp` ($2n(n-1)$ generators)
- **Odd Basis**:
  - For $k=1,\dots,n$: `E_eps1_del{k}_pp` ($a_1^+ b_k^+$), `E_eps1_del{k}_pm` ($a_1^+ b_k^-$), `E_eps1_del{k}_mp` ($a_1^- b_k^+$), `E_eps1_del{k}_mm` ($a_1^- b_k^-$) ($4n$ generators)
