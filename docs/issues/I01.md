## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

## Requirements
1. Define even and odd basis lists for C(n+1) for n=1, 2, 3 (i.e., C(2), C(3), C(4)), following the Frappat notation.
2. Determine PBW ordering with ε-roots: list at least two concrete options, choose one, and justify the choice.
3. Design oscillator generator labels consistent with `handover/notation.md`.
4. Update `handover/notation.md` with the finalized conventions.

### Response

- **Even and Odd Basis Lists**: Defined in `handover/notation.md` for C(2), C(3), and C(4). Calculated dimension counts to verify correctness against theoretical values.
- **PBW Ordering**: Two options were considered:
  - Option A: $\varepsilon \succ \delta_1 \succ \dots \succ \delta_n$
  - Option B: $\delta_1 \succ \dots \succ \delta_n \succ \varepsilon$
  We chose **Option A** because placing $\varepsilon$ before $\delta_i$ aligns nicely with standard supermatrix conventions where the odd coordinates (in the $(1|0)$ block) logically precede the even blocks.
- **Notation Conventions**: Set conventions as:
  - Even generators: `H_k`, `E_2del{k}_p`, `E_2del{k}_m`, `E_del{i}_del{j}_pp`, `E_del{i}_del{j}_pm`, etc.
  - Odd generators: `E_eps1_del{k}_pp`, `E_eps1_del{k}_pm`, `E_eps1_del{k}_mp`, `E_eps1_del{k}_mm`.
- `handover/notation.md` was successfully updated.
