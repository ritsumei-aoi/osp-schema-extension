## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

#### Analysis & Decisions

**1. Basis Definition for C(n+1)**

From `Cn1_definition.md`, the root system for $C(n+1) = \mathfrak{osp}(2|2n)$ is:
$$\Delta = \{\pm\delta_k \pm \delta_l,\ \pm 2\delta_k,\ \pm\varepsilon \pm \delta_k\}$$

This decomposes into:
- **Even roots**: $\Delta_{\bar{0}} = \{\pm 2\delta_k\} \cup \{\pm(\delta_i \pm \delta_j) \mid i < j\}$
- **Odd roots**: $\Delta_{\bar{1}} = \{\pm\varepsilon \pm \delta_k\}$

The basis for each $n$ (bosonic rank):

**C(2) ($n=1$)**:
- Even: $H_1, H_2, E_{2\delta_1}, E_{-2\delta_1}$ (4 elements)
- Odd: $E_{\varepsilon+\delta_1}, E_{\varepsilon-\delta_1}, E_{-\varepsilon+\delta_1}, E_{-\varepsilon-\delta_1}$ (4 elements)
- Total: 8 (matches dimension formula: $2(1)^2+1+1=4$ even, $4(1)=4$ odd)

**C(3) ($n=2$)**:
- Even: $H_1, H_2, H_3, E_{2\delta_1}, E_{2\delta_2}, E_{\delta_1+\delta_2}, E_{\delta_1-\delta_2}, E_{-\delta_1+\delta_2}, E_{-(\delta_1+\delta_2)}, E_{-2\delta_1}, E_{-2\delta_2}$ (11 elements)
- Odd: 8 generators (2 ε-roots per bosonic oscillator: $\varepsilon+\delta_k, \varepsilon-\delta_k, -\varepsilon+\delta_k, -\varepsilon-\delta_k$ for $k=1,2$)
- Total: 19 (matches: $2(4)+2+1=11$ even, $4(2)=8$ odd)

**C(4) ($n=3$)**:
- Even: 22 elements (Cartan: 4, even roots: 18)
- Odd: 12 elements (3 bosonic oscillators × 4 ε-root types)
- Total: 34 (matches: $2(9)+3+1=22$ even, $4(3)=12$ odd)

**2. PBW Ordering Decision**

I considered two main options:

**Option 1 (Chosen)**: Standard extension from B(0,n)
- Order: $\kappa$ < [odd generators with ε] < [even generators]
- Rationale: Maintains continuity with B(0,n) convention, simplifies oscillator algebra computations

**Option 2**: Group by fermionic content
- Order: $\kappa$ < [odd with $a_1^+$] < [odd with $a_1^-$] < [even]
- Rationale: Would reflect fermionic oscillator ordering but breaks symmetry with B(0,n)

**Decision**: Adopt **Option 1** because:
1. Extends B(0,n) framework naturally (the reference case uses this ordering)
2. Easier to implement in structure constant generators
3. Standard in oscillator algebra literature
4. Maintains consistency when transitioning between cases

**3. Generator Label Convention**

Extending from B(0,n) labeling:
- Even double roots: `E_2del{k}_p` for $E_{2\delta_k}$, `E_2del{k}_m` for $E_{-2\delta_k}$
- Even pair roots: `E_del{i}_del{j}_pp/pm/mp/mm` for $E_{\pm(\delta_i \pm \delta_j)}$
- **Odd ε-roots**: `E_eps_del{k}_pp/pm/mp/mm` for $E_{\pm\varepsilon \pm \delta_k}$
  - First index (p/m) encodes ε-sign: p = $+\varepsilon$, m = $-\varepsilon$
  - Second index (p/m) encodes δ-sign: p = $+\delta_k$, m = $-\delta_k$
