## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

#### 1. Analysis and Options Considered
For the C(n+1) basis and PBW ordering design, two distinct ordering conventions were evaluated:
- **Option A (Parity-Grouped PBW Ordering: `κ < [odd generators] < [even generators]`)**: Group all odd generators before even generators.
- **Option B (Root-Height / Weight Ordering: `κ < [negative roots] < [Cartan generators] < [positive roots]`)**: Order elements strictly by root weight regardless of parity.

**Decision**: Selected **Option A**.
**Rationale**: Option A preserves exact 1-to-1 schema structure compatibility with the B(0,n) v5.0 specification. Grouping elements by parity maintains clean submodule separation ($\mathfrak{g}_{\bar{1}}$ vs $\mathfrak{g}_{\bar{0}}$) and simplifies super-commutator evaluation and block-linear algebra for coboundary solvers.

#### 2. Finalized Basis & Naming Conventions
- **Fermionic oscillators**: Standard CAR pair `a_1_p` ($a_1^+$) and `a_1_m` ($a_1^-$) with $\{a_1^-, a_1^+\} = 1$.
- **Bosonic oscillators**: Standard CCR pairs `b_k_p` ($b_k^+$) and `b_k_m` ($b_k^-$) for $k=1, \dots, n$ with $[b_k^-, b_l^+] = \delta_{kl}$.
- **Generators**:
  - Even Cartans: `H_1, ..., H_{n+1}`
  - Even roots: `E_2del{k}_p`, `E_2del{k}_m`, `E_del{i}_del{j}_pp/mm/pm/mp` ($i < j$)
  - Odd roots: `E_eps1_del{k}_pp`, `E_eps1_del{k}_pm`, `E_eps1_del{k}_mp`, `E_eps1_del{k}_mm` ($k=1, \dots, n$)
  - Central elements: `kappa` (parity 1) and `K` (parity 0)
