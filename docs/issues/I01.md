## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

#### 1. Basis lists (Requirement 1)
Even part = $\mathfrak{so}(2)\oplus\mathfrak{sp}(2n)$: $n+1$ Cartans `H_1..H_{n+1}`, $2n$ long roots
$\pm2\delta_k$, $4\binom n2$ roots $\pm\delta_i\pm\delta_j$ → $2n^2+n+1$.
Odd part: $\pm\varepsilon\pm\delta_k$ → $4n$. Explicit lists for n=1,2,3 are in
`handover/notation.md` §3 (counts 4|4, 11|8, 22|12; totals 8, 19, 34, matching
`Cn1_definition.md`).

#### 2. PBW ordering (Requirement 2) — options considered
| Option | Ordering | Pros | Cons |
|---|---|---|---|
| **A (chosen)** | κ < [odd: ε-sign major (pp, pm, mp, mm), k ascending] < [even: B(0,n) v5.0 pattern] | Same block structure `κ < [odd] < [even]` as B(0,n) v5.0, so all layer tools index identically; odd block grouped by the fermion used ($a_1^+$ vs $a_1^-$), which matches the rows σ of the 2×2n gb matrix; positive odd roots ε±δ_k come first | Not ordered by root height |
| B | triangular: positive roots < Cartan < negative roots (odd/even interleaved) | Natural for highest-weight/Verma computations | Breaks the B(0,n) `[odd] < [even]` convention; odd/even interleaving complicates the parity-block structure of the odd map f (I07) |
| C | κ < [odd, k-major: for each k: pp, pm, mp, mm] < [even] | Groups the 4 odd generators sharing $b_k$ | Hides the σ (fermion) block structure relevant for the gb rows; differs from B(0,n) sign-major odd ordering |

Decision: **Option A**, reasons in the table (backward compatibility with B(0,n) v5.0 tooling is
the main criterion; the σ-grouping is a secondary benefit for I05–I08).

#### 3. Generator labels (Requirement 3)
- Odd: `E_eps1_del{k}_{sε}{sδ}` with realization $a_1^{s_\varepsilon} b_k^{s_\delta}$.
- Even: unchanged B(0,n) labels (`E_2del{k}_p/m`, `E_del{i}_del{j}_pp/mm/pm/mp`) plus Cartans `H_1..H_{n+1}`.
- Oscillators: `a_1_p, a_1_m, b_k_p, b_k_m`; central `kappa` (odd), `K` (even, = 1).

#### Ambiguities and assumptions recorded
1. **Normalization of $E_{\pm2\delta}$**: `Cn1_definition.md` gives $\tfrac12(b_n^\pm)^2$ in the
   simple-generator table but $(b_k^\pm)^2$ in the all-root list. Adopted $(b_k^\pm)^2$ for all k
   (a rescaling of one basis vector; consistent with B(0,n) v5.0). Structure constants change by
   the corresponding factor only.
2. **Cartan constants**: $H_{n+1} = -b_n^+b_n^- - \tfrac12$ contains a constant. Checked by hand
   that with $H_1 = a_1^+a_1^- + b_1^+b_1^-$ the Cartan span equals
   span$\{a_1^+a_1^- - \tfrac12,\ b_k^+b_k^- + \tfrac12\}$, e.g.
   $\{a_1^+b_1^+, a_1^-b_1^-\} = b_1^+b_1^- - a_1^+a_1^- + 1 = -H_1 - 2H_2$ (n=1), so brackets
   close in $\mathfrak g$ with no stray $K$ (verified computationally in I03/I04).
3. Label `eps1`: the `1` refers to the fermionic pair index (m=1), so labels extend to osp(2m|2n) later.
