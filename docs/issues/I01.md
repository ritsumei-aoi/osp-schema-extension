## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

Implemented the conventions in `handover/notation.md`. The even basis contains
the $n+1$ Cartan generators, the $\pm2\delta_k$ roots, and all four
$\pm\delta_i\pm\delta_j$ root labels for $i<j$; the odd basis contains all four
$\pm\varepsilon\pm\delta_k$ labels for each $k$. Enumerated lists are supplied
for C(2), C(3), and C(4). The count formula gives even/odd dimensions
$(4,4)$, $(11,8)$, and $(22,12)$, agreeing with `Cn1_definition.md`.

For PBW order I considered (1) the schema grouping order with the odd roots
contiguous, then Cartan, then positive and negative even roots, and (2) a
lexicographic ordering of root-coordinate tuples with Cartan between the
negative- and positive-root blocks. I chose (1) because it directly extends
the existing B(0,n) schema grouping and gives a clear, reproducible order for
the four odd-root types. The central $\kappa$ is an optional prefix only in the
extension, not a basis element; $K=1$ is excluded.

Verification: compared root labels and oscillator realizations against
`docs/math/Cn1_definition.md`, and checked the list sizes against
$\dim\mathfrak g_{\bar 0}=2n^2+n+1$ and
$\dim\mathfrak g_{\bar 1}=4n$ for $n=1,2,3$; all match.
