## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

#### 1. Mathematical Decisions & Analysis

##### 1.1 Superdimension & Parity Decomposition
For $C(n+1) = \mathfrak{osp}(2|2n)$, where $m=1$ and bosonic rank is $n$:
- **Even subalgebra**: $\mathfrak{so}(2) \times \mathfrak{sp}(2n)$ with dimension $2n^2 + n + 1$.
  - Cartans ($n+1$): $H_1 = a_1^+ a_1^- + b_1^+ b_1^-$, $H_k = b_{k-1}^+ b_{k-1}^- - b_k^+ b_k^-$ for $2 \le k \le n$, and $H_{n+1} = -b_n^+ b_n^- - 1/2$.
  - Long roots ($2n$): $E_{\pm 2\delta_k} = (b_k^\pm)^2$.
  - Short roots ($2n(n-1)$): $E_{\pm\delta_i \pm\delta_j} = b_i^\pm b_j^\pm$ ($1 \le i < j \le n$).
- **Odd subspace**: $\Delta_{\bar{1}} = \{\pm \varepsilon \pm \delta_k \mid k = 1, \dots, n\}$, dimension $4n$.
  - $E_{\varepsilon \pm \delta_k} = a_1^+ b_k^\pm$
  - $E_{-\varepsilon \pm \delta_k} = a_1^- b_k^\pm$
- **Total dimension**: $2n^2 + 5n + 1$.
  - $n=1$ ($C(2)$): Even = 4, Odd = 4, Total = 8.
  - $n=2$ ($C(3)$): Even = 11, Odd = 8, Total = 19.
  - $n=3$ ($C(4)$): Even = 22, Odd = 12, Total = 34.

##### 1.2 Oscillator Generator Labels
Following the conventions in `docs/math/B0n_schema_v5.md` and Frappat:
- Bosonic oscillators: $b_j^\pm \to$ `"b_{j}_p"`, `"b_{j}_m"`.
- Fermionic oscillators: $a_1^\pm \to$ `"a_1_p"`, `"a_1_m"`.
- Odd root generators:
  - $E_{\varepsilon + \delta_k} \to$ `"E_eps1_del{k}_pp"` ($a_1^+ b_k^+$)
  - $E_{\varepsilon - \delta_k} \to$ `"E_eps1_del{k}_pm"` ($a_1^+ b_k^-$)
  - $E_{-\varepsilon + \delta_k} \to$ `"E_eps1_del{k}_mp"` ($a_1^- b_k^+$)
  - $E_{-\varepsilon - \delta_k} \to$ `"E_eps1_del{k}_mm"` ($a_1^- b_k^-$)
- Even root generators:
  - $E_{2\delta_k} \to$ `"E_2del{k}_p"`
  - $E_{-2\delta_k} \to$ `"E_2del{k}_m"`
  - $E_{\delta_i + \delta_j} \to$ `"E_del{i}_del{j}_pp"`
  - $E_{-\delta_i - \delta_j} \to$ `"E_del{i}_del{j}_mm"`
  - $E_{\delta_i - \delta_j} \to$ `"E_del{i}_del{j}_pm"`
  - $E_{-\delta_i + \delta_j} \to$ `"E_del{i}_del{j}_mp"`

##### 1.3 PBW Ordering: Options and Decision
Two concrete options were evaluated:
- **Option A (Polarity-First ordering, Selected)**:
  Order odd generators by oscillator polarities:
  `E_eps1_del{k}_pp` ($k=1..n$) $\to$ `E_eps1_del{k}_pm` ($k=1..n$) $\to$ `E_eps1_del{k}_mp` ($k=1..n$) $\to$ `E_eps1_del{k}_mm` ($k=1..n$).
  Even generators ordered: Cartans ($H_1, \ldots, H_{n+1}$) $\to$ Positive roots $\to$ Negative roots $\to$ Mixed roots.
  *Justification*: This preserves direct backward conceptual compatibility with the $B(0,n)$ v5.0 convention (where positive roots precede negative roots), maintains a clean separation between the $a_1^+$ and $a_1^-$ subspaces, and structures triangular decompositions naturally.
- **Option B (Mode-First ordering)**:
  Order odd generators grouped by oscillator index $k \in \{1, \ldots, n\}$:
  `E_eps1_del{k}_pp`, `E_eps1_del{k}_pm`, `E_eps1_del{k}_mp`, `E_eps1_del{k}_mm` for each $k$.
  *Drawback*: Interleaves creation and annihilation operators across different root polarities.

**Decision**: Adopted **Option A**.
