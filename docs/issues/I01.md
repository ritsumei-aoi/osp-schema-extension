## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

2. Determine PBW ordering with ε-roots: list at least two concrete options, choose one, and justify the choice.
3. Design oscillator generator labels consistent with `handover/notation.md`.
4. Update `handover/notation.md` with the finalized conventions.

### Response

**Status**: done (No-Gate: decisions made here, no approval requested).

**Basis (finalized in `handover/notation.md` §3).** Odd: `E_eps1_del{k}_{pp,pm,mp,mm}` = $a^{\pm}b_k^{\pm}$, $4n$ elements. Even: $H_1,\dots,H_{n+1}$ and $\tfrac12(b_k^\pm)^2$, $b_i^\pm b_j^\pm$ ($i<j$). Dimensions $2n^2+n+1$ even and $4n$ odd, checked by code (`build_basis`) for $n=1,2,3$: $8, 19, 34$ total, with even/odd counts $4/4$, $11/8$, $22/12$.

**PBW ordering.** Options considered:
- (A) odd first, then even in the B(0,n) schema order. This is the chosen option.
- (B) even first.
- (C) height ordering by the $\varepsilon$-grading.

Reasons for (A): it keeps the $\kappa<[\text{odd}]<[\text{even}]$ rule from `B0n_schema_v5.md`, so the B and C schemas can be compared position by position. The algebra is unchanged by the choice; only the labelling changes. Normal ordering in the oscillator words is fermions left, $a^+$ before $a^-$, $b^+$ before $b^-$, bosons sorted by index.

**Decisions and ambiguities** (all recorded in notation.md §8):
- **A1 (parity of gb).** The doc says $p(\mathrm{gb})=1$, but with $[b,a]=-\mathrm{gb}\,\kappa$ the left side is odd and $\kappa$ is odd, so gb must be even for consistency. I treat gb as commuting scalars and record parity 0.
- **A2.** $E_{\pm2\delta_k}=\tfrac12(b_k^\pm)^2$ for all $k$. The root list in the doc omits the $\tfrac12$, but it is needed so that $[E_{2\delta_n},E_{-2\delta_n}]=H_{n+1}$ exactly.
- **A3.** Odd elements are written fermion first ($a^\sigma b^s$), which matches the general root list. The simple-root line writes $b_1^+a^-$ instead; this differs only by a multiple of $\kappa K$ and does not change the $\mathfrak g$-valued $\gamma$.
- **A4.** A new fact: normal ordering produces a $\kappa\cdot K$ term ($K=1$) in brackets of odd with even elements. This is not in the doc. I keep the $\mathfrak g$-valued $\gamma$ as the object of study and record the $K$-component separately.

**Verification.** The engine (`src/c_algebra.py`) confirms the dimensions above and that every $\mathfrak g$-valued bracket lies in the span of the basis. Full checks are in I03 and I04.
