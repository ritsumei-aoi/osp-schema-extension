## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

Selected the generator labels and complete basis lists documented in
`handover/notation.md`. The dimensions from the lists are C(2) `4|4` (total
8), C(3) `11|8` (total 19), and C(4) `22|12` (total 34), agreeing with
$2n^2+n+1|4n$.

Considered two PBW orders: (1) the B(0,n)-style parity-block order and (2) a
root-triangular order with negative roots, Cartan generators, then positive
roots. Chose (2) because it reflects the root decomposition and fixes the
positive odd roots as $\varepsilon\pm\delta_k$; exact within-block ordering
is specified in the notation document. Labels use the first sign for
$\varepsilon$ or $\delta_i$ and the second for $\delta_k$ or $\delta_j$,
respectively.

Verification: checked the explicit generator counts against the dimension
formula for `n=1,2,3`; all counts agree. Completion criteria are checked above.
