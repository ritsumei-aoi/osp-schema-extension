## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

**1. Even and Odd Basis Lists**
For $C(n+1) = \mathfrak{osp}(2|2n)$:
*   **C(2)** ($n=1$):
    *   **Even** (4 elements): `H_1`, `H_2`, `E_2del1_p`, `E_2del1_m`
    *   **Odd** (4 elements): `E_eps1_del1_pp`, `E_eps1_del1_pm`, `E_eps1_del1_mp`, `E_eps1_del1_mm`
*   **C(3)** ($n=2$):
    *   **Even** (11 elements): `H_1`, `H_2`, `H_3`, `E_2del1_p`, `E_2del1_m`, `E_2del2_p`, `E_2del2_m`, `E_del1_del2_pp`, `E_del1_del2_pm`, `E_del1_del2_mp`, `E_del1_del2_mm`
    *   **Odd** (8 elements): `E_eps1_del1_pp`, `E_eps1_del1_pm`, `E_eps1_del1_mp`, `E_eps1_del1_mm`, `E_eps1_del2_pp`, `E_eps1_del2_pm`, `E_eps1_del2_mp`, `E_eps1_del2_mm`
*   **C(4)** ($n=3$):
    *   **Even** (22 elements): `H_1`, `H_2`, `H_3`, `H_4`, `E_2del1_p`, `E_2del1_m`, `E_2del2_p`, `E_2del2_m`, `E_2del3_p`, `E_2del3_m`, `E_del1_del2_pp`, `E_del1_del2_pm`, `E_del1_del2_mp`, `E_del1_del2_mm`, `E_del1_del3_pp`, `E_del1_del3_pm`, `E_del1_del3_mp`, `E_del1_del3_mm`, `E_del2_del3_pp`, `E_del2_del3_pm`, `E_del2_del3_mp`, `E_del2_del3_mm`
    *   **Odd** (12 elements): `E_eps1_del1_pp`...`mm`, `E_eps1_del2_pp`...`mm`, `E_eps1_del3_pp`...`mm`

**2. PBW Ordering Decision**
*   **Option A:** `[Odd Roots] < [Cartans] < [Even Roots]`
*   **Option B:** `[Cartans] < [Even Roots] < [Odd Roots]`
*   **Decision:** Option A is chosen.
*   **Justification:** This perfectly matches the established convention from the base B(0,n) schema (`[odd] < [even]`). Within each group, generators are ordered lexicographically by their index and sign (e.g. `pp` < `pm` < `mp` < `mm`).

**3. Generator Labels**
The standard CAR pair is labeled `a_1_p` and `a_1_m`. Roots corresponding to $\pm \varepsilon \pm \delta_k$ are labeled `E_eps1_del{k}_{signs}`. These mappings have been finalized.

`handover/notation.md` has been successfully updated with the definitions and conventions.
