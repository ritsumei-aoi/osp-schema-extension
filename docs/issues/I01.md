## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

**Decision: PBW Ordering**

Two options considered:
- **Option A** (chosen): κ < [odd: E_eps1_del{k}_{pp,pm,mp,mm}] < [even: H_k, E_2del{k}, E_del{i}_del{j}_...]. Mirrors B(0,n) convention directly; groups odd generators together; simplifies cross-algebra code reuse.
- **Option B**: κ < [ε-raising odd] < [ε-lowering odd] < [even]. Groups by ε-sign; less natural for structure constant bookkeeping.

**Basis counts verified**:
- C(2), n=1: even=4 (2 Cartan + 2 non-Cartan), odd=4. Total=8. Formula: 2(1)²+1+1=4, 4(1)=4. ✓
- C(3), n=2: even=11 (3 Cartan + 8 non-Cartan), odd=8. Total=19. Formula: 2(4)+2+1=11, 4(2)=8. ✓
- C(4), n=3: even=22 (4 Cartan + 18 non-Cartan), odd=12. Total=34. Formula: 2(9)+3+1=22, 4(3)=12. ✓
