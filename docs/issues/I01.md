## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

#### Decision: PBW Ordering for C(n+1)

Two candidate PBW orderings are considered:

**Option 1 (Adopted)**: κ < [odd: E_eps1_del{k}_{...}] < [even: H_i, E_2del{k}_{...}, E_del{i}_del{j}_{...}]
- Rationale: Mirrors B(0,n) structure, placing central extension first, then odd roots, then even roots (Cartan first, then positive, then negative).

**Option 2 (Alternative)**: κ < [even: H_i] < [odd: E_eps1_del{k}_{...}] < [even positive/negative]
- Places Cartan elements at the hierarchy's highest level after κ, suitable for algorithms requiring strict weight ordering.

**Choice**: **Option 1 (Adopted)** for consistency with B(0,n) and standard Lie superalgebra conventions.

#### Basis Design for C(n+1)

For C(n+1) = osp(2|2n) with bosonic rank n:
- **Even dimension**: 2n² + n + 1
- **Odd dimension**: 4n
- **Total dimension**: 2n² + 5n + 1

##### C(2) = osp(2|2), n=1
- **Even** (4): H_1, H_2, E_2del1_p, E_2del1_m
- **Odd** (4): E_eps1_del1_pp, E_eps1_del1_pm, E_eps1_del1_mp, E_eps1_del1_mm
- **Total**: 8

##### C(3) = osp(2|4), n=2
- **Even** (11): H_1, H_2, H_3, E_2del1_p, E_2del2_p, E_del1_del2_pp, E_del1_del2_mm, E_del1_del2_pm, E_del1_del2_mp, E_2del1_m, E_2del2_m
- **Odd** (8): E_eps1_del1_pp, E_eps1_del1_pm, E_eps1_del1_mp, E_eps1_del1_mm, E_eps1_del2_pp, E_eps1_del2_pm, E_eps1_del2_mp, E_eps1_del2_mm
- **Total**: 19

##### C(4) = osp(2|6), n=3
- **Even** (22): H_1, H_2, H_3, H_4, E_2del1_p, E_2del2_p, E_2del3_p, E_del1_del2_pp, E_del1_del2_mm, E_del1_del3_pp, E_del1_del3_mm, E_del2_del3_pp, E_del2_del3_mm, E_del1_del2_pm, E_del1_del2_mp, E_del1_del3_pm, E_del1_del3_mp, E_del2_del3_pm, E_del2_del3_mp, E_2del1_m, E_2del2_m, E_2del3_m
