#### Implementation
`src/verify_C_structure.py` reads **only** `data/C_{n}_structure.json` (no oscillator engine), so
it is an independent check of the I03 output.
- Graded antisymmetry, all ordered pairs: $c^Z_{YX} = -(-1)^{p(X)p(Y)} c^Z_{XY}$ (possible because
  Schema 1 stores both orders).
- Super Jacobi, **all ordered triples** (dim³, no symmetry reduction):
  $(-1)^{p(X)p(Z)}[X,[Y,Z]] + (-1)^{p(Y)p(X)}[Y,[Z,X]] + (-1)^{p(Z)p(Y)}[Z,[X,Y]] = 0$,
  evaluated exactly with `Fraction`.
- `tests/test_verify_C_structure.py`: real data passes for n=1,2,3; a deliberately corrupted
  constant (`[E_2del1_p, E_2del1_m]` H_2-coefficient 4→5, kept antisymmetric) is detected by the
  Jacobi check (guards against a vacuous verifier).
