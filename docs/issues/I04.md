### Response

**Implementation (2026-10-08, no-gate)**

`src/verify_C_structure.py` loads `data/C_{n}_structure.json`, rebuilds the bracket table with exact
`Fraction` arithmetic and runs three checks:

1. **Closure / parity**: every entry refers to basis labels and `p(Z) = p(X) + p(Y) mod 2`.
2. **Graded antisymmetry**: `[X,Y} = -(-1)^{p(X)p(Y)} [Y,X}` for all `dim^2` ordered pairs.
3. **Super Jacobi**: `(-1)^{p(X)p(Z)}[X,[Y,Z}} + (-1)^{p(Y)p(X)}[Y,[Z,X}} + (-1)^{p(Z)p(Y)}[Z,[X,Y}} = 0`
   for **all `dim^3` ordered triples** (the CLI uses `all_ordered=True`; the module also offers the
   reduced `X <= Y <= Z` enumeration, which is sufficient given antisymmetry).

The functions are generic (`basis`, `parity`, `table`) so that the same verifier is reused in I06 for the
deformed extended algebra `g~ (+) kappa g~`. `tests/test_C_jacobi.py` runs the three checks for n = 1, 2, 3
and includes a negative control: corrupting `[E_2del1_p, E_2del1_m]` from `4 H_2` to `3 H_2` (keeping
antisymmetry) is detected as a Jacobi failure, so the check is not vacuous.

the verification confirms that the decomposition into the basis (in particular the Cartan constants) was
done correctly and that the stored data is self-consistent.
