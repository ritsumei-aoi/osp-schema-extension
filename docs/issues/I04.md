### Response

#### Implementation
- `src/C_common.py`: `LieSuperalgebra` loader (bracket table from `structure_constants`,
  `K` treated as central), sparse vectors, linear forms and an exact sparse solver
  (reused by I05–I08).
- `src/verify_C_structure.py`: independent check that uses **only** the stored JSON
  (not the oscillator engine): (a) parity/label closure, (b) super-antisymmetry
  `[X,Y} = -(-1)^{p(X)p(Y)}[Y,X}` for all d² ordered pairs, (c) super-Jacobi
  `(-1)^{p(X)p(Z)}[X,[Y,Z}} + cyclic = 0` for all d³ ordered triples. Exit code 0 iff all pass.
- `tests/test_verify_C_structure.py` wraps the three checks for n=1,2,3.

#### Summary report
All checks pass for n = 1, 2, 3; no failures, hence no root-cause analysis was required.
Note that Jacobi holding for the *stored* constants is a non-trivial check of the generator:
it would detect sign errors in the graded commutator, in the normal-ordering rules, or in the
decomposition into the Frappat Cartan basis.
