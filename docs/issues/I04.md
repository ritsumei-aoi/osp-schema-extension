#### Verification Script

The verification is implemented in `tests/test_C_structure.py` (added in I03).

Key tests:
- `test_antisymmetry(n)`: Checks [X,Y} = -(-1)^{p(X)p(Y)} [Y,X} for all generator pairs.
- `test_super_jacobi(n)`: Checks the cyclic Jacobi sum:
  [X,[Y,Z}} + (-1)^{pX(pY+pZ)} [Y,[Z,X}} + (-1)^{pZ(pX+pY)} [Z,[X,Y}} = 0
