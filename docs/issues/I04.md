### Response

**Status**: done. All checks pass.

**Script.** `src/verify_C_structure.py` reads only `data/C_{n}_structure.json`. It does not import the engine, so it checks the written artifact, not the code that produced it. It checks three things for every pair and every triple of basis elements:
- parity grading: $p(Z)=p(X)+p(Y)$ for each structure constant;
- anti-symmetry: $[X,Y]+(-1)^{p(X)p(Y)}[Y,X]=0$;
- super-Jacobi: $[X,[Y,Z]]=[[X,Y],Z]+(-1)^{p(X)p(Y)}[Y,[X,Z]]$.

Results are written to `data/C_structure_verification.json`.

**Results (run output).**

```
n=1 C(2) dim=8  pairs=64   triples=512   parity=0 antisym=0 jacobi=0 -> PASS
n=2 C(3) dim=19 pairs=361  triples=6859  parity=0 antisym=0 jacobi=0 -> PASS
n=3 C(4) dim=34 pairs=1156 triples=39304 parity=0 antisym=0 jacobi=0 -> PASS
```

**Sensitivity check.** A passing verifier is only useful if it can fail. A test (`test_verifier_detects_corrupted_structure_constant`) changes one structure constant and asserts that the check reports a failure. It passes, so the checks do detect corruption.

**Note.** The sign error found in I03 would not have been caught by these checks. Negating all brackets preserves Jacobi and anti-symmetry. That error was caught by the independent Cartan weight test and by a hand calculation. The checks here are necessary, not sufficient, and I rely on the weight test for the sign.
