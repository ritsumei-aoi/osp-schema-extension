### Response

#### Implementation
`src/verify_C_structure.py` reads **only** `data/C_{n}_structure.json` (no dependence on the generator code) and checks
1. super-antisymmetry $[Y,X\} = -(-1)^{p(X)p(Y)}[X,Y\}$ for all ordered pairs (both orders are stored, so this is a real data check);
2. grading $p(Z) = p(X)+p(Y)$ for every non-zero constant;
3. super-Jacobi $(-1)^{p(X)p(Z)}[X,[Y,Z\}\} + (-1)^{p(Y)p(X)}[Y,[Z,X\}\} + (-1)^{p(Z)p(Y)}[Z,[X,Y\}\} = 0$ for **all** ordered triples (dim³), in exact rational arithmetic.

`tests/test_verify_C_structure.py` runs it for n=1,2,3 and includes a negative control (corrupting $[E_{2\delta_1}^+, E_{2\delta_1}^-]$ is detected by both the antisymmetry and the Jacobi check).
