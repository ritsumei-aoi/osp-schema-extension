### Response

#### Deliverables
* `src/verify_C_structure.py` — loads `C_{n}_structure.json` and checks, **using only the
  JSON records** (no dependency on the oscillator engine that produced them):
  (A) parity additivity of every record, (B) graded antisymmetry
  $[Y,X] = -(-1)^{p(X)p(Y)}[X,Y]$ for every ordered pair, (C) super Jacobi
  $[X,[Y,Z]] = [[X,Y],Z] + (-1)^{p(X)p(Y)}[Y,[X,Z]]$ for every ordered triple,
  (D) closure (targets are basis labels). Exit status 0 iff all pass.
* `tests/test_verify_C_structure.py` — runs the verifier on n = 1, 2, 3 and contains two
  negative tests (a corrupted coefficient and an injected parity-violating record) to prove
  that the checks are not vacuous.

#### Decisions
* Exhaustive enumeration over all $\dim^3$ ordered triples (512 / 6859 / 39304) rather than
  only unordered triples, so no symmetry assumption enters the verification. Runtime is
  0.2 s in total, so no optimisation was needed.
* Antisymmetry is a real test because Schema 1 stores $(X,Y)$ and $(Y,X)$ independently (I03).
