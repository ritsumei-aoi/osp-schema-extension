#### Implementation

Implemented `src/verify_C_structure.py` which:
1. Checks graded anti-symmetry: `[X,Y} + (-1)^{p(X)p(Y)} [Y,X} = 0` for all pairs.
2. Checks Super Jacobi identity (cyclic form) for all triples.
3. Computes brackets directly from the oscillator algebra (via `C_generators.graded_bracket`) to avoid circular reasoning.

#### Bugs Fixed in C_generators.py

During verification, two bugs were found and fixed:

1. **Fermionic nilpotency**: `(a_1_p)^2 = 0` was not enforced. Fixed by adding a check in `_normalize` that discards words with adjacent identical fermionic operators.

2. **Greedy `express_in_basis`**: The original greedy algorithm failed when generators shared monomials (e.g., H_1 and H_2 both contain `(b_1_p, b_1_m)`). Replaced with Gaussian elimination using all generator monomials as constraints, ensuring unique decomposition.
