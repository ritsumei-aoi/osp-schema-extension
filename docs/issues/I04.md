### Response

#### Implementation
`src/verify_C_structure.py` reads **only** `data/C_{n}_structure.json` (no generator code), builds a
sparse table [X,Y} → {Z: c} with exact Fractions and checks, for all ordered pairs/triples:
- bracket parity: p(Z) = p(X)+p(Y) mod 2 for every non-zero entry;
- graded anti-symmetry: [X,Y} = −(−1)^{p(X)p(Y)}[Y,X} (both orders are stored, so this is a genuine check);
- super Jacobi: (−1)^{p(X)p(Z)}[X,[Y,Z}} + (−1)^{p(Y)p(X)}[Y,[Z,X}} + (−1)^{p(Z)p(Y)}[Z,[X,Y}} = 0, all dim³ ordered triples.

`tests/test_verify_C_structure.py` runs the checks for n=1,2,3 and a negative control
(corrupting one coefficient makes both anti-symmetry and Jacobi checks fail — the checker is not vacuous).
