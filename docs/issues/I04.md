### Response

**Verification script**: `src/verify_C_structure.py`

Implements:
- `build_bracket_table(data)`: loads structure constants and expands anti-symmetry to populate all (X,Y) → {Z: coeff} pairs. K treated as central (skip in inner bracket computations).
- `verify_n(n)`: iterates all generator pairs for anti-symmetry, all triples for Super Jacobi identity `(-1)^{pXpZ}[X,[Y,Z]] + (-1)^{pYpX}[Y,[Z,X]] + (-1)^{pZpY}[Z,[X,Y]] = 0`.
- `main()`: runs for n=1,2,3 and prints summary.

**Root cause of initial failures (I03 revision context)**:

Two bugs in the original hardcoded structure constant generator caused all Jacobi failures:
1. Wrong formula for {E_{ε+δk}, E_{-ε-δk}} at the same index k: code used N_{bk} but the correct value is N_{bk} + 1 - N_f (from the non-trivial boson-fermion reordering in the anti-commutator).
2. Missing even-even bracket families: [E_{δi+δj}^++, E_{-2δk}] and [E_{δi+δj}^{--}, E_{2δk}] for k∈{i,j}, plus [E_{δi+δj}^{++}, E_{-(δj+δl)}^{--}] for shared index j.

Both bugs were eliminated by rewriting the generator to use the algebraic `lie_bracket` function (see I03 revision), which correctly computes all brackets from first principles.
