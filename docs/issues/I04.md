### Response

#### Implementation
`src/verify_C_structure.py` loads `data/C_{n}_structure.json` and works **only from the JSON
structure constants** (it does not import the oscillator engine), so it is an independent check of
the I03 output. Exact rational arithmetic (`fractions.Fraction`). Checks:

1. closure and parity: every `Z` is a basis label and $p(Z)=p(X)+p(Y) \bmod 2$;
2. anti-symmetry for **all ordered pairs**: $[X,Y\} = -(-1)^{p(X)p(Y)}[Y,X\}$;
3. super Jacobi for **all ordered triples**:
   $(-1)^{p(X)p(Z)}[X,[Y,Z\}\} + (-1)^{p(Y)p(X)}[Y,[Z,X\}\} + (-1)^{p(Z)p(Y)}[Z,[X,Y\}\} = 0$;
4. bonus: the Cartan subalgebra is abelian and acts diagonally.

The script exits with status 1 on any failure and prints the offending pairs/triples.

All checks pass; no root-cause analysis needed. Run time 0.2 s.

#### Self-check of the verifier (`tests/test_verify_C_structure.py`)
Because a verifier that cannot fail proves nothing, two mutation tests inject errors into the n=1
data: (a) changing a single coefficient breaks both anti-symmetry and Jacobi and is reported as
such; (b) flipping $[E_{2\delta_1},E_{-2\delta_1}]$ and its mirror consistently keeps anti-symmetry
but is caught by the Jacobi check alone. Both behave as expected.
