### Response

**Implementation**: `src/verify_C_structure.py` loads only the JSON files (independent of the oscillator code) and checks
(1) anti-symmetry `[X,Y} = -(-1)^{p(X)p(Y)}[Y,X}` for all ordered pairs and every Z, and
(2) the super Jacobi identity `[X,[Y,Z]} = [[X,Y},Z} + (-1)^{p(X)p(Y)}[Y,[X,Z]}` for **all** ordered basis triples (dim^3), with exact `Fraction` arithmetic.
`tests/test_verify_C_structure.py` also checks that corrupting a coefficient makes both checks fail (the checker is not vacuous).

**Report**
```
$ python3 src/verify_C_structure.py

C_2: dim=19 pairs=361  triples=6859  antisym_failures=0 jacobi_failures=0 -> PASS
C_3: dim=34 pairs=1156 triples=39304 antisym_failures=0 jacobi_failures=0 -> PASS
$ python3 -m pytest -q   -> 26 passed
```
All checks pass for n=1,2,3; no failures, hence no root-cause analysis required.

**Decision note**: Jacobi was verified in the "derivation" form (equivalent to the cyclic super form for homogeneous elements); the form used is stated in the docstring. Since the structure constants were produced from an associative oscillator product, passing is expected, but the check is independent of that construction (JSON only).
