#### Implementation

`src/verify_C_structure.py` loads `C_{n}_structure.json` (n = 1, 2, 3) and
verifies, using **only the JSON data** (fully independent of the oscillator
engine that generated it; exact `Fraction` arithmetic throughout):

1. **Graded anti-symmetry** for every ordered pair:
   `[X,Y} + (−1)^{p(X)p(Y)} [Y,X} = 0`.
2. **Super Jacobi identity** for every ordered triple:
   `(−1)^{p(X)p(Z)}[X,[Y,Z}} + (−1)^{p(Y)p(X)}[Y,[Z,X}} + (−1)^{p(Z)p(Y)}[Z,[X,Y}} = 0`
   (graded cyclic form; brackets resolved via structure-constant lookup).

`tests/test_verify_structure.py` wires the verification into the pytest suite.
