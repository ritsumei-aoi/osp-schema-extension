**Implementation**: `src/verify_C_structure.py` loads `data/C_{1,2,3}_structure.json` and checks, in exact `Fraction` arithmetic:
- graded antisymmetry $[X,Y] = -(-1)^{p(X)p(Y)}[Y,X]$ for all ordered pairs;
- super Jacobi $(-1)^{xz}[x,[y,z]] + (-1)^{yx}[y,[z,x]] + (-1)^{zy}[z,[x,y]] = 0$ for all triples.

**First run (before fix)**: 0 antisymmetry failures, but 64 / 448 / 1344 Jacobi failures for $n=1,2,3$.
- Root cause: a bug in the verifier, not in the algebra. I applied the sign $(-1)^{p(x)p(z)}$ to all three cyclic terms. The super Jacobi identity needs a separate sign for each term.
- Fix: per-term signs $(-1)^{xz}$, $(-1)^{yx}$, $(-1)^{zy}$.

**Negative control**: flipping one coefficient in memory for $n=1$ gives `pass=False` with 2 antisymmetry and 27 Jacobi failures, so the check is sensitive.
