#### Implementation
`src/verify_C_structure.py` reads **only** the JSON files (no import of the generator), builds the table
$(X,Y)\mapsto\sum_Z c\,Z$ in exact `Fraction`s and checks, for every basis element:
- super-antisymmetry $[X,Y\} = -(-1)^{p(X)p(Y)}[Y,X\}$ for all $d^2$ ordered pairs;
- super Jacobi $(-1)^{p(X)p(Z)}[X,[Y,Z\}\} + (-1)^{p(Y)p(X)}[Y,[Z,X\}\} + (-1)^{p(Z)p(Y)}[Z,[X,Y\}\} = 0$ for all $d^3$ ordered triples;
- parity of every output $Z$ equals $p(X)+p(Y)$.

`tests/test_verify_C_structure.py` runs it for n=1,2,3 and adds a **negative control**: corrupting one coefficient
($[E_{2\delta_1}^+,E_{2\delta_1}^-]$: 4 → 3) is detected by both the antisymmetry and the Jacobi check, so the checker is not vacuous.
