- `check_super_jacobi()`: verifies (-1)^{pX·pZ}[[X,Y},Z} + cyclic = 0 for all triples

#### Bug Fix During Verification
Initial verification revealed Jacobi failures in all three algebras. Root cause: `express_in_basis()` in `C_generators.py` was matching oscillator words to generators independently, causing double-counting for multi-term generators (e.g., H_1 = a_1^+a_1^- + b_1^+b_1^-). Fixed by implementing a proper linear decomposition that subtracts matched generator contributions before proceeding.
