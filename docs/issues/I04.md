### Response

**Decisions**
- `src/verify_C_structure.py` loads the *JSON files* (not the generator objects), so it checks the shipped data. Exact `Fraction` arithmetic, no tolerances.
- Antisymmetry convention: `[X,Y} = -(-1)^{p(X)p(Y)} [Y,X}` over all unordered pairs including X=Y (so odd-odd `[X,X}` is allowed to be non-zero, e.g. {E_{ε+δ}, E_{ε+δ}} would need to vanish or be symmetric by itself).
- Super Jacobi convention: `[X,[Y,Z}} = [[X,Y},Z} + (-1)^{p(X)p(Y)} [Y,[X,Z}}` for **all ordered** triples (n³ of them, not just X≤Y≤Z), so no sign-symmetry argument is assumed.
- Added negative controls (a corrupted table must fail) so a vacuous "all pass" is excluded.
