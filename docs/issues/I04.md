### Response

**Date**: 2026-10-09.

#### Script: `src/verify_C_structure.py`

Loads `C_{n}_structure.json` and works **only from the stored structure constants** (the oscillator realization is not used, so this is an independent check of the data, not of the generator's internal consistency). For the bracket table $c(X,Y)=\{Z:\text{coeff}\}$ it checks:

1. **Parity**: every stored $Z$ satisfies $p(Z) = p(X)+p(Y) \bmod 2$.
2. **Graded antisymmetry**: $[Y,X\} = -(-1)^{p(X)p(Y)}[X,Y\}$ for all ordered pairs (possible because both orders are stored).
3. **Super Jacobi** in derivation form, $[X,[Y,Z\}\} = [[X,Y\},Z\} + (-1)^{p(X)p(Y)}[Y,[X,Z\}\}$, for **all** ordered triples (no symmetry reduction), with exact rational arithmetic.

It also rejects duplicate or zero entries. Exit code 1 on failure.

**Options considered**: cyclic form $\sum_{\text{cyc}} (-1)^{p(X)p(Z)}[X,[Y,Z\}\} = 0$ versus derivation form. Both are equivalent given antisymmetry; the derivation form was chosen because it stays meaningful even when antisymmetry fails, which helps root-cause analysis.
