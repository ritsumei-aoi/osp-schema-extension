#### Decisions and Results

**Implementation**: Created `src/verify_C_structure.py` with:
- `check_antisymmetry(data)`: Verifies [X,Y} = -(-1)^{p(X)p(Y)} [Y,X} for all pairs.
- `check_super_jacobi(data)`: Verifies (-1)^{px·pz}[[x,y],z] + (-1)^{py·px}[[y,z],x] + (-1)^{pz·py}[[z,x],y] = 0 for all triples.

**Note**: Initial implementation had a sign error in the Super Jacobi formula (wrong sign convention for the cyclic terms). Fixed to use the standard form with [z,x] (not [x,z]) in the third term.
