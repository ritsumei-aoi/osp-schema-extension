### Response

**Decisions and Results**:

1. **Verification script**: Created `src/verify_C_structure.py` with:
   - Anti-symmetry check: $[X,Y\} = -(-1)^{p(X)p(Y)} [Y,X\}$ for all pairs
   - Super Jacobi identity: $(-1)^{p(X)p(Z)}[X,[Y,Z]] + \text{cyclic} = 0$ for all triples

2. **Bug fix during verification**: Initial runs revealed Jacobi failures. Root cause: the normal ordering function incorrectly handled words with non-adjacent duplicate fermions. The fix changed from a pre-check that killed ANY word with duplicate fermions (too aggressive — killed intermediate words that should contract) to checking only ADJACENT identical fermions (correct — only $a \cdot a = 0$ when $a$ is immediately next to itself after swaps bring them together).
