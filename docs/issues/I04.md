### Response

#### Implementation
`src/verify_C_structure.py` loads `data/C_{n}_structure.json` and works **only from the JSON**
(it does not import the generator or the oscillator engine, so it is an independent check).
`BracketTable` turns the `structure_constants` list into a bracket table; `verify()` checks, in exact
rational arithmetic:
1. graded antisymmetry $[X,Y\}+(-1)^{p(X)p(Y)}[Y,X\}=0$ for all $N^2$ ordered pairs;
2. super Jacobi $(-1)^{p(X)p(Z)}[X,[Y,Z\}\}+(-1)^{p(Y)p(X)}[Y,[Z,X\}\}+(-1)^{p(Z)p(Y)}[Z,[X,Y\}\}=0$
   for all $N^3$ ordered triples (no symmetry reduction, by design);
3. parity grading of every stored constant;
4. dimension bookkeeping against the formulas $2n^2+n+1$ / $4n$.

Design choice: all ordered triples are checked rather than only $X<Y<Z$ — the cost is negligible
(39 304 triples for n=3 in 0.2 s) and it removes any dependence on the antisymmetry check.
`tests/test_verify_C_structure.py` wraps the script and adds a **negative control**: flipping the sign of
one structure constant in `C_1_structure.json` makes both the antisymmetry and the Jacobi check fail,
so the verifier is not vacuous.
