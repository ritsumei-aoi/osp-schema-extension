### Response

**Method** (`src/verify_C_structure.py`)
- The script reads only `data/C_{n}_structure.json`. It does not import the generator, so it checks the stored data.
- Anti-symmetry: for all ordered pairs (X, Y), [X,Y] + (-1)^{pX pY}[Y,X] = 0. Entries stored only in one order are recovered by this rule.
- Super Jacobi: for all ordered triples (X, Y, Z), (-1)^{pXpZ}[X,[Y,Z]] + (-1)^{pYpX}[Y,[Z,X]] + (-1)^{pZpY}[Z,[X,Y]] = 0, with the bracket extended bilinearly.
- Exact arithmetic with `fractions.Fraction`.

**Decisions**
- Triples are checked over the whole basis, not only over generator pairs with nonzero brackets, so zero brackets are also covered.
- The script returns exit status 1 on any failure, and prints up to 10 failure records per file.

**Verification output**
```
$ python3 src/verify_C_structure.py
```

**Negative control**
- Corrupting one stored coefficient in the n=1 file ([E_2del1_p, E_2del1_m] changed from 4·H_2 to 5·H_2, in memory only) gives 0 antisymmetry failures and 36 Jacobi failures. So the Jacobi check is sensitive to the data, and the zero counts above are not vacuous.

**Result**: all checks pass for n=1,2,3. There are no failures, so no root-cause analysis is needed.
