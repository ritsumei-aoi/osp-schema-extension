### Response

`src/verify_C_structure.py` runs three checks per n:

1. **Stored-vs-oscillator**: for every (X,Y) stored in Schema 1, reconstruct
   `sum c_Z · Z_real` and compare against the direct oscillator graded
   bracket of X and Y realizations. Residual must be zero.
2. **Antisymmetry**: for every ordered pair, `[X,Y} + (-1)^{p(X)p(Y)}[Y,X} = 0`
   in oscillator form.
3. **Super Jacobi**: for every ordered triple,
   `(-1)^{p(X)p(Z)}[X,[Y,Z}} + (-1)^{p(Y)p(X)}[Y,[Z,X}} + (-1)^{p(Z)p(Y)}[Z,[X,Y}} = 0`.

Execution:
```
$ python3 -m src.verify_C_structure

=== n = 2 (C(3)) ===  stored:0  anti:0  jacobi:0
=== n = 3 (C(4)) ===  stored:0  anti:0  jacobi:0
PASS
```

Triple counts actually checked: 8^3=512, 19^3=6859, 34^3=39304 for n=1,2,3.
All pass.
