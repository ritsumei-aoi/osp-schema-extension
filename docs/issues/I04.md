### Response

**Design decision: independent check, not a re-read**
- A check that only reads the stored `structure_constants` would be vacuous for antisymmetry (the file stores one orientation per pair). So `src/verify_C_structure.py` recomputes every ordered bracket from the `generator_realization` oscillator words, using its own normal-ordering routine (it does not import `C_generators.py`), then compares with the stored table.
- Considered: (a) reading the stored table only (rejected, vacuous as above); (b) importing the generator engine (rejected, a shared bug would pass both sides); (c) an independent recomputation (chosen).

**Checks**
1. Stored `structure_constants` = recomputed brackets, and no recomputed nonzero pair is missing from the file.
2. Antisymmetry $[X,Y\} = -(-1)^{p(X)p(Y)}[Y,X\}$ for all ordered pairs, both orientations recomputed.
3. Super Jacobi for all ordered triples.
4. No central term K appears.

**Results**
```
C(n=1) basis=8:  antisymmetry pairs=64,   Jacobi triples=512,   PASS (0 failures)
C(n=2) basis=19: antisymmetry pairs=361,  Jacobi triples=6859,  PASS (0 failures)
C(n=3) basis=34: antisymmetry pairs=1156, Jacobi triples=39304, PASS (0 failures)
exit=0
```
Triple counts are $\text{basis}^3$ by construction (all ordered triples, not just $X\le Y\le Z$).

**Issue found during the run, and its root cause**
- First run reported 12 / 40 / 84 "missing from file" failures. Root cause was in the verifier, not the data: it built its label list as even-then-odd, while the PBW order fixed in I01 (and used by the generator) is odd-then-even. The generator correctly stored `(E_pp, H_eps)` and the verifier looked for `(H_eps, E_pp)`. Fixed by using the odd-first order from `basis.odd + basis.even`.

**Sensitivity (mutation) check**
- The pass result is only meaningful if the verifier can fail. `tests/test_verify_C_structure.py` perturbs (a) one oscillator coefficient ($E_{2\delta_1}^+$: $\tfrac12\to 1$) and (b) one stored structure constant ($\to 7$). Both are caught.

**Tests**: `python3 -m pytest -q` gives **21 passed** (16 generator + 5 verifier).
