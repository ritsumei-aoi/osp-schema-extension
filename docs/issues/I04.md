### Response

**Executed by**: Claude Sonnet 4.6, 2026-10-03

Implemented `src/verify_C_structure.py` which:
1. Loads structure constants from JSON
2. Checks graded anti-symmetry: [X,Y} + (-1)^{p(X)p(Y)} [Y,X} = 0
3. Checks super Jacobi: (-1)^{pX pZ} [X,[Y,Z}} + (-1)^{pY pX} [Y,[Z,X}} + (-1)^{pZ pY} [Z,[X,Y}} = 0

**Bugs found and fixed during I03/I04:**
1. Initial structure constant decomposition was greedy (wrong for multi-word generators like H_1 which has both a_1^+ a_1^- and b_1^+ b_1^- terms). Fixed by proper Gaussian elimination on the generator-to-word matrix.
2. Anti-symmetry check had wrong sign (`(-1)^{pX pY+1}` instead of `(-1)^{pX pY}`). Fixed.
3. Scalar terms `()` from CAR/CCR relations (e.g., `{E_pp, E_mm} = b^+ b^- + 1 - a^+ a^-`) needed to be included in the decomposition word-space (H_{n+1} has a -1/2 scalar term that accounts for them). Fixed.
