### Response

#### Implementation
`src/verify_C_structure.py` reads only `data/C_{n}_structure.json` (it does not import the oscillator
engine, so it is an independent check of the stored data). Checks, all in exact rational arithmetic:
1. Graded antisymmetry for every ordered pair: [X,Y} = -(-1)^{p(X)p(Y)} [Y,X}.
2. Parity: every Z in [X,Y} has p(Z) = p(X)+p(Y) mod 2.
3. Super Jacobi for **all ordered triples** (dim³):
   (-1)^{p(X)p(Z)}[X,[Y,Z]] + (-1)^{p(Y)p(X)}[Y,[Z,X]] + (-1)^{p(Z)p(Y)}[Z,[X,Y]] = 0.

Decision: checked all ordered triples rather than only X ≤ Y ≤ Z — cheap (≤ 39 304 triples) and avoids
relying on the symmetry argument that reduces the triple set.
