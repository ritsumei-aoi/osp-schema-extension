#### Implementation

`src/verify_C_structure.py` loads only the JSON files (it does not import the generator, so it is an
independent check of the data) and verifies, with exact `Fraction` arithmetic:

1. **Graded antisymmetry** $[X,Y\} = -(-1)^{|X||Y|}[Y,X\}$ for every ordered pair (both orders are stored in the file).
2. **Super Jacobi identity** in derivation form
   $[X,[Y,Z\}\} = [[X,Y\},Z\} + (-1)^{|X||Y|}[Y,[X,Z\}\}$ for **every** triple $(X,Y,Z)$ (no symmetry reduction, $\dim^3$ triples).
3. Parity consistency $|Z| = |X|+|Y|$ and $Z \in$ basis for every stored term.
4. Dimension bookkeeping against the formulas $2n^2+n+1$, $4n$.

`tests/test_verify_C_structure.py` runs the verifier for n=1,2,3 and contains a **mutation test**:
changing the single coefficient of `[E_2del1_p, E_2del1_m] = 4 H_2` to `3` makes both the antisymmetry
and the Jacobi check fail, so the checks are known to have teeth.
