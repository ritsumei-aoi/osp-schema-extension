#### 2. Conventions fixed (decision)

The super Jacobi identity has several equivalent presentations; sign errors in
this step are the classic failure mode, so **both** standard forms are checked
independently rather than one:

- **Derivation form** (ad is a graded derivation):
  $$[[X,Y\},Z\} = [X,[Y,Z\}\} - (-1)^{p(X)p(Y)}[Y,[X,Z\}\}$$
- **Cyclic form**:
  $$(-1)^{p(X)p(Z)}[[X,Y\},Z\} + (-1)^{p(Y)p(X)}[[Y,Z\},X\} + (-1)^{p(Z)p(Y)}[[Z,X\},Y\} = 0$$

Bracket convention: $[X,Y\} = XY - (-1)^{p(X)p(Y)}YX$; graded antisymmetry
$[X,Y\} = -(-1)^{p(X)p(Y)}[Y,X\}$. All arithmetic is exact (`fractions.Fraction`);
no floating point is used anywhere in the verification.

#### 3. Independence of the check (decision)

Options considered:

- **(a)** Verify the JSON table against itself only.
- **(b)** Re-derive brackets from the oscillator engine and compare.
- **(c) Chosen — both.** The verifier runs four layers:
  1. well-formedness/closure/parity-additivity on the stored entries;
  2. graded antisymmetry computed **from the oscillator engine** over *all*
     $N^2$ ordered pairs (not from the stored table, so it is not a tautology);
  3. fidelity: the stored half expanded by antisymmetry must equal the engine's
     full table at all $N^2$ ordered pairs;
  4. super Jacobi on **all $N^3$ triples**, both forms, using the reconstructed
     table (so Jacobi tests the *data*, not the engine).

Layer 2 is the part the I02 storage decision (store only
`pbw_index(X) <= pbw_index(Y)`) makes meaningful: antisymmetry is a genuine
property of the realization, confirmed independently, and then *used* to expand
the file — layer 3 closes that loop.

Rejected shortcut: checking Jacobi only on triples of simple generators. It is
sufficient in theory but would not catch a transcription error in a non-simple
entry, which is exactly the risk here.

#### 5. Failures

**None.** No root-cause analysis is required.

This is the expected outcome and is *explained*, not merely observed: the
generators are realized as elements of the associative superalgebra
$\mathcal U(A)$, where the graded commutator satisfies super-Jacobi
identically. The non-trivial content verified here is therefore (i) that the
chosen 8/19/34-element spans are genuinely closed subalgebras — this is enforced
at runtime by `CAlgebra.decompose`, which raises if a bracket leaves the span —
and (ii) that the serialization to JSON and the half-table storage convention
preserve the algebra exactly. Both hold.

Secondary confirmations recorded:

- **No `K`-leakage** at any rank, re-confirming the symmetrized Cartan
  normalization decided in I01. Had the unsymmetrized Cartan been used, layer 1
  would have reported `Z == "K"` entries and the "basis" would not have been a
  subalgebra of $\mathfrak{g}$ but only of $\mathfrak{g}\oplus\mathbb{C}K$.
- **Parity additivity** $p([X,Y\}) = p(X)+p(Y)$ holds for every stored entry, so
  the $\mathbb{Z}_2$-grading of the basis split (odd $4n$ / even $2n^2+n+1$) is
  consistent.
