**Root Cause Analysis of Intermediate Failures**: During development, the initial
structure constant computation used eigenvalues for the α+β=0 bracket case, which
is incorrect. The correct formula requires direct oscillator algebra computation.
Specifically:
- Type A (±2δ_k): [(b_k^+)^2, (b_k^-)^2] = 4H_{n+1} - 4 sum_{j=k+1}^n H_j
- Type B (δ_i+δ_j pair): -sum H_j' - 2 sum H_j'' + 2H_{n+1}
- Type C (δ_i-δ_j pair): sum_{j'=i+1}^j H_{j'}
- Type D (ε+δ_k pair): -H_1 + sum_{j=2}^k H_j + 2 sum_{j=k+1}^n H_j - 2H_{n+1}
- Type E (ε-δ_k pair): H_1 - sum_{j=2}^k H_j

Also fixed: reverse brackets [E_α, H_k] were missing; added inline during Cartan loop.
The root×root loop already handles both orderings, so no global reverse sweep needed.
