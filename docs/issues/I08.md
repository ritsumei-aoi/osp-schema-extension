**Investigation and decision.** Added `src/C_triviality.py` to compare the
all-\(+1\) Schema 3 data with the selected Schema 4 map and, separately, to
solve the exact linear existence problem for an arbitrary odd linear map
\(f:\mathfrak g\to\mathfrak g\). The second calculation parameterizes every
parity-reversing basis-to-basis coefficient of \(f\), computes all
\(\delta f\) columns with rational arithmetic, and reduces each symbolic gb
coefficient in the quotient by the full coboundary image. Comparing only
against the single reference map would not establish non-triviality; I
therefore used the full linear solve for the conclusion.

**Case-specific evidence.** For all three ranks, the nonzero self-bracket
pair \((E_{\varepsilon+\delta_1},E_{\varepsilon+\delta_1})\) agrees between
the all-\(+1\) deformation and the chosen reference coboundary:
\(\gamma=2E_{\varepsilon+\delta_1}=(\delta f)\). These pairwise coincidences
do not make the full structures equal. Across all three ranks, the pair
\((E_{\varepsilon+\delta_1},E_{\varepsilon-\delta_1})\) instead has
\(\gamma=E_{\varepsilon+\delta_1}+E_{\varepsilon-\delta_1}\), whereas the
chosen reference map gives only
\((\delta f)=E_{\varepsilon-\delta_1}\). For C(2) there is also a central
obstruction: at \((E_{\varepsilon-\delta_1},H_\varepsilon)\), the all-\(+1\)
deformation gives \(H_\varepsilon+\tfrac12K\), while the reference
coboundary is zero. The exchange relation moves a boson past a fermion and
produces terms the reference map does not reproduce; in the latter example
the scalar `K` component cannot be an output of \(\delta f\) when
\(f:\mathfrak g\to\mathfrak g\) and `K` is excluded from \(\mathfrak g\)'s
basis.

**General odd-map search and conjecture.** For C(2), C(3), and C(4), the
exact coboundary-image ranks are 28, 168, and 516. After quotienting the
\(4n\) symbolic gamma columns by those images, their ranks are respectively
4, 8, and 12, while the allowed gb subspace has dimension 0 in each case.
Thus the necessary and sufficient condition on these tested ranks is that
all gb parameters vanish; the zero assignment has \(\gamma=0=\delta 0\).
The rank pattern supports the conjecture that for every bosonic rank \(n\),
the deformation is trivial exactly when all \(4n\) gb parameters vanish.
The arbitrary-rank statement remains a conjecture; the exact exhaustive
linear solve establishes it only for \(n=1,2,3\).
