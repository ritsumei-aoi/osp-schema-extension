### Response

**Status**: done. **Result: every gb profile gives a trivial deformation.** The set of trivial profiles is the whole space $\mathbb C^{4n}$ for $n=1,2,3$. The analysis below is exact, and the evidence is a set of explicit trivialising maps checked by reconstruction.

**Triviality Search Report.**

**1. Method.** For the g-valued part, the deformation at profile $\mathrm{gb}$ is $\gamma(\mathrm{gb})=\sum_m \mathrm{gb}_m G_m$ (Schema 2). The coboundaries are $D=\{\delta f_{ij}\}$ (Schema 4). The set $T=\{\mathrm{gb}:\gamma(\mathrm{gb})\in D\}$ is linear in gb. The code (`src/triviality_search.py`) computes it by exact elimination over $\mathbb Q$: it finds all linear relations among $\{\delta f_{ij}\}\cup\{G_m\}$, projects them to gb, and takes the nullspace for the defining equations. The K-part is handled the same way with the K-coboundaries $-\lambda\circ[\cdot,\cdot]_{\mathrm{odd}}$.

**2. Results.**

| $n$ | $\dim T_g$ | $\dim T_K$ | defining equations of $T_g$ | defining equations of $T_K$ |
|---|---|---|---|---|
| 1 | 4 | 4 | none | none |
| 2 | 8 | 8 | none | none |
| 3 | 12 | 12 | none | none |

Consistency of the method: the rank of $D$ for $n=1$ is 28, out of 32 elementary maps. The 4-dimensional kernel matches the 4 odd elements of $\mathfrak g$ (the odd inner derivations $\mathrm{ad}X$), which is expected.

**3. Case-specific evidence (trivial cases).**
- *Unit profiles* $\mathrm{gb}=e_m$. For each of the $4n$ parameters there is an explicit odd map $f^{(m)}$ with $\delta f^{(m)}=G_m$ exactly. Stored in `data/C_triviality.json`, verified by reconstruction inside `certificate()`. For $n=1$, the map for $\mathrm{gb}_{a_1^+,b_1^+}$ is
  $E_{\varepsilon+\delta_1}\mapsto -H_2$, $\quad E_{\varepsilon-\delta_1}\mapsto 2E_{2\delta_1}^{-}$ (with $E_{2\delta_1}^-=\tfrac12(b_1^-)^2$), $\quad H_1\mapsto E_{-\varepsilon-\delta_1}$.
  The K-part for the same profile is $E_{\varepsilon+\delta_1}\mapsto \tfrac12 K$.
- *Representative profile* $\mathrm{gb}=\mathbf 1$ (I06). With $f_{\mathbf 1}=\sum_m f^{(m)}$, the Layer 3 vs Layer 4 comparison gives **0 mismatches** in the g-part (92, 568, 1660 entries for $n=1,2,3$) and **0 mismatches** in the K-part (20, 84, 180). So the evaluated deformation (Schema 3) equals $\delta f_{\mathbf 1}$ (Schema 4) coefficient by coefficient.
- *General profile.* By linearity, $f_{\mathrm{gb}}=\sum_m \mathrm{gb}_m f^{(m)}$ trivialises $\gamma(\mathrm{gb})$ for every $\mathrm{gb}$.

**4. Negative control.** The test is not vacuous: a single extra component $(E_{\varepsilon+\delta_1},E_{\varepsilon+\delta_1},Z)$ added to $G_1$ (with $Z$ of the correct parity) leaves the coboundary span (the sympy rank rises). The independent solver (sympy) confirms each unit $G_m$ lies in the span of $D$ for $n=1$. This confirms that the membership test can return "non-trivial"; it simply does not do so for the actual $\gamma$.

**5. Discrepancy analysis.** There are no non-trivial cases, so there are no inconsistent generator pairs in the real data. The only discrepancy is the one introduced by the negative control above. Its location, the pair $(E_{\varepsilon+\delta_1},E_{\varepsilon+\delta_1})$ with a component on $Z$, is what a real obstruction would look like.

**6. Why a simple reason does not suffice.** One might hope to remove the deformation by a shift of oscillators, $b_j^s\mapsto b_j^s+\kappa\,\mu\,a^\sigma$, which kills $[b,a]=-\mathrm{gb}\,\kappa$ and leaves the bosonic commutators unchanged (since $\kappa^2=0$). This does not preserve $\mathfrak g$: it produces $a_1^+a_1^-$ alone (from $E_{\varepsilon+\delta_1}$), which is not in $\mathfrak g$ (only $H_1=a^+a^-+b_1^+b_1^-$ is). So the triviality does not come from this shift; it is established only by the exact certificates above.

**7. General conjecture.** For $C(n+1)=\mathfrak{osp}(2|2n)$, with the deformation $[b_j^s,a_1^\sigma]=-\mathrm{gb}_{\sigma,j,s}\kappa$:

> **Conjecture.** For every $\mathrm{gb}\in\mathbb C^{4n}$ the inhomogeneous deformation is trivial: $\gamma(\mathrm{gb})=\delta f_{\mathrm{gb}}$ with $f_{\mathrm{gb}}=\sum_{\sigma,j,s}\mathrm{gb}_{\sigma,j,s}f^{(\sigma,j,s)}$ an odd map, and the K-part is a K-coboundary. Equivalently, the set of trivial gb is all of $\mathbb C^{4n}$, and there is no non-trivial profile.

Status: verified exactly for $n=1,2,3$ (all $4n$ unit profiles and the representative profile). **Not proven for general $n$.** Only the $n\le3$ computations are available.

**8. Assumptions and limits** (see notation.md §8).
- The gb are commuting scalars (A1). If they were Grassmann-odd (the doc's parity claim), the sign rules would change and this analysis would not apply directly.
- Triviality uses odd linear maps $f:\mathfrak g\to\mathfrak g$, as in the doc. The K-part is reported separately (A4).
- The result is invariant under the representative choices: the K-only change from A3, and the rescaling of $E_{\pm2\delta_k}$ from A2 (a basis change).
- The triviality is proven only for $n\le 3$.

**Interpretation for the user.** The question "which gb make the deformation trivial" has answer "all of them" for $C(n+1)$, $n\le3$. The B(0,n) case of the study may differ, but I did not analyse it here.
