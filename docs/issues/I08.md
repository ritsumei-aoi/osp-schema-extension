## Triviality Search Report

### 0. Method
`src/C_triviality.py` sets up the linear system $(\delta f)(X,Y)_Z = \gamma(X,Y)_Z$ for **all ordered pairs** $(X,Y)$ and all components $Z \in \text{basis} \cup \{K\}$:
- left side: **Layer 4** (`C_{n}_coboundary.json`, linear forms in φ);
- right side: **Layer 3** (`C_{n}_evaluated*.json`, six gb profiles), and, for the general statement, **Layer 2** (`C_{n}_gamma.json`, γ symbolic in gb).

The system is solved by exact rational Gaussian elimination. Rows that reduce to $0 = r$ give the **consistency conditions** $r = 0$. With the symbolic right side, these are linear conditions on gb, i.e. the necessary and sufficient triviality conditions. Every solution found is re-checked independently by substituting it back into Layer 4 and comparing with γ entry by entry. Output: `data/C_triviality_report.json`.

**Interpretation of "γ = δf up to scalar"** (`C_coboundary_definition.md` §3). Layer 2 showed that γ takes values in $\mathfrak g \oplus \mathbb{C}K$. I considered three readings and computed all of them:

| Mode | f | Components compared | Meaning |
|---|---|---|---|
| **A** (adopted as the main reading) | $\mathfrak g \to \mathfrak g \oplus \mathbb{C}K$ | all, including K | trivial up to central scalars ($K = 1$); this is how I read "up to scalar" |
| B | $\mathfrak g \to \mathfrak g$ | all, including K | strict, literal reading of $f:\mathfrak g\to\mathfrak g$ |
| C | $\mathfrak g \to \mathfrak g$ | K-components dropped | γ projected to $\mathfrak g$ |

Why A: the doc explicitly says "up to scalar". Also, $K=1$ and κ both lie in the algebra $A$, so replacing an odd generator $X$ by $X - c\,\kappa$ ($c$ a scalar) is a legitimate change of generators.

### 2. Where the discrepancies are and why (mode B)
**Which pairs.** Every inconsistent row is a $K$-component of an (odd, even) or (even, odd) pair. In mode B no unknown reaches the $K$ rows, so each residual equals the raw $\gamma_K$ value. n=1, profile `single` (only $\mathrm{gb}_{a_1^+,b_1^+}=1$), the complete list:

| X | Y | $\gamma(X,Y)_K$ | $(\delta f)(X,Y)_K$ for any $f:\mathfrak g\to\mathfrak g$ |
|---|---|---|---|
| E_eps1_del1_pp | H_1 | 1 | 0 |
| E_eps1_del1_pp | H_2 | −1/2 | 0 |
| E_eps1_del1_pm | E_2del1_p | −1 | 0 |
| (the 3 transposed pairs) | | opposite sign | 0 |

For `allplus`, n=1, there are 20 such rows, e.g. (E_eps1_del1_pp, E_2del1_m)_K = 1, (E_eps1_del1_mm, H_1)_K = −1, (E_eps1_del1_pm, H_2)_K = 1/2. All other components ($Z \in \mathfrak g$) are matched exactly; this is why mode C is trivial.

**Mathematical reason.**
1. *Where $K$ comes from.* Commuting $b_j^s$ through $a_1^\sigma$ yields $\kappa$ times a boson monomial that is **not** Weyl-ordered. Rewriting it in the basis uses the CCR constant, e.g. $b_j^+b_j^- = h_j - \tfrac12$. Example: $[(b_1^+)^2, a_1^+b_1^-]$ has κ-part $-2g\,b_1^+b_1^- = 2gH_2 + gK$.
2. *Exact form of the obstruction* (verified for all pairs, n=1,2,3):
   $$\gamma_K(X,Y) = -f_K([X,Y]), \qquad f_K(E_{\sigma\varepsilon + s\delta_j}) = \tfrac12\,\mathrm{gb}_{\sigma,j,s}.$$
   So $\gamma_K(X,Y) = -\tfrac12\sum_{W \in \mathfrak g_{\bar 1}} [X,Y]_W\,\mathrm{gb}_W$.
3. *Why no $f:\mathfrak g\to\mathfrak g$ can fix it.* The structure constants of $\mathfrak g$ never produce $K$ (verified in I03: the Weyl-ordered generators close). So for such an $f$, $\delta f$ has no $K$-component. Since $\mathfrak g$ is simple, hence perfect ($\mathfrak g_{\bar1} = [\mathfrak g_{\bar0}, \mathfrak g_{\bar1}]$), $\gamma_K = 0$ forces $f_K = 0$ on $\mathfrak g_{\bar1}$, i.e. gb = 0. The symbolic rank (4n of 4n) confirms this.
4. *Why it disappears in mode A.* $\gamma_K$ is itself the coboundary of the scalar-valued odd map $f_K$. Equivalently, it is removed by shifting each odd generator by a scalar multiple of κ: $X \mapsto X - f_K(X)\,\kappa$.

### 3. Closed-form trivializing map (holds for all n)
Define $c^\sigma = \sum_k (\mathrm{gb}_{\sigma,k,-}\,b_k^+ - \mathrm{gb}_{\sigma,k,+}\,b_k^-)$ and $a'^\sigma = a_1^\sigma + \kappa c^\sigma$. Then $[b_j^s, a'^\sigma] = 0$, $\{a'^-, a'^+\} = 1$ and $(a'^\pm)^2 = 0$: the primed oscillators obey the **undeformed** relations (this uses $\kappa^2 = 0$). Writing each generator as $X = X(a') + \kappa f(X)$ gives
$$f(a_1^\sigma b_j^s) = -c^\sigma b_j^s,\qquad f(H_1) = a_1^+c^- - a_1^-c^+,\qquad f(\text{all other even}) = 0,$$
and $\gamma = \delta f$ in the doc's sign convention (derivation in the I07 Response). n=1 explicitly (from `C_triviality_report.json`):
```
f(E_eps1_del1_pp) = -gb_a1p_b1p H_2 - gb_a1p_b1m E_2del1_p + 1/2 gb_a1p_b1p K
f(E_eps1_del1_pm) =  gb_a1p_b1m H_2 + gb_a1p_b1p E_2del1_m + 1/2 gb_a1p_b1m K
f(E_eps1_del1_mp) = -gb_a1m_b1p H_2 - gb_a1m_b1m E_2del1_p + 1/2 gb_a1m_b1p K
f(E_eps1_del1_mm) =  gb_a1m_b1m H_2 + gb_a1m_b1p E_2del1_m + 1/2 gb_a1m_b1m K
f(H_1) = gb_a1m_b1m E_eps1_del1_pp - gb_a1m_b1p E_eps1_del1_pm - gb_a1p_b1m E_eps1_del1_mp + gb_a1p_b1p E_eps1_del1_mm
```
Machine check: $\delta f_{\rm can} = \gamma$ exactly for each of the 4n unit gb vectors. By linearity this covers all gb, for n=1,2,3.

**Uniqueness.** The solution space has dimension exactly 4n = dim $\mathfrak g_{\bar1}$ (nullity 4/8/12). It is spanned by the 4n inner odd maps $X\mapsto[Z,X\}$, $Z\in\mathfrak g_{\bar1}$: all of them are δ-closed (verified), and they are independent because $\mathfrak g$ has trivial center. So the trivializing $f$ is unique modulo inner maps. In the computed range, odd $H^1$ vanishes.

### 4. Conjecture
For every $n\ge1$ and every $\mathrm{gb}\in\mathbb{C}^{4n}$, the inhomogeneous deformation $[b_j^s, a_1^\sigma] = -\mathrm{gb}_{\sigma,j,s}\kappa$ of $C(n+1)=\mathfrak{osp}(2|2n)$ satisfies:
1. **(Main: trivial up to scalars.)** It is **always trivial**: $\gamma = \delta f$ with $f:\mathfrak g\to\mathfrak g\oplus\mathbb{C}K$ odd, given by the closed form of §3. **No condition on gb is needed.** Equivalently, the triviality condition is the empty set of linear conditions (rank 0).
2. **(Strict.)** With $f:\mathfrak g\to\mathfrak g$ required, it is trivial **iff gb = 0**. The only obstruction is the central cocycle $\gamma_K = -f_K\circ[\cdot,\cdot]$, $f_K = \tfrac12\mathrm{gb}$.
3. **(Projected.)** The $\mathfrak g$-projection of γ is always a coboundary of some $f:\mathfrak g\to\mathfrak g$.
4. The trivializing f is unique modulo the 4n inner odd maps.

**Status.** (1)–(3) hold for n=1,2,3 by exact computation. Points 1 and 2 also have the n-independent proof sketch above: the oscillator change of variables, plus perfectness of $\mathfrak g$. So I expect them to hold for all n. Point 4 is verified for n ≤ 3 only.

Structural reason C(n+1) behaves this way: the fermionic pair is a **standard** CAR pair. A shift $a'^\sigma = a^\sigma + \kappa c^\sigma$ by a linear boson form can absorb the mixed form $(b|a)$ *without* disturbing the CAR, because $\kappa^2 = 0$ and $[c, a]\propto\kappa$. Contrast with B(0,n), where the deformation enters through $a_0^2$. No B(0,n) data was available in this repository, so this contrast is not checked.
