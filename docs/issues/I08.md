### 3. Rigorous analysis of the only candidate discrepancy (K-components)

γ(X,Y) contains scalar (`K`) components precisely on mixed-parity pairs
where a deformed contraction is followed by a CCR contraction (24/80/168
records for n = 1/2/3). Structure-constant brackets never produce K (the
algebra closes on g), so within δf only the term −f([X,Y]) can generate
K-components — i.e. **a strictly g→g map f cannot reproduce the K-part of
γ**. This is the one potential obstruction in the data.

Resolution: (i) the canonical f of I07 naturally takes values in g ⊕ ℂK
(e.g. f(`E_eps_del1_pp`) ∋ ½·K via `b_1^- b_1^+ = H_1 + ½`), and with those
central components γ = δf holds **exactly**, K-parts included; (ii) in the
adjoint representation (the setting of `C_coboundary_definition.md`, where
C(n+1) ⊂ U(A) acts adjointly and the center acts trivially — "up to
scalar"), the K-parts of both sides act as zero, and the comparison modulo
K is *also* an exact match (0 mismatches). Under either reading the
deformation is a coboundary.

### 4. General conjecture

> **Conjecture (triviality for C(n+1)).** For every n ≥ 1 and **every**
> value of the 4n deformation parameters gb_{σ,j,s}, the inhomogeneous
> deformation γ of C(n+1) = osp(2|2n) is trivial: γ = δf for the odd map
>
> f(a_1^σ b_l^{s'}) = Σ_{j,s} t_{σ,j,s}·:b_j^s b_l^{s'}: ,
> f(H_eps) = Σ_{j,s}(−t_{−,j,s} a_1^+ b_j^s + t_{+,j,s} a_1^- b_j^s),
> f|_{bosonic} = 0, with t_{σ,j,+} = −gb_{σ,j,−}, t_{σ,j,−} = +gb_{σ,j,+}.
>
> Hence the necessary and sufficient condition on gb is **vacuous** — the
> relevant H²-class vanishes identically, and the gb "moduli" are pure gauge.

**Mathematical reason / proof sketch**: the deformed relation
[b_j^s, a_1^σ] = −gb_{σ,j,s}κ is implemented by the κ-shift
a_1^σ ↦ a_1^σ + κ Σ t_{σ,j,s} b_j^s inside A = V ⊕ ℂK ⊕ ℂκ. This shift
preserves the CAR ({ã_1^-, ã_1^+} = 1 up to κ² = 0) and the CCR, i.e. it is
an automorphism of A to first order in κ, so the deformed algebra is
isomorphic to the undeformed one and the cocycle is exact, f being the
derivative of the shift. The computation confirms this at the level of all
structure constants for n = 1, 2, 3.

**Contrast with the reference case B(0,n)**: there the deformation lives in
a_0² ↦ ½ + κ Σ gb·b_j^s. A shift a_0 ↦ a_0 + κT (T bosonic) does **not**
reproduce it: the cross terms a_0(κT) + (κT)a_0 = κ[T, a_0] vanish
classically because κ anticommutes with the *single* self-conjugate fermion
a_0. The absorbing mechanism available to C(n+1) — two independent fermionic
directions a_1^± that can be shifted independently — is absent in B(0,n),
which is why B(0,n) admits genuinely nontrivial inhomogeneous deformations
while C(n+1), per the data above, does not.
