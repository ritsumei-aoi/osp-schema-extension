#### 1. Method

The deformation $\gamma$ is trivial iff there exists an odd linear map $f: \mathfrak{g} \to \mathfrak{g}$ such that $\gamma = \delta f$. This reduces to a linear system:

$$A \cdot \phi_\text{vec} = \gamma_\text{vec}$$

where:
- $A$ = coboundary matrix (Layer 4): $A[\text{triple}_{XYZ}][\phi_{ij}]$ = coefficient of $\phi_{ij}$ in $(\delta f)(X,Y)^Z$.
- $\gamma_\text{vec}$ = gamma vector (Layer 3): concrete values of $\gamma(X,Y)^Z$ at the given gb assignment.

Solvability ↔ triviality. The symbolic analysis checks each individual gb-parameter direction.

#### 3. Symbolic Analysis: Per-gb-direction Triviality

For each of the 4n gb parameters individually:

| n | Non-trivial directions | Trivial directions |
|---|---|---|
| 1 | ALL 4: gb_p_1_p, gb_p_1_m, gb_m_1_p, gb_m_1_m | none |

**Key structural observation**: `rank(A) = n_phi - 4n`, i.e., `kernel(δ) has dimension 4n = number of gb parameters`. This is not a coincidence — it reflects a deep symmetry:

The kernel of the coboundary operator δ on odd linear maps $f: \mathfrak{g} \to \mathfrak{g}$ has dimension 4n for C(n+1). This equals exactly the number of deformation parameters.

#### 4. Root Cause Analysis of Non-triviality

For each gb direction (say $\mathrm{gb}_{a_1^+, b_1^+}$), the gamma vector $\gamma^{gb}$ has components $\gamma(X,Y)^Z$ that are **not in the image** of the coboundary operator A.

Specifically, the non-trivial structure is visible in the ε-root brackets. Consider:
- $X = E_{\varepsilon+\delta_1}$ (odd, root ε+δ_1), $Y = H_k$ (even Cartan).
- $\gamma(E_{\varepsilon+\delta_1}, H_k)^Z$ gains a contribution from $[b_k, a_1^+] = -\mathrm{gb}_{p,k,m}\kappa$ type terms.
- The coboundary $(\delta f)(E_{\varepsilon+\delta_1}, H_k)$ must equal this, but the Cartan action on odd generators combined with the parity reversal constraint on $f$ prevents this matching.

The constraint is: if $f$ maps Cartans $H_k$ to odd generators, then $[X, f(H_k)]$ for $X$ odd would contribute to the gamma condition. But $f(H_k)$ is odd by parity reversal, and $[E_{\varepsilon+\delta_k}, f(H_k)]$ gives even generators. The required combination cannot be achieved because the ε-type generators introduce 4n independent constraints (one per gb direction) that exceed the effective degrees of freedom of $f$ after the Jacobi conditions are imposed.

---

#### 5. General Conjecture

**Conjecture**: The inhomogeneous deformation $\gamma(\mathrm{gb})$ of $C(n+1) = \mathfrak{osp}(2|2n)$ is trivial (a coboundary) **if and only if** $\mathrm{gb} = 0$ (all 4n deformation parameters vanish).

**Equivalently**: For any non-zero choice of gb parameters, the deformed Lie superalgebra structure is genuinely non-trivial — it cannot be transformed back to the undeformed algebra by an inner automorphism of the form $\mathrm{id} + \kappa f$.

**Evidence**:
1. Every individual gb direction is non-trivial (symbolic analysis, n=1,2,3).
2. The coboundary operator rank = n_phi - 4n for all tested n, leaving exactly 4n directions outside Image(δ).
3. The pattern rank(A) = n_phi - 4n = (dimension of odd maps) - (number of gb params) is consistent across n=1,2,3.
4. The concrete gb=+1 case is non-trivial for all n.

**Contrast with B(0,n)**: In B(0,n), the deformation is parametrized by 2n parameters. The analogous conjecture for B(0,n) (see `docs/drafts/aoi2026_triviality_osp1_2n.tex`) states the deformation is also non-trivial. The C(n+1) case doubles the parameter count (4n vs 2n) due to the standard fermionic pair a1±, and all 4n directions are similarly non-trivial.

---

#### 6. Additional Investigation: Zero-gb Case

For completeness: gb=0 gives $\gamma=0$, and the system $A\phi = 0$ is trivially solvable ($\phi=0$). So the zero deformation is always trivial. ✓

This confirms: triviality holds precisely for gb=0.
