## Triviality Search Report — C(n+1) = osp(2|2n)

**Tools:** `src/C_triviality.py` (exact rational linear algebra comparing Layer 3 γ with Layer 4
δf) and `src/C_triviality_witness.py` (minimal explicit obstruction). Summary data written to
`data/C_triviality_summary.json`.

### Method
A deformation γ is trivial iff γ = δf for some odd map f. Both sides are 2-cochains valued on the
Layer-1 basis, indexed by $(X,Y,Z)$:
- $\gamma(X,Y)_Z$ is **linear in the 4n gb parameters** → coefficient matrix $B$ ($E\times 4n$).
- $\delta f(X,Y)_Z$ is **linear in the P φ parameters** of the general odd map (Layer 4) → matrix
  $M$ ($E\times P$).

A given gb is trivializable iff $\exists\,\phi:\ M\phi = B\,\mathrm{gb}$. The set of trivializable
gb is a linear subspace of dimension
$$\dim L = 4n - \big(\operatorname{rank}[M\,|\,B] - \operatorname{rank} M\big).$$
The pipeline was validated by confirming a genuine coboundary ($\delta f$ for a random φ) is
reported solvable.

### (1) Layer 3 vs Layer 4 comparison — results

| $C(n+1)$ | $n$ | eqns $E$ | $P=\dim\,$1-cochain | rank $M$ (coboundaries) | rank $B$ | rank $[M\,|\,B]$ | $\dim L$ |
|---|---|---|---|---|---|---|---|
| C(2) | 1 | 124 | 36 | 32 | 4 | 36 | **0** |
| C(3) | 2 | 1438 | 184 | 176 | 8 | 184 | **0** |
| C(4) | 3 | 7122 | 540 | 528 | 12 | 540 | **0** |

In every case $\operatorname{rank}[M|B] = \operatorname{rank} M + 4n$ and $\operatorname{rank}B=4n$:
the $4n$ gb deformation directions are **linearly independent of the entire coboundary space**.
Hence $\dim L = 0$: **the only trivializable deformation is $\mathrm{gb}=0$**.

- **Trivial case (structures coincide):** only $\mathrm{gb}=0$. Then Layer 3 γ ≡ 0, which equals
  $\delta f$ with $f=0$; Layer 3 and Layer 4 coincide (both vanish). This is the undeformed algebra.
- **Non-trivial cases (do not coincide):** every $\mathrm{gb}\neq 0$. No choice of the $P$ φ
  parameters reproduces γ.

### (2) Rigorous analysis of the discrepancy — a concrete obstruction

`C_triviality_witness.py` isolates a **single-entry** obstruction for C(2):

```
equation [X = E_eps1_del1_mp, Y = H_1] -> component H_2
```
Reading the generated data directly:
- Layer 3: $\gamma(E_{-\varepsilon+\delta_1},\,H_1)\big|_{H_2} = -2\,\mathrm{gb}_{m,1,p}$
  (file `C_1_gamma.json`).
- Layer 4: $\delta f(E_{-\varepsilon+\delta_1},\,H_1)$ has components only on
  $\{H_1,\,E_{2\delta_1}^{+},\,E_{2\delta_1}^{-}\}$ — **no $H_2$ component for any φ**
  (file `C_1_coboundary.json`).

So this matrix element forces $0 = -2\,\mathrm{gb}_{m,1,p}$, i.e. it can be matched only if
$\mathrm{gb}_{m,1,p}=0$. **Mathematical reason:** bracketing the odd root vector
$E_{-\varepsilon+\delta_1}$ with the Cartan $H_1$ produces, under the deformation, a *Cartan drift*
along $H_2$ (the $\mathfrak{sp}(2)$ coroot direction). A coboundary $\delta f$ at an
(odd generator, Cartan) argument can only populate the root directions tied to $f$'s image on those
generators; it cannot generate this independent Cartan component. The analogous single-entry
$H_{n+1}$/Cartan obstruction exists for each gb parameter and each $n$, which is exactly why
$\operatorname{rank}[M|B]=\operatorname{rank}M+4n$ (one independent obstruction per gb).

### (3) General conjecture (necessary & sufficient condition)

> **Conjecture.** For $C(n+1)=\mathfrak{osp}(2|2n)$ the inhomogeneous (gb) deformation is trivial
> **if and only if all $4n$ gb parameters vanish**. Equivalently, the $4n$ parameters
> $\mathrm{gb}_{\sigma,j,s}$ ($\sigma\in\{+,-\}$, $j=1..n$, $s\in\{+,-\}$) map to $4n$ **linearly
> independent non-trivial classes** in the odd deformation cohomology $H^2(\mathfrak g,\mathfrak g)_{\bar 1}$;
> no nonzero linear combination is a coboundary.

This is verified exactly for $n=1,2,3$ (the conditions returned are precisely
$\mathrm{gb}_{\sigma,j,s}=0$ for every parameter).

### (4) Active investigation / notes
- The non-triviality is **rank-certified** (exact arithmetic) and independently corroborated by (a)
  direct solvability (rank $[M|b]$ > rank $M$ for the `all_plus` and single-parameter profiles) and
  (b) the explicit single-equation witness above.
- **Contrast with B(0,n).** The handover references Aoi (2026) on triviality of the $B(0,n)$
  deformation. The structural difference is the fermionic sector: $B(0,n)$ uses the *supplementary*
  fermion $a_0$ ($a_0^2=\tfrac12$) whose deformation ($a_0^2\mapsto\tfrac12+\kappa\sum \mathrm{gb}\,b$)
  is a reparameterization of a single auxiliary square, whereas $C(n+1)$ uses a genuine CAR pair
  $a_1^\pm$ and deforms the independent relations $[b_j^s,a_1^\sigma]$ (4n of them). The extra
  fermionic direction ($\mathfrak{so}(2)$ factor in the even part) is what carries the obstruction,
  making the $C(n+1)$ family rigidly non-trivial. (Stated as an interpretation; only the $C(n+1)$
  computation above is performed here.)
