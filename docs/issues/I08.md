**Discrepancy analysis (non-trivial cases)**

- The g-part of γ coincides with a coboundary for every gb. The system has no gb-constraint at all from the g-rows (rank 0 for $n=1,2,3$, checked separately). So every disagreement is in the central component $K$.
- Concrete $n=1$ case: the pair $(E_{\varepsilon+\delta_1}, H_1)$. Layer 3 gives $\gamma(E_{\varepsilon+\delta_1},H_1)\ni \mathrm{gb}_{a_1^+,b_1^+}\,K$ with coefficient $1$. Layer 4 has no K-component, since every $\delta f$ lies in $\mathfrak g$. The mismatch is $\mathrm{gb}_{a_1^+,b_1^+}$.
- Mathematical reason: the anomaly $[b_k^s,a_1^\sigma]=-\mathrm{gb}\,\kappa$ produces $\kappa$ times a bilinear in the bosons, e.g. $\kappa\,b_1^+b_1^-$, which is not in $\mathfrak g$ as written. Rewriting it in the basis uses $b_1^+b_1^-=-H_2-\tfrac12$, and the constant $-\tfrac12$ is forced by closure of the κ-free algebra (I03). That constant is the source of a $K$-component. The exact K-coefficients in the data differ by pair (for example $1$, $-\tfrac12$, $-1$, $\tfrac12$ in the $n=1$ list), so this is a summary of the mechanism, not a closed formula for every entry. Since every $\delta f$ lies in $\mathfrak g$, this part cannot be absorbed by $f:\mathfrak g\to\mathfrak g$.
- Each gb parameter appears alone in at least one K-equation (for $n=1,2,3$). So the K-equations directly force $\mathrm{gb}_{\sigma,k,s}=0$.

**General conjecture (for the strict reading, f: g -> g)**

For $C(n+1)=\mathfrak{osp}(2|2n)$, the inhomogeneous deformation $\gamma(\mathrm{gb})$ is trivial if and only if $\mathrm{gb}=0$.

- Necessary: the central (K) component of γ is $\sum_{\sigma,k,s}\mathrm{gb}_{\sigma,k,s}\,c_{\sigma,k,s}$ with the $c$ linearly independent (rank $4n$). This vanishes only if $\mathrm{gb}=0$, since $\delta f$ never has a K-part.
- Sufficient: for $\mathrm{gb}=0$ the deformation is the undeformed bracket, and $f=0$ works.
- The g-part being always a coboundary is the statement that the "gb-linear" g-part of γ lies in the image of δ for every gb.
- Verified exactly for $n=1,2,3$. The general-$n$ statement is a conjecture from this pattern, not a proof.

**Reading of "trivial" (decision and sensitivity)**

- The doc's definition uses $f:\mathfrak g\to\mathfrak g$. I used this as the primary reading. Under it, the answer is "only gb=0".
- The extended reading (f may send odd elements to $K$, which is parity-reversing) makes every gb trivial. The K-part is absorbed by the maps $Z_j\mapsto K$, $j$ odd, which contribute only K-components. This is an extra investigation, not the doc's definition. It shows that the non-triviality found above is entirely due to the K-component, and that it depends on whether $K$ is allowed in the coboundary.
- The "up to scalar" wording in the doc does not change the answer: rescaling $f$ absorbs the scalar, and the strict locus is still $\{0\}$.

**Checks**: kernel witnesses were verified exactly on all equations (for the extended reading, the representative profile was verified too). The elimination was checked against the full system; the g-only check gave rank 0 independently. The rank computation is exact (Fractions), not floating point.

**Limitations**: the general-$n$ conjecture is verified only for $n=1,2,3$. The cocycle check for δf (I07) was run on a sample of maps for $n=2,3$, not all maps. The docs conflict on whether γ takes values in $\mathfrak g$ or in $\mathfrak g\oplus\mathbb CK$; this affects the answer and should be settled by the document owner.
