## Triviality Search Report — inhomogeneous deformation of C(n+1) = osp(2|2n)

### 0. Bottom line
- **g-valued (on L = g ⊕ κg, as in the math doc):** the deformation is a coboundary, γ = δf, **for every**
  gb ∈ ℂ^{4n}. There is no condition on gb. This holds for n = 1, 2, 3 by exact computation, and for all n by the
  argument in §4.
- **Strict closure (with the κK term the oscillator realization actually produces):** the realization has an extra
  κ·K component γ_K. No g-valued f can produce it. γ_K = 0 **iff all gb = 0**. This central part is still a
  coboundary once odd generators may be shifted by κ·constants (h: g₁ → ℂK).
- Which answer is the "triviality condition" depends on which notion is meant. Both are reported, with data.

### 1. Method (`src/C_triviality.py`, output `data/C_triviality_report.json`)
The unknowns are the 2·dim g₀·dim g₁ coefficients φ of an odd map f (Layer 4) and, optionally, the dim g₁
coefficients ψ of h(Z_j) = ψ_j K. The equations are (δf + δh)(X,Y)_Z = γ(X,Y)_Z for all index(X) ≤ index(Y) and
all Z, plus the K-component. They are solved by exact rational sparse Gaussian elimination:
- *Symbolically*: the right-hand side is Layer 2 with gb kept as symbols. Every row whose left side eliminates to 0
  leaves a linear form in gb that must vanish. The span of these forms is **exactly** the necessary-and-sufficient
  condition for triviality.
- *Numerically*: the right-hand side is each Layer 3 profile.
- Every solution is then checked: Layer 4 evaluated at the solution is compared entry by entry with Layer 2/3 on
  **all ordered pairs**.

Three notions are tested:
- T1: γ = δf (g-valued).
- T2: γ + γ_K K = δf + δh.
- T3: γ + γ_K K = δf with f g-valued (strict).

The γ = +δf vs −δf convention does not matter (f → −f).

### 3. Root cause of the discrepancies
1. Every δf with f: g → g is g-valued, because Schema 1 has no K component. So T3 needs γ_K ≡ 0.
2. γ_K comes from normal ordering inside κ-terms: κ b_k^- b_k^+ = κ(b_k^+ b_k^- + 1) and κ a^- a^+ = κ(1 − a^+ a^-).
   Only odd–even pairs produce it, because p(γ) = p(X)+p(Y)+1 must be 0 for a scalar.
3. The data satisfy γ_K(X,Y) = h_F([X,Y]₀) with h_F(E_{σ,k,s}) = −½ gb_{σ,k,s}. Take X = H with
   α(H) ≠ 0 for the odd root α of E. Then γ_K(H, E) = α(H)·h_F(E). This vanishes for all H iff
   gb_{σ,k,s} = 0. Hence T3 ⇔ gb = 0. The eliminator finds exactly this: the 4n independent conditions are
   `{gb_a1σ_bjs: 1}`, i.e. each gb = 0.
4. This obstruction is not cohomological in the adjoint module. Shifting each odd generator
   E ↦ E − ½ gb_{σ,k,s} κK (the ψ-part, T2) removes it.

### 4. Conjecture / theorem (proved for all n, verified exactly for n = 1, 2, 3)
Let L^σ = Σ_j (gb_{σ,j,−} b_j^+ − gb_{σ,j,+} b_j^-) and a'^σ = a_1^σ + κ L^σ. Then:
- [b_j^s, a'^σ] = −gb_{σ,j,s}κ + κ[b_j^s, L^σ] = 0.
- {a'^-, a'^+} = 1 and (a'^±)² = 0, because κ² = 0.

So (a', b) satisfy the **undeformed** relations, and X ↦ X(a', b) = X + κF(X) is an isomorphism onto the
undeformed algebra. This gives γ + γ_K K = −δF. Explicitly:
- F(a^σ b_k^s) = L^σ b_k^s ∈ sp(2n) ⊕ ℂK, with K-part −½ gb_{σ,k,s}.
- F(H_1) = a^- L^+ − a^+ L^- ∈ g₁.
- F = 0 on the sp(2n) generators H_2..H_{n+1}, E_{±2δ}, E_{±δ±δ}.

`closed_form_check_mismatches = 0` for n = 1, 2, 3, symbolically in all gb.

**Conjecture (necessary and sufficient conditions on gb):**
1. *(g-valued / L = g ⊕ κg)* The inhomogeneous deformation of C(n+1) is trivial for **all** gb ∈ ℂ^{4n}. A
   trivializing odd map is f = −F_g. It is unique modulo ker δ = {inner odd derivations ad_E, E ∈ g₁}
   (dim ker δ = 4n observed, so H¹_odd(g, g) = 0 for n ≤ 3).
2. *(strict, generators may only change by g-valued κ-terms)* Trivial ⇔ gb_{σ,j,s} = 0 for all σ, j, s.
3. *(with central shift h: g₁ → ℂK)* Trivial for all gb, with h(E_{σ,k,s}) = ½ gb_{σ,k,s} in the γ = δf
   convention.

The result does not depend on the sign profile: all six non-zero profiles behave identically. Only "gb = 0 or not"
matters, which the single-parameter profile also confirms.
