### Triviality comparison report

**Method.** Added `src/C_triviality.py` to compare the Layer 2 symbolic gamma
coefficients, Layer 3 all-positive evaluation, and Layer 4 generic
`delta f` image. The comparison is exact over rational coefficients. The
decisive obstruction is that Layer 4 maps `g x g -> g` and its `Z` outputs
are all Schema 1 basis generators, whereas the computed Layer 3 gamma has
terms proportional to the identity `K`. No choice of `f: g -> g` can
produce or cancel a `K` output.

**Non-trivial cases and evidence.** The all-positive Layer 3 assignment is
non-trivial for every tested rank. It has 20, 84, and 180 nonzero `K`
obstruction records for C(2), C(3), and C(4), respectively; the corresponding
Layer 4 coefficient lists contain no `K` output. Four explicit independent
parameter witnesses present for all three ranks are:

| Generator pair | Identity coefficient in gamma |
|---|---|
| `(E_2del1_m, E_eps1_del1_mp)` | `+1/2 * gb_a_1_m_b_1_m * K` |
| `(E_2del1_m, E_eps1_del1_pp)` | `+1/2 * gb_a_1_p_b_1_m * K` |
| `(E_2del1_p, E_eps1_del1_mm)` | `-1/2 * gb_a_1_m_b_1_p * K` |
| `(E_2del1_p, E_eps1_del1_pm)` | `-1/2 * gb_a_1_p_b_1_p * K` |

For each `k>=2` in the rank-2 and rank-3 results, the additional witnesses
are `(H_1, E_eps1_del{k}_pp/pm/mp/mm)`, with coefficient
`-1/2 * gb_a_1_{p/p/m/m}_b_{k}_{p/m/p/m} * K`, respectively. Automated
comparison found at least one single-parameter identity witness for every
one of the `4n` parameters at each rank. Thus no cancellation among other gb
parameters can remove all these obstructions.

**Trivial case.** If every `gb` parameter is zero, the Layer 2 gamma and its
Layer 3 evaluation vanish term-by-term. The zero map `f=0` gives
`delta f=0`, so the two structures coincide. The comparison script confirms
zero evaluated gamma terms and zero coboundary terms for this assignment.

**Conjecture.** In the formal model generated from the supplied exchange
relations and the declared basis, the deformation is a coboundary if and
only if all `4n` parameters vanish. Necessity follows from the identity
witnesses above; sufficiency follows from gamma being linear in gb and
choosing `f=0`. This extrapolates the witness pattern observed for n=1,2,3.

**Caveat.** This is a result about the formal coefficient expansion, not a
validated Lie-superalgebra deformation: as recorded in I02 and I05, odd gb
times odd kappa has the wrong parity for `[b,a]`, and nonzero gamma has
off-basis identity terms. The conjecture is conditional on resolving those
source-definition inconsistencies.
