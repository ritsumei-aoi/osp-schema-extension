#### Triviality search report

Added `src/analyze_C_triviality.py` to compare each evaluated Layer 3
bracket, symbolic Layer 2 gamma term, and Layer 4 coboundary expression.
The comparison uses the central identity `K`, which is recorded in
Schema 1 but excluded from the Lie-algebra basis. A coboundary computed
from \(\mathfrak g\)-valued brackets and an odd map \(f:\mathfrak g\to
\mathfrak g\) has no `K` output. Therefore any nonzero `K` coefficient
in \(\gamma\) is an immediate obstruction to \(\gamma=\delta f\).

**Specific cases.**

- For the zero assignment \(gb=0\), all gamma coefficients vanish.
  Taking \(f=0\) gives \(\delta f=0\), so this is a trivial case for
  C(2), C(3), and C(4).
- The Layer 3 `all_positive` profile is non-trivial for each rank. In
  C(2), it contains the four distinct central terms:
  `[E_eps1_del1_pm, E_2del1_p] -> +K`,
  `[E_eps1_del1_pp, E_2del1_m] -> -K`,
  `[E_eps1_del1_mm, E_2del1_p] -> +K`, and
  `[E_eps1_del1_mm, H_1] -> +K`.
  Each witnesses one independent gb parameter. The same four patterns
  recur for each bosonic mode in C(3) and C(4).

**General condition and evidence.** For every mode \(k\), four `K` rows
isolate the four parameters:

| Parameter | Generator pair yielding a `K` term | Coefficient |
|---|---|---:|
| `gb_a_1_p_b_{k}_p` | (`E_eps1_del{k}_pm`, `E_2del{k}_p`) | \(+1\) |
| `gb_a_1_p_b_{k}_m` | (`E_eps1_del{k}_pp`, `E_2del{k}_m`) | \(-1\) |
| `gb_a_1_m_b_{k}_p` | (`E_eps1_del{k}_mm`, `E_2del{k}_p`) | \(+1\) |
| `gb_a_1_m_b_{k}_m` | (`E_eps1_del{k}_mm`, `H_j`) | nonzero |

Here \(H_j=H_1\) for \(k=1\), otherwise \(H_j=H_{k+1}\). The last
coefficient is \(+1\) at \(k=1\), \(+1/2\) for interior modes, and
\(-1/2\) at a terminal mode in the generated ranks; it never vanishes.
The exact rational `K`-obstruction matrix has rank \(4n\) and nullity 0
for n=1,2,3. An additional in-memory rank-4 calculation gave rank 16/16.
Its rows isolate all parameters; the Layer 4 data contains no `K` outputs.

The resulting conjecture (and proof from the displayed witness rows for
the stated oscillator formulas) is: **the deformation is trivial if and
only if every `gb` parameter is zero.** Necessity follows because any
nonzero parameter leaves a nonzero `K` term that no \(\mathfrak g\)-valued
coboundary can produce; sufficiency follows by taking \(f=0\). The
central identity is not expressible as a linear combination of the
Schema 1 basis generators, so the obstruction cannot be absorbed into a
Cartan component. This conclusion uses the parity-0 `gb` correction
recorded in I05, which makes the exchange relation parity-homogeneous.
