### Response

Implemented `src/compare_C_triviality.py`. It constructs the exact rational
linear system comparing the Schema 2 gamma map (symbolic in `gb`) with the
image of the generic odd-map coboundary from Schema 4. Sparse elimination
produces necessary-and-sufficient conditions on the parameters and witnesses
for inconsistent profiles.

**Evidence from the three ranks.** The all-plus Layer 3 assignment is
non-trivial for every rank. In each evaluated file,
`(X,Y,Z) = (E_2del1_m, E_eps_del1_mp, K)` has `base_coeff = 0` and
`kappa_coeff = 1`. Layer 4 has no `K` output: `f` maps into the Layer 1 basis,
which excludes the central identity. Thus this coefficient cannot be
reproduced by any $\delta f$. Conversely, setting all `gb` values to zero
makes every evaluated `kappa_coeff` zero, and the zero map $f=0$ matches it;
this is a trivial case.

The symbolic comparison returned zero-dimensional trivial parameter spaces
for C(2), C(3), and C(4): respectively 0/4, 0/8, and 0/12 allowed independent
parameters. The `K`-component records provide an individual obstruction for
each parameter; the following pattern was present for every $j$ in all three
computed ranks:

| Parameter | Generator pair $(X,Y)$ | $K$ coefficient in $\gamma(X,Y)$ |
|---|---|---|
| `gb_a_1_p_b_{j}_p` | $(E_{2\delta_j}, E_{\varepsilon-\delta_j})$ | $-\mathrm{gb}_{a_1^+,b_j^+}$ |
| `gb_a_1_p_b_{j}_m` | $(E_{-2\delta_j}, E_{\varepsilon+\delta_j})$ | $+\mathrm{gb}_{a_1^+,b_j^-}$ |
| `gb_a_1_m_b_{j}_p` | $(E_{-\varepsilon-\delta_j}, E_{2\delta_j})$ | $+\mathrm{gb}_{a_1^-,b_j^+}$ |
| `gb_a_1_m_b_{j}_m` | $(E_{-2\delta_j}, E_{-\varepsilon+\delta_j})$ | $+\mathrm{gb}_{a_1^-,b_j^-}$ |

These isolated central coefficients cannot cancel against one another. Under
the convention adopted in I05 (the displayed exchange relation read literally,
with odd $\kappa$ factored to the left), the resulting necessary-and-sufficient
condition is therefore
$$
\mathrm{gb}_{a_1^\sigma,b_j^s}=0
\quad\text{for every }\sigma,s\in\{+,-\},\ 1\leq j\leq n.
$$
This is the general conjecture for all $n\geq1$: the zero deformation is
trivial, and every nonzero parameter profile is non-trivial. The universal
per-index obstruction pattern supplies the necessity argument; the choice
$f=0$ supplies sufficiency when all parameters vanish. The parity ambiguity in
the source exchange relation remains a stated assumption, so the conclusion
is conditional on that convention.
