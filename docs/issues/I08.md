## Triviality Search Report: C(n+1) = osp(2|2n)

### 1. Comparison Method

The analysis implemented in `src/C_triviality.py` sets up the linear system:

  γ(X,Y)[Z](gb) = (δf)(X,Y)[Z](φ)   for all (X,Y,Z)

where:
- γ(X,Y)[Z](gb) is the evaluated gamma (Layer 3, with specific gb values)
- (δf)(X,Y)[Z](φ) = sum_j φ_{i,j} * coboundary coefficients (Layer 4)

The system is solved over ℚ using Gaussian elimination. If it is consistent, the deformation is trivial; otherwise it is non-trivial.

### 2. Symbolic Analysis Results

For each gb parameter gb_l, we ask: is the corresponding bilinear form Γ_l
(where γ(gb) = Σ_l gb_l Γ_l) in the image of the coboundary operator δ?

**Results** (consistent across all n=1,2,3):

| n | rank(δ) | dim(φ) | Obstruction count | Triviality condition |
|---|---|---|---|---|
| 1 | 28 | 32 | 4 (= 4n) | All 4 gb = 0 |
| 2 | 168 | 176 | 8 (= 4n) | All 8 gb = 0 |
| 3 | 516 | 528 | 12 (= 4n) | All 12 gb = 0 |

**Key finding**: The obstruction parameters are precisely ALL 4n gb parameters:
  {gb_p_j_p, gb_p_j_m, gb_m_j_p, gb_m_j_m | j=1..n}

The null space dimension of δ equals 4n = dim(Im(γ)/Im(δ∘γ)), which is exactly the number of gb parameters. This means each gb parameter contributes an independent cohomology class in H²(g,g).

### 4. Specific Evidence for Non-Triviality

Sample inconsistent equation from the all-ones assignment (n=1):

  γ(E_eps1_del1_mm, E_eps1_del1_mm)[E_eps1_del1_mm] = -2

Coboundary at this triple:
  (δf)(E_eps1_del1_mm, E_eps1_del1_mm)[E_eps1_del1_mm]
  = -4 * φ_{H_1, E_eps1_del1_mm} + 2 * φ_{H_2, E_eps1_del1_mm}

This constraint: -4φ_{H_1} + 2φ_{H_2} = -2, i.e., 2φ_{H_1} - φ_{H_2} = 1.

However, combined with other constraints from other (X,Y,Z) triples, the system becomes overdetermined and has no solution. This is because the self-bracket [E_eps1_del1_mm, E_eps1_del1_mm] (which is a fermionic-fermionic bracket producing an even generator) contributes via γ to a cohomology class that is not accessible to any coboundary δf.

### 5. Mathematical Explanation of Discrepancies

The root cause of non-triviality:

**For odd-odd brackets involving the ε-sector**: The gamma 2-cocycle for the bracket of two odd generators (e.g., E_eps1_del{k}_{s1s2}) receives contributions from the deformation [b_j^s, a_1^sigma] = -gb * κ. These contributions structurally involve mixing the ε-sector (fermionic a_1^±) with the bosonic sector (b_j^±) in a way that cannot be "undone" by any odd linear map f on g.

Specifically: γ(E_eps1_del{k}_{s1s2}, E_eps1_del{l}_{t1t2}) involves Cartan generators H_j and even root vectors. The coboundary δf acting on such pairs can only reach generator Z if there is a non-trivial [X, f(Y)] or [Y, f(X)] or f([X,Y]) bracket that produces Z. But the ε-root generators and their brackets have a particular structure that leaves 4n independent directions unreachable by coboundaries.

**Topological interpretation**: The 4n-dimensional obstruction space corresponds to the 4n odd root generators {E_eps1_del{k}_{ss}} playing the role of "deformation directions" that are not inner automorphisms. This is consistent with the fact that in osp(2|2n), the fermionic generators are not in the adjoint image of the even generators.

### 6. General Conjecture

**Conjecture (Triviality of C(n+1) inhomogeneous deformations)**:

The inhomogeneous deformation of C(n+1) = osp(2|2n) defined by the 4n parameters gb_{sigma,j,s} (sigma ∈ {+,-}, j=1..n, s ∈ {+,-}) is trivial (i.e., equivalent to the undeformed algebra by an automorphism) **if and only if all gb parameters are zero**:

  γ(gb) is trivial ⟺ gb_{sigma,j,s} = 0 for all sigma, j, s.

This is supported by:
1. **Symbolic evidence**: For each of the 4n gb parameters, the corresponding Γ_l ∉ Im(δ), verified exactly over ℚ for n=1,2,3.
2. **Linear independence**: The 4n obstructions are linearly independent (each individual gb creates a distinct non-trivial class).
3. **Consistency with B(0,n)**: The analogous statement for B(0,n) = osp(1|2n) is that the 2n parameters gb_{a_0, b_j^±} each create non-trivial deformations (as established in Bakalov-Sullivan / Aoi 2026). The C(n+1) result doubles this to 4n parameters, consistent with the doubled fermionic sector.

**Corollary**: The space of non-trivial deformation classes for C(n+1) is 4n-dimensional, generated by the independent directions Γ_{gb_{sigma,j,s}}.

### 7. Additional Investigation

The analysis script also computes the null space dimension of δ, which equals 4n for all tested cases. This matches the dimension of the cohomology group H²_odd(g,g) relevant for odd deformations of g. The 4n-dimensional obstruction is thus the full H² group in this context.
