#### Implementation

**Script**: `src/C_triviality.py` — solves the linear system γ = δf over exact fractions for n=1,2,3.

**Auxiliary script**: `src/analyze_conditions.py` — finds unique (normalized) triviality conditions on gb.

**Method**: For each n, build the linear system:

$$M_\phi \cdot \vec{\phi} = \vec{\gamma}(gb)$$

where $M_\phi$ is the coboundary matrix (rows = (X,Y,Z) triples, columns = phi parameters) and $\vec{\gamma}(gb)$ is the evaluated gamma vector. Two analyses are performed:

1. **Numerical**: set all gb=1, solve $M_\phi \cdot \vec{\phi} = \vec{\gamma}(1)$ via Gaussian elimination. Check consistency.
2. **Symbolic**: treat gb as formal variables in the RHS. After Gaussian elimination on $[M_\phi \mid \Gamma_{gb}]$, zero-M rows give linear conditions on gb for consistency.

#### Root Cause Analysis

The inhomogeneous deformation is parametrized by modified bracket:

$$[b_k^s, a_1^\sigma]_\gamma = [b_k^s, a_1^\sigma]_0 + \kappa \cdot (-gb_{\sigma,k,s})$$

The coboundary operator δf cannot produce such a constant (central/scalar) shift in the bracket because:

1. δf is built from three terms involving the undeformed brackets [X, f(Y)], [Y, f(X)], f([X,Y]).
2. Each term is linear in the bracket (which maps into the Lie superalgebra) composed with f (which is a map into the Lie superalgebra). So δf always maps into the Lie superalgebra, and each component is a combination of structure constants times phi parameters.
3. The deformation γ introduces a **pure κ-shift** (a 2-cocycle contribution that does not arise as a coboundary). This is the content of a non-trivial H^1(g, g) class.

Concretely: the inconsistent equations come from (X,Y,Z) triples where γ(X,Y)_Z is non-zero but the corresponding row of the coboundary matrix is zero (no phi parameter can contribute). These correspond to pairs where the deformation adds to generator components that δf cannot reach.

#### Coboundary Rank Formula

The observed data confirms:

$$\text{rank}(M_\phi) = 2 \cdot \dim_{\bar{0}} \cdot \dim_{\bar{1}} - 4n$$

| n | $2 \cdot \dim_{\bar{0}} \cdot \dim_{\bar{1}}$ | rank(M) |
|---|-----------------------------------------------|---------|
| 1 | $2 \times 4 \times 4 = 32$ | 28 = 32 - 4 |
| 2 | $2 \times 11 \times 8 = 176$ | 168 = 176 - 8 |
| 3 | $2 \times 22 \times 12 = 528$ | 516 = 528 - 12 |

So $\dim(\ker \delta) = 4n$ for all n tested.

#### General Conjecture

**Conjecture**: For $C(n+1) = \mathrm{osp}(2|2n)$ with $n \geq 1$, the inhomogeneous deformation $\gamma_{gb}$ parametrized by the 4n constants $\{gb_{\sigma,k,s}\}$ is trivial (i.e., $\gamma_{gb} = \delta f$ for some odd linear map $f: \mathfrak{g} \to \mathfrak{g}$) **if and only if all gb parameters vanish**: $gb_{\sigma,k,s} = 0$ for all $\sigma, k, s$.

Equivalently: the cohomology class $[\gamma_{gb}] \in H^1(\mathfrak{g}, \mathfrak{g})$ is zero if and only if $\gamma_{gb} = 0$.

Corollary: Every non-zero inhomogeneous deformation of $C(n+1)$ is a genuinely non-trivial deformation — it cannot be "gauged away" by a reparametrization of the basis. The deformation space (dimension 4n) injects into the first cohomology $H^1(\mathfrak{g}, \mathfrak{g})$.

Supporting evidence:
- The 4n unique independent conditions each isolate a single gb parameter.
- No combination of gb parameters (other than all-zero) satisfies the system.
- The pattern holds for n=1,2,3 with no exceptions.
- The kernel dimension of δ equals 4n (= dim of deformation space), consistent with the deformation space being exactly the obstruction space.
