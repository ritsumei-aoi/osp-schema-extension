## Triviality Search Report

### 0. Summary (headline result, with its main caveat)
- Whether the deformation is "trivial" depends on **one modelling choice that the handover documents leave open**: whether the odd map `f` may have a component along the central constant `K` (= 1).
  - **(T1) f: g -> g (+) C K** (constants allowed on odd generators; this is what the oscillator redefinition `a -> a + kappa*(c.b)` produces): the deformation is trivial for **every** gb in C^{4n}, no condition.
  - **(T2) f: g -> g strictly** (as literally written in `C_coboundary_definition.md`), with gamma including its central `K` component: the deformation is trivial **iff gb = 0**.
  - **(T3) f: g -> g, K-component of gamma discarded** (gamma: g x g -> g as written in `C_inhomogeneous_definition.md` section 2): trivial for **every** gb.
- These are computed facts for n=1,2,3 (exact where stated, see Section 4); the general-n statements are conjectures supported by a structural argument (Section 5). Which of T1/T2/T3 the project intends is **not decided by the documents**; my choice and its reason are recorded in Section 6.

### 3. Discrepancies in the non-trivial (T2) case: which pairs, which gamma coefficients
For n=1, `all_plus` the inconsistent pairs are exactly the 20 ordered pairs with `gamma_K != 0` (one odd, one even generator; `[X,Y]` is odd and non-zero):
```
gamma_K(E_eps1_del1_pp, H_1) = 1     gamma_K(E_eps1_del1_pp, H_2) = -1/2    gamma_K(E_eps1_del1_pp, E_2del1_m) = 1/2
gamma_K(E_eps1_del1_pm, H_2) = 1/2   gamma_K(E_eps1_del1_pm, E_2del1_p) = -1/2
gamma_K(E_eps1_del1_mp, H_2) = -1/2  gamma_K(E_eps1_del1_mp, E_2del1_m) = 1/2
gamma_K(E_eps1_del1_mm, H_1) = -1    gamma_K(E_eps1_del1_mm, H_2) = 1/2     gamma_K(E_eps1_del1_mm, E_2del1_p) = -1/2
gamma_K(H_1, E_eps1_del1_pp) = -1    gamma_K(H_1, E_eps1_del1_mm) = 1       (+ the graded-skew partners of all of the above, e.g. gamma_K(E_2del1_p, E_eps1_del1_pm) = 1/2, gamma_K(H_2, E_eps1_del1_pp) = 1/2, ...)
```
(Values for `all_plus`; each is a single gb parameter times a rational: e.g. `gamma_K(E_eps1_del1_pp,H_1) = +gb_{a_1^+,b_1^+}`, `gamma_K(E_eps1_del1_pp,E_2del1_m) = +1/2 gb_{a_1^+,b_1^-}`; the full table is in `data/C_1_gamma.json`, entries with `"Z": "K"`.) The g-valued components of gamma match delta f for every pair.

**Mathematical reason.** The deformed relation `[b,a] = -gb*kappa` can be removed to first order by the redefinition `a^sigma -> a^sigma + kappa*l^sigma`, `l^sigma = sum c b`. Applied to a generator `X = a^sigma b^s` it gives `X + kappa*l^sigma b^s`, and `l^sigma b^s` is a *non-Weyl-symmetrized* quadratic in b: `b^- b^+ = (b^+ b^- + 1/2) + 1/2`. So `f(X)` = (element of g) + (1/2)(c) K. Example n=1: `f(E_eps1_del1_pp) = c_{p,1,m}( -H_2 + (1/2)K ) + 2 c_{p,1,p} E_2del1_p`. Because K is central, `[X,f(Y)]` ignores the K part, so K enters (delta f) only through `-f([X,Y])`: `(delta f)_K(X,Y) = -k([X,Y])`, with `k(Z)` the K-coefficient of `f(Z)` for odd Z. This equals `gamma_K(X,Y)` exactly (verified for all pairs, Part A). Therefore:
- if f is allowed a K-component `k != 0` (T1), the central part of gamma is cancelled by `-k([.,.])`;
- if f: g -> g (T2), `k = 0`, so `(delta f)_K = 0` while `gamma_K = -k_gb([.,.])` where `k_gb(Z)` is `+-1/2` times a single gb: it vanishes only if all `k_gb(Z) = 0` on `[g,g]_odd = g_odd` (since `[g_even, g_odd] = g_odd` for this algebra), i.e. only for gb = 0.

### 4. Active investigation (Part B): unrestricted search over all odd f
Unknowns: every odd `phi_ij` (2*E*O: 32, 176, 528 for n=1,2,3, plus K-constants on odd generators in T1), equations: `(delta f)(X,Y)_Z = gamma(gb)(X,Y)_Z` for all N^3 triples (and the K row), gb free (4n unknowns). The solution set projected to gb is a linear subspace (gamma and delta f are both linear). Result (SVD null space, tolerance 1e-8):

```
n=1: strict (T2)=0/4   gonly (T3)=4/4   const (T1)=4/4    exact rank of gb -> gamma_K: 4/4
n=2: strict (T2)=0/8   gonly (T3)=8/8   const (T1)=8/8    exact rank of gb -> gamma_K: 8/8

```
- "dim of trivial gb-subspace" = number of linearly independent gb directions for which gamma is a coboundary.
- The strict result 0 is **exact**, not only numerical: the K-row alone forces `gamma_K(gb) = 0`, and the exact (Fraction) rank of `gb -> gamma_K` is 4n, i.e. the kernel is `{0}`.
- The T1/T3 full-dimension result is **exact** as well: the explicit f_c of Layer 4 satisfies `delta f_c = gamma(gb)` identically (exact rational arithmetic, all N^3 triples, tested), so the numerical SVD result is only a cross-check.
- Because the trivial set is a linear subspace, "up to scalar" in the definition plays no role beyond gb = 0 (`lambda=0` case).

### 5. General conjecture
Let `g = C(n+1) = osp(2|2n)`, `gb = (gb_{sigma,j,s})` in `C^{4n}` and `gamma(gb)` the first-order deformation `[b_j^s, a_1^sigma] = -gb_{sigma,j,s} kappa`.
1. **(T1/T3) Conjecture A:** for every n >= 1 and **every** gb in `C^{4n}`, `gamma(gb)` is a coboundary: `gamma(gb) = delta f_c` with `c_{sigma,j,m} = gb_{sigma,j,p}`, `c_{sigma,j,p} = -gb_{sigma,j,m}` (proved by the oscillator-redefinition argument for general n: the shift is an automorphism-type change of the generating oscillators, it commutes with the construction of g, and it only fails to land in g by the central constant; verified exactly for n=1,2,3). In T3 (K-component ignored) there is **no condition** on gb; in T1 the same holds with f taking values in `g (+) C K`.
2. **(T2) Conjecture B:** if f must take values in g (no central component) and the central part of gamma is kept, then the deformation is trivial **iff gb = 0** (necessary and sufficient). Proof sketch for general n: `(delta f)_K = 0` for f: g -> g, and `gamma_K(gb)(X,Y) = -k_gb([X,Y])` with `k_gb(E_{sigma s,j}) = +-(1/2) gb_{sigma,j,-s}` (up to the sign pattern stored in `C_{n}_coboundary.json`), which vanishes identically iff all gb vanish. Exact for n=1,2,3.
So there is **no non-trivial sub-condition** such as "sum of gb = 0" or sign constraints: signs of gb (all profiles tested: all_plus, alternating, fermion_sign, boson_sign) play no role; the trivial set is always either everything (T1/T3) or {0} (T2).

### 6. Decisions, ambiguities and assumptions (No-Gate)
- **Ambiguity 1 (central K):** `C_inhomogeneous_definition.md` says gamma: g x g -> g, but the actual first-order bracket produces an additional constant (central) term `kappa*K` from Weyl re-ordering. I stored it explicitly (Schema 2, `Z="K"`) rather than dropping it (reason: dropping it would break the cocycle identity check, which holds only with K included for the generated data). Options: T1/T2/T3 above. **Adopted reading for the headline conclusion: T1 (f: g -> g (+) C K) with T3 as its g-valued projection**, because K = 1 is identified with the scalar in this project, the central element kappa of the oscillator algebra `A = V + CK + C kappa` is part of the framework, and "deformation trivial" should mean "removable by changing the generators", which is exactly the oscillator redefinition. T2 is reported in full so that a reader who insists on f: g -> g literally can use it. This is a modelling decision I could not confirm with a human.
- **Ambiguity 2 (parity of gb):** treated gb as ordinary scalars (see I05).
- **Ambiguity 3 (K normalization):** K identified with the scalar 1; a different normalization only rescales k_gb and does not change the conclusions.
- Limitation: general-n statements are conjectures (verified for n=1,2,3 only); the first-order (in kappa) deformation theory is used throughout (kappa^2 = 0).
- Not claimed: that g has no other cohomologically non-trivial deformations; only the 4n-parameter gb family was analyzed.
