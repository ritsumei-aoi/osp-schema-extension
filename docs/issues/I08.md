### Triviality Search Report

**Setup and method** (`src/C_triviality.py`, tests in `tests/test_C_triviality.py`)
- γ(gb) is linear in gb (Schema 2 / Layer 2–3). δf is linear in the parameters φ of an odd map f (Schema 4 / Layer 4).
- γ is trivial iff ∃ φ with δf(φ) = γ(gb). "Up to scalar" changes nothing: λδf = δ(λf). With λ = 0 the condition is γ = 0, which is also gb = 0.
- Writing A φ = B gb (rows = (X,Y,Z), X ≤ Y), the trivial set is T = {gb : B gb ∈ col A}. Computed exactly (sympy nullspace) for n=1 and by SVD (tolerance 1e-9) for n=2,3.
- Equations: 144 (n=1), 1620 (n=2), 7726 (n=3). Unknowns: 32, 176, 528 φ and 4, 8, 12 gb.

**Sanity checks** (all pass)
- ker A has dimension 4, 8, 12 for n=1,2,3, and rank A = 28, 168, 516. The kernel is the odd inner derivations ad(E_odd), whose dimension is 4n, as expected for a centreless algebra. So the machinery is consistent with the algebra.
- Synthetic test: if B = A·R (every gb trivial by construction), T = the full gb space (dimension 4 for n=1 and 8 for n=2). So the projection code can detect triviality.

**2. Discrepancies for the non-trivial cases**

Concrete γ entries (from `data/C_1_gamma.json`, n=1) that cannot be matched by any δf:
- [E_eps1_del1_pp, H_1] has γ = gb_p_1_p·H_1 + gb_p_1_m·E_2del1_p + **gb_p_1_p·K**.
- [E_eps1_del1_pm, E_2del1_p] has γ = −2·gb_p_1_p·H_2 − **gb_p_1_p·K**.
- [E_eps1_del1_mp, E_2del1_m] has γ = −2·gb_m_1_m·H_2 + **gb_m_1_m·K**.
- [E_eps1_del1_mm, E_2del1_p] has γ = −2·gb_m_1_p·H_2 − **gb_m_1_p·K**.

Root cause, part (a), the central K-component:
- The boson-fermion relation [b, a] = −gb·κ produces scalar constants when normal-ordered. In g these are identified with K (the scalar 1). Every γ with a constant term therefore has a K-component.
- Schema 1 brackets of basis elements have no K component (checked: the Schema 1 table has no K). Every δf entry is a linear combination of basis elements, so δf has no K component (`label_errors = 0` in `consistency_check`, and K is not a basis label).
- So any trivial γ must have zero K-component. For n=1 this forces each of gb_p_1_p, gb_p_1_m, gb_m_1_m, gb_m_1_p to vanish directly, because each appears alone in one K entry above.
- The K-constraint matrix has full rank 4n: 4 (n=1), 8 (n=2), 12 (n=3). So the K-components alone force gb = 0 for every n tested.

Root cause, part (b), the non-K part:
- Dropping the K-rows still gives T = {0} for n=1,2,3. So the obstruction is not only the central term.
- Dimension count: Im δ has codimension (equations − rank A) = 116 (n=1), 1452 (n=2), 7210 (n=3) in the space of coboundary values. The non-K part of γ(gb) lies outside Im δ for all gb ≠ 0.
- The discrepancy rows are spread over all generator types: Cartan, E_2del, E_del-pairs, and the odd ε-generators, for pairs (X,Y) of every type. For instance at n=1 the unmatched rows include the odd×odd pairs (20), the odd×Cartan pairs (22) and the E_2del×odd pairs (16). The least-squares residual is not unique, so these counts show where the residual falls, not a canonical list of bad coefficients.

**3. General conjecture**

- **Conjecture.** For C(n+1) = osp(2|2n), the inhomogeneous deformation γ(gb) is trivial (as a coboundary of an odd linear map f: g → g, up to scalar) **if and only if gb = 0**, i.e. all 4n parameters gb_{σ,j,s} vanish.
- Sufficiency: gb = 0 gives γ = 0 = δ(0).
- Necessity, sketch: a trivial γ(gb) must have zero K-component. The K-component is a linear map gb ↦ K-part with full rank 4n (verified for n=1,2,3), so gb = 0. The non-K part gives the same answer (T = {0} for n = 1, 2, 3 even without K-rows).
- Status of the proof: the K-argument is exact for n=1 (explicit entries, rational coefficients). For n=2,3 it rests on matrix ranks of float matrices with small rational entries, which are reliable but not exact. The conjecture is therefore verified computationally for n=1,2,3, not proved for general n.

**4. Assumptions and ambiguities (recorded)**
- **f: g → g** (as in `docs/math/C_coboundary_definition.md`). The K-obstruction depends on this. If f were allowed to map into g ⊕ K, the K-rows could in principle be matched, and the conclusion would need re-checking. I did not explore that case.
- "Up to scalar" is read as λγ = δf. Since λ can be absorbed into f, and λ = 0 gives γ = 0, the conclusion is the same under either reading.
- The Cn1 definition gives E_{2δ_n} with a ½ factor, and I used the uniform (b_k^±)² form (I03). The rescaling does not change the triviality result, because it only rescales one basis element and so one column of A.
- Odd inner derivations: their dimension 4n is the kernel of δ on maps, so the trivial set T is well defined on gb (it is not affected by the choice of f within the kernel).
