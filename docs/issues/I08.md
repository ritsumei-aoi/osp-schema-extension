**Concrete cases**

- **Trivial formal specialization:** Set every gb parameter to zero. This is
  parity-homogeneous, all gamma corrections vanish, and `f=0` gives
  $\delta f=0$. The evaluator confirms the zero assignment has no nonzero
  `kappa_coeff`.
- **Non-trivial uniform `+1` specializations:** Layer 4 has no `K` output,
  since $f$ maps into the Schema 1 Lie basis and `K=1` is excluded from it.
  Layer 3 has nonzero scalar corrections, so these cannot equal any
  $\delta f$. Concrete witnesses are:

| Algebra | Pair $(X,Y)$ | Output | `kappa_coeff` at all `gb=+1` |
|---|---|---|---:|
| C(2) | (`H_1`, `E_eps1_del1_pm`) | `K` | 1 |
| C(3) | (`H_1`, `E_eps1_del1_pm`) | `K` | 1 |
| C(4) | (`H_1`, `E_eps1_del1_pm`) | `K` | 1 |

Further nonzero examples include C(3)/C(4)
`(H_1, E_eps1_del2_pp) -> K` with coefficient `1/2`.

For arbitrary gb, the matrix taking gb values to all gamma coefficients with
`Z=K` has exact ranks 4, 8, and 12 for C(2), C(3), and C(4), respectively,
equal to the parameter counts `4*n`. Its kernel is zero in all tested ranks.
Because $\delta f$ has no `K` component, any trivial deformation must lie in
this kernel; for these ranks this forces every gb parameter to vanish.
Conversely, all-zero gb is trivial via $f=0$. Thus the data support the
necessary-and-sufficient condition **all gb parameters are zero** for
`n=1,2,3`.

**General conjecture and limitations**

Conjecture: for every bosonic rank `n >= 1`, the scalar-identity projection
of the formal gamma map has full column rank `4*n`; hence the deformation is
trivial exactly when all gb parameters vanish. The observed full ranks at
three ranks support, but do not prove, this general statement.

This conclusion uses literal equality in the Lie basis: `K` is a recorded
scalar identity but is not in `g`, and the Layer 4 map has codomain `g`.
The phrase “up to scalar” in the coboundary reference could alternatively be
read as equality modulo scalar identity; if that was intended, the `K`
obstruction would need to be removed and the remaining equations re-solved.
No such quotient is specified, so it was not assumed.

Finally, this is a formal coefficient result rather than a fully validated
Lie-superalgebra deformation: the source assigns parity 1 to both `gb` and
`kappa`, making the displayed even-boson/odd-fermion commutator relation
parity-inhomogeneous. Nonzero real sign assignments are formal specializations
of those odd parameters. The zero case is parity-homogeneous. The full-rank
result is therefore reported with the source convention and anomaly stated,
not as a resolution of it.
