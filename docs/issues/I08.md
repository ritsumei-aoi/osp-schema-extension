### 2. Rigorous Analysis of Discrepancies

**Key finding**: The inconsistency arises because the image of the coboundary operator Im(δ) does not contain the deformation vector γ(gb=1).

**Direct witness triples** (triples (X,Y,Z) where the coboundary has zero contribution but γ is non-zero):

| gb parameter | Witness triple | γ coefficient |
|---|---|---|
| gb_a1p_b1m | (E_eps_del1_pm, H_1, H_2) | -2 · gb_a1p_b1m |

For this triple: `(δf)(E_eps_del1_pm, H_1)[H_2] = 0` for ALL f (verified by computing the coboundary data — no phi parameter contributes to this component), while `γ(E_eps_del1_pm, H_1)[H_2] = -2 · gb_a1p_b1m` is non-zero when gb_a1p_b1m ≠ 0.

**Mathematical explanation**: When computing [E_eps_del1_pm, H_1]_deformed using the oscillator algebra (E_eps_del1_pm = a_1^+ b_1^-, H_1 = a_1^+ a_1^- + b_1^+ b_1^-), the deformed commutation relation `[b_1^-, a_1^+] = -gb_a1p_b1m · κ` fires at two points: once in the XY term (b_1^- from X passes a_1^+ from H_1's a_1^+ a_1^- part, yielding a κ term -gb_a1p_b1m · a_1^+ a_1^-) and once in the YX term (b_1^- from H_1's b_1^+ b_1^- part passes a_1^+ from X, yielding +gb_a1p_b1m · b_1^+ b_1^-). The combined κ contribution is gb_a1p_b1m · (-a_1^+ a_1^- + b_1^+ b_1^-). When expressed in the generator basis (non-scalar part), this is -H_1 - 2·H_2, giving γ(E_eps_del1_pm, H_1)[H_2] = -2 · gb_a1p_b1m. The coboundary (δf)(E_eps_del1_pm, H_1) has no H_2 component for any f (confirmed by inspection of the coboundary data), making this a valid obstruction witness.

**For the remaining gb parameters** (gb_a1p_b1p, gb_a1m_b{k}s for all k,s, gb_a1p_b{k>1}s): each individual non-zero value produces inconsistencies in different triples involving mixed root generators, confirming that each is independently constrained to be zero (see individual gb tests below).

**Individual gb tests** (setting one gb=1, rest=0): ALL yield non-trivial deformations for n=1,2,3.

Key witness triples per parameter (representative sample):
- `gb_a1m_b1m = 0`: witnessed by `(E_eps_del1_mm, E_2del1_m, E_2del1_m)`
- `gb_a1m_b1p = 0`: witnessed by `(E_eps_del1_mm, E_2del1_p, H_2)`
- `gb_a1p_b{k}m = 0` (k>1): witnessed by `(E_eps_del1_pm, E_del1_del{k}_mm, E_2del1_m)`
- `gb_a1p_b{k}p = 0` (k>1): witnessed by `(E_eps_del1_pm, E_del1_del{k}_mp, E_2del1_m)`

### 3. General Conjecture

**Conjecture** (supported by computational evidence for n=1,2,3):

> The inhomogeneous deformation of $C(n+1) = \mathfrak{osp}(2|2n)$ with deformation parameters $\mathrm{gb}_{\sigma,j,s}$ is trivial (i.e., a coboundary $\gamma = \delta f$ for some odd linear map $f: \mathfrak{g} \to \mathfrak{g}$) **if and only if all $4n$ deformation parameters are zero**:
> $$\mathrm{gb}_{\sigma,j,s} = 0 \quad \text{for all } \sigma \in \{+,-\},\, j = 1,\ldots,n,\, s \in \{+,-\}.$$

**Evidence**:
1. **n=1 (C(2))**: Full Gaussian elimination of the 213-equation, 32-phi-parameter system confirms that the solvability conditions require ALL 4 gb parameters = 0. This is verified by row-reducing [Cob | Gam] and finding 4 independent conditions on gb, one for each parameter.
2. **n=2,3**: Individual gb tests show each of the 8 (resp. 12) parameters individually forces inconsistency. By linearity, any non-zero linear combination of gb parameters yields a non-trivial deformation.
3. **Structural argument**: The witnesses consistently involve pairs (X, Y) where an oscillator from X must pass an oscillator of Y in the deformed algebra, triggering the relation `[b_j^s, a_1^σ] = -gb · κ`. The resulting κ term, when expressed in the generator basis, produces components (such as H_j or E_{±2δ_k}) that cannot be matched by the coboundary operator δf at those positions. For the main witness (E_eps_del1_pm, H_1, H_2), the H_2 component arises from the non-scalar content of the oscillator element -a_1^+a_1^- + b_1^+b_1^- (expressible as -H_1 - 2·H_2 in the generator basis). For witnesses involving purely bosonic generators (e.g., E_2del1_m), the obstruction arises from the κ term proportional to (b_1^-)^2 or similar bosonic monomials whose basis expression has no coboundary preimage.

**Comparison with B(0,n)**: According to `docs/math/B0n_definition.md`, B(0,n) = osp(1|2n) has 2n deformation parameters gb_{a_0, b_j^s} (j=1..n, s=±). C(n+1) has 4n parameters. Both deformation spaces are strictly parametric (no single-parameter reduction for general n). The present data does not establish detailed triviality conditions for B(0,n); that analysis is outside the scope of this computational study.
