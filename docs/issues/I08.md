**Investigation:** Added `src/C_triviality_search.py`. It expresses the
Schema 4 coboundary as a rational linear map from the $\phi$ variables,

Layer 3 constant and $\kappa$ parts against Layers 1–2, and reports the

**Evidence and comparison:**

- With every `gb` set to zero, Layer 3 reduces exactly to Layer 1 and
  $\gamma=0$. Taking $f=0$ gives $\delta f=0$, so this case is trivial for
  n=1, 2, and 3.
- With the persisted all-positive profile, the deformation is
  non-trivial at all three ranks. For example, Layer 2 gives
  $\gamma(E_{\varepsilon-\delta_1}, E_{2\delta_1})$ a term
  $-\mathrm{gb}_{a_1^+,b_1^+}K$; Layer 3 evaluates it to $-K\kappa$.
  Layer 4 has no `K` output at all: $\delta f$ is valued in the listed
  Lie-algebra basis, where `K=1` is explicitly not an independent basis
  element. Thus no choice of $\phi$ can match this component.
- The same unique scalar witness occurs for each parameter at each
  tested rank. For every k:

  | Parameter | Pair and output in Layer 2 |
  |---|---|
  | `gb_a1_p_b{k}_p` | `(E_eps1_del{k}_pm, E_2del{k}_p) -> K`, coefficient `-1` |
  | `gb_a1_p_b{k}_m` | `(E_eps1_del{k}_pp, E_2del{k}_m) -> K`, coefficient `+1` |
  | `gb_a1_m_b{k}_p` | `(E_eps1_del{k}_mm, E_2del{k}_p) -> K`, coefficient `-1` |
  | `gb_a1_m_b{k}_m` | `(E_eps1_del{k}_mp, E_2del{k}_m) -> K`, coefficient `+1` |

  Each row is the only parameter contribution to its displayed `K`
  component. These obstructions force each corresponding `gb` to zero;
  they cannot cancel against another parameter.

The exact-image computation found 4, 8, and 12 independent conditions
for n=1,2,3, respectively, each condition being one `gb=0` equation.
The coboundary map ranks were 28/32, 168/176, and 516/528; the all-positive
residuals had 47, 201, and 441 nonzero entries. The displayed scalar
obstructions alone prove non-membership in the coboundary image.

**Root cause and conjecture:** Under the documented normalization,
inhomogeneous mixed-oscillator relations create scalar-identity (`K`)
terms in $\gamma$, while the odd coboundary $\delta f$ has outputs only
in the noncentral C(n+1) basis. The conjectured necessary and sufficient
condition for triviality is therefore that all $4n$ `gb` parameters
vanish. Necessity is witnessed locally at each bosonic index by the
four pairs above; sufficiency follows because the deformation vanishes
when all parameters are zero. This is supported computationally for
n=1,2,3 and the local witness pattern extends to arbitrary n under the
stated oscillator relations and the convention `K=1` excluded from the
Lie-algebra basis.
