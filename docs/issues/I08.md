### 0. What "trivial" means here (and the ambiguity)
`C_coboundary_definition.md`: γ is trivial iff γ = δf for an odd f: g → g, "up to scalar". Layer 2 showed γ takes values in
g ⊕ ℂK (K = 1 central). So I tested three readings:

| reading | f maps into | K components compared? |
|---|---|---|
| **strict-g** | g | yes |
| **mod-K** ("up to scalar", the documented definition as I read it) | g | no |
| **strict-gK** | g ⊕ ℂK | yes |

*Adopted reading*: **mod-K** — the definition explicitly says "up to scalar", and κ·K is central in L, so it cannot change any bracket.
The other two readings are reported too, because they lead to different answers.

### 2. Discrepancies (the strict-g reading) and their root cause
Only the strict-g reading gives non-trivial cases, and **every** discrepancy is a K component. For f: g → g, δf never has a K component
(Schema 1 brackets contain no K), but γ does. Exact list for n=1, all_plus (20 entries, (X, Y, γ_K)):
```
(E_eps1_del1_pp, H_1, 1)  (E_eps1_del1_pp, H_2, -1/2)  (E_eps1_del1_pp, E_2del1_m, 1/2)
(E_eps1_del1_pm, H_2, 1/2)  (E_eps1_del1_pm, E_2del1_p, -1/2)  (E_eps1_del1_mp, H_2, -1/2)  (E_eps1_del1_mp, E_2del1_m, 1/2)
(E_eps1_del1_mm, H_1, -1)  (E_eps1_del1_mm, H_2, 1/2)  (E_eps1_del1_mm, E_2del1_p, -1/2)  + the 10 reversed pairs (graded-antisymmetric)
```
The g-components of all these pairs agree exactly; only the scalar part differs. n=2: 84 entries, n=3: 180 entries, always (odd, even) pairs.

**Mathematical reason.** The deformation contracts a fermion with a boson; the remaining bosonic bilinear is not symmetrized,
e.g. in [a⁺b⁺, a⁺a⁻ + b⁺b⁻] the a⁺–b⁺ contraction leaves b⁺b⁻ = ½{b⁺,b⁻} − ½, so γ(E_pp, H_1) = gb_p_1_p (H_1 + K).
These scalars are exactly a coboundary of the trivial module: verified **exactly and symbolically in gb** for n=1,2,3 (part D, 0 failures):

  γ_K(X,Y) = −φ_K([X,Y]),  φ_K(E_eps1_del{k}_{σs}) = ½ gb_{σ,k,s},  φ_K = 0 on g_even,

i.e. the central part of f_gb. Since K = 1 is central, it can only be absorbed by an f with a K component (strict-gK) or ignored (mod-K).
With f restricted to g it cannot be absorbed, hence "non-trivial" in strict-g for every gb ≠ 0 (rigorous: each γ_K entry involves a single gb, and all 4n gb appear in γ_K, so γ_K ≠ 0 ⇔ gb ≠ 0).

### 3. General statement (conjecture → with a proof sketch valid for all n)
**Claim.** For C(n+1) = osp(2|2n) with deformation [b_j^s, a_1^σ] = −gb_{σ,j,s} κ, the deformation γ_gb is trivial
(up to scalar, the documented definition) **for every gb ∈ ℂ^{4n}**; there is no condition on the gb parameters. Explicitly
γ_gb = δf_gb, f_gb = −F, where F(X) is the κ-part of X(a′,b) − X(a,b) under the odd fermion shift

  a′^σ = a^σ + κ Σ_j ( gb_{σ,j,−} b_j⁺ − gb_{σ,j,+} b_j⁻ ).

The trivializing map is unique up to inner odd derivations: {f} = f_gb + ad(g_odd) (dim ker δ = 4n observed for n=1,2,3).

*Why for all n:* the shift satisfies [b_j^s, a′^σ] = 0, {a′⁻, a′⁺} = 1, (a′^±)² = 0 for every n (I07 hand computation), so the
generators expressed in (a′, b) obey the undeformed brackets; this gives γ = −δF directly (I07 sign derivation). The data for n=1,2,3 confirm it.

**Under the other readings:** strict-gK — trivial for all gb (same f_gb including its K part ½gb); strict-g — trivial **iff gb = 0**,
the obstruction being exactly the scalar cochain φ_K∘[ , ] above.

**Necessary and sufficient condition on gb (adopted reading): none — every gb matrix gives a trivial deformation.**

Caveats: (i) the conclusion uses my realization conventions (I01: symmetrized Cartans, ½(b^±)²); a different normalization only rescales basis vectors and does not change triviality. (ii) gb treated as commuting scalars (I05 decision); if gb were genuinely Grassmann-odd the relation [b,a] = −gb κ would not be parity-consistent. (iii) The numerical rank computations (float SVD) are backed by exact Fraction checks of the explicit solution, so "trivial" verdicts are exact; the "non-trivial" strict-g verdicts follow from the exact K-component argument above.
