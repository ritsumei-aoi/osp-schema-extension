## Triviality Search Report — inhomogeneous deformation of C(n+1) = osp(2|2n)

### 0. Summary
- **Result.** For n = 1, 2, 3 and **every** gb ∈ ℚ^{4n}, the deformation γ is a coboundary:
  γ = δf for an odd map f. This was shown for all 4n unit gb vectors (then by linearity for all gb)
  and checked directly on the 8 non-zero sign profiles of Layer 3. It holds "up to scalar" (the
  definition in `C_coboundary_definition.md`). It also holds **exactly** if f may carry a scalar
  part (f: g → g ⊕ ℂK).
- **Only discrepancy.** If f must map strictly g → g *and* the central (K) component of γ must
  also match, the deformation is trivial **iff gb = 0**. All discrepancies in that reading are in
  the K-component, and they come from normal-ordering constants (§3).
- **Conjecture (proof sketch for all n in §4; computation for n ≤ 3).** For every n ≥ 1, the
  inhomogeneous deformation of C(n+1) is trivial for all gb. There is no condition on the gb
  matrix. An explicit trivializing map is f(X) = κ-coefficient of X(a) − X(a − κλ), where
  λ^σ = Σ_j (gb_{σ,j,+} b_j^- − gb_{σ,j,−} b_j^+). Structurally, H²_odd(g; g) = 0 for n = 1, 2, 3.

### 1. Method (Requirements 1 and 4)
- `src/C_triviality.py` loads three inputs:
  - Layer 3 (`C_{n}_evaluated.json`, the gb profiles);
  - Layer 2 (symbolic γ, giving the 4n unit-gb targets);
  - Layer 4 (`C_{n}_coboundary.json`, δf as linear forms in φ, ψ).

  It solves δf = γ for all targets at once with an **exact sparse rational eliminator** (no
  floating point). It uses the equations (X ≤ Y, W); by graded antisymmetry these determine all
  ordered pairs. Three readings:
  | reading | components compared | unknowns |
  |---|---|---|
  | `mod_K` (doc's "up to scalar") | W ∈ g | φ (f: g→g) |
  | `exact` | W ∈ g ⊕ ℂK | φ and ψ (f: g → g ⊕ ℂK) |
  | `strict` | W ∈ g ⊕ ℂK | φ only |

  For every solvable target, the particular solution is substituted back into Layer 4. The
  residual γ − δf is then computed over **all ordered pairs**, and the script asserts it is 0.
- Analytic candidate f (oscillator shift, §4), compared against γ exactly.
- `src/C_cohomology.py`: dimension of the odd 2-cocycle space Z²_odd (from the κ-part of super
  Jacobi) vs. B²_odd = rank δ.
- `src/C_triviality_report.py` prints the evidence below. Output data: `data/C_{n}_triviality.json`.
- Controls:
  - Perturbing one γ entry makes the system inconsistent, so the solver is not vacuous.
  - δ(ad_Z) = 0 for odd Z, and a wrong-sign map is not annihilated (I07).

### 3. Discrepancies and their mathematical cause (Requirement 2)
In the strict reading, the inconsistent equations are **exclusively K-components**:
```
n=1: inconsistent components {('K',)}; #inconsistent equations {'all_plus': 10, 'unit_p_1_p': 3, 'unit:gb_m_1_m': 3}
n=2: inconsistent components {('K',)}; #inconsistent equations {'all_plus': 42, 'unit_p_1_p': 5, 'unit:gb_m_1_m': 5}
n=3: inconsistent components {('K',)}; #inconsistent equations {'all_plus': 90, 'unit_p_1_p': 7, 'unit:gb_m_1_m': 7}
n=1 all_plus examples (X, Y, Z, γ): (E_pp, H_1, K, 1), (E_pp, H_2, K, −1/2), (E_pp, E_2del1_m, K, 1),
                                   (E_pm, H_2, K, 1/2), (E_pm, E_2del1_p, K, −1), (E_mp, H_2, K, −1/2)
```
Symbolically (Layer 2), examples are γ^K(E_pp, H_1) = gb_p_1_p, γ^K(E_pp, H_2) = −½ gb_p_1_p,
γ^K(E_pp, E_2del1_m) = gb_p_1_m and γ^K(E_pm, E_2del1_p) = −gb_p_1_p. In total 20/84/180 pairs
carry a K-part, and every gb appears.

*Why δf cannot match these when f: g → g.* The undeformed bracket has no K-component (I03: the
Cartan basis absorbs all constants). So every term of
δf(X,Y) = ±[X,f(Y)]_0 ± [Y,f(X)]_0 − f([X,Y]_0) lies in g. The K-row of δ is therefore
identically zero, and any γ^K ≠ 0 is an inconsistent equation.

*Where γ^K comes from.* γ is obtained by moving κ to the left and normal ordering. The
contractions produce terms like κ b_k^- b_k^+ = κ(b_k^+b_k^- + 1) or κ a^-a^+ = κ(1 − a^+a^-), whose
constants are not part of any basis element. Example: in [E_2del1_p, E_pm] = [b^+b^+, a^+b^-], the
deformed contraction leaves κ·gb_p_1_p times a b^-b^+-type product, which normal-orders to
κ(2 gb_p_1_p H_2 + gb_p_1_p K).

*Why this is not a genuine obstruction.* In the exact reading, the K-equations are solved by
ψ(E_{σ t, k}) = ½ gb_{σ,k,t}, i.e. γ^K(X,Y) = −ψ([X,Y]_0).
- So γ^K is the coboundary of a linear functional (a trivial central-extension cocycle). It is
  removed by shifting the odd basis elements by constants, E ↦ E − κψ(E)K.
- g is perfect (every odd basis element is a bracket), so γ^K fixes ψ on g_1 uniquely, and ψ = 0
  forces gb = 0. Hence "strict-trivial iff gb = 0".
- This is an artefact of conventions (the choice K = 1 and the constants in H_{n+1}), not a
  property of the deformation of g. The doc's "up to scalar" clause excludes it.

### 4. General conjecture (Requirement 3), with a proof sketch valid for all n
**Conjecture / Proposition.** For every n ≥ 1 and every gb matrix (2 × 2n, arbitrary entries), the
inhomogeneous deformation [X,Y]_γ = [X,Y]_0 + κγ(X,Y) of C(n+1) is trivial: γ = δf with
f: g → g ⊕ ℂK odd, and modulo scalars f: g → g. *Necessary and sufficient condition on gb: none.*
(Strict variant: f: g → g with exact equality including the K-part ⇔ gb = 0.)

*Proof sketch (all n).* Put a'^σ = a^σ − κλ^σ with λ^σ = Σ_j (gb_{σ,j,+} b_j^- − gb_{σ,j,−} b_j^+).
1. [b_j^+, a'^σ] = −gb_{σ,j,+}κ − κ[b_j^+, λ^σ] = −gb_{σ,j,+}κ + gb_{σ,j,+}κ = 0, and likewise for b_j^-.
2. {a'^σ, a'^τ} = {a^σ, a^τ} − κ([λ^τ, a^σ] + [λ^σ, a^τ]) = {a^σ, a^τ}, because [λ, a] ∈ ℂκ and κ² = 0.
3. So (a', b) satisfy the **undeformed** CAR/CCR with [b, a'] = 0, and X' := X(a', b) obeys
   [X', Y'] = Σ_Z c^Z_{XY} Z' (no K-term, I03).
4. Write X' = X − κf(X) and expand using [X, κW] = (−1)^{p(X)}κ[X,W] (I07 derivation). This gives
   exactly γ = δf with the doc's formula.

Explicitly:
- f(E_eps1_del{k}_{σt}) = λ^σ b_k^t ∈ sp(2n) ⊕ ℂK (scalar part ½ gb_{σ,k,t}),
- f(H_1) = a^-λ^+ − a^+λ^- ∈ g_1,
- f = 0 on all purely bosonic generators (H_2..H_{n+1}, E_2del*, E_del*_del*).

Example n=2: f(E_eps1_del2_pm) = gb_p_1_p E_del1_del2_mm − gb_p_1_m E_del1_del2_pm + gb_p_2_p E_2del2_m
+ gb_p_2_m H_3 + ½ gb_p_2_m K (computed and hand-checked).

Computational confirmation: the residual of this f against γ (exact reading, including K) is **0**
for every profile and unit vector for n = 1, 2, 3, and for a generic integer gb (n=2, test). ∎ (sketch)

**Uniqueness / structure.** On odd maps, ker δ has dimension 4n = dim g_1 for n = 1, 2, 3. So it
consists exactly of the inner maps ad_Z (Z odd), with no odd outer derivations, and f is unique up
to these. Moreover (`src/C_cohomology.py`):
```
n=1: odd cochains=128,  rank(cocycle eqs)=100,  dim Z^2_odd=28,  dim B^2_odd=28,  dim H^2_odd=0
n=2: odd cochains=1696, rank(cocycle eqs)=1528, dim Z^2_odd=168, dim B^2_odd=168, dim H^2_odd=0
n=3: odd cochains=9516, rank(cocycle eqs)=9000, dim Z^2_odd=516, dim B^2_odd=516, dim H^2_odd=0
```
So for n ≤ 3, every odd g-valued 2-cocycle of C(n+1) is a coboundary. The triviality of this
deformation is therefore forced by rigidity, independent of the particular gb. This is consistent
with γ being a cocycle (I05).
