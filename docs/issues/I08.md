## Triviality Search Report

### 1. Method and the comparison that was run

Trivial means $\gamma(\mathrm{gb}) = \delta f$ for some odd $f=\sum\phi_{ij}f_{ij}$ (Schema 4 basis). Both sides are linear, so a scalar factor is absorbed into $\phi$, and "up to scalar" adds nothing. Let $D$ be the coboundary matrix (rows $(X,Y,Z)$, columns $\phi_{ij}$) and $G$ the matrix of $\gamma$ (rows $(X,Y,Z)$, columns gb). Then $\gamma(\mathrm{gb})$ is trivial iff $G\,\mathrm{gb}\in\mathrm{im}\,D$. The set $T$ of trivial gb is the projection to gb of $\ker[-D\mid G]$. We compute $T$ exactly over $\mathbb{Q}$ with `src/C_triviality.py`, and its annihilator, the explicit conditions on gb.

Layer 3 (evaluated) and Layer 4 (coboundary) are compared through this exact linear system; the Layer 3 numbers (all $\mathrm{gb}=+1$) are a special point of it.

Two variants were run, because K has no counterpart in coboundaries:
- **K included**: the full bracket, including the $\kappa K$ components of $\gamma$.
- **K dropped**: the $K$ rows of $\gamma$ are ignored (K treated as an absent scalar, as `notation.md` describes it).

### 3. Specific evidence

**Trivial case.** $\mathrm{gb}=0$. Then $\gamma=0$, and $\phi=0$ gives $\delta f=0$. This is the only trivial point found.

**Non-trivial case: the Layer 3 profile** ($\mathrm{gb}\equiv+1$, `data/C_{n}_evaluated.json`, 56 / 272 / 744 nonzero entries). It is nontrivial since every gb coordinate must vanish. Concrete witness for n=1 (K dropped), for $\mathrm{gb}_{a_1^+,b_1^+}$: a functional $y$ on the entries $(X,Y,Z)$ that is zero on every coboundary column (checked on all 32) but equals $\mathrm{gb}_{a_1^+,b_1^+}$ on $\gamma$. Its three nonzero rows are:

| $(X,Y,Z)$ | $\gamma$ coefficient | $y$ |
|---|---|---|
| $(E^{pm}_{\varepsilon-\delta_1},\,E^{mp}_{\varepsilon-\delta_1},\,E^{mm}_{\varepsilon-\delta_1})$ | $-\mathrm{gb}_{a_1^+,b_1^+}$ | $-\tfrac12$ |
| $(E^{pm}_{\varepsilon-\delta_1},\,H_1,\,E_{-2\delta_1})$ | $+2\,\mathrm{gb}_{a_1^+,b_1^+}$ | $+\tfrac14$ |
| $(E^{pm}_{\varepsilon-\delta_1},\,H_\varepsilon,\,E_{-2\delta_1})$ | $0$ | $+\tfrac14$ |

Check: $y\cdot\gamma = (-\tfrac12)(-\mathrm{gb}) + \tfrac14(2\,\mathrm{gb}) + 0 = \mathrm{gb}$. Hence every trivial deformation has $\mathrm{gb}_{a_1^+,b_1^+}=0$.

Row labels are the notation labels from `handover/notation.md` (`E_eps1_del1_pm` = $E_{\varepsilon-\delta_1}^{pm}$, `E_2del1_m` = $E_{-2\delta_1}$).

**Where the K-components enter.** For n=1 the K-included system has 12 nonzero K-entries of $\gamma$, all linear in gb. Example: $\gamma(E^{pp}_{\varepsilon+\delta_1},H_\varepsilon)$ has K coefficient $-\tfrac12\mathrm{gb}_{a_1^+,b_1^+}$. Coboundaries have no K part, so each such entry forces its gb to vanish. The K-dropped variant reaches the same answer by the witness above, which uses no K row. So the K-components are sufficient for nontriviality but not necessary: the obstruction does not depend on them.

### 4. Discrepancy analysis (root cause)

- **Source of the discrepancy.** Each $\gamma_{\mathrm{gb}_k}$ (one gb at a time) has a witness supported on entries of the pairs $(E^{pm},E^{mp})$ and $(E^{pm},H_1)$, $(E^{pm},H_\varepsilon)$. The witness is a left-kernel vector of $D$; every coboundary column satisfies it, while $\gamma_{\mathrm{gb}_k}$ violates it by exactly $\mathrm{gb}_k$. This is an observed fact of the computation; I have not derived it in closed form.
- **Torus weights.** The Cartan $H_\varepsilon, H_1,\dots,H_n$ acts on everything, and $\delta$ commutes with this action. $\mathrm{gb}_{\sigma,j,s}$ carries weight $-\mathrm{wt}(E_{\sigma,j,s})$, and these $4n$ weights are distinct. So $\gamma_{\mathrm{gb}_k}$ can only be a coboundary of maps of its own weight. **This does not close the argument:** every weight class does contain nonzero coboundaries (the check `weight_obstruction` reports 6, 12, 18 for n=1,2,3). The obstruction is a linear-algebra fact, not a weight-count fact. I did not find a closed-form reason beyond the witness.
- **Conclusion for root cause.** For each $\mathrm{gb}_k$, $\gamma_{\mathrm{gb}_k}\notin \mathrm{im}\,D$; the $4n$ obstructions are independent (the conditions matrix has rank $4n$). Nothing cancels between different gb.

### 5. General conjecture

**Conjecture (C-triv).** For $C(n+1)=\mathfrak{osp}(2|2n)$ with the oscillator deformation $[b_j^s,a_1^\sigma]=-\mathrm{gb}_{\sigma,j,s}\kappa$, the inhomogeneous deformation $\gamma(\mathrm{gb})$ is trivial (equal to $\delta f$ for an odd $f$) **if and only if** $\mathrm{gb}_{\sigma,j,s}=0$ for all $\sigma,j,s$.

- Sufficient: trivially, $\mathrm{gb}=0$ gives $\gamma=0$.
- Necessary: verified exactly over $\mathbb{Q}$ for $n=1,2,3$ (both K variants). For general $n$, this is a conjecture.
- Equivalent form: the set of trivial gb is the zero subspace, i.e., there are no nonzero trivial deformations in this family. The zero set is unchanged by rescaling $\kappa$ (which only rescales gb by a nonzero factor).

### 6. Active investigation and checks

- **Sensitivity of the solver** (tests): a synthetic deformation $\gamma=\mathrm{gb}_0\,\delta f_k$ is recognized as trivial (its subspace contains $e_0$). A deformation with a K row that no coboundary can cancel is recognized as nontrivial.
- **Sign convention of δ**: the implemented $\delta f=(-1)^{p(X)}[X,fY]-(-1)^{(p(X)+1)p(Y)}[Y,fX]-f[X,Y]$ equals $[fX,Y]+(-1)^{p(X)}[X,fY]-f[X,Y]$ (graded antisymmetry), the standard odd-derivation form. A hand computation for n=1 gives $-3E^{pm}$, which the program reproduces.
- **Weight analysis** (described above): does not give the proof, but it explains why the problem splits into independent 1-parameter obstructions.

### 7. Limitations and assumptions

1. **Cocycle property of γ was not checked** directly. γ is obtained from an associative realization (graded commutators in one algebra), so the Jacobi identity should hold, but I did not verify $\delta\gamma=0$ numerically. This does not affect the triviality computation, which uses only γ and δf.
2. **K convention.** The "K included" variant keeps the $\kappa K$ components as stated in the schema. The "K dropped" variant gives the same result, so the conclusion does not depend on this choice.
3. **Weyl symmetrization** fixes the constant parts of the basis (I03). A different constant convention could change the K-components but not the non-K witness above, which I did not prove for all conventions.
4. **Field.** All data are rational, so the rank conditions are the same over $\mathbb{Q}$, $\mathbb{R}$ and $\mathbb{C}$.
5. **Conjecture for general $n$** is supported only for $n=1,2,3$.
