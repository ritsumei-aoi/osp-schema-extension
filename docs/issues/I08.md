### 0. Summary of the result

**The inhomogeneous deformation of C(n+1) defined in `C_inhomogeneous_definition.md` is trivial
for every value of the $4n$ parameters gb** — with one precise caveat about the central element
$K$:

| Reading of "trivial" | Condition on gb | Evidence |
|---|---|---|
| (i) $\gamma = \delta f$ with $f:\mathfrak g\to\mathfrak g\oplus\mathbf CK$ (equality in $\mathfrak g\oplus\mathbf CK$) | **none — always trivial** | Layer 3 = Layer 4 exactly; general solve consistent for all 16+ profiles, n = 1,2,3; symbolic identity $\gamma = \delta f_{\rm can}$; general proof §3 |
| (ii) $\gamma \equiv \delta f \pmod K$ with $f:\mathfrak g\to\mathfrak g$ ("up to scalar", the wording of `C_coboundary_definition.md` §3) | **none — always trivial** | general solve of $\gamma_{\mathfrak g} = \delta f$ consistent for all profiles |
| (iii) $\gamma = \delta f$ with $f:\mathfrak g\to\mathfrak g$ **and** equality including the $K$-component | **gb = 0 only** | the system is inconsistent for every unit profile; the obstruction is exactly $\gamma_K \ne 0$ |

Readings (i) and (ii) are the mathematically meaningful ones (the deformation lives in
$\mathfrak g\oplus\mathbf CK$, and $K=1$ is central), so the answer to "when is the deformation
trivial?" is: **always, with the explicit odd map $f_{\rm can}$ below.** Reading (iii) explains
the only place where Layer 3 and a $\mathfrak g$-valued coboundary *fail* to coincide, and
that failure is fully characterised (§2).

### 2. Rigorous analysis of the discrepancies (Requirement 2)

The only discrepancies that exist anywhere in the data are the **$K$-components**. They are
completely characterised:

* **Which pairs.** Exactly the ordered pairs $(X,Y)$ whose *undeformed* bracket has an odd
  component: 20 / 84 / 180 ordered pairs for n = 1, 2, 3 (10 / 42 / 90 unordered). Types:
  (Cartan, odd), (odd, Cartan), ($E_{\pm2\delta_k}$ or $E_{\pm\delta_i\pm\delta_j}$, odd) and
  their transposes. Never (odd, odd) and never (even, even), because $[X,Y]_0$ is then even.
* **Closed form (verified on all pairs, all n, symbolically):**
  $$\gamma(X,Y)_K \;=\; -\tfrac12\sum_{\sigma,k,u} \mathrm{gb}_{a_1^\sigma,b_k^u}\,[X,Y]_0\big|_{E_{\sigma\varepsilon+u\delta_k}} .$$
  Example: $[H_1,E_{\varepsilon+\delta_1}]_0 = 2E_{\varepsilon+\delta_1}$ ⇒ $\gamma(H_1,E_{\varepsilon+\delta_1})_K = -\mathrm{gb}_{a^+b^+}$;
  $[H_2,E_{\varepsilon+\delta_1}]_0 = -E_{\varepsilon+\delta_1}$ ⇒ $\gamma_K = +\tfrac12\mathrm{gb}_{a^+b^+}$;
  $[E_{2\delta_1},E_{\varepsilon-\delta_1}]_0 = -2E_{\varepsilon+\delta_1}$ ⇒ $\gamma_K = +\mathrm{gb}_{a^+b^+}$ (n = 1 listing in the log below).
* **Why they arise.** Normal-ordering the deformed bracket produces $\kappa\,\mathrm{gb}\,b_k^-b_k^+$
  terms, and $b_k^-b_k^+ = b_k^+b_k^- + 1$; the basis of $\mathfrak g$ consists of *symmetrised*
  quadratics ($b_k^+b_k^-+\tfrac12 \in \mathfrak h$), so the leftover $\tfrac12$ is a genuine
  $K = 1$ component. In cohomological terms: the odd 1-cochain $f_K:\mathfrak g_{\bar 1}\to\mathbf CK$,
  $f_K(a_1^\sigma b_k^u) = \tfrac12\mathrm{gb}_{a_1^\sigma,b_k^u}$, has coboundary
  $(\delta f_K)(X,Y) = -f_K([X,Y])$ (since $[X,K]=0$), which is exactly the closed form above.
* **Why a $\mathfrak g$-valued $f$ cannot absorb them.** For $f:\mathfrak g\to\mathfrak g$,
  $\delta f$ takes values in $\mathfrak g$, so the $K$-rows of the linear system read $0 = \gamma_K(X,Y)$.
  Since $\gamma_K(N_k, E_{\sigma\varepsilon+u\delta_k}) = -\tfrac{u}{2}\mathrm{gb}_{\sigma,k,u}$ with
  $N_k = b_k^+b_k^-+\tfrac12 = H_{k+1}+\dots+H_n-H_{n+1}$, every single parameter is obstructed:
  reading (iii) holds iff gb = 0. The solver confirms that *all* inconsistent rows have $Z = K$
  (asserted in `tests/test_C_triviality.py`).
* **Uniqueness.** $\mathfrak g$ is perfect, so $f_K$ is uniquely determined by $\gamma_K$; the
  $\mathfrak g$-part of $f$ is unique up to the kernel of $\delta$ on odd 1-cochains, which the
  solver finds to be exactly $4n$-dimensional = $\{\mathrm{ad}_Z : Z \in \mathfrak g_{\bar 1}\}$.
  Hence $H^1(\mathfrak g,\mathfrak g)_{\bar 1} = 0$ for n = 1, 2, 3 (no outer odd derivations),
  and the solution set is the affine space $f_{\rm can} + \mathrm{ad}(\mathfrak g_{\bar 1})$.

### 3. General conjecture — in fact a theorem (Requirement 3)

**Statement.** For every $n\ge1$ and every $\mathrm{gb}\in\mathbf C^{2\times 2n}$ the
inhomogeneous deformation $[b_k^s,a_1^\sigma] = -\mathrm{gb}_{a_1^\sigma,b_k^s}\kappa$ of
$C(n+1)$ is trivial: $\gamma = \delta f_{\rm can}$ with the odd map
$$f_{\rm can}(a_1^\sigma b_k^u) = -\,c^\sigma b_k^u,\qquad f_{\rm can}(H_1) = a_1^+c^- - c^+a_1^-,\qquad f_{\rm can}\big|_{\mathfrak{sp}(2n)} = 0,$$
$$c^\sigma = \sum_{k=1}^n\big(\mathrm{gb}_{a_1^\sigma,b_k^-}\,b_k^+ - \mathrm{gb}_{a_1^\sigma,b_k^+}\,b_k^-\big),$$
(products normal-ordered; the constants produced by $b_k^-b_k^+$ are the $K$-components
$f_K(a_1^\sigma b_k^u) = \tfrac12\mathrm{gb}_{a_1^\sigma,b_k^u}$). **Necessary and sufficient
condition on gb: none.** Modulo $K$ ("up to scalar") the same map without its $K$-part works.
Strict equality in $\mathfrak g\oplus\mathbf CK$ with $f$ confined to $\mathfrak g$ is possible
iff gb = 0.

**Proof (valid for all n).** Put $\tilde a^\sigma := a^\sigma - \kappa c^\sigma$. Using
$[b_k^-,b_k^+]=1$: $[b_k^s,\tilde a^\sigma] = -\mathrm{gb}_{\sigma,k,s}\kappa - \kappa[b_k^s,c^\sigma] = 0$;
$\{\tilde a^-,\tilde a^+\} = 1 + \kappa(\ldots)\kappa = 1$ and $(\tilde a^\sigma)^2 = 0$ because every
correction is proportional to $\kappa^2 = 0$. So $(\tilde a, b)$ satisfy the undeformed relations
inside the deformed $\mathcal U(A)$. For a generator $X = X(a,b)$ write
$\tilde X := X(\tilde a,b) = X + \kappa f(X)$, which defines $f = f_{\rm can}$. Then
$[\tilde X,\tilde Y] = \widetilde{[X,Y]_0} = [X,Y]_0 + \kappa f([X,Y]_0)$ (undeformed
computation), while expanding directly,
$[\tilde X,\tilde Y] = [X,Y]_0 + \kappa\big(\gamma(X,Y) + (-1)^{p(X)}[X,f(Y)] - (-1)^{(p(X)+1)p(Y)}[Y,f(X)]\big)$,
using $[X,\kappa W] = (-1)^{p(X)}\kappa[X,W]$, $[\kappa W,Y] = \kappa[W,Y]$ and $\kappa^2=0$.
Comparing κ-coefficients gives $\gamma(X,Y) = (\delta f)(X,Y)$ with precisely the formula of
`C_coboundary_definition.md` (the sign of $\tilde a$ was chosen so that no extra minus sign
appears). ∎ — The identity was also checked **symbolically in the gb parameters** by
`tests/test_C_coboundary.py::test_gamma_equals_delta_f_can_symbolically` for n = 1, 2, 3.

**Structural remark / contrast with B(0,n).** The argument only uses that the deformation is of
"pre-oscillator-form type" ($[v,w] = (v|w)\kappa$ for $p(v)\ne p(w)$) and that the even
form on $V_{\bar0}$ is non-degenerate (so any functional $(\cdot|w)$ on $V_{\bar0}$ is realised by
a $c_w\in V_{\bar0}$). Such mixed boson–fermion deformations are therefore always absorbable
by the odd shift $w\mapsto w-\kappa c_w$, for any oscillator superalgebra. The B(0,n)
deformation of `B0n_definition.md` is of a *different* type — it modifies the odd–odd relation
$a_0^2 = \tfrac12 + \kappa\sum\mathrm{gb}\,b$ — which an odd shift of $a_0$ leaves invariant
($(a_0-\kappa c)^2 = a_0^2 + \kappa[a_0,c] = a_0^2$); so no conclusion about B(0,n) follows
from the present result, and the two "inhomogeneous deformations" should not be expected to
behave alike. (I also note that an odd–odd deformation $\{a_1^-,a_1^+\} = 1 + \kappa\beta$,
$\beta\in V_{\bar0}$, is *not* compatible with the Jacobi identity of $A$ when κ is central —
$[\{a^-,a^+\},b] = \kappa[\beta,b] \ne 0$ while the other side vanishes — so for C(n+1) the
mixed-type definition in `C_inhomogeneous_definition.md` is the consistent one.)
