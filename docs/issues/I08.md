### 0. Summary of the answer

Let g = C(n+1), g~ = g ⊕ CK (K = central identity, present in the schema since I02), and let
γ(gb) be the Layer 2/3 cocycle, which is linear in the 4n parameters gb.

| reading of "f" | trivial iff | evidence |
|---|---|---|
| **f: g → g~** (K allowed as target; the natural reading because γ itself has K-components) | **always** (every gb ∈ Q^{4n}) | 0 constraints on gb for n = 1, 2, 3; explicit f found for all 7 profiles; closed-form f for all n |
| f: g → g, γ taken modulo K | always | 0 constraints for n = 1, 2, 3 |
| **f: g → g strictly** (literal `C_coboundary_definition.md`) | **gb = 0** (all 4n parameters vanish) | exactly 4n independent constraints `gb_a1σ_bjs = 0` for n = 1, 2, 3 |

The only obstruction is the **K-component of γ**, which is a non-zero scalar 2-cocycle whenever gb ≠ 0.
In addition, dim H²(g, g~)_odd = 0 for n = 1, 2 (computed), so in the K-extended setting *every* odd
deformation of C(2), C(3) with values in g~ is trivial, not just the gb-deformation.

- Unknowns: the φ parameters of Schema 4 (`f(Z_j) = Σ_i φ_ij Z_i`, 36 / 184 / 540 for n = 1 / 2 / 3).
- Equations: one per component (X, Y, Z): `(δf)_{XY}^Z(φ) = γ_{XY}^Z(gb)` (232 / 2832 / 14156 equations).
  The left side is read from `C_{n}_coboundary.json`, the right side from `C_{n}_gamma.json`

  restricted to the φ-columns; rows whose φ-part vanishes give the **necessary and sufficient linear
  conditions on gb** for solvability. (Correctness: γ(gb) ∈ Im D ⇔ γ(gb) is orthogonal to the left kernel of D.)
- Numeric comparison per profile: solve D φ = γ_L3, then **independently** re-evaluate the Schema 4 linear forms
  at the solution and compare, component by component, with the Layer 3 `gamma_evaluated` list.
- Closed-form candidate: the map induced by the oscillator change of variables (Section 4), computed with the
  oscillator engine and checked against γ.
- Variants: f: g → g~ ("K"), f: g → g ("strict"), f: g → g with γ projected to g ("mod_K").

### 3. Rigorous analysis of the discrepancy

Where it sits. For K central, `(δf)(X,Y)` has K-component `−f_K([X,Y])` only (the two bracket terms
cannot produce K). Hence in the strict reading (f_K ≡ 0) the K-part of γ must vanish by itself, and the
inconsistent components are precisely the pairs (X, Y) with γ_K(X,Y) ≠ 0: 20 / 84 / 180 pairs for the ±1 profiles.

What γ_K is. From the data (and proved in Section 4), γ_K is the scalar odd 2-cocycle
$$\gamma_K(X,Y) \;=\; -\tfrac12 \sum_{Z\ \mathrm{odd}} c_{XY}^{Z}\, \mathrm{gb}_Z ,\qquad
\mathrm{gb}_{E_{\varepsilon s\,\delta_k t}} := \mathrm{gb}_{a_1^{s}, b_k^{t}},$$
i.e. γ_K = φ_K∘[·,·] with the odd functional φ_K(E_eps1_del{k}_{st}) = −gb_{s,k,t}/2, φ_K(even) = 0.
Check against the data: [H_1, E_eps1_del1_pp] = 2 E_eps1_del1_pp gives γ_K = −½·2·gb_a1p_b1p = −1 at all_plus ✓;
[H_2, E_eps1_del1_pp] = −E_eps1_del1_pp gives +½ ✓; [E_2del1_p, E_eps1_del1_pm] = −2 E_eps1_del1_pp gives +1 ✓.

Why it is an obstruction only in the strict reading. γ_K is the coboundary of the K-valued 1-cochain
−φ_K (that is what the "K" variant uses), but it is not the coboundary of any g-valued map. For it to vanish
identically we need φ_K([X,Y]) = 0 for all X, Y, i.e. φ_K = 0 on [g, g] = g (C(n+1) is simple), i.e. every
gb_{s,k,t} = 0. This is exactly the set of 4n constraints the row reduction produced for n = 1, 2, 3.

Mathematical origin. The K-terms arise because normal-ordering `a_1^- a_1^+ = 1 − a_1^+ a_1^-` and
`b^- b^+ = b^+ b^- + 1` create constants, and the Cartan subalgebra of C(n+1) (unlike the span {N_a, N_k, 1})
does not contain the constant 1: its span is {N_a − ½, N_k + ½}. So the deformed bracket of g closes only in
g~ = g ⊕ CK; the "deformation of g" is really a deformation of the central extension g~, and K-valued
components of f are the natural (and necessary) trivializing data.

### 4. General result: closed-form trivialization for all n (conjecture, with proof sketch)

**Claim.** For every n ≥ 1 and every gb ∈ C^{4n}, γ(gb) = δf with
f = −f_shift: g → g~, where f_shift is defined by X + κ f_shift(X) := X(a_1, b') and
$$ b_j^{s}{}' \;=\; b_j^{s} + \kappa\big(\mathrm{gb}_{a_1^+, b_j^s}\, a_1^- + \mathrm{gb}_{a_1^-, b_j^s}\, a_1^+\big). $$
Explicitly (all n):
```
f(E_eps1_del{k}_p t) =  gb_{a1p,bkt} · a_1^+ a_1^-  =  gb_{a1p,bkt} (N_a - 1/2) + gb_{a1p,bkt}/2 · K
f(E_eps1_del{k}_m t) =  gb_{a1m,bkt} · a_1^- a_1^+  = -gb_{a1m,bkt} (N_a - 1/2) + gb_{a1m,bkt}/2 · K
f(b_i^s b_j^t)        = -(gb_{a1p,bis} a_1^- + gb_{a1m,bis} a_1^+) b_j^t - (gb_{a1p,bjt} a_1^- + gb_{a1m,bjt} a_1^+) b_i^s
f(H_k)                = obtained from the words of H_k by the previous line (constants map to 0)
```
with N_a − ½ = H_1 − H_2 − ⋯ − H_n + H_{n+1} ∈ g.

**Proof sketch.** In the deformed pre-oscillator algebra A_gb, [b'_j{}^s, a_1^σ] = −gb_{σ,j,s} κ + κ·gb_{σ,j,s} = 0
(using [κ a_1^τ, a_1^σ] = κ{a_1^τ, a_1^σ} = κ δ_{τ,−σ}), [b', b'] = [b, b] (the cross terms are κ·[a,b] ∝ κ² = 0),
and the CAR of a_1^± are untouched. Hence (a_1^±, b') generate an *undeformed* oscillator algebra, so the elements
X' = X(a_1, b') obey the undeformed structure constants: [X', Y'}_γ = Σ_Z c_{XY}^Z Z'. Because κ² = 0,
X' = X + κ f_shift(X) with f_shift(X) a quadratic word (one b replaced by κ a_1), hence in g~. Comparing κ-parts
gives γ = −δ f_shift (Section 2 of I07 for the sign), i.e. γ = δ(−f_shift). ∎

**Computational confirmation.** `check_shift_map` computes f_shift with the oscillator engine, evaluates
the Layer 4 linear forms at −f_shift and compares with γ: for n = 1, 2, 3 and the profiles all_plus,
checkerboard, single_pp (and row_sign in the tests) there are **0 mismatches** and the κ⁰ part of X' is X
(residual 0). The symbolic f_shift is stored in `shift_map.f_shift_symbolic` of each `C_{n}_triviality.json`
and matches the closed form above (e.g. n = 2: f_shift(E_eps1_del1_pp) = −gb_a1p_b1p (H_1 − H_2 + H_3) − gb_a1p_b1p/2 K,
and H_1 − H_2 + H_3 = N_a − ½).

**Conjecture (necessary and sufficient conditions on gb).**
1. As a deformation of g~ = C(n+1) ⊕ CK (or of C(n+1) modulo the central term), the inhomogeneous
   deformation is trivial for **all** gb ∈ C^{4n}, for all n ≥ 1 — with the explicit trivializing map above.
   (Proved above for all n; verified by exact computation for n = 1, 2, 3.)
2. As a deformation of C(n+1) with the trivializing map confined to C(n+1), it is trivial **iff gb = 0**;
   the obstruction is the scalar cocycle γ_K = −½ Σ_{Z odd} c_{XY}^Z gb_Z, which is non-zero as soon as one gb ≠ 0.
   (Proved above using simplicity of C(n+1); verified for n = 1, 2, 3.)
3. Stronger context (computed, n = 1, 2): dim H²(C(n+1), g~)_odd = 0 (cochains 144 / 1784, dim Z² = dim B² = 32 / 176),
   so every odd g~-valued 2-cocycle is a coboundary; the gb-deformation is not special in this respect.
   We conjecture H²(C(n+1), g~)_odd = 0 for all n ≥ 1 (not computed for n = 3; ≈10⁴ unknowns).

### 5. Contrast with B(0,n) and caveats

- The mechanism is the same one that makes the constant ½ appear in H_{n+1}: the oscillator Cartan elements
  carry constants. For B(0,n) the analogous central term would be attached to a_0² = ½. We did not use
  any B(0,n) data; the comparison is only conceptual.
- Parity bookkeeping: gb were treated as scalars (I05). If gb were Grassmann-odd, γ would still be linear in gb
  and the linear-algebra conclusions (constraints, ranks) are unchanged.
- The sign convention of `C_coboundary_definition.md` was followed verbatim; the criterion γ ∈ Im δ is sign-free.
