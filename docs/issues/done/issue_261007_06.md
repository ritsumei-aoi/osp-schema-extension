### 1. What Schema 3 Contains

Schema 3 stores the **fully evaluated deformed bracket** on L = g ⊕ κg for a specific numerical choice of gb parameters. For each ordered pair (X, Y) of basis generators, the deformed bracket is:

```
[X, Y]_γ = [X, Y]_0  +  κ · γ(X, Y)|_{gb=values}
```

The output has two components per pair:
- **g-part**: same as Schema 1 structure constants (undeformed bracket)
- **κg-part**: evaluated γ(X,Y) with gb substituted by the chosen values

Only pairs with at least one non-zero component are stored. The κg-part also includes `"c": "K"` entries (even central element arising from CCR reordering).

### 2. gb Label Convention (as used in Schema 2 files)

The Schema 2 files use the format `gb_{sigma}_{j}_{s}` where sigma ∈ {p,m}, j = boson index, s ∈ {p,m}. For example, for n=1:

| Label | Meaning |
|---|---|
| `gb_p_1_p` | gb for [b_1^+, a_1^+]_γ = -gb · κ |
| `gb_p_1_m` | gb for [b_1^-, a_1^+]_γ = -gb · κ |
| `gb_m_1_p` | gb for [b_1^+, a_1^-]_γ = -gb · κ |
| `gb_m_1_m` | gb for [b_1^-, a_1^-]_γ = -gb · κ |

For n=2,3: additional indices j=2 (and j=3 for n=3).

### 4. Proposed Schema 3 JSON Structure

File: `data/C_{n}_evaluated_{suffix}.json`

```json
{
  "schema_version": "5.0",
  "schema_layer": 3,
  "algebra": {
    "family": "C",
    "n": <n>,
    "cartan_type": "C(<n+1>)",
    "alternative_notation": {"osp": "osp(2|<2n>)"},
    "schema2_file": "C_<n>_gamma.json"
  },
  "gb_profile": {
    "label": "<suffix>",
    "description": "<human-readable description>",
    "values": {
      "gb_p_1_p": "1",
      "gb_p_1_m": "1",
      ...
    }
  },
  "deformed_brackets": [
    {
      "X": "<gen_a>",
      "Y": "<gen_b>",
      "g_part":    [{"Z": "<gen_c>", "coeff": "<rational>"}],
      "kappa_part": [{"Z": "<gen_c_or_K>", "coeff": "<rational>"}]
    }
  ],
  "metadata": {
    "generated_by": "src/C_evaluated.py",
    "generation_date": "<YYYY-MM-DD>",
    "notes": "g_part = [X,Y]_0 coefficients (rational); kappa_part = evaluated gamma(X,Y) coefficients (rational). K = even central element."
  }
}
```

Storage convention: only pairs where at least one of `g_part` or `kappa_part` is non-empty. `kappa_part` is omitted (or `[]`) when γ(X,Y)|_{gb=values} = 0.
