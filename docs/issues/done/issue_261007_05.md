## Rev.1 Proposal (2026-10-07)

### 1. Overview

This proposal defines the gamma structure for the C(n+1) inhomogeneous deformation and presents sign convention options for human approval.

The deformed bracket on L = g ⊕ κg is:
```
[X, Y]_γ = [X, Y]_0 + κ · γ(X, Y)
```
where γ: g ⊗ g → g is a 2-cocycle, κ is an odd central element (κ² = 0), and the deformation is specified by:
```
[b_j^s, a_1^σ]_γ = -gb_{σ,j,s} · κ,   σ ∈ {+,-}, j=1,...,n, s ∈ {+,-}
```
In terms of the oscillator commutator: `b_j^s a_1^σ - a_1^σ b_j^s = -gb_{σ,j,s} · κ`, equivalently:
```
a_1^σ b_j^s = b_j^s a_1^σ + gb_{σ,j,s} · κ
```

### 2. gb_matrix Definition

For C(n+1), the gb_matrix is a 2 × 2n array indexed by (σ, j, s):

| | b_1^+ | b_1^- | b_2^+ | b_2^- | ... | b_n^+ | b_n^- |
|---|---|---|---|---|---|---|---|
| a_1^+ | gb_{+,1,+} | gb_{+,1,-} | gb_{+,2,+} | gb_{+,2,-} | ... | gb_{+,n,+} | gb_{+,n,-} |
| a_1^- | gb_{-,1,+} | gb_{-,1,-} | gb_{-,2,+} | gb_{-,2,-} | ... | gb_{-,n,+} | gb_{-,n,-} |

Total: 4n parameters.

**JSON representation** (symbolic; actual numeric values set at Schema 3 evaluation):
```json
"gb_matrix": {
  "rows": ["a_1_p", "a_1_m"],
  "cols": ["b_1_p", "b_1_m", ..., "b_n_p", "b_n_m"],
  "entries": {
    "a_1_p": { "b_1_p": "gb_pp_1_p", "b_1_m": "gb_pp_1_m", ... },
    "a_1_m": { "b_1_p": "gb_pm_1_p", "b_1_m": "gb_pm_1_m", ... }
  }
}
```
(Label convention: `gb_{σ_label}_{j}_{s_label}` where `p`=+, `m`=−.)

### 3. Derivation of γ_{abc}

**Parity constraint**: Since p(κ) = 1:
- γ(even, even) = 0 (even generators contain only b-bilinears, no a_1)
- γ(odd, odd) ∈ odd subspace (p = 1+1+1 = 1 mod 2)
- γ(even, odd) ∈ even subspace (p = 0+1+1 = 0 mod 2)

Odd generators have oscillator realization E_eps1_delj_σs = a_1^σ b_j^s.

**Derivation for (odd, odd):**

Let G_a = a_1^σ b_j^s, G_b = a_1^{σ'} b_{j'}^{s'}. Compute {G_a, G_b}_γ:

```
{a_1^σ b_j^s, a_1^{σ'} b_{j'}^{s'}}_γ
 = a_1^σ (b_j^s a_1^{σ'}) b_{j'}^{s'} + a_1^{σ'} (b_{j'}^{s'} a_1^σ) b_j^s

 = a_1^σ (a_1^{σ'} b_j^s - gb_{σ',j,s}·κ) b_{j'}^{s'}
 + a_1^{σ'} (a_1^σ b_{j'}^{s'} - gb_{σ,j',s'}·κ) b_j^s

 = [a_1^σ a_1^{σ'} b_j^s b_{j'}^{s'} + a_1^{σ'} a_1^σ b_{j'}^{s'} b_j^s]  ← undeformed part
 + κ · [- gb_{σ',j,s} · a_1^σ b_{j'}^{s'}  - gb_{σ,j',s'} · a_1^{σ'} b_j^s]  ← κ-part
```

Extracting γ:
```
γ(E_eps1_delj_σs, E_eps1_delj'_σ's') =
    - gb_{σ',j,s}  · E_eps1_delj'_σs'
    - gb_{σ,j',s'} · E_eps1_delj_σ's
```

In structure-constant notation (γ^c_{ab}):
```
γ^{E_eps1_delj'_σs'}_{E_eps1_delj_σs, E_eps1_delj'_σ's'} += -gb_{σ',j,s}
γ^{E_eps1_delj_σ's}_{E_eps1_delj_σs, E_eps1_delj'_σ's'} += -gb_{σ,j',s'}
```

**Derivation for (even, odd):**

Let G_even = Σ c_{α} · m_α where m_α are oscillator monomials in b's only.
G_odd = a_1^σ' b_{j'}^{s'}.

When computing [G_even, G_odd]_γ, the κ-contribution arises when each b in G_even passes by a_1^{σ'}:
```
[b_j^s ... b_l^{s''}, a_1^{σ'} b_{j'}^{s'}]_γ  →  κ-terms from each b passing a_1^{σ'}
```

Each b_j^s in G_even contributes a term `-gb_{σ',j,s} · κ · (remaining b's × b_{j'}^{s'})`. The resulting κ-coefficient is an element of the even subspace (a product of b's), which must then be identified with an even basis element.

The concrete formula requires the oscillator realization of each even generator from Schema 1. This will be computed numerically by the gamma script using the `generator_realization` entries in `C_n_structure.json`.

**Concrete example (n=1):**

For C(2) = osp(2|2), n=1, the 4 odd generators are:
```
F1 = E_eps1_del1_pp = a_1^+ b_1^+
F2 = E_eps1_del1_pm = a_1^+ b_1^-
F3 = E_eps1_del1_mp = a_1^- b_1^+
F4 = E_eps1_del1_mm = a_1^- b_1^-
```

γ values among odd generators (using σ=+,j=1,s=+; σ'=+,j'=1,s'=- as example):
```
γ(F1, F2) = γ(a_1^+ b_1^+, a_1^+ b_1^-)
           = -gb_{+,1,+} · E_eps1_del1_pm - gb_{+,1,-} · E_eps1_del1_pp
           = -gb_{+,1,+} · F2 - gb_{+,1,-} · F1

γ(F1, F3) = γ(a_1^+ b_1^+, a_1^- b_1^+)
           = -gb_{-,1,+} · E_eps1_del1_pp - gb_{+,1,+} · E_eps1_del1_mp
           = -gb_{-,1,+} · F1 - gb_{+,1,+} · F3

γ(F1, F4) = γ(a_1^+ b_1^+, a_1^- b_1^-)
           = -gb_{-,1,+} · E_eps1_del1_pm - gb_{+,1,-} · E_eps1_del1_mp
           = -gb_{-,1,+} · F2 - gb_{+,1,-} · F3

γ(F2, F3) = γ(a_1^+ b_1^-, a_1^- b_1^+)
           = -gb_{-,1,-} · E_eps1_del1_pp - gb_{+,1,+} · E_eps1_del1_mm
           = -gb_{-,1,-} · F1 - gb_{+,1,+} · F4

γ(F2, F4) = γ(a_1^+ b_1^-, a_1^- b_1^-)
           = -gb_{-,1,-} · E_eps1_del1_pm - gb_{+,1,-} · E_eps1_del1_mm
           = -gb_{-,1,-} · F2 - gb_{+,1,-} · F4

γ(F3, F4) = γ(a_1^- b_1^+, a_1^- b_1^-)
           = -gb_{-,1,+} · E_eps1_del1_mm - gb_{-,1,-} · E_eps1_del1_mp
           = -gb_{-,1,+} · F4 - gb_{-,1,-} · F3
```

γ(F_i, F_i) for same pair: γ(F1, F1) = -gb_{+,1,+}·F1 - gb_{+,1,+}·F1 = -2 gb_{+,1,+}·F1, etc.

### 4. Sign Convention Question (HUMAN APPROVAL REQUIRED)

**The issue**: γ_{abc} can be stored with either an upper or lower c-index. The choice affects Schema 2 and downstream Schema 4 coboundary computation.

#### Option A: Upper-index convention (γ^c_{ab})

Store γ^c_{ab} = coefficient of basis element e_c in γ(e_a, e_b), computed directly from the oscillator algebra. **No Gram matrix required**.

```json
"gamma_cocycle": [
  {"a": "E_eps1_del1_pp", "b": "E_eps1_del1_pm",
   "c": "E_eps1_del1_pm", "coeff_sym": "-gb_pp_1_p"},
  {"a": "E_eps1_del1_pp", "b": "E_eps1_del1_pm",
   "c": "E_eps1_del1_pp", "coeff_sym": "-gb_pp_1_m"},
  ...
]
```

Pros: Unambiguous; no metric needed; directly computed from oscillators.
Cons: Index position must be tracked carefully in coboundary computation.

#### Option B: All-lower-index convention (γ_{abc})

Store γ_{abc} = Σ_d γ^d_{ab} G_{dc} using the Gram matrix G of the invariant bilinear form on g.

This requires specifying the form (·|·) on the generators of g, which has a sign ambiguity in the fermionic sector. The two sub-options are:

**Option B1 (standard oscillator metric)**:
```
(a_1^+, a_1^-) = +1  →  G_{F_i, F_j} derived with positive fermionic norm
```

**Option B2 (alternate sign)**:
```
(a_1^+, a_1^-) = -1  →  G_{F_i, F_j} derived with negative fermionic norm
```

The sign `(a_1^+, a_1^-)` directly controls the signs of γ_{abc} entries involving the fermionic sector, which propagates into coboundary triviality checks.

**Recommendation**: Option A (upper-index). The Gram matrix can be added as a separate block in Schema 2 or deferred to Schema 4. This keeps γ_{abc} unambiguous and allows the human to choose the metric convention independently.

If Option B is preferred, please specify the sign of `(a_1^+, a_1^-)`.

### 3′. Corrected Derivation of γ_{abc}

**Which generators contain a_1?** (from C_n_structure.json for all n)

- **H_1** (even): `a_1_p · a_1_m + b_1_p · b_1_m` — the unique even generator with a_1 terms
- **H_2, ..., H_{n+1}** (even): bilinears in b's only (and possibly constants) — NO a_1
- **E_2delk_p, E_2delk_m, E_deli_delj_ss'** (even): bilinears in b's only — NO a_1
- **E_eps1_delj_σs** (odd, all 4n): `a_1^σ b_j^s` — all contain a_1

**Non-zero γ sectors:**

γ(X, Y) can be non-zero if and only if at least one of X, Y contains a_1 in its oscillator realization.

| Pair type | Contains a_1? | γ result parity | Non-zero? |
|---|---|---|---|
| (odd, odd) | both odd have a_1 | odd (p=1+1+1=1) | yes in general |
| (H_1, G_even_no_a1) | H_1 has a_1 | odd (p=0+0+1=1) | yes in general |
| (H_1, G_odd) | both have a_1 | even (p=0+1+1=0) | yes in general |
| (G_even_no_a1, G_odd) | odd has a_1 | even (p=0+1+1=0) | yes in general |
| (G_even_no_a1, G_even_no_a1) | neither has a_1 | — | zero |
| (H_1, H_1) | — | — | zero (antisymmetry for p=0) |

**Formula for (odd, odd)** (unchanged from Rev.1):

For G_a = a_1^σ b_j^s, G_b = a_1^{σ'} b_{j'}^{s'}:
```
γ(G_a, G_b) = -gb_{σ',j,s} · (a_1^σ b_{j'}^{s'}) - gb_{σ,j',s'} · (a_1^{σ'} b_j^s)
            = -gb_{σ',j,s} · E_eps1_delj'_σs' - gb_{σ,j',s'} · E_eps1_delj_σ's
```

**Formula for (H_1, G_even_no_a1):**

H_1's a_1-part = a_1^+ a_1^-. For G_even_no_a1 = Σ c_α b_k^r b_l^t (bilinears in b's):

When computing [a_1^+ a_1^-, b_k^r b_l^t]_γ, the κ-terms arise because b's must move past a_1^+, a_1^- to normal-order the product b_k^r b_l^t a_1^+ a_1^-. At first order in gb, each b-a_1 pair contributes one swap. The formula (using the general rule: b_j^s a_1^σ = a_1^σ b_j^s - gb_{σ,j,s}·κ) is:

```
κ-coeff(b_k^r b_l^t a_1^+ a_1^-) =
  - gb_{+,k,r} · (a_1^- b_l^t)   [b_k^r swaps with a_1^+, remaining: b_l^t a_1^-]
  - gb_{-,k,r} · (a_1^+ b_l^t)   [b_k^r swaps with a_1^-]
  - gb_{+,l,t} · (a_1^- b_k^r)   [b_l^t swaps with a_1^+]
  - gb_{-,l,t} · (a_1^+ b_k^r)   [b_l^t swaps with a_1^-]
```

and κ-coeff(a_1^+ a_1^- b_k^r b_l^t) = 0 (already in PBW order). So:
```
γ([a_1^+ a_1^-], b_k^r b_l^t) = gb_{+,k,r}·E_eps1_dell_ms + gb_{-,k,r}·E_eps1_dell_ps
                                + gb_{+,l,t}·E_eps1_delk_mr + gb_{-,l,t}·E_eps1_delk_pr
```
(shorthand: E_eps1_dell_ms = a_1^- b_l^t, E_eps1_delk_pr = a_1^+ b_k^r, etc.)

H_1's b_1-part = b_1^+ b_1^-. Its contribution to γ(H_1, G_even_no_a1) also comes from [b_1^+ b_1^-, b_k^r b_l^t]_γ. Since both sides are b-bilinears, NO a_1 interaction occurs → κ-coeff = 0.

Therefore: **γ(H_1, G_even_no_a1) is determined entirely by the a_1-part of H_1.**

Concrete example (n=1), γ(H_1, E_2del1_p) where E_2del1_p = b_1^+ b_1^+:
```
b_k^r b_l^t = b_1^+ b_1^+ → k=1,r=+, l=1,t=+

γ(H_1, E_2del1_p) = gb_{+,1,+}·(a_1^- b_1^+) + gb_{-,1,+}·(a_1^+ b_1^+)
                   + gb_{+,1,+}·(a_1^- b_1^+) + gb_{-,1,+}·(a_1^+ b_1^+)
                 = 2·gb_{+,1,+}·E_eps1_del1_mp + 2·gb_{-,1,+}·E_eps1_del1_pp
```

Concrete example (n=1), γ(H_1, H_2) where H_2 = -b_1^+ b_1^- - 1/2:
Only the b_1^+ b_1^- term of H_2 contributes (the -1/2 constant has no oscillators):
```
b_k^r b_l^t = b_1^+ b_1^- → k=1,r=+, l=1,t=-

γ(H_1, H_2) = -[gb_{+,1,+}·(a_1^- b_1^-) + gb_{-,1,+}·(a_1^+ b_1^-)
               + gb_{+,1,-}·(a_1^- b_1^+) + gb_{-,1,-}·(a_1^+ b_1^+)]
            = -gb_{+,1,+}·E_eps1_del1_mm - gb_{-,1,+}·E_eps1_del1_pm
              - gb_{+,1,-}·E_eps1_del1_mp - gb_{-,1,-}·E_eps1_del1_pp
```
(the overall sign from the -1 coefficient in H_2 = -(b_1^+ b_1^-) - 1/2 applies)

**Formula for (G_even_no_a1, G_odd):**

G_even_no_a1 = Σ c_α b_k^r b_l^t (no a_1). G_odd = a_1^σ b_{j'}^{s'}.

Graded commutator: [G_even, G_odd] = G_even G_odd - G_odd G_even (since p(G_even)=0, p(G_odd)=1).

In G_even · G_odd = (b_k^r b_l^t)(a_1^σ b_{j'}^{s'}): the b's from G_even must pass a_1^σ.
In G_odd · G_even = (a_1^σ b_{j'}^{s'})(b_k^r b_l^t): a_1^σ is to the LEFT of all b's — no reordering needed, κ-coeff = 0.

For one term b_k^r b_l^t · a_1^σ b_{j'}^{s'}:
Each b moves rightward past a_1^σ (acquiring -gb_{σ,·,·}·κ):
```
κ-coeff(b_k^r b_l^t a_1^σ b_{j'}^{s'}) =
  -gb_{σ,k,r} · (b_l^t b_{j'}^{s'})   [b_k^r passes a_1^σ, remaining b_l^t b_{j'}^{s']
  -gb_{σ,l,t} · (b_k^r b_{j'}^{s'})   [b_l^t passes a_1^σ]
```
So:
```
γ(b_k^r b_l^t, a_1^σ b_{j'}^{s'}) = -gb_{σ,k,r}·(b_l^t b_{j'}^{s'}) - gb_{σ,l,t}·(b_k^r b_{j'}^{s'})
```

The products b_l^t b_{j'}^{s'} and b_k^r b_{j'}^{s'} are b-bilinears. They must be expressed in the basis using the generator realizations from Schema 1. Note that b_j^- b_{j'}^+ = δ_{jj'}·K + b_{j'}^+ b_j^- may produce the central element K (= scalar 1, stored with "c": "K" in JSON).

Concrete example (n=1), γ(E_2del1_p, E_eps1_del1_mp) where E_2del1_p = b_1^+ b_1^+ and E_eps1_del1_mp = a_1^- b_1^+:
```
b_k^r b_l^t = b_1^+ b_1^+, σ=-, j'=1, s'=+
γ(E_2del1_p, E_eps1_del1_mp) = -gb_{-,1,+}·(b_1^+ b_1^+) - gb_{-,1,+}·(b_1^+ b_1^+)
                               = -2·gb_{-,1,+}·E_2del1_p
```

Concrete example (n=1), γ(H_2, E_eps1_del1_pp) where H_2 = -b_1^+ b_1^- - 1/2 and E_eps1_del1_pp = a_1^+ b_1^+:
The -1/2 constant contributes nothing. For b_1^+ b_1^- term (c=-1):
```
b_k^r b_l^t = b_1^+ b_1^-, σ=+, j'=1, s'=+
γ(b_1^+ b_1^-, a_1^+ b_1^+) = -gb_{+,1,+}·(b_1^- b_1^+) - gb_{+,1,-}·(b_1^+ b_1^+)

b_1^- b_1^+ = K + b_1^+ b_1^-  (CCR: [b_1^-,b_1^+]=1, so b_1^- b_1^+ = 1·K + b_1^+ b_1^-)
            → expressed in basis: using H_2 = -b_1^+ b_1^- - 1/2, so b_1^+ b_1^- = -(H_2+1/2)
              and b_1^- b_1^+ = K + b_1^+ b_1^- = K - H_2 - 1/2

So γ(b_1^+ b_1^-, a_1^+ b_1^+) = -gb_{+,1,+}·(K - H_2 - 1/2) - gb_{+,1,-}·E_2del1_p

With c=-1 coefficient from H_2 = -b_1^+ b_1^- - 1/2:
γ(H_2, E_eps1_del1_pp) = gb_{+,1,+}·(K - H_2 - 1/2) + gb_{+,1,-}·E_2del1_p
```
This produces entries for c = "K", c = "H_2", and c = "E_2del1_p" in the JSON. The constant -1/2 · gb term is absorbed into the K entry (K = 1).
