### Gamma computation and sign-convention proposal (2026-10-07)

I reviewed the prescribed handover documents, all documents in `docs/math/`,
the three Schema 1 files, and the I04 verification record. The I04 schemas
provide the ordered generator realizations and basis needed for coefficient
extraction; the repository does not currently contain a Schema 2 example or a
more detailed Schema 2 field specification.

**Proposed `gb_matrix` order:** use two rows, `a_1_p` then `a_1_m`, and
`2n` columns in the order `b_1_p`, `b_1_m`, `b_2_p`, `b_2_m`, ...,
`b_n_p`, `b_n_m`. Thus each entry is named
`gb_{a_1_sign,b_j_sign}` and all `4n` entries are independent formal
parameters.

**Proposed computation:** represent each Schema 1 generator by its exact
oscillator polynomial, extend the normal-ordering rules by the mixed
relations, and compute each ordered graded bracket. Subtract the undeformed
bracket (equivalently, retain only terms linear in `κ`), use `κ^2=0`, and
extract the coefficient of each Schema 1 basis generator to form the
`(X,Y,Z,coeff)` gamma records. Combine duplicate records and omit zero
coefficients. The implementation should fail explicitly if a coefficient
cannot be expressed in the Schema 1 basis. Validation should check parameter
linearity, graded skew-symmetry, parity consistency, the first-order cocycle
identity, and that the zero-parameter bracket reproduces each I04 Schema 1
file.

**Sign choices for human approval:**

1. **Gram-entry convention (recommended):** `gb_{a,b}` denotes the ordered
   mixed Gram entry `(a_1^σ|b_j^s)`. Skew-supersymmetry gives
   `(b_j^s|a_1^σ)=-(a_1^σ|b_j^s)`, so use the reference relation literally:
   `[b_j^s,a_1^σ]=-gb_{a,b} κ`. With the stated generator order, store the
   resulting gamma coefficients without an extra global sign change.
2. **Bracket-coefficient convention:** define a newly named parameter as the
   coefficient of `[b_j^s,a_1^σ]` instead. Its relation has a plus sign, and
   it equals `-gb_{a,b}` from the reference convention; consequently all
   gamma coefficients change sign if the same parameter symbols are reused.
   This is a reparameterization, not a different deformation.
