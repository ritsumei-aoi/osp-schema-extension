## 5. Concrete discrepancy evidence

The non-triviality has **two independent sources**:

1. a **central (`K`) obstruction**
2. a **basis-valued residual obstruction**

### 5.1 Central (`K`) obstruction

The most decisive discrepancy is that Layer 3 `gb_one` contains non-zero `K` terms, while Layer 4 coboundaries are generated by maps

```text
f : g -> g
```

so every coboundary `δf` is `g`-valued and cannot produce `K`.

## 6. Mathematical reason for the discrepancies

The core mechanism is:

1. the deformation is generated by moving bosons past fermions
2. those exchanges produce both:
   - basis-generator corrections
   - constant (`K`) corrections
3. the coboundary operator built from an odd parity-reversing map `f : g -> g` can only produce `g`-valued outputs

Therefore:

- any non-zero `K` component is already fatal to triviality
- and in the computed `gb_one` cases, even the basis-valued remainder still fails the image test

## 7. General conjecture on the gb-parameter condition

### Data-supported conclusion for the tested ranks

For `n = 1, 2, 3`, the data supports the rule:

```text
The inhomogeneous deformation of C(n+1) is trivial if and only if all gb parameters vanish.
```

That is:

```text
trivial  <=>  gb_{sigma,j,s} = 0 for all sigma, j, s
```

### Why this is strongly supported

#### Sufficiency

If all `gb` parameters are zero, then:

- every evaluated gamma coefficient vanishes
- Layer 3 deformation is zero
- `f = 0` is a coboundary witness

#### Necessity (supported by the generated data)

For `n = 1, 2, 3`, every individual `gb` label appears **isolated** in at least one `K`-valued gamma coefficient.

Examples:

- `n = 1`: all four labels `gb_a1p_b1p`, `gb_a1p_b1m`, `gb_a1m_b1p`, `gb_a1m_b1m` appear alone in `K` terms
- `n = 2`: all eight labels appear alone in `K` terms
- `n = 3`: all twelve labels appear alone in `K` terms

Since no coboundary `δf` can produce `K`, any non-zero isolated `gb` coefficient immediately forces non-triviality.

So for the tested ranks, the necessary condition collapses to:

```text
all gb parameters must be zero
```

### General conjecture beyond the tested ranks

I conjecture the same rule holds for all `n >= 1`:

```text
The C(n+1) inhomogeneous deformation is trivial exactly for the zero gb profile.
```

Equivalently:

```text
any non-zero gb assignment produces a non-trivial deformation.
```

The reason is that the same oscillator mechanism that generated isolated `K` obstructions for `n = 1, 2, 3` appears structurally stable in higher rank.
