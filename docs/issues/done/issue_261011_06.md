### Evaluation Framework

Schema 3 substitutes concrete values into the 4n symbolic gb parameters of Schema 2.

The evaluated deformed bracket is:
```
[X, Y]_γ|_{gb=assigned} = [X,Y]_0 + κ · Σ_{gb_label} gb_val · γ(X,Y,gb_label)
```

- **g-part** `[X,Y]_0`: from Schema 1 `structure_constants` (unchanged)
- **κ-part** `κ · Σ gb_val · γ(...)`: from Schema 2 `gamma` entries after substitution

**Counts for reference**:
| n | gb params | γ pairs (non-zero) | g pairs (non-zero) |
|---|---|---|---|
| 1 | 4 | 29 | 19 |
| 2 | 8 | ~100 | ~55 |
| 3 | 12 | ~260 | ~120 |

### Proposed gb Sign Profiles

The 4n gb parameters for C(n+1) are `gb_a1{σ}_b{k}{s}` where σ ∈ {p,m}, k = 1,...,n, s ∈ {p,m}. Three natural profiles are proposed.

#### Profile A — All-Ones (Recommended)

All 4n parameters = 1.

```
gb_a1p_b{k}p = 1,  gb_a1p_b{k}m = 1
gb_a1m_b{k}p = 1,  gb_a1m_b{k}m = 1    for all k
```

**Sample evaluated κ-bracket (n=1)**:
```
κ·γ(H_1, H_2)             = κ·{−E_eps1_del1_pp − E_eps1_del1_pm − E_eps1_del1_mp − E_eps1_del1_mm}
κ·γ(H_1, E_eps1_del1_pp)  = κ·{−2·E_2del1_p + H_1 + 2·H_2}
κ·γ(H_1, E_eps1_del1_pm)  = κ·{H_1 + 2·H_2 + K − 2·E_2del1_m}
```

This is the standard reference profile: the simplest assignment that activates all deformation directions simultaneously and gives rational (integer) κ-part coefficients. File suffix: `all1`.

---

#### Profile B — Fermionic-Sign

Sign determined by the fermionic oscillator label: +1 for a_1^+, −1 for a_1^−.

```
gb_a1p_b{k}p = +1,  gb_a1p_b{k}m = +1
gb_a1m_b{k}p = −1,  gb_a1m_b{k}m = −1    for all k
```

This profile is antisymmetric in the fermionic oscillator sign. It separates the a_1^+ deformation sector from the a_1^− sector and is natural if the two fermionic directions are treated as conjugate to each other. File suffix: `a1sign`.

---

#### Profile C — Product-Sign

Sign = (σ-sign) × (s-sign), where p → +1, m → −1.

```
gb_a1p_b{k}p = +1,  gb_a1p_b{k}m = −1
gb_a1m_b{k}p = −1,  gb_a1m_b{k}m = +1    for all k
```

This profile is symmetric in the exchange (σ ↔ s) and is related to the skew-supersymmetric form (a_1^σ | b_k^s). File suffix: `prodsign`.

### Proposed Schema 3 JSON Format

File naming: `data/C_{n}_evaluated_{profile}.json`

```json
{
  "schema_version": "5.0",
  "algebra": { "family": "C", "m": 1, "n": 1, ... },
  "gb_profile": {
    "name": "all_ones",
    "file_suffix": "all1",
    "assignments": {
      "gb_a1p_b1p": "1",
      "gb_a1p_b1m": "1",
      "gb_a1m_b1p": "1",
      "gb_a1m_b1m": "1"
    }
  },
  "evaluated_brackets": [
    {
      "X": "H_1",
      "Y": "E_eps1_del1_pp",
      "g_part":    [{"Z": "E_eps1_del1_pp", "coeff": "2"}],
      "kappa_part": [{"Z": "E_2del1_p", "coeff": "-2"},
                     {"Z": "H_1",       "coeff": "1"},
                     {"Z": "H_2",       "coeff": "2"}]
    }
  ],
  "metadata": { ... }
}
```

Entries are included for all pairs (X, Y) that have a non-zero g-part OR non-zero κ-part (or both). The `g_part` and `kappa_part` lists may each be empty `[]` if that layer is zero.
