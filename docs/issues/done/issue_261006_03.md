### Key Design Decisions

**Oscillator index convention** (for given bosonic rank n):
```
0       : a1+  (fermionic creation, parity 1)
1..n    : b1+..bn+  (bosonic creation, parity 0)
n+1     : a1-  (fermionic annihilation, parity 1)
n+2..2n+1 : b1-..bn-  (bosonic annihilation, parity 0)
```
Normal order: smaller index first (creation before annihilation).

**Operator representation**: Each generator is a `dict {monomial_tuple: Fraction}`. Monomials are tuples of oscillator indices in normal order.

**Normal ordering algorithm**: Recursive bubble-sort using CCR/CAR:
- a1- · a1+ = −a1+ · a1− + 1  (anticommutation)
- bk− · bk+ = bk+ · bk− + 1  (commutation, same k)
- Mixed pairs commute with coefficient 0

**Critical bug discovered and fixed**: The early fermionic nilpotency check (`if seq.count(0) > 1: return`) was applied *before* contractions, incorrectly zeroing sequences like `[a1+, a1−, a1+, b1+]` which normal-order to `a1+ b1+` via contraction. The fix: apply nilpotency only on *already normal-ordered* sequences.

**Graded bracket**: `[X, Y} = X·Y − (−1)^{p(X)p(Y)} Y·X`.

**Decomposition into basis**: After computing the bracket, result is expressed as a linear combination of basis generators by matching monomials. Cartan coefficients are recovered via the tridiagonal structure:
- Scalar term `()` → coefficient of H_{n+1} (since H_{n+1} contributes −1/2)
- Monomial `(0, n+1)` = a1+a1− → coefficient of H_1 (unique to H_1)
- Monomials `(k−1, n+k)` = b{k−1}+b{k−1}− → recover H_k via recurrence (k=2..n)

### Proposed Generator Script (`src/build_C_structure_constants.py`)

```python
"""
C(n+1) = osp(2|2n) structure constant generator.
Computes all non-zero graded brackets [X, Y} in the oscillator realization
and outputs Schema 1 JSON files: C_{n}_structure.json for n=1,2,3.
"""

from fractions import Fraction
from collections import defaultdict
import json
from datetime import date
import os

def osc_parity(idx, n):
    return 1 if (idx == 0 or idx == n + 1) else 0

def contraction(a, b, n):
    if a == n + 1 and b == 0:
        return Fraction(1)
    if n + 2 <= a <= 2 * n + 1 and 1 <= b <= n:
        if a - (n + 1) == b:
            return Fraction(1)
    return Fraction(0)

def normal_order_seq(seq, n, coeff, result):
    for i in range(len(seq) - 1):
        a, b = seq[i], seq[i + 1]
        if a > b:
            grade_sign = Fraction((-1) ** (osc_parity(a, n) * osc_parity(b, n)))
            normal_order_seq(seq[:i] + [b, a] + seq[i + 2:], n, coeff * grade_sign, result)
            c = contraction(a, b, n)
            if c:
                normal_order_seq(seq[:i] + seq[i + 2:], n, coeff * c, result)
            return
    # In normal order — apply nilpotency here only
    if seq.count(0) > 1 or seq.count(n + 1) > 1:
        return
    key = tuple(seq)
    result[key] = result.get(key, Fraction(0)) + coeff

def op_mul(op1, op2, n):
    result = {}
    for m1, c1 in op1.items():
        for m2, c2 in op2.items():
            normal_order_seq(list(m1) + list(m2), n, c1 * c2, result)
    return {m: c for m, c in result.items() if c != 0}

def op_add(op1, op2):
    result = dict(op1)
    for m, c in op2.items():
        result[m] = result.get(m, Fraction(0)) + c
    return {m: c for m, c in result.items() if c != 0}

def graded_bracket(X, Xp, Y, Yp, n):
    sign = Fraction((-1) ** (Xp * Yp))
    return op_add(op_mul(X, Y, n), {m: -sign * c for m, c in op_mul(Y, X, n).items()})

def build_basis(n):
    odd = []
    for k in range(1, n + 1):
        odd += [f"E_eps1_del{k}_pp", f"E_eps1_del{k}_pm"]
    for k in range(1, n + 1):
        odd += [f"E_eps1_del{k}_mp", f"E_eps1_del{k}_mm"]
    even = [f"H_{k}" for k in range(1, n + 2)]
    for k in range(1, n + 1):
        even.append(f"E_2del{k}_p")
    for i in range(1, n + 1):
        for j in range(i + 1, n + 1):
            even.append(f"E_del{i}_del{j}_pp")
    for k in range(1, n + 1):
        even.append(f"E_2del{k}_m")
    for i in range(1, n + 1):
        for j in range(i + 1, n + 1):
            even.append(f"E_del{i}_del{j}_mm")
    for i in range(1, n + 1):
        for j in range(i + 1, n + 1):
            even += [f"E_del{i}_del{j}_pm", f"E_del{i}_del{j}_mp"]
    return odd, even

def label_parity(label):
    return 1 if label.startswith("E_eps1") else 0
```
