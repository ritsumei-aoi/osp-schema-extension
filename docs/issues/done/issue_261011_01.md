## Analysis: C(n+1) = osp(2|2n) Structure

### Mathematical Foundation

From `docs/math/Cn1_definition.md` (Frappat et al.):

**Root system** (in terms of orthogonal vectors ε [fermionic] and δ₁,…,δₙ [bosonic]):

| Parity | Roots |
|---|---|
| Even Δ₀ | ±2δ_k (k=1,…,n) and ±(δᵢ ± δⱼ) (i<j) |
| Odd Δ₁ | ±ε ± δ_k (k=1,…,n) |

**Oscillator realization**:
- Standard fermionic pair: a₁⁺, a₁⁻ with {a₁⁻, a₁⁺} = 1 (CAR)
- Bosonic oscillators: b_k⁺, b_k⁻ for k=1,…,n with [b_k⁻, b_l⁺] = δ_{kl} (CCR)

**All root generators** (Frappat, Table 2):

| Root | Oscillator realization |
|---|---|
| ε + δ_k | a₁⁺ b_k⁺ |
| ε − δ_k | a₁⁺ b_k⁻ |
| −ε + δ_k | a₁⁻ b_k⁺ |
| −ε − δ_k | a₁⁻ b_k⁻ |
| δᵢ + δⱼ (i<j) | b_i⁺ b_j⁺ |
| δᵢ − δⱼ (i<j) | b_i⁺ b_j⁻ |
| −(δᵢ − δⱼ) (i<j) | b_i⁻ b_j⁺ |
| −(δᵢ + δⱼ) (i<j) | b_i⁻ b_j⁻ |
| 2δ_k | (1/2)(b_k⁺)² |
| −2δ_k | (1/2)(b_k⁻)² |

**Cartan generators** (n+1 total, from simple root decomposition α₁=ε−δ₁, αₖ=δ_{k−1}−δ_k, α_{n+1}=2δ_n):

| Generator | Realization | Role |
|---|---|---|
| H_1 | a₁⁺ a₁⁻ + b₁⁺ b₁⁻ | so(2) × sp(2n) coupling |
| H_k (2≤k≤n) | b_{k−1}⁺ b_{k−1}⁻ − b_k⁺ b_k⁻ | sp(2n) Cartan |
| H_{n+1} | −b_n⁺ b_n⁻ − 1/2 | terminal sp(2n) Cartan |

## 3. PBW Ordering Proposals

**[HUMAN SELECTION REQUIRED]**

The global structure is fixed:
```
κ  <  [odd block]  <  [even block]
```
(matching B(0,n) convention; κ is the nilpotent central extension symbol)

Within **even block**, the ordering follows B(0,n) convention:
```
Cartans (H_1,…,H_{n+1}) < positive-type (+) < negative-type (−) < mixed (pm, mp)
```

The choice to be made concerns **within the odd block**, where C(n+1) has 4n generators (vs. 2n in B(0,n)):

---

### Option A: Group by ε-sign (fermionic-oscillator-first ordering)

Rationale: group by which fermionic oscillator appears (a₁⁺ first, a₁⁻ second), then within each fermionic group order by bosonic sign (b⁺ before b⁻), then by bosonic index k.

```
[ε>0 block] E_eps1_del1_pp, E_eps1_del2_pp, …, E_eps1_deln_pp,
             E_eps1_del1_pm, E_eps1_del2_pm, …, E_eps1_deln_pm,
[ε<0 block] E_eps1_del1_mp, E_eps1_del2_mp, …, E_eps1_deln_mp,
             E_eps1_del1_mm, E_eps1_del2_mm, …, E_eps1_deln_mm
```

Full PBW for C(3), n=2 (illustrative):
```
κ
< E_eps1_del1_pp, E_eps1_del2_pp,
  E_eps1_del1_pm, E_eps1_del2_pm,
  E_eps1_del1_mp, E_eps1_del2_mp,
  E_eps1_del1_mm, E_eps1_del2_mm
< H_1, H_2, H_3,
  E_2del1_p, E_2del2_p, E_del1_del2_pp,
  E_2del1_m, E_2del2_m, E_del1_del2_mm,
  E_del1_del2_pm, E_del1_del2_mp
```

**Advantage**: Reflects the oscillator algebra structure—generators are grouped by which creation/annihilation operator (a₁±) they contain. Natural for computing structure constants programmatically (separate a₁⁺ and a₁⁻ sectors first).

---

### Option B: Group by bosonic index (root-system-first ordering)

Rationale: group all 4 generators associated with a given bosonic mode δ_k together (analogous to how B(0,n) pairs E_del{k}_p and E_del{k}_m), then within each group order by ε-sign.

```
[k=1 block] E_eps1_del1_pp, E_eps1_del1_pm,
             E_eps1_del1_mp, E_eps1_del1_mm,
[k=2 block] E_eps1_del2_pp, E_eps1_del2_pm,
             E_eps1_del2_mp, E_eps1_del2_mm,
             …
[k=n block] E_eps1_deln_pp, E_eps1_deln_pm,
             E_eps1_deln_mp, E_eps1_deln_mm
```

Full PBW for C(3), n=2 (illustrative):
```
κ
< E_eps1_del1_pp, E_eps1_del1_pm, E_eps1_del1_mp, E_eps1_del1_mm,
  E_eps1_del2_pp, E_eps1_del2_pm, E_eps1_del2_mp, E_eps1_del2_mm
< H_1, H_2, H_3,
  E_2del1_p, E_2del2_p, E_del1_del2_pp,
  E_2del1_m, E_2del2_m, E_del1_del2_mm,
  E_del1_del2_pm, E_del1_del2_mp
```

**Advantage**: Preserves the B(0,n) pattern where the k-th bosonic mode contributes a contiguous block of odd generators. Easier for humans to verify root-by-root correspondence and for comparing C(n+1) with B(0,n) schemas.
