### 3. PBW Ordering — **Human Selection Required**

The following two options are proposed. Both respect the graded Lie superalgebra structure; they differ in how odd generators are interleaved with even ones.

---

#### **Option A: Parity-First (direct extension of B(0,n) convention)**

All odd generators come before all even generators, matching the B(0,n) convention `κ < [odd] < [even]`. Within each parity block, the internal ordering is:
- **Odd**: ε-positive generators (pp, pm) before ε-negative (mp, mm), indexed by k=1,...,n
- **Even**: Cartans (H_1,...,H_{n+1}), then positive even roots (by height, bosonic creation before mixed), then negative even roots

**Rationale**: Maximal structural continuity with the existing B(0,n) schema. Makes automated refactoring of existing code simpler (only the odd sector changes shape).

Example for C(3) (n=2):
```
odd:  E_eps1_del1_pp, E_eps1_del1_pm, E_eps1_del2_pp, E_eps1_del2_pm,
      E_eps1_del1_mp, E_eps1_del1_mm, E_eps1_del2_mp, E_eps1_del2_mm
even: H_1, H_2, H_3,
      E_2del1_p, E_2del2_p, E_del1_del2_pp,
      E_2del1_m, E_2del2_m, E_del1_del2_mm,
      E_del1_del2_pm, E_del1_del2_mp
```

---

#### **Option B: Root-Height Ordering (triangular decomposition)**

Generators are ordered by root height: positive roots (odd then even, by height) → Cartan → negative roots (even then odd, by height). This follows the standard triangular decomposition $\mathfrak{g} = \mathfrak{n}^- \oplus \mathfrak{h} \oplus \mathfrak{n}^+$ strictly.

**Rationale**: More natural for computing structure constants in the adjoint action and for representation-theoretic computations. Fermions at the "extremes" of the ordering.

Example for C(3) (n=2):
```
pos odd:  E_eps1_del1_pp, E_eps1_del2_pp, E_eps1_del1_pm, E_eps1_del2_pm
pos even: E_2del1_p, E_2del2_p, E_del1_del2_pp, E_del1_del2_pm
cartan:   H_1, H_2, H_3
neg even: E_del1_del2_mp, E_del1_del2_mm, E_2del1_m, E_2del2_m
neg odd:  E_eps1_del1_mp, E_eps1_del2_mp, E_eps1_del1_mm, E_eps1_del2_mm
```
