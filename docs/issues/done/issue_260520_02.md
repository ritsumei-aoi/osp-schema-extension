## Proposal: Schema 1 v5.0 Field Definitions for C(n+1)

The proposed content for `docs/json_schema_specification.md` is given below.
All JSON blocks use **n = 1 (C(2))** as a concrete example; the general pattern for n > 1 is stated alongside each block.

---

### Requirement 1 — `algebra` field

```json
{
  "family": "C",
  "m": 1,
  "n": 1,
  "cartan_type": "C(2)",
  "alternative_notation": {
    "osp": "osp(2|2)",
    "dimension_formula": "osp(2m|2n) with m=1"
  },
  "dimension": {
    "total": 8,
    "even": 4,
    "odd": 4
  }
}
```

**Dimension formulas** (C(n+1)): even = 2n²+n+1, odd = 4n, total = 2n²+5n+1.

| n | even | odd | total | Algebra |
|---|---|---|---|---|
| 1 | 4 | 4 | 8 | C(2) = osp(2\|2) |
| 2 | 11 | 8 | 19 | C(3) = osp(2\|4) |
| 3 | 22 | 12 | 34 | C(4) = osp(2\|6) |

**Compatibility note**: same top-level key structure as B(m,n); only `family`, `m`, `cartan_type`, `osp`, `dimension_formula`, and `dimension` values differ.

---

### Requirement 2 — `oscillator_generators` field

The `supplementary_fermion` key is removed and replaced by a `fermions` key.

```json
{
  "fermions": {
    "count": 2,
    "labels": ["a_1_p", "a_1_m"],
    "parity": 1,
    "description": "Standard fermionic pair a_1^± satisfying CAR: {a_1^-, a_1^+} = 1"
  },
  "bosons": {
    "count": 2,
    "n": 1,
    "labels": ["b_1_p", "b_1_m"],
    "description": "Bosonic oscillators b_k^± with k = 1,...,n"
  }
}
```

**General pattern** (arbitrary n): `fermions.count = 2` (always), `fermions.labels = ["a_1_p", "a_1_m"]`; `bosons.count = 2n`, `bosons.labels = ["b_1_p", "b_1_m", ..., "b_n_p", "b_n_m"]`.

**Compatibility note**: key name change `supplementary_fermion` → `fermions`; the `bosons` sub-object is structurally identical to B(m,n).

---

### Requirement 3 — `oscillator_relations` field

The `supplementary_fermion_relation` key is replaced by `standard_fermion_anticommutators`.

```json
{
  "standard_fermion_anticommutators": {
    "description": "Canonical anticommutation relations for the standard fermionic pair",
    "relations": {
      "cross":      "{a_1^-, a_1^+} = 1",
      "same_plus":  "{a_1^+, a_1^+} = 0",
      "same_minus": "{a_1^-, a_1^-} = 0"
    }
  },
  "bosonic_commutators": {
    "description": "Canonical commutation relations for bosonic oscillators",
    "relations": {
      "same_type":     "[b_i^±, b_j^±] = 0  for all i, j",
      "conjugate_pair": "[b_i^-, b_j^+] = δ_{ij}"
    }
  },
  "mixed_commutators": {
    "boson_fermion": "[b_i^±, a_1^±] = 0"
  }
}
```

**Compatibility note**: structurally parallel to B(m,n); only the fermion sub-object key and content differ.

---

### Requirement 4 — `central_elements` field (new top-level key)

This key is new relative to the B(m,n) schema (or it existed but was not fully specified).

```json
{
  "kappa": {
    "label": "kappa",
    "parity": 1,
    "relation": "kappa^2 = 0",
    "description": "Odd central element of the Bakalov-Sullivan extension. Appears first in the PBW ordering."
  },
  "K": {
    "label": "K",
    "parity": 0,
    "relation": "K = 1",
    "description": "Even central identity element. Identified with the scalar 1 in all current applications; excluded from PBW basis and structure constant computations."
  }
}
```

**Compatibility note**: identical for B(m,n) and C(n+1); this key can be standardized across both families.

---

### Requirement 5 — File naming convention

Following the convention already established in `handover/notation.md` and `docs/math/B0n_schema_v5.md`:

| Layer | File pattern | Example: C(2), n=1 | Example: C(3), n=2 | Example: C(4), n=3 |
|---|---|---|---|---|
| Schema 1 | `C_{n}_structure.json` | `C_1_structure.json` | `C_2_structure.json` | `C_3_structure.json` |
| Schema 2 | `C_{n}_gamma.json` | `C_1_gamma.json` | `C_2_gamma.json` | `C_3_gamma.json` |
| Schema 3 | `C_{n}_evaluated_{gb}.json` | `C_1_evaluated_gb0.json` | `C_2_evaluated_gb0.json` | — |
| Schema 4 | `C_{n}_coboundary_{gb}.json` | `C_1_coboundary_gb0.json` | `C_2_coboundary_gb0.json` | — |

Note: `n` is the **bosonic rank** (number of bosonic oscillator pairs), not the Cartan index of the algebra name.

```json
}
```

#### `parity` field — C(2), n=1

```json
{
  "H_1": 0, "H_2": 0,
  "E_2del1_p": 0, "E_2del1_m": 0,
  "E_eps1_del1_pp": 1, "E_eps1_del1_pm": 1,
  "E_eps1_del1_mp": 1, "E_eps1_del1_mm": 1
}
```

#### `generator_realization` field — C(2), n=1

Oscillator PBW ordering: `a_1_p, a_1_m, b_1_p, b_1_m` (a_1_p < a_1_m < b_k_p < b_k_m).

```json
{
  "description": "Standard form with PBW ordering of oscillators",
  "ordering": "a_1_p, a_1_m, b_1_p, b_1_m",
  "realizations": {
    "H_1": {
      "standard_form": [
        {"words": ["a_1_p", "a_1_m"], "coeff": "1"},
        {"words": ["b_1_p", "b_1_m"], "coeff": "1"}
      ],
      "frappat_form": "a_1^+ a_1^- + b_1^+ b_1^-",
      "parity": 0
    },
    "H_2": {
      "standard_form": [
        {"words": ["b_1_p", "b_1_m"], "coeff": "-1"},
        {"words": [], "coeff": "-1/2"}
      ],
      "frappat_form": "-b_1^+ b_1^- - 1/2",
      "parity": 0,
      "note": "Terminal Cartan (k = n+1); constant -1/2 is intrinsic to the Frappat formula"
    },
    "E_eps1_del1_pp": {
      "standard_form": [{"words": ["a_1_p", "b_1_p"], "coeff": "1"}],
      "frappat_form": "a_1^+ b_1^+",
      "parity": 1
    },
    "E_eps1_del1_pm": {
      "standard_form": [{"words": ["a_1_p", "b_1_m"], "coeff": "1"}],
      "frappat_form": "a_1^+ b_1^-",
      "parity": 1
    },
    "E_eps1_del1_mp": {
      "standard_form": [{"words": ["a_1_m", "b_1_p"], "coeff": "1"}],
      "frappat_form": "a_1^- b_1^+",
      "parity": 1
    },
    "E_eps1_del1_mm": {
      "standard_form": [{"words": ["a_1_m", "b_1_m"], "coeff": "1"}],
      "frappat_form": "a_1^- b_1^-",
      "parity": 1
    },
    "E_2del1_p": {
      "standard_form": [{"words": ["b_1_p", "b_1_p"], "coeff": "1"}],
      "frappat_form": "(b_1^+)^2",
      "parity": 0
    },
    "E_2del1_m": {
      "standard_form": [{"words": ["b_1_m", "b_1_m"], "coeff": "1"}],
      "frappat_form": "(b_1^-)^2",
      "parity": 0
    }
  }
}
```

> **Note on E_2del{k} normalization**: The Frappat formula includes a factor of 1/2, i.e., E_{2δ_k} = (1/2)(b_k^+)^2. The convention adopted here (following `handover/notation.md`) absorbs this factor into the normalization, giving E_2del{k}_p = (b_k^+)^2 with coefficient "1".

### Summary: B(m,n) ↔ C(n+1) Compatibility Map

| Schema 1 key | B(m,n) | C(n+1) | Change |
|---|---|---|---|
| `schema_version` | `"5.0"` | `"5.0"` | None |
| `algebra.family` | `"B"` | `"C"` | Value |
| `algebra.m` | `0` | `1` | Value |
| `algebra.dimension_formula` | `osp(2m+1\|2n)` | `osp(2m\|2n)` | Value |
| `oscillator_generators` | key: `supplementary_fermion` | key: `fermions` | Key rename + content |
| `oscillator_relations` | key: `supplementary_fermion_relation` | key: `standard_fermion_anticommutators` | Key rename + content |
| `central_elements` | not in base B schema | new top-level key | Addition |
| `basis.odd` count | 2n generators | 4n generators | Count + labels |
| `basis.odd` labels | `E_del{k}_p/m` | `E_eps1_del{k}_pp/pm/mp/mm` | Labels |
| `parity` | odd: `E_del{k}_p/m` | odd: `E_eps1_del{k}_{...}` | Labels |
| `generator_realization.ordering` | starts with `a_0` | starts with `a_1_p, a_1_m` | First 1–2 entries |
| `structure_constants` | computed for B | computed for C | Values |
| `metadata.generated_by` | `build_B_structure_constants.py` | `build_C_structure_constants.py` | Value |
