## AI Agent Proposal (2026-10-06)

### 1. Method for Computing Gamma Coefficients

**Core idea**: Modify the oscillator normal-ordering algorithm from Schema 1 to track `κ`-valued contractions separately (first-order in `gb`). For each pair of basis elements `(X, Y)`, the bracket `[X, Y]` in the deformed oscillator algebra yields:

```
[X, Y]_γ = [X, Y]_0 + κ · γ(X, Y)
```

The `γ(X, Y)` term arises when, during normal ordering of the oscillator word `X·Y - (-1)^{p(X)p(Y)} Y·X`, a bosonic oscillator `bj^s` is commuted past a fermionic oscillator `a1^σ`. At this step the deformed relation `[bj^s, a1^σ] = −gb_{σ,j,s}·κ` inserts a `κ`-term. The remaining monomial after the `κ`-insertion is then decomposed in the basis of `C(n+1)` to yield `γ(X,Y)`.

**Implementation strategy**: Introduce a "dual" tracking mode in the normal-ordering function:
- Ordinary mode: collects the `g`-valued part → Schema 1 structure constants (already done).
- Kappa mode: collects the `κ·g`-valued part → Schema 2 gamma coefficients.

The kappa-mode contraction table (derived from `[bj^s, a1^σ] = −gb_{σ,j,s}·κ`) is:

| Commutation event | oscillator index pair (a > b) | gb key | contraction |
|---|---|---|---|
| `bj^+` moves past `a1^+` | `(j, 0)`, j ∈ 1..n | `gb_{+,j,+}` | `−gb_{+,j,+}` |
| `bj^-` moves past `a1^+` | `(n+1+j, 0)` | `gb_{+,j,−}` | `−gb_{+,j,−}` |
| `a1^-` moves past `bj^+` | `(n+1, j)` | `gb_{−,j,+}` | `+gb_{−,j,+}` |
| `bj^-` moves past `a1^-` | `(n+1+j, n+1)` | `gb_{−,j,−}` | `−gb_{−,j,−}` |

**Note on case 3 sign**: The positive sign in row 3 comes from `[a1^-, bj^+] = −[bj^+, a1^-] = gb_{−,j,+}·κ` (antisymmetry of the bracket flips the sign of `[bj^s, a1^σ]`).

**Which brackets have non-zero γ**: Only those where a bosonic oscillator (from one generator) must commute past a fermionic oscillator (from the other). Concretely:
- `γ(odd, odd)` can be non-zero (both generators carry `a1^±` and `bk^±`).
- `γ(odd, even)` can be non-zero only if the even generator carries `a1^±` — only `H_1 = a1^+a1^- + b1^+b1^-` qualifies.
- `γ(even, even)` = 0 always (no fermionic oscillators in even generators other than `H_1`, but `H_1` carries no free bosonic oscillator that would cross a fermionic one from the other generator).

**Completeness**: The gamma coefficients are linear in the `4n` gb-parameters `{gb_{σ,j,s}}`. Each nonzero `γ(X,Y)` is a sum of terms `c_{σ,j,s} · gb_{σ,j,s} · Z` where `Z` is a basis element of `C(n+1)`.

### 2. Sign Convention Options (Gram Matrix)

The document `C_inhomogeneous_definition.md` defines:
```
[bj^s, a1^σ] = −gb_{σ,j,s} · κ
```

There is a legitimate ambiguity in whether the **left-actor** is bosonic or fermionic. This yields two concrete options:

#### Option A (as written in the math document — bosonic on the left):
```
[bj^s, a1^σ] = −gb_{σ,j,s} · κ
```
- `bj^+ a1^σ = a1^σ bj^+ − gb_{σ,j,+} · κ`
- `bj^- a1^σ = a1^σ bj^- − gb_{σ,j,−} · κ`
- Contraction table as in the table above.
- Result: `γ(X,Y)` has the signs shown above.

Concrete example for n=1: `γ(E_eps1_del1_pm, E_eps1_del1_mm)`:
```
= −gb_{−,1,−} · E_eps1_del1_pm − gb_{+,1,−} · E_eps1_del1_mm
```

#### Option B (fermionic on the left — equivalent to negating all gb):
```
[a1^σ, bj^s] = −gb_{σ,j,s} · κ
```
(equivalently: `[bj^s, a1^σ] = +gb_{σ,j,s} · κ`)
- All contraction signs are flipped relative to Option A.
- Result: `γ(X,Y)` has ALL signs flipped compared to Option A.

Concrete example for n=1: `γ(E_eps1_del1_pm, E_eps1_del1_mm)`:
```
= +gb_{−,1,−} · E_eps1_del1_pm + gb_{+,1,−} · E_eps1_del1_mm
```

**My recommendation**: **Option A**, because it matches the defining document `C_inhomogeneous_definition.md` exactly and provides continuity with the mathematical derivation.

### 3. Proposed Schema 2 JSON Format

The `inhomogeneous_deformation` field to be added to Schema 2 JSON:

```json
{
  "schema_version": "5.0",
  "algebra": { ... },
  "inhomogeneous_deformation": {
    "deformation_type": "gb",
    "gb_matrix": {
      "description": "Deformation parameters indexed by (sigma, j, s); gb_{sigma, j, s} is the coefficient in [bj^s, a1^sigma] = -gb_{sigma,j,s} * kappa (Option A convention).",
      "size": [2, "2n"],
      "parameters": [
        {"label": "gb_pp_1", "sigma": "+", "j": 1, "s": "+"},
        {"label": "gb_pm_1", "sigma": "+", "j": 1, "s": "-"},
        {"label": "gb_mp_1", "sigma": "-", "j": 1, "s": "+"},
        {"label": "gb_mm_1", "sigma": "-", "j": 1, "s": "-"}
      ]
    },
    "sign_convention": "Option_A",
    "defining_relation": "[bj^s, a1^sigma] = -gb_{sigma,j,s} * kappa",
    "gamma_coefficients": [
      {
        "X": "E_eps1_del1_pm",
        "Y": "E_eps1_del1_mm",
        "gb_key": "gb_mm_1",
        "Z": "E_eps1_del1_pm",
        "coeff": "-1"
      },
      {
        "X": "E_eps1_del1_pm",
        "Y": "E_eps1_del1_mm",
        "gb_key": "gb_pm_1",
        "Z": "E_eps1_del1_mm",
        "coeff": "-1"
      }
    ]
  }
}
```

The `gamma_coefficients` list records all triples `(X, Y, gb_key, Z, coeff)` such that:
```
γ(X, Y) = Σ_{gb_key, Z} coeff · gb_key · Z   (summed over all records with this X, Y)
```
