#### Analysis & Proposal (2026-05-18)

Based on `docs/math/C_inhomogeneous_definition.md`, I have analyzed the inhomogeneous deformation for $C(n+1)$ and formulated the following implementation plan.

### 1. `gb_matrix` Definition
The deformation is defined by $4n$ parity-1 parameters. I propose the following label convention for clarity:
`gb_a1{sigma}_b{j}{s}` where $\sigma, s \in \{p, m\}$ and $j \in \{1, \dots, n\}$.
Example for $n=1$: `gb_a1p_b1p`, `gb_a1p_b1m`, `gb_a1m_b1p`, `gb_a1m_b1m`.

### 2. Gamma Computation Method
I will implement a new script `src/C_gamma_generators.py` that extends the oscillator algebra engine developed in I03:
- **Deformed Exchange Relation**: Implement $[b_j^s, a_1^\sigma] = - \mathrm{gb}_{\sigma, j, s} \kappa$ where $\kappa^2=0$ and $\kappa$ is central.
- **Evaluation**: For each pair of generators $(X, Y)$, compute the full commutator $[X, Y]_\gamma$ in the oscillator representation.
- **Extraction**: Isolate terms linear in $\kappa$ and linear in exactly one $\mathrm{gb}$ parameter.
- **Decomposition**: Project the resulting oscillator expression onto the Schema 1 basis to find $\gamma_{abc}$ such that $\gamma(X, Y) = \sum_{c, \text{param}} \text{coeff}_{abc, \text{param}} \cdot \text{param} \cdot Z_c$.

### 3. Sign Convention (Mandatory Choice)
I propose to follow the definition in `C_inhomogeneous_definition.md` strictly:
**Option A (Recommended)**: $[b_j^s, a_1^\sigma] = - \mathrm{gb}_{\sigma, j, s} \kappa$.
This ensures consistency with the provided mathematical grounding.

### 4. Schema 2 JSON Design
I will add a top-level `inhomogeneous_deformation` key:
- `parameters`: List of $4n$ gb labels.
- `exchange_relations`: Explicit definition of the oscillator-level deformation.
- `gamma_structure`: List of non-zero $\gamma(X, Y)$ components.
