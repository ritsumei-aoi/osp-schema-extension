### Mathematical Setup

An **odd linear map** $f: \mathfrak{g} \to \mathfrak{g}$ reverses parity. For $C(n+1)$ with bases:

- $\mathfrak{g}_{\bar{0}}$ (even, dim $= 2n^2+n+1$): Cartan $H_k$, roots $E_{\pm 2\delta_k}$, $E_{\pm(\delta_i \pm \delta_j)}$
- $\mathfrak{g}_{\bar{1}}$ (odd, dim $= 4n$): roots $E_{\pm\varepsilon \pm \delta_k}$

The most general $f$ has parameters $\phi_{kl}$ (odd $\to$ even part) and $\psi_{kl}$ (even $\to$ odd part):

$$f(Z_l^{(\bar{0})}) = \sum_k \psi_{kl}\, Z_k^{(\bar{1})}, \qquad f(Z_l^{(\bar{1})}) = \sum_k \phi_{kl}\, Z_k^{(\bar{0})}$$

Total free parameters: $4n(2n^2+n+1) + (2n^2+n+1)(4n)$ — symmetric count.

The coboundary is computed from:
$$(\delta f)(X,Y) = (-1)^{p(X)}[X,f(Y)] - (-1)^{(p(X)+1)p(Y)}[Y,f(X)] - f([X,Y])$$

### Proposed Options for $f$

I propose the following two options for the parameterization of $f$. Please select one.

---

#### Option A: Fully General Parameterization

Keep **all** $\phi_{kl}$ and $\psi_{kl}$ as free parameters.

Schema 4 stores the coboundary as a **linear system** in these parameters: for each basis pair $(X, Y)$, for each output generator $Z$:

$$(\delta f)(X,Y)|_Z = \sum_{k,l} c^{XYZ}_{kl}\,\phi_{kl} + \sum_{k,l} d^{XYZ}_{kl}\,\psi_{kl}$$

**Schema 4 JSON format** (Option A):
```json
{
  "schema_version": "5.0",
  "layer": 4,
  "algebra": { "family": "C", "n": 1, ... },
  "coboundary": {
    "f_parameterization": "general_odd",
    "f_parameters": {
      "phi": [{"name": "phi_H1_eps1del1pp", "from": "E_eps1_del1_pp", "to": "H_1"}, ...],
      "psi": [{"name": "psi_eps1del1pp_H1", "from": "H_1", "to": "E_eps1_del1_pp"}, ...]
    },
    "delta_f_entries": [
      {
        "X": "E_eps1_del1_pp",
        "Y": "H_1",
        "Z": "H_1",
        "coeff_expression": "2*psi_eps1del1pp_H1 - phi_H1_eps1del1pp"
      }, ...
    ]
  }
}
```

**Pros**: Complete — allows checking triviality for any $\gamma$.  
**Cons**: Large output (polynomial expressions in many parameters). For n=1: $4 \times 4 + 4 \times 4 = 32$ free parameters.

---

#### Option B: Root-Space Aligned (Natural) Parameterization

Restrict $f$ to map **along root-space directions** using the fermionic oscillator $a_1^\pm$ as a "bridge":

| Even root/generator | ↔ | Odd root (via $a_1^+$) | ↔ | Odd root (via $a_1^-$) |
|---|---|---|---|---|
| $E_{2\delta_k}$ | ↔ | $E_{\varepsilon+\delta_k}$ | ↔ | (none) |
| $E_{-2\delta_k}$ | ↔ | (none) | ↔ | $E_{-\varepsilon-\delta_k}$ |
| $H_k$ | ↔ | $\sum \alpha_l E_{\varepsilon \pm \delta_l}$ | (linear) | |
| $E_{\delta_i-\delta_j}$ | ↔ | $E_{\varepsilon+\delta_i}$ and $E_{-\varepsilon-\delta_j}$ | | |

This gives a **block-diagonal** $f$ with one parameter per root-space pair (plus Cartan mixing). For n=1: reduces to ~8 parameters instead of 32.

**Schema 4 JSON format** (Option B):
```json
{
  "schema_version": "5.0",
  "layer": 4,
  "algebra": { "family": "C", "n": 1, ... },
  "coboundary": {
    "f_parameterization": "root_aligned",
    "f_parameters": [
      {"name": "alpha_1", "f_rule": "f(E_2del1_p) = alpha_1 * E_eps1_del1_pp"},
      {"name": "alpha_2", "f_rule": "f(E_2del1_m) = alpha_2 * E_eps1_del1_mm"},
      {"name": "beta_1",  "f_rule": "f(H_1) = beta_1 * E_eps1_del1_pp + ..."},
      ...
    ],
    "delta_f_entries": [
      {
        "X": "E_eps1_del1_pp",
        "Y": "H_1",
        "Z": "H_1",
        "coeff_expression": "2*alpha_1 - beta_1"
      }, ...
    ]
  }
}
```

**Pros**: More compact; reflects natural root-space structure; directly motivated by the oscillator realization.  
**Cons**: May miss coboundaries not of this form; requires a specific alignment choice for the Cartan directions.

---

### Scaling Convention

Independently of the parameterization, a **scaling convention** must be chosen for the $\phi_{kl}$ parameters. I propose:

- **Scale A (Natural)**: No additional scaling; coefficients are taken as written from the structure constants.
- **Scale B (Normalized)**: Normalize so that the coboundary coefficients are integers when the $\phi$ parameters are integers.

**Recommendation**: Scale A (Natural), for simplicity and direct comparability with Schema 3 evaluated coefficients.
