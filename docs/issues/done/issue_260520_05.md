### Response

#### 1. Mathematical Framework

The inhomogeneous deformation for C(n+1) is defined by the deformed exchange relation
between bosonic and fermionic oscillators (from `docs/math/C_inhomogeneous_definition.md`):

```
[b_j^s, a_1^σ] = -gb_{σ,j,s} · κ       (σ ∈ {+,−}, j=1..n, s ∈ {+,−})
```

This gives 4n deformation parameters. The deformed bracket on g = C(n+1) is:

```
[X, Y]_γ = [X, Y]_0 + κ · γ(X, Y)
```

where γ(X,Y) is computed by evaluating the PBW-reduced associative product in the
deformed algebra and reading off the κ-coefficient.

**Mechanism:** Whenever a b-oscillator must pass to the right of an a-oscillator during
PBW reordering (the relation b_j^s · a_1^σ = a_1^σ · b_j^s − gb_{σ,j,s}·κ is used),
a κ-term is generated. Since κ is central and κ²=0, these contributions do not cascade.

**Which brackets are affected:** γ(X,Y) ≠ 0 only when at least one of X, Y is an odd
generator (i.e., contains an a-oscillator), because even generators contain only b-oscillators
and the b–b CCR relations are undeformed.

#### 2. Sign Convention Proposal (for human approval)

I propose **Sign Convention A**, directly from the document:

| Convention | Exchange relation | γ definition |
|---|---|---|
| **Option A (proposed)** | `[b_j^s, a_1^σ] = −gb_{σ,j,s} · κ` | γ(X,Y) = κ-coefficient of [X,Y]_{deformed} |
| Option B (opposite) | `[b_j^s, a_1^σ] = +gb_{σ,j,s} · κ` | sign-flipped γ |

Option A is the convention stated in `C_inhomogeneous_definition.md`. It gives the PBW
reordering rule: `b_j^s · a_1^σ = a_1^σ · b_j^s − gb_{σ,j,s} · κ`.

#### 3. gb_matrix Layout Proposal

The gb_matrix is a 2×2n matrix of symbolic parameter labels:

```
Rows    (σ): row 0 = a_1^+,  row 1 = a_1^−
Columns (j,s): col 0=(j=1,s=+), col 1=(j=1,s=−), col 2=(j=2,s=+), ..., col 2j-2=(j,s=+), col 2j-1=(j,s=−)
```

For n=1 (C(2), 2×2 matrix):

```
           b_1^+             b_1^−
a_1^+  [ gb_a1p_b1p,    gb_a1p_b1m ]
a_1^−  [ gb_a1m_b1p,    gb_a1m_b1m ]
```

For n=2 (C(3), 2×4 matrix):

```
           b_1^+          b_1^−          b_2^+          b_2^−
a_1^+  [ gb_a1p_b1p,  gb_a1p_b1m,  gb_a1p_b2p,  gb_a1p_b2m ]
a_1^−  [ gb_a1m_b1p,  gb_a1m_b1m,  gb_a1m_b2p,  gb_a1m_b2m ]
```

**Parameter label scheme:** `gb_a1{σ}_b{j}{s}` where σ ∈ {p,m}, s ∈ {p,m}.

This gives 4n parameters total: `gb_a1p_b1p, gb_a1p_b1m, ..., gb_a1m_bnp, gb_a1m_bnm`.

#### 4. γ-Coefficient JSON Format

Since γ(X,Y) is linear in the gb parameters, each non-zero entry is stored as:

```json
{
  "X": "E_eps1_del1_pp",
  "Y": "E_eps1_del1_mm",
  "Z": "E_eps1_del1_pm",
  "coeff": {"gb_a1m_b1p": "-1"},
  "sign_rule": "graded"
}
```

where `"coeff"` is an object mapping gb-parameter labels to rational string coefficients
(since γ is linear in gb, each entry has at most one nonzero gb term).

**Worked example (n=1):** `[E_eps1_del1_pp, E_eps1_del1_mm}` = `{a_1^+ b_1^+, a_1^- b_1^-}`

Computing via the deformed reordering rule:
- XY = a_1^+ b_1^+ · a_1^- b_1^- → b_1^+ passes a_1^-: gets −gb_a1m_b1p · κ a_1^+ b_1^-
- YX = a_1^- b_1^- · a_1^+ b_1^+ → b_1^- passes a_1^+: gets −gb_a1p_b1m · κ a_1^- b_1^+

γ(E_eps1_del1_pp, E_eps1_del1_mm) = −gb_a1m_b1p · E_eps1_del1_pm − gb_a1p_b1m · E_eps1_del1_mp

→ Two entries in the gamma_matrix for this pair.

#### 6. Computation Method

The implementation plan for `src/C_gamma.py`:

1. Reuse `build_generators()`, `express_in_generators()` from `C_generators.py`.
2. Extend `pbw_reduce_word()` to a new `pbw_reduce_word_deformed()` that:
   - Tracks a "κ-accumulator" alongside the normal reduced polynomial.
   - Applies the deformed swap rule for the (b_j^s, a_1^σ) transposition:
     `b · a → a · b + (κ-contribution: −gb_{σ,j,s} · constant_word)`.
   - Since κ²=0, κ-accumulator terms do not get further κ-contributions.
3. For each gb parameter gb_{σ,j,s}, set it to 1 and all others to 0, then:
   - Compute the deformed bracket for every generator pair.
   - Read off the κ-coefficient and express it in the generator basis.
   - This gives the column of γ corresponding to gb_{σ,j,s}.
4. Combine all 4n columns into the full γ matrix (linear in gb).
5. Output `data/C_{n}_gamma.json` for n=1,2,3.
