## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

## 1. Even and Odd Basis Lists

### Generator label conventions (recap)

**Even generators**:
- Cartan: `H_{k}` for k = 1, …, n+1
- Long even: `E_2del{k}_p` (root 2δ_k), `E_2del{k}_m` (root −2δ_k)
- Mixed even (i < j): `E_del{i}_del{j}_pp` (δ_i+δ_j), `E_del{i}_del{j}_mm` (−δ_i−δ_j), `E_del{i}_del{j}_pm` (δ_i−δ_j), `E_del{i}_del{j}_mp` (−δ_i+δ_j)

**Odd generators** (k = 1, …, n):
- `E_eps1_del{k}_pp` (ε+δ_k = a_1^+ b_k^+), `E_eps1_del{k}_pm` (ε−δ_k = a_1^+ b_k^−), `E_eps1_del{k}_mp` (−ε+δ_k = a_1^− b_k^+), `E_eps1_del{k}_mm` (−ε−δ_k = a_1^− b_k^−)

## 2. PBW Ordering Proposals

Two concrete options are presented for human selection. Both options place κ first and use the same internal ordering within each block; they differ only in whether odd or even generators come first.

---

### **Option A: Fermionic-first** (recommended — consistent with B(0,n) v5.0)

```
κ  <  [odd generators]  <  [even generators]
```

**Odd block** (inner order: positive ε first, then negative ε; within each, index k = 1…n):
```
E_eps1_del{k}_pp  (k=1..n),
E_eps1_del{k}_pm  (k=1..n),
E_eps1_del{k}_mp  (k=1..n),
E_eps1_del{k}_mm  (k=1..n)
```

**Even block** (inner order: Cartan, then positive, then negative, then mixed):
```
H_1, H_2, …, H_{n+1},
E_2del{k}_p  (k=1..n),  E_del{i}_del{j}_pp  (i<j),
E_2del{k}_m  (k=1..n),  E_del{i}_del{j}_mm  (i<j),
E_del{i}_del{j}_pm  (i<j),  E_del{i}_del{j}_mp  (i<j)
```

**Concrete example for C(3), n=2**:
```
κ,
E_eps1_del1_pp, E_eps1_del2_pp,
E_eps1_del1_pm, E_eps1_del2_pm,
E_eps1_del1_mp, E_eps1_del2_mp,
E_eps1_del1_mm, E_eps1_del2_mm,
H_1, H_2, H_3,
E_2del1_p, E_2del2_p, E_del1_del2_pp,
E_2del1_m, E_2del2_m, E_del1_del2_mm,
E_del1_del2_pm, E_del1_del2_mp
```

**Rationale**: Directly generalises the B(0,n) v5.0 ordering (where odd generators also precede even ones). Minimises structural differences in any code that iterates over the basis.

---

### **Option B: Bosonic-first (even-first)**

```
κ  <  [even generators]  <  [odd generators]
```

**Even block** (same internal order as Option A's even block):
```
H_1, …, H_{n+1},
E_2del{k}_p, E_del{i}_del{j}_pp,
E_2del{k}_m, E_del{i}_del{j}_mm,
E_del{i}_del{j}_pm, E_del{i}_del{j}_mp
```

**Odd block** (same internal order as Option A's odd block):
```
E_eps1_del{k}_pp, E_eps1_del{k}_pm,
E_eps1_del{k}_mp, E_eps1_del{k}_mm  (k=1..n)
```

**Concrete example for C(3), n=2**:
```
κ,
H_1, H_2, H_3,
E_2del1_p, E_2del2_p, E_del1_del2_pp,
E_2del1_m, E_2del2_m, E_del1_del2_mm,
E_del1_del2_pm, E_del1_del2_mp,
E_eps1_del1_pp, E_eps1_del2_pp,
E_eps1_del1_pm, E_eps1_del2_pm,
E_eps1_del1_mp, E_eps1_del2_mp,
E_eps1_del1_mm, E_eps1_del2_mm
```

**Rationale**: Places the even (bosonic) sub-sector contiguously at the front, which may be preferable when the even subalgebra sp(2n) is the primary computational object. Breaks consistency with B(0,n).

| Category | Labels |
|---|---|

No changes to generator labels are proposed; the conventions from `Cn1_definition.md` are adopted as-is.
