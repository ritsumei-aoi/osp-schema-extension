#### 2. Generator Implementation Design (`src/C_generators.py`)

The structure constant generator employs an exact algebraic polynomial engine (`OscillatorPoly`) over $\mathbb{Q}$:
1. **Canonical Normal Ordering**:
   - Fermionic CAR: $\{a_1^-, a_1^+\} = 1 \implies a_1^- a_1^+ = 1 - a_1^+ a_1^-$, $(a_1^\pm)^2 = 0$.
   - Bosonic CCR: $[b_i^-, b_j^+] = \delta_{ij} \implies b_i^- b_j^+ = \delta_{ij} + b_j^+ b_i^-$.
   - Normal form: $(a_1^+)^{f_+} (a_1^-)^{f_-} \prod_{k=1}^n (b_k^+)^{p_k} (b_k^-)^{m_k}$ with rational coefficients.
2. **Graded Lie Superalgebra Bracket**:
   $$[X, Y\} = X Y - (-1)^{p(X) p(Y)} Y X$$
3. **Basis & PBW Polarity Ordering (Option 1)**:
   - Odd sector ($4n$ generators):
     `E_eps1_del{k}_pp` ($k=1..n$), `E_eps1_del{k}_pm` ($k=1..n$), `E_eps1_del{k}_mp` ($k=1..n$), `E_eps1_del{k}_mm` ($k=1..n$).
   - Even sector ($2n^2 + n + 1$ generators):
     Cartan `H_1, ..., H_{n+1}`, Long `+` `E_2del{k}_p`, Short `++` `E_del{i}_del{j}_pp`, Long `-` `E_2del{k}_m`, Short `--` `E_del{i}_del{j}_mm`, Short `+-` `E_del{i}_del{j}_pm`, Short `-+` `E_del{i}_del{j}_mp`.
   - Global PBW ordering: $\kappa < [\text{Odd Sector}] < [\text{Even Sector}]$.
4. **Exact Decomposition into Basis**:
   - Each bracket $[X, Y\}$ is converted to a vector over oscillator monomials and decomposed against the basis matrix via Gauss-Jordan elimination over SymPy rationals.
   - Non-zero coefficients are recorded as `{"X": x, "Y": y, "Z": z, "coeff": str(c), "sign_rule": "graded"}`.
5. **Schema 1 Assembly**:
   - Compiles the full JSON structure with all 10 top-level keys matching `docs/json_schema_specification.md`.
