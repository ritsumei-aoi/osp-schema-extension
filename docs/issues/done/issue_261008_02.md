### 1. `algebra` field

```json
"algebra": {
  "family": "C",
  "m": 1,
  "n": "<bosonic rank>",
  "cartan_type": "C(n+1)",
  "alternative_notation": {
    "osp": "osp(2|2n)",
    "dimension_formula": "osp(2m|2n) with m=1"
  },
  "dimension": {
    "total": "<2n^2 + 5n + 1>",
    "even": "<2n^2 + n + 1>",
    "odd": "<4n>"
  }
}
```

Concrete values by case:

| Case | n | even | odd | total |
|---|---|---|---|---|
| C(2) | 1 | 4 | 4 | 8 |
| C(3) | 2 | 11 | 8 | 19 |
| C(4) | 3 | 22 | 12 | 34 |

**Difference from B(0,n)**: `family` changes from `"B"` to `"C"`, `m` is fixed at `1`; dimension formulas change (B even=2n²+n, C even=2n²+n+1; B odd=2n, C odd=4n).

### 2. `oscillator_generators` field

```json
"oscillator_generators": {
  "fermions": {
    "m": 1,
    "labels": ["a_1_p", "a_1_m"],
    "parity": 1,
    "description": "Standard fermionic pair a_1^± with CAR: {a_1^-, a_1^+} = 1"
  },
  "bosons": {
    "count": "<2n>",
    "n": "<bosonic rank>",
    "labels": ["b_1_p", "b_1_m", "...", "b_n_p", "b_n_m"],
    "description": "Bosonic oscillators b_k^± with k=1,...,n; CCR: [b_k^-, b_l^+] = delta_{kl}"
  }
}
```

Concrete label lists:

| Case | n | `fermions.labels` | `bosons.labels` |
|---|---|---|---|
| C(2) | 1 | `["a_1_p","a_1_m"]` | `["b_1_p","b_1_m"]` |
| C(3) | 2 | `["a_1_p","a_1_m"]` | `["b_1_p","b_1_m","b_2_p","b_2_m"]` |
| C(4) | 3 | `["a_1_p","a_1_m"]` | `["b_1_p","b_1_m","b_2_p","b_2_m","b_3_p","b_3_m"]` |

**Difference from B(0,n)**: The `supplementary_fermion` key (with `a_0`, relation `a_0^2 = 1/2`) is replaced by `fermions` (standard CAR pair). The `bosons` key is structurally identical but the label count doubles relative to the fermion count change.

### 3. `oscillator_relations` field

```json
"oscillator_relations": {
  "fermionic_anticommutators": {
    "description": "CAR for the standard fermionic pair a_1^±",
    "relations": {
      "conjugate_pair": "{a_1^-, a_1^+} = 1",
      "same_sign": "{a_1^s, a_1^s} = 0 for s in {+,-}"
    }
  },
  "bosonic_commutators": {
    "description": "CCR for bosonic oscillators",
    "relations": {
      "same_type": "[b_i^s, b_j^s] = 0 for all i,j,s",
      "conjugate_pair": "[b_i^-, b_j^+] = delta_{ij}"
    }
  },
  "mixed_commutators": {
    "description": "Boson-fermion mixed relations (undeformed algebra)",
    "relations": {
      "boson_fermion": "[b_k^s, a_1^sigma] = 0 for all k,s,sigma"
    }
  }
}
```

**Notes**:
- The mixed relation is a **commutator** (not anticommutator) because p(a_1^±)=1 and p(b_k^±)=0, so the graded bracket reduces to an ordinary commutator with sign (−1)^{1·0}=1.
- In the **deformed** (inhomogeneous) algebra (Schema 2), this relation becomes `[b_j^s, a_1^σ] = −gb_{σ,j,s}·κ`; Schema 1 records only the undeformed value.
- **Difference from B(0,n)**: `supplementary_fermion_relation` (`a_0^2 = 1/2`) is replaced by `fermionic_anticommutators`. The mixed key name changes from `boson_fermion: [b_i^±, a_0] = 0` to the same commutator condition but referencing `a_1^±`.

### 4. `central_elements` field (top-level key)

This is a **new top-level key** in C(n+1) (not present as its own key in B(0,n) v5.0, though κ and K are documented there).

```json
"central_elements": {
  "kappa": {
    "label": "kappa",
    "parity": 1,
    "nilpotency": "kappa^2 = 0",
    "role": "odd central element; appears in deformed bracket [X,Y]_gamma = [X,Y]_0 + kappa * gamma(X,Y)"
  },
  "K": {
    "label": "K",
    "parity": 0,
    "role": "even central element; identified with scalar 1 in all current applications; not an independent basis element"
  }
}
```

**Notes**:
- κ (kappa) is parity-1 (odd) with κ²=0. It is the formal nilpotent extension symbol in the deformed algebra.
- K is parity-0 (even), the identity-like central element arising from the pre-oscillator form (see `C_inhomogeneous_definition.md`). It is excluded from PBW basis lists (identified with 1).
- Both κ and K are excluded from the `basis` lists; they appear only in `central_elements` for schema completeness.
- **Difference from B(0,n)**: B(0,n) v5.0 records κ inline in the `basis.ordering_convention` note. C(n+1) promotes `central_elements` to a **dedicated top-level key** (mandatory per issue requirements).

| Algebra | Bosonic rank n | File name |
|---|---|---|
| C(2) = osp(2\|2) | 1 | `C_1_structure.json` |
