#### Proposed gb Sign Profiles

For $C(n+1)$, the deformation parameters are:
$$\{ \mathrm{gb}_{\sigma, j, s} \mid \sigma \in \{+,-\},\ j=1,\ldots,n,\ s \in \{+,-\} \}$$

Labels in the JSON are `gb_pp_j`, `gb_pm_j`, `gb_mp_j`, `gb_mm_j` for each $j$.

Three representative sign profiles are proposed:

---

**Option A: Uniform (+1) Profile**

All 4n parameters set to $+1$:

| Parameter | Value (all j) |
|---|---|
| `gb_pp_j` | +1 |
| `gb_pm_j` | +1 |
| `gb_mp_j` | +1 |
| `gb_mm_j` | +1 |

*Rationale*: The maximally symmetric, simplest baseline. Useful for establishing a non-trivial but structurally clear evaluated structure. All gamma coefficients become pure integer multiples of generators.

---

**Option B: Sign-Diagonal (σ=s) Profile**

The value of $\mathrm{gb}_{\sigma,j,s}$ depends on whether the fermionic oscillator sign $\sigma$ matches the bosonic oscillator sign $s$:

| Parameter | Value (all j) |
|---|---|
| `gb_pp_j` | +1 |
| `gb_pm_j` | −1 |
| `gb_mp_j` | −1 |
| `gb_mm_j` | +1 |

*Rationale*: Encodes a "same-sign = positive, opposite-sign = negative" rule. This is compatible with the natural Cartan involution $\sigma \mapsto -\sigma$, $s \mapsto -s$ (which maps `gb_pp` ↔ `gb_mm` and `gb_pm` ↔ `gb_mp`), satisfying $\mathrm{gb}_{-\sigma,j,-s} = \mathrm{gb}_{\sigma,j,s}$. Gives a more varied but still structured pattern.

---

**Option C: Mode-Dependent Profile (j-indexed signs)**

Signs alternate with the bosonic mode index $j$:

| Parameter | Value |
|---|---|
| `gb_pp_j` | $(-1)^{j+1}$ |
| `gb_pm_j` | $(-1)^{j+1}$ |
| `gb_mp_j` | $(-1)^{j+1}$ |
| `gb_mm_j` | $(-1)^{j+1}$ |

i.e., all parameters for mode $j$ have sign $+1$ if $j$ is odd, $-1$ if $j$ is even.

*Rationale*: Tests sensitivity to inter-mode sign variation. For $n=1$ this reduces to Option A; for $n=2,3$ it introduces cancellations between mode contributions. Useful for probing mode-mixing structure.

---

#### Recommendation

**Option A** is recommended as the primary representative profile for Layer 3. It is the standard first evaluation point (analogous to setting all deformation parameters to 1 in deformation theory), produces the cleanest non-trivial evaluated gamma structure, and provides a natural baseline before exploring sign-varied profiles in future issues.
