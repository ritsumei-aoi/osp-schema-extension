I propose preserving the v5.0 version and reusing Schema 1's sparse

**Proposed `gb_matrix`:** rows are fermionic oscillator labels
`["a_1_p", "a_1_m"]`; columns are bosonic labels in rank order
`["b_1_p", "b_1_m", ..., "b_n_p", "b_n_m"]`. Each matrix entry is a distinct
odd parameter named `gb_a1_p_b1_p`, `gb_a1_p_b1_m`, ..., `gb_a1_m_b{n}_m`,
equivalent to \(\mathrm{gb}_{\sigma,j,s}\). The matrix is therefore exactly
2 by 2n and carries parameter parity 1.

**Proposed computation:** Build every basis generator from its Schema 1
oscillator realization. Apply the CAR, CCR, and the selected mixed
commutator rule to each ordered generator pair, retaining terms linear in
\(\kappa\) and the gb parameters and discarding \(\kappa^2\) terms. Subtract
the undeformed bracket and express the remaining coefficient of \(\kappa\)
in the Schema 1 basis. Store each nonzero \(\gamma(X,Y)\) coefficient as an
exact symbolic expression in gb parameters, with all nonzero ordered pairs
explicitly represented and `sign_rule: "graded"`. This keeps Schema 2
consistent with the explicit-order convention approved for Schema 1.

**Sign-convention options for selection**

1. **Literal-source convention (recommended):** Store the raw parameters
   \(\mathrm{gb}_{\sigma,j,s}\) in the matrix and apply the defining relation

   \([b_j^s,a_1^\sigma]=+\widetilde{\mathrm{gb}}_{\sigma,j,s}\kappa\).
