### Mathematical Method

**Source**: `docs/math/C_inhomogeneous_definition.md`.

The inhomogeneous deformation modifies the exchange relation between fermionic and bosonic oscillators. In the deformed oscillator algebra, two sign conventions are possible:

#### Option A (as per definition doc): `[b_j^s, a_1^σ] = −gb_{σ,j,s} · κ`

Follows from the skew-supersymmetric pre-oscillator form `(a|b)` with `gb_{σ,j,s} = (a_1^σ | b_j^s)` and the bracket rule `[a,b] = (a|b)κ` for mixed parity. The antisymmetry `(a|b) = −(b|a)` (for mixed parity with `(−1)^{p(a)p(b)} = −1`) gives `(b_j^s | a_1^σ) = −gb_{σ,j,s}`, so `[b_j^s, a_1^σ] = (b_j^s | a_1^σ)·κ = −gb_{σ,j,s}·κ`.

Operationally: when a bosonic oscillator `b_j^s` (higher PBW index) is swapped past a fermionic `a_1^σ` (lower PBW index) during PBW normalization, it contributes a correction `−gb_{σ,j,s}` multiplied by the reduced word. The γ coefficients are the κ¹ terms extracted from `[X,Y]_γ − [X,Y]_0`.

#### Option B (opposite sign): `[b_j^s, a_1^σ] = +gb_{σ,j,s} · κ`

All γ entries are negated relative to Convention A.

### Note on K-terms

Some γ(X, Y) values include a contribution from the central element **K** (= identity scalar 1). For example:

```
gamma(H_1, E_eps1_del1_pm)[gb_a1p_b1m] = H_1 + 2*H_2 + K
```

This arises because the polynomial `{(a_1_p, a_1_m): 1, (b_1_p, b_1_m): −1}` cannot be expressed as a linear combination of g-generators without K:

```
H_1 + 2*H_2 + K = {(a_1_p, a_1_m):1} + {(b_1_p, b_1_m): 1−2} + {(): −1+1} = {(a_1_p, a_1_m):1, (b_1_p, b_1_m):−1}
```

This is consistent with the extension structure L = g ⊕ κg: the deformed bracket maps into L, and κ·(c·K) = c·κ. K-terms in γ represent contributions to the central κ-direction of L.
