### 1. Mathematical Setup

The inhomogeneous deformation is given by the 2-cochain γ (Schema 2):
```
[b_j^s, a_1^σ]_γ = [b_j^s, a_1^σ]_0 + κ · γ(b_j^s, a_1^σ)
```
with 4n symbolic parameters gb_{σ,j,s} (where σ,s ∈ {+,−}, j = 1,…,n).

The deformation is **trivial** iff there exists an odd linear map f: g → g such that γ = δf, where the coboundary formula is:
```
(δf)(X,Y) = (−1)^{p(X)} [X, f(Y)] − (−1)^{(p(X)+1)p(Y)} [Y, f(X)] − f([X,Y])
```
Since f maps g → g (within the Lie superalgebra, not into K) and all structure constants in Schema 1 stay within g, the coboundary (δf) can never produce a K-component.

### 2. K-Obstruction: The Primary Constraint

**Observation**: Every gb parameter appears with non-zero coefficient in at least one K-component of γ.

Concretely for n=1 (C(2) = osp(2|2)):
| (X, Y) | γ(X,Y)^K | Required triviality condition |
|--------|-----------|-------------------------------|
| (H_1, E_eps1_del1_pm) | gb_{p,1,m} | gb_{p,1,m} = 0 |
| (H_1, E_eps1_del1_mm) | gb_{m,1,m} | gb_{m,1,m} = 0 |
| (H_2, E_eps1_del1_pp) | (1/2)·gb_{p,1,p} | gb_{p,1,p} = 0 |
| (H_2, E_eps1_del1_mp) | (1/2)·gb_{m,1,p} | gb_{m,1,p} = 0 |

Since (δf)^K = 0 identically, triviality requires γ(X,Y)^K = 0 for all (X,Y). These equations are individually independent and their constraint matrix (the K-constraint system) has **full rank** equal to the number of gb parameters.

**K-constraint rank analysis** (from `src/C_triviality.py`):

| 2 | 84 | 84 | 8 | 8 | **YES** |

The K-constraint system alone forces **all gb = 0** for all n = 1, 2, 3.

### 4. Specific Evidence: Trivial vs. Non-Trivial Cases

**Trivial case (the only one): gb = 0**

Setting all gb = 0 makes γ = 0, and f = 0 (the zero map) satisfies δ(0) = 0 = γ. The deformation is trivially trivial (no deformation at all). This is the unique trivial case.

**Non-trivial cases (all three tested profiles)**:

Profile `all_plus` (gb_{σ,j,s} = 1 for all σ, j, s):
- γ(H_1, E_eps1_del1_pm)^K = 1 ≠ 0
- γ(H_1, E_eps1_del1_mm)^K = 1 ≠ 0
- These K-components cannot be matched by any (δf). **Non-trivial.**

Profile `diagonal` (gb_{σ,j,s} = δ_{σs}):
- γ(H_1, E_eps1_del1_mm)^K = gb_{m,1,m} = 1 ≠ 0. **Non-trivial.**

Profile `anti_diagonal` (gb_{σ,j,s} = 1 − δ_{σs}):
- γ(H_1, E_eps1_del1_pm)^K = gb_{p,1,m} = 1 ≠ 0. **Non-trivial.**

In each case, at least one K-component of γ is non-zero, immediately obstructing triviality.

### 5. Root Cause Analysis

The obstruction has a concrete algebraic origin in the oscillator realization:

When computing γ(X,Y) from deformed brackets involving b_j^s and a_1^σ, the bosonic CCR identity
```
b_j^- · b_j^+ = K − b_j^+ · b_j^-    (in U(A))
```
introduces the central element K = Σ_j b_j^+ b_j^- + 1/2 into γ(X,Y). Specifically, whenever two bosonic operators reorder through CCR in the computation of γ^c_{XY}, a K-term is generated.

The odd linear map f: g → g has image inside g (not K), so all three terms of the coboundary formula stay within g. This makes K-generation in γ an **irremovable obstruction**: it cannot be cancelled by any choice of f.

### 6. General Conjecture

**Conjecture (Rigidity of C(n+1) inhomogeneous deformations)**:

> For C(n+1) = osp(2|2n) with the inhomogeneous deformation parametrized by gb_{σ,j,s} (σ,s ∈ {+,−}, j = 1,…,n), the deformation γ is trivial (there exists an odd f: g → g with γ = δf) **if and only if all gb_{σ,j,s} = 0**.

**Equivalently**: every non-zero inhomogeneous deformation of C(n+1) is non-trivial.

**Evidence**:
- Verified for n = 1, 2, 3 by exact rational arithmetic.
- Mechanism: the K-constraint system has rank = 4n = gb_count for all n tested, establishing that K-components of γ yield 4n independent necessary conditions, all of the form gb_i = 0.
- The coboundary operator δ: C^1_odd(g,g) → C^2(g,g) has rank deficiency exactly 4n, which matches the dimension of the "K-obstruction subspace."

**Necessary and sufficient conditions**:
- **Necessary**: all gb = 0 (from K-obstruction, verified by rank analysis).
- **Sufficient**: all gb = 0 gives γ = 0 = δ(0). ✓

**Predicted pattern for general n**: The K-constraint rank should equal 4n for all n ≥ 1, since each of the 4n parameters gb_{σ,j,s} appears as the sole coefficient in at least one K-entry of γ (namely, γ(H_1, E_{ε_1−δ_j,σs})^K = ±gb_{σ,j,s} where σs denotes the sign combination (σ,s)).
