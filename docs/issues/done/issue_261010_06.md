#### Background
For C(n+1), there are 4n deformation parameters:

```
gb_{a_1^+, b_j^+},  gb_{a_1^+, b_j^-},  gb_{a_1^-, b_j^+},  gb_{a_1^-, b_j^-}   (j = 1, …, n)
```

Schema 3 evaluates the symbolic gamma structure by substituting concrete ±1 values for each gb parameter. The output files will be named `C_{n}_evaluated_{suffix}.json`.

---

#### Proposed Sign Profiles

**Option A: All-ones (Recommended)**
All 4n parameters set to +1.

| Parameter | Value |
|---|---|
| `gb_a_1_p_b_j_p` | +1 |
| `gb_a_1_p_b_j_m` | +1 |
| `gb_a_1_m_b_j_p` | +1 |
| `gb_a_1_m_b_j_m` | +1 |

- File suffix: `allplus`
- Output: `C_1_evaluated_allplus.json`, `C_2_evaluated_allplus.json`, `C_3_evaluated_allplus.json`
- Rationale: Maximum deformation with all interactions active. The simplest and most uniform case, standard as a canonical representative. Directly reveals the full structure of the gamma 2-cocycle.

---

**Option B: Symplectic pairing (off-diagonal only)**
Only opposite-sign oscillator pairs are non-zero.

| Parameter | Value |
|---|---|
| `gb_a_1_p_b_j_p` | 0 |
| `gb_a_1_p_b_j_m` | +1 |
| `gb_a_1_m_b_j_p` | +1 |
| `gb_a_1_m_b_j_m` | 0 |

- File suffix: `symp`
- Output: `C_1_evaluated_symp.json`, etc.
- Rationale: Reflects the natural symplectic pairing (a_1^+ pairs with b_j^-, and a_1^- pairs with b_j^+). Half the parameters are zero, giving a sparser deformation.

---

**Option C: Diagonal only (same-direction pairs)**
Only same-sign oscillator pairs are non-zero.

| Parameter | Value |
|---|---|
| `gb_a_1_p_b_j_p` | +1 |
| `gb_a_1_p_b_j_m` | 0 |
| `gb_a_1_m_b_j_p` | 0 |
| `gb_a_1_m_b_j_m` | +1 |

- File suffix: `diag`
- Output: `C_1_evaluated_diag.json`, etc.
- Rationale: Only creation-creation and annihilation-annihilation pairings. Another natural sparse case.

#### Agent Recommendation

If multiple profiles are desired, Option A + Option B together would cover both the fully-active and the "symplectic-natural" cases.
