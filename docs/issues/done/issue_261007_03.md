### Proposed implementation

I propose a dependency-light Python generator in `src/C_generators.py`, with
exact rational arithmetic (`fractions.Fraction`) and no floating-point
structure constants. Its public entry points would build the ordered basis,
the oscillator realizations, and the complete Schema 1 object for a given
positive rank `n`; the command-line entry point would write
`data/C_{n}_structure.json` only for the explicitly selected ranks 1, 2, and
3.

The oscillator algebra would be represented as sparse rational polynomials
in canonical normal-ordered oscillator monomials. Multiplication would
normalize adjacent fermion and boson factors using
`{a_1^-,a_1^+}=1`, `a_1^\pm a_1^\pm=0`, and
`b_i^-b_j^+=b_j^+b_i^-+δ_ij`; bosons commute with fermions. Each basis
generator would be encoded from the approved realization formulas, including
the `1/2` factors on both terminal-root vectors. For every ordered pair of
basis elements, the generator would compute
`XY - (-1)^(p(X)p(Y))YX`, discard zero results, and express each remaining
polynomial exactly as a rational linear combination of the basis
realizations. A nonzero remainder outside that span should raise an explicit
error rather than be silently omitted. The resulting records would use the
specified `X`, `Y`, `Z`, `coeff`, and `"sign_rule": "graded"` fields.

The schema builder would produce the finalized parity-block basis order,
parity map, oscillator metadata and relations, top-level `central_elements`,
realizations, dimensions, and C-specific metadata exactly as specified in
`docs/json_schema_specification.md`. Tests would exercise basis uniqueness
and parity, rank-specific counts, realization coverage, exact coefficient
formatting, bracket closure/graded antisymmetry, and selected CAR/CCR
identities for each supported rank. Generation and tests are proposed only;
they have not been implemented or run pending approval.
