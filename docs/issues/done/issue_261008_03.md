### Files Written (draft — not committed, no JSON in `data/`)

#### `src/C_structure_generator.py`
Implements:
- `OscAlgebra(n)`: associative oscillator algebra with PBW reduction
  - `reduce(word, coeff)`: bubble-sort reduction using CAR/CCR relations
  - `mul(p1, p2)`: polynomial multiplication with full reduction
  - `bracket(X, pX, Y, pY)`: graded Lie bracket `[X,Y} = XY - (-1)^{pX*pY} YX`
- `build_generators(alg)`: generator realizations as oscillator polynomials (§generator_realization in schema)
- `basis_order(n)`: PBW basis list (ε-first, Option A)
- `poly_to_basis(poly, alg)`: decomposes a bracket result into the basis; solves the Cartan linear system
- `compute_structure_constants(n)`: enumerates all pairs (i<j) and collects non-zero brackets
- `build_schema1_json(n)`: assembles the full Schema 1 JSON conforming to `json_schema_specification.md`

**Key algebraic conventions implemented**:
- `a_1_m * a_1_p → 1 - a_1_p * a_1_m` (CAR anticommutator)
- `b_k_m * b_k_p → b_k_p * b_k_m + 1` (CCR commutator)
- All boson–fermion and cross-boson pairs commute freely
- Cartan extraction: solves the linear system relating monomials `(0,1)`, `(b_k_p, b_k_m)`, `()` to `f_1,...,f_{n+1}` (**derivation recorded inline**)
