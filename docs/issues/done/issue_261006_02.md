The existing Schema 1 (algebra structure) was designed for B(m,n). Extending to
C(n+1) requires modifications to several fields while maintaining backward
compatibility. Issue I01 has finalized the basis and PBW ordering.

## Requirements
1. Design `algebra` field for C(n+1) (family="C").
2. Design `oscillator_generators` without supplementary fermion.
3. Design `oscillator_relations` for standard fermionic pair (CAR).
4. Determine `central_elements` (kappa, K) for C(n+1).
5. Define file naming conventions (e.g., `C_1_structure.json`, `C_2_structure.json`, `C_3_structure.json`).

### Mandatory unified rules (fixed for all runs)
- **Algebra Field**: explicitly include `"m": 1` and the dimension formulas `even`: `2n^2 + n + 1`, `odd`: `4n`.
- **Oscillator Generators**: two keys, `"fermions"` (with `m=1`, labels `a_1_p, a_1_m`) and `"bosons"` (with rank `n`).
- **Central Elements**: `central_elements` is a **top-level key**, containing `kappa` (parity 1) and `K` (parity 0).
- **File Naming**: `C_{n}_structure.json`, where `n` is the bosonic rank (e.g., C(2) uses `n=1`).

### C-9. `structure_constants`

Format (same as B(0,n)); field `[X, Y} = coeff · Z` stored as:

```json
[
  {
    "X": "H_1",
    "Y": "E_eps1_del1_pp",
    "Z": "E_eps1_del1_pp",
    "coeff": "2",
    "sign_rule": "graded"
  },
  {
    "X": "H_1",
    "Y": "E_eps1_del1_pm",
    "Z": "E_eps1_del1_pm",
    "coeff": "0",
    "sign_rule": "graded"
  }
]
```

**Eigenvalue table for H_k on generators** (derived from oscillator algebra):

Let $s_\varepsilon = +1$ if generator contains $a_1^+$, $-1$ if $a_1^-$; $s_j = +1$ if contains $b_j^+$, $-1$ if $b_j^-$, $0$ otherwise. Then:

| Cartan | Eigenvalue formula | Example (E_eps1_del1_pp, n=2) |
|---|---|---|
| H_1 = n_1 + N_1 | $s_\varepsilon + s_1$ | $1 + 1 = 2$ |
| H_k = N_{k-1} - N_k (2≤k≤n) | $s_{k-1} - s_k$ | n/a for k=2: $0 - 0 = 0$ |
| H_{n+1} = -N_n - 1/2 | $-s_n$ | $0$ |

Full eigenvalue table for C(3), n=2:

| Generator | $s_\varepsilon$ | $s_1$ | $s_2$ | [H_1,·] | [H_2,·] | [H_3,·] |
|---|---|---|---|---|---|---|
| E_eps1_del1_pp | +1 | +1 | 0 | **2** | **1** | **0** |
| E_eps1_del1_pm | +1 | -1 | 0 | **0** | **-1** | **0** |
| E_eps1_del1_mp | -1 | +1 | 0 | **0** | **1** | **0** |
| E_eps1_del1_mm | -1 | -1 | 0 | **-2** | **-1** | **0** |
| E_eps1_del2_pp | +1 | 0 | +1 | **1** | **0** | **-1** |
| E_eps1_del2_pm | +1 | 0 | -1 | **1** | **0** | **1** |
| E_eps1_del2_mp | -1 | 0 | +1 | **-1** | **0** | **-1** |
| E_eps1_del2_mm | -1 | 0 | -1 | **-1** | **0** | **1** |

Key odd–odd brackets (computed from CAR+CCR; `n_1 = a_1^+ a_1^-`, `N_j = b_j^+ b_j^-`):

| X | Y | {X,Y} | In basis |
|---|---|---|---|
| E_eps1_del{j}_pp | E_eps1_del{j}_mm | $N_j + 1 - n_1$ | linear comb. of H_k (see note) |
| E_eps1_del{j}_pp | E_eps1_del{k}_mm (j<k) | $b_j^+ b_k^-$ | E_del{j}_del{k}_pm |
| E_eps1_del{j}_pp | E_eps1_del{k}_mm (j>k) | $b_j^+ b_k^-$ | E_del{k}_del{j}_mp |
| E_eps1_del{j}_pm | E_eps1_del{j}_mp | $-(N_j + 1 - n_1)$ | negative of above |
| E_eps1_del{j}_pp | E_eps1_del{k}_pm (j≠k) | $b_j^+ \cdot (b_k^-)^2$ = 0 (both odd, scalar 0) | 0 (nilpotency) |

**Note on $N_j + 1 - n_1$** (Cartan expansion):
Using $N_j = \sum_{l=j+1}^{n} H_l - H_{n+1} - \tfrac{1}{2}$ and $n_1 = H_1 - \sum_{l=2}^{n} H_l + H_{n+1} + \tfrac{1}{2}$:

$$\{E_{\varepsilon+\delta_j},\, E_{-\varepsilon-\delta_j}\} = -H_1 + \sum_{l=2}^{j} H_l + 2\sum_{l=j+1}^{n} H_l - 2H_{n+1}$$

Example (j=1, n=2): $\{E_{\varepsilon+\delta_1}, E_{-\varepsilon-\delta_1}\} = -H_1 + 2H_2 - 2H_3$  
Example (j=2, n=2): $\{E_{\varepsilon+\delta_2}, E_{-\varepsilon-\delta_2}\} = -H_1 + H_2 - 2H_3$

The full structure constants table (all non-zero brackets) will be populated programmatically. The format above is sufficient to drive code generation.

**Compatibility note**: Structure constants format is identical to B(0,n); only the generator labels and values change.
