## Verification Script

**File**: `src/verify_C_structure.py`

**Design**:
- Loads each JSON file with `Fraction` arithmetic (exact, no floating-point error)
- Reconstructs `[Y, X}` from stored `[X, Y}` via the anti-symmetry rule `[Y,X} = -(-1)^{pX*pY} [X,Y}` (the `br()` function handles both PBW orderings)
- Applies linearity to compute `[X, sum_i c_i Z_i} = sum_i c_i [X, Z_i}` (the `br_poly()` function)

**Anti-symmetry check**: For every stored pair `(X, Y)` with `X < Y` (PBW), verifies  
`[X, Y} + (-1)^{pX·pY} · [Y, X} = 0`  
where `[Y, X}` is reconstructed via `br()`. This confirms the stored data is self-consistent under the graded anti-symmetry rule.

**Super Jacobi check**: For all ordered triples `(i < j < k)` in PBW basis, verifies  
`[X,[Y,Z}} + (-1)^{pX(pY+pZ)} [Y,[Z,X}} + (-1)^{pZ(pX+pY)} [Z,[X,Y}} = 0`

This is an **independent check** from the I03 oscillator-level Jacobi test: it operates purely on the stored rational coefficients in the JSON, without re-invoking the oscillator algebra. A failure here would indicate a missing or incorrect term in the stored structure constants.
