## Context & Background
The existing Schema 1 (algebra structure) was designed for B(m,n). Extending to
C(n+1) requires modifications to several fields while maintaining backward
compatibility. Issue I01 has finalized the basis and PBW ordering.

## Requirements
1. Design `algebra` field for C(n+1) (family="C").
2. Design `oscillator_generators` without supplementary fermion.
3. Design `oscillator_relations` for standard fermionic pair (CAR).
4. Determine `central_elements` (kappa, K) for C(n+1).
5. Define file naming conventions (e.g., `C_1_structure.json`, `C_2_structure.json`, `C_3_structure.json`).

### Mandatory unified rules (fixed for all runs)
- **Algebra Field**: explicitly include `"m": 1` and the dimension formulas `even`: `2n^2 + n + 1`, `odd`: `4n`.
- **Oscillator Generators**: two keys, `"fermions"` (with `m=1`, labels `a_1_p, a_1_m`) and `"bosons"` (with rank `n`).
- **Central Elements**: `central_elements` is a **top-level key**, containing `kappa` (parity 1) and `K` (parity 0).
- **File Naming**: `C_{n}_structure.json`, where `n` is the bosonic rank (e.g., C(2) uses `n=1`).

#### 2. Detailed Field Definitions for $C(n+1)$

##### 2.1 `algebra` Field
Incorporates the mandatory `"m": 1`, rank `n`, Cartan notation $C(n+1)$, and explicit dimension formulas:
```json
{
  "family": "C",
  "m": 1,
  "n": 2,
  "cartan_type": "C(3)",
  "alternative_notation": {
    "osp": "osp(2|4)",
    "dimension_formula": "osp(2m|2n) with m=1"
  },
  "dimension": {
    "total": 19,
    "even": 11,
    "odd": 8
  },
  "dimension_formulas": {
    "even": "2n^2 + n + 1",
    "odd": "4n",
    "total": "2n^2 + 5n + 1"
  }
}
```
*Rank and dimension summary across target cases:*
- $n = 1$: `cartan_type`: `"C(2)"`, `osp`: `"osp(2|2)"`, `total`: 8, `even`: 4, `odd`: 4.
- $n = 2$: `cartan_type`: `"C(3)"`, `osp`: `"osp(2|4)"`, `total`: 19, `even`: 11, `odd`: 8.
- $n = 3$: `cartan_type`: `"C(4)"`, `osp`: `"osp(2|6)"`, `total`: 34, `even`: 22, `odd`: 12.

##### 2.2 `oscillator_generators` Field
Replaces B-family's `supplementary_fermion` ($a_0$) with a clean two-key schema containing `"fermions"` ($m=1$) and `"bosons"` ($n$ modes):
```json
{
  "fermions": {
    "count": 2,
    "m": 1,
    "labels": ["a_1_p", "a_1_m"],
    "description": "Standard fermionic pair a_1^± with m=1 (CAR)"
  },
  "bosons": {
    "count": 4,
    "n": 2,
    "labels": ["b_1_p", "b_1_m", "b_2_p", "b_2_m"],
    "description": "Bosonic oscillators b_k^± with k=1,...,n (CCR)"
  }
}
```

##### 2.3 `oscillator_relations` Field
Specifies the canonical anticommutation relations (CAR) for the fermionic pair, commutation relations (CCR) for bosons, and trivial undeformed mixed commutators:
```json
{
  "fermionic_anticommutators": {
    "description": "Canonical anticommutation relations (CAR) for standard fermionic pair",
    "relations": {
      "conjugate_pair": "{a_1^-, a_1^+} = 1",
      "nilpotency": "(a_1^±)^2 = 0"
    }
  },
  "bosonic_commutators": {
    "description": "Canonical commutation relations (CCR) for bosonic oscillators",
    "relations": {
      "same_type": "[b_i^±, b_j^±] = 0 for all i, j",
      "conjugate_pair": "[b_i^-, b_j^+] = δ_{ij}"
    }
  },
  "mixed_commutators": {
    "boson_fermion": "[b_k^±, a_1^±] = 0 (undeformed)"
  }
}
```

##### 2.4 `central_elements` Field (Top-Level Key)
Defines the central extension $\tilde{\mathfrak{g}} = \mathfrak{g} \oplus \mathbb{R}\kappa \oplus \mathbb{R}K$:
```json
{
  "kappa": {
    "label": "kappa",
    "parity": 1,
    "nilpotency": "kappa^2 = 0",
    "description": "Odd central element parametrizing inhomogeneous deformation"
  },
  "K": {
    "label": "K",
    "parity": 0,
    "value": 1,
    "description": "Even central element (identity scalar unit K = 1)"
  }
}
```

##### 2.5 `basis` Field (Aligning with Approved Option 1 Polarity-Order)
Following the approved decisions from Issue I01:
- `ordering_convention`: `"PBW: kappa < [odd: Delta_{1}^+ (pp, pm) < Delta_{1}^- (mp, mm)] < [even: Cartan (H) < Long(+) < Short(++) < Long(-) < Short(--) < Short(+-) < Short(-+)]"`
- Example for $n = 2$ ($C(3)$):
```json
{
  "even": [
    "H_1", "H_2", "H_3",
    "E_2del1_p", "E_2del2_p",
    "E_del1_del2_pp",
    "E_2del1_m", "E_2del2_m",
    "E_del1_del2_mm",
    "E_del1_del2_pm",
    "E_del1_del2_mp"
  ],
  "odd": [
    "E_eps1_del1_pp", "E_eps1_del2_pp",
    "E_eps1_del1_pm", "E_eps1_del2_pm",
    "E_eps1_del1_mp", "E_eps1_del2_mp",
    "E_eps1_del1_mm", "E_eps1_del2_mm"
  ],
  "ordering_convention": "PBW: kappa < [odd: Delta_{1}^+ (pp, pm) < Delta_{1}^- (mp, mm)] < [even: Cartan < Long(+) < Short(++) < Long(-) < Short(--) < Short(+-) < Short(-+)]"
}
```

##### 2.6 `parity` Field
Maps each basis generator to its $\mathbb{Z}_2$-grading:
- Even generators (`H_k`, `E_2del{k}_p/m`, `E_del{i}_del{j}_*`): `0`
- Odd generators (`E_eps1_del{k}_*`): `1`

##### 2.7 `generator_realization` Field
Expresses all generators in standard PBW-ordered oscillator words (`a_1_p, a_1_m, b_1_p, b_1_m, ...`):
```json
{
  "description": "Standard form with PBW ordering",
  "ordering": "a_1_p, a_1_m, b_1_p, b_1_m, b_2_p, b_2_m, ...",
  "realizations": {
    "H_1": {
      "standard_form": [
        {"words": ["a_1_p", "a_1_m"], "coeff": "1"},
        {"words": ["b_1_p", "b_1_m"], "coeff": "1"}
      ],
      "frappat_form": "a_1^+ a_1^- + b_1^+ b_1^-",
      "parity": 0

      "standard_form": [
        {"words": ["b_{k-1}_p", "b_{k-1}_m"], "coeff": "1"},

      "frappat_form": "b_{k-1}^+ b_{k-1}^- - b_k^+ b_k^-",

    },
    "H_{n+1}": {

        {"words": ["b_n_p", "b_n_m"], "coeff": "-1"},
```

##### 2.8 `structure_constants` and `metadata` Fields
- `structure_constants`: List of graded brackets `[X, Y}`:
  `{"X": "...", "Y": "...", "Z": "...", "coeff": "...", "sign_rule": "graded"}`
- `metadata`: Contains schema generator name, version, timestamp, references to Frappat et al. (2000).

#### 3. File Naming Conventions Across Schema Layers

In accordance with the mandatory rule, the file naming indexes by bosonic rank $n$:
- `C_{n}_structure.json` for Schema 1 (Algebra Structure)
- `C_{n}_gamma.json` for Schema 2 (Deformation / $\gamma$-structure)
- `C_{n}_evaluated_<gb>.json` for Schema 3 (Evaluated Structure Constants)
- `C_{n}_coboundary_<gb>.json` for Schema 4 (Coboundary Data)

**Target file names for $n = 1, 2, 3$:**
- $n = 1$ ($C(2) = \mathfrak{osp}(2|2)$): `C_1_structure.json`
- $n = 2$ ($C(3) = \mathfrak{osp}(2|4)$): `C_2_structure.json`
- $n = 3$ ($C(4) = \mathfrak{osp}(2|6)$): `C_3_structure.json`

#### 4. Compatibility Analysis with $B(m,n)$ Schema

| Field | $B(0,n)$ (Base Schema v5.0) | $C(n+1) = \mathfrak{osp}(2|2n)$ Schema | Compatibility / Migration Rule |
|---|---|---|---|
| `algebra.family` | `"B"` | `"C"` | Tag discriminator |
| `algebra.m` | `0` | `1` | Indicates fermionic rank ($2m$ fermions) |
| `algebra.cartan_type` | `"B(0,n)"` | `"C(n+1)"` | Lie superalgebra Cartan classification |
| `algebra.dimension` | $(2n^2+n) \mid 2n$ | $(2n^2+n+1) \mid 4n$ | Dimension formula reflects $H_1$ and $\varepsilon$-roots |
| `oscillator_generators` | `supplementary_fermion` (`a_0`, $a_0^2=1/2$) | `fermions` (`m=1`, `a_1_p`, `a_1_m`, CAR) | Replaces auxiliary fermion with canonical CAR pair |
| `central_elements` | Documented in comments / optional | Explicit top-level key (`kappa`, `K`) | Promoted to schema standard for both algebras |
| `basis.odd` | `E_del{k}_p`, `E_del{k}_m` ($2n$ total) | `E_eps1_del{k}_pp/pm/mp/mm` ($4n$ total) | Standardized root labels with $\varepsilon_1$ tag |
| `ordering_convention` | $\kappa < \text{Odd}(p < m) < \text{Even}$ | $\kappa < \text{Odd}(pp < pm < mp < mm) < \text{Even}$ | Retains identical polarity-based PBW philosophy |
| `generator_realization` | Linear in $a_0$; $H_n$ constant $+1/2$ | Bilinear $a_1^\pm b_k^\pm$; $H_1$ has $a_1^+ a_1^-$; $H_{n+1}$ constant $-1/2$ | Standard normal-ordered word representation preserved |
