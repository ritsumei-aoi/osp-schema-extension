### Response

#### Implementation

**File created:** `src/verify_C_structure.py`

The script:
1. Loads each `data/C_{n}_structure.json` file
2. Builds a full bracket table from the stored SC entries, deriving reversed pairs via the graded anti-symmetry rule `[Y,X} = -(-1)^{p(X)p(Y)} [X,Y}`
3. **Anti-symmetry check**: for all ordered pairs (X,Y), verifies `[X,Y} + (-1)^{p(X)p(Y)} [Y,X} = 0` component-by-component
4. **Super Jacobi check**: for all ordered triples (X,Y,Z), computes `(-1)^{p(X)p(Z)} [X,[Y,Z}} + (-1)^{p(Y)p(X)} [Y,[Z,X}} + (-1)^{p(Z)p(Y)} [Z,[X,Y}}` and verifies it is zero

Arithmetic is exact (Python `Fraction`).
