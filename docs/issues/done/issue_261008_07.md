### Response

#### 1. Mathematical Framework

The coboundary formula from `docs/math/C_coboundary_definition.md`:

$$(\delta f)(X, Y) = (-1)^{p(X)}[X, f(Y)]_0 \;-\; (-1)^{(p(X)+1)p(Y)}[Y, f(X)]_0 \;-\; f([X, Y]_0)$$

The bracket $[\cdot,\cdot]_0$ is the undeformed Lie superalgebra bracket (Schema 1).

The **odd linear map** $f: \mathfrak{g} \to \mathfrak{g}$ reverses parity:
$$f(Z_j) = \sum_{i:\, p(Z_i)\neq p(Z_j)} \phi_{Z_i, Z_j} \cdot Z_i$$

where $\phi_{Z_i, Z_j}$ are scalar parameters. Label convention: `phi_{output}_{input}`, e.g., `phi_H_1_E_eps_del1_pp` = coefficient of $H_1$ in $f(E_{\varepsilon+\delta_1,++})$.

#### 2. Parameterization of f — **Approval Required**

##### Option G — "General" (Recommended)

Keep **all** $\phi$ parameters independent and symbolic. Schema 4 stores the complete coboundary as a linear form in the $\phi$ parameters:
```
{X, Y, Z, phi, coeff}  →  (δf)(X,Y) contains coeff × phi × Z
```
This is structurally identical to Schema 2 (`{X, Y, Z, gb, coeff}`). It:
- Is fully general: any odd map $f$ can be recovered by substituting specific $\phi$ values
- Enables triviality analysis for any $f$ without recomputing
- File: `C_n_coboundary.json` (one per n, independent of specific $f$)

Parameter counts:

| n | C(n+1) | φ params | (δf) entries | Basis pairs |
|---|--------|----------|--------------|-------------|
| 1 | C(2)   | 32       | 192          | 28          |
| 2 | C(3)   | 176      | 2 418        | 171         |
| 3 | C(4)   | 528      | 11 128       | 561         |

##### Option S — "Sparse/Unit maps"

Generate one Schema 4 per basis unit map $f_k$ (where $f_k(Z_k) = Z_{partner}$, all others zero). This produces $\dim \mathfrak{g}$ separate files but avoids symbolic parameters.
- Harder to use for triviality analysis (requires superposition)
- Not recommended
