### Response

#### 1. Implementation Summary

**Script**: `src/C_gamma_generator.py`

**Approach**: First-order deformation tracking via `DeformedOscAlgebra`. Elements are represented as pairs `(poly0, polyk)`:
- `poly0`: standard PBW polynomial (undeformed part)
- `polyk`: `{gb_key: poly}` dictionary, the κ-coefficient per deformation parameter

During PBW reduction of `poly0`, whenever a boson `b_j^s` (PBW index ≥ 2) passes a fermion `a_1^σ` (PBW index < 2), a κ-correction is generated per the deformed exchange relation. Since κ² = 0, second-order terms are dropped throughout.

**Key technical issue resolved**: γ-polynomials contain a **K component** (scalar multiple of the even central element K, identified with 1). The standard `poly_to_basis` function requires `c_const = -f[n+1]/2` exactly, which fails for γ-polynomials. A new function `poly_to_basis_gamma` was introduced that computes `K_coeff = c_const + f[n+1]/2` and records `'K': K_coeff` in the decomposition when non-zero.

#### 2. Sign Convention — **Approval Required**

##### Convention A (Recommended — document-faithful)

```
[b_j^s, a_1^σ]_γ = −gb_{σ,j,s} · κ
```

This is the negative sign as written in `docs/math/C_inhomogeneous_definition.md`. Implemented in the current script.

##### Convention B (Positive sign)

```
[b_j^s, a_1^σ]_γ = +gb_{σ,j,s} · κ
```

Equivalent to redefining `gb_{σ,j,s} → −gb_{σ,j,s}` throughout, i.e., all γ coefficients flip sign. Purely conventional; produces the same algebraic structure.

**Recommendation**: Convention A, to remain faithful to the definition document.

#### 5. Proposed Schema 2 JSON Structure

Each `gamma_structure` entry has fields: `X`, `Y`, `Z`, `gb`, `coeff`, `sign_rule`.
- `Z` ∈ basis ∪ `{'K'}` (basis labels from Schema 1 plus the central identity K)
- `gb` is a gb parameter key such as `"gb_pp_1"`
- `coeff` is a rational number as a string (e.g. `"-1/2"`)

The `gb_matrix` field catalogues the 4n deformation parameters:
- Size: 2 × 2n (rows: σ ∈ {+,−}, columns: (j, s) ordered (1,+),(1,−),(2,+),(2,−),…)
- Label format: `gb_{σs}_{j}` where first letter = σ direction for a_1^σ, second = s direction for b_j^s
