### Mathematical Framework

The coboundary is computed from Schema 1 structure constants alone (no oscillator algebra). For a general odd linear map f parameterized by $\phi_{ij}$ (where $f(Z_j) = \sum_i \phi_{ij} Z_i$, $p(Z_i) \neq p(Z_j)$), expanding the three terms of $(\delta f)(X,Y)$:

$$(\delta f)(X, Y)[Z_w] = \sum_{i:\,p(Z_i)\neq p(Y)} \phi_{i,Y}\,(-1)^{p(X)}\,c_{X,Z_i}^w - \sum_{j:\,p(Z_j)\neq p(X)} \phi_{j,X}\,(-1)^{(p(X)+1)p(Y)}\,c_{Y,Z_j}^w - \sum_{k}\,c_{XY}^k\!\!\sum_{m:\,p(Z_m)\neq p(Z_k)} \phi_{m,k}\,\delta_{m,w}$$

This is linear in the $\phi$ parameters and computable purely from Schema 1.

**Schema 4 role**: Like Schema 2 records $\gamma$ symbolically (linear in gb), Schema 4 records $\delta f$ symbolically (linear in $\phi$). Later, triviality ($\gamma = \delta f$) is checked by linear algebra over the two parameter sets.

### Proposed Options for the Scope of $f$

#### Option A — General f (Recommended)

Keep **all** $2 \times \text{dim}_\text{even} \times \text{dim}_\text{odd}$ parameters free. This is the maximally general odd linear map and yields a complete Schema 4 from which triviality can be tested by solving a linear system.

```
n=1: 32 phi parameters
n=2: 176 phi parameters
n=3: 528 phi parameters
```

Advantage: No information is discarded; any subsequent triviality check works directly on the full Schema 4.  
Disadvantage: Schema 4 may contain many entries, but this is handled automatically by the script.

---

#### Option B — Cartan-to-Odd Restricted f

Only allow:
- $f(H_k) \in \text{span of odd generators}$ (n+1 Cartans → odd)
- $f(\text{odd}) \in \text{span of Cartans}$ (odd → n+1 Cartans)

All other $\phi_{ij}$ = 0 (root generators not in the domain of f, or only Cartan-aligned output allowed).

```
n=1: (n+1)×dim_odd + dim_odd×(n+1) = 2×4×2 = 16 phi parameters (H_1,H_2 only)
n=2: (3)×8 + 8×3 = 48 phi parameters
n=3: (4)×12 + 12×4 = 96 phi parameters
```

Advantage: Focuses on the physically natural deformation directions (Cartan ↔ odd).  
Disadvantage: May miss coboundary contributions from root-generator components of f.

---

#### Option C — Root-Compatible f

Only allow $\phi_{ij} \neq 0$ when the root of $Z_i$ differs from the root of $Z_j$ by exactly $\pm\varepsilon$. This is the most constrained and physically motivated option (maps generators related by the fermionic root direction).

For C(n+1), the even roots are $\pm 2\delta_k$, $\pm(\delta_i \pm \delta_j)$, and Cartans. The odd roots are $\pm\varepsilon \pm \delta_k$. Root-compatible f maps:
- $E_{\delta_k \pm \delta_l} \leftrightarrow E_{\varepsilon \pm \delta_k \pm \delta_l}$ (where such odd roots exist)
- $H_k \leftrightarrow E_{\varepsilon \pm ?}$ (Cartan compatibility uncertain)

```
n=1: ~8 phi parameters (only compatible pairs)
n=2: ~32 phi parameters
n=3: ~72 phi parameters
```

Advantage: Smallest set; most physically meaningful.  
Disadvantage: Requires careful root-compatibility analysis per pair; may exclude valid coboundary directions.

### Proposed phi Label Convention

**Label**: `phi_{out_idx}_{in_idx}` where `out_idx` and `in_idx` are 1-based positions in the full basis `even_labels + odd_labels`.

The phi_matrix table in Schema 4 provides the human-readable lookup:
```json
{
  "label": "phi_5_1",
  "output_idx": 5,
  "output_lbl": "E_eps1_del1_pp",
  "output_parity": 1,
  "input_idx": 1,
  "input_lbl": "H_1",
  "input_parity": 0,
  "description": "coeff of E_eps1_del1_pp in f(H_1)"
}
```

Using integer indices (rather than full label concatenation) keeps phi_label strings compact and stable.

### Proposed Schema 4 JSON Format

File naming: `data/C_{n}_coboundary.json`

```json
{
  "schema_version": "5.0",
  "algebra": { "family": "C", "m": 1, "n": 1, ... },
  "phi_matrix": {
    "description": "Parameters of the general odd linear map f",
    "count": 32,
    "parameters": [
      {
        "label": "phi_5_1",
        "output_idx": 5, "output_lbl": "E_eps1_del1_pp", "output_parity": 1,
        "input_idx":  1, "input_lbl":  "H_1",            "input_parity": 0,
        "description": "coeff of E_eps1_del1_pp in f(H_1)"
      }
    ]
  },
  "coboundary": [
    {
      "X": "H_1", "Y": "H_2",
      "phi_label": "phi_5_1",
      "Z": "E_eps1_del1_pp",
      "coeff": "2"
    }
  ],
  "metadata": { ... }
}
```

Entries cover all pairs $(X,Y)$ with PBW index $X \leq Y$ for which $(\delta f)(X,Y)$ has a non-zero $\phi$-dependent term. Entries with zero coefficient are omitted.
