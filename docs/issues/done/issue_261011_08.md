### 1. Linear-Algebra Setup

The deformation γ (Schema 2) is a 2-cocycle linear in the 4n gb-parameters.  
The coboundary δf (Schema 4) is a 2-cochain linear in the 2·dim_even·dim_odd φ-parameters.

**Triviality condition**: γ = δf  ⟺  the linear system `A·φ = B·gb` has a solution, where:
- `A` = coboundary matrix (n_triples × n_phi): `A[t][p]` = coeff of φ_p in `(δf)(X,Y)[Z]` for triple t
- `B` = gamma matrix (n_triples × n_gb): `B[t][g]` = coeff of gb_g in `γ(X,Y)[Z]` for triple t

The condition `B·gb ∈ Im(A)` is equivalent to: for every row `v` in the left null space of `A`, `v·(B·gb) = 0`.

Algorithm: row-reduce `[A | B]` pivoting on A-columns. After reduction, rows where A-block = 0 give independent linear constraints on gb.

### 5. Root Cause Analysis

The obstruction is structural, not arithmetic:

**Claim**: `(δf)(X,Y)[K] = 0` for ALL X, Y ∈ g and ALL odd linear maps f: g → g.

**Proof**: The coboundary formula is:
```
(δf)(X,Y) = (-1)^{p(X)} [X, f(Y)]  −  (-1)^{(p(X)+1)p(Y)} [Y, f(X)]  −  f([X,Y])
```
Each term is a bracket or map acting within g (the standard Lie superalgebra g = osp(2|2n)):
- `[X, f(Y)] ∈ g` since `[·,·]: g × g → g`
- `f([X,Y]) ∈ g` since `f: g → g`

Therefore `(δf)(X,Y) ∈ g` for all X, Y, f. The central element K is outside g (it is only used as a decomposition basis element for the κ·K = κ correction in the extended algebra L = g ⊕ κg). Hence the K-component of `(δf)(X,Y)` is always zero.

**Contrast**: The deformation γ(X,Y) contains K-components whenever the oscillator PBW normalization of `[X,Y]_deformed` produces a scalar correction κ·(identity) = κ·K. This occurs whenever the commutator `[b_j^s, a_1^σ] = -gb_{σ,j,s}·κ` generates a residual scalar term (i.e., when the surrounding word normalizes to the vacuum). Each gb parameter produces at least one such K-contribution (the certificates above), and these contributions are linearly independent over Q (the K-submatrix has full rank = 4n).

**Interpretation**: The K-components of γ represent a cohomological obstruction in `H²(g, k)` (central cohomology with trivial coefficients), while the coboundary image δ: Hom(g,g)_odd → C²(g,g) lies in `H²(g, g)` (adjoint cohomology). These two spaces are disjoint (K ∉ g), so the K-obstruction is irreducible.
