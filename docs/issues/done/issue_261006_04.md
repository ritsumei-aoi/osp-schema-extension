#### Verification Script

Implemented: `src/verify_C_structure.py`

- Loads each `data/C_{n}_structure.json` (n = 1, 2, 3).
- Builds the complete bracket table by deriving the anti-symmetric partner for every pair that appears in only one direction, and flags any explicit inconsistencies if both directions are stored.
- **Anti-symmetry check**: For all X, Y in the basis, verifies  
  `[X, Y] = −(−1)^{p(X)p(Y)} [Y, X]`  
  (coefficient-by-coefficient over each basis output Z).
- **Super Jacobi check**: For all ordered triples (X, Y, Z), verifies  
  `(−1)^{p(X)p(Z)} [X,[Y,Z]] + (−1)^{p(Y)p(X)} [Y,[Z,X]] + (−1)^{p(Z)p(Y)} [Z,[X,Y]] = 0`  
  using exact rational arithmetic (`fractions.Fraction`).
