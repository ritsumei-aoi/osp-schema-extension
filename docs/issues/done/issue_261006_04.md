### 1. Overview

The verification loads the three Schema 1 JSON files and builds a complete bracket table (both
directions) by reconstructing the reverse direction via graded anti-symmetry:

```
[Y, X} = -(-1)^{pX pY} [X, Y}
```

Two independent checks are performed:

| Check | What is verified |
|---|---|
| Anti-symmetry | Consistency of the full bracket table (sanity check on data loading/reconstruction) |
| Super Jacobi | `(-1)^{pX pZ}[X,[Y,Z}} + (-1)^{pY pX}[Y,[Z,X}} + (-1)^{pZ pY}[Z,[X,Y}} = 0` for all unordered triples — a nontrivial algebraic identity on the SC entries |

**Note on anti-symmetry scope**: Because the reverse direction of the bracket table is constructed
by applying anti-symmetry to the forward direction (which is all the JSON stores), the
anti-symmetry check is inherently a consistency/loading sanity check rather than an independent
mathematical verification. The Jacobi identity is the genuine independent algebraic check.
