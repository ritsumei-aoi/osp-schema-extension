## Context & Background
The existing Schema 1 (algebra structure) was designed for B(m,n). Extending to
C(n+1) requires modifications to several fields while maintaining backward
compatibility. Issue I01 has finalized the basis and PBW ordering.

## Requirements
1. Design `algebra` field for C(n+1) (family="C").
2. Design `oscillator_generators` without supplementary fermion.
3. Design `oscillator_relations` for standard fermionic pair (CAR).
4. Determine `central_elements` (kappa, K) for C(n+1).
5. Define file naming conventions (e.g., `C_1_structure.json`, `C_2_structure.json`, `C_3_structure.json`).

### Mandatory unified rules (fixed for all runs)
- **Algebra Field**: explicitly include `"m": 1` and the dimension formulas `even`: `2n^2 + n + 1`, `odd`: `4n`.
- **Oscillator Generators**: two keys, `"fermions"` (with `m=1`, labels `a_1_p, a_1_m`) and `"bosons"` (with rank `n`).
- **Central Elements**: `central_elements` is a **top-level key**, containing `kappa` (parity 1) and `K` (parity 0).
- **File Naming**: `C_{n}_structure.json`, where `n` is the bosonic rank (e.g., C(2) uses `n=1`).

### Response

#### 1. Architecture Overview & Top-Level Keys

Schema 1 (`C_{n}_structure.json`) represents the fundamental Lie superalgebra structure of $C(n+1) = \mathfrak{osp}(2|2n)$.
In accordance with the mandatory unified rules, `central_elements` is established as a standalone top-level key.

The top-level structure is defined as:
```json
{
  "schema_version": "5.0",
  "algebra": { ... },
  "central_elements": { ... },
  "oscillator_generators": { ... },
  "oscillator_relations": { ... },
  "basis": { ... },
  "parity": { ... },
  "generator_realization": { ... },
  "structure_constants": [ ... ],
  "metadata": { ... }
}
```

#### 2. Detailed Specification of Schema 1 Fields

##### 2.1 `schema_version`
```json
"schema_version": "5.0"
```

##### 2.2 `algebra`
Follows the unified rule with explicit `"m": 1`, bosonic rank `n`, Cartan type `C(n+1)`, alternative notation `osp(2|2n)`, and dimension formulas:
- Formula: `even` $= 2n^2 + n + 1$, `odd` $= 4n$, `total` $= 2n^2 + 5n + 1$.

*Example for $n=1$ ($C(2) = \mathfrak{osp}(2|2)$)*:
```json
{
  "family": "C",
  "m": 1,
  "n": 1,
  "cartan_type": "C(2)",
  "alternative_notation": {
    "osp": "osp(2|2)",
    "dimension_formula": "osp(2m|2n) with m=1: even = 2n^2 + n + 1, odd = 4n, total = 2n^2 + 5n + 1"
  },
  "dimension": {
    "total": 8,
    "even": 4,
    "odd": 4
  }
}
```
*(For $n=2$, `cartan_type`: `"C(3)"`, `total`: 19, `even`: 11, `odd`: 8; for $n=3$, `cartan_type`: `"C(4)"`, `total`: 34, `even`: 22, `odd`: 12).*

##### 2.3 `central_elements` (Top-Level Key)
Establishes the odd nilpotent deformation carrier $\kappa$ ($p=1, \kappa^2=0$) and the even central identity element $K$ ($p=0, K=1$):
```json
{
  "kappa": {
    "parity": 1,
    "nilpotent_order": 2,
    "relation": "kappa^2 = 0",
    "description": "Odd central nilpotent element carrier of inhomogeneous deformation parameter"
  },
  "K": {
    "parity": 0,
    "scalar_value": 1,
    "description": "Even central identity element (identified with scalar 1; excluded from PBW basis)"
  }
}
```

##### 2.4 `oscillator_generators`
Follows the unified rule with two dedicated keys: `"fermions"` (with `m=1`, labels `["a_1_p", "a_1_m"]`) and `"bosons"` (with rank `n`):
```json
{
  "fermions": {
    "count": 2,
    "m": 1,
    "labels": ["a_1_p", "a_1_m"],
    "parity": 1,
    "description": "Standard fermionic CAR pair a_1^± (replaces B(0,n) supplementary fermion a_0)"
  },
  "bosons": {
    "count": 2,
    "n": 1,
    "labels": ["b_1_p", "b_1_m"],
    "parity": 0,
    "description": "Bosonic CCR oscillators b_i^± with i=1,...,n"
  }
}
```

##### 2.5 `oscillator_relations`
Defines standard CAR for fermions, CCR for bosons, and commuting mixed relations in the undeformed algebra:
```json
{
  "fermionic_anticommutators": {
    "description": "Canonical anticommutation relations (CAR) for standard fermionic pair",
    "relations": {
      "same_type": "{a_1^±, a_1^±} = 0 (nilpotent: (a_1^±)^2 = 0)",
      "conjugate_pair": "{a_1^-, a_1^+} = 1"
    }
  },
  "bosonic_commutators": {
    "description": "Canonical commutation relations (CCR) for bosonic oscillators",
    "relations": {
      "same_type": "[b_i^±, b_j^±] = 0 for all i, j",
      "conjugate_pair": "[b_i^-, b_j^+] = δ_{ij}"
    }
  },
  "mixed_commutators": {
    "boson_fermion": "[b_i^±, a_1^±] = 0 (in undeformed algebra)"
  }
}
```

##### 2.6 `basis`
Strictly reflects the finalized and approved Option 1 PBW ordering and generator labels from Issue I01-1 / `handover/notation.md`:
- `ordering_convention`: `"PBW: κ < [odd: ++, +-, -+, --] < [even]"`
- Even basis: simple coroots `H_1, ..., H_{n+1}`, positive long roots `E_2del{k}_p`, positive cross roots `E_del{i}_del{j}_pp`, negative long roots `E_2del{k}_m`, negative cross roots `E_del{i}_del{j}_mm`, mixed cross roots `E_del{i}_del{j}_pm`, `E_del{i}_del{j}_mp`.
- Odd basis: `E_eps1_del{k}_pp` ($k=1..n$) $<$ `E_eps1_del{k}_pm` ($k=1..n$) $<$ `E_eps1_del{k}_mp` ($k=1..n$) $<$ `E_eps1_del{k}_mm` ($k=1..n$).

*Example for $n=1$ ($C(2)$)*:
```json
{
  "even": [
    "H_1", "H_2",
    "E_2del1_p",
    "E_2del1_m"
  ],
  "odd": [
    "E_eps1_del1_pp",
    "E_eps1_del1_pm",
    "E_eps1_del1_mp",
    "E_eps1_del1_mm"
  ],
  "ordering_convention": "PBW: κ < [odd: ++, +-, -+, --] < [even]"
}
```

##### 2.7 `parity`
Maps each generator to its $\mathbb{Z}_2$-degree:
- All even elements (`H_k`, `E_2del{k}_p/m`, `E_del{i}_del{j}_...`): `0`
- All odd elements (`E_eps1_del{k}_{s1}{s2}`): `1`

##### 2.8 `generator_realization`
Stores standard normal-ordered form in oscillators (`ordering: "a_1_p, a_1_m, b_1_p, b_1_m, ..."`):
- Cartans:
  - `H_1`: $a_1^+ a_1^- + b_1^+ b_1^-$ (`[{"words": ["a_1_p", "a_1_m"], "coeff": "1"}, {"words": ["b_1_p", "b_1_m"], "coeff": "1"}]`)
  - `H_k` ($2 \le k \le n$): $b_{k-1}^+ b_{k-1}^- - b_k^+ b_k^-$
  - `H_{n+1}`: $-b_n^+ b_n^- - 1/2$ (`[{"words": ["b_n_p", "b_n_m"], "coeff": "-1"}, {"words": [], "coeff": "-1/2"}]`)
- Even roots:
  - `E_2del{k}_p`: $(b_k^+)^2$, `E_2del{k}_m`: $(b_k^-)^2$
  - `E_del{i}_del{j}_pp`: $b_i^+ b_j^+$, `E_del{i}_del{j}_pm`: $b_i^+ b_j^-$, `E_del{i}_del{j}_mp`: $b_i^- b_j^+$, `E_del{i}_del{j}_mm`: $b_i^- b_j^-$
- Odd roots:
  - `E_eps1_del{k}_pp`: $a_1^+ b_k^+$
  - `E_eps1_del{k}_pm`: $a_1^+ b_k^-$
  - `E_eps1_del{k}_mp`: $a_1^- b_k^+$
  - `E_eps1_del{k}_mm`: $a_1^- b_k^-$

##### 2.9 `structure_constants`
List of non-zero graded brackets $[X, Y\} = \sum_Z c_{XY}^Z Z$:
```json
[
  {
    "X": "H_1",
    "Y": "E_eps1_del1_pp",
    "Z": "E_eps1_del1_pp",
    "coeff": "2",
    "sign_rule": "graded"
  }
]
```

##### 2.10 `metadata`
```json
{
  "generated_by": "build_C_structure_constants.py",
  "generation_date": "YYYY-MM-DD",
  "references": [
    "Frappat et al. (2000), Dictionary on Lie Algebras and Superalgebras",
    "Bakalov and Sullivan (2017)"
  ]
}
```

#### 3. File Naming Conventions

Following the mandatory unified rule, schema files for $C(n+1) = \mathfrak{osp}(2|2n)$ are indexed by the bosonic rank $n$:
- **Pattern**: `C_{n}_structure.json`
- **Specific instances**:
  - $n=1$ ($C(2) = \mathfrak{osp}(2|2)$): `C_1_structure.json`
  - $n=2$ ($C(3) = \mathfrak{osp}(2|4)$): `C_2_structure.json`
  - $n=3$ ($C(4) = \mathfrak{osp}(2|6)$): `C_3_structure.json`

#### 4. Compatibility and Differences with B(0,n) Schema

| Field / Key | B(0,n) Schema (v5.0) | C(n+1) Schema (v5.0 Extension) | Architectural Rationale |
|---|---|---|---|
| `algebra.family` | `"B"` | `"C"` | Lie superalgebra family identification |
| `algebra.m` | `0` | `1` | Fermionic rank ($m=1$ for $osp(2|2n)$) |
| `algebra.cartan_type` | `"B(0,n)"` | `"C(n+1)"` | Frappat Cartan classification |
| `algebra.dimension` | even $= 2n^2+n$, odd $= 2n$ | even $= 2n^2+n+1$, odd $= 4n$ | $\mathfrak{so}(2)$ factor adds $+1$ even dim; CAR pair adds $2 \times 2n$ odd roots |
| `central_elements` | Implicit / schema note | **Top-level key** with `kappa` ($p=1$) and `K` ($p=0$) | Unifies central extension handling across pipelines |
| `oscillator_generators` | `supplementary_fermion` (`a_0`, $a_0^2=1/2$) and `bosons` | `fermions` (`m=1`, `a_1_p, a_1_m`) and `bosons` | Standard fermionic creation/annihilation algebra |
| `oscillator_relations` | `supplementary_fermion_relation` | `fermionic_anticommutators` (CAR) | $\{a_1^-, a_1^+\} = 1$, $(a_1^\pm)^2 = 0$ |
| `basis.even` | $H_1, \ldots, H_n$ ($n$ Cartans) + roots | $H_1, \ldots, H_{n+1}$ ($n+1$ Cartans) + roots | Rank $n+1$; $H_1$ contains $a_1^+ a_1^- + b_1^+ b_1^-$ |
| `basis.odd` | `E_del{k}_p/m` ($2n$ generators) | `E_eps1_del{k}_pp/pm/mp/mm` ($4n$ generators) | Fully graded by $(\varepsilon, \delta_k)$ signs |
| `basis.ordering_convention` | `κ < [odd] < [even]` | `κ < [odd: ++, +-, -+, --] < [even]` | Option 1 charge-stratified convention |
