#### Approved implementation proposal and initial checks

No Python generator or Python test files currently exist under `src/` or

**Proposed generator design**

1. `build_basis(n)` validates `n >= 1` and builds the even/odd label arrays
   in the exact I01 Option A order. It also returns the parity map and
   oscillator realizations, using the formulas in
   `handover/notation.md` and `docs/json_schema_specification.md`.
2. Represent an oscillator polynomial as a mapping from canonical oscillator
   words (tuples of labels) to exact `Fraction` coefficients. A recursive
   normal-order rewrite places `a_1_p` before `a_1_m`, and each boson creator
   before its annihilator, with bosonic indices in a fixed order. Apply
   `a_1_m a_1_p = 1 - a_1_p a_1_m`,
   `b_i_m b_j_p = b_j_p b_i_m + δ_ij`, same-type boson commutativity,
   fermion nilpotency (`a_1_p^2 = a_1_m^2 = 0`), and boson/fermion
   commutativity. All reductions use exact rational coefficients.
3. Form each graded bracket as `XY - (-1)^(p(X)p(Y)) YX`, normalize it,
   and decompose it into the given generator realizations by exact rational
   linear elimination over the constant and normal-ordered monomial
   coordinates. Raise an explicit error if any nonzero residual remains;
   do not silently omit a term outside the span.
4. Enumerate unordered pairs in PBW basis order, including equal odd pairs
   (which can have nonzero anticommutators), and emit one record per nonzero
   output coefficient using the approved v5.0 shape:
   `X`, `Y`, `Z`, rational-string `coeff`, and `sign_rule: "graded"`.
   Generate the remaining Schema 1 fields and metadata from the specification,
   and serialize deterministically to `data/C_{n}_structure.json`.
5. Expose a rank-parameterized function such as
   `generate_schema(n)` and a CLI accepting ranks/output directory, defaulting
   to `n=1,2,3` and `data/`. Keep generation separate from module import so
   unit tests can call the functions without writing final JSON.

**Proposed tests**

  order, and parity coverage.
- Verify oscillator rewrite identities for the CAR, CCR, same-type
  commutation, and mixed commutation rules.
- Verify every realization has exactly one basis label and matching parity.
- Verify all basis-pair brackets decompose with zero residual; check graded

- Validate generated JSON top-level fields, complete basis/parity/realization
  coverage, structure-constant record shape, dimensions, and filenames.
  Verify repeated generation is byte-for-byte deterministic.
