#### 2. Proposed Schema 3 JSON Format

Schema 3 represents the **deformed algebra structure** at specific gb values. The deformed bracket is:

```
[X, Y]_γ = [X, Y]_0 + κ · γ(X, Y)|_{gb=specific}
```

Since κ is odd and central (κ²=0), the deformed algebra has two types of non-zero structure constants:
- **"body" terms**: coefficients of Z in [X,Y]_0 (from Schema 1, gb-independent)
- **"kappa" terms**: coefficients of κ·Z in κ·γ(X,Y) evaluated at the specific gb values

Proposed top-level structure:

```json
{
  "schema_version": "5.0",
  "schema_layer": 3,
  "algebra": { ... },
  "gb_assignment": {
    "profile": "gb1",
    "description": "All 4n gb parameters set to +1",
    "values": {
      "gb_a1p_b1p": "1",
      "gb_a1p_b1m": "1",
      "gb_a1m_b1p": "1",
      "gb_a1m_b1m": "1"
    }
  },
  "evaluated_structure_constants": [
    {
      "X": "H_1",
      "Y": "E_eps1_del1_pp",
      "Z": "E_eps1_del1_pp",
      "coeff": "2",
      "part": "body",
      "sign_rule": "graded"
    },
    {
      "X": "E_eps1_del1_pp",
      "Y": "E_eps1_del1_mm",
      "Z": "E_eps1_del1_pm",
      "coeff": "-1",
      "part": "kappa",
      "sign_rule": "graded"
    }
  ],
  "entry_count": {
    "body": 84,
    "kappa": 50,
    "total": 134
  },
  "metadata": { ... }
}
```

- `part: "body"` — Z-coefficient from the undeformed bracket [X,Y]_0
- `part: "kappa"` — κ·Z-coefficient from the evaluated deformation κ·γ(X,Y)

The `part` field distinguishes the two sectors without requiring a separate schema.

**File naming convention**: `C_{n}_evaluated_{profile}.json`
- e.g., `C_1_evaluated_gb0.json`, `C_1_evaluated_gb1.json`
