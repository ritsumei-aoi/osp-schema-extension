## Proposal for I06-1 (Schema 3: evaluated structure)

### 1. Recommended first assignment: `gb_zero`

Because the user instruction says to begin “starting with `gb=0`”, I recommend that the **first approved evaluation profile** be:

```text
gb_a1p_bjp = 0
gb_a1p_bjm = 0
gb_a1m_bjp = 0
gb_a1m_bjm = 0
for every j = 1, ..., n
```

I recommend naming this profile:

```text
gb_zero
```

Why this is the best first evaluated profile:

1. it is mathematically canonical
2. it must recover the undeformed Layer 1 bracket exactly
3. it gives the cleanest validation of the Schema 2 substitution engine before trying non-zero sign choices
4. it avoids introducing arbitrary sign conventions before the baseline case is verified

### 2. Proposed evaluation method

I recommend implementing Schema 3 by **evaluating the already-generated Schema 2 gamma data**, not by recomputing oscillator brackets from scratch.

Concretely, for each basis pair `(X, Y)`:

```text
[X, Y]_(evaluated)
= [X, Y]_0 + kappa * gamma_eval(X, Y)
```

where:

1. `[X, Y]_0` comes from `C_n_structure.json`
2. `gamma_eval(X, Y)` is obtained from `C_n_gamma.json` by substituting the approved numeric values into each sparse `coeff` dictionary

So for a Schema 2 entry of the form

```json
{
  "X": "...",
  "Y": "...",
  "Z": "...",
  "coeff": {
    "gb_a1p_b1p": "-1",
    "gb_a1m_b1m": "2"
  }
}
```

the evaluated coefficient becomes

```text
(-1) * value(gb_a1p_b1p) + 2 * value(gb_a1m_b1m)
```

This approach is preferable because it:

1. reuses the approved Schema 2 data directly
2. makes the Layer 2 → Layer 3 relationship explicit
3. gives a simple consistency check: with `gb_zero`, every gamma contribution must vanish

### 4. Proposed Schema 3 JSON shape

Because Schema 3 is an evaluated version of Schema 1 + Schema 2, I recommend keeping the same structural backbone as Schema 1 and adding an explicit evaluated-profile block.

Proposed top-level layout:

```json

  "algebra": { ... },
  "basis": { ... },
  "parity": { ... },
  "central_elements": { ... },
  "evaluation_profile": {
    "name": "gb_zero",
    "assignment_type": "explicit",
    "gb_values": {
      "gb_a1p_b1p": "0",
      "gb_a1p_b1m": "0"
    }
  },
  "evaluated_structure_constants": [
    {
      "X": "...",
      "Y": "...",
      "Z": "...",

    }
  ],
  "consistency_with_schema_2": {
    "gamma_file": "C_n_gamma.json",
    "structure_file": "C_n_structure.json"
  },

}
```

Important convention:

- `evaluated_structure_constants` should store the **final coefficient of `Z` after substitution**
- if the evaluated deformation contributes to a `K` term, that should be retained as `Z = "K"` just as Schema 2 already allows
