#### Proposed implementation

Implement `src/C_generators.py` with public functions along these lines:

- `build_basis(n)` returns the ordered even and odd label lists, parity map,
  and generator-to-root information for integer \(n\geq1\).
- `build_realizations(n)` constructs each basis generator from exact
  oscillator monomials and rational coefficients.
- `graded_bracket(x, y)` computes the bracket using the generator parities
  and the undeformed oscillator relations.
- `compute_structure_constants(n)` computes and validates all nonzero
  coefficients in the agreed basis.
- `build_schema(n)` and `write_schema(n, output_dir)` assemble and serialize
  the complete v5.0 Schema 1 document.

The basis builder will follow `handover/notation.md`: even labels in the
approved Cartan/positive-root/negative-root order; odd labels with the
positive-\(\varepsilon\) families before the negative-\(\varepsilon\)
families; and PBW blocks \(\kappa < [\mathrm{odd}] < [\mathrm{even}]\).
Neither \(K\) nor \(\kappa\) will be included in the algebra's basis arrays.

Represent an oscillator polynomial as a mapping from an ordered oscillator
word (tuple of labels) to an exact `sympy.Rational` coefficient. Implement a
deterministic normal-order rewrite using the specified relations:

- fermion squares vanish and
  `a_1_m a_1_p = 1 - a_1_p a_1_m`;
- bosons of like type commute and
  `b_i_m b_j_p = δ_ij + b_j_p b_i_m`;
- fermion and boson generators commute.

Realize the generators using the Cartan and root formulas from the approved
Schema 1 specification. In particular, use
`E_2del{i}_p = 1/2 (b_i_p)^2` and
`E_2del{i}_m = 1/2 (b_i_m)^2` for every \(i\). Compute
\([X,Y\}=XY-(-1)^{p(X)p(Y)}YX\), normal-order the result, then solve exactly
for its coefficients in the realization vectors of the basis generators.
Raise an explicit error if the residual is nonzero or the result is outside
the basis span; do not discard scalar terms or unrecognized monomials.

Serialize one record per nonzero coefficient for every ordered pair \(X,Y\),
iterating \(X\), \(Y\), and output \(Z\) in basis order. This makes the
structure-constant array deterministic and records the reverse bracket
according to graded skew-symmetry as well. Store rational coefficients as
strings and use `"sign_rule": "graded"`. `build_schema` will emit every
top-level key and field defined in `docs/json_schema_specification.md`,
including the exact basis, parity map, realization records, central element
metadata, and generated-by/date/reference metadata. The CLI will write
`data/C_1_structure.json`, `data/C_2_structure.json`, and
`data/C_3_structure.json`.
