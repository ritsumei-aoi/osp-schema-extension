## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

For C(n+1) root structure, refer to:
Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

### Proposal options (human selected Option A)

#### Root sets and basis for \(C(n+1)=\mathfrak{osp}(2|2n)\)

Use \(\varepsilon\) and \(\delta_1,\ldots,\delta_n\), with simple roots
\(\alpha_1=\varepsilon-\delta_1\), \(\alpha_k=\delta_{k-1}-\delta_k\)
(\(2\leq k\leq n\)), and \(\alpha_{n+1}=2\delta_n\). This gives the positive
even roots
\[
\Delta_{\bar 0}^+=\{2\delta_i:1\leq i\leq n\}
\cup\{\delta_i-\delta_j,\delta_i+\delta_j:1\leq i<j\leq n\}
\]
and positive odd roots
\[
\Delta_{\bar 1}^+=\{\varepsilon-\delta_i,\varepsilon+\delta_i:1\leq i\leq n\}.
\]
The negative roots are the negatives of these roots. Accordingly, define the
even basis as \(H_1,\ldots,H_{n+1}\) and one root vector for every even root;
define the odd basis as one root vector for every odd root. The Cartan
generators are those in `Cn1_definition.md` (in particular, \(H_1\) includes
the fermion number and \(H_{n+1}=-b_n^+b_n^--\tfrac12\)).

| Algebra | Even basis | Odd basis |
|---|---|---|
| \(C(2)\), \(n=1\) | \(H_1,H_2;\ E_{\pm2\delta_1}\) (4 total) | \(E_{\varepsilon-\delta_1},E_{\varepsilon+\delta_1},E_{-\varepsilon+\delta_1},E_{-\varepsilon-\delta_1}\) (4 total) |
| \(C(3)\), \(n=2\) | \(H_1,H_2,H_3;\ E_{\pm2\delta_1},E_{\pm2\delta_2};\ E_{\pm(\delta_1-\delta_2)},E_{\pm(\delta_1+\delta_2)}\) (11 total) | \(E_{\varepsilon\pm\delta_i},E_{-\varepsilon\pm\delta_i}\) for \(i=1,2\) (8 total) |
| \(C(4)\), \(n=3\) | \(H_1,\ldots,H_4;\ E_{\pm2\delta_i}\) for \(i=1,2,3;\ E_{\pm(\delta_i-\delta_j)},E_{\pm(\delta_i+\delta_j)}\) for \(1\leq i<j\leq3\) (22 total) | \(E_{\varepsilon\pm\delta_i},E_{-\varepsilon\pm\delta_i}\) for \(i=1,2,3\) (12 total) |

These counts agree with \(\dim\mathfrak g_{\bar0}=2n^2+n+1\) and
\(\dim\mathfrak g_{\bar1}=4n\).

#### Generator labels

Keep the established `p`/`m` oscillator suffixes for \(+\)/\(-\). Use
`H_1` through `H_{n+1}` for the Cartan generators and retain the even-root
labels from the B(0,n) convention:

| Root | Label | Oscillator realization |
|---|---|---|
| \(2\delta_i\), \(-2\delta_i\) | `E_2del{i}_p`, `E_2del{i}_m` | \((b_i^+)^2\), \((b_i^-)^2\) |
| \(\delta_i+\delta_j\), \(-(\delta_i+\delta_j)\), \(i<j\) | `E_del{i}_del{j}_pp`, `E_del{i}_del{j}_mm` | \(b_i^+b_j^+\), \(b_i^-b_j^-\) |
| \(\delta_i-\delta_j\), \(-(\delta_i-\delta_j)\), \(i<j\) | `E_del{i}_del{j}_pm`, `E_del{i}_del{j}_mp` | \(b_i^+b_j^-\), \(b_i^-b_j^+\) |
| \(\varepsilon+\delta_i,\varepsilon-\delta_i\) | `E_eps1_del{i}_pp`, `E_eps1_del{i}_pm` | \(a_1^+b_i^+\), \(a_1^+b_i^-\) |
| \(-\varepsilon+\delta_i,-\varepsilon-\delta_i\) | `E_eps1_del{i}_mp`, `E_eps1_del{i}_mm` | \(a_1^-b_i^+\), \(a_1^-b_i^-\) |

For pairs, iterate \(1\leq i<j\leq n\). The first odd suffix character
records the fermion sign and the second the boson sign. The labels thus cover
the four odd roots for each \(i\), without conflating the \(\varepsilon\)
sign with the \(\delta_i\) sign.

#### PBW options for human selection

Both options below exclude the scalar identity \(K=1\), as in the existing
schema convention. In each family, iterate indices increasingly; for pair
roots iterate lexicographically over \(i<j\).

**Option A — preserve the existing B(0,n) parity-block convention.**
Order the basis as \(\text{odd}<\text{even}\), with:

1. Odd: for \(i=1,\ldots,n\), `E_eps1_del{i}_pp`, `E_eps1_del{i}_pm`;
   then for \(i=1,\ldots,n\), `E_eps1_del{i}_mp`, `E_eps1_del{i}_mm`.
2. Even: `H_1,...,H_{n+1}`; then `E_2del{i}_p`,
   `E_del{i}_del{j}_pp`, `E_del{i}_del{j}_pm`; then
   `E_2del{i}_m`, `E_del{i}_del{j}_mm`, `E_del{i}_del{j}_mp`.

This puts all \(\varepsilon\)-positive odd roots before all
\(\varepsilon\)-negative odd roots, while preserving the established
Cartan/positive-even/negative-even block pattern.

**Option B — triangular root-space order.**
Order all negative-root vectors first, then the Cartan, then all
positive-root vectors:

1. Negative even: `E_2del{i}_m`, `E_del{i}_del{j}_mm`,
   `E_del{i}_del{j}_mp`.
2. Negative odd: `E_eps1_del{i}_mp`, `E_eps1_del{i}_mm`.
3. Cartan: `H_1,...,H_{n+1}`.
4. Positive odd: `E_eps1_del{i}_pp`, `E_eps1_del{i}_pm`.
5. Positive even: `E_2del{i}_p`, `E_del{i}_del{j}_pp`,
   `E_del{i}_del{j}_pm`.

This is the conventional \(\mathfrak n^-<\mathfrak h<\mathfrak n^+\)
triangular grouping; it differs from Option A in whether parity blocks or
root-space blocks take precedence.

**Selection:** The human researcher selected Option A to preserve the existing
B(0,n) parity-block convention.

The finalized conventions are recorded in `handover/notation.md`. The even
and odd bases for C(2), C(3), and C(4), PBW ordering, and oscillator generator
labels are documented, and all completion criteria are satisfied.
