B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW

https://github.com/ritsumei-aoi/osp-triviality

### 1. Basis Lists (for $n=1, 2, 3$)

**Generator Label Conventions:**
- **Bosonic Oscillators**: `b_k_p` ($b_k^+$), `b_k_m` ($b_k^-$)
- **Fermionic Oscillators**: `a_1_p` ($a_1^+$), `a_1_m` ($a_1^-$)
- **Even Basis Labels**:
  - `H_k`: Cartan generators ($k=1 \dots n+1$)
  - `E_2delk_p`, `E_2delk_m`: Roots $\pm 2\delta_k$
  - `E_del{i}_del{j}_pp`, `E_del{i}_del{j}_mm`: Roots $\pm(\delta_i + \delta_j)$
  - `E_del{i}_del{j}_pm`, `E_del{i}_del{j}_mp`: Roots $\pm(\delta_i - \delta_j)$
- **Odd Basis Labels**:
  - `E_eps1_delk_pp`: Root $\varepsilon + \delta_k$
  - `E_eps1_delk_pm`: Root $\varepsilon - \delta_k$
  - `E_eps1_delk_mp`: Root $-\varepsilon + \delta_k$
  - `E_eps1_delk_mm`: Root $-\varepsilon - \delta_k$

### 2. PBW Ordering Options

I propose three options for the PBW ordering. **Option A** is recommended for consistency with the existing $B(0,n)$ v5.0 schema.

**Option A: Parity-based (Fermionic-first)**
- **Order**: $\kappa < [\text{Odd Roots}] < [\text{Even Cartan}] < [\text{Even Roots}]$
- **Internal Odd Order**: Sort by $\varepsilon$-sign (p, m), then by $\delta$-sign (p, m), then by index $k$.
  - Example: `E_eps1_del1_pp`, `E_eps1_del2_pp`, `E_eps1_del1_pm`, `E_eps1_del2_pm`, `E_eps1_del1_mp`, ...
- **Internal Even Order**: $H_1, \dots, H_{n+1} \to \text{Pos. Roots} \to \text{Neg. Roots} \to \text{Mixed Roots}$ (matching B(0,n)).
- **Pros**: Maintains the $B(0,n)$ convention where nilpotent/odd elements come first.

**Option B: Weight-based (Standard Lie convention)**
- **Order**: $\kappa < [\text{Even Cartan}] < [\text{Positive Roots}] < [\text{Negative Roots}]$
- **Internal order**: Mixed parity within root blocks, sorted by weight height.
- **Pros**: Mathematically intuitive for root system analysis.

**Option C: Oscillator-lexicographical**
- **Order**: $\kappa < \text{Sorted by oscillator word realization alphabetically}$
- **Pros**: Purely algorithmic and stable.
