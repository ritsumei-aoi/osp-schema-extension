B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW

https://github.com/ritsumei-aoi/osp-triviality

#### 2. PBW Ordering Options (Action Required)

Following the Fermionic-first convention from B(0,n) ($[\text{odd generators}] < [\text{even generators}]$), we need to decide the internal ordering for the odd generators. Please select one of the following options:

*   **Option A (Sign-block grouped):** Groups odd generators by their $\varepsilon$ and $\delta$ signs first.
    1.  $E_{\varepsilon+\delta_k}$ for $k=1..n$
    2.  $E_{\varepsilon-\delta_k}$ for $k=1..n$
    3.  $E_{-\varepsilon+\delta_k}$ for $k=1..n$
    4.  $E_{-\varepsilon-\delta_k}$ for $k=1..n$
    *(Followed by Even: Cartan < Positive roots < Negative roots)*

*   **Option B (Index-grouped):** Groups odd generators by the index $k$ first.

    *(Followed by Even: Cartan < Positive roots < Negative roots)*
