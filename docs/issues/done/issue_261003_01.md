## Context & Background

B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

#### Proposal: root system, basis, and generator labels

Use the Frappat root coordinates \(\varepsilon,\delta_1,\ldots,\delta_n\), with
\(\varepsilon\) the fermionic coordinate and the \(\delta_i\) the bosonic
coordinates. A compatible simple system is
\[
\alpha_1=\varepsilon-\delta_1,\quad
\alpha_{i+1}=\delta_i-\delta_{i+1}\ (1\leq i<n),\quad
\alpha_{n+1}=2\delta_n.
\]
This gives positive odd roots \(\varepsilon\pm\delta_i\) and positive even
roots \(2\delta_i\), \(\delta_i+\delta_j\), and \(\delta_i-\delta_j\) for
\(i<j\); negative roots are their opposites. The even generators include
\(H_1,\ldots,H_{n+1}\), accounting for the \(\mathfrak{so}(2)\) Cartan
generator as well as the \(\mathfrak{sp}(2n)\) Cartan generators.

Keep the B(0,n) even-root labels and define the C(n+1) odd-root labels by
putting the \(\varepsilon\) sign first and the \(\delta_i\) sign second:

| Root | Label | Oscillator realization |
|---|---|---|
| \(\varepsilon+\delta_i\) | `E_eps1_del{i}_pp` | `a_1_p b_i_p` |
| \(\varepsilon-\delta_i\) | `E_eps1_del{i}_pm` | `a_1_p b_i_m` |
| \(-\varepsilon+\delta_i\) | `E_eps1_del{i}_mp` | `a_1_m b_i_p` |
| \(-\varepsilon-\delta_i\) | `E_eps1_del{i}_mm` | `a_1_m b_i_m` |

Here `p` and `m` denote \(+\) and \(-\), respectively. Thus the even
generators are labeled `H_k`, `E_2del{i}_p/m`, and
`E_del{i}_del{j}_pp/pm/mp/mm` (\(i<j\)); the odd generators are the four
`E_eps1_del{i}_pp/pm/mp/mm` labels for each \(i\).

The explicit basis lists below use an even-generator display order matching
the existing B(0,n) schema: Cartan, positive long roots, positive pair roots,
negative long roots, negative sum roots, then the two mixed-sign pair roots.
The odd display order is positive-\(\varepsilon\) roots first (delta index
ascending, `pp` then `pm`), followed by negative-\(\varepsilon\) roots (delta
index ascending, `mp` then `mm`).

**C(2), \(n=1\)** — even:
`H_1, H_2, E_2del1_p, E_2del1_m`.
Odd:
`E_eps1_del1_pp, E_eps1_del1_pm, E_eps1_del1_mp, E_eps1_del1_mm`.
Dimensions: \(4|4\), total \(8\).

**C(3), \(n=2\)** — even:
`H_1, H_2, H_3, E_2del1_p, E_2del2_p, E_del1_del2_pp, E_2del1_m, E_2del2_m, E_del1_del2_mm, E_del1_del2_pm, E_del1_del2_mp`.
Odd:
`E_eps1_del1_pp, E_eps1_del1_pm, E_eps1_del2_pp, E_eps1_del2_pm, E_eps1_del1_mp, E_eps1_del1_mm, E_eps1_del2_mp, E_eps1_del2_mm`.
Dimensions: \(11|8\), total \(19\).

**C(4), \(n=3\)** — even:
`H_1, H_2, H_3, H_4, E_2del1_p, E_2del2_p, E_2del3_p, E_del1_del2_pp, E_del1_del3_pp, E_del2_del3_pp, E_2del1_m, E_2del2_m, E_2del3_m, E_del1_del2_mm, E_del1_del3_mm, E_del2_del3_mm, E_del1_del2_pm, E_del1_del2_mp, E_del1_del3_pm, E_del1_del3_mp, E_del2_del3_pm, E_del2_del3_mp`.
Odd:
`E_eps1_del1_pp, E_eps1_del1_pm, E_eps1_del2_pp, E_eps1_del2_pm, E_eps1_del3_pp, E_eps1_del3_pm, E_eps1_del1_mp, E_eps1_del1_mm, E_eps1_del2_mp, E_eps1_del2_mm, E_eps1_del3_mp, E_eps1_del3_mm`.
Dimensions: \(22|12\), total \(34\).

These counts follow \(\dim\mathfrak g_{\bar 0}=2n^2+n+1\) and
\(\dim\mathfrak g_{\bar 1}=4n\), and include the \(n+1\) Cartan generators.

#### PBW ordering choices for human selection

Both choices below order the non-central algebra basis; \(K\), if represented
as the scalar identity, is excluded from the basis as in the B(0,n) schema.
If an extended/deformed basis explicitly includes \(\kappa\), place it first,
as in the existing B(0,n) convention.

**Option A — preserve the B(0,n) parity-block convention (recommended for
schema consistency):**
`κ < [odd: E_eps1_del{i}_pp, E_eps1_del{i}_pm (i ascending), then E_eps1_del{i}_mp, E_eps1_del{i}_mm (i ascending)] < [even: H_1,...,H_{n+1}, then even roots in the display order above]`.
This keeps all odd generators, including all four \(\varepsilon\)-root
families, in one block before the even generators.

**Option B — triangular root-space PBW order:**
`κ < [all negative-root generators] < H_1 < ... < H_{n+1} < [all positive-root generators]`.
Within each root block, order by family and increasing indices: negative odd
`E_eps1_del{i}_mm, E_eps1_del{i}_mp`, negative even
`E_2del{i}_m, E_del{i}_del{j}_mm, E_del{i}_del{j}_mp`; for the positive
block use positive odd `E_eps1_del{i}_pp, E_eps1_del{i}_pm` and positive
even `E_2del{i}_p, E_del{i}_del{j}_pp, E_del{i}_del{j}_pm`. In each family,
take indices ascending (`i<j` for pair roots). This follows the usual
negative-root / Cartan / positive-root triangular organization, rather than
the existing parity-block convention.

**Human approval received**: Option A was selected. The approved conventions
have been finalized in `handover/notation.md`, including the basis lists,
generator labels, and PBW order. Completion criteria are met.
