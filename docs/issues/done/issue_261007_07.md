### 1. Mathematical Setup

The coboundary formula (from `C_coboundary_definition.md`):

```
(δf)(X, Y) = (-1)^{p(X)} [X, f(Y)] - (-1)^{(p(X)+1)p(Y)} [Y, f(X)] - f([X, Y])
```

The map f: g → g is **odd** (reverses parity):
- f(even generator) ∈ odd subspace
- f(odd generator) ∈ even subspace

**Parametrization**: φ_{ij} is the coefficient of Z_i in f(Z_j):
```
f(Z_j) = Σ_i  φ_{ij} · Z_i    (summed over i with p(Z_i) ≠ p(Z_j))
```

JSON label convention: `phi_<image>_<domain>` (image generator first, domain second).
For example, `phi_E_eps1_del1_pp_H_1` = coefficient of E_eps1_del1_pp in f(H_1).

### 3. Proposed Approach Options

---

**Option A: Full Symbolic** (recommended for triviality analysis)

Keep all φ_{ij} as **symbolic parameters**. The coboundary (δf)^c_{XY} is computed as a rational linear combination of φ parameters using Schema 1 structure constants.

The three terms of δf evaluated symbolically:
- **Term 1**: (-1)^{p(X)} [X, f(Y)] — for each Z_i with p(Z_i) ≠ p(Y): multiply φ_{i←Y} · c([X,Z_i])
- **Term 2**: -(-1)^{(p(X)+1)p(Y)} [Y, f(X)] — for each Z_i with p(Z_i) ≠ p(X): multiply φ_{i←X} · c([Y,Z_i])
- **Term 3**: -f([X,Y]) — for each Z_k with c([X,Y])^k ≠ 0: multiply φ_{i←k} · c^k_{XY}

**Output**: Schema 4 JSON stores (δf)^c_{XY} = Σ_m coeff_m · φ_m, where coeff_m ∈ ℚ from Schema 1.

**Advantages**: Complete; enables full triviality check (does ∃ f s.t. δf = γ?); no numerical input required.
**Disadvantage**: Large output (many φ parameters).

---

**Option B: Specific Numerical Map**

Choose a concrete f by specifying numerical φ values. For example:

*B1 — Cartan-to-simple-odd:* f(H_j) = E_eps1_delj_pp (if j ≤ n), f(E_eps1_delj_pp) = H_j, all others = 0.

*B2 — All-one:* φ_{ij} = 1 for all valid (i,j). Gives a "dense" coboundary for comparison.

**Advantages**: Simple, small output.
**Disadvantage**: Less general; does not directly answer the triviality question.

---

**Recommendation**: **Option A (Full Symbolic)**, because:
1. It directly enables checking if δf = γ by solving a linear system φ → gb comparison.
2. Schema 4 is then a complete invariant of the deformation theory, not just a snapshot.
3. The implementation is straightforward: compute symbolic coboundary from Schema 1 brackets.

If the parameter count (32/176/528) is acceptable, Option A is mathematically complete.
If a simpler output is preferred, Option B1 (Cartan-to-simple-odd) is a natural geometric choice.
