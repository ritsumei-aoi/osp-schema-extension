## Proposal: Gamma Computation Method and Sign Conventions for Schema 2

### 1. Mathematical Framework

The γ-structure arises from the deformed oscillator exchange relation (from `C_inhomogeneous_definition.md`):

```
[b_j^s, a_1^σ] = -gb_{σ,j,s} · κ,   σ ∈ {+,−}, s ∈ {+,−}, j = 1,...,n
```

The basis relation is: since b_j^s is bosonic (p=0) and a_1^σ is fermionic (p=1),
```
b_j^s · a_1^σ  =  a_1^σ · b_j^s  -  gb_{σ,j,s} · κ
```

In PBW order, `a_1^σ < b_j^s`, so whenever a product requires passing `b_j^s` left past `a_1^σ`,
a `−gb_{σ,j,s} · κ` term is produced. These κ-coefficients, after decomposing in the basis,
give γ(X, Y) such that `[X, Y]_γ = [X, Y]_0 + κ · γ(X, Y)`.

### 2. Computation Algorithm

The gamma computation extends `C_generators.py` by adding a deformed normalization pass:

1. **Build generators** as oscillator polynomials (same as Schema 1).
2. **Deformed normal-ordering**: whenever the normalizer encounters `(b_j^s, a_1^σ)` out of PBW order, in addition to the PBW swap, accumulate a `−gb_{σ,j,s} · κ` scalar term.
3. **Compute [X, Y]_deformed = XY_deformed − (−1)^{p(X)p(Y)} YX_deformed**.
4. **Separate** the κ-free part ([X,Y]_0) from the κ-coefficient part (γ(X,Y)).
5. **Decompose** γ(X,Y) in the basis {Z_c} to get `γ_{abc}` coefficients as rational linear forms in gb parameters.

### 3. Sign Convention Options

The "Gram matrix" is the 4×n matrix of gb parameters, with rows indexed by
(σ,s) ∈ {(+,+),(+,−),(−,+),(−,−)} and columns by j=1,...,n.

The origin of the minus sign: the pre-oscillator bilinear form (·|·) is skew-supersymmetric.
For the mixed fermionic-bosonic block:
```
(a_1^σ | b_j^s) = gb_{σ,j,s}    [the Gram matrix entry]
[b_j^s, a_1^σ] = (b_j^s | a_1^σ) · κ = −(a_1^σ | b_j^s) · κ = −gb_{σ,j,s} · κ
```

**Option A** (Recommended): Store gb as `gb_{σ,j,s} = (a_1^σ | b_j^s)`.
- Gram matrix rows: fermionic labels `a_1_p`, `a_1_m`; columns: bosonic labels `b_j_p`, `b_j_m`.
- Deformed relation: `[b_j^s, a_1^σ] = −gb_{σ,j,s} · κ` (minus sign explicit).
- γ entries carry the minus sign from the skew-symmetry.
- **Advantage**: Direct correspondence to the bilinear form; consistent with definition in `C_inhomogeneous_definition.md`; γ coefficients contain explicit minus signs that encode the algebraic geometry of the form.

**Option B**: Store gb as `tgb_{j,s,σ} = −gb_{σ,j,s}` (bracket-oriented convention).
- Deformed relation: `[b_j^s, a_1^σ] = +tgb_{j,s,σ} · κ` (no minus sign).
- γ entries are purely positive or zero.
- **Advantage**: γ coefficients are sign-free and more readable.
- **Disadvantage**: Disconnects from bilinear form; introduces an ad hoc sign flip.

### 4. Recommended Schema 2 JSON Structure

Regardless of convention, Schema 2 (`C_{n}_gamma.json`) will contain:

```json
{
  "schema_version": "5.0",
  "algebra": { "cartan_type": "C(n+1)", ... },
  "sign_convention": "A",
  "gb_matrix": {
    "description": "gb[fermionic_label][bosonic_label] = (a_1^σ | b_j^s)",
    "rows": ["a_1_p", "a_1_m"],
    "cols": ["b_1_p", "b_1_m", ..., "b_n_p", "b_n_m"],
    "deformed_relation": "[b_j^s, a_1^σ] = -gb[a_1^σ][b_j^s] * kappa"
  },
  "gamma_structure": [
    {
      "X": "E_eps1_del1_pp",
      "Y": "H_1",
      "Z": "E_2del1_p",
      "gamma_coeff": "-2*gb_a1p_b1p",
      "gb_terms": [{"gb_label": "gb_a1p_b1p", "coeff": "-2"}]
    },
    ...
  ],
  "metadata": { ... }
}
```

The `gamma_coeff` field expresses each γ_{XYZ} as a symbolic linear combination of gb parameters.
Non-zero entries only (X<Y in PBW order, c runs over all basis generators).
