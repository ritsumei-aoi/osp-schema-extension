### Response

#### 1. Implementation Plan

The evaluation script (`src/C_evaluated_generator.py`) will:
1. Load Schema 1 (`C_n_structure.json`) and Schema 2 (`C_n_gamma.json`)
2. For a given gb profile `{gb_label: rational_value}`, substitute into each `gamma_structure` entry to compute the evaluated γ coefficients
3. Aggregate per `(X, Y, Z)` triple: `coeff_eval = Σ_{gb_key} coeff_{XY,Z,gb_key} · gb_value[gb_key]`
4. Write Schema 3 JSON: `data/C_{n}_evaluated_{profile_name}.json`

Schema 3 JSON will contain:
- `gb_profile.values`: concrete rational values for each gb label
- `structure_constants_0`: copy of undeformed brackets from Schema 1 (the [X,Y]_0 part)
- `gamma_evaluated`: evaluated γ entries `{X, Y, Z, coeff}` with K included as Z where relevant
- `metadata`: source files, profile name, entry counts

#### 2. gb Sign Profile Options — **Approval Required**

For C(n+1) there are 4n parameters: `gb_pp_j`, `gb_pm_j`, `gb_mp_j`, `gb_mm_j` for j=1..n.

##### Profile A — "uniform_plus" (Recommended)

All 4n parameters set to **+1**:
```
gb_pp_j = gb_pm_j = gb_mp_j = gb_mm_j = +1  for all j = 1..n
```
- Simplest symmetric assignment; no sign ambiguity
- Good baseline for verifying algebraic consistency
- File: `C_n_evaluated_uniform_plus.json`

##### Profile B — "diagonal_pm"

Same-sign pairs = +1, opposite-sign pairs = −1:
```
gb_pp_j = gb_mm_j = +1,  gb_pm_j = gb_mp_j = -1  for all j = 1..n
```
- Encodes the Gram matrix where (a_1^σ | b_j^s) = +1 if σ = s, −1 if σ ≠ s
- More structured sign pattern; may be physically natural for certain representations
- File: `C_n_evaluated_diagonal_pm.json`

##### Profile C — "unit_pp" (sparse)

Only the σ=+, s=+ parameters are non-zero:
```
gb_pp_j = +1,  gb_pm_j = gb_mp_j = gb_mm_j = 0  for all j = 1..n
```
- Minimal deformation; isolates the (a_1^+ | b_j^+) sector
- Useful for debugging and cross-checking individual contributions
- File: `C_n_evaluated_unit_pp.json`

#### 3. Uniform_plus Preview (C(2), n=1)

With all gb = +1, the 56 symbolic gamma entries evaluate to 56 non-zero `(X, Y, Z)` triples (no cancellations occur for this profile). Sample evaluated values:

```
γ_eval(E_eps_del1_pp, E_eps_del1_pm) = −1·E_eps_del1_pm  −1·E_eps_del1_pp
γ_eval(E_eps_del1_pp, H_1)           = −1·H_1  −2·H_2  +2·E_2del1_p
γ_eval(E_eps_del1_pp, H_2)           = +1·H_2  −1/2·K  −2·E_2del1_p
γ_eval(E_eps_del1_pm, H_1)           = +2·E_2del1_m  −1·H_1  −2·H_2  −1·K

                                         −1·E_eps_del1_mp  −1·E_eps_del1_pm
```
