**AI Agent Proposal — C(n+1) Structure Constant Generator**

#### Approach: Direct Frappat Formula (same as B_generators.py)

Use exact rational arithmetic with Python's `Fraction`, coefficient format `p + q*sqrt(2)`, and the same helper infrastructure as B(0,n). No sympy dependency for structure constants.

#### Proposed Files

##### 1. `src/C_generators.py`

**`build_C_basis(n: int) -> Tuple[List[str], List[str], Dict[str, int]]`**

Even basis (PBW order from notation.md):
```
H_1, ..., H_{n-1}, H_n, H_{n+1}       # Cartan (n+1)
E_2del1_p, ..., E_2deln_p              # positive long roots (n)
E_del{i}_del{j}_pp for i<j             # positive sum roots (n(n-1)/2)
E_2del1_m, ..., E_2deln_m              # negative long roots (n)
E_del{i}_del{j}_mm for i<j             # negative sum roots (n(n-1)/2)
E_del{i}_del{j}_pm for i<j             # mixed δ_i-δ_j (n(n-1)/2)
E_del{i}_del{j}_mp for i<j             # mixed -δ_i+δ_j (n(n-1)/2)
```
Even count = n(n+1)/2 (Cartan) + 2n (long) + 2·n(n-1)/2 (short sum) + 2·n(n-1)/2 (mixed) = n(2n+1)+1

Odd basis (PBW order from notation.md):
```
E_eps1_del{k}_pp for k=1..n            # ε₁+δ_k (positive)
E_eps1_del{k}_pm for k=1..n            # ε₁-δ_k (positive)
E_eps1_del{k}_mp for k=1..n            # -(ε₁-δ_k) (negative)
E_eps1_del{k}_mm for k=1..n            # -(ε₁+δ_k) (negative)
```
Odd count = 4n

**`build_C_structure_constants(n: int) -> Dict[Tuple[str, str], Dict[str, str]]`**

Structure constant computation organized into sections:

| Section | Bracket | Description |
|---------|---------|-------------|
| 1 | `[H_k, E_eps1_del{l}_{*}]` | Cartan × odd (all 4 signs) |
| 2 | `{E_eps1_del{k}_**, E_eps1_del{l}_**}` | Odd-odd: 4×4 sign blocks → even generators |
| 3 | `[E_2del{k}_p, E_2del{k}_m]` | Long even × long even (H-expansion) |
| 4 | `[E_2del{k}_p/m, E_eps1_del{l}_{*}]` | Even × odd |
| 5 | `[E_del{i}_del{j}_pp, E_del{i}_del{j}_mm]` | Short even × short even (H-expansion) |
| 6 | `[E_del{i}_del{j}_pp/mm, E_eps1_del{k}_{*}]` | Short even × odd |
| 7 | `[E_del{i}_del{j}_pm/mp, E_eps1_del{k}_{*}]` | Mixed even × odd |
| 8 | `[E_2del{k}_p, E_del{i}_del{j}_{*}]` | Even-even cross brackets |
| 9 | `[E_del{i}_del{j}_pp, E_del{k}_del{l}_mm]` | Short×short (Cartan/off-diagonal) |
| 10 | `[H_k, even_l]` | Cartan × even (standard eigenvalue action) |

**Key formula: Odd-odd bracket**

For `{E_eps1_del{k}_αβ, E_eps1_del{l}_γδ}` with signs α,β,γ,δ ∈ {+,−} encoded as p=+1, m=-1:

The anticommutator `{a_1^{α} b_k^{β}, a_1^{γ} b_l^{δ}}` expands as:
- `b_k^{β} b_l^{δ} * {a_1^{α}, a_1^{γ}}` → when α ≠ γ: gives `b_k^{β} b_l^{δ}` (since {a_1^-, a_1^+}=1)
  - If β = δ: diagonal: `b_k^{β} b_k^{-β}` → H-expansion
  - If β ≠ δ: off-diagonal: `b_k^{β} b_l^{-β}` → E_del{k}_del{l}_{*} mixed even
  - If k ≠ l: off-diagonal: `b_k^{β} b_l^{δ}` → E_del{k}_del{l}_{*} off-diagonal even
- `a_1^{γ} a_1^{α} * [b_k^{β}, b_l^{δ}]` (from the anticommutator expansion of `aba'b' = a{a',b}b' ± ...`)
  - When α = γ and β = δ: gives number operator → H-expansion
  - When α = γ and β ≠ δ: gives off-diagonal

**Coefficient format**: Only rational numbers (no sqrt(2) since no supplementary fermion). Coefficient utility functions reused.
