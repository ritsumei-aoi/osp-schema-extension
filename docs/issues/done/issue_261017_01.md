## Context & Background
C(n+1) = osp(2|2n) uses a standard fermionic pair (a_1_p, a_1_m) instead of
B(0,n)'s supplementary fermion a_0. This changes the basis structure, PBW
ordering, and oscillator relations throughout the entire schema.

The existing B(0,n) implementation is available for reference at:
https://github.com/ritsumei-aoi/osp-triviality

Frappat et al., "Dictionary on Lie Algebras and Superalgebras", arXiv:hep-th/9607161

### Response

#### 1. Mathematical Analysis & Generator Design

For $C(n+1) = \mathfrak{osp}(2|2n)$:
- **Oscillator pairs**:
  - Bosons: $b_k^+, b_k^-$ ($k = 1, \ldots, n$) with CCR $[b_j^-, b_k^+] = \delta_{jk}$. Labels: `b_k_p`, `b_k_m`.
  - Fermions: standard pair $a_1^+, a_1^-$ with CAR $\{a_1^-, a_1^+\} = 1$ (replacing $B(0,n)$'s supplementary fermion $a_0$). Labels: `a_1_p`, `a_1_m`.
  - Central element: $\kappa$ ($p(\kappa) = 1, \kappa^2 = 0$).
- **Root System & Dimensions**:
  - Even roots: $\Delta_{\bar{0}} = \{\pm 2\delta_k \mid 1 \le k \le n\} \cup \{\pm \delta_i \pm \delta_j \mid 1 \le i < j \le n\}$.
  - Odd roots: $\Delta_{\bar{1}} = \{\pm \varepsilon \pm \delta_k \mid 1 \le k \le n\}$.
  - Dimension formula: $\dim \mathfrak{g}_{\bar{0}} = 2n^2 + n + 1$, $\dim \mathfrak{g}_{\bar{1}} = 4n$, total $= 2n^2 + 5n + 1$.
    - $n=1$ ($C(2) = \mathfrak{osp}(2|2)$): even = 4, odd = 4, total = 8.
    - $n=2$ ($C(3) = \mathfrak{osp}(2|4)$): even = 11, odd = 8, total = 19.
    - $n=3$ ($C(4) = \mathfrak{osp}(2|6)$): even = 22, odd = 12, total = 34.

#### 2. Generator Label Conventions

##### (a) Cartan Generators (dimension $n+1$)
Following Frappat et al. and `Cn1_definition.md`, the simple coroots correspond to the $n+1$ simple roots:
- $H_1 = a_1^+ a_1^- + b_1^+ b_1^-$ (for $\alpha_1 = \varepsilon - \delta_1$)
- $H_k = b_{k-1}^+ b_{k-1}^- - b_k^+ b_k^-$ for $2 \le k \le n$ (for $\alpha_k = \delta_{k-1} - \delta_k$)
- $H_{n+1} = -b_n^+ b_n^- - \tfrac{1}{2}$ (for $\alpha_{n+1} = 2\delta_n$)

Labels: `H_1, H_2, ..., H_{n+1}`.

##### (b) Even Root Generators ($\mathfrak{sp}(2n)$ sector, dimension $2n^2$)
Directly preserving the $B(0,n)$ schema convention:
- Long roots $\pm 2\delta_k$:
  - $+2\delta_k$: `E_2del{k}_p` $\to (b_k^+)^2$
  - $-2\delta_k$: `E_2del{k}_m` $\to (b_k^-)^2$
- Short roots $\pm \delta_i \pm \delta_j$ ($1 \le i < j \le n$):
  - $\delta_i + \delta_j$: `E_del{i}_del{j}_pp` $\to b_i^+ b_j^+$
  - $\delta_i - \delta_j$: `E_del{i}_del{j}_pm` $\to b_i^+ b_j^-$
  - $-\delta_i + \delta_j$: `E_del{i}_del{j}_mp` $\to b_i^- b_j^+$
  - $-\delta_i - \delta_j$: `E_del{i}_del{j}_mm` $\to b_i^- b_j^-$

##### (c) Odd Root Generators (dimension $4n$)
Following the required specification in `docs/math/B0n_schema_v5.md` with explicit `eps1` label:
- $+\varepsilon + \delta_k$: `E_eps1_del{k}_pp` $\to a_1^+ b_k^+$
- $+\varepsilon - \delta_k$: `E_eps1_del{k}_pm` $\to a_1^+ b_k^-$
- $-\varepsilon + \delta_k$: `E_eps1_del{k}_mp` $\to a_1^- b_k^+$
- $-\varepsilon - \delta_k$: `E_eps1_del{k}_mm` $\to a_1^- b_k^-$
