#### Sample Structure Constants (C(2), n=1)

Basis odd: `[E_eps1_del1_pp, E_eps1_del1_pm, E_eps1_del1_mp, E_eps1_del1_mm]`  
Basis even: `[H_1, H_2, E_2del1_p, E_2del1_m]`

Selected brackets (stored as `[X, Y}` with X before Y in PBW):
```
{E_eps1_del1_pp, E_eps1_del1_mp} =  2 * E_2del1_p
{E_eps1_del1_pp, E_eps1_del1_mm} = -1 * H_1 + -2 * H_2
[E_eps1_del1_pp, H_1]            = -2 * E_eps1_del1_pp   (so [H_1, E] = +2*E ✓)
[E_eps1_del1_pp, H_2]            = +1 * E_eps1_del1_pp   (so [H_2, E] = -1*E ✓)
{E_eps1_del1_pm, E_eps1_del1_mm} =  2 * E_2del1_m
```

Note: structure constants are stored with X < Y in PBW order; [H_1, E_eps1_del1_pp] = 2·E follows from graded antisymmetry [E, H_1] = -[H_1, E].

#### Implementation Notes

1. **Oscillator algebra**: implemented via normal-ordering bubble sort; non-zero elementary brackets are `{a_1^-, a_1^+} = 1` and `[b_k^-, b_k^+] = 1` only.
2. **Decomposition**: non-Cartan words map uniquely to non-Cartan generators; Cartan coefficients solved via explicit linear system derived from the Cartan matrix.
3. **Cartan solve for n=1** uses a different equation than n≥2 (H_2 contributes −1 vs +1 to (b_1^+b_1^−) because it is the terminal Cartan for n=1).
4. **Schema conformance**: all JSON fields match `docs/json_schema_specification.md` (schema_version, algebra, oscillator_generators, oscillator_relations, central_elements, basis, parity, generator_realization, structure_constants, metadata).
