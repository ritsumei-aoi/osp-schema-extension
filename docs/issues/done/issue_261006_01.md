## 1. Even and Odd Basis Lists

### Root System Summary

For $C(n+1) = \mathfrak{osp}(2|2n)$:
- **Even roots** $\Delta_{\bar{0}} = \{\pm 2\delta_k\} \cup \{\pm(\delta_i \pm \delta_j) \mid i < j\}$  
- **Odd roots** $\Delta_{\bar{1}} = \{\pm\varepsilon \pm \delta_k \mid k = 1, \ldots, n\}$
- **Even subalgebra**: $\mathfrak{so}(2) \times \mathfrak{sp}(2n)$, dim = $2n^2 + n + 1$
- **Odd dimension**: $4n$

Cartan elements: $H_1, \ldots, H_{n+1}$ (rank $n+1$, following Frappat):
- $H_1 = a_1^+ a_1^- + b_1^+ b_1^-$ (simple root $\alpha_1 = \varepsilon - \delta_1$, odd)
- $H_k = b_{k-1}^+ b_{k-1}^- - b_k^+ b_k^-$ for $2 \leq k \leq n$ (simple root $\alpha_k = \delta_{k-1} - \delta_k$, even)
- $H_{n+1} = -b_n^+ b_n^- - \tfrac{1}{2}$ (simple root $\alpha_{n+1} = 2\delta_n$, even)

## 2. Generator Label Conventions

Extending the B(0,n) label system consistently:

| Root | Generator label | Oscillator realization |
|---|---|---|
| $2\delta_k$ | `E_2del{k}_p` | $(b_k^+)^2$ |
| $-2\delta_k$ | `E_2del{k}_m` | $(b_k^-)^2$ |
| $\delta_i + \delta_j$ ($i<j$) | `E_del{i}_del{j}_pp` | $b_i^+ b_j^+$ |
| $-(\delta_i + \delta_j)$ ($i<j$) | `E_del{i}_del{j}_mm` | $b_i^- b_j^-$ |
| $\delta_i - \delta_j$ ($i<j$) | `E_del{i}_del{j}_pm` | $b_i^+ b_j^-$ |
| $-(\delta_i - \delta_j)$ ($i<j$) | `E_del{i}_del{j}_mp` | $b_i^- b_j^+$ |
| $\varepsilon + \delta_k$ | `E_eps1_del{k}_pp` | $a_1^+ b_k^+$ |
| $\varepsilon - \delta_k$ | `E_eps1_del{k}_pm` | $a_1^+ b_k^-$ |
| $-\varepsilon + \delta_k$ | `E_eps1_del{k}_mp` | $a_1^- b_k^+$ |
| $-\varepsilon - \delta_k$ | `E_eps1_del{k}_mm` | $a_1^- b_k^-$ |

**Rationale**: The `eps1` prefix distinguishes the single fermionic direction ε of C(n+1) from the bosonic δ directions. The sign suffix `_pp/_pm/_mp/_mm` encodes (sign of ε component, sign of δ component), matching the pattern already used for even generators.

The oscillator ordering in standard form:
```
a_1_p < a_1_m < b_1_p < b_1_m < b_2_p < b_2_m < ... < b_n_p < b_n_m
```

## 3. PBW Ordering Options (HUMAN SELECTION REQUIRED)

The global structure is fixed: $\kappa < [\text{odd}] < [\text{even}]$.  
The even sector ordering follows B(0,n) convention (Cartans → positive → negative → mixed) and is not controversial.  
**The decision below concerns the ordering within the odd sector.**

---

### Option A — ε-priority (fermionic creation/annihilation partition)

Group by the sign of the $\varepsilon$ component (i.e., by whether the generator contains $a_1^+$ or $a_1^-$):

```
κ
< [ε+, δ+: E_eps1_del{k}_pp  for k=1..n]
< [ε+, δ-: E_eps1_del{k}_pm  for k=1..n]
< [ε-, δ+: E_eps1_del{k}_mp  for k=1..n]
< [ε-, δ-: E_eps1_del{k}_mm  for k=1..n]
< [even: H_1..H_{n+1}, E_2del{k}_p, E_del{ij}_pp, E_2del{k}_m, E_del{ij}_mm, E_del{ij}_pm, E_del{ij}_mp]
```

Example (C(3), n=2):
```
odd = [E_eps1_del1_pp, E_eps1_del2_pp,
       E_eps1_del1_pm, E_eps1_del2_pm,
       E_eps1_del1_mp, E_eps1_del2_mp,
       E_eps1_del1_mm, E_eps1_del2_mm]
```

**Rationale**: The $a_1^+$ block precedes the $a_1^-$ block, directly reflecting the fermionic creation/annihilation split. This matches the lexicographic order of the oscillator words ($a_1^+ < a_1^-$ in the standard form ordering). The four-block structure (++, +-, -+, --) follows the sign pair $(s_\varepsilon, s_\delta)$ in order.

---

### Option B — δ-priority (bosonic creation/annihilation partition)

Group by the sign of the $\delta_k$ component, mirroring the B(0,n) convention where positive $\delta$ roots (= $a_0 b_k^+$) precede negative $\delta$ roots (= $a_0 b_k^-$):

```
κ
< [δ+: E_eps1_del{k}_pp, E_eps1_del{k}_mp  for k=1..n  (interleaved or by k)]
< [δ-: E_eps1_del{k}_pm, E_eps1_del{k}_mm  for k=1..n  (interleaved or by k)]
< [even: ...]
```

Example (C(3), n=2) — grouped by k within each δ block:
```
odd = [E_eps1_del1_pp, E_eps1_del1_mp,
       E_eps1_del2_pp, E_eps1_del2_mp,
       E_eps1_del1_pm, E_eps1_del1_mm,
       E_eps1_del2_pm, E_eps1_del2_mm]
```

**Rationale**: The B(0,n) odd basis places `E_del{k}_p` (= $a_0 b_k^+$) before `E_del{k}_m` (= $a_0 b_k^-$). Extending this: for C(n+1), generators containing $b_k^+$ ($\delta$-positive) come before those containing $b_k^-$ ($\delta$-negative), regardless of the $\varepsilon$ sign. This gives the closest structural analogy to B(0,n).

---

### Option C — Lexicographic by sign pair (++, +-, -+, --)

Order all odd generators by the sign pair $(s_\varepsilon, s_\delta)$ lexicographically, each group sorted by $k$:

```
κ
< [++: E_eps1_del{k}_pp  for k=1..n]
< [+-: E_eps1_del{k}_pm  for k=1..n]
< [-+: E_eps1_del{k}_mp  for k=1..n]
< [--: E_eps1_del{k}_mm  for k=1..n]
< [even: ...]
```

Example (C(3), n=2):
```
odd = [E_eps1_del1_pp, E_eps1_del2_pp,
       E_eps1_del1_pm, E_eps1_del2_pm,
       E_eps1_del1_mp, E_eps1_del2_mp,
       E_eps1_del1_mm, E_eps1_del2_mm]
```

**Note**: Option C produces the same list order as Option A. The difference is purely conceptual: Option A is motivated by the fermionic split ($a_1^+$ block vs $a_1^-$ block), while Option C is motivated by lexicographic sign ordering as a schema design principle.

---

## 4. Agent Recommendation

**Recommended: Option A / Option C** (they produce the same ordering).

Rationale:
1. The four-block structure (++, +-, -+, --) is the most systematic and schema-friendly.
2. It places $a_1^+$ generators before $a_1^-$ generators, consistent with the oscillator word order $a_1^+ < a_1^-$ used in `generator_realization.ordering`.
3. It makes the sign pattern explicit and symmetric, aiding readability of the JSON schema.
4. Option B is also defensible as the closest B(0,n) analogy, but it interleaves $a_1^+$ and $a_1^-$ generators within each $k$-block, which may complicate structure constant tabulation.

**Please select: Option A (= Option C), Option B, or provide an alternative.**
