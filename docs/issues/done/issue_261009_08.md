#### Triviality analysis

**Comparison method.** For the approved map `f: g -> g`, every Schema 4
`delta_f_coefficients` output `Z` is a Schema 1 basis generator. Thus every
coefficient of `K` in the Schema 3 deformation is an obstruction: no choice
of the `phi` parameters can make that central component equal to `delta f`.
I extracted the exact linear equations on `gb` from the Schema 2 records with
`Z = "K"` and computed their rational matrix ranks. The resulting Layer 3
files provide concrete evaluations of the all-positive profile.

| Rank | Central `K` equations | `gb` parameters | Exact matrix rank | Nullity |
|---|---:|---:|---:|---:|
| `n=1` | 20 | 4 | 4 | 0 |
| `n=2` | 84 | 8 | 8 | 0 |
| `n=3` | 180 | 12 | 12 | 0 |

**Non-trivial cases.** In every generated all-positive Layer 3 file,
`[E_eps1_del1_pp, H_1]` has a `Z: "K"` correction with coefficient
`gb_a1p_b1p = 1`. The Schema 4 coboundary has no `Z: "K"` records, so this
pair already proves the all-positive profile is non-trivial for each of the
three ranks. The complete unmatched central-component lists contain 20, 84,
and 180 records for `n=1,2,3`, respectively.

The full-rank central equations isolate every parameter. Representative
singleton witnesses from Schema 2 are:

| Parameter(s) | Pair `(X,Y)` | Coefficient of `K` |
|---|---|---|
| `gb_a1p_b1p` | `(E_eps1_del1_pp, H_1)` | `gb_a1p_b1p` |
| `gb_a1p_b1m` | `(E_eps1_del1_pp, E_2del1_m)` | `gb_a1p_b1m` |
| `gb_a1m_b1p` | `(E_eps1_del1_mp, H_2)` | `-1/2*gb_a1m_b1p` for `n=1`; `1/2*gb_a1m_b1p` for `n>=2` |
| `gb_a1m_b1m` | `(E_eps1_del1_mp, E_2del1_m)` | `gb_a1m_b1m` |
| `gb_a1p_b{j}p`, `gb_a1p_b{j}m` (`j>=2`) | `(E_eps1_del1_pp, E_del1_del{j}_mp/mm)` | `1/2` times the corresponding parameter |
| `gb_a1m_b{j}p`, `gb_a1m_b{j}m` (`j>=2`) | `(E_eps1_del1_mp, E_del1_del{j}_mp/mm)` | `1/2` times the corresponding parameter |

Each listed `K` coefficient is a nonzero multiple of exactly one `gb`
parameter. Therefore, for each tested rank, vanishing of all central
components forces every entry of the `gb_matrix` to be zero. This argument
does not require solving for the `phi` variables: central `K` is outside the
image of the approved `delta f: g tensor g -> g` map.

**Trivial case and condition.** At the all-zero `gb` specialization, the
Schema 2 deformation coefficients all vanish. Taking `f=0` gives
`delta f=0`, so the structures coincide and the deformation is trivial. The
stored Schema 3 files use the approved all-positive profile; the zero case is
the exact specialization of the symbolic Schema 2 data, not one of those
three stored profiles.

**Conjecture.** For every `n>=1`, the inhomogeneous deformation is trivial
under this coboundary definition if and only if every parameter vanishes:
`gb_{a_1^sigma,b_j^s}=0` for all `sigma,s in {+,-}` and `j=1,...,n`.
The exact central-equation matrices have full column rank for `n=1,2,3`.
The singleton witness pattern above extends by the same root-generator
families for each additional `j`, providing the expected full-rank condition
at higher ranks as well.
