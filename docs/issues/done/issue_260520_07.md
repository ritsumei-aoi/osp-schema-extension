#### 1. Mathematical Framework

The coboundary operator acts on **odd linear maps** f: g → g (parity-reversing):

```
(δf)(X, Y) = (-1)^{p(X)} [X, f(Y)] − (-1)^{(p(X)+1)p(Y)} [Y, f(X)] − f([X, Y])
```

using the **undeformed** bracket [·,·]_0 from Schema 1.

The deformation γ is **trivial** (a coboundary) if and only if there exists f such
that δf = γ. This is a question about the linear system `M · φ = γ_vec`.

---

#### 2. Proposed Parameterization of f

I propose using the **full unconstrained** space of parity-reversing linear maps:

```
f(Z_j) = Σ_i  φ_{ij} · Z_i    subject to: p(Z_i) ≠ p(Z_j)
```

For C(n+1) with dimensions (d_e | d_o):

| n | d_e | d_o | free φ parameters |
|---|---|---|---|
| 1 | 4  | 4  | 2 × 4 × 4 = **32** |
| 2 | 11 | 8  | 2 × 11 × 8 = **176** |
| 3 | 22 | 12 | 2 × 22 × 12 = **528** |

This is the maximal space — no restriction to Cartan or diagonal maps — ensuring
the rank test gives a **definitive** answer for triviality.

---

#### 3. Proposed Rank-Based Verification Method

**Step 1 — Build coboundary operator matrix M:**

For each basis function f_{ij} (the map sending Z_j → Z_i, all others → 0):
- Evaluate (δf_{ij})(X, Y) for all ordered pairs (X ≤ Y in PBW order) using Schema 1 structure constants.
- Project onto each basis element Z to get M[(X,Y,Z), (i,j)] ∈ Q.

Row indices: (X, Y, Z) triples (ordered pair + output basis element).  
Column indices: φ_{ij} parameters (one per parity-reversing basis-to-basis map).

**Step 2 — Build γ vector:**

From Schema 3 gb1 profile, collect all kappa entries:
```
γ_vec[(X, Y, Z)] = coeff  for each "part": "kappa" entry
```
Entries not present in Schema 3 are treated as 0.

**Step 3 — Rank test over Q (exact arithmetic):**

```
rank_M         = rank(M)
rank_augmented = rank([M | γ_vec])
is_trivial     = (rank_M == rank_augmented)
```

If `is_trivial = True`: the deformation is **coboundary** (trivial); we also solve
for an explicit f using back-substitution.  
If `is_trivial = False`: the deformation is **non-trivial**; γ is a genuine
cohomology class in H²(g; g).

All arithmetic is done in **exact rationals** (Python `Fraction`) using
Gaussian elimination — same approach as prior layers.
