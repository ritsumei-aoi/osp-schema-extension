### 1. Mathematical Analysis & Representative Sign Profile Options

In Layer 2 (`data/C_{n}_gamma.json`), the inhomogeneous deformation $\gamma(X, Y)$ is given symbolically in terms of $4n$ deformation parameters:
$$\mathrm{gb}_{\sigma, j, s} \quad (\sigma \in \{+, -\}, j \in \{1, \ldots, n\}, s \in \{+, -\}).$$

#### 1.1 Structural Property of $C(n+1)$ Inhomogeneous Deformation
An analysis of the generated cocycles across all ranks reveals a crucial structural property:
- **Unique Parameter Dependency**: Every non-zero deformed bracket component $\gamma(X, Y) \to Z$ depends on **exactly one** deformation parameter $\mathrm{gb}_{\sigma, j, s}$.
- The maximum number of parameters contributing to any single $(X, Y, Z)$ triple is exactly 1 for all $n \in \{1, 2, 3\}$.
- **Consequence**: For any sign assignment $\mathrm{gb}_{\sigma, j, s} \in \{+1, -1\}$, no cancellation occurs between distinct $\mathrm{gb}$ parameters for the same triple $(X, Y, Z)$. The bracket coefficient simply scales by the assigned sign:
  $$\gamma_{XY}^Z(\mathrm{gb}) = \mathrm{gb}_{\sigma, j, s} \cdot c_{XY}^Z.$$

#### 1.2 Proposed Sign Profile Options

##### Profile 1: Canonical Uniform Profile (`all_plus`) — **RECOMMENDED**
$$\mathrm{gb}_{\sigma, j, s} = +1 \quad \forall \sigma \in \{+, -\}, j \in \{1, \ldots, n\}, s \in \{+, -\}.$$
- **Rationale**: This is the standard canonical benchmark profile in deformation theory and is explicitly suggested in Requirement 1 (`e.g., all set to +1`).
- Preserves the full coupling strength across all bosonic modes $b_j^\pm$ and both fermionic modes $a_1^\pm$ without introducing artificial directional bias.
- Non-zero evaluated $\gamma$ brackets:
  - $n=1$: 108 non-zero brackets.
  - $n=2$: 978 non-zero brackets.
  - $n=3$: 3,372 non-zero brackets.

##### Profile 2: Fermion-Alternating Profile (`fermion_alternating`)
$$\mathrm{gb}_{a_1^+, b_j^s} = +1, \quad \mathrm{gb}_{a_1^-, b_j^s} = -1 \quad \forall j, s.$$
- **Rationale**: Tests sensitivity to chiral signs between the creation fermion $a_1^+$ and annihilation fermion $a_1^-$.

##### Profile 3: Boson-Alternating Profile (`boson_alternating`)
$$\mathrm{gb}_{a_1^\sigma, b_j^+} = +1, \quad \mathrm{gb}_{a_1^\sigma, b_j^-} = -1 \quad \forall \sigma, j.$$
- **Rationale**: Tests sensitivity between bosonic creation operators $b_j^+$ and annihilation operators $b_j^-$.

##### Profile 4: Mode-Parity Profile (`mode_alternating`)
$$\mathrm{gb}_{\sigma, j, s} = (-1)^{j-1} \quad \forall \sigma, s.$$
- **Rationale**: Imposes alternating phases across the Cartan chain of bosonic modes $j = 1, \ldots, n$.

**Recommendation**: We recommend **Profile 1 (`all_plus`)** as the primary canonical profile for `C_{n}_evaluated.json`. We will also design `src/evaluate_C_structure.py` to support parameterized profile selection (e.g. `--profile all_plus`, `--profile fermion_alternating`) for future flexibility.
