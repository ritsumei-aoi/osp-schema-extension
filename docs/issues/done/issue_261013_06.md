### Response

#### 1. Context & Schema 3 (Evaluated Structure) Overview

In accordance with `docs/json_schema_specification.md` and `docs/math/C_inhomogeneous_definition.md`:
- Schema 2 provides the symbolic inhomogeneous deformation $\gamma$ with $4n$ parameters:
  $$ [X, Y]_\gamma = [X, Y]_0 + \kappa \cdot \sum_{\text{param}} \mathrm{gb}_{\text{param}} \cdot \gamma_{\text{param}}(X, Y) $$
- Schema 3 represents the evaluated structure for a concrete assignment (sign profile) of the deformation parameters $\mathrm{gb}$:
  $$ \gamma_{\text{eval}}(X, Y) = \sum_{\text{param}} \mathrm{gb}_{\text{param}} \cdot \gamma_{\text{param}}(X, Y) $$
  and the total deformed structure constants:
  $$ [X, Y]_{\text{total}} = [X, Y]_0 + \kappa \cdot \gamma_{\text{eval}}(X, Y) $$

---

#### 2. Concrete $gb$ Sign Profile Options Proposed for Human Selection

For each rank $n$, there are $4n$ parameters in the $2 \times 2n$ `gb_matrix`. We propose three standard concrete sign profile options:

##### **Option 1: Uniform Positive Profile (`all_plus_one`) [Recommended]**
- **Definition**: All $4n$ parameters are assigned value $+1$:
  $$ \mathrm{gb}_{\sigma, j, s} = +1 \quad \text{for all } \sigma \in \{a_1^+, a_1^-\}, j \in \{1..n\}, s \in \{+,-\} $$
- **Characteristics**:
  - $n=1$ ($C(2)$): 4 parameters $= (+1, +1, +1, +1)$
  - $n=2$ ($C(3)$): 8 parameters $= (+1, \ldots, +1)$
  - $n=3$ ($C(4)$): 12 parameters $= (+1, \ldots, +1)$
- **Advantage**: Standard canonical choice across benchmark studies, maximally symmetric, directly tests the full sum of all deformation channels.
- **File Naming**: `C_{n}_evaluated.json` (or `C_{n}_evaluated_all_plus.json`).

##### **Option 2: Alternating Parity/Sign Profile (`alternating_signs`)**
- **Definition**: Positive for $a_1^+$ row, negative for $a_1^-$ row:
  $$ \mathrm{gb}_{a_1^+, b_j^s} = +1, \quad \mathrm{gb}_{a_1^-, b_j^s} = -1 $$
- **Characteristics**: Reflects fermionic chirality/grading opposite signs between the creation and annihilation fermionic sectors.

##### **Option 3: Diagonal / Minimal Unit Basis Profile (`unit_standard`)**
- **Definition**: A standard non-zero sign profile where creation pairs are $+1$ and annihilation pairs are $+1$:
  $$ \mathrm{gb}_{a_1^+, b_j^+} = +1, \quad \mathrm{gb}_{a_1^-, b_j^-} = +1, \quad \text{others } 0 \text{ (or } -1 \text{)} $$

**Recommendation**: **Option 1 (`all_plus_one`)** is strongly recommended as the canonical benchmark evaluation for Layer 3.
