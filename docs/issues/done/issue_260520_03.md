### `src/C_generators.py` — Design summary

**Core data structure**: `OscPoly = Dict[Tuple[int,...], Fraction]`  
Polynomial in oscillator algebra PBW monomials with exact rational coefficients.

**Index assignment** (PBW order within oscillators):
```
a_1_p → 0,  a_1_m → 1,  b_k_p → 2k,  b_k_m → 2k+1  (k = 1..n)
```

**Key functions**:
- `_swap_pair(i, j)`: returns replacement terms for an out-of-order adjacent pair
  - `(1, 0)` (a_1_m · a_1_p): anticommutation → `1·() + (−1)·(0,1)`
  - `(2k+1, 2k)` (b_k_m · b_k_p): bosonic CCR → `1·() + 1·(2k, 2k+1)`
  - all others: free commutation
- `pbw_reduce_word(word)`: bubble-sort to PBW normal form; fermionic squares discarded
- `poly_multiply(X, Y)`: multiply two `OscPoly`s via word concatenation + reduction
- `graded_bracket(X, pX, Y, pY)`: `XY − (−1)^{pX·pY} YX`
- `build_generators(n)`: returns all realizations, parities, `even_basis`, `odd_basis` in PBW order
- `express_in_generators(poly, gens, basis)`: Gaussian elimination with `Fraction` arithmetic
- `compute_structure_constants(n)`: all non-zero `[X,Y}` for X ≤ Y in PBW order
- `build_schema1(n)`: complete Schema 1 dict; `main()` writes `data/C_{n}_structure.json`

**Convention**: `E_{±2δ_k} = (b_k^±)^2` — the Frappat 1/2 factor is absorbed (per `notation.md`).
