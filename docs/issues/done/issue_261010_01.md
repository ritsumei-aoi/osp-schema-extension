## Analysis and Proposals for I01-1

### 1. Even and Odd Basis Lists

The root system of C(n+1) = osp(2|2n) decomposes as:
- Even roots Δ₀̄: { ±2δₖ } ∪ { ±(δᵢ ± δⱼ) | i < j }
- Odd roots Δ₁̄: { ±ε ± δₖ | k = 1, …, n }

The Cartan subalgebra has dimension n+1 (simple roots: α₁ = ε−δ₁, αₖ = δₖ₋₁−δₖ for 2≤k≤n, α_{n+1} = 2δₙ).

Dimension check: even = 2n²+n+1, odd = 4n, total = 2n²+5n+1.

#### C(2) = osp(2|2), n=1 (dim: 4|4 = 8)

**Even basis** (4 elements):
```
Cartan:   H_1, H_2
Positive: E_2del1_p
Negative: E_2del1_m
```
(No E_del{i}_del{j}_xx terms since n=1 has no i<j pair.)

**Odd basis** (4 elements):
```
E_eps1_del1_pp,  E_eps1_del1_pm,  E_eps1_del1_mp,  E_eps1_del1_mm
```

#### C(3) = osp(2|4), n=2 (dim: 11|8 = 19)

**Even basis** (11 elements):
```
Cartan:      H_1, H_2, H_3
Positive:    E_2del1_p, E_2del2_p, E_del1_del2_pp
Negative:    E_2del1_m, E_2del2_m, E_del1_del2_mm
Mixed:       E_del1_del2_pm, E_del1_del2_mp
```

**Odd basis** (8 elements):
```
E_eps1_del1_pp, E_eps1_del2_pp,
E_eps1_del1_pm, E_eps1_del2_pm,
E_eps1_del1_mp, E_eps1_del2_mp,
E_eps1_del1_mm, E_eps1_del2_mm
```

#### C(4) = osp(2|6), n=3 (dim: 22|12 = 34)

**Even basis** (22 elements):
```
Cartan:      H_1, H_2, H_3, H_4
Positive:    E_2del1_p, E_2del2_p, E_2del3_p,
             E_del1_del2_pp, E_del1_del3_pp, E_del2_del3_pp
Negative:    E_2del1_m, E_2del2_m, E_2del3_m,
             E_del1_del2_mm, E_del1_del3_mm, E_del2_del3_mm
Mixed:       E_del1_del2_pm, E_del1_del3_pm, E_del2_del3_pm,
             E_del1_del2_mp, E_del1_del3_mp, E_del2_del3_mp
```

**Odd basis** (12 elements):
```
E_eps1_del1_pp, E_eps1_del2_pp, E_eps1_del3_pp,
E_eps1_del1_pm, E_eps1_del2_pm, E_eps1_del3_pm,
E_eps1_del1_mp, E_eps1_del2_mp, E_eps1_del3_mp,
E_eps1_del1_mm, E_eps1_del2_mm, E_eps1_del3_mm
```

### 2. Generator Label Conventions

The label convention extends the B(0,n) schema naturally:

| Root | Label | Oscillator realization |
|---|---|---|
| 2δₖ | `E_2del{k}_p` | (1/2)(bₖ⁺)² |
| −2δₖ | `E_2del{k}_m` | (1/2)(bₖ⁻)² |
| δᵢ+δⱼ (i<j) | `E_del{i}_del{j}_pp` | bᵢ⁺ bⱼ⁺ |
| δᵢ−δⱼ (i<j) | `E_del{i}_del{j}_pm` | bᵢ⁺ bⱼ⁻ |
| −δᵢ+δⱼ (i<j) | `E_del{i}_del{j}_mp` | bᵢ⁻ bⱼ⁺ |
| −(δᵢ+δⱼ) (i<j) | `E_del{i}_del{j}_mm` | bᵢ⁻ bⱼ⁻ |
| ε+δₖ | `E_eps1_del{k}_pp` | a₁⁺ bₖ⁺ |
| ε−δₖ | `E_eps1_del{k}_pm` | a₁⁺ bₖ⁻ |
| −ε+δₖ | `E_eps1_del{k}_mp` | a₁⁻ bₖ⁺ |
| −ε−δₖ | `E_eps1_del{k}_mm` | a₁⁻ bₖ⁻ |

The subscript `eps1` distinguishes the single ε direction from the n bosonic δ directions. This is consistent with B(0,n)'s `del{k}` suffix.

The oscillator ordering for generator_realization standard_form is:
```
a_1_p < a_1_m < b_1_p < b_1_m < b_2_p < b_2_m < ... < b_n_p < b_n_m
```

**Note on central elements**: As in B(0,n), the even central element K is identified with the scalar 1 and is not an independent basis element. The odd central element κ (defined via the pre-oscillator form structure) plays the analogous role to B(0,n)'s κ.

### 3. PBW Ordering — Two Options for Human Selection

The overall PBW structure is:
```
κ  <  [4n odd generators]  <  [2n²+n+1 even generators]
```
(κ is excluded from the basis for the same reason as in B(0,n): it is the central nilpotent extension element.)

The even generator ordering (same in both options):
```
H_1 < H_2 < ... < H_{n+1}
< E_2del1_p < ... < E_2del{n}_p  < E_del{i}_del{j}_pp (i<j, asc.)
< E_2del1_m < ... < E_2del{n}_m  < E_del{i}_del{j}_mm (i<j, asc.)
< E_del{i}_del{j}_pm  < E_del{i}_del{j}_mp  (i<j, asc.)
```

The two options differ only in how the **4n odd generators** are ordered.

---

#### Option A: ε-grouped ordering

**Principle**: Group all generators by the sign of ε first (positive-ε block, then negative-ε block), then by the sign of δₖ within each block, then by the index k.

```
[+ε, +δ]:  E_eps1_del1_pp, E_eps1_del2_pp, ..., E_eps1_del{n}_pp
[+ε, −δ]:  E_eps1_del1_pm, E_eps1_del2_pm, ..., E_eps1_del{n}_pm
[−ε, +δ]:  E_eps1_del1_mp, E_eps1_del2_mp, ..., E_eps1_del{n}_mp
[−ε, −δ]:  E_eps1_del1_mm, E_eps1_del2_mm, ..., E_eps1_del{n}_mm
```

**For C(3), n=2, full odd list in order**:
```
E_eps1_del1_pp, E_eps1_del2_pp,
E_eps1_del1_pm, E_eps1_del2_pm,
E_eps1_del1_mp, E_eps1_del2_mp,
E_eps1_del1_mm, E_eps1_del2_mm
```

**Rationale**: The +ε generators (involving a₁⁺) and −ε generators (involving a₁⁻) are cleanly separated. This mirrors the B(0,n) structure where the supplementary fermion a₀ acted uniformly on all b-oscillators. It also groups generators by the fermionic oscillator type (a₁⁺ vs a₁⁻), which is more natural for manual inspection and cohomological analysis.

**Tradeoff**: Within the "pp/pm" block, δ-conjugate pairs (±δₖ) are separated.

---

#### Option B: δ-grouped ordering

**Principle**: Group all generators by the bosonic index k first, then by the sign combinations. Within each k-group, order by (ε-sign, δ-sign) = (pp, pm, mp, mm).

```
[k=1]:  E_eps1_del1_pp, E_eps1_del1_pm, E_eps1_del1_mp, E_eps1_del1_mm
[k=2]:  E_eps1_del2_pp, E_eps1_del2_pm, E_eps1_del2_mp, E_eps1_del2_mm
  ...
[k=n]:  E_eps1_del{n}_pp, E_eps1_del{n}_pm, E_eps1_del{n}_mp, E_eps1_del{n}_mm
```

**For C(3), n=2, full odd list in order**:
```
E_eps1_del1_pp, E_eps1_del1_pm, E_eps1_del1_mp, E_eps1_del1_mm,
E_eps1_del2_pp, E_eps1_del2_pm, E_eps1_del2_mp, E_eps1_del2_mm
```

**Rationale**: Corresponds directly to the natural oscillator-word order `a_1_p < a_1_m < b_1_p < b_1_m < ... < b_n_p < b_n_m`. All four generators linked to the same bosonic oscillator bₖ are adjacent, which may simplify bookkeeping when computing structure constants for each bₖ sector.

**Tradeoff**: The a₁⁺ and a₁⁻ families are interleaved, which may make pattern recognition across the ε-direction less transparent.
