### Response

**Implementation summary**

Created `src/C_generators.py` implementing:
- `build_basis(n)`: constructs even/odd basis lists for C(n+1)
- `cartan_eigenvalue(h_idx, gen_label, n)`: computes [H_k, E_α] eigenvalues from oscillator charges
- `build_structure_constants(n, ...)`: derives all non-zero graded brackets using oscillator algebra identities:
  - Cartan-root: eigenvalue formula
  - Odd-odd: {a1^σ bks, a1^τ blt} = δ_{σ,−τ} bks blt (anti-commutator reduction)
  - Even-even: [(bkp)^2, (bkm)^2] = 4H_{n+1} - 4Σ H_j; [δi+δj, -(δi+δj)]; [δi-δj, δj-δi]; chain rules
  - Even-odd: [E_{2δk}, E_odd] via [(bkp)^2, bkm] = -2bkp; [E_{δi±δj}, E_odd] via [bip bjp, bjm] = -bip etc.
- `build_schema1(n)`: assembles the full Schema 1 JSON
- `main()`: writes C_1_structure.json, C_2_structure.json, C_3_structure.json to data/

Created `tests/test_C_structure.py` with 18 tests covering:
- Dimension counts for n=1,2,3
- Parity consistency
- Cartan eigenvalue correctness
- JSON file validity (schema_version, family, dimension formulas)
- No zero-coefficient structure constant entries
- Unique basis labels
