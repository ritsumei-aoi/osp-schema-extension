#### Technical Notes

1. **PBW Basis Ordering** (from I01 notation.md):
   - κ < [E_eps_del{k}_{...}] < [H_k, E_2delta_k, E_delta_i_delta_j]
   - Verified in basis generation

2. **Generator Label Convention** (from I01):
   - E_eps_del{k}_pp: ε+δ_k (a_1^+ b_k^+)
   - E_eps_del{k}_pm: ε-δ_k (a_1^+ b_k^-)
   - E_eps_del{k}_mp: -ε+δ_k (a_1^- b_k^+)
   - E_eps_del{k}_mm: -ε-δ_k (a_1^- b_k^-)

3. **Cartan Elements**:
   - H_1 = a_1^+ a_1^- + b_1^+ b_1^-
   - H_k = b_{k-1}^+ b_{k-1}^- - b_k^+ b_k^- (2 ≤ k ≤ n)
   - H_{n+1} = -b_n^+ b_n^- - 1/2

4. **Structure Constants**: Framework in place; full bracket computation deferred to I04 verification phase where Jacobi identity will be validated.
