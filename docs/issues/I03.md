### Response

#### Implementation
- `src/C_oscillator.py`: exact oscillator engine on U(A). Words are normal ordered
  (`a_1_p < a_1_m < b_1_p < b_1_m < ...`) by adjacent swaps x y = (-1)^{p(x)p(y)} y x + [x,y};
  κ is moved to the front with the Koszul sign, κ² = 0. Coefficients are exact `Fraction`s
  (as linear forms in parameters, needed later for gb). Optional deformation flag adds
  [b_j^s, a_1^σ] = -gb_{σ,j,s} κ (used from I05 on).
- `src/C_generators.py`: basis in PBW order (`handover/notation.md`), realizations, and a
  decomposer: span{generators} ⊕ CK is identified with the span of normal-ordered quadratic
  monomials {1, a⁺a⁻, a^σ b, b b'} (a square invertible rational matrix, size 2n²+5n+2). Every
  bracket [X,Y} = XY - (-1)^{p(X)p(Y)}YX is computed in U(A) and decomposed exactly.
  The generator asserts that no K-component and no non-quadratic word ever appears.
- Output: `data/C_{1,2,3}_structure.json` per `docs/json_schema_specification.md` §1.

#### Decision: what goes into `structure_constants`
Options: (a) only X ≤ Y, (b) all ordered pairs. Chose (b) (as stated in I02) so antisymmetry
is checkable from data alone.
