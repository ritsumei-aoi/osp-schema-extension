#### Implementation

- `src/oscillator_algebra.py` — exact symbolic CAR/CCR normal-ordering engine
  over `fractions.Fraction`. Letters are integers (`a_1_p < a_1_m < b_1_p <
  b_1_m < ...`, matching the I01 word ordering); elements are linear
  combinations of normal-ordered words. Rewrite rules: `a_1_m a_1_p = 1 −
  a_1_p a_1_m`, `(a_1^±)² = 0`, `b_k_m b_k_p = b_k_p b_k_m + 1`, mixed
  letters commute. The engine also carries an optional first-order
  κ-deformation channel (used from I05 onward; inert here).
  `super_bracket(X,Y) = XY − (−1)^{p(X)p(Y)} YX`.
- `src/C_generators.py` — builds the I01 basis (labels, parities, oscillator
  realizations), computes all ordered-pair brackets, decomposes them exactly
  onto the basis (`decompose` raises if a residual scalar remains, so closure
  is asserted on every bracket), and emits Schema 1 JSON conforming to
  `docs/json_schema_specification.md`.

Design choice: brackets are *computed in the oscillator representation*, not
tabulated by hand — associativity of the oscillator algebra then guarantees
the super Jacobi identity structurally, and I04 re-verifies it independently
from the JSON alone.
