#### Implementation

  normal ordering by adjacent swaps $xy = (-1)^{p(x)p(y)}yx + [x,y\}$, $(a_1^\pm)^2=\kappa^2=0$. It already supports the
  I05 deformation flag ($[b_j^s,a_1^\sigma]=-\mathrm{gb}_{\sigma,j,s}\kappa$), off in Schema 1. Coefficients are exact
  `Fraction` linear combinations (`Lin`).

  (left inverse of the realization matrix over the monomials, with a residual check, columns = basis + `K`), and the
  Schema 1 writer following `docs/json_schema_specification.md`. Every bracket of two basis elements is computed in the
  oscillator algebra and re-expanded; a non-zero `K` component or a residual raises an error.
- `tests/test_C_generators.py` — counts, parity, PBW order, the oscillator relations, two hand-computed brackets
  ($\{a_1^+b_1^+, a_1^-b_1^-\} = -H_1-2H_2$, $[(b_1^+)^2,(b_1^-)^2]=4H_2$), and JSON ↔ spec conformance
