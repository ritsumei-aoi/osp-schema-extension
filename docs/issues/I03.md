1. **Implementation**: Created `src/C_generators.py` with:
   - `build_basis(n)`: builds even/odd basis lists following PBW ordering
   - `oscillator_form(label, n)`: maps generators to oscillator monomials
   - `normal_order(word, n)`: normal-orders oscillator products using CAR/CCR
