#### Implementation (`src/C_generators.py`)

* `OscillatorAlgebra(n, gb=None)`: exact (Fraction) normally ordered Weyl–Clifford algebra with symbols `kappa < a_1_p < a_1_m < b_1_p < b_1_m < …`. Reordering rules: $\{a_1^-,a_1^+\}=1$, $[b_k^-,b_k^+]=1$, fermionic squares $=0$, $\kappa$ odd/central/nilpotent, and the optional deformation $[b_k^s,a_1^\sigma] = -\mathrm{gb}\,\kappa$ (used from I05 on). Graded bracket $[A,B\} = AB - (-1)^{p(A)p(B)}BA$.
* `build_basis(n)`: odd/even label lists in the PBW order of `handover/notation.md` §4, realizations (Frappat Cartans $H_1,\dots,H_{n+1}$, $(b_k^\pm)^2$, $b_i^\pm b_j^\pm$, $a_1^\sigma b_k^s$) and root strings.
* `Decomposer`: exact RREF-based decomposition of any element in $\mathrm{span}(\text{basis}\cup\{K\})$; raises if the basis were dependent or the element outside the span (so closure is *asserted*, not assumed).
* `compute_structure_constants(n)`: all ordered pairs $(X,Y)$; asserts no $\kappa$ and no $K$ component arises in the undeformed brackets.
* `build_schema1(n)` writes `data/C_{n}_structure.json` per `docs/json_schema_specification.md` §1.

**Options considered for decomposition**: (a) solve a fresh linear system per bracket (too slow: ~10⁴ solves × 34³ Fraction ops), (b) greedy monomial matching (fragile for the Cartan sector, where $b_k^+b_k^-$ and constants mix), (c) one RREF of the basis matrix with tracked transformation, reused for every bracket — chosen (c).
