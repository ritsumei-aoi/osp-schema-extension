#### Decisions and Results

**Implementation**: Created `src/C_generators.py` with:
- `build_basis(n)`: Constructs even/odd basis lists following PBW ordering from I01.
- `get_realization(label, n)`: Returns oscillator word representation for each generator.
- `compute_bracket(x, y, n)`: Computes graded bracket [X, Y} via oscillator normal ordering with CAR/CCR relations.
- `decompose_via_inverse(osc_result, inv_map, n)`: Decomposes oscillator expressions into basis generators, with special handling for multi-term Cartan generators via `_solve_cartan`.
- `generate_schema1_json(n)`: Produces complete Schema 1 JSON.

**Key design decision**: The bracket computation uses recursive normal ordering with automatic fermion nilpotency detection (duplicate fermionic operators → zero).
