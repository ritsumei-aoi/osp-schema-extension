**Oscillator Realizations**:
- H_1 = a_1^+ a_1^- + b_1^+ b_1^-
- H_k = b_{k-1}^+ b_{k-1}^- - b_k^+ b_k^- (for k=2,...,n)
- H_{n+1} = -b_n^+ b_n^- - 1/2
- E_eps_del{k}_pp = a_1^+ b_k^+
- E_eps_del{k}_pm = a_1^+ b_k^-
- E_eps_del{k}_mp = a_1^- b_k^+
- E_eps_del{k}_mm = a_1^- b_k^-
- E_2del{k}_p = (1/2)(b_k^+)^2
- E_del{i}_del{j}_pp/pm/mp/mm = b_i^{±} b_j^{±}
