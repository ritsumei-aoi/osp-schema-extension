#### Decisions and Results

1. **Implementation**: Created `src/C_generators.py` using the graded Leibniz rule approach for computing brackets of bilinear oscillator generators. The fundamental oscillator brackets (CAR for fermions, CCR for bosons) are used to expand [AB, CD} into four terms via:
   `[AB, CD} = A[B,C}D + (-1)^{pB*pC}[A,C}BD + (-1)^{(pA+pB)*pC}C·A[B,D} + (-1)^{(pA+pB)*pC+pB*pD}C·[A,D}B`

2. **Structure constants generated**:
   - C(2) = osp(2|2), n=1: 21 structure constants, dim 8 = 4|4
   - C(3) = osp(2|4), n=2: 102 structure constants, dim 19 = 11|8
   - C(4) = osp(2|6), n=3: 263 structure constants, dim 34 = 22|12
