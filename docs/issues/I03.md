#### Implementation

**Script**: `src/C_generators.py`

Key components:
1. `get_basis(n)` — returns even/odd generator lists following PBW ordering from I01.
2. `build_mono_to_gen(n, all_basis)` — builds the inverse map from oscillator monomials to generators+scalar K. Uses exact algebraic inverses for Cartan monomials:
   - N_k = b_k+b_k- = (sum_{j=k+1}^{n} H_j) - H_{n+1} - 1/2 K
   - N_a = a1+a1- = H_1 - (sum_{j=2}^{n} H_j) + H_{n+1} + 1/2 K
3. `normal_order(word, n)` — normal-orders oscillator words using bubble sort with CCR/CAR.
4. `graded_commutator_monos(m1, m2, n)` — graded commutator in the oscillator algebra.
5. `compute_structure_constants(n, all_basis, mono_map)` — computes [X,Y} for all pairs, expresses result in basis.
6. `build_schema(n)` — assembles the full Schema 1 JSON.

**Bug encountered and fixed**: Initial mono_to_gen naive inversion mapped b1+b1- to H_1-H_2 instead of -H_2 - 1/2. Fixed by deriving the algebraic inverse of the Cartan generator→monomial system, which correctly handles the scalar K terms (that cancel in valid Lie algebra brackets).
