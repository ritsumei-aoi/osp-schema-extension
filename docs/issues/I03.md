#### Implementation
- `src/oscillator.py` — exact (Fraction) super oscillator algebra: normal ordering
  `a_1_p < a_1_m < b_1_p < b_1_m < ...` via adjacent super-swaps `xy = (-1)^{p(x)p(y)} yx + [x,y}`;
  CAR/CCR; optional deformed mixed relation (used from I05); κ kept on the far left with sign
  `(-1)^{parity of the prefix}`, κ² = 0.
- `src/C_generators.py` — basis in PBW order (`notation.md` §4), realizations (§3), bracket
  `[X,Y} = XY - (-1)^{p(X)p(Y)}YX` evaluated in the oscillator algebra, and **exact** decomposition
  into the basis + K (Gauss–Jordan inverse over the (dim+1) quadratic/constant monomials).
  The generator raises an error if any K (constant) component appears — none did, confirming
  that the super-symmetrized Cartans of `Cn1_definition.md` give a closed span.
- `tests/test_C_generators.py` — oscillator relations, counts (2n²+n+1 | 4n), parity of
  realizations, parity of bracket results, Chevalley checks
  ([E_2del{n}_p, E_2del{n}_m] = H_{n+1}, [E_eps1_del1_pm, E_eps1_del1_mp] = H_1),
  JSON-on-disk equals freshly generated data, schema key/dimension conformance.
