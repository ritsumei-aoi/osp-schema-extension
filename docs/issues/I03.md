### Response

#### Implementation

`src/C_generators.py` implements:
- `build_basis(n)`: returns (even, odd) lists following PBW convention from notation.md.
- `compute_structure_constants(n, even, odd)`: computes all nonzero graded brackets analytically from CAR/CCR relations.
- `build_schema1(n)`: assembles the full Schema 1 JSON dict.
- `main()`: writes `data/C_{n}_structure.json` for n=1,2,3.

Bracket computation covers: Cartan action on all generators (using eigenvalue formulas derived from N_bk and N_a in terms of H_k), odd-odd anticommutators (resolved via CAR analysis), even-odd commutators, and even-even commutators.
