### Response

**Implementation**

- `src/C_oscillator.py`: a small exact (Fraction) Weyl–Clifford engine. Generators `kappa < a_1_p < a_1_m < b_1_p < ...`; normal ordering by adjacent swaps with the relations `{a-,a+}=1`, `[b-,b+]=1`, `(a±)²=0`, `κ²=0`, κ super-central, and the (optional) deformation `[b_j^s, a^σ] = -gb κ`. With gb = 0 it is the undeformed algebra.
- `src/C_generators.py`: basis builders (PBW order of `notation.md`), `realization(n)`, a `Decomposer` that expands an oscillator element in the Weyl-symmetrised basis, `structure_constants(n, gb)` (returns undeformed part, κ-part and residual central constants), and the Schema 1 writer.
- Options considered for computing structure constants: (a) hard-code Frappat's root-space tables (error-prone, no independent check); (b) compute the brackets from the oscillator realization (chosen: the CAR/CCR relations are the *definition* in the docs, and the same engine later gives the deformation of I05 for free); (c) matrix representation (needs a super-vector-space rep; unnecessary).
- Decision: all ordered pairs stored (so antisymmetry is a real check in I04). The undeformed algebra closes with no residual central constant (asserted in `build_schema1`).

**Results**: `python3 src/C_generators.py` writes `data/C_1_structure.json` (40 non-zero entries), `C_2_structure.json` (198), `C_3_structure.json` (528).

**Verification** (`python3 -m pytest -q`): `16 passed`. Tests cover generator counts (4|4, 11|8, 22|12), schema keys, p(Z)=p(X)+p(Y) for every entry, JSON == freshly generated constants, and hand-checked weights (e.g. `[H_2, E_eps1_del1_pp] = -E_eps1_del1_pp`, `[H_1, E_eps1_del1_pp] = 2 E_eps1_del1_pp` for n=1).
