### Response

**Decisions:**
1. **Implementation**: Wrote a Python normal ordering engine for oscillators in `src/C_generators.py`. The engine bubbles oscillators using canonical commutation/anticommutation relations (`[b^-, b^+] = 1`, `{a^-, a^+} = 1`, else 0). Superbrackets are computed as $[X, Y] = X Y - (-1)^{p(X)p(Y)} Y X$.
2. **Finding Linear Combinations**: Since root generators are simple monomials, their coefficients are easily extracted. The Cartan elements are reconstructed starting with `H_1` and progressing to `H_{n+1}`.
3. **Tests**: Added `tests/test_C_generators.py` to assert dimension count formulas against the generated arrays and validate the produced JSON schemas.

**Results & Verification:**
- Scripts generated `C_1_structure.json`, `C_2_structure.json`, and `C_3_structure.json` in `data/`.
- Tests passed perfectly.
