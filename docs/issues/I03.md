#### Implementation Summary

**Script**: `src/C_generators.py` — implements the `CnPlusOne` class with:
- `_build_generators()`: constructs all generator realizations as oscillator monomials
- `_no_recurse()`: recursive PBW normal ordering using CCR/CAR rules
- `multiply()` / `bracket()`: algebra element multiplication and graded bracket
- `_solve_cartan()`: Gaussian elimination to extract Cartan coefficients
- `element_to_gens()`: converts monomial dict to generator coefficients
- `compute_structure_constants()`: computes all pairwise brackets
- `build_schema1()`: assembles the Schema 1 JSON document

**Key implementation choices**:
- Oscillators indexed 0=a1p, 1=a1m, 2=b1p, 3=b1m, 4=b2p, ... (PBW order)
- Normal ordering: a1m*a1p → 1 - a1p*a1m; bkm*bkp → bkp*bkm + 1; mixed just commute
- Cartan extraction: Gaussian elimination on (n+2)×(n+1) augmented matrix

**JSON output**:
- `data/C_1_structure.json`: dim 4|4, 20 non-zero brackets
- `data/C_2_structure.json`: dim 11|8, 99 non-zero brackets
- `data/C_3_structure.json`: dim 22|12, 264 non-zero brackets
