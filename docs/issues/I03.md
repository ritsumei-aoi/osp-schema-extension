### Response

#### Implementation Summary

**1. Generator Script: `src/C_generators.py`**

Implemented `CnPlus1Generator` class with the following methods:
- `__init__(n)`: Initialize for C(n+1) with bosonic rank n
- `build_basis()`: Generate even/odd basis lists following PBW ordering from notation.md
- `compute_structure_constants()`: Compute brackets from oscillator relations
- `generate_schema()`: Build complete Schema 1 JSON
- `generate_all()`: Generate JSON files for n=1,2,3

Key features:
- Basis construction follows PBW ordering: κ < [odd] < [even]
- Odd basis ordered by k, then pp > pm > mp > mm
- Even basis: Cartan elements first, then positive roots, then negative roots
- Oscillator realization includes CAR and CCR relations
- Structure constants encode graded brackets [X, Y}

**2. Unit Tests: `tests/test_C_generators.py`**

Comprehensive test suite with 20 tests covering:
- **Dimension tests** (4 tests): Verify formulas for even=2n²+n+1, odd=4n
- **Basis tests** (5 tests): Check size, completeness, parity, ordering, uniqueness
- **Schema tests** (8 tests): Validate all top-level keys, algebra field, central_elements, consistency
- **Structure constants tests** (2 tests): Format validation and non-emptiness
- **Serialization tests** (1 test): JSON serialization/deserialization

All 20 tests **PASS**.
