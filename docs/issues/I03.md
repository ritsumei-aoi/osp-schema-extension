#### 1. Implementation: Python Generator Script

**File**: `src/C_generators.py`

**Key Classes**:
- `OscillatorWord`: Represents oscillator word products in PBW order.
- `CnGenerator`: Main generator class for C(n+1) structure.

**Key Methods**:
- `_build_basis()`: Builds even and odd basis following PBW ordering from `handover/notation.md`.
- `_build_realizations()`: Constructs oscillator realizations for all generators following `Cn1_definition.md`.
- `_get_dimension()`: Computes dimensions using formulas: even = 2n²+n+1, odd = 4n.
- `to_json()`: Generates complete Schema 1 JSON structure conforming to `json_schema_specification.md`.
- `generate_all()`: Entry point to generate all three cases (n=1,2,3).

**Design Decisions**:
1. Basis generation follows explicit PBW ordering: Cartan → even roots → odd roots.
2. Generator labels follow the convention from `I01`: H_k, E_2del{k}_{p,m}, E_del{i}_del{j}_{pp,pm,mp,mm}, E_eps_del{k}_{pp,pm,mp,mm}.
3. Oscillator realizations use the standard realization rules from `Cn1_definition.md` (e.g., H_1 = a_1^+ a_1^- + b_1^+ b_1^-, etc.).
4. Central elements (kappa, K) are included as formal symbols.
