#### Implementation
- `src/oscillator_algebra.py` — exact (Fraction) normal-ordering engine for U(A): generators
  κ, a_1^±, b_k^±, relations CAR/CCR, κ central odd with κ²=0, optional deformation
  [b_j^s, a_1^σ] = −gb_{σ,j,s}κ (used from I05 on). Normal order κ < a_1_p < a_1_m < b_1_p < b_1_m < ….
- `src/C_generators.py` — basis in PBW order (notation.md §3), oscillator realizations,
  `Decomposer` (exact inversion of the square map  g ⊕ ℂK → monomial space), structure
  constants for **all ordered pairs**, Schema 1 JSON writer.
- `tests/test_C_structure.py` (+ `tests/conftest.py`).

Design decision: structure constants are not hand-coded; they are computed by expanding
$[X,Y] = XY - (-1)^{p(X)p(Y)}YX$ in U(A), normal ordering, and decomposing in the basis. The
generator raises if any undeformed bracket has a non-zero K (constant) component or a monomial
outside g ⊕ ℂK — neither occurred.
