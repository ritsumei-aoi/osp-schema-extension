### Response

#### Implementation

- `src/oscillator_algebra.py`: exact Weyl–Clifford engine. Elements are dictionaries
  {normal-ordered word → `Fraction`}; normal ordering is an iterative rewriting system with the
  rules `a_1_m a_1_p = -a_1_p a_1_m + 1`, `(a_1^±)^2 = 0`, `b_k_m b_k_p = b_k_p b_k_m + 1`,
  and (when `deformed=True`, used from I05 on) `b_j^s a_1^σ = a_1^σ b_j^s - gb_{σ,j,s} kappa`
  with `kappa` odd central and `kappa^2 = 0`. Deformation parameters are formal commuting
  symbols placed first in the word, so all coefficients stay exact rationals.
  `Decomposer` expresses an element in the basis (plus `K` = constant) by exact linear algebra
  and raises if the element is not in the span.
- `src/C_generators.py`: label rules (`even_labels`, `odd_labels`, `pbw_order` exactly as in
  `notation.md` §4–5), oscillator realization (`realization_words`), structure constants for
  all ordered pairs (`compute_structure_constants`), and the Schema 1 document
  (`build_schema1`, `write_schema1`). CLI: `python3 src/C_generators.py 1 2 3`.
- `tests/test_C_generators.py`: 29 tests (engine relations; counts for n=1,2,3; explicit
  lists vs notation.md; parity from realization and from the file; closure of brackets with no
  `K` term; Cartan elements commute and root vectors are weight vectors; specific hand-computed
  brackets for n=1; super-antisymmetry for n=1,2,3; super-Jacobi for n=1,2; schema conformance
  to `docs/json_schema_specification.md`; on-disk files equal to a fresh generation).

#### Design decisions
- All ordered pairs (X,Y) are stored (not only X<Y) so that antisymmetry is checkable from
  the file alone (I04). Counts of non-zero brackets: n=1: 40, n=2: 198, n=3: 528.
- The generator asserts that no constant (`K`) term appears in any bracket; this holds for all
  n because the Frappat Cartan elements are exactly the symmetrized number operators
  (`notation.md` §3.3). Verified: `[E_2del1_p, E_2del1_m] = 4 H_2` and
  `[E_eps1_del1_pp, E_eps1_del1_mm] = -H_1 - 2 H_2` (both also checked by hand).
