### Response

**Implementation:** `src/C_generators.py` with oscillator algebra computation.

**Algorithm:** Normal ordering via bubble sort with CCR/CAR rules:
- CAR: a_1_m * a_1_p → -a_1_p * a_1_m + 1; adjacent identical fermion → 0
- CCR: b_k_m * b_k_p → b_k_p * b_k_m + 1 (same mode)
- Cross: boson-fermion commute freely

**Bug fixed:** Initial implementation incorrectly dropped all monomials with repeated fermionic operators (non-adjacent). Correct rule: only ADJACENT identical fermionic operators give zero.

**Results:**
```
C(2) = osp(2|2), n=1: dim=(4|4), non-zero brackets: 20
C(3) = osp(2|4), n=2: dim=(11|8), non-zero brackets: 99
C(4) = osp(2|6), n=3: dim=(22|12), non-zero brackets: 264
```

**Spot checks verified:**
