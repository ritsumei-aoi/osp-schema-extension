### Response

**Implementation: `src/C_generators.py`**

Key functions:
- `make_basis(n)`: generates even/odd basis lists following PBW ordering from I01.
- `make_parity(basis)`: assigns parity 0/1 to each generator.
- `make_generator_realization(n)`: encodes each generator as oscillator words.
- `compute_structure_constants(n)`: computes all non-zero graded brackets using oscillator algebra rules (CAR + CCR).
- `build_schema1(n)`: assembles full Schema 1 JSON.

**Bracket computation strategy**: Used oscillator algebra:
- Cartan × root generator: eigenvalue from H_k action on root vectors.
- Root × root: check if root sum is 0 (→ Cartan) or another root (→ N_{αβ} coefficient).
- N_{αβ} computed explicitly from CAR/CCR: {a_1^σ b_k^s, a_1^τ b_l^t} = {a_1^σ,a_1^τ} b_k^s b_l^t + fermionic cross terms.

**Results**:
- n=1: 32 structure constants, dim=(4|4) ✓
- n=2: 168 structure constants, dim=(11|8) ✓
- n=3: 456 structure constants, dim=(22|12) ✓

**Tests**: 30 tests in `tests/test_C_structure.py` — all pass.
Tests cover: dimension, parity counts, label consistency, parity conservation, Cartan action, odd-odd brackets, schema fields.
