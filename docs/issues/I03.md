### Response

**Decisions and Results**

#### Implementation

- `src/C_generators.py`: Full implementation of C(n+1) structure constant generator.
  - `build_basis(n)`: Constructs even/odd basis lists following PBW ordering from I01.
  - `OscillatorAlgebra`: Computes graded brackets via oscillator normal ordering with proper sign rules for the graded bracket $[X,Y\} = XY - (-1)^{p(X)p(Y)} YX$.
  - `decompose_result()`: Decomposes bracket results (sums of monomials) into linear combinations of generators using linear algebra over $\mathbb{Q}$.
  - `generate_schema1(n)`: Produces complete Schema 1 JSON for given bosonic rank.

#### Bug Fix Note

Initial implementation had a sign error in the graded bracket for odd-odd elements (computing commutator instead of anticommutator). Fixed by using the correct formula: second term coefficient = $-(-1)^{p(X)p(Y)}$. Also fixed generator identification to use linear system solving instead of monomial matching, since generators like $H_1 = a_1^+ a_1^- + b_1^+ b_1^-$ span multiple monomials.
