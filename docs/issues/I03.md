#### Implementation

Implemented `src/C_generators.py` with:
- `build_basis(n)`: returns (even_basis, odd_basis) following PBW ordering from I01.
- `build_generator_realizations(n)`: maps generator labels to oscillator monomials.
- `graded_bracket(e1, p1, e2, p2, n)`: computes [X,Y} = XY - (-1)^{p(X)p(Y)} YX using CAR/CCR normal ordering.
- `compute_structure_constants(n)`: iterates all pairs and collects non-zero brackets.
- `build_schema1(n)`: assembles the complete Schema 1 JSON.
