### Response

**Implementation**

- `src/C_oscillator.py` — symbolic oscillator algebra with normal-order
  reduction under CAR/CCR relations; graded-bracket primitive.
- `src/C_generators.py` — PBW basis, oscillator realizations, projector
  mapping normal-form polynomials back to basis coefficients, and the
  Schema 1 JSON builder.
- `tests/test_C_generators.py` — dimension counts, parity, a specific
  Cartan–root bracket (expected eigenvalue 2), closure check for every
  pair across n=1,2,3, antisymmetry sample, projection round-trip.

**Debugging note**: The first draft of the Cartan projection had the wrong
signs in the recursion for n≥2. Verified against
`[E_{2δ_1}, E_{-2δ_1}] = -4 b_1^+ b_1^- - 2` (a direct sl_2 computation
using [b_1^-, b_1^+] = 1), which decomposes as -4 H_2 + 4 H_3 for n=2. The
fixed recursion passes the closure check for n=1, 2, 3.

**Verification output**

```

...... 6 passed in 0.03s
$ python3 -m src.C_generators
wrote data/C_1_structure.json (20 brackets)
wrote data/C_2_structure.json (99 brackets)
wrote data/C_3_structure.json (264 brackets)
```

Bracket counts (non-zero, stored once per unordered pair) scale as expected
with dim(g). Closure test embedded in `structure_constants()` validates
every bracket lies in the span of the basis realizations (no residual
K-direction term for the undeformed algebra).
