#### Implementation

- Created `src/C_generators.py` with:
  - `build_basis(n)`: generates even and odd basis lists following PBW ordering from I01
  - `get_realization(label, n)`: maps each generator to its oscillator realization
  - `compute_bracket_oscillator()`: computes graded bracket using normal-ordered oscillator algebra
