#### 2. Design decision: compute, don't tabulate

Options considered for obtaining the structure constants:

- **(a) Hard-code a root-system bracket table** $[E_\alpha, E_\beta] = N_{\alpha\beta}E_{\alpha+\beta}$
  with Chevalley-style $N_{\alpha\beta}$.
- **(b) Matrix realization** of $\mathfrak{osp}(2|2n)$ as $(2+2n)\times(2+2n)$
  supermatrices, brackets by supermatrix commutator.
- **(c) Chosen — symbolic oscillator calculus**: represent every generator as a
  normal-ordered word in $a_1^\pm, b_k^\pm$ and compute $[X,Y\}$ as the graded
  commutator inside $\mathcal U(A)$, then decompose back into the basis.

**(c)** was chosen because it is the *only* option that extends without change
to Layers 2–4: the inhomogeneous deformation of I05 is literally a modification
of one oscillator contraction (`[b_k^s, a_1^σ] = -gb·κ`), so the same
`normalize()` routine computes both the undeformed and the deformed brackets.
(a) would require re-deriving sign conventions by hand and would give no path to
γ; (b) would require a separate supertrace-form bookkeeping for κ.

A further benefit: option (c) makes closure a *theorem checked at runtime*.
`CAlgebra.decompose` raises `ValueError` if a bracket leaves
$\mathrm{span}(\text{basis}) + \mathbb{C}K$, so the 8/19/34-dimensional spans
being subalgebras is verified rather than assumed.

#### 3. Engine details

Normal ordering is a confluent rewriting on letter words with index map
`kappa=0, a_1_p=1, a_1_m=2, b_k_p=2k+1, b_k_m=2k+2`. For the first descent
$(x,y)$ the rule is

```
x y  ->  (-1)^{p(x)p(y)} y x  +  [x, y}
```

with the only non-zero letter-brackets being $\{a_1^-,a_1^+\}=1$,
$[b_k^-,b_k^+]=1$ and (Layer 2+) $[b_k^s,a_1^\sigma]=-\mathrm{gb}\,\kappa$.
Sorted words containing a repeated odd letter are set to zero, implementing
$(a_1^\pm)^2 = \kappa^2 = 0$. Results are memoised per algebra instance.

Decomposition exploits the fact that each basis element has a unique *signature
word* (its quadratic monomial); after reading off those coefficients the
residual must be a scalar, which is reported as the `K`-component.
