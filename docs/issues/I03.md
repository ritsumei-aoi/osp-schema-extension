### Response

Implemented `src/C_generators.py`, the CAR/CCR normal-ordering and graded
bracket generator, plus `tests/test_C_generators.py`. Generated
`data/C_1_structure.json`, `data/C_2_structure.json`, and
`data/C_3_structure.json`. The generator solves each bracket in the basis over
exact rational coefficients and raises an error if closure or linear
independence fails. Added `pythonpath = .` to `pytest.ini` so the source module
imports with the standard pytest command.

The C(n+1) definition gives the terminal simple-root realization with a
$\tfrac12(b_n^+)^2$ factor, but gives all-root generators as $(b_i^+)^2$.
For the schema I followed the all-root formula uniformly (also for the
terminal root), matching the general generator-label realization; this fixes
the normalization used in the generated constants.

Verification:
- `pytest -q tests/test_C_generators.py`: 5 passed.
- Parsed and checked all generated JSON files. Counts/bracket records:
  `C_1_structure.json`: 4 even, 4 odd, 20 non-zero bracket records;
  `C_2_structure.json`: 11 even, 8 odd, 99 records;
  `C_3_structure.json`: 22 even, 12 odd, 264 records.
- Every structure-constant label resolves to the generated basis, and parity,
  realization coverage, and dimension formulas pass validation.
