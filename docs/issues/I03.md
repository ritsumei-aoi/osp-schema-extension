### Response

**Implementation**: `src/C_generators.py` — uses an oscillator algebra normal-ordering engine (CAR for a1p/a1m, CCR for bkp/bkm) to compute structure constants by evaluating graded brackets [X,Y} = XY - (-1)^{pX*pY}YX.

Key fix required: `_is_zero_monomial` to detect fermion-squared terms BEFORE swap-sorting (a1p*a1p=0 can occur in already-sorted position).

**Results**:
- C_1_structure.json: 4 odd + 4 even = 8 generators, 22 non-zero structure constants
- C_2_structure.json: 8 odd + 11 even = 19 generators, 97 non-zero structure constants
- C_3_structure.json: 12 odd + 22 even = 34 generators, 258 non-zero structure constants

**Tests**: `tests/test_C_structure.py` — 24 tests, all PASSED. Checks: basis counts, parity conservation, schema version, central elements, Cartan count, eps1 generator count, non-empty structure constants.
