### Response

#### Decisions and Results

**Implementation**: Created `src/C_generators.py` with the following components:
- `build_basis(n)`: generates even/odd basis lists following PBW ordering from I01
- `get_realization(label, n)`: returns oscillator word representation for each generator
- `compute_bracket(X, Y, n)`: computes graded bracket using oscillator algebra (CAR for fermions, CCR for bosons)
- `express_in_basis(osc_terms, n)`: converts oscillator word results back to generator basis, including proper Cartan decomposition via linear system solving
- `generate_schema1(n)`: produces complete Schema 1 JSON

**Bug fix during development**: Initial `express_in_basis` failed to decompose multi-term Cartan generators. Fixed by implementing `_solve_cartan_system()` which solves the Cartan word ↔ generator linear system exactly using Fraction arithmetic.

**Generated files**:
- `data/C_1_structure.json`: C(2) = osp(2|2), 4 even + 4 odd, 19 non-zero brackets
- `data/C_2_structure.json`: C(3) = osp(2|4), 11 even + 8 odd, 92 non-zero brackets
- `data/C_3_structure.json`: C(4) = osp(2|6), 22 even + 12 odd, 243 non-zero brackets

**Tests**: 35 tests pass covering basis counts, dimension formulas, parity, realizations, bracket computations, schema structure, and JSON file consistency.
