### Analysis & Decisions
1. **Implementation Strategy**: Instead of a full symbolic solver, I wrote a script (`src/C_generators.py`) that uses a custom algebra evaluator for normal-ordered polynomials of oscillators. It computes the graded commutator using exact oscillator algebra relations (incorporating `omega` function for scalar central parts, although only the quadratic part is kept for the unextended Lie superalgebra structure constants).
2. **Schema Output**: Successfully emitted `data/C_1_structure.json`, `data/C_2_structure.json`, and `data/C_3_structure.json` containing the evaluated structure constants.
3. **Tests**: Implemented and passed `tests/test_C_generators.py` using `pytest`. The tests verify basis lengths against the $2n^2 + n + 1$ (even) and $4n$ (odd) formulas and ensure parity preservation in the structure constants.
4. **Execution**: All completion criteria met.
