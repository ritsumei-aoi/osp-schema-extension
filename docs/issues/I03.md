### Response

**Implementation summary:**

Script: `src/C_generators.py`
Tests: `tests/test_C_generators.py` (19 tests, all pass)

**Architecture:**
- `CnAlgebra` class: oscillator algebra for C(n+1) using exact Fraction arithmetic.
- Monomial representation: tuple `(e_a1p, e_a1m, b1p, b1m, ..., bnp, bnm)`.
- Fermionic multiplication: hardcoded 16-case table (CAR relations).
- Bosonic multiplication: normal-ordering formula $(b^-)^q(b^+)^r = \sum_j j!\binom{q}{j}\binom{r}{j}(b^+)^{r-j}(b^-)^{q-j}$.
- `super_comm`: graded bracket $[X,Y\} = XY - (-1)^{p(X)p(Y)} YX$.
- `decompose`: non-Cartan generators identified by unique monomials; Cartan generators solved via the H_j matrix equations.

**Key discovery:** [H_1, E_eps1_del{k}_pp] = 2*E (not 1*E), because H_1 = N^f + N_1 and both a_1^+ and b_k^+ contribute weight +1 each. This is correct as the root ε+δ_k has weight 2 under H_1.
