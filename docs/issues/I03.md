### Response

Implemented `src/C_generators.py`, which constructs the basis in finalized
PBW order, computes exact oscillator products using CAR/CCR normal ordering,
projects all graded brackets onto the basis, and writes Schema 1 output for
ranks 1–3. Generated `data/C_1_structure.json`,
`data/C_2_structure.json`, and `data/C_3_structure.json`; each contains
complete basis, parity, oscillator realization, central-element metadata, and
nonzero structure-constant records. Added tests for schema/basis counts,
parities, generated-file consistency, bracket record consistency, and the
graded Jacobi identity.

Implementation decision: use exact `Fraction` coefficients and a small
in-repository CAR/CCR normal-ordering implementation rather than floating
point or a new dependency. Bracket records store each canonical PBW-ordered
input pair once, with graded skew-symmetry determining the reversed pair.
During validation, the first Jacobi run exposed incorrect handling of
non-adjacent repeated fermion symbols in the normal-ordering reducer; the
reducer was corrected to apply the CAR relation before deciding whether
fermion squares vanish.
