### Response

**Implementation**: `src/C_generators.py`

Key algorithm: Wick-contraction formula for Lie superalgebra brackets of oscillator bilinears:
  [o1·o2, o3·o4}_g = c23·(o1·o4) + (-1)^{p2·p3}·c24·(o1·o3) + (-1)^{p2·(p3+p4)}·c13·(o4·o2) + (-1)^{p2·(p3+p4)+p1·p3}·c14·(o3·o2)

Number operators expressed in terms of Cartan generators analytically:
  n_k = sum_{l=k+1}^{n} H_l - H_{n+1} - 1/2 (bosonic)
  n_a = H_1 - H_2 - ... - H_n + H_{n+1} + 1/2 (fermionic)

**Results**:
- C(2) (n=1): 20 non-zero structure constants. Total dim=8 (4+4).
- C(3) (n=2): 99 non-zero structure constants. Total dim=19 (11+8).
- C(4) (n=3): 264 non-zero structure constants. Total dim=34 (22+12).

**Known bracket verification** (manually computed and confirmed):
- [E_eps1_del1_pp, E_eps1_del1_mm] = -H_1 - 2*H_2 ✓ (matches direct oscillator algebra computation)
- [E_2del1_p, E_2del1_m] = 4*H_2 ✓ (verified via matrix element calculation: [(b^+)^2,(b^-)^2] = -4n-2 = 4H_2)
- [H_1, E_eps1_del1_pp] = 2*E_eps1_del1_pp ✓
- [H_2, E_eps1_del1_pp] = -E_eps1_del1_pp ✓

**Tests**: 24 tests passed (`tests/test_C_generators.py`).

**Bug fixed during development**: Signs in Wick contraction Terms 3 and 4 initially used p1 instead of p2 (= p(B) in [AB,CD}_g Leibniz formula). Fixed and all tests pass.
