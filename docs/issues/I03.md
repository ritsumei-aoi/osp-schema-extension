### Response

**Implementation**
- `src/osc_algebra.py`: exact (Fraction) normal-ordered Weyl-Clifford algebra: fermion products via a faithful 2x2 matrix model of the CAR pair, boson products via `b-^q b+^p = sum_k k! C(q,k) C(p,k) b+^{p-k} b-^{q-k}`; graded bracket `[X,Y} = XY - (-1)^{pxpy}YX`. It also contains the optional kappa-contraction used from I05 on.
- `src/C_generators.py`: `build_basis(n)` (PBW order from `handover/notation.md`), `Decomposer` (exact coordinates in the basis, with residual detection), `structure_constants(n)`, `build_schema1(n)`, writes `data/C_{1,2,3}_structure.json`.
- `tests/test_C_generators.py`: counts, parity, anti-symmetry, known brackets, schema keys, data-file == generator output, closure.

**Decisions / options**
- Structure constants are computed from the oscillator realization itself (no hand-typed table), by decomposing every bracket in the basis with an exact left inverse. Alternative (root-theoretic formulas with Frappat normalization) rejected: more error-prone, no independent check. Closure is checked: any bracket leaving the span would raise (residual constant or monomial). **No residual occurred**: the Weyl-symmetrized Cartan choice makes the span closed without a separate K, for n=1,2,3.
- `E_{±2δ}` carries 1/2; `[E_2del_n_p, E_2del_n_m] = H_{n+1}` (an earlier sign typo in notation.md was corrected: it is +H_{n+1}).

**Results**
- n=1: 4|4, 40 nonzero (X,Y,Z) entries; n=2: 11|8, 198 entries; n=3: 22|12, 528 entries.
- Spot check by hand: `{a+b+, a-b-} = b+b- - a+a- + 1 = -H_1 - 2H_2` for n=1 matches the JSON (`-1`, `-2`).
