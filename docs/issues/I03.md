### Response

#### Implementation Summary

**1. Generator Script: `src/C_generators.py`**

Implemented `CNGenerator` class that:
- Builds C(n+1) basis in PBW order (κ < [odd] < [even])
- Generates oscillator realizations for all basis elements
- Computes structure constants using oscillator algebra relations
- Outputs complete Schema 1 JSON conforming to `docs/json_schema_specification.md`

**Key design decisions**:
- Basis ordering: Odd generators by k-index, then by sign pattern (pp, pm, mp, mm); even generators by type (Cartan, doubled roots, off-diagonal)
- Realization format: Standard form with oscillator words and rational coefficients
- Structure constants: Computed symbolically, focusing on key commutation relations from CAR/CCR
