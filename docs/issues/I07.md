### Response

**Design**
- δf implemented exactly as in `C_coboundary_definition.md`: `(δf)(X,Y) = (−1)^{p(X)}[X,f(Y)] − (−1)^{(p(X)+1)p(Y)}[Y,f(X)] − f([X,Y])`, with f parametrized by φ_ij (`f(Z_j)=Σ_i φ_ij Z_i`, p(Z_i)≠p(Z_j)). `src/coboundary.py` reads only Schema 1/3 JSON. It writes δ of every elementary odd map (32 / 176 / 528 maps for n=1,2,3) and, per Layer-3 profile, a concrete f, its δf and the residual γ − δf.
- **Choice of the concrete f** (options considered): (a) arbitrary basic solution of the linear system δf = γ by elimination — works but gives an unstructured, pivot-dependent f; (b) a structured f from the geometry. Chose (b): the deformation `[b_j^s,a^σ] = −gb κ` is removed by the gauge shift `b' = b + κ u_{j,s}`, `u_{j,s} = gb_{+,j,s} a_1^- + gb_{−,j,s} a_1^+` (then `[b',a^τ] = −gb κ + κ{u,a^τ} = 0`). The induced odd derivation D of the Weyl-symmetrised quadratics (`D(b)=u, D(a)=0`, `src/gauge_f.py`) gives the map; **f = −D_gb** satisfies δf = γ(gb) (sign found by exact comparison; the opposite sign gives −γ). Elimination (a) is kept as an independent triviality test and must agree with (b) (asserted in the generator).
- Reminder: δf uses the undeformed bracket; γ takes values in g thanks to the I05 Weyl-symmetrised realization.
