### Response

Implemented `src/C_coboundary.py`. 

**Odd map f**: Parametrized by gb variables. f(H_1) = sum_{j,sigma,s} gb_{sigma,j,s} * E_eps1_delj_{sigma_s}. All other generators map to 0 (f(H_k for k>1) = 0, f(even roots) = 0, f(odd) = 0).

**Coboundary formula** (from C_coboundary_definition.md):
(δf)(X,Y) = (-1)^{p(X)}[X,f(Y)] - (-1)^{(p(X)+1)p(Y)}[Y,f(X)] - f([X,Y])

The computation iterates over all basis pairs (X,Y), applies f to Y and X, computes [X,f(Y)] and [Y,f(X)] using the Schema 1 structure constants, then subtracts f([X,Y]).

**Output**:
- C_1_coboundary.json: 52 coboundary entries (n=1)
- C_2_coboundary.json: 220 coboundary entries (n=2)
- C_3_coboundary.json: 496 coboundary entries (n=3)

All Z labels in coboundary entries are in the Layer 1 basis (verified: no missing-label warnings).
