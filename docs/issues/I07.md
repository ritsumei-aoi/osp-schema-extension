### Response

**Implementation:** `src/C_coboundary.py`

**Coboundary formula:**
(δf)(X,Y) = (−1)^{p(X)}[X,f(Y)] − (−1)^{(p(X)+1)p(Y)}[Y,f(X)] − f([X,Y])

**f map design:**
- f is an odd linear map g → g.
- Parameters: φ_{src}_{tgt} for each parity-compatible pair (src, tgt).
- f(even) ⊂ span(odd generators); f(odd) ⊂ span(even generators).
- For C(2)/n=1: 4 even × 4 odd + 4 odd × 4 even = 32 phi parameters.

**Algorithm:** Symbolic computation using Schema 1 structure constants (oscillator algebra). For each pair (X,Y), compute three terms symbolically in phi parameters, sum coefficients per basis element Z.

**Spot check:** (δf)(H_1,H_2) at Z=E_ε₁δ₁_pp:
- Term 1: sign=+1, [H_1,f(H_2)] gives 2·φ_{H_2,E_pp}.
- Term 2: sign=-1, [H_2,f(H_1)], [H_2,E_pp]=−E_pp, gives −(−1)·φ_{H_1,E_pp} = +φ_{H_1,E_pp}.
- Term 3: f([H_1,H_2])=0.
- Result: φ_{H_1,E_pp} + 2·φ_{H_2,E_pp} ✓ (matches computed output)

**Results:**
```

```

**Consistency with Layer 1:** All Z entries in (δf)(X,Y) belong to the basis of C(n+1). ✓
