(δf)(X,Y) = (-1)^{p(X)} [X, f(Y)] - (-1)^{(p(X)+1)p(Y)} [Y, f(X)] - f([X,Y])

**Map f**: parity-reversing, f(Z_j) = Σ_i φ_{i,j} Z_i where p(Z_i) ≠ p(Z_j).
Parameterized by φ_{target,source} coefficients.

**Implementation**: `src/C_coboundary.py`
- `compute_coboundary(n)`: computes (δf)(X,Y) symbolically as linear forms in φ parameters

  - Term 3: -Σ_{W,C} f_{XY}^W * φ_{C,W} * C
- Each coboundary entry: (X, Y, Z, phi_param, coeff) where coeff is rational
