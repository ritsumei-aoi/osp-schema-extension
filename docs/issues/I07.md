### Response

#### Implementation
- `src/C_coboundary.py`
  - `coboundary(g, f)`: implements
    `(δf)(X,Y) = (-1)^{p(X)}[X,f(Y)] - (-1)^{(p(X)+1)p(Y)}[Y,f(X)] - f([X,Y])` on the abstract
    algebra of Schema 1 (`[X,K]=0`); coefficients are exact linear forms, so the same code
    handles a symbolic f (unknowns `phi[Z_i][Z_j]`) and a numeric f.
  - `generic_f(g, allow_K)`: the odd map parameterized by one unknown per parity-reversing
    pair (target, source); with `allow_K` the even central element K is an admissible target
    for odd sources (f(K)=0 is forced since f(K) would have to be central and odd).
    Unknown counts: n=1: 36 (32 without K), n=2: 184 (176), n=3: 540 (528).
  - `shift_map_symbolic(n)`: the **representative f**. The deformed relation
    `[b_j^t, a_1^s] = -gb_{s,j,t} κ` is undone at the oscillator level by
    `a_1^s → a_1^s + Σ_{j,t} d_{s,j,t} b_j^t κ` with `d_{s,j,+} = gb_{s,j,-}`, `d_{s,j,-} = -gb_{s,j,+}`
    (κ central, κ²=0 ⇒ CAR/CCR unchanged). Substituting into the realization of a basis
    element gives `X + κ·l(X)` with `l(X)` quadratic, i.e. in g ⊕ C K. Comparing
    `[X+κl(X), Y+κl(Y)]` with `[X,Y]_0 + κ l([X,Y])` yields γ = -δl (with the handover sign
    convention), so `f_rep := -l` is written to Schema 4, both numerically (profile `all_plus`)
    and symbolically in gb.
- Output `data/C_{n}_coboundary.json` (spec §4): `f_parameterization`, `coboundary_symbolic`
  (δ of the generic f, pairs with index(X) ≤ index(Y)), `representative_f` (`map`,
  `map_symbolic_in_gb`, `K_components`), `coboundary_evaluated` (δf_rep, all ordered pairs),
  `comparison_with_layer3`.
- `tests/test_C_coboundary.py`: unknown counts; δ(ad W)=0 for every odd W (sign-convention
  check of the formula); δ(f_rep) = Layer-3 γ for all 5 non-zero profiles and n=1,2,3;
  file conformance; explicit n=1 values.

#### Representative f for n=1 (symbolic in gb; `data/C_1_coboundary.json`)
```
f(E_eps1_del1_pp) = -gb_a1p_b1p·H_2 - gb_a1p_b1m·E_2del1_p + ½gb_a1p_b1p·K
f(E_eps1_del1_pm) =  gb_a1p_b1m·H_2 + gb_a1p_b1p·E_2del1_m + ½gb_a1p_b1m·K
f(E_eps1_del1_mp) = -gb_a1m_b1p·H_2 - gb_a1m_b1m·E_2del1_p + ½gb_a1m_b1p·K
f(E_eps1_del1_mm) =  gb_a1m_b1m·H_2 + gb_a1m_b1p·E_2del1_m + ½gb_a1m_b1m·K
f(H_1)            =  gb_a1m_b1m·E_eps1_del1_pp - gb_a1m_b1p·E_eps1_del1_pm - gb_a1p_b1m·E_eps1_del1_mp + gb_a1p_b1p·E_eps1_del1_mm
f(H_2) = f(E_2del1_±) = 0
```
In general f_rep is supported on the odd generators and on `H_1` (the only even generator
with a fermionic factor); f_rep(odd) ∈ sp(2n)-part ⊕ C K, f_rep(H_1) ∈ g_1.
