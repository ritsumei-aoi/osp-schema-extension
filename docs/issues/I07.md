#### Definition of the odd map f (design decision)

Rather than leaving f as a free parameterization, I derived a **canonical
candidate** from the structure of the deformation: the deformed relation
`[b_j^s, a_1^σ] = −gb_{σ,j,s} κ` is exactly what one obtains by shifting the
fermionic pair inside the ambient oscillator algebra,

    a_1^σ → a_1^σ + κ·Σ_{j,s} t_{σ,j,s} b_j^s,
    t_{σ,j,p} = −gb_{σ,j,m},   t_{σ,j,m} = +gb_{σ,j,p},

(the t/gb index swap and sign come from `[b_j^−, b_j^+] = 1 = −[b_j^+, b_j^−]`).
The induced first-order change on each generator, f(X) = ∂_κ X(a_shifted),
is an **odd** linear map g → g (with central K components):

- `f(E_eps_del{l}_{σs'}) = Σ_{j,s} t_{σ,j,s} · NO(b_j^s b_l^{s'})`
  (even targets; K component ½·t_{σ,l,m} appears when (j,s)=(l,m), s'=p),
- `f(H_eps) = Σ_{j,s} (−t_{m,j,s}·E_eps_del{j}_p{s} + t_{p,j,s}·E_eps_del{j}_m{s})`
  (odd targets),
- `f ≡ 0` on all purely bosonic even generators.

Before implementing, I hand-verified the pair (X,Y) =
(`E_eps_del1_pp`, `E_2del1_m`) end-to-end with the issue's δf convention:
δf = −[Y, f(X)] − f([X,Y]) = gb_p_1_m·(2H_1 + K) = γ(X,Y) ✓.

#### Implementation and results

`src/C_coboundary.py` computes (δf)(X,Y) =
`(−1)^{p(X)}[X,f(Y)] − (−1)^{(p(X)+1)p(Y)}[Y,f(X)] − f([X,Y])`
for all ordered pairs, purely from the Schema 1 structure constants
(brackets with K are zero), at gb = all +1 (matching Schema 3).

```
C(2): f has 16 entries, 108 nonzero coboundary records -> data/C_1_coboundary.json
C(3): f has 48 entries, 536 records -> data/C_2_coboundary.json
C(4): f has 96 entries, 1476 records -> data/C_3_coboundary.json
```

#### Layer 1 consistency (criterion 3)

Asserted at generation time for every record: X, Y, Z are Schema 1 basis
labels (or Z = K); parity rule p(Z) = p(X)+p(Y)+1 holds for every δf term;
and f itself is parity-reversing on every f_map entry. All assertions pass
for n = 1, 2, 3. Tests in `tests/test_C_coboundary.py` (determinism, odd-map
property, zero-gb ⇒ zero coboundary). Full suite: **40 passed**.

**Preview (full analysis in I08)**: the Layer 4 coboundary records coincide
*exactly* (same record count, zero mismatches) with the Layer 3 evaluated
deformation for all three ranks.
