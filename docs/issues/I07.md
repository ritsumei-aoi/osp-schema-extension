#### Decisions and Results

**Implementation**: Created `src/C_coboundary.py` implementing:
- `compute_coboundary_entry(x, y, f_matrix, bracket_lookup, parity_map)`: Computes (δf)(X,Y) = (-1)^{p(X)}[X,f(Y)] - (-1)^{(p(X)+1)p(Y)}[Y,f(X)] - f([X,Y]) for a given odd linear map f.
- `compute_coboundary_symbolic(n, structure_data)`: Computes symbolic coboundary coefficients for each pair (X,Y) and each phi parameter, using unit maps f that send one generator to another.

**Parameterization**: The odd linear map f reverses parity. For C(n+1) with dim_even = 2n²+n+1 and dim_odd = 4n, the total number of phi parameters is 2 × dim_even × dim_odd.

| n | dim_even | dim_odd | phi params | coboundary entries |
|---|---|---|---|---|
| 1 | 4 | 4 | 32 | 184 |
| 2 | 11 | 8 | 176 | 2276 |
| 3 | 22 | 12 | 528 | 10384 |

**Generated data**: `data/C_{n}_coboundary.json` for n=1,2,3.

**Consistency**: All generators in coboundary entries are valid Layer 1 basis elements (verified for all three cases).
