#### 1. The odd linear map f
Generic: f(Z_j) = Σ_i φ[Z_i|Z_j] Z_i with p(Z_i) ≠ p(Z_j) (2·even·odd unknowns: 32 / 176 / 528 for n=1/2/3),
plus optionally φ[K|Z_j] for odd Z_j (component along the central K = 1; 4n unknowns), because Layer 2 showed γ has K components.

**Sign convention derivation** (κ on the left, κ odd central, κ²=0): for X' = X + κF(X),
[X, κF(Y)] = (−1)^{p(X)} κ[X,F(Y)] and [κF(X), Y] = −(−1)^{(p(X)+1)p(Y)} κ[Y,F(X)], so the requirement
[X',Y']_γ = ([X,Y]_0)' is exactly γ = −δF with the δ of `C_coboundary_definition.md`. Hence γ is trivial iff γ = δf for some odd f (f = −F).
Consistency of the formula is tested: for every odd ξ, δ(ad ξ) = 0 (`test_inner_odd_derivation_is_cocycle`).

**Reference map f_gb** (one explicit candidate, linear in gb): the odd shift of the fermions
a'^σ = a^σ + κ Σ_j (gb_{σ,j,−} b_j⁺ − gb_{σ,j,+} b_j⁻).
By hand: [b_j⁻, a'^σ] = −gb_{σ,j,−}κ + gb_{σ,j,−}κ = 0, [b_j⁺, a'^σ] = −gb_{σ,j,+}κ + gb_{σ,j,+}κ = 0,
{a'⁻, a'⁺} = 1 and (a'^±)² = 0 (cross terms are κ·[b,a] ∝ κ² = 0). So X(a',b) obey the undeformed brackets;
F(X) := κ-part of X(a',b) − X(a,b) is computed by the oscillator engine, f_gb := −F. Example (n=1):
f_gb(H_1) = gb_m_1_m E_pp − gb_m_1_p E_pm − gb_p_1_m E_mp + gb_p_1_p E_mm (E_σs = E_eps1_del1_σs);
f_gb(E_eps1_del1_pp) = −gb_p_1_p H_2 − 2 gb_p_1_m E_2del1_p + ½ gb_p_1_p K.
