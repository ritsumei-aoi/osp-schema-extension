### Response

**Implementation: `src/C_coboundary.py`**

**Coboundary formula:**
$$(\delta f)(X, Y) = (-1)^{p(X)}[X, f(Y)] - (-1)^{(p(X)+1)p(Y)}[Y, f(X)] - f([X,Y])$$

**Canonical odd linear map f (chosen):** $f(E_\text{odd}) = 1 \cdot H_1$ for all odd generators, $f(E_\text{even}) = 0$.

This map is odd (maps odd → even) and uses the simplest non-trivial parameterization (all $\phi_k = 1$ mapping to $H_1$).
