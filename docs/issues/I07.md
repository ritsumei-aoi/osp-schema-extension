### Response

**Decisions**
- **Odd map parameterization**: $f=\sum_{ij}\phi_{ij}f_{ij}$, where $f_{ij}$ sends $Z_j\mapsto Z_i$ and kills the other basis elements. Only pairs with $p(Z_i)\neq p(Z_j)$ are included, so each $f_{ij}$ is odd. This matches the parameterization in `docs/math/C_coboundary_definition.md`, §3.
- **Bracket for δ**: the undeformed Schema 1 bracket, read from `data/C_{n}_structure.json` (Layer 1), not from the generator code. The file stores one orientation per pair, so the reversed orientation comes from graded antisymmetry.
- **Formula**: $(\delta f)(X,Y) = (-1)^{p(X)}[X,f(Y)] - (-1)^{(p(X)+1)p(Y)}[Y,f(X)] - f([X,Y])$, implemented term by term. Terms 1 and 2 are nonzero only when the argument of $f$ is $Z_j$; term 3 uses the bracket coefficient of $Z_j$ in $[X,Y]$.
- **Layer 4 content**: the basis coboundaries $\{\delta f_{ij}\}$, one per parameter, stored as sparse entries (only nonzero coefficients). The general coboundary is $\sum\phi_{ij}\,\delta f_{ij}$, so the space is spanned by these entries (I08 will use this).
- **Not stored**: a Gram-type or rank computation. The span is left for I08, where the question is actually asked.

**Results**
- Parameter counts (= $2\cdot\#\text{even}\cdot\#\text{odd}$): 32, 176, 528 for n=1,2,3.
- Parity: every coboundary coefficient has parity $p(X)+p(Y)+1$, the same parity as γ. The check is an assert in `to_json` and passes for all n.
- Files: `data/C_1_coboundary.json` (43 KB), `C_2_coboundary.json` (434 KB), `C_3_coboundary.json` (1.9 MB).

**Hand-checked value** (test `test_known_value_n1`): for $f: E_{2\delta_1}^+\mapsto E_{\varepsilon-\delta_1}^{pm}$ and $X=H_1$, $Y=E_{2\delta_1}^+$, the formula gives $[H_1,E^{pm}] - f(2E_{2\delta_1}^+) = -E^{pm} - 2E^{pm} = -3E^{pm}$. The program returns $-3$.

**Tests**: `tests/test_C_coboundary.py`: parameter counts, parity on a sample, the hand-checked value, and file equals a fresh run. `python3 -m pytest -q` gives **52 passed**.
