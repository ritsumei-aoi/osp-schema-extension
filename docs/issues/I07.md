#### Definition of f
$f(Z_j) = \sum_{i:\,p(Z_i)=p(Z_j)+1} \phi[Z_i,Z_j]\,Z_i \;+\; \phi[K,Z_j]\,K$ (the $K$-term only for odd $Z_j$, since $K$ is even and $f$ is odd).
Unknowns: even→odd $e\cdot o$, odd→even $o\cdot e$, odd→K $o$; total 36 (n=1), 184 (n=2), 540 (n=3).

**Decision on the K-component** (No-Gate). Options: (a) $f:\mathfrak g\to\mathfrak g$ only, as literally written in `C_coboundary_definition.md`; (b) $f:\mathfrak g\to\mathfrak g\oplus\mathbb{C}K$. Schema 2 showed that γ has genuine $K$ components, and the triviality definition says "up to scalar". I chose (b) in the data: the `phi[K,*]` unknowns are included and clearly labelled, so I08 can analyse both the strict reading (set them to 0) and the "up to scalar" reading without regenerating Layer 4.

#### Coboundary
$(\delta f)(X,Y) = (-1)^{p(X)}[X,f(Y)] - (-1)^{(p(X)+1)p(Y)}[Y,f(X)] - f([X,Y])$, computed from the Schema 1 JSON as exact linear forms in φ (`src/C_coboundary.py`). Stored for PBW-ordered pairs $X\le Y$ in `data/C_{n}_coboundary.json` (format: spec §5).
