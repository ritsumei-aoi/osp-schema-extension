### Response

#### 1. Choice of the odd linear map $f$ — options considered
* (a) A generic $f$ with free coefficients $\phi_{ij}$ (all parity-reversing entries). Implemented as
  the general routine `coboundary(labels, parity, table, f)` (used by I08's linear solver), but a
  generic $f$ is not a useful *reference* structure by itself.
* (b) $f$ supported on a single generator (e.g. $f(E_{\varepsilon+\delta_1})=H_1$). Rejected as the
  main deliverable: it gives a coboundary but one unrelated to the deformation.
* (c) **Chosen: the shift map.** The deformed relation $[b_j^s,a_1^\sigma]=-\mathrm{gb}_{\sigma,j,s}\kappa$
  is undone by the oscillator substitution
  $\psi(b_j^s)=b_j^s+\kappa(\mathrm{gb}_{-,j,s}a_1^+ + \mathrm{gb}_{+,j,s}a_1^-)$, $\psi(a_1^\pm)=a_1^\pm$
  (one checks $[\psi(b_j^s),a_1^\sigma]_{\rm gb}=-\mathrm{gb}_{\sigma,j,s}\kappa+\kappa\,\mathrm{gb}_{\sigma,j,s}=0$,
  $[\psi b,\psi b']=[b,b']$ since $\kappa^2=0$). On generators $\psi(X)=X+\kappa f_0(X)$, and
  $f:=\mathrm{SIGN}\cdot f_0$ with SIGN fixed by the computation. $f$ is odd and takes values in
  $\mathfrak g\oplus\mathbb{C}K$ (constant components appear exactly as in γ).

Explicit $f$ for n=1 (from `data/C_1_coboundary.json`), with $N_a=H_1+H_2$:
$f(E_{\pm\varepsilon+ s\delta_1}) = \pm\mathrm{gb}_{\pm,1,s}(H_1+H_2) + \tfrac12\mathrm{gb}_{\pm,1,s}K$,
$f(H_1)=-(\mathrm{gb}_{-,1,-}E_{\varepsilon+\delta_1}+\mathrm{gb}_{-,1,+}E_{\varepsilon-\delta_1}+\mathrm{gb}_{+,1,-}E_{-\varepsilon+\delta_1}+\mathrm{gb}_{+,1,+}E_{-\varepsilon-\delta_1})$,
$f(H_2)=-f(H_1)$, $f(E_{2\delta_1})=-2(\mathrm{gb}_{-,1,+}E_{\varepsilon+\delta_1}+\mathrm{gb}_{+,1,+}E_{-\varepsilon+\delta_1})$,
$f(E_{-2\delta_1})=-2(\mathrm{gb}_{-,1,-}E_{\varepsilon-\delta_1}+\mathrm{gb}_{+,1,-}E_{-\varepsilon-\delta_1})$.

#### 2. Coboundary coefficients
`src/C_coboundary.py::coboundary` implements
$(\delta f)(X,Y)=(-1)^{p(X)}[X,f(Y)]-(-1)^{(p(X)+1)p(Y)}[Y,f(X)]-f([X,Y])$ with the Layer 1
brackets, $[\cdot,K]=0$, $f(K)=0$, for all ordered pairs. Result: **with SIGN = −1, $\delta f=\gamma$
exactly (symbolically in gb, all pairs, all $Z$ including $K$) for n=1,2,3.** With SIGN = +1 it is
$-\gamma$, consistent with the derivation $\gamma=-\delta f_0$ from $\psi([X,Y]_0)=[\psi X,\psi Y]_\gamma$.
Ambiguity recorded: the math note says "equal … up to scalar"; the scalar is $-1$ for $f_0$, absorbed
into the definition of $f$.
