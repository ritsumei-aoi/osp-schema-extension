### Response

**Design decision on f.** The issue says "define the odd linear map f". A *single* fixed f would only
probe one coboundary; since I07 feeds the triviality search (I08), I instead define f as the **general
odd (parity-reversing) linear map** carrying symbolic coefficients $\phi$:
$$ f(Z_{\rm src}) = \sum_{\rm tgt} \phi_{\rm src\to tgt}\, Z_{\rm tgt}, $$
where `tgt` ranges over the opposite-parity basis (and the central $K$ is allowed as a target of odd
sources; $f(K)=0$). This is strictly more informative — any concrete f is a substitution of the
$\phi$ — and makes $\delta f$ a $\phi$-linear object directly comparable with the gb-linear $\gamma$
in I08.

**Coboundary computation (`src/C_coboundary.py`).** Implements exactly
$(\delta f)(X,Y)=(-1)^{p(X)}[X,f(Y)]-(-1)^{(p(X)+1)p(Y)}[Y,f(X)]-f([X,Y])$
with the undeformed bracket from I03 (cached `base.bracket`), extended linearly over $f$'s symbolic
image. $\delta f$ lands on the Layer-1 basis $\cup\{K\}$ by construction (every bracket/`f` output is
decomposed onto that basis), satisfying the "consistent with Layer 1 basis" criterion.

**Outputs.**
- `data/C_1_coboundary.json` — 36 $\phi$ params, 120 $\delta f$ records.
- `data/C_2_coboundary.json` — 184 $\phi$ params, 1432 records.
- `data/C_3_coboundary.json` — 540 $\phi$ params, 7114 records.

Each file stores the $f$ parameterization (`f_map`), the coboundary formula, and the nonzero
$\delta f$ coefficients (as $\phi$-linear strings) for every PBW pair $X\le Y$.

**Tests.** `tests/test_C_layers34.py::test_coboundary_present` (odd parity, `delta_f` present) plus
full suite: 42 passed. All completion criteria met.
