#### 1. Definition of the odd linear map $f$ (Requirement 1)
Options considered:
* **(a) Generic symbolic $f$** with $2\cdot\dim_{\bar0}\cdot\dim_{\bar1}$ unknowns $\phi_{ij}$
  and Schema 4 = the full matrix of $\delta$ on odd 1-cochains. Complete but ~5 MB for
  n = 3 and not directly comparable with Layer 3.
* **(b) A specific reference map derived from the deformation itself.**
* **(c) An ad-hoc map** (e.g. $f = \mathrm{ad}_Z$ for an odd $Z$, which is a cocycle,
  $\delta f = 0$) — would carry no information about γ.

**Chosen: (b), with (a) kept available in code.** Schema 4 stores the parameterisation
(`phi_<i>_<j>`, `phiK_<j>`, counts), the explicit reference map `f_can` for the same gb
assignment as the Layer 3 file (`f_matrix`, `values`), and its coboundary. The general
solve over all $\phi_{ij}$ is done in I08 with the same `delta_f` routine (no need to store
the operator matrix).

**Derivation of `f_can`.** With $[b_k^s, a_1^σ] = -\mathrm{gb}_{σ,k,s}\kappa$, set
$c^σ = \sum_k(\mathrm{gb}_{σ,k,-}b_k^+ - \mathrm{gb}_{σ,k,+}b_k^-)$ and $\tilde a^σ = a^σ - \kappa c^σ$.
Then $[b_k^s,\tilde a^σ] = -\mathrm{gb}_{σ,k,s}\kappa - \kappa[b_k^s, c^σ] = 0$ (using
$[b_k^-,b_k^+]=1$), $\{\tilde a^-,\tilde a^+\} = 1$ and $(\tilde a^σ)^2 = 0$ (all corrections
carry $\kappa^2 = 0$). Hence the shifted oscillators obey the undeformed relations. Writing
each generator as $X(\tilde a, b) = X(a,b) + \kappa f_{\rm can}(X)$ and expanding
$[X(\tilde a,b), Y(\tilde a,b)]$ in two ways (undeformed computation vs. deformed bracket of
$X + \kappa f(X)$, using $[X,\kappa W] = (-1)^{p(X)}\kappa[X,W]$ and $[\kappa W,Y] = \kappa[W,Y]$)
gives **$\gamma(X,Y) = (\delta f_{\rm can})(X,Y)$** with exactly the formula of
`C_coboundary_definition.md`. Closed form: $f_{\rm can}(a_1^σ b_k^u) = -c^σ b_k^u$ (normal
ordered, so $b_k^-b_k^+ = b_k^+b_k^- + 1$ produces a $K$-component),
$f_{\rm can}(H_1) = a_1^+c^- - c^+a_1^-$, and $f_{\rm can} = 0$ on the $\mathfrak{sp}(2n)$ sector.
Example (n = 1): $f_{\rm can}(E_{\varepsilon+\delta_1}) = -\mathrm{gb}_{a^+b^-}E_{2\delta_1} - \mathrm{gb}_{a^+b^+}H_2 + \tfrac12\mathrm{gb}_{a^+b^+}K$,
$f_{\rm can}(H_1) = \mathrm{gb}_{a^-b^-}E_{\varepsilon+\delta_1} - \mathrm{gb}_{a^-b^+}E_{\varepsilon-\delta_1} - \mathrm{gb}_{a^+b^-}E_{-\varepsilon+\delta_1} + \mathrm{gb}_{a^+b^+}E_{-\varepsilon-\delta_1}$.
`f_can` is not typed in: the script substitutes $\tilde a$ into the realizations, normal
orders, extracts the κ-coefficient and decomposes it (asserting that the κ⁰ part reproduces
the original generator). Note that $f_{\rm can}$ necessarily has $K$-components on odd
generators ($4n$ of them), which is where the $K$-components of γ (I05) come from.

#### 2. Coboundary coefficients (Requirement 2)
$(\delta f)(X,Y) = (-1)^{p(X)}[X,f(Y)] - (-1)^{(p(X)+1)p(Y)}[Y,f(X)] - f([X,Y])$, with
$[X,K]=0$, evaluated for all ordered pairs from the Schema 1 table (exact rationals).
