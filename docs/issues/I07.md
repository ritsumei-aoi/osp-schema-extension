### Response

**Decisions**
- **Odd linear map f, symbolic (choice made).** I parameterise f(Z_j) = Σ_i φ_{i,j} Z_i over all pairs with p(Z_i) ≠ p(Z_j), so f is odd by construction. Options considered: (a) one fixed representative f (e.g. a pairing of even with odd generators); (b) the full symbolic parameter family (chosen); (c) a random f. Reason for (b): I08 asks for the conditions under which γ is a coboundary, so the answer has to depend on the free parameters. A single representative f would hide them. (a) is still available by setting φ values in I08.
- Brackets are read from `data/C_{n}_structure.json` via `src/verify_C_structure.py`, so δf is computed from the stored Schema 1 data, not from generator code.
- δf is stored for X ≤ Y in PBW order. Graded symmetry is checked for X < Y.
- Symbol names: `phi_{i}_{j}`, with 1-based PBW positions i, j. The map section lists each symbol with its labels (i, j).
