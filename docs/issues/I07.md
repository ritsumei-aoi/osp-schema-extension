### Response

#### Odd Linear Map f

The map f: g → g is odd (parity-reversing), parameterized by phi_{i,j} coefficients:

  f(Z_j) = sum_i phi_{i,j} * Z_i,  where p(Z_i) ≠ p(Z_j)

For C(n+1) with dim_even = 2n²+n+1 and dim_odd = 4n:
- f(even generator) → linear combination of odd generators
- f(odd generator) → linear combination of even generators

Number of phi parameters:
- C_1 (n=1): dim_even=4, dim_odd=4 → 4*4 + 4*4 = 32 phi params
- C_2 (n=2): dim_even=11, dim_odd=8 → 11*8 + 8*11 = 176 phi params
- C_3 (n=3): dim_even=22, dim_odd=12 → 22*12 + 12*22 = 528 phi params

Basis ordering: odd generators first (PBW), then even, matching Schema 1.

#### Coboundary Formula

  (δf)(X,Y) = (-1)^{p(X)} [X, f(Y)] - (-1)^{(p(X)+1)p(Y)} [Y, f(X)] - f([X,Y])

Implementation in `src/C_coboundary.py`:
- Term 1: sign1 = (-1)^{p(X)}, brackets X with each possible f(Y) image
- Term 2: sign2 = -(-1)^{(p(X)+1)p(Y)}, brackets Y with each possible f(X) image
- Term 3: f applied to [X,Y] using Schema 1 structure constants
- Each term produces symbolic coefficients times phi_{i,j} parameters
- Results consolidated by (X,Y,Z,phi_param) key before output

Pairs computed: only (X,Y) with yi >= xi (anti-symmetry of delta f follows from anti-symmetry of structure constants).

#### Results

```
C_1 (n=1): 202 coboundary entries (phi parameters from 32 phi vars)
C_2 (n=2): 2460 coboundary entries (phi parameters from 176 phi vars)
C_3 (n=3): 11218 coboundary entries (phi parameters from 528 phi vars)
```

All Z generators in coboundary entries reference valid Schema 1 basis elements (both even and odd), verified by the structure constant basis used in computation.

The coboundary entries are structured as {X, Y, Z, phi_param, coeff} where:
- X, Y: source pair of generators
- Z: target generator (output of δf(X,Y))
- phi_param: phi_{i,j} parameter appearing in the coefficient
- coeff: rational coefficient (Fraction)
