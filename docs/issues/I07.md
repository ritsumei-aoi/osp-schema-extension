#### Implementation

Implemented `src/C_coboundary.py` which:
1. Parameterizes f as `f(Z_j) = sum_i phi_{Zi,Zj} Z_i`, with phi_{ij} nonzero only when p(Zi) != p(Zj) (odd map condition).
2. Computes `(δf)(X,Y)` using the formula from `C_coboundary_definition.md`:
   `(δf)(X,Y) = (-1)^{p(X)} [X, f(Y)] - (-1)^{(p(X)+1)*p(Y)} [Y, f(X)] - f([X,Y])`
3. Each coboundary entry is expressed symbolically as a linear combination of phi parameters.

**Sample entry (n=1)**: `(δf)(E_eps_del1_pp, E_eps_del1_pp) → E_eps_del1_pp: 4·phi_{H_1,E_eps_del1_pp} - 2·phi_{H_2,E_eps_del1_pp}`.

This is correct: `(δf)(X,X) = 2·(-1)^{p(X)} [X, f(X)] - f(0) = 2(-1)^{1} [E_eps_del1_pp, phi·H_k + ...] + ...`.

#### Parity Check

For each entry (X,Y,Z) in the coboundary, verified that `p(Z) = (p(X)+p(Y)+1) mod 2` (since δf shifts parity by 1 relative to the bracket). All entries pass.
