### Response

**Definition of f** (`src/C_coboundary.py`): `f_c` = odd derivation of the oscillator algebra induced by the shift `a_1^sigma -> a_1^sigma + kappa * l^sigma`, `l^sigma = sum_{j,s} c[sigma,j,s] b_j^s` (4n parameters `f_a_1_{sigma}_b_{j}_{s}`). On basis elements `f(Z_j) = sum_i phi_ij Z_i` with phi linear in c; it reverses parity (a-letters are replaced by b-letters). Images are computed exactly and decomposed in `g (+) C K`: oscillator re-ordering produces a constant (K) component for odd sources, e.g. for n=1 `f(E_eps1_del1_pp) = c[p,1,m] (-H_2 + 1/2 K)`.

Options considered for f: (a) generic phi_ij (2*E*O unknowns, 528 for n=3), used in I08 as the *search space*; (b) a structured family induced by oscillator redefinition (chosen for Layer 4: a definite, small reference family that arises from redefining the oscillators).

**Coboundary**: `(delta f)(X,Y)` computed with the formula of `C_coboundary_definition.md` (signs exactly as stated) using Schema 1 structure constants; K-components of f enter only via `-f([X,Y])` since `[X,K]=0`.

**Key result** (exact, all pairs and all Z incl. K): `delta f_c = gamma(gb)` with `gb_{sigma,j,p} = c_{sigma,j,m}`, `gb_{sigma,j,m} = -c_{sigma,j,p}`; each unit delta f is +-(one unit gamma). Stored in `gb_correspondence`. So the odd-derivation family realizes every gb, provided the K-component of f is allowed (see I08 for the discussion of the K issue).
