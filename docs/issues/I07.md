### Response

**Implementation (2026-10-08, no-gate)**

Files: `src/C_coboundary.py` (class `CoboundaryOperator`, Schema 4 writer, loader, evaluator),
`data/C_{1,2,3}_coboundary.json`, `tests/test_C_coboundary.py`, `docs/json_schema_specification.md` §8.

**1. Definition of f.** f is the *general* odd linear map, parameterized by φ:
`f(Z_j) = Σ_i phi__{Z_i}__{Z_j} Z_i` over all pairs with p(Z_i) = p(Z_j) + 1. Decision recorded
(ai_trust_policy): the target of f is g~ = g ⊕ CK, i.e. for odd Z_j the central identity K is an allowed
target. Options: (a) f: g → g literally as in `C_coboundary_definition.md`; (b) f: g → g ⊕ CK.
Chose (b) because γ (I05) has K-components, so a K-valued part of f is needed for γ = δf to be solvable
at all; option (a) is recovered by setting the 4n `phi__K__*` parameters to zero and is analysed as a
separate variant in I08. Parameter counts: 36 / 184 / 540 for n = 1 / 2 / 3.

**2. Coboundary.** Implemented exactly as in `C_coboundary_definition.md`:
`(δf)(X,Y) = (-1)^{p(X)} [X, f(Y)] - (-1)^{(p(X)+1)p(Y)} [Y, f(X)] - f([X,Y])`, using the Schema 1 brackets
with exact `Fraction` arithmetic and `[X, K] = 0`. Every component is stored as a linear form in φ.
Sign check: for the change of basis X' = X + κ f(X) in g~ ⊕ κ g~ (κ super-central) one finds
[X', Y'] = [X,Y]_0 + κ(δf(X,Y) + f([X,Y]_0)) = ([X,Y]_0)' + κ (δf)(X,Y), i.e. the undeformed algebra
written in the primed basis looks like the deformation γ = +δf, while trivializing a given γ by X ↦ X + κ f(X)
requires γ = −δf. Both say the same thing: γ is trivial iff γ ∈ image(δ) (sign-independent, replace f by −f).
The stored convention follows the document verbatim; the `triviality_criterion` field documents the sign.

**3. Consistency with the Layer 1 basis (tests, all pass).** Entries use Layer 1 labels (or K), parity
p(Z) = p(X)+p(Y)+1, δf is graded antisymmetric, and — the decisive check — δf is a 2-cocycle: deforming
g~ ⊕ κ g~ by γ := δf at random rational φ satisfies super Jacobi for n = 1, 2, 3. A hand-computed value
is also asserted: (δf)(E_eps1_del1_pp, E_eps1_del1_pp) = (4 φ_{H_1} − 2 φ_{H_2}) E_eps1_del1_pp + 4 φ_{E_2del1_m} E_eps1_del1_pm.
