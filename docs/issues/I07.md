#### 2. Decision: the target of $f$ is $\tilde{\mathfrak g} = \mathfrak g \oplus \mathbb C K$

`docs/math/C_coboundary_definition.md` §1 writes $f:\mathfrak g\to\mathfrak g$
and parameterises it by $f(Z_j)=\sum_i\phi_{ij}Z_i$ over "the basis $\{Z_i\}$
of $\mathfrak g$". I05 showed that $\gamma$ has non-zero $K$-components. Options:

- **(a)** Keep $f:\mathfrak g\to\mathfrak g$ strictly. Then $(\delta f)|_K \equiv 0$
  (brackets of $\mathfrak g$ never produce $K$ — verified in I04), so $\delta f$
  could never equal $\gamma$ and *every* non-zero deformation would be declared
  non-trivial, for a purely bookkeeping reason.
- **(b)** Drop the $K$-components of $\gamma$ ("work modulo $K$"). Rejected:
  that is changing the object being tested, and the $K$-part is not removable by
  any choice of Cartan normalization (§7).
- **(c) Chosen** — take $\{Z_i\}$ to be the basis of the central extension
  $\tilde{\mathfrak g} = \mathfrak g \oplus \mathbb C K$, i.e. $f:\mathfrak g\to
  \tilde{\mathfrak g}$, with $f(K) := 0$.

**Reason.** `C_inhomogeneous_definition.md` constructs the entire setting inside
$A = V \oplus \mathbb C K \oplus \mathbb C\kappa$, so $K$ is part of the ambient
object from the start; $\gamma$ lands in $\tilde{\mathfrak g}$, and a coboundary
operator whose target is smaller than its source's is not a meaningful test.
Since $K$ is central, $[X,f(Y)]$ is unaffected by the $K$-component of $f$; $K$
enters $\delta f$ only through $-f([X,Y])$, i.e. exactly on pairs whose bracket
has an odd component — which is precisely the support of $\gamma|_K$. The
supports match, which is strong evidence that (c) is the intended reading.

**This decision is load-bearing and was tested, not assumed.** The generator
re-runs the whole comparison with the $K$-components of $f$ deleted and reports
the damage: `K_target_is_necessary: true`, with 12 / 40 / 84 pairs failing for
n = 1 / 2 / 3 — exactly the pairs carrying a $K$-component. Under option (a)
the answer to I08 would have been "never trivial"; under (c) it is "always
trivial". Readers who prefer (a) can read the result as: *γ is trivial modulo
the central 2-cocycle $\gamma|_K$, which is itself the coboundary of the
$K$-valued part of $f$.*

#### 3. Decision: construct $f$ analytically, then verify — rather than solve a linear system

Options for producing $f$:

- **(a)** Set up $\gamma = \delta f$ as a linear system in the $\phi_{ij}$ and
  solve numerically for each gb profile.
- **(b) Chosen** — derive $f$ in closed form from an automorphism of the
  oscillator algebra, then verify $\delta f = \gamma$ symbolically.

**Derivation.** The deformation only changes one relation,
$[b_k^s, a_1^\sigma] = -\mathrm{gb}_{\sigma,k,s}\kappa$. Substitute

$$a_1^\sigma \longmapsto \tilde a_1^\sigma = a_1^\sigma + \kappa\,u_\sigma,
\qquad
u_\sigma = \sum_{j=1}^{n}\bigl(-\mathrm{gb}_{\sigma,j,-}\,b_j^+
+ \mathrm{gb}_{\sigma,j,+}\,b_j^-\bigr),
\qquad b_k^s \longmapsto b_k^s .$$

Then, using $[b_k^+, b_k^-] = -1$ and $[b_k^-, b_k^+] = +1$,

$$[\,b_k^s, \tilde a_1^\sigma\,] = \kappa\,[b_k^s, u_\sigma]
= -\,\mathrm{gb}_{\sigma,k,s}\,\kappa ,$$

which is exactly the deformed relation. The substitution also preserves the CAR
($\{\tilde a^-,\tilde a^+\}=1$, $(\tilde a^\pm)^2=0$, since all corrections are
$O(\kappa^2)=0$), so it is an **isomorphism** of the deformed onto the
undeformed extension. Writing $\tilde X = X + \kappa f(X)$ for each basis
generator $X$ defines $f$, which is automatically parity-reversing: $f$ kills
purely bosonic generators and swaps the fermion count by one.

(b) was preferred because it yields a *closed-form, all-$n$, all-gb* answer with
an intelligible mechanism, instead of 21 separate numerical solves. The linear
system of option (a) is still solved in I08, to settle **uniqueness** and to
confirm the analytic answer by an independent route.

#### 4. Sign convention (correction recorded)

The paper derivation predicted $\gamma = \delta(-f_{\rm nat})$ under the sign
conventions of `C_coboundary_definition.md`. The first run gave
$\delta f = -\gamma$ uniformly (every mismatch was exactly $-2\gamma$),
identifying a sign slip in the hand conversion between
$[f(Y),X]$ and $[X,f(Y)]$. The code now uses $f = f_{\rm nat}$ directly, giving
$\delta f = \gamma$ exactly. The convention is recorded in the JSON
(`f_map.construction`) so the result is reproducible. No other quantity was
affected; the `delta f` formula itself is implemented verbatim from the source
document.

#### 5. The explicit map (n = 1, complete)

```
f(E_eps1_del1_pp) = gbPP·H_del1 − gbPM·E_2del1_p + (gbPP/2)·K
f(E_eps1_del1_pm) = −gbPM·H_del1 + gbPP·E_2del1_m + (gbPM/2)·K
f(E_eps1_del1_mp) = gbMP·H_del1 − gbMM·E_2del1_p + (gbMP/2)·K
f(E_eps1_del1_mm) = −gbMM·H_del1 + gbMP·E_2del1_m + (gbMM/2)·K
f(H_eps1)         = gbMM·E_eps1_del1_pp − gbMP·E_eps1_del1_pm
                    − gbPM·E_eps1_del1_mp + gbPP·E_eps1_del1_mm
f(Z) = 0  for every purely bosonic even Z  (H_del1, E_2del1_p, E_2del1_m)
```
(`gbSB` = `gb_a1S_b1B`.) The general-$n$ pattern, visible in
`data/C_2_coboundary.json`, is $f(a_1^\sigma b_k^s) = u_\sigma b_k^s$ and
$f(a_1^+a_1^- - \tfrac12) = -a_1^+u_- + u_+a_1^-$, each re-expressed in the
basis; the $K$-terms come from normal-ordering $b_k^-b_k^+ = b_k^+b_k^- + 1$.

**Support of $f$**: exactly $4n+1$ non-zero sources — the $4n$ odd generators
plus `H_eps1`. $f$ annihilates all $2n^2+n$ purely bosonic even generators,
because the substitution touches only the fermionic letters. Tested.
