#### 1. Definition of the odd linear map $f$ (Requirement 1)

Two levels are provided in `src/C_coboundary.py`, both expressed in the Layer 1 basis $\{Z_i\}$ (`pbw_order`):

* **General parameterization**: $f(Z_j) = \sum_i \phi_{ij} Z_i$ with $p(Z_i) = p(Z_j)+1$. The elementary odd maps $f_{ij}: Z_j \mapsto Z_i$ (all others $\mapsto 0$) form a basis of the space of odd maps; labels `phi[Z_i][Z_j]`. Since $\gamma$ (I05) has scalar components, the target $Z_i = K$ is additionally allowed for odd $Z_j$ (`count` vs `count_without_K_targets`): 36/32 (n=1), 184/176 (n=2), 540/528 (n=3).
* **Explicit candidate map $f_{\rm shift}$**: the deformed relation $[b_k^s, a_1^\sigma] = -\mathrm{gb}\,\kappa$ is undone by the change of oscillator variables $\tilde b_k^s = b_k^s - \kappa\sum_\tau \mathrm{gb}_{a_1^{-\tau},b_k^s}\,a_1^\tau$ (hand derivation: $[\kappa a_1^\tau, a_1^\sigma] = \kappa\{a_1^\tau,a_1^\sigma\} = \kappa\delta_{\tau,-\sigma}$, and CCR/CAR are preserved because $\kappa^2=0$ and $\kappa$ is central). Writing $X(\tilde b, a) = X(b,a) + \kappa f_{\rm shift}(X)$ defines an odd map $f_{\rm shift}:\mathfrak g\to\mathfrak g\oplus\mathbb CK$, linear in gb. Example (n=1): $f(E_{\varepsilon+\delta_1}) = \mathrm{gb}_{a_1^+b_1^+}\,a_1^+a_1^- = \mathrm{gb}_{a_1^+b_1^+}(H_1+H_2+\tfrac12 K)$, $f(E_{2\delta_1}) = -2\mathrm{gb}_{a_1^-b_1^+}E_{\varepsilon+\delta_1} - 2\mathrm{gb}_{a_1^+b_1^+}E_{-\varepsilon+\delta_1}$, $f(H_1) = -\sum \mathrm{gb}_{a_1^{-\sigma}b_1^{-s}}E_{\sigma\varepsilon+s\delta_1}$. In general $f_{\rm shift}(E_{\sigma\varepsilon+s\delta_k}) = \mathrm{gb}_{a_1^\sigma b_k^s}\,a_1^\sigma a_1^{-\sigma} = \mathrm{gb}_{a_1^\sigma b_k^s}(\sigma J + \tfrac12 K)$, so the only $K$-components are $\tfrac12\mathrm{gb}_{a_1^\sigma b_k^s}$ on the odd generators (asserted in the tests).

#### 2. Coboundary coefficients (Requirement 2)
`coboundary(sc, par, f, X, Y)` implements $(\delta f)(X,Y) = (-1)^{p(X)}[X,f(Y)\} - (-1)^{(p(X)+1)p(Y)}[Y,f(X)\} - f([X,Y\})$ **using only the Schema 1 structure constants** ($[X,K\}=0$ for scalar components). It is applied to (a) every elementary map (pairs with index$(X)\le$ index$(Y)$ stored; the rest follows from graded antisymmetry) and (b) $f_{\rm shift}$ per gb parameter (all ordered pairs, linear forms in gb).
