#### Implementation

**Script**: `src/C_coboundary.py` — computes the coboundary operator δf symbolically.

**Coboundary formula** (from `docs/math/C_coboundary_definition.md`):
$$(\delta f)(X, Y) = (-1)^{p(X)}[X, f(Y)] - (-1)^{(p(X)+1)p(Y)}[Y, f(X)] - f([X, Y])$$

**Map f parametrization**: $f(Z_j) = \sum_i \phi_{ij} Z_i$ where $p(Z_i) \neq p(Z_j)$ (f reverses parity). Labels: `phi_{src}_{tgt}`.

**Algorithm**: For each pair (gx, gy) and each phi parameter:
1. Term 1: $(-1)^{p(X)}$ times [gx, gtgt] when the phi parameter is φ_{gy, gtgt}
2. Term 2: $-(-1)^{(p(X)+1)p(Y)}$ times [gy, gtgt] when the phi parameter is φ_{gx, gtgt}
3. Term 3: $-$ gtgt when the phi parameter is φ_{gk, gtgt} and gk appears in [gx, gy]

All brackets are precomputed using the Schema 1 structure constants.

**Parity check**: For (X, Y) with p(X)=0, p(Y)=0: target parity = 1 (odd generators). For (X,Y) with p(X)=0, p(Y)=1: target parity = 0 (even generators). Verified in output samples. ✓
