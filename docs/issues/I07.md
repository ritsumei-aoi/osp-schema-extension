### Response

**Decisions and Results**

#### Implementation

`src/C_coboundary.py` computes the symbolic coboundary $(\delta f)(X,Y)$ using:

$$(\delta f)(X,Y) = (-1)^{p(X)}[X, f(Y)] - (-1)^{(p(X)+1)p(Y)}[Y, f(X)] - f([X,Y])$$

The odd linear map $f$ is parameterized by $\phi_{Z,X}$ coefficients where $f(X) = \sum_Z \phi_{Z,X} Z$ with $p(Z) = 1 - p(X)$.

Each coboundary entry records $\{X, Y, Z, \phi\_param, coeff\}$, meaning the contribution of $\phi\_param$ to the $Z$-component of $(\delta f)(X,Y)$.

The number of φ parameters is $\dim(\text{even}) \times \dim(\text{odd}) + \dim(\text{odd}) \times \dim(\text{even}) = 2 \times \dim(\text{even}) \times \dim(\text{odd})$:
- n=1: $2 \times 4 \times 4 = 32$ ✓
- n=2: $2 \times 11 \times 8 = 176$ ✓
- n=3: $2 \times 22 \times 12 = 528$ ✓

#### Consistency
