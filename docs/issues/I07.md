### Response

**Status**: done.

**Odd linear map $f$ (requirement 1).** $f$ is parity-reversing, so the admissible maps are the elementary maps $f_{ij}$ with $f_{ij}(X_j)=X_i$, $p(X_i)\ne p(X_j)$, and $f_{ij}(X_k)=0$ for $k\ne j$. A general odd map is $f=\sum\phi_{ij}f_{ij}$, and $\delta f=\sum\phi_{ij}\,\delta f_{ij}$. The number of elementary maps is $2\,d_0 d_1$: 32, 176, 528 for $n=1,2,3$. Storing $\delta f_{ij}$ for each elementary map therefore describes the whole image of $\delta$ on odd maps.

**Coboundary (requirement 2).** $(\delta f)(X,Y)=(-1)^{p(X)}[X,f(Y)]-(-1)^{(p(X)+1)p(Y)}[Y,f(X)]-f([X,Y])$, computed from the Schema 1 JSON table (`src/C_coboundary.py`). Output: `data/C_{n}_coboundary.json` (Schema 4), with 394, 4878, and 22346 non-zero coefficients for $n=1,2,3$.

**Checks.**

| check | result |
|---|---|
| graded anti-symmetry of $\delta f_{ij}$ | 0 failures (all maps, $n=1,2$; 40 sampled maps, $n=3$) |
| parity: $(\delta f)(X,Y)$ has parity $p(X)+p(Y)+1$ | 0 failures |
| cocycle condition, in the $\kappa$-left convention (same as $\gamma$) | 0 failures |

For $n=3$ the cocycle check uses a fixed random sample of 40 of the 528 maps (seed 20261008), for time reasons. By linearity this is a sample, not a proof for all maps; $n=1,2$ were checked on all maps.

**Why the cocycle check is meaningful.** Passing checks would prove nothing if the test were insensitive. The negative control `test_sign_flip_in_coboundary_is_detected` flips the sign of the $f([X,Y])$ term and confirms that the checks reject the result. The test passes, so the check does detect a wrong coboundary formula. In the same way, the cocycle check reproduced the convention question for $\gamma$ (decision A7): in the right-$\kappa$ convention $\gamma$ failed, in the left convention it passed.

**Consistency with Layer 1 (basis).** Every $Z$ in $\delta f$ is a basis label, and parities match.
