### Response

#### Definition of f
General odd linear map on the Layer-1 basis Z_0..Z_{N-1} (global order odd + even):
f(Z_j) = Σ_i φ_{i,j} Z_i with φ_{i,j} = 0 unless p(Z_i) ≠ p(Z_j) (parity reversing), i.e. 2·dim g₀·dim g₁ free
parameters: 32 (n=1), 176 (n=2), 528 (n=3). (δf)_{XYZ} is computed with exactly the formula of
`C_coboundary_definition.md`, using the Schema 1 structure constants, as exact linear forms in φ.

#### Decision: central part
Schema 2 showed that the deformed bracket has a κK component γ_K for mixed-parity pairs. A g-valued f can never
produce a K term, so to allow a fair comparison in I08 I also included the optional central odd map
h: g → CK, h(Z_j) = ψ_j K for odd Z_j, with (δh)(X,Y) = −h([X,Y]) (K is central). Options considered: (a) ignore the
κK part (pure g-valued triviality), (b) treat it as an obstruction, (c) include h. Layer 4 stores (c) separately
(`coboundary_central`) so I08 can evaluate (a), (b) and (c).

#### Sign convention check
The formula in the math doc is consistent with κ placed on the left: from φ(X) = X + κ f(X) one gets
[φX, φY]_γ = φ([X,Y]_0) ⇔ γ = −δf (with the doc's δ), so "γ = δf up to scalar" (f → −f) is the right criterion.
Numerically: for random integer φ, ψ, δf + δh satisfies the first-order deformed Jacobi identity of I05 (δ² = 0,
`delta_squared_zero_random_f_failures = 0`), while a random odd cochain fails it (unit test), and inner odd
derivations f = ±ad_E lie in the kernel of δ (unit test).
