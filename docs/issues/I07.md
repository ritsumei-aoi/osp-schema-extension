#### 1. Definition of the odd map $f$ (Requirement 1)

Options considered for "the" odd linear map of Layer 4:

| Option | Description | Verdict |
|---|---|---|
| A (chosen) | Canonical candidate from the oscillator shift (below), depending linearly on gb | gives the reference coboundary that should reproduce $\gamma$ if the deformation is trivial; this is what I08 needs to compare against Layer 3 |
| B | Generic $f$ with all $2\cdot\dim\mathfrak g_{\bar0}\cdot\dim\mathfrak g_{\bar1}$ unknowns $\phi_{ij}$ | not a data layer but a linear system; used in I08 as the *search* over all $f$ |
| C | Inner maps $f = \mathrm{ad}(z)$, $z$ odd | $\delta(\mathrm{ad}\,z) = 0$ (they are 1-cocycles), so they can never produce $\gamma \neq 0$ |

**Derivation of option A.** Set $c_k^s := \mathrm{gb}_{+,k,s}a_1^- + \mathrm{gb}_{-,k,s}a_1^+$ and
$\tilde b_k^s := b_k^s + \kappa c_k^s$. Then, using $\{a_1^\tau,a_1^\sigma\}=\delta_{\tau,-\sigma}$ and $\kappa a = -a\kappa$,
$$[\tilde b_k^s, a_1^\sigma] = -\mathrm{gb}_{\sigma,k,s}\kappa + \kappa\{c_k^s, a_1^\sigma\} = -\mathrm{gb}_{\sigma,k,s}\kappa + \mathrm{gb}_{\sigma,k,s}\kappa = 0,$$
and $[\tilde b, \tilde b'] = [b,b']$ because every correction is $O(\kappa^2)=0$. So $(\tilde b, a_1)$ satisfy the
**undeformed** relations inside the deformed algebra, and $\phi: Z(b,a)\mapsto Z(\tilde b,a)$ is an algebra
homomorphism. Writing $\phi(Z) = Z + \kappa F(Z)$ (κ leftmost) and expanding $[\phi X,\phi Y\} = \phi([X,Y\}_0)$
to first order gives
$$\gamma(X,Y) = F([X,Y]) - (-1)^{|X|}[X,F(Y)] - [F(X),Y] = -(\delta F)(X,Y) = (\delta f)(X,Y),\qquad f := -F,$$
with exactly the $\delta$ of `C_coboundary_definition.md` (the sign bookkeeping was verified by the code, see below).
Explicitly, for the basis:
* even $Z$ (purely bosonic words): $f(Z) = -\sum_{\text{boson letters}} (\text{letter replaced by } c)$, e.g.
  $f(E_{2\delta_k}) = -2(\mathrm{gb}_{+,k,+}E_{-\varepsilon+\delta_k} + \mathrm{gb}_{-,k,+}E_{\varepsilon+\delta_k})$,
  $f(H_1) = \ldots$ (all odd, $\mathfrak g$-valued);
* odd $Z = E_{+\varepsilon, s\delta_k} = a_1^+b_k^s$: $f(Z) = \mathrm{gb}_{+,k,s}\,a_1^+a_1^- = \mathrm{gb}_{+,k,s}(N_a - \tfrac12) + \tfrac12\mathrm{gb}_{+,k,s}K$;
* odd $Z = E_{-\varepsilon, s\delta_k} = a_1^-b_k^s$: $f(Z) = \mathrm{gb}_{-,k,s}\,a_1^-a_1^+ = -\mathrm{gb}_{-,k,s}(N_a-\tfrac12) + \tfrac12\mathrm{gb}_{-,k,s}K$.

So $f$ is $\mathfrak g$-valued on $\mathfrak g_{\bar 0}$ but on $\mathfrak g_{\bar1}$ it has a **$K$-component**
$\lambda(E_{\sigma\varepsilon+s\delta_k}) = \tfrac12\mathrm{gb}_{\sigma,k,s}$. Since the definition requires $f:\mathfrak g\to\mathfrak g$,
Layer 4 stores the $\mathfrak g$-valued part in `f_map` and $\lambda$ separately in `f_K_component`
(`f(Z_j) = Σ_i φ_ij Z_i` as in the parameterization of §3 of the definition).

#### 2. Coboundary coefficients (Requirement 2)

`src/C_coboundary.py` computes $f$ by letter substitution in the oscillator engine (`OscAlgebra.substitute`),
decomposes $F(Z)$ exactly in basis ∪ {K}, then evaluates $(\delta f)(X,Y)$ for all ordered pairs with the
literal formula $(-1)^{|X|}[X,f(Y)] - (-1)^{(|X|+1)|Y|}[Y,f(X)] - f([X,Y])$ using the Schema 1 bracket table
(from `C_{n}_structure.json`) — i.e. the coboundary is computed from Layer 1 data, independently of the
deformed engine. The $K$-terms $-\lambda([X,Y])K$ that the $K$-component would contribute are stored under
`K_extension` (nothing else in $\delta$ sees $\lambda$ since $K$ is central).
