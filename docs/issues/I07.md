- Computed the coboundary 2-cochain $\delta f_{ij}: \mathfrak{g} \otimes \mathfrak{g} \to \mathfrak{g}$ for each elementary map $f_{ij}(Z_j) = Z_i$ using the graded formula:
  $$ (\delta f_{ij})(X, Y) = (-1)^{p(X)} \delta_{Y, Z_j} [X, Z_i\} - (-1)^{(p(X)+1)p(Y)} \delta_{X, Z_j} [Y, Z_i\} - c_{X, Y}^j Z_i. $$
