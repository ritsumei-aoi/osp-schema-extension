#### Definition of f
$f(Z_j) = \sum_i \phi_{ij} Z_i$ over the Schema 1 PBW-ordered basis (1-based indices, map stored in
`odd_map.index`), restricted to $p(Z_i)\neq p(Z_j)$ (odd map). Parameter counts: $2\cdot(2n^2+n+1)\cdot 4n$
= 32 / 176 / 528 for n = 1/2/3. In addition, for odd $Z_j$ an optional central component $\phi_{K,j}K$
($K$ even, so this is still parity-reversing) — 4n parameters `phi_K_j`. Setting all `phi_K_j = 0` gives the strict
$f: g\to g$ of `C_coboundary_definition.md`; the extension is kept so I08 can examine the "up to scalar" clause
(γ has a `K` part, see I05).

#### Computation
`src/C_coboundary.py` reads `C_{n}_structure.json` and evaluates, for all ordered pairs,
$(\delta f)(X,Y) = (-1)^{p(X)}[X,f(Y)] - (-1)^{(p(X)+1)p(Y)}[Y,f(X)] - f([X,Y])$ symbolically (exact linear forms in φ;
$[X,K]=0$). Output `C_{n}_coboundary.json`: `odd_map`, `coboundary_formula`, `coboundary: [{X,Y,Z,coeff}]` (spec §4).
