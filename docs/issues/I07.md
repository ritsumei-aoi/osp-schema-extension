### Response

**Decisions:**
1. **Coboundary Logic**: Implemented `src/C_coboundary_generator.py`. It parameterizes the odd linear map $f: \mathfrak{g} \to \mathfrak{g}$ using variables $\phi_{c,a}$, tracking the definition $(\delta f)(X, Y) = (-1)^{p(X)}[X, f(Y)] - (-1)^{(p(X)+1)p(Y)}[Y, f(X)] - f([X, Y])$.
2. **Schema 4 Definition**: The resulting evaluation yields `delta_f_constants`, dictating the coefficients of $\phi_{c,a}$ associated with each target generator resulting from the coboundary operator applied to pairs of generators.
3. **Parity Preservation**: Variables $\phi_{c,a}$ are generated purely for parity-reversing maps (i.e. where $p(c) \neq p(a)$).
