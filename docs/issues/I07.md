### Response

#### Decisions and Results

**1. Odd linear map f**: Parameterized by φ_{source, target} where:
- f(target) = Σ_{source} φ_{source, target} · source
- p(source) ≠ p(target) (f reverses parity)

Parameter counts:
- C(2): 2 × 4 × 4 = 32 phi parameters
- C(3): 2 × 11 × 8 = 176 phi parameters
- C(4): 2 × 22 × 12 = 528 phi parameters

**2. Coboundary formula**: (δf)(X, Y) is computed using:
(δf)(X, Y) = (-1)^{p(X)} [X, f(Y)] - (-1)^{(p(X)+1)p(Y)} [Y, f(X)] - f([X, Y])

Each term is expanded using the structure constants from Schema 1. The result is linear in the φ parameters.

**3. Schema 4 output**:
- `C_1_coboundary.json`: 192 coboundary entries
- `C_2_coboundary.json`: 2418 entries
- `C_3_coboundary.json`: 11128 entries

Each entry records (X, Y, Z, phi_source, phi_target, coeff), meaning (δf)(X,Y)^Z includes coeff × φ_{source, target}.

**4. Consistency**: All generator references validated against Schema 1 basis. All phi parameters satisfy the parity-reversal constraint. Basis and parity data match Schema 1 exactly.
