### Response

**Implementation**: `src/C_coboundary.py`

**Coboundary formula**:
```
(delta f)(X,Y) = (-1)^{p(X)} [X, f(Y)]
               - (-1)^{(p(X)+1)*p(Y)} [Y, f(X)]
               - f([X,Y])
```

**f parametrization**: f(Z_j) = Σ_{i: p(Z_i)=1-p(Z_j)} phi_{Z_j, Z_i} Z_i.
Parity constraint: f maps even ↔ odd. For n=1, the phi parameters are:
- phi_{H_k, E_...} (even → odd): 2 Cartans × 4 odds = 8 params
- phi_{E_root, E_...} (even → odd): roots × 4 odds (per mode)
- phi_{E_odd, H_k/E_root} (odd → even): 4 odds × even count

**Algorithm**: For each pair (X, Y) with Xi ≤ Yi:
1. Term 1: (-1)^{pX} · Σ_i phi_{Yi,i} [X, Zi] (where p(Zi) ≠ pY).
2. Term 2: -(-1)^{(pX+1)pY} · Σ_i phi_{Xi,i} [Y, Zi] (where p(Zi) ≠ pX).
3. Term 3: -f([X,Y]) = -Σ_{W in [X,Y]} c_W Σ_i phi_{Widx,i} Zi (where p(Zi) ≠ p(W)).

**Results**:
```
n=1: 110 coboundary entries
n=2: 1390 coboundary entries
n=3: 7024 coboundary entries
```

Sample (n=1):
```
(delta f)(H_1,H_2) -> E_eps1_del1_pp: phi_{H_1,E_eps1_del1_pp} + 2*phi_{H_2,E_eps1_del1_pp}
```
This means: [H_1, f(H_2)] contains phi_{H_2, E_pp} · [H_1, E_pp] = phi_{H_2,E_pp}·2·E_pp, plus contributions from [H_2, f(H_1)] and f([H_1,H_2])=0. Coefficient 2 comes from the Cartan eigenvalue [H_1, E_eps1_del1_pp] = 2 E_eps1_del1_pp. ✓
