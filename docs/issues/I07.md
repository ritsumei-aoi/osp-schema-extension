### Response

Implemented `src/C_coboundary.py`.

**Choice of f.** The map f : g → g is parameterized **fully generally** by
a parity-reversing matrix: f(Z_j) = sum_{i: p(Z_i)≠p(Z_j)} φ_{i,j} Z_i,
with one sympy symbol φ_{i,j} per compatible (target, source) pair. This
keeps Schema 4 agnostic to any specific trivialization ansatz and lets
Issue I08 solve for φ against γ directly.

**Computation.** Bracket lookups come from the Schema 1 structure constants
(both orderings reconstructed with graded antisymmetry). The coboundary

   (δf)(X,Y) = (−1)^{p(X)}[X, f(Y)] − (−1)^{(p(X)+1)p(Y)}[Y, f(X)] − f([X,Y])

is evaluated with sympy; coefficients are linear in φ. Zero entries are
dropped.

**Dimensions**: φ-count = 2 · (dim even) · (dim odd) because each basis
element can map to any opposite-parity target. For n = 1, 2, 3:
2·4·4 = 32, 2·11·8 = 176, 2·22·12 = 528.

**Output.**
```
$ python3 -m src.C_coboundary
wrote data/C_1_coboundary.json (32 phi, 212 entries)
wrote data/C_2_coboundary.json (176 phi, 2748 entries)
wrote data/C_3_coboundary.json (528 phi, 13976 entries)
```

Entries use only basis labels from Schema 1, so Layer 1 consistency holds
by construction.
