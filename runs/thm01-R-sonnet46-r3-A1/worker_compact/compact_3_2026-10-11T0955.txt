2. Key Technical Concepts:

- **C(n+1) = osp(2|2n)**: Lie superalgebra; fermionic ε, bosonic δ₁,...,δₙ; dim = (2n²+n+1)|4n
- **Oscillator realization**: Fermionic CAR pair a₁⁺, a₁⁻ + bosonic CCR b_k⁺, b_k⁻
- **PBW ordering (Option A approved)**: κ < [odd: pp→pm→mp→mm by k] < [even: Cartans, pos, neg, mixed]
- **gb parameters**: 4n deformation parameters `gb_a1{σ}_b{k}{s}`; Convention A: `[b_j^s, a_1^σ] = −gb_{σ,j,s}·κ`
- **K-include (approved)**: γ(X,Y) can include central element K
- **4-layer schema**: Schema 1 (structure), Schema 2 (gamma/symbolic), Schema 3 (evaluated/Profile A), Schema 4 (coboundary/symbolic)
- **Schema 3 format**: Two-layer JSON per (X,Y) pair: `g_part` (from Schema 1) + `kappa_part` (evaluated γ at gb=1)
- **Schema 4 format**: Symbolic coboundary entries `{X, Y, phi_label, Z, coeff}` where `phi_{out_1idx}_{in_1idx}` are 1-indexed
- **Coboundary formula**: `(δf)(X,Y) = (-1)^{p(X)}[X,f(Y)] − (-1)^{(p(X)+1)p(Y)}[Y,f(X)] − f([X,Y])`
- **Triviality condition**: γ(gb) ∈ Im(δ) ⟺ augmented RREF constraint rows give all gb=0
- **K-obstruction**: `(δf)(X,Y)[K] = 0` for ALL f: g → g, but `γ(X,Y)[K] ≠ 0` for nonzero gb — irremovable obstruction
- **Exact rational arithmetic**: All computations use Python `Fraction` for exact results over Q
