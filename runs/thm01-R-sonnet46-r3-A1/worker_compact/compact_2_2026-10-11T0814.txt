2. Key Technical Concepts:

- **C(n+1) = osp(2|2n)**: Lie superalgebra; fermionic direction ε, bosonic δ₁,…,δₙ; dim = (2n²+n+1)|4n
- **Oscillator realization**: Standard fermionic pair a₁⁺, a₁⁻ (CAR: {a₁⁻, a₁⁺}=1) + bosonic b_k⁺, b_k⁻ (CCR: [b_k⁻, b_l⁺]=δ_{kl})
- **PBW ordering (Option A)**: `a_1_p < a_1_m < b_1_p < b_1_m < b_2_p < b_2_m < ...`; generators: `κ < [odd: pp→pm→mp→mm by k] < [even: Cartans, pos, neg, mixed]`
- **Graded bracket**: [X, Y} = XY − (−1)^{p(X)p(Y)} YX
- **Graded Jacobi identity** (correct cyclic form): `(−1)^{p(x)p(z)} [[x,y},z} + (−1)^{p(y)p(x)} [[y,z},x} + (−1)^{p(z)p(y)} [[z,x},y} = 0`
- **Bubble sort normalization**: PBW normalization by swapping adjacent pairs with commutator insertion
- **Gaussian elimination over Q** (`Fraction`): used in `decompose()` to express bracket results in the basis
- **4-layer schema**: Schema 1 (structure), Schema 2 (gamma), Schema 3 (evaluated), Schema 4 (coboundary)
- **gb_matrix**: 4n deformation parameters `gb_a1{σ}_b{k}{s}` (σ,k,s indexing)
- **Convention A (approved)**: `[b_j^s, a_1^σ] = −gb_{σ,j,s}·κ` (fermionic-first, minus sign, from definition doc)
- **K-include (approved)**: γ(X,Y) can include central element K (= scalar identity 1); κ·K = κ in L = g ⊕ κg
- **Deformed algebra**: κ is central and nilpotent (κ²=0); κ¹ corrections tracked separately in PBW normalization
- **Schema 3**: Evaluated structure — substitute concrete gb values into Schema 2 gamma to get numerical deformed brackets
