### 3. PBW Ordering — Two Options for Approval

The B(0,n) PBW convention is:
```
κ < [odd] < [even]
```
The even sector ordering is fixed by the root structure (same as above). The question is how to order the 4n odd generators.

#### Option A: ε-sign-first ordering

Group all ε+ generators first, then all ε− generators. Within each group, order by bosonic index k ascending, then δ-sign (+ before −).

```
κ  <  E_eps1_del1_pp, E_eps1_del1_pm, ..., E_eps1_del{n}_pp, E_eps1_del{n}_pm   [ε+]
    < E_eps1_del1_mp, E_eps1_del1_mm, ..., E_eps1_del{n}_mp, E_eps1_del{n}_mm   [ε−]
    <  [even: H_1,...,H_{n+1}, ...]
```

*Rationale*: Groups by the fermionic oscillator (a_1^+ vs a_1^−), mirroring how B(0,n) separated positive/negative odd roots (`E_del{k}_p` then `E_del{k}_m`). Follows the natural PBW word order given oscillator ordering `a_1_p < a_1_m`.

#### Option B: bosonic-index-first ordering

Group by bosonic index k. Within each k-block, list all four sign combinations in order pp, pm, mp, mm.

```
κ  <  E_eps1_del1_pp, E_eps1_del1_pm, E_eps1_del1_mp, E_eps1_del1_mm   [k=1]
    < E_eps1_del2_pp, E_eps1_del2_pm, E_eps1_del2_mp, E_eps1_del2_mm   [k=2]
    < ...
    <  [even: H_1,...,H_{n+1}, ...]
```

*Rationale*: Keeps all generators involving the same bosonic mode b_k together. Useful when iterating over bosonic index in computations.

$$[X, Y]_{\text{eval}} = [X, Y]_0 + \kappa \cdot \gamma(X, Y)\big|_{gb \to \text{values}}$$
