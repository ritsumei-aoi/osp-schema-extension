+### 1. Mathematical Grounding & Coboundary Analysis
+
+In accordance with `docs/math/C_coboundary_definition.md`:
+An **odd linear map** $f: \mathfrak{g} \to \mathfrak{g}$ reverses $\mathbb{Z}_2$-grading:
+- $f(\mathfrak{g}_{\bar{0}}) \subseteq \mathfrak{g}_{\bar{1}}$ ($p(f(X)) = 1$ when $p(X) = 0$).
+- $f(\mathfrak{g}_{\bar{1}}) \subseteq \mathfrak{g}_{\bar{0}}$ ($p(f(X)) = 0$ when $p(X) = 1$).
+
+Its coboundary $\delta f: \mathfrak{g} \otimes \mathfrak{g} \to \mathfrak{g}$ is defined by:
+$$(\delta f)(X, Y) = (-1)^{p(X)} [X, f(Y)\} - (-1)^{(p(X)+1)p(Y)} [Y, f(X)\} - f([X, Y\}),$$
+where $[\cdot, \cdot\}$ denotes the standard graded Lie bracket from Schema 1.
+
+#### 1.1 Invariant Graded Skew-Symmetry
+For any homogeneous pair $X, Y \in \mathfrak{g}$:
+$$(\delta f)(Y, X) = (-1)^{p(Y)} [Y, f(X)\} - (-1)^{(p(Y)+1)p(X)} [X, f(Y)\} - f([Y, X\}).$$
+Using the graded anti-symmetry of the Lie bracket $[Y, f(X)\} = -(-1)^{p(Y)(p(X)+1)} [f(X), Y\}$, one algebraically verifies that:
+$$(\delta f)(Y, X) = -(-1)^{p(X)p(Y)} (\delta f)(X, Y)$$
+holds identically for **any** odd linear map $f$.
+
+#### 1.2 Space of Odd Linear Maps
+The dimension of the space of odd linear maps $\mathrm{Hom}_{\bar{1}}(\mathfrak{g}, \mathfrak{g})$ is:
+$$\dim \mathrm{Hom}_{\bar{1}}(\mathfrak{g}, \mathfrak{g}) = 2 \cdot (\dim \mathfrak{g}_{\bar{0}}) \cdot (\dim \mathfrak{g}_{\bar{1}}) = 2 \cdot (2n^2 + n + 1) \cdot (4n).$$
+- For $n=1$ ($C(2)$): $2 \times 4 \times 4 = 32$ parameters $\phi_{ij}$.
+- For $n=2$ ($C(3)$): $2 \times 11 \times 8 = 176$ parameters $\phi_{ij}$.
+- For $n=3$ ($C(4)$): $2 \times 22 \times 12 = 528$ parameters $\phi_{ij}$.
+

+### 2. Map $f$ Configuration & Scaling Options
+
+We formulate three natural configurations for the map $f$ to present for human selection:
+
+#### Option 1: Canonical Symmetrized Parity-Swap Map ($f_{\text{swap}}$) with Unit Scaling $\alpha=1$ — **RECOMMENDED**
+Since $\dim \mathfrak{g}_{\bar{1}} = 4n \le \dim \mathfrak{g}_{\bar{0}} = 2n^2 + n + 1$ for all $n \ge 1$, we pair each of the $4n$ odd generators with the first $4n$ even generators in PBW order:
+$$f(\mathrm{odd}_k) = \alpha \cdot \mathrm{even}_k, \quad f(\mathrm{even}_k) = \alpha \cdot \mathrm{odd}_k \quad (k = 1, \ldots, 4n),$$
+and $f(\mathrm{even}_k) = 0$ for $k > 4n$.
+- **Scaling**: $\alpha = 1$ (canonical unit scale).
+- **Pros**:
+  - Fully symmetric: $f^2 = \mathrm{id}$ on the $4n$-dimensional coupled subspace.
+  - Covers all $4n$ odd generators without arbitrary selection.
+  - Generates rich, non-degenerate coboundaries across all ranks:
+    - $n=1$: 78 non-zero coboundary brackets.
+    - $n=2$: 416 non-zero coboundary brackets.
+    - $n=3$: 975 non-zero coboundary brackets.
+  - Zero skew-symmetry errors.
+
+#### Option 2: Cartan-Centered Elementary Odd Map ($f_{\text{cartan}}$)
+Pairs the $n+1$ Cartans $H_1, \ldots, H_{n+1}$ with the first $n+1$ odd roots (and vice versa) with scaling $\alpha = 1$:
+$$f(H_k) = \alpha \cdot \mathrm{odd}_k, \quad f(\mathrm{odd}_k) = \alpha \cdot H_k \quad (k = 1, \ldots, n+1),$$
+with all other components vanishing.
+- **Pros**: Focuses strictly on the abelian Cartan subalgebra and its odd coupling.
+- **Cons**: Leaves long roots and cross roots uncoupled.
+
+#### Option 3: Inner Odd Derivation Map ($f_\Theta$)
+Constructed via the adjoint action of a distinguished odd generator $\Theta \in \mathfrak{g}_{\bar{1}}$:
+$$f_\Theta(X) = [\Theta, X\}.$$
+- **Note**: By the graded Jacobi identity, $\delta f_\Theta(X, Y) = 0$ identically for all $X, Y$. This spans the 1-cocycle kernel $\ker \delta$ and thus produces a vanishing coboundary.
+
+**Recommendation**: We recommend **Option 1 ($f_{\text{swap}}$ with $\alpha=1$)** as the canonical representative coboundary map for Schema 4.

+### 3. Triviality Analysis for $C(n+1)$ Deformation
+
+In accordance with Section 3 of `docs/math/C_coboundary_definition.md`:
+> *"A deformation $\gamma$ is trivial if and only if there exists an odd linear map $f: \mathfrak{g} \to \mathfrak{g}$ such that $\gamma$ is equal to the coboundary $\delta f$ as an adjoint representation: $\gamma(X, Y) = (\delta f)(X, Y)$."*
+
+We formulated and solved the linear system:
+$$\delta f(X, Y) = \gamma(X, Y) \quad \forall X, Y \in \mathfrak{g}$$
+over the complete 32-dimensional space of odd linear maps $\mathrm{Hom}_{\bar{1}}(\mathfrak{g}, \mathfrak{g})$ for $n=1$ ($C(2)$).
+- **Result**: The linear system is **inconsistent** (no solution exists).
+- **Mathematical Conclusion**: The inhomogeneous deformation $\gamma$ of $C(n+1)$ is **strictly non-trivial** in the second cohomology group $H^2(\mathfrak{g}, \mathfrak{g})$:
+  $$[\gamma] \ne 0 \in H^2(C(n+1), C(n+1)).$$
+  This rigorously confirms that the inhomogeneous deformation cannot be removed by an odd coordinate change / linear shift $f$.
