### 1. Implementation Overview (`src/C_generators.py`)

The structure constant generator has been designed and implemented using exact rational arithmetic (`fractions.Fraction` and `sympy`):

1. **Oscillator Algebra Engine**:
   - `Monomial` and `Poly` classes implementing the normal-ordered associative algebra generated by $(a_1^\pm, b_k^\pm)_{k=1}^n$.
   - Enforces canonical anticommutation relations (CAR): $\{a_1^-, a_1^+\} = 1$, $(a_1^\pm)^2 = 0$.
   - Enforces canonical commutation relations (CCR): $[b_i^-, b_j^+] = \delta_{ij}$, $[b_i^\pm, b_j^\pm] = 0$.
   - Commuting mixed relations: $[b_k^\pm, a_1^\pm] = 0$.

2. **Basis & Realization Builder (`build_c_generators(n)`)**:
   - **Cartan subalgebra** ($\dim = n+1$):
     - $H_1 = a_1^+ a_1^- + b_1^+ b_1^-$
     - $H_k = b_{k-1}^+ b_{k-1}^- - b_k^+ b_k^-$ ($2 \le k \le n$)
     - $H_{n+1} = -b_n^+ b_n^- - \tfrac{1}{2}$
   - **Long even roots** ($\dim = 2n$):
     - $E_{2\delta_k}^+ = (b_k^+)^2$, $E_{2\delta_k}^- = (b_k^-)^2$
   - **Short even roots** ($\dim = 2n(n-1)$):
     - $E_{\delta_i+\delta_j} = b_i^+ b_j^+$, $E_{-\delta_i-\delta_j} = b_i^- b_j^-$, $E_{\delta_i-\delta_j} = b_i^+ b_j^-$, $E_{-\delta_i+\delta_j} = b_i^- b_j^+$
   - **Odd roots** ($\dim = 4n$, Option A Boson Mode Block ordering):
     - For $k = 1, \dots, n$: `E_eps1_del{k}_pp` ($a_1^+ b_k^+$), `E_eps1_del{k}_pm` ($a_1^+ b_k^-$), `E_eps1_del{k}_mp` ($a_1^- b_k^+$), `E_eps1_del{k}_mm` ($a_1^- b_k^-$)

3. **Graded Bracket & Basis Decomposition (`compute_structure_constants(n)`)**:
   - Evaluates $[X, Y\} = XY - (-1)^{p(X)p(Y)} YX$ directly via oscillator polynomial multiplication.
   - Decomposes resulting quadratic polynomials into the PBW basis using exact rational linear solving (`sympy.gauss_jordan_solve`).
   - Generates the full Schema 1 JSON dictionary adhering to `docs/json_schema_specification.md`.
