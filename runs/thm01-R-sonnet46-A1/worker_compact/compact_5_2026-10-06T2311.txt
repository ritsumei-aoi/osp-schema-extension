2. Key Technical Concepts:

- **C(n+1) = osp(2|2n)**: Lie superalgebra with fermionic pair a_1^± (CAR: {a_1^-,a_1^+}=1) and bosonic oscillators b_k^± (CCR: [b_k^-,b_l^+]=δ_kl)
- **PBW ordering**: a_1_p < a_1_m < b_1_p < b_1_m < ... < b_n_p < b_n_m
- **Inhomogeneous deformation**: [b_j^s, a_1^σ]_γ = -gb_{σ,j,s}·κ, 4n parameters
- **Deformed bracket**: [X,Y]_γ = [X,Y]_0 + κ·γ(X,Y)
- **γ (Schema 2)**: symbolic cocycle with coeff_gb; K-terms from CCR/CAR reordering
- **identify_extended()**: solves (n+2)×(n+2) Cartan+K system (different for n=1 vs n≥2)
- **Schema 3**: evaluated γ with concrete gb values; g_part + kappa_part separation
- **Schema 4**: symbolic coboundary (δf)(X,Y) of odd linear map f:g→g
- **Coboundary formula**: (δf)(X,Y) = (-1)^{p(X)}[X,f(Y)] - (-1)^{(p(X)+1)p(Y)}[Y,f(X)] - f([X,Y])
- **φ parameters**: f(Z_j) = Σ_i φ_{ij}·Z_i where p(Z_i)≠p(Z_j)
- **Triviality condition**: γ = δf iff ∃ odd f s.t. Σ_m coeff_phi·φ_m = Σ_gb coeff_gb·gb for all (X,Y,Z)
- **K**: even central element (= scalar 1), excluded from g-basis; stored as "c":"K" in JSON
- **gb_label format**: `gb_{sigma}_{j}_{s}` (e.g., `gb_p_1_p` for [b_1^+, a_1^+] deformation)
- **phi_label format**: `phi_{image}_{domain}` (coefficient of Z_image in f(Z_domain))
- **Three gb profiles**: all_plus (all=1), diagonal (gb_p_j_p=gb_m_j_m=1), anti_diagonal (gb_p_j_m=gb_m_j_p=1)

  ```python
  def _solve_cartan_K(c_n1, c_N, c_const, n):
      alpha = {1: c_n1}
      if n == 1:
          alpha[2] = alpha[1] - c_N[1]  # H_2=H_{n+1} has m_1 coeff=-1
      else:
          alpha[2] = c_N[1] - alpha[1]
          for k in range(2, n):
              alpha[k+1] = c_N[k] + alpha[k]
          alpha[n+1] = -c_N[n] - alpha[n]
      alpha_K = c_const + Fraction(1,2) * alpha[n+1]
      return alpha, alpha_K
  ```
